# Հավելված ՀՀ կրթության և գիտության նախարարի 2014 թ. սեպտեմբերի 1-ի N 857-Ն հրամանի
ՆԱԽՆԱԿԱՆ ՄԱՍՆԱԳԻՏԱԿԱՆ (ԱՐՀԵՍՏԱԳՈՐԾԱԿԱՆ) ԿՐԹՈՒԹՅԱՆ 5-33.13.03 «ՌԱԴԻՈԷԼԵԿՏՐՈՆԱՅԻՆ ՄԻՋՈՑՆԵՐԻ ՏԵԽՆԻԿԱԿԱՆ ՍՊԱՍԱՐԿՈՒՄ ԵՎ ՆՈՐՈԳՈՒՄ» ՄԱՍՆԱԳԻՏՈՒԹՅԱՆ 5-33.13.03.01-3 «ՌԱԴԻՈՀԵՌՈՒՍՏԱՏԵՍԱՅԻՆ ՍԱՐՔԱՎՈՐՈՒՄՆԵՐ ՍՊԱՍԱՐԿՈՂ ԵՎ ՆՈՐՈԳՈՂ ՌԱԴԻՈՄԵԽԱՆԻԿ» ՈՐԱԿԱՎՈՐՄԱՆ ՊԵՏԱԿԱՆ ԿՐԹԱԿԱՆ ՉԱՓՈՐՈՇԻՉ
