# Հավելված ՀՀ քաղաքաշինության նախարարի 2015 թվականի օգոստոսի 5-ի N 186-Ն հրամանի
ՊԱՇՏՈՆԱԿԱՆ ՊԱՐԶԱԲԱՆՈՒՄ
ՀՀ կառավարության 2015 թվականի մարտի 19-ի N 596-Ն որոշման N 5 հավելվածի ձև 3-2 ձևաթղթում ավարտված շինարարական օբյեկտի շահագործման ընդունող հանձնաժողովի ակտի վերջնամասում ստորագրությունների վավերացման վերաբերյալ
Հայաստանի Հանրապետության կառավարության 2015 թվականի մարտի 19-ի N 596-Ն որոշման N 5 հավելվածի ձև 3-2 ձևաթղթի վերջնամասում ավարտված շինարարական օբյեկտը շահագործման ընդունող հանձնաժողովի ակտի վերջնամասում «ԿՏ» նշումը հստակեցված չէ, թե որ ստորագրության վավերացմանն է դա վերաբերում, և բացառված չէ ակտի վավերացում առանց հանձնաժողովի որևէ անդամի ստորագրության կամ ստորագրության փոփոխության պայմաններում:
Ելնելով վերոհիշյալից, ինչպես նաև տարաբնույթ մեկնաբանություններ բացառելու նպատակով, հիմք ընդունելով «Իրավական ակտերի մասին» Հայաստանի Հանրապետության օրենքի 87-րդ հոդվածի 1-ին մասը, 2-րդ մասի «ա» կետը և Հայաստանի Հանրապետության կառավարության 2002 թվականի հուլիսի 15-ի N 1294-Ն որոշման N 1 հավելվածի 14-րդ կետը, Հայաստանի Հանրապետության քաղաքաշինության նախարարությունը պարզաբանում է`
ՀՀ կառավարության 2015 թվականի մարտի 19-ի N 596-Ն որոշման N 5 հավելվածի ձև 3-2 ձևաթղթում ավարտված շինարարական օբյեկտի շահագործման ընդունող հանձնաժողովի ակտի վերջնամասում հանձնաժողովի կազմում ներգրավված կազմակերպությունների ներկայացուցիչների ստորագրությունները ենթակա են վավերացման այդ կազմակերպությունների կնիքով:
