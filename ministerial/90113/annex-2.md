# Հավելված N 2 Ձև N 1-ՀՀ-ամփոփ
ՏԵՂԵԿԱՆՔ
Հայաստանի Հանրապետության 2015 թվականի պետական բյուջեից ՀՀ համայնքների բյուջեներին «Ֆինանսական համահարթեցման մասին» ՀՀ օրենքով սահմանված կարգով ֆինանսական
համահարթեցման դոտացիաների գումարների հաշվարկներում օգտագործվող հողի հարկի գծով 2013 թվականի ելակետային տվյալների մասին
հազար դրամներով
