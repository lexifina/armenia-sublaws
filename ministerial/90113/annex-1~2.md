# Հավելված N 1 Ձև N 1-ԳՀ-ամփոփ
ՏԵՂԵԿԱՆՔ
Հայաստանի Հանրապետության 2015 թվականի պետական բյուջեից ՀՀ համայնքների բյուջեներին «Ֆինանսական համահարթեցման մասին» ՀՀ օրենքով սահմանված կարգով ֆինանսական համահարթեցման դոտացիաների գումարների հաշվարկներում օգտագործվող գույքահարկի գծով 2013 թվականի ելակետային տվյալների մասին
