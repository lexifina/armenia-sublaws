# ՀԱՎԵԼՎԱԾ 1 Հաստատված է ՀՀ ֆինանսների և էկոնոմիկայի նախարարի 27. 08.2002 թ. N 631-Ն հրամանով
Վիճակախաղերի կազմակերպիչների կողմից վիճակախաղերի կազմակերպման վերաբերյալ տեղեկությունների (հաշվետվությունների) ներկայացման ձև
1. Տպված տոմսերի մասին ամբողջական տեղեկատվություն պարունակող բազայի կառուցվածքը`
Անվանումը` PRINTED.DBF
Դաշտերի տիպերը և չափսերը`
{
NUMBER VARCHAR(20)
T1 NUMBER(6)
T2 NUMBER(6)
T3 NUMBER(6)
T4 NUMBER(6)
. . .
TN NUMBER(6)
}
Որտեղ T1, T2,,,TN այն դաշտերն են, որոնք պարունակում են տեղեկատվություն տոմսի կառուցվածքի մասին և հնարավորություն են տալիս ստանալ տոմսի ամբողջական պատկերը (шаxматка):
2. Վաճառված տոմսերի համարները պարունակող տվյալների բազայի կառուցվածքը`
Անվանումը` SALED.DBF
Դաշտերի տիպերը և չափսերը`
{
NUMBER VARCHAR(20)
}
3. Շահած տոմսերի համարները պարունակող տվյալների բազայի կառուցվածքը`
Անվանումը` Winned.DBF
Դաշտերի տիպերը և չափսերը`
{
NUMBER VARCHAR(20)
PRISE NUMBER(10)
TICKET NUMBER(3)
}
Բազաները պետք է լինեն dBase IV տիպի և չպետք է պարունակեն ինդեքսներ:
Տոմսերի համարները բոլոր բազաներում պետք է ներկայացվեն նույն ձևով` ներառյալ տասնորդական նիշերի սիմվոլների դիրքը և սիմվոլների ռեգիստրի նմանատիպությունը: Հակառակ դեպքում համակարգը սխալ կտա նշված դաշտին համապատասխան տողի վրա:
