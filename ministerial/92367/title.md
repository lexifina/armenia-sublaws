Երևան | ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԲՆԱՊԱՀՊԱՆՈՒԹՅԱՆ ՆԱԽԱՐԱՐ 23 հունիսի 2014 թ. N 153-Ն ք. Երևան | ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿՐԹՈՒԹՅԱՆ ԵՎ ԳԻՏՈՒԹՅԱՆ ՆԱԽԱՐԱՐ 1 հուլիսի 2014 թ. N 703-Ն ք. Երևան | ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆՆ ԱՌԸՆԹԵՐ ՄԻՋՈՒԿԱՅԻՆ ԱՆՎՏԱՆԳՈՒԹՅԱՆ ԿԱՐԳԱՎՈՐՄԱՆ ՊԵՏԱԿԱՆ ԿՈՄԻՏԵԻ ՆԱԽԱԳԱՀ 7 հուլիսի 2014 թ. N 118-Ն ք. Երևան

Ղեկավարվելով «Իրավական ակտերի մասին» ՀՀ օրենքի 19-րդ հոդվածի 2-րդ մասով և հիմք ընդունելով Հայաստանի Հանրապետության կառավարության 2013թ. մայիսի 23-ի նիստի «Համընդհանուր լաբորատոր ցանցի ստեղծման ռազմավարական ծրագրին և 2013-2014 թվականների միջոցառումների ցանկին հավանություն տալու մասին» N 20 արձանագրային որոշման հավելված 2-ի 18-րդ կետի 1-ին ենթակետի պահանջները`
