# Հավելված N 1 ՀՀ առողջապահության նախարարի 2013 թվականի սեպտեմբերի 28-ի N 57-Ն հրամանի
Չ Ա Փ Ո Ր Ո Շ Ի Չ
ԲՆԱԿՉՈՒԹՅԱՆԸ ՊԵՏՈՒԹՅԱՆ ԿՈՂՄԻՑ ԵՐԱՇԽԱՎՈՐՎԱԾ ԱՆՎՃԱՐ ԿԱՄ ԱՐՏՈՆՅԱԼ ՊԱՅՄԱՆՆԵՐՈՎ ԲԺՇԿԱԿԱՆ ՕԳՆՈՒԹՅԱՆ ԵՎ ՍՊԱՍԱՐԿՄԱՆ ՇՐՋԱՆԱԿՆԵՐՈՒՄ ՆՈՐԱԳՈՒՅՆ ԵՎ ԹԱՆԿԱՐԺԵՔ ՏԵԽՆՈԼՈԳԻԱՆԵՐԻ ԿԻՐԱՌՄԱՄԲ ՄԱՏՈՒՑՎՈՂ ԲԺՇԿԱԿԱՆ ԾԱՌԱՅՈՒԹՅՈՒՆՆԵՐԻ
1. Սույն հրամանի հավելված N 2-ով հաստատված նորագույն և թանկարժեք տեխնոլոգիաներով մատուցվող բժշկական ծառայությունները տրամադրվում են վճարովի հիմունքներով բնակչության բոլոր խմբերի համար, այդ թվում նաև Հայաստանի Հանրապետության կառավարության 2004 թվականի մարտի 4-ի N 318-Ն որոշման հավելված 1-ով սահմանված բնակչության սոցիալապես անապահով ու առանձին (հատուկ) խմբերի ցանկում ընդգրկված Հայաստանի Հանրապետության քաղաքացիների համար:
2. Սույն հրամանի հավելված N 2-ով սահմանված նորագույն և թանկարժեք տեխնոլոգիաներով մատուցվող բժշկական ծառայությունները կարող են իրականացվել պետության կողմից երաշխավորված անվճար կամ արտոնյալ պայմաններով բժշկական օգնության և սպասարկման շրջանակներում առողջապահության նախարարի հրամանով` Հայաստանի Հանրապետության օրենսդրությամբ սահմանված լիազորությունների շրջանակում` ՀՀ ֆինանսների նախարարի հետ համաձայնեցված ծառայությունների փոխհատուցման գներով:
3. Սույն հրամանի հավելված N 2-ով հաստատված ցանկի 1-ին կետի 3-րդ ենթակետով, 4-րդ կետի 3-րդ ենթակետով, 7-րդ կետի 1-ին, 2-րդ ենթակետերով, 9-րդ կետի 1-ին, 2-րդ ենթակետերով նախատեսված բժշկական ծառայությունները կարող են իրականացվել Հայաստանի Հանրապետության առողջապահության նախարարի հրամանով:
4. Սույն հրամանի հավելված N 2-ով հաստատված ցանկի 5-րդ կետի 2-րդ ենթակետում նշված տեսակի դեպքում ուղեգրումը իրականացվում է Հայաստանի Հանրապետության առողջապահության նախարարության կողմից` Հայաստանի Հանրապետության առողջապահության նախարարի հրամանով հաստատված անվճար բժշկական օգնության և հետազոտությունների ուղեգրման կազմակերպման կարգի համաձայն:
5. Բժշկական կազմակերպություններում մարդասիրական օգնության ճանապարհով ստացվող լինզաների և էնդոպրոթեզների առկայության, կամ քաղաքացիների կողմից լինզաների և էնդոպրոթեզների ձեռքբերման դեպքում սույն հրամանի հավելված N 2-ով հաստատված ցանկի 3-րդ կետի 4-րդ ենթակետով, 4-րդ կետի 1-ին ենթակետով նախատեսված դեպքերում բժշկական օգնությունը և սպասարկումն իրականացվում է պետական պատվերի շրջանակներում` առանց Հայաստանի Հանրապետության առողջապահության նախարարության կողմից ուղեգրման:
6. Սույն հրամանի հավելված N 2-ով հաստատված ցանկի 1-ին կետի 5-րդ ենթակետով, 3-րդ կետի 3-րդ ենթակետով նախատեսված դեպքերում ուղեգրումը իրականացվում է ինչպես Հայաստանի Հանրապետության առողջապահության նախարարության, այնպես էլ ամբուլատոր-պոլիկլինիկական հաստատությունների կողմից:
7. Սույն հրամանի հավելված N 2-ով հաստատված ցանկի 2-րդ կետի 1-ին ենթակետով նախատեսված դեպքում ուղեգրումն իրականացվում է ինչպես Հայաստանի Հանրապետության առողջապահության նախարարի հրամանով, այնպես էլ Հայաստանի Հանրապետության առողջապահության նախարարության կողմից լիցենզավորված և պետական պատվեր տեղադրված բժշկական կազմակերպությունների կողմից` այդ նպատակով ստեղծված հանձնաժողովի մասնագիտական եզրակացության հիման վրա՝ պետության մասնակցության մասով:
8. Սույն հրամանի հավելված N 2-ով հաստատված ցանկի 2-րդ կետի 1-ին ենթակետով նախատեսված դեպքերում 0-7 տարեկան, սոցիալապես անապահով և հատուկ խմբերում ընդգրկված 7-18 տարեկան երեխաների և ընտանիքների անապահովության գնահատման համակարգում հաշվառված 36.00 և ավելի բարձր անապահովության միավորներ ունեցող ընտանիքների անդամների բժշկական օգնությունը և սպասարկումն ամբողջությամբ իրականացվում է անվճար` պետական պատվերի շրջանակներում:
9. Սույն հրամանի հավելված N 2-ով հաստատված ցանկի 4-րդ կետի 5)-րդ ենթակետով նախատեսված դեպքերում 0-7 տարեկան, սոցիալապես անապահով և հատուկ խմբերում ընդգրկված 7-18 տարեկան երեխաների բժշկական օգնությունը և սպասարկումն ամբողջությամբ իրականացվում է անվճար` պետական պատվերի շրջանակներում:
10. Սույն հրամանի հավելված N 2-ով հաստատված ցանկի 2-րդ կետի 5-րդ ենթակետով նախատեսված դեպքերում հղիների, ծննդաբերների և ծննդկանների (հետծննդյան 42 օրերի ընթացքում) բժշկական օգնությունը և սպասարկումն ամբողջությամբ իրականացվում է պետական պատվերի շրջանակներում անվճար` Հայաստանի Հանրապետության առողջապահության նախարարի հրամանի հիման վրա:
11. Սույն հրամանի հավելված N 2-ով հաստատված ցանկի 2-րդ կետի 5-րդ ենթակետով, 3-րդ կետի 1-ին և 2-րդ ենթակետերով, 4-րդ կետի 2-րդ, 3-րդ, 4-րդ և 6-րդ ենթակետերով, 7-րդ կետի 1-ին ենթակետով և 11-րդ կետի 2-րդ և 3-րդ ենթակետերով նախատեսված դեպքերում զինծառայողների և նրանց հավասարեցված անձանց, նրանց ընտանիքների անդամների, ինչպես նաև փրկարար ծառայության ծառայողների և նրանց ընտանիքների անդամների պետության կողմից երաշխավորված անվճար կամ արտոնյալ պայմաններով բժշկական օգնության և սպասարկման շրջանակներում նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական ծառայությունները իրականացվում են Հայաստանի Հանրապետության կառավարության 2013 թվականի հուլիսի 25-ի N 806-Ն որոշումով հաստատված կարգի համաձայն:
