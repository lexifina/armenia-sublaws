# Հավելված ՀՀ առողջապահության նախարարի 2013 թվականի սեպտեմբերի 28-ի N 57-Ն հրամանի
ՉԱՓՈՐՈՇԻՉ
ՊԵՏՈՒԹՅԱՆ ԿՈՂՄԻՑ ԵՐԱՇԽԱՎՈՐՎԱԾ ԱՆՎՃԱՐ ԵՎ ԱՐՏՈՆՅԱԼ, ԻՆՉՊԵՍ ՆԱԵՎ ԱՅԼ ՊԱՅՄԱՆՆԵՐՈՎ ԲԺՇԿԱԿԱՆ ՕԳՆՈՒԹՅԱՆ ԵՎ ՍՊԱՍԱՐԿՄԱՆ ՇՐՋԱՆԱԿՆԵՐՈՒՄ ՆՈՐԱԳՈՒՅՆ ԵՎ ԹԱՆԿԱՐԺԵՔ ՏԵԽՆՈԼՈԳԻԱՆԵՐԻ ԿԻՐԱՌՄԱՄԲ ՄԱՏՈՒՑՎՈՂ ԲԺՇԿԱԿԱՆ ԾԱՌԱՅՈՒԹՅՈՒՆՆԵՐԻ ԿԱԶՄԱԿԵՐՊՄԱՆ ԵՎ ԻՐԱԿԱՆԱՑՄԱՆ (վերնագիրը խմբ. 04.07.23 N 35-Ն)
1. Սույն չափորոշչով կարգավորվում են պետության կողմից երաշխավորված անվճար և արտոնյալ, ինչպես նաև այլ պայմաններով բժշկական օգնության և սպասարկման շրջանակներում նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական ծառայությունների կազմակերպման և իրականացման հետ կապված հարաբերությունները:
2. Նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական ծառայությունները կազմակերպվում և իրականացվում են բժշկական օգնության և սպասարկման համապատասխան տեսակի գործունեության լիցենզիա ունեցող բժշկական օգնություն և սպասարկում իրականացնող կազմակերպություններում՝ (այսուհետ` Կազմակերպություն)` Հայաստանի Հանրապետության օրենսդրությանը և սույն չափորոշչի համապատասխան:
3. Պետության կողմից երաշխավորված արտոնյալ և վճարովի պայմաններով բժշկական օգնության և սպասարկման շրջանակներում նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական ծառայությունները կազմակերպվում և իրականացվում են տվյալ Կազմակերպությունում սահմանված կարգով և գներով, ընդ որում գները հիմնվում են տվյալ ծառայության իրականացման համար անհրաժեշտ իրական ծախսերի վրա:
4. Առողջապահության նախարարի 2023 թվականի մայիսի 11-ի թիվ 20–Ն հրամանով հաստատված նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական օգնության և սպասարկման ծառայությունները կարող են կազմակերպվել և իրականացվել պետության կողմից երաշխավորված անվճար կամ արտոնյալ պայմաններով բժշկական օգնության և սպասարկման շրջանակներում Առողջապահության նախարարի հրամանով` Առողջապահության նախարարի կողմից սահմանված գներով:
5. Պետության կողմից երաշխավորված անվճար պայմաններով բժշկական օգնության և սպասարկման շրջանակներում կազմակերպվում և իրականացվում են.
1) Հայաստանի Հանրապետության կառավարության 2004 թվականի մարտի 4-ի N 318-Ն որոշման N 3 հավելվածի 2-րդ կետի 1-ին ենթակետի «թ», «ժ», «ժա» պարբերություններով սահմանված նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական ծառայությունները (սրտամկանի սուր ինֆարկտի անհետաձգելի վիրահատական (կորոնար անոթների ստենտավորում), աորտայի անևրիզմաների պատռվածքների և (կամ) շերտազատումների վիրահատությունների և գլխուղեղի սուր կամ ենթասուր իշեմիկ կաթվածների բուժման (ներառյալ ներերակային թրոմբոլիտիկ թերապիան ալտեպլազա դեղով))` ամբողջ բնակչության համար,
2) Հայաստանի Հանրապետության կառավարության 2004 թվականի մարտի 4-ի N 318-Ն որոշման N 3 հավելվածի 8-րդ կետով սահմանված նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական ծառայությունները` Հայաստանի Հանրապետության կառավարության 2004 թվականի մարտի 4-ի N 318-Ն որոշման N 1 հավելվածի 1-ին կետի 1-ին, 2-րդ, 3-րդ, 5-րդ, 6-րդ, 8-րդ, 11-17-րդ, 21-րդ և 23-րդ ենթակետերում անձանց համար, ինչպես նաև Հայաստանի Հանրապետության կառավարության 2014 թվականի մարտի 27-ի N 375-Ն որոշման Հավելված 1-ի 2-րդ կետում ընդգրկված սոցիալական փաթեթի շահառու հանդիսացող անձանց համար,
3) Առողջապահության նախարարի 2023 թվականի մայիսի 11-ի թիվ 20–Ն հրամանով հաստատված նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական օգնության և սպասարկման ծառայությունների ցանկի 22-րդ կետով նախատեսված Սիներակի (Վ.Կավա/V.Cava) ֆիլտրի տեղադրման (ներառյալ՝ ֆիլտրի արժեքը) ծառայությունը` Հայաստանի Հանրապետության կառավարության 2004 թվականի մարտի 4-ի N 318-Ն որոշման Հավելված 1-ի 7-րդ կետում ընդգրկված վերարտադրության տարիքի կանանց համար` հղիության, ծննդաբերության և հետծննդյան շրջանում/42օր/,
4) Առողջապահության նախարարի 2023 թվականի մայիսի 11-ի թիվ 20–Ն հրամանով հաստատված նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական օգնության և սպասարկման ծառայությունների ցանկի 36-րդ կետով նախատեսված արյունաստեղծ ցողունային բջիջների ալոգեն փոխպատվաստման կամ աուտոփոխպատվաստման ծառայությունները` Հայաստանի Հանրապետության առողջապահության նախարարի կողմից սահմանված գնով,
5) Առողջապահության նախարարի 2023 թվականի մայիսի 11-ի թիվ 20–Ն հրամանով հաստատված նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական օգնության և սպասարկման ծառայությունների ցանկի 59-րդ կետով նախատեսված Varian(Վարիան) էլեկտրոնային արագացուցիչով ճառագայթային բուժումը` Հայաստանի Հանրապետության կառավարության 2004 թվականի մարտի 4-ի N 318-Ն որոշման N 1 հավելվածի 1-ին կետի 1-8-րդ ենթակետերում, 15-րդ և 23-րդ ենթակետերում ընդգրկված անձանց համար,
6) Առողջապահության նախարարի 2023 թվականի մայիսի 11-ի թիվ 20–Ն հրամանով հաստատված նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական օգնության և սպասարկման ծառայությունները` Հայաստանի Հանրապետության նախագահի, վարչապետի, Ազգային ժողովի նախագահի և նրանց ընտանիքի անդամների համար` Հայաստանի Հանրապետության կառավարության 2023 թվականի մայիսի 18-ի N 754-Ն որոշման համաձայն:
(5-րդ կետը լրաց. 25.01.24 N 47-Ն, փոփ. 14.05.25 N 47-Ն)
6. Պետության կողմից երաշխավորված արտոնյալ պայմաններով բժշկական օգնության և սպասարկման շրջանակներում կազմակերպվում և իրականացվում են.
1) Առողջապահության նախարարի 2023 թվականի մայիսի 11-ի թիվ 20–Ն հրամանով հաստատված նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական օգնության և սպասարկման ծառայությունների ցանկի 9-րդ կետով նախատեսված աորտակորոնար շունտավորումը` Հայաստանի Հանրապետության առողջապահության նախարարի 2021 թվականի հուլիսի 15-ի N 54-Ն հրամանով հաստատված չափորոշչի 33-րդ կետով նախատեսված դեպքերում,
2) Առողջապահության նախարարի 2023 թվականի մայիսի 11-ի թիվ 20–Ն հրամանով հաստատված նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական օգնության և սպասարկման ծառայությունների ցանկի 35-րդ կետով նախատեսված դոնորական օրգանների և հյուսվածքների փոխպատվաստման ծառայությունը` Հայաստանի Հանրապետության առողջապահության նախարարի կողմից սահմանված գներով,
3) Առողջապահության նախարարի 2023 թվականի մայիսի 11-ի թիվ 20–Ն հրամանով հաստատված նորագույն և թանկարժեք տեխնոլոգիաների կիրառմամբ մատուցվող բժշկական օգնության և սպասարկման ծառայությունների ցանկի 59-րդ կետով նախատեսված Varian(Վարիան) էլեկտրոնային արագացուցիչով ճառագայթային բուժումը բնակչության բոլոր խմբերին` բացառությամբ Հայաստանի Հանրապետության կառավարության 2004 թվականի մարտի 4-ի N 318-Ն որոշման N 1 հավելվածի 1-ին կետի 1-8-րդ ենթակետերում, 15-րդ և 23-րդ ենթակետերում ընդգրկված անձանց:
