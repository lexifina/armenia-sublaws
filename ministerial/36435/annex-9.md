# Հավելված N 4-ի լրացման կարգը
1. Հավելված N 4-ը լրացվում է այն համայնքների համար, որտեղ գույքահարկ վճարող կազմակերպությունների քանակը մինչև 50 է: Եթե տվյալ համայնքում ելակետային տվյալների բացակայության պատճառով հնարավոր չէ լրացնել սույն հավելվածը, ապա այդ կազմակերպությունների համար լրացվում է N 1 հավելվածը:
2. Հավելված N 4-ի աղյուսակի [1] սյունակի [1]-ից մինչև [13] տողերով պահանջվող տեղեկատվությունը լրացվում է ամսական կտրվածքով, ըստ հասարակական, արտադրական նշանակության (բացառությամբ ավտոտնակների) շինությունների (սյունակ [2]) և ավտոտնակների (սյունակ [3]): Տեղեկատվության աղբյուր է հանդիսանում կազմակերպությունների կողմից այդ N 4ա հավելվածով տեղական ինքնակառավարման մարմնին տրամադրվող տեղեկատվությունը: Համայնքի վարչական տարածքում գտնվող շինությունների համար գույքահարկ վճարող կազմակերպությունների կողմից N 4ա հավելվածով ստացվող տեղեկություններից առանձնացվում են պահանջվող ցուցանիշները և սույն կարգի համաձայն լրացվում N 4 հավելվածի աղյուսակի համապատասխան վանդակներում: Մասնավորապես.
ա) [1] տողի [2] սյունակում լրացվում է կազմակերպություններին պատկանող` համայնքի վարչական տարածքում գտնվող հասարակական, արտադրական նշանակության շինությունների (բացառությամբ ավտոտնակների)` 01.01.06թ. դրությամբ մնացորդային արժեքը (հավելված N 4 ա-ի 1-ին աղյուսակի «ընդամենը» տողի [1] սյունակ),
բ) [1] տողի [3] սյունակում լրացվում է կազմակերպություններին պատկանող` համայնքի վարչական տարածքում գտնվող ավտոտնակների` 01.01.06թ. դրությամբ մնացորդային արժեքը (հավելված N 4ա-ի 2-րդ աղյուսակի «ընդամենը» տողի [1] սյունակ):
Նույն մոտեցմամբ լրացվում են սույն հավելվածի [2], [3], սյունակների [2]-ից մինչև [13] բոլոր տողերը՝ 01.02.06թ. դրությամբ, 01.03.06թ. դրությամբ և այլն:
3. Հավելված N 4-ի աղյուսակի [14] տողում լրացվում են միայն [4] և [5] սյունակները: [4] և [5] սյունակներում լրացվում են կազմակերպություններին պատկանող` համայնքի վարչական տարածքում գտնվող համապատասխանաբար` հասարակական, արտադրական նշանակության շինությունների և ավտոտնակների 2006 թվականի գույքահարկի տարեկան հաշվարկային գումարը (ներառյալ ՀՀ օրենքներով և համայնքի ավագանու կողմից սահմանված արտոնությունների գումարը): Տեղեկատվությունը կարելի է ստանալ կազմակերպությունների համար նախատեսված գույքահարկի հաշվարկման տեղեկատվական ավտոմատացված համակարգից կամ հաշվարկել կազմակերպությունների կողմից ներկայացված 2006 թվականի գույքահարկի եռամսյակային հաշվարկների միջոցով (հրահանգի N 3 հավելված):

5. Հավելված N 4-ի աղյուսակի [16] տողը վերաբերում է 2006 թվականին համայնքի ավագանու կողմից գույքահարկի գծով սահմանված արտոնություններից օգտվող կազմակերպություններին պատկանող` համայնքի վարչական տարածքում գտնվող հասարակական, արտադրական նշանակության շինությունների (սյունակ [4]) և ավտոտնակների (սյունակ [5]) համար հաշվարկված գույքահարկի գծով արտոնությունների ընդհանուր գումարին:
