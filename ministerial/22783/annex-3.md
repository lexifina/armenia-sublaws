# Հավելված N 3 ՀՀ ֆինանսների և էկոնոմիկայի նախարարի 2006 թվականի փետրվարի 20-ի N 172-Ն հրամանով
Ց Ա Ն Կ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅՈՒՆՈՒՄ ՀԱՇՎԱՊԱՀՆԵՐԻ ՈՐԱԿԱՎՈՐՄԱՆ ՔՆՆՈՒԹՅՈՒՆՆԵՐԻ ԸՆԹԱՑՔՈՒՄ ՕԳՏՎԵԼՈՒ ՀԱՄԱՐ ԹՈՒՅԼԱՏՐՎՈՂ ՆՈՐՄԱՏԻՎ ԻՐԱՎԱԿԱՆ ԱԿՏԵՐԻ
1. «Հաշվապահական հաշվառման մասին» ՀՀ օրենք 2. «Հարկերի մասին» ՀՀ օրենք 3. «Շահութահարկի մասին» ՀՀ օրենք 4. «Եկամտահարկի մասին» ՀՀ օրենք 5. «Ավելացված արժեքի մասին» ՀՀ օրենք 6. «Ակցիզային հարկի մասին» ՀՀ օրենք 7. «Գույքահարկի մասին» ՀՀ օրենք 8. «Հողի հարկի մասին» ՀՀ օրենք 9. «Պարզեցված հարկի մասին» ՀՀ օրենք 10. «Հաստատագրված վճարների մասին» ՀՀ օրենք 11. «Պետական տուրքի մասին» ՀՀ օրենք 12. «Տեղական տուրքերի և վճարների մասին» ՀՀ օրենք 13. «Պարտադիր սոցիալական ապահովագրության վճարների մասին» ՀՀ օրենք 14. Հայաստանի Հանրապետության մաքսային օրենսգիրք 15. «Իրավական ակտերի մասին» ՀՀ օրենք 16. «Լիցենզավորման մասին» ՀՀ օրենք 17. «Հայաստանի Հանրապետությունում ստուգումների կազմակերպման և անցկացման մասին» ՀՀ օրենք 18. «Արժեթղթերի շուկայի կարգավորման մասին» ՀՀ օրենք 19. Հայաստանի Հանրապետության քաղաքացիական օրենսգիրք 20. «Բաժնետիրական ընկերությունների մասին» ՀՀ օրենք 21. «Բանկերի և բանկային գործունեության մասին» ՀՀ օրենք 22. «Աուդիտորական գործունեության մասին» ՀՀ օրենք 23. ՀՀ կառավարության 2005 թ. ապրիլի 21-ի «Աուդիտի ստանդարտները հաստատելու մասին» N 509-Ն որոշում 24. ՀՀ կառավարության 2005 թ. դեկտեմբերի 9-ի «Հայաստանի Հանրապետության հաշվապահական հաշվառման ստանդարտները հաստատելու մասին» N 2159-Ն որոշում 25. ՀՀ ֆինանսների և էկոնոմիկայի նախարարության 2000 թ. դեկտեմբերի 29-ի «Կազմակերպությունների ֆինանսատնտեսական գործունեության հաշվապահական հաշվառման հաշվային պլանը հաստատելու մասին» N 319 հրաման
