# Հավելված N 2 ՀՀ սպորտի և երիտասարդության հարցերի նախարարի 2009 թ. փետրվարի 2-ի N 1-Ն հրամանի
Կ Ա Զ Մ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՀԱՎԱՔԱԿԱՆ ԹԻՄԵՐԻ ԿԱԶՄՈՒՄ ՕԼԻՄՊԻԱԿԱՆ ԽԱՂԵՐՈՒՄ, ԱՇԽԱՐՀԻ ԵՎ ԵՎՐՈՊԱՅԻ ԱՌԱՋՆՈՒԹՅՈՒՆՆԵՐՈՒՄ ԲԱՐՁՐ ԱՐԴՅՈՒՆՔՆԵՐԻ ՀԱՍԱԾ ՄԱՐԶԻԿՆԵՐԻՆ ԵՎ ՆՐԱՆՑ ՄԱՐԶԻՉՆԵՐԻՆ ԱՆՎԱՆԱԿԱՆ ԹՈՇԱԿԻ ԹԵԿՆԱԾՈՒՆԵՐ ԸՆՏՐԵԼՈՒ ԵՎ ԱՌԱՋԱԴՐԵԼՈՒ ԱՇԽԱՏԱՆՔՆԵՐՆ ԻՐԱԿԱՆԱՑՆՈՂ ՀԱՆՁՆԱԺՈՂՈՎԻ
Արթուր Պետրոսյան | - Հայաստանի Հանրապետության սպորտի և երիտասարդության հարցերի նախարար (հանձնաժողովի նախագահ),
Սամվել Խաչատրյան | - Հայաստանի Հանրապետության սպորտի և երիտասարդության հարցերի նախարարի տեղակալ,
Լևոն Խալիկյան | - Հայաստանի Հանրապետության սպորտի և երիտասարդության հարցերի նախարարության աշխատակազմի (այսուհետ՝ Աշխատակազմ) ղեկավար,
Արտաշես Նազարյան | - Աշխատակազմի մարզական կազմակերպությունների և մանկապատանեկան սպորտի քաղաքականության վարչության պետ,
Բագրատ Բուռնազյան | - Աշխատակազմի սպորտի բարձրագույն նվաճումների քաղաքականության վարչության պետ,
Էդուարդ Պետրոսյան | - Աշխատակազմի ծրագրերի կառավարման վարչության պետ,
Ռազմիկ Ստեփանյան | - Հայաստանի ազգային օլիմպիական կոմիտեի նախագահի առաջին տեղակալ, Հայաստանի ըմբշամարտի ֆեդերացիայի անդամ (համաձայնությամբ),
Հրաչյա Ռոստոմյան | - Հայաստանի ազգային օլիմպիական կոմիտեի գլխավոր քարտուղար (համաձայնությամբ),
Դերենիկ Գաբրիելյան | - Հայաստանի ազգային օլիմպիական կոմիտեի նախագահի տեղակալ, Հայաստանի բռնցքամարտի ֆեդերացիայի անդամ (համաձայնությամբ),
Հրաչյա Պետիկյան | - Հայաստանի ազգային օլիմպիական կոմիտեի գործադիր կոմիտեի անդամ, Հայաստանի հրաձգության ֆեդերացիայի նախագահ (համաձայնությամբ),
Սմբատ Լպուտյան | - «Հայաստանի շախմատի ակադեմիա» հիմնադրամի նախագահ, Հայաստանի շախմատային ֆեդերացիայի նախագահի առաջին տեղակալ, միջազգային գրոսմայստեր (համաձայնությամբ)։
(Հավելվածը խմբ. 14.12.10 N 3-Ն)
