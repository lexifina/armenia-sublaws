# Հավելված N 2 ՀՀ սպորտի և երիտասարդության հարցերի նախարարի 2009 թվականի փետրվարի 2-ի N 1-Ն հրամանի
Կ Ա Զ Մ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՀԱՎԱՔԱԿԱՆ ԹԻՄԵՐԻ (ՆԵՐԱՌՅԱԼ ՀԱՇՄԱՆԴԱՄԱՅԻՆ ՍՊՈՐՏԸ) ԿԱԶՄՈՒՄ ՕԼԻՄՊԻԱԿԱՆ, ՊԱՐԱԼԻՄՊԻԿ, ՍՈՒՐԴԼԻՄՊԻԿ ԽԱՂԵՐՈՒՄ, ԱՇԽԱՐՀԻ ԵՎ ԵՎՐՈՊԱՅԻ ԱՌԱՋՆՈՒԹՅՈՒՆՆԵՐՈՒՄ ԲԱՐՁՐ ԱՐԴՅՈՒՆՔՆԵՐԻ ՀԱՍԱԾ ՄԱՐԶԻԿՆԵՐԻՆ ԵՎ ՆՐԱՆՑ ՄԱՐԶԻՉՆԵՐԻՆ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՆԱԽԱԳԱՀԻ ԱՆՎԱՆԱԿԱՆ ԹՈՇԱԿԻ ԹԵԿՆԱԾՈՒՆԵՐ ԸՆՏՐԵԼՈՒ ԵՎ ԱՌԱՋԱԴՐԵԼՈՒ ԱՇԽԱՏԱՆՔՆԵՐՆ ԻՐԱԿԱՆԱՑՆՈՂ ՀԱՆՁՆԱԺՈՂՈՎԻ
1. | Հրաչյա Ռոստոմյան | - | Հայաստանի Հանրապետության սպորտի և երիտասարդության հարցերի նախարար (հանձնաժողովի նախագահ),
2. | Ավետիս Բերբերյան | - | Հայաստանի Հանրապետության Նախագահի օգնական
3. | Վահե Էլոյան | - | Հայաստանի Հանրապետության սպորտի և երիտասարդության հարցերի նախարարության աշխատակազմի (այսուհետ՝ Աշխատակազմ) ղեկավար,
4. | Վաղինակ Գալուստյան | - | Աշխատակազմի մարզական կազմակերպությունների և մանկապատանեկան սպորտի քաղաքականության վարչության պետ,
5. | Նարինե Շահբազյան | - | Աշխատակազմի սպորտի բարձրագույն նվաճումների քաղաքականության վարչության պետ,
6. | Լևոն Վահրադյան | - | Մասսայական սպորտի և ֆիզիկական դաստիարակության քաղաքականության վարչության պետ,
7. | Հոկսեն Միրզոյան | - | Հայաստանի Հանրապետության սպորտի և երիտասարդության հարցերի նախարարության ենթակայության «Երևանի ծանրամարտի մանկապատանեկան մարզադպրոց» ՊՈԱԿ-ի տնօրեն,
8. | Վահրամ Առաքելյան | - | Հայաստանի ազգային օլիմպիական կոմիտեի փոխնախագահ (համաձայնությամբ),
9. | Դերենիկ Գաբրիելյան | - | Հայաստանի ազգային օլիմպիական կոմիտեի նախագահի տեղակալ (համաձայնությամբ),
10. | Ռուբեն Հակոբյան | - | Հայաստանի ազգային օլիմպիական կոմիտեի նախագահի խորհրդական (համաձայնությամբ),
11. | Գագիկ Բոլշիկյան | - | Հայաստանի ազգային օլիմպիական կոմիտեի բաժնի պետ (համաձայնությամբ),
12. | Սմբատ Լպուտյան | - | «Հայաստանի շախմատի ակադեմիա» հիմնադրամի նախագահ, Հայաստանի շախմատային ֆեդերացիայի նախագահի առաջին տեղակալ (համաձայնությամբ),
13. | Հակոբ Աբրահամյան | - | «Հայաստանի ազգային պարալիմպիկ կոմիտե» հասարակական կազմակերպության նախագահ,
14. | Գրիգոր Գրիգորյան | - | «Խուլերի հայկական սպորտային կոմիտե» հասարակական կազմակերպության նախագահ
(հավելվածը խմբ. 14.12.10 N 3-Ն, 02.11.11 N 4-Ն, 19.11.12 N 1-Ն, 07.10.13 N 6-Ն, 16.01.14 N 2-Ն, 29.04.15 N 1-Ն, լրաց. 17.06.15 N 4-Ն, խմբ. 14.12.16 N 1-Ն)
