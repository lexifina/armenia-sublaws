# Հավելված N 2 ՀՀ սպորտի և երիտասարդության հարցերի նախարարի 2009 թ. փետրվարի 2-ի N 1-Ն հրամանի
Կ Ա Զ Մ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՀԱՎԱՔԱԿԱՆ ԹԻՄԵՐԻ ԿԱԶՄՈՒՄ ՕԼԻՄՊԻԱԿԱՆ ԽԱՂԵՐՈՒՄ, ԱՇԽԱՐՀԻ ԵՎ ԵՎՐՈՊԱՅԻ ԱՌԱՋՆՈՒԹՅՈՒՆՆԵՐՈՒՄ ԲԱՐՁՐ ԱՐԴՅՈՒՆՔՆԵՐԻ ՀԱՍԱԾ ՄԱՐԶԻԿՆԵՐԻՆ ԵՎ ՆՐԱՆՑ ՄԱՐԶԻՉՆԵՐԻՆ ԱՆՎԱՆԱԿԱՆ ԹՈՇԱԿԻ ԹԵԿՆԱԾՈՒՆԵՐ ԸՆՏՐԵԼՈՒ ԵՎ ԱՌԱՋԱԴՐԵԼՈՒ ԱՇԽԱՏԱՆՔՆԵՐՆ ԻՐԱԿԱՆԱՑՆՈՂ ՀԱՆՁՆԱԺՈՂՈՎԻ
1. Յուրի Վարդանյան | - Հայաստանի Հանրապետության սպորտի և երիտասարդության հարցերի նախարար (հանձնաժողովի նախագահ),
2. Ավետիս Բերբերյան | - Հայաստանի Հանրապետության Նախագահի օգնական,
3. Նազարեթ Մնացականյան | - Հայաստանի Հանրապետության սպորտի և երիտասարդության հարցերի նախարարի տեղակալ,
4. Մհեր Անանյան | - Հայաստանի Հանրապետության սպորտի և երիտասարդության հարցերի նախարարության աշխատակազմի (այսուհետ՝ Աշխատակազմ) ղեկավար,
5. Հովհաննես Հարությունյան | - Հայաստանի Հանրապետության սպորտի և երիտասարդության հարցերի նախարարի խորհրդական,
6. Տիգրան Միքայելյան | - Աշխատակազմի մարզական կազմակերպությունների և մանկապատանեկան սպորտի քաղաքականության վարչության պետ,
7. Նարինե Շահբազյան | - Աշխատակազմի սպորտի բարձրագույն նվաճումների քաղաքականության վարչության պետ,
8. Ռազմիկ Ստեփանյան | - «Հայաստան» մարզական միություն հասարակական կազմակերպության նախագահ, Հայաստանի ըմբշամարտի ֆեդերացիայի նախագահության անդամ (համաձայնությամբ),
9. Վահրամ Առաքելյան | - Հայաստանի ազգային օլիմպիական կոմիտեի փոխնախագահ (համաձայնությամբ),
10. Դերենիկ Գաբրիելյան | - Հայաստանի ազգային օլիմպիական կոմիտեի նախագահի տեղակալ, Հայաստանի բռնցքամարտի ֆեդերացիայի նախագահության անդամ (համաձայնությամբ),
11. Գաբրիել Ղազարյան | - Հայաստանի ազգային օլիմպիական կոմիտեի բաժնի պետ, Հայաստանի ջրացատկի ֆեդերացիայի նախագահ (համաձայնությամբ),
12. Սմբատ Լպուտյան | - «Հայաստանի շախմատի ակադեմիա» հիմնադրամի տնօրեն, Հայաստանի շախմատային ֆեդերացիայի նախագահի առաջին տեղակալ, միջազգային գրոսմայստեր (համաձայնությամբ)
(հավելվածը խմբ. 14.12.10 N 3-Ն, 02.11.11 N 4-Ն, 19.11.12 N 1-Ն, 07.10.13 N 6-Ն)
