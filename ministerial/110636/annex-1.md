# Հավելված ՀՀ կրթության և գիտության նախարարի 2016թ. նոյեմբերի 14-ի N 1169-Ն հրամանի
ՆԱԽՆԱԿԱՆ ՄԱՍՆԱԳԻՏԱԿԱՆ (ԱՐՀԵՍՏԱԳՈՐԾԱԿԱՆ) ԿՐԹՈՒԹՅԱՆ 0714.02.4 «ՄԵՔԵՆԱՆԵՐԻ ԵՎ ՄԵԽԱՆԻԶՄՆԵՐԻ ԷԼԵԿՏՐԱՍԱՐՔԱՎՈՐՈՒՄՆԵՐԻ ՏԵԽՆԻԿԱԿԱՆ ՇԱՀԱԳՈՐԾՈՒՄ» ՄԱՍՆԱԳԻՏՈՒԹՅԱՆ 0714.02.02.4 «ԷԼԵԿՏՐԱՄԵԽԱՆԻԿ` ՎԵՐԵԼԱԿՆԵՐԻ» ՈՐԱԿԱՎՈՐՄԱՆ ՊԵՏԱԿԱՆ ԿՐԹԱԿԱՆ ՉԱՓՈՐՈՇԻՉ
