# Հավելված ՀՀ առողջապահության նախարարի 2010 թ. հոկտեմբերի 1-ի N 21-Ն հրամանի
ԱՎՏՈԲԵՆԶԱԼՑԱԿԱՅԱՆՆԵՐԻՆ, ԱՎՏՈԳԱԶԱԼԻՑՔԱՎՈՐՄԱՆ ՃՆՇԱԿԱՅԱՆՆԵՐԻՆ ԵՎ ԱՎՏՈԳԱԶԱԼԻՑՔԱՎՈՐՄԱՆ ԿԱՅԱՆՆԵՐԻՆ ՆԵՐԿԱՅԱՑՎՈՂ ՀԻԳԻԵՆԻԿ ՊԱՀԱՆՋՆԵՐ
ՍԱՆԻՏԱՐԱԿԱՆ ԿԱՆՈՆՆԵՐ ԵՎ ՆՈՐՄԵՐ N 2.1.7.004-10
(վերնագիրը խմբ. 07.04.20 N 12-Ն)
1. ԸՆԴՀԱՆՈՒՐ ԴՐՈՒՅԹՆԵՐ
1. Սույն սանիտարական կանոնները և նորմերը (այսուհետ` սանիտարական կանոններ) սահմանում են ավտոբենզալցակայանների և ավտոգազալիցքավորման ճնշակայանների (այսուհետ` ԱԳԼՃԿ), ավտոգազալիցքավորման կայանների (այսուհետ` ԱԳԼԿ) տեղակայմանը, տարածքի սանիտարական պահպանմանը, տեխնոլոգիական գործընթացների և սարքավորումներին, ջրամատակարարմանը, ջրահեռացմանը, աշխատողների սանիտարակենցաղային պայմանների ապահովմանը, աշխատանքային անվտանգությանը, աշխատողների բժշկական զննության կազմակերպմանը ներկայացվող հիգիենիկ պահանջները:
(1-ին կետը լրաց. 07.04.20 N 12-Ն)
2. Սույն սանիտարական կանոնները տարածվում են Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով ավտոբենզալցավորման և ավտոգազալիցքավորման գործունեություն իրականացնող, ինչպես նաև նախագծման և կառուցման աշխատանքներ իրականացնող տնտեսվարող սուբյեկտների վրա:
3. Սույն սանիտարական կանոնները տարածվում են նաև առևտրային, արդյունաբերական, վերամշակման, գյուղատնտեսական գործունեություն իրականացնող կազմակերպությունների կամ պետական այն հիմնարկների վրա, որտեղ ավտովառելիքը օգտագործվում է բացառապես կազմակերպության գործունեության նպատակների համար` շահագործվող ավտոմեքենաների լիցքավորման համար:
2. ՏԵՐՄԻՆՆԵՐ ԵՎ ՍԱՀՄԱՆՈՒՄՆԵՐ
4. ավտոբենզալցակայան` հեղուկ ավտովառելիքի, տեխնիկական հեղուկների, լցավորման մշտական (ստացիոնար) կայան,
5. ավտոգազալիցքավորման ճնշակայան` լիցքավորման ճնշակայան, որի տարածքում իրականացվում է մարդատար, բեռնատար, ինչպես նաև հատուկ մեքենաների` բնական գազով աշխատելու հարմարեցված վառելիքային համակարգի գլանոթների լիցքավորում,
(5-րդ կետը փոփ. 07.04.20 N 12-Ն)
5.1 ավտոգազալիցքավորման կայան` լիցքավորման կայան, որի տարածքում իրականացվում է մարդատար, բեռնատար, ինչպես նաև հատուկ մեքենաների` հեղուկ նավթային գազով աշխատելու հարմարեցված վառելիքային համակարգի գլանոթների լիցքավորում,
(5.1-ին կետը լրաց. 07.04.20 N 12-Ն)
6. ավտովառելիք` նավթաթորվածքներ, այդ թվում՝ բենզինը և դիզելային վառելիքը, գազային վառելիք, որոնք ավտոբենզալցակայանում կամ ավտոգազալիցքավորման ճնշակայանում բաժնավորվում են ավտոմեքենաների բաքերում կամ շարժական բեռնարկղերում,
7. վերգետնյա ռեզերվուար` գետնի մակերևույթից բարձր անշարժ տեղակայված տարողություն` նախատեսված ավտովառելիքի պահեստավորման և օգտագործման նպատակով,
8. ստորգետնյա ռեզերվուար` գետնի մակերևույթից ցածր անշարժ տեղակայված տարողություն` նախատեսված ավտովառելիքի պահեստավորման և օգտագործման նպատակով,
9. խողովակաշար` խողովակների ամբողջություն, որոնց միջոցով ավտովառելիքը փոխանցվում է պահեստավորման ռեզերվուարներից դեպի բաժնավորիչները: Նշված համակարգը ներառում է բոլոր խողովակաոստերը, կցորդիչները, միացումները, կափույրները և այլ ամրակցված տարրերը։
3. ԱՎՏՈԲԵՆԶԱԼՑԱԿԱՅԱՆՆԵՐԻ ԵՎ ԱՎՏՈԳԱԶԱԼՑԱԿԱՅԱՆՆԵՐԻ ՏԵՂԱԿԱՅՄԱՆԸ ԵՎ ՏԱՐԱԾՔԻՆ ՆԵՐԿԱՅԱՑՎՈՂ ՀԻԳԻԵՆԻԿ ՊԱՀԱՆՋՆԵՐ
10. Նոր կառուցվող ավտոբենզալցակայանները և ԱԳԼՃԿ-ները տարանջատվում են բնակելի և հասարակական շենքերից սանիտարապաշտպանական գոտով, որոնց հեռավորությունը սահմանվում է ՀՀ կառավարության 2008 թվականի օգոստոսի 28-ի «Ավտոգազալիցքավորման ճնշակայանների (ԱԳԼՃԿ) կառուցման և շահագործման նվազագույն պահանջների տեխնիկական կանոնակարգը հաստատելու մասին» N 1101-Ն, 2005 թվականի դեկտեմբերի 22-ի «Անվտանգության կանոնները գազի տնտեսությունում տեխնիկական կանոնակարգը հաստատելու մասին» N 2399-Ն որոշումներով հաստատված կանոնակարգերի և Հայաստանի Հանրապետության քաղաքաշինության նախարարի 2014 թվականի հոկտեմբերի 14-ի N 263-Ն հրամանով հաստատված ՀՀՇՆ 30-01-2014 «Քաղաքաշինություն. Քաղաքային և գյուղական բնակավայրերի հատակագծում և կառուցապատում» շինարարական նորմերի պահանջներին համապատասխան:
(10-րդ կետը փոփ. 07.04.20 N 12-Ն)
11. Ավտոբենզալցակայանները և ԱԳԼՃԿ-ները, ԱԳԼԿ-ները չեն տեղակայվում խմելու ջրամատակարարման աղբյուրների սանիտարական պահպանման բոլոր գոտիներում:
(11-րդ կետը լրաց. 07.04.20 N 12-Ն)
12. Նոր կառուցվող ավտոբենզալցակայանի նախագիծը ներառում է կայանի տեղակայման տարածքի իրավիճակային հատակագիծը, ներառյալ տարածքի սահմանագծերը, տարածքում կամ դրա սահմաններից դուրս բոլոր ուղղություններով մինչև 300 մ հեռավորության վրա գտնվող մակերեսային կամ ստորգետնյա խմելու ջրամատակարարման աղբյուրների առկայությունը, աշխատողների և հաճախորդների համար նախատեսված սանիտարահիգիենիկ շինությունների և հարմարությունների տեղակայումը ու նկարագրությունը, կայանի ջրամատակարարման և ջրահեռացման համակարգերի տեղակայումը և այլն:
13. Ավտոբենզալցակայանների և ԱԳԼՃԿ-ների, ԱԳԼԿ-ների տեղակայման տարածքը լինում է բարեկարգ և կանաչապատ:
(13-րդ կետը լրաց. 07.04.20 N 12-Ն)
14. Տարածքի սանիտարական մաքրումը կատարվում է ամեն օր, ամռան ընթացքում` խոնավ եղանակով:
15. Տարածքում առանձնացվում է հրապարակ կենցաղային կոշտ թափոնների հավաքման ժամանակավոր պահպանման համար:
16. Տարածքում տեղադրում են աղբանոթներ և կափարիչով աղբի կոնտեյներներ:
17. Ավտոբենզալցակայանի և ԱԳԼՃԿ-ների, ԱԳԼԿ-ների տարածքը ապահովվում է ջրանթափանց, հարթ ծածկով, հեղեղատար ջրերի հեռացման համակարգով:
(17-րդ կետը լրաց. 07.04.20 N 12-Ն)
18. Ավտոբենզալցակայանների և ԱԳԼՃԿ-ների, ԱԳԼԿ-ների /որոնք նախատեսված չեն բացառապես կազմակերպության գործունեության նպատակների համար/ տեղակայման տարածքը ապահովվում է հասարակական զուգարանով:
(18-րդ կետը լրաց. 07.04.20 N 12-Ն)
19. Ավտոբենզալցակայանների, ԱԳԼՃԿ-ների և ԱԳԼԿ-ների հասարակական զուգարանների կառուցվածքը համապատասխանում է Հայաստանի Հանրապետության առողջապահության նախարարի 2009 թվականի ապրիլի 16-ի N 06-Ն հրամանով հաստատված «Հասարակական զուգարաններին ներկայացվող հիգիենիկ պահանջներ» N2-III-2.13 սանիտարական կանոնների և նորմերի պահանջներին:
(19-րդ կետը խմբ. 07.04.20 N 12-Ն)
