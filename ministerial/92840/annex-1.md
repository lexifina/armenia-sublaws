# Հավելված ՀՀ ֆինանսների նախարարի 2014 թվականի սեպտեմբերի 8-ի N 588-Ն հրամանի

ԱՌԵՎՏՐԱԿԱՆ (ԱՌՔ ՈՒ ՎԱՃԱՌՔԻ) ԳՈՐԾՈՒՆԵՈՒԹՅՈՒՆ ԻՐԱԿԱՆԱՑՆՈՂ ՇՐՋԱՆԱՌՈՒԹՅԱՆ ՀԱՐԿ ՎՃԱՐՈՂՆԵՐԻ ԿՈՂՄԻՑ ՄԻՆՉԵՎ 2014 ԹՎԱԿԱՆԻ ՀՈԿՏԵՄԲԵՐԻ 1-Ը ՁԵՌՔ ԲԵՐՎԱԾ ԵՎ 2014 ԹՎԱԿԱՆԻ ՀՈԿՏԵՄԲԵՐԻ 1-Ի ԴՐՈՒԹՅԱՄԲ ԱՌԿԱ ԱՊՐԱՆՔԱՅԻՆ ՄՆԱՑՈՐԴԻ ՎԵՐԱԲԵՐՅԱԼ

2. Հարկ վճարողի հաշվառման համարը
3. Առևտրային կազմակերպության անվանումը կամ անհատ ձեռնարկատիրոջ անունը, ազգանունը

6. Մինչև 2014 թվականի հոկտեմբերի 1-ը ձեռքբերված և 2014 թվականի հոկտեմբերի 1-ի դրությամբ առկա ապրանքային մնացորդը.
