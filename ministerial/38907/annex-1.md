# Հավելված
Հաստատված է ՀՀ պաշտպանության նախարարի, ՀՀ կրթության և գիտության նախարարի և ՀՀ ոստիկանության պետի 2004 թ. հունիսի 30-ի N 601-Ն/ 483-Ն/ 3-Ն համատեղ հրամանով
Կ Ա Ր Գ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՀԱՆՐԱԿՐԹԱԿԱՆ ԴՊՐՈՑՆԵՐՆ ՈՒ ՄԻՋԻՆ ՄԱՍՆԱԳԻՏԱԿԱՆ ՈՒՍՈՒՄՆԱԿԱՆ ՀԱՍՏԱՏՈՒԹՅՈՒՆՆԵՐՆ ՈՒՍՈՒՄՆԱԿԱՆ ԶԵՆՔՈՎ ԵՎ ՌԱԶՄԱՄԹԵՐՔՈՎ ԱՊԱՀՈՎԵԼՈՒ
I. ԸՆԴՀԱՆՈՒՐ ԴՐՈՒՅԹՆԵՐ
1. Սույն կարգը մշակվել է Հայաստանի Հանրապետության կառավարության 1999 թ. օգոստոսի 25-ի թիվ 532 որոշմամբ հաստատված «Հայաստանի Հանրապետության հանրա կրթական դպրոցներում և միջին մասնագիտական ուսումնական հաստատություններում նախազորակոչային պատրաստության կարգի» 6-րդ կետի դ) ենթակետի, ինչպես նաև «Զենքի մասին» Հայաստանի Հանրապետության օրենքի 10-րդ և 15-րդ հոդվածների համաձայն և կանոնակարգում է Հայաստանի Հանրապետության հանրակրթական դպրոցներն ու միջին մասնագիտական ուսումնական հաստատություններն (այսուհետ` ուսումնական հաստատություններ) ուսումնական զենքով և ռազմամթերքով (այսուհետ` զենք) ապահովելու գործընթացը:
2. Ուսումնական զենք համարվում է միայն ուսումնական գործընթացում օգտագործվող զենքը, որից կրակելն առանց վերանորոգման անհնար է, ընդ որում, ուսումնական հաստատությունները Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով իրավունք ունեն ձեռք բերելու նաև սպորտային և որսորդական զենք:
3. Ուսումնական հաստատություններում զենք պահելը, օգտագործելը, հաշվառելն իրականացվում է «Զենքի մասին» Հայաստանի Հանրապետության օրենքով, Հայաստանի Հանրապետության կառավարության 1999 թվականի հոկտեմբերի 26-ի «Հայաստանի Հանրապետության տարածքում քաղաքացիական ու ծառայողական զենքի և դրա փամփուշտների շրջանառությունը կարգավորելու մասին» N 673 որոշմամբ. ՀՀ ներքին գործերի նախարարի 2002 թվականի մարտի 15-ի «Ներքին գործերի մարմինների կողմից Հայաստանի Հանրապետության տարածքում քաղաքացիական ու ծառայողական զենքի և դրա փամփուշտների շրջանառության նկատմամբ իրականացվող վերահսկողության կարգի մասին» N 101 հրամանով և դրանցից բխող այլ իրավական ակտերով»:
II. ԶԵՆՔԻ ԱՆՀՐԱԺԵՇՏ ՔԱՆԱԿՈՒԹՅԱՆ ՀԱՅՏԱՎՈՐՈՒՄԸ ԵՎ ՀԱՏԿԱՑՈՒՄԸ
4. Ուսումնական զենքի անհրաժեշտ քանակության հաշվառումը կատարում է Հայաստանի Հանրապետության կրթության և գիտության նախարարությունը:
5. Հաշվառման հիման վրա, զենքի պահանջվող քանակությունը ճշտելուց հետո, յուրաքանչյուր ուսումնական տարվա սկզբին Հայաստանի Հանրապետության կրթության և գիտության նախարարությունը հայտ է ներկայացնում Հայաստանի Հանրապետության պաշտպանության նախարարություն և Հայաստանի Հանրապետության ոստիկանություն:
6. Հայաստանի Հանրապետության պաշտպանության նախարարությունը ստանալով հայտը, 2004-2005 ուսումնական տարվանից սկսած, Հայաստանի Հանրապետության ոստիկանության տնտեսական վարչությանը պարբերաբար հատկացնում է Հայաստանի Հանրապետության հանրակրթական դպրոցների և միջին մասնագիտական ուսումնական հաստատությունների համար նախատեսված զենքը:
7. Հայաստանի Հանրապետության ոստիկանությունը ուսումնական հաստատություններին զենքի հատկացումն իրականացնում է տարածքային ոստիկանության մարմինների միջոցով:
8. Ոստիկանության տարածքային ստորաբաժանման թույլտվության համակարգի տեսուչը ստուգում է ուսումնական հաստատություններում ուսումնական զենքի պահման պայմանները և կազմում է ակտ:
Զենք պահելու պայմանների համապատասխանության դեպքում Հայաստանի Հանրապետության կառավարության 1999 թվականի հոկտեմբերի 26-ի «Հայաստանի Հանրապետության տարածքում քաղաքացիական ու ծառայողական զենքի և դրա փամփուշտների շրջանառությունը կարգավորելու մասին» N 673 որոշմամբ սահմանված կարգով զենքը հանձնվում է ուսումնական հաստատության զենքի պահպանության պատասխանատու անձին, որը ՀՀ ներքին գործերի նախարարի 2002 թվականի մարտի 15-ի «Ներքին գործերի մարմինների կողմից Հայաստանի Հանրապետության տարածքում քաղաքացիական ու ծառայողական զենքի և դրա փամփուշտների շրջանառության նկատմամբ իրականացվող վերահսկողության կարգի մասին» N 101 հրամանով սահմանված կարգով կատարում է հաշվառում:
