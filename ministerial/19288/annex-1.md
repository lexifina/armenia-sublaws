# Հավելված N 1 Հաստատված է ՀՀ մշակույթի, երիտասարդության հարցերի և սպորտի նախարարի 2003 թ. ապրիլի 1-ի N 154-Ն հրամանով
Կ Ա Ր Գ
ՀԱՅԱՍՏԱՆԻ ԱԶԳԱՅԻՆ ԱՐԽԻՎԱՅԻՆ ՖՈՆԴԻ ՓԱՍՏԱԹՂԹԵՐԸ ՊԵՏԱԿԱՆ ԱՐԽԻՎ Ի ՊԱՀ ՀԱՆՁՆԵԼՈՒ
1. Սույն կարգը սահմանում է ֆիզիկական և իրավաբանական անձանց կողմից փաստաթղթերը պետական արխիվ ի պահ հանձնելու կարգը։
2. Փաստաթղթերը պետական արխիվ ի պահ են հանձնվում պահատուի գրավոր դիմումի հիման վրա։
3. Փաստաթղթերն ի պահ ընդունելու հարցը վճռվում է պետարխիվի տնօրենի կողմից։
4. Փաստաթղթերն ի պահ են հանձնվում համապատասխան ցուցակներով։ Առանձին դեպքերում փաստաթղթերը կարող են ի պահ հանձնվել զմռսված պարկերով և արկղերով։
5. Փաստաթղթերի ի պահ հանձնումն իրականացվում է պայմանագրով (սույն հրամանի N 2 հավելված) և ընդունման-հանձնման ակտով (սույն հրամանի N 3 հավելված), որոնք կազմվում են 2-ական օրինակից։
6. Ի պահ ընդունված փաստաթղթերը հետ են վերցվում, ընդունվում են պետական պահպանության կամ ոչնչացվում են սահմանված կարգով՝ դրանց պայմանագրով նախատեսված պահատվության ժամկետները լրանալուց հետո։
7. Ի պահ ընդունված փաստաթղթերի շարժը պետական արխիվում իրականացվում է հաշվառման մատյանում (սույն հրամանի N 4 հավելված)։
