# Հավելված ՀՀ կրթության և գիտության նախարարի 2009 թ. դեկտեմբերի 7-ի N 1023-Ն հրամանի
ՆԱԽՆԱԿԱՆ ՄԱՍՆԱԳԻՏԱԿԱՆ (ԱՐՀԵՍՏԱԳՈՐԾԱԿԱՆ) ԿՐԹՈՒԹՅԱՆ 2014 «ՌԱԴԻՈԷԼԵԿՏՐՈՆԱՅԻՆ ՄԻՋՈՑՆԵՐԻ ՏԵԽՆԻԿԱԿԱՆ ՍՊԱՍԱՐԿՈՒՄ ԵՎ ՆՈՐՈԳՈՒՄ» ՄԱՍՆԱԳԻՏՈՒԹՅԱՆ «ՌԱԴԻՈԷԼԵԿՏՐՈՆԻԿԱՅԻ ՍԱՐՔԱՎՈՐՈՒՄՆԵՐ ՍՊԱՍԱՐԿՈՂ ԵՎ ՆՈՐՈԳՈՂ ՌԱԴԻՈՄԵԽԱՆԻԿ» ՈՐԱԿԱՎՈՐՄԱՆ ՊԵՏԱԿԱՆ ԿՐԹԱԿԱՆ ՉԱՓՈՐՈՇԻՉ
