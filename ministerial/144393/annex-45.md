# Հավելված N 9բ-ի աղյուսակի լրացման կարգը
77. Հավելված N 9բ-ն վերաբերվում է «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքի 12-րդ հոդվածի 1-ին մասի 6-րդ կետով նախատեսված թույլտվության համար տեղական տուրքին: Հաշվի առնելով «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքով սահմանված դրույքաչափերը և կատարված օրենսդրական փոփոխությունները, հավելվածը կազմված է ըստ գյուղական (N 9բ) համայնքի:
78. Հավելված N 9բ-ն կազմված է «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքի 12-րդ հոդվածի 1-ին մասի 6-րդ կետում «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքում լրացումներ կատարելու մասին» Հայաստանի Հանրապետության 2016 թվականի դեկտեմբերի 16-ի ՀՕ-234-Ն օրենքով (ուժի մեջ է մտել 2017 թվականի հունվարի 9-ից) կատարված փոփոխություններին համապատասխան:
79. Հավելված N 9բ-ի աղյուսակի (գյուղական համայնքների համար) [1], [2], [5], [7] սյունակների տեղեկատվությունն ունի կողմնորոշիչ նշանակություն մնացած դատարկ վանդակները լրացնելու համար:
80. Հավելված N 9բ-ի աղյուսակի [4]-րդ և [9]-րդ սյունակներում լրացվում է նշված տեղական տուրքի գծով համայնքի ավագանու սահմանած դրույքաչափերը` համապատասխանաբար 2016 թ. և 2019 թ. համար: Այն պետք է գտնվի տվյալ տեղական տուրքի համար օրենքով սահմանված դրույքաչափերի սահմաններում` վերին սահմանի նկատմամբ գործակիցների կիրառմամբ (տես տվյալ տողի համապատասխանաբար [1], [2], [5], և [7] սյունակները):
81. Հավելված N 9բ-ի աղյուսակի [10]-րդ սյունակում լրացվում է 2019 թ. համար համայնքի ավագանու կողմից տրված թույլտվությունների քանակը:
82. Հավելված N 9բ-ի աղյուսակի [11]-րդ սյունակում պետք է լրացվի 2019 թ. համար համայնքի ավագանու կողմից տրամադրված արտոնությունների քանակին վերաբերվող ելակետային տվյալները:
