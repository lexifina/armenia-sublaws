# Հավելված N 15բ-ի աղյուսակի լրացման կարգը
113. Հավելված N 15բ-ն վերաբերվում է «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքի 12-րդ հոդվածի 1-ին մասի 14-րդ կետի «ա» ենթակետով նախատեսված թույլտվության համար տեղական տուրքին: Հաշվի առնելով «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքով սահմանված դրույքաչափերը և կատարված օրենսդրական փոփոխությունները, հավելվածը կազմված է ըստ գյուղական (N 15բ) համայնքի:
114. Հավելված N 15բ-ն կազմված է «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքի 12-րդ հոդվածի 1-ին մասի 14-րդ կետի «ա» ենթակետում «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքում լրացումներ կատարելու մասին» Հայաստանի Հանրապետության 2016 թվականի դեկտեմբերի 16-ի ՀՕ-234-Ն օրենքով (ուժի մեջ է մտել 2017 թվականի հունվարի 9-ից) կատարված փոփոխություններին համապատասխան:
115. Հավելված N 15բ-ի աղյուսակի (գյուղական համայնքների համար) [1], [2], [5], [7] սյունակների տեղեկատվությունն ունի կողմնորոշիչ նշանակություն մնացած դատարկ վանդակները լրացնելու համար:
116. 117. Հավելված N 15բ-ի աղյուսակի [10]-րդ սյունակում լրացվում է 2019 թ. համար համայնքի ավագանու կողմից տրված թույլտվությունների քանակը:
