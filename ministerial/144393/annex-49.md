# Հավելված N 18բ-ի աղյուսակի լրացման կարգը
131. Հավելված N 18բ-ն վերաբերվում է «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքի 12-րդ հոդվածի 1-ին մասի 15-րդ կետով նախատեսված թույլտվության համար տեղական տուրքին: Հաշվի առնելով «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքով սահմանված դրույքաչափերը և կատարված օրենսդրական փոփոխությունները, հավելվածը կազմված է ըստ գյուղական (N 18բ) համայնքների:
132. Հավելված N 18բ-ն կազմված է «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքի 12-րդ հոդվածի 1-ին մասի 15-րդ կետում «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքում լրացումներ կատարելու մասին» Հայաստանի Հանրապետության 2016 թվականի դեկտեմբերի 16-ի ՀՕ-234-Ն օրենքով (ուժի մեջ է մտել 2017 թվականի հունվարի 9-ից) կատարված փոփոխություններին համապատասխան:
133. Հավելված N 18բ-ի աղյուսակի (գյուղական համայնքների համար) [1], [2], [5], [7] սյունակների տեղեկատվությունն ունի կողմնորոշիչ նշանակություն մնացած դատարկ վանդակները լրացնելու համար:
