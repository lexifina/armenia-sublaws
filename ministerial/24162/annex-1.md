# Հավելված ՀՀ գյուղատնտեսության նախարարի 2006 թ. մարտի 14-ի N 42-Ն հրամանի
Կ Ա Ր Գ ՄՇԱԿԱԲՈՒՍՅԵՐԻ ՍԵՐՄՆԱԴԱՇՏԵՐԻ ԴԱՇՏԱՅԻՆ ՀԵՏԱԶՈՏՈՒԹՅՈՒՆՆԵՐ ԿԱՏԱՐԵԼՈՒ ՎԵՐԱԲԵՐՅԱԼ ՀԱՅՏԻ ՆԵՐԿԱՅԱՑՄԱՆ
1. Սույն կարգը սահմանում է Հայաստանի Հանրապետությունում մշակաբույսերի սերմնադաշտերի դաշտային հետազոտություններ կատարելու վերաբերյալ արտադրողի կողմից հայտի ներկայացման ընթացակարգը:
2. Հայտը կարող է ներկայացնել ցանկացած իրավաբանական և ֆիզիկական անձ՝ համաձայն Հայաստանի Հանրապետության կառավարության 2005 թ. դեկտեմբերի 9-ի «Հայաստանի Հանրապետությունում սերմնադաշտերի դաշտային հետազոտություններ կատարողի (ապրոբատորի) հավատարմագրման կարգը և սերմնադաշտերի դաշտային հետազոտությունների մասին հայտի ձևը հաստատելու մասին» N 2239-Ն որոշման 1-ին կետի «բ» ենթակետով հաստատված ձևի:
3. Մշակաբույսերի սերմնադաշտերի դաշտային հետազոտություններ կատարելու վերաբերյալ հայտը ներկայացվում է Հայաստանի Հանրապետության գյուղատնտեսության նախարարություն անմիջական կամ փոստային առաքմամբ, անձամբ կամ ներկայացուցչի միջոցով:
4. Մշակաբույսերի սերմնադաշտերի դաշտային հետազոտություններ կատարելու վերաբերյալ հայտը ներկայացվում է տվյալ մշակաբույսի ցանքսից առնվազն մեկ ամիս առաջ:
5. Ներկայացված հայտը համարակալվում է և գրանցվում գրանցամատյանում, որը վարում է Հայաստանի Հանրապետության գյուղատնտեսության նախարարության «Սերմերի գործակալություն» պետական ոչ առևտրային կազմակերպությունը:
6. Գրանցված և համարակալված հայտի տեղեկություններն օգտագործվում են սերմերի հավաստագրման գործընթացում:
