# Հավելված ՀՀ մշակույթի նախարարի 2016 թվականի հուլիսի 11-ի N 366-Ն հրամանի
Կ Ա Ր Գ
ՀԱՅԱՍՏԱՆԻ ԱԶԳԱՅԻՆ ԳՐԱԴԱՐԱՆԻ ԿՈՂՄԻՑ ՄԻՋԳՐԱԴԱՐԱՆԱՅԻՆ ԳՐՔԱՓՈԽԱՆԱԿՈՒԹՅԱՆ ՀԱՎԱՔԱԾՈՒԻ ՁԵՎԱՎՈՐՄԱՆ ԵՎ ՕԳՏԱԳՈՐԾՄԱՆ
I. ԸՆԴՀԱՆՈՒՐ ԴՐՈՒՅԹՆԵՐ
1. Սույն կարգով կարգավորվում են «Հայաստանի ազգային գրադարան» պետական ոչ առևտրային կազմակերպության (այսուհետ` գրադարան) կողմից միջգրադարանային գրքափոխանակության հավաքածուի ձևավորման, օգտագործման և հաշվառման հետ կապված հարաբերությունները:
2. Գրադարանում միջգրադարանային գրքափոխանակության հավաքածուի ստեղծման նպատակն է Հայաստանի և օտարերկրյա պետությունների ֆիզիկական և իրավաբանական անձանց գրադարանային փաստաթղթի գրքափոխանակություն (այսուհետ` գրքափոխանակություն) իրականացնելը:
II. ԳՐԱԴԱՐԱՆՈՒՄ ԳՐՔԱՓՈԽԱՆԱԿՈՒԹՅԱՆ ՀԱՎԱՔԱԾՈՒԻ ՁԵՎԱՎՈՐՄԱՆ ՍԿԶԲՈՒՆՔՆԵՐԸ
3. Գրադարանի գրքափոխանակության հավաքածուում կարող են ընդգրկվել տեքստային, թվանշանային, պատկերային, տեսա- և (կամ) ձայնաշարային կամ համակցված նյութական կրիչներ:
4. Գրքափոխանակության հավաքածուում չեն կարող ընդգրկվել ազգային գրադարանային հավաքածուի գրադարանային փաստաթղթերը:
5. Հավաքածուի համալրման աղբյուրներն են`
1) իրավաբանական և ֆիզիկական անձանց սեփականությունը հանդիսացող և գրադարանին նվիրաբերած, նվիրած կամ ժառանգած գրադարանային փաստաթուղթը.
2) գրադարանի գործող հավաքածուից զտված, բազմօրինակ գրադարանային փաստաթուղթը:
6. Գրադարանային փաստաթղթերը գրադարանի գրքափոխանակության բաժին մուտք են գործում համալրման բաժնից (Ձև N 1), իսկ պարբերական մամուլը` համալրման բաժնի պարբերական մամուլի ենթաբաժնից (Ձև N 2):
III. ԳՐՔԱՓՈԽԱՆԱԿՈՒԹՅԱՆ ՀԱՎԱՔԱԾՈՒԻ ՕԳՏԱԳՈՐԾՈՒՄԸ
7. Գրքափոխանակության հավաքածուի գրադարանային փաստաթուղթը օգտագործվում է հետևյալ նպատակներով.
1) բնական կամ տեխնածին աղետներից (երկրաշարժ, ջրհեղեղ, հրդեհ, ռազմական գործողություններ) տուժած` Հայաստանի և օտարերկրյա պետությունների ֆիզիկական և իրավաբանական անձանց գրադարանների վնասված հավաքածուների համալրման,
2) նոր բացվող գրադարանների հավաքածուների համալրման,
3) Հայաստանի և օտարերկրյա պետությունների ֆիզիկական և իրավաբանական անձանց գրադարանային փաստաթղթի փոխանակման ինչպես տպագիր, այնպես էլ էլեկտրոնային տարբերակով:
8. Գրադարանի ղեկավարի հրամանի հիման վրա ստեղծված հանձնաժողովը ուսումնասիրում է գործող հավաքածուից գրքափոխանակության նպատակով առանձնացված գրադարանային փաստաթղթերը, կազմում հաշվառումից հանելու և համալրման բաժին հանձնելու (Ձև N 7) ակտ:
9. Գրադարանի ղեկավարի հրամանի հիման վրա ստեղծված հանձնաժողովը ուսումնասիրում է հաշվառումից հանելու նպատակով առանձնացված գրադարանային փաստաթղթերը և կազմում է գրքափոխանակության հավաքածուի կազմից հաշվառումից հանելու (Ձև N 3), գրադարանային փաստաթղթերի անհատույց տրամադրման (Ձև N 4) և գրադարանային փաստաթղթերի փոխանակման (Ձև N 5) համապատասխան ակտեր:
10. Հայաստանի և օտարերկրյա պետությունների ֆիզիկական և իրավաբանական անձանց գրքափոխանակությամբ տրամադրվող գրադարանային փաստաթղթերի համար կազմվում են անհրաժեշտ ուղեկցող փաստաթղթեր (Ձև 4 և Ձև 5), որոնց պահպանությունը և վերահսկողությունը իրականացվում է գրքափոխանակության հավաքածուի պատասխանատուի կողմից:
11. Հաշվառումից հանելու ակտը (Ձև N 3) և կազմվում է 3 օրինակից, հաստատվում է գրադարանի ղեկավարի կողմից: Ակտի առաջին օրինակը պահվում է գրադարանի գրքափոխանակության բաժնում, երկրորդ օրինակը` գրադարանի հաշվապահությունում և երրորդ օրինակը` համալրման բաժնում:
12. Գրադարանային փաստաթղթերի անհատույց տրամադրման (Ձև N 4) և գրադարանային փաստաթղթերի փոխանակման (Ձև N 5) ակտերը կազմվում են 3 օրինակից, հաստատվում են գրադարանի ղեկավարի կողմից: Ակտերի առաջին օրինակները պահվում են գրադարանի հաշվապահությունում, երկրորդ օրինակները տրվում է ընդունողին, իսկ երրորդ օրինակները պահվում են գրադարանի գրքափոխանակության բաժնում:
13. Դուրս գրված փաստաթղթերի մասին գրառումներ են կատարվում գրադարանի գումարային հաշվառման մատյանի 3-րդ մասում և գրքափոխանակության հավաքածուի ֆոնդային մատյանում` համաձայն Հայաստանի Հանրապետության մշակույթի նախարարի 2014 թվականի հոկտեմբերի 2-ի «Գրադարանային փաստաթղթերի հաշվառման, պահպանման, վերականգնման և ամրակայման (կոնսերվացման) կարգը հաստատելու մասին» N 598-Ն հրամանով հաստատված կարգի 22-րդ կետի:
IV. ԳՐՔԱՓՈԽԱՆԱԿՈՒԹՅԱՆ ՀԱՎԱՔԱԾՈՒԻ ՀԱՇՎԱՌՈՒՄԸ
14. Գրքափոխանակության հավաքածուի գրադարանային փաստաթղթերի հաշվառումը իրականացվում է Հայաստանի Հանրապետության մշակույթի նախարարի 2014 թվականի հոկտեմբերի 2-ի «Գրադարանային փաստաթղթերի հաշվառման, պահպանման, վերականգնման և ամրակայման (կոնսերվացման) կարգը հաստատելու մասին» N 598-Ն հրամանով հաստատված կարգի համաձայն:
15. Գրքափոխանակության հավաքածուի ֆոնդային մատյանը /Ձև N 6/ վարում է գրքափոխանակության հավաքածուի պատասխանատուն:
16. Գրքափոխանակության հավաքածուի կազմից դուրս գրվող գրադարանային փաստաթղթերի մասին հաշվառման փաստաթղթերում կատարվում են նշումներ (օրինակ` «Դուրս է գրված», «Փոխանակված է»)` հղում անելով համապատասխան ակտին /Ձև N 3, Ձև N 4, Ձև N 5/:
17. Գրքափոխանակության հավաքածուից ելք արվող գրադարանային փաստաթղթի յուրաքանչյուր միավորի վերջին տիտղոսաթերթի դարձերեսին` գրքափոխանակության հաշվառանիշի վրա դրվում է մարումը հաստատող կնիք, որի վրա նշվում է գրադարանի անունը և «Մարված» բառը:
