# Հավելված N 4 ՀՀ առևտրի և տնտեսական զարգացման նախարարի 23.11.2004 թ. N 190-Ն հրամանի
Կ Ա Զ Մ
Զբոսավարի եվ ուղեկցորդի որակավորման եվ լիցենզավորման հանձնաժողովի
1. Արա Պետրոսյան | - | ՀՀ առևտրի և տնտեսական զարգացման նախարարի տեղակալ (Հանձնաժողովի նախագահ)
2. Մեխակ Ապրեսյան | - | ՀՀ առևտրի և տնտեսական զարգացման նախարարության զբոսաշրջության վարչության պետ (Հանձնաժողովի նախագահի տեղակալ)
3. Սուսաննա Ասլիզադյան | - | ՀՀ առևտրի և տնտեսական զարգացման նախարարության զբոսաշրջության վարչության առաջատար մասնագետ (Հանձնաժողովի քարտուղար)
4. Արտաշես Հովհաննիսյան | - | ՀՀ առևտրի և տնտեսական զարգացման նախարարության 1-ին բաժնի պետ
5. Լիաննա Գևորգյան | - | ՀՀ առևտրի և տնտեսական զարգացման նախարարության օրենսդրության և իրավաբանական վարչության առաջատար մասնագետ
6. Ներկայացուցիչ զբոսաշրջության բնագավառում կրթական գործունեություն իրականացնող կազմակերպություններից (համաձայնությամբ)
7. Ներկայացուցիչ գիտական կազմակերպություններից (համաձայնությամբ)
8. Ներկայացուցիչ ՀՀ նախարարություններից և պետական կառավարման այլ մարմիններից (համաձայնությամբ)
9. Ներկայացուցիչ ոչ առևտրային կազմակերպություններից (համաձայնությամբ)
(կազմը փոփ., խմբ. 16.09.05 N 196-Ն)
