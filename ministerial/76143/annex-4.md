# Հավելված N 4 ՀՀ ֆինանսների նախարարի 2012 թվականի ապրիլի 28-ի N 386-Ն հրամանի
Ց Ա Ն Կ
Համայնքի բյուջեի եկամուտները նվազեցնող՝ Հայաստանի Հանրապետության օրենքների կիրարկման արդյունքում համայնքի 2011 թվականի բյուջեի եկամուտների կորուստների հաշվարկներում կիրառվող ելակետային տվյալների
Տեղական ինքնակառավարման մարմնի կողմից Հայաստանի Հանրապետության մարզպետարաններ տրամադրվող ելակետային տվյալներ
Հ/հ | Ելակետային տվյալի անվանումը | Ելակետային տվյալի ներկայացման ձևը սահմանող հավելվածի համարը
1. | «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքի 10-րդ հոդվածի 4-րդ մասով նախատեսված թույլտվությունների համար տեղական տուրքի 2008, 2011թթ. համայնքի ավագանու սահմանած դրույքաչափերն ըստ Հայաստանի Հանրապետության կառավարության 21.02.2002 թվականի N 163 որոշմամբ սահմանված մարտական գործողությունների հետևանքով չօգտագործվող հողատարածքներ ունեցող սահմանամերձ բնակավայրերի ցանկում ընդգրկված քաղաքային և գյուղական համայնքների | NN 1ա-1բ
2. | «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքի 10-րդ հոդվածի 4-րդ մասով նախատեսված թույլտվությունների քանակը` տրամադրված համայնքի ավագանու կողմից 2011թ., ըստ Հայաստանի Հանրապետության կառավարության 21.02.2002 թվականի N 163 որոշմամբ սահմանված մարտական գործողությունների հետևանքով չօգտագործվող հողատարածքներ ունեցող սահմանամերձ բնակավայրերի ցանկում ընդգրկված քաղաքային և գյուղական համայնքների | NN 1ա-1բ
3. | «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքի 10-րդ հոդվածի 4-րդ մասերով նախատեսված թույլտվությունների գծով` 2010թ. համայնքի ավագանու սահմանած արտոնությունների քանակներն ըստ Հայաստանի Հանրապետության կառավարության 21.02.2002 թվականի N 163 որոշմամբ սահմանված մարտական գործողությունների հետևանքով չօգտագործվող հողատարածքներ ունեցող սահմանամերձ բնակավայրերի ցանկում ընդգրկված քաղաքային և գյուղական համայնքների | NN 1ա-1բ
4. | Համայնքի 2011 թվականի բյուջե փաստացի գանձված (մուտքագրված) ձյունագնացի և մոտոամենագնացի (քվադրոցիկլի) համար գույքահարկի և ավտոկայանատեղերի տեղական տուրքի գումարները Հայաստանի Հանրապետության կառավարության 21.02.2002 թվականի N 163 որոշմամբ սահմանված մարտական գործողությունների հետևանքով չօգտագործվող հողատարածքներ ունեցող սահմանամերձ բնակավայրերի ցանկում ընդգրկված համայնքների | N 2
5. | Համայնքի բյուջե հողի հարկ վճարող կազմակերպություններին «Հողի հարկի արտոնությունների մասին» Հայաստանի Հանրապետության օրենքով վերապահված արտոնությունների 2011թ. գումարը (այն համայնքների մասով, որոնք ընդգրկված են Հայաստանի Հանրապետության կառավարության 21.02.2002 թվականի N 163 որոշմամբ սահմանված մարտական գործողությունների հետևանքով չօգտագործվող հողատարածքներ ունեցող սահմանամերձ բնակավայրերի ցանկում) | N 3
6. | Համայնքի բյուջե հողի հարկ վճարող «Հողի հարկի արտոնությունների մասին» Հայաստանի Հանրապետության օրենքով ֆիզիկական անձանց վերապահված արտոնությունների 2011թ. գումարը (այն համայնքների մասով, որոնք ընդգրկված են Հայաստանի Հանրապետության կառավարության 21.02.2002 թվականի N 163 որոշմամբ սահմանված մարտական գործողությունների հետևանքով չօգտագործվող հողատարածքներ ունեցող սահմանամերձ բնակավայրերի ցանկում) | N 3
