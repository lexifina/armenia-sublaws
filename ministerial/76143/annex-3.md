# Հավելված N 2-ի լրացման կարգը
25. Հավելված N 2-ը վերաբերում է.
ա) «Գույքահարկի մասին» Հայաստանի Հանրապետության օրենքում լրացումներ կատարելու մասին» ՀՀ օրենքին (15.11.2010 թ., ՀՕ-172-Ն, ուժի մեջ է մտել 2010 թվականի դեկտեմբերի 25-ից), որով գույքահարկով հարկվող օբյեկտ են սահմանվել նաև ձյունագնացը և մոտոամենագնացը (քվադրոցիկլը),
բ) «Տեղական տուրքերի և վճարների մասին» Հայաստանի Հանրապետության օրենքի 7-րդ հոդվածում կատարված փոփոխությանը, որով սահմանվել է տեղական տուրքի օբյեկտի նոր տեսակ` համայնքային սեփականությունը հանդիսացող ընդհանուր օգտագործման փողոցներում կազմակերպված վճարովի ավտոկայանատեղերում ավտոտրանսպորտային միջոցը կամ դրա կցորդը կայանելու համար (23.06.2011 թ. ՀՕ-224-Ն օրենք, ուժի մեջ է մտել 2011 թվականի հուլիսի 30-ից): Այս տեղական տուրքի հետ կապված հարաբերությունները կարգավորվում են «Ավտոտրանսպորտային միջոցների կայանատեղերի տեղական տուրքերի մասին» Հայաստանի Հանրապետության օրենքով (23.06.2011թ., ՀՕ-221-Ն, ուժի մեջ է մտել 2011 թվականի հուլիսի 30-ից):
26. Հավելված N 2-ը, ինչպես բոլոր հավելվածները, լրացնում են միայն Հայաստանի Հանրապետության կառավարության 2002 թվականի փետրվարի 21-ի N 163 որոշմամբ սահմանված մարտական գործողությունների հետևանքով չօգտագործվող հողատարածքներ ունեցող սահմանամերձ բնակավայրերի ցանկում ընդգրկված համայնքները:
27. Հավելված N 2-ով ներկայացվող ելակետային տվյալներով հաշվարկվելու են նշված օրենսդրական փոփոխության կիրարկման արդյունքում համայնքի բյուջեի լրացուցիչ եկամուտները:
28. Հավելված N 2-ի աղյուսակում լրացվում է համապատասխան եկամտատեսակի գծով համայնքի բյուջե փաստացի գանձված (համայնքի բյուջե մուտքագրված) գումարները:
