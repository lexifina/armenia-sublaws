# Հավելված N 4ա-ի լրացման կարգը
1. Հավելված N 4ա-ի աղյուսակներով պահանջվող տեղեկատվությունը լրացվում է ամսական կտրվածքով, ըստ հասարակական, արտադրական նշանակության շինությունների (1-ին աղյուսակ) և ավտոտնակների (2-րդ աղյուսակ):
2. Հավելված N 4ա-ի աղյուսակները լրացվում են համայնքի բյուջե գույքահարկ վճարող կազմակերպությունների կողմից տեղական ինքնակառավարման մարմնին պաշտոնապես տրամադրվող տվյալների հիման վրա: Կազմակերպությունները տեղեկությունները պետք է տրամադրեն ըստ առանձին շինությունների: Ընդ որում տվյալ ամսվա սկզբի դրությամբ շինության մնացորդային արժեքը սկզբնական (ձեռքբերման) արժեքի 20%-ից պակաս լինելու դեպքում այդ շինության մասով որպես մնացորդային արժեք ընդունվում է սկզբնական (ձեռքբերման) արժեքի 20%-ը:
3. Հավելված N 4ա-ի աղյուսակները լրացնելու համար պահանջվող ելակետային տվյալները պետք է ներկայացնեն համայնքի բյուջե գույքահարկ վճարող բոլոր կազմակերպությունները: Եթե պահանջվող ցուցանիշները ներկայացվել են ոչ բոլոր կազմակերպությունների կողմից, ապա սույն հավելվածը, ինչպես նաև հավելվածներ NN 4, 5-ը չեն լրացվում և այդ համայնքի համար լրացվում է միայն հավելված N 1-ը:
