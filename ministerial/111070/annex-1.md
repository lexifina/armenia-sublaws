# Հավելված N 1 ՀՀ պաշտպանության նախարարի 2016 թվականի դեկտեմբերի 29-ի N 15-Ն հրամանի
ԿԱԶՄ
ՌԱԶՄԱԿԱՆ ՆՇԱՆԱԿՈՒԹՅԱՆ ԱՐՏԱԴՐԱՆՔԻ ԱՐՏԱՀԱՆՄԱՆ ԵՎ ՆԵՐՄՈՒԾՄԱՆ, ՌԱԶՄԱԿԱՆ ՆՇԱՆԱԿՈՒԹՅԱՆ ԱՐՏԱԴՐԱՆՔԻ ՏԱՐԱՆՑԻԿ ՓՈԽԱԴՐՄԱՆ, ՌԱԶՄԱԿԱՆ ՆՇԱՆԱԿՈՒԹՅԱՆ ԱՐՏԱԴՐԱՆՔԻ ԱՌԵՎՏՐԻ ՄԻՋՆՈՐԴԱԿԱՆ ԳՈՐԾՈՒՆԵՈՒԹՅԱՆ ԼԻՑԵՆԶԱՎՈՐՄԱՆ ՀԱՆՁՆԱԺՈՂՈՎԻ
(վերնագիրը խմբ. 21.05.19 N 6-Ն, 02.09.19 N 9-Ն)
1. ՀՀ պաշտպանության նախարարության գլխավոր քարտուղարի տեղակալ՝ պաշտպանության նախարարի որոշմամբ (հանձնաժողովի նախագահ)
2. ՀՀ ՊՆ սպառազինության և տեխնիկական ապահովման վարչության շտաբի պետ - վարչության պետի տեղակալ
3. ՀՀ զինված ուժերի ինժեներական զորքերի պետի տեղակալ-վարչության պետի տեղակալ
4. ՀՀ զինված ուժերի հրթիռային զորքերի և հրետանու շտաբի պետ-վարչության պետի տեղակալ
5. ՀՀ զինված ուժերի հակաօդային պաշտպանության զորքերի պետի տեղակալ սպառազինության գծով – վարչության պետի տեղակալ
6. ՀՀ զինված ուժերի գլխավոր շտաբի օպերատիվ գլխավոր վարչության ռազմատնտեսական պլանավորման վարչության պետ
7. ՀՀ զինված ուժերի ռադիացիոն քիմիական, կենսաբանական պաշտպանության զորքերի վարչության սպառազինության և միջոցների պլանավորման ապահովման և հաշվառման բաժնի պետ
8. ՀՀ պաշտպանության նախարարության պաշտպանական քաղաքականության և միջազգային համագործակցության վարչության միջազգային ռազմական համագործակցության բաժնի ավագ սպա
9. ՀՀ զինված ուժերի գլխավոր շտաբի անօդաչու թռչող սարքերի վարչության ԱԹՀ բաժնի նյութատեխնիկական ապահովման, պլանավորման և հաշվառման բաժանմունքի ավագ սպա
(հավելվածը խմբ. 07.07.17 N 7-Ն, 21.05.19 N 6-Ն, 02.09.19 N 9-Ն, 23.12.25 N 10-Ն)
