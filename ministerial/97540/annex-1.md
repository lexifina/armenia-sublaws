CՀՀ = 3000 + N X 1000 (ՀՀ դրամ)
2) Եվրասիական տնտեսական միության տեխնիկական կանոնակարգերին համապատասխան` (բանաձև N 2)
CԵՏՄ = 4000 + N X 1000 (ՀՀ դրամ)
