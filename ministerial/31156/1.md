1. Հաստատել.
1.1 Հայաստանի Հանրապետության բյուջետային դասակարգումները`
1) «Ոչ ֆինանսական ակտիվների դասակարգումը»` համաձայն հավելված N 1-ի,
2) «Ֆինանսական ակտիվների դասակարգումը»` համաձայն հավելված N 2-ի,
3) «Պարտավորությունների դասակարգումը»` համաձայն հավելված N 3-ի,
4) «Սեփական կապիտալի դասակարգումը»` համաձայն հավելված N 4-ի,
5) «Ընթացիկ ծախսերի դասակարգումը»` համաձայն հավելված N 5-ի,
6) «Ոչ ֆինանսական ակտիվների գծով ծախսերի դասակարգումը»` համաձայն հավելված N 6-ի,
7) «Հիմնական գումարի մարման և ֆինանսական ակտիվների ձեռք բերման գծով ծախսերի դասակարգումը»` համաձայն հավելված N 7-ի,
8) «Ընթացիկ եկամուտների դասակարգումը»` համաձայն հավելված N 8-ի,
9) «Ոչ ֆինանսական ակտիվների իրացումից մուտքերի դասակարգումը»` համաձայն հավելված N 9-ի,
10) «Փոխառու միջոցներից և ֆինանսական ակտիվների իրացումից մուտքերի դասակարգումը»` համաձայն հավելված N 10-ի,
11) «Բյուջետային ծախսերի գործառական դասակարգումը»` համաձայն հավելված N 11-ի:
(1.1-ին կետը փոփ. 11.10.23 N 429-Ն)
1.2 Հայաստանի Հանրապետության բյուջետային դասակարգումների կիրառման կարգը`
1) «Ոչ ֆինանսական ակտիվների դասակարգման կիրառման կարգը»` համաձայն հավելված N 12-ի,
2) «Ֆինանսական ակտիվների դասակարգման կիրառման կարգը»` համաձայն հավելված N 13-ի,
3) «Պարտավորությունների դասակարգման կիրառման կարգը»` համաձայն հավելված N 14-ի,
4) «Սեփական կապիտալի դասակարգման կիրառման կարգը»` համաձայն հավելված N 15-ի,
5) «Ընթացիկ ծախսերի դասակարգման կիրառման կարգը»` համաձայն հավելված N 16-ի,
6) «Ոչ ֆինանսական ակտիվների գծով ծախսերի դասակարգման կիրառման կարգը»` համաձայն հավելված N 17-ի,
7) «Հիմնական գումարի մարման և ֆինանսական ակտիվների ձեռք բերման գծով ծախսերի դասակարգման կիրառման կարգը»` համաձայն հավելված N 18-ի,
8) «Ընթացիկ եկամուտների դասակարգման կիրառման կարգը»` համաձայն հավելված N 19-ի,
9) «Ոչ ֆինանսական ակտիվների իրացումից մուտքերի դասակարգման կիրառման կարգը»` համաձայն հավելված N 20-ի,
10) «Փոխառու միջոցներից և ֆինանսական ակտիվների իրացումից մուտքերի դասակարգման կիրառման կարգը»` համաձայն հավելված N 21-ի,
11) «Բյուջետային ծախսերի գործառական դասակարգման կիրառման կարգը»` համաձայն հավելված N 22-ի:
(1.2-րդ կետը փոփ. 11.10.23 N 429-Ն)
1.3 Բյուջետային ծախսերի գերատեսչական դասակարգումը` համաձայն հավելված N 23-ի:
1.4 Բյուջետային ծախսերի տարածքային դասակարգումը` համաձայն հավելված N 24-ի:
1.5 Տարեսկզբի ազատ մնացորդը` համաձայն հավելված N 25-ի:
(1.5-րդ կետը լրաց. 23.07.07 N 596-Ն)
1.6 Արտարժութային գործառնությունների վերագնահատումից մուտքերը կամ ելքերը համաձայն հավելված N 26-ի:
(1.6-րդ կետը լրաց. 27.05.21 N 244-Ն)
1.7 Բյուջետային ծախսերի տարածքային դասակարգում կատարելու պարագայում առաջնորդվել ՀՀ էկոնոմիկայի նախարարի 30.12.2021թ. N 1709-Ն հրամանի Հավելվածի Աղյուսակ 1-ով:
(1.7-րդ կետը լրաց. 11.10.23 N 429-Ն)
