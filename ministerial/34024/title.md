ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՍՈՑԻԱԼԱԿԱՆ ԱՊԱՀՈՎՈՒԹՅԱՆ ՆԱԽԱՐԱՐԻ, ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՖԻՆԱՆՍՆԵՐԻ ԵՎ ԷԿՈՆՈՄԻԿԱՅԻ ՆԱԽԱՐԱՐԻ, ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՏՐԱՆՍՊՈՐՏԻ ԵՎ ԿԱՊԻ ՆԱԽԱՐԱՐԻ ՄԻ ՇԱՐՔ ՀԱՄԱՏԵՂ ՀՐԱՄԱՆՆԵՐ ՈՒԺԸ ԿՈՐՑՐԱԾ ՃԱՆԱՉԵԼՈՒ ՄԱՍԻՆ
Հաշվի առնելով «Ընտանիքների անապահովության գնահատման համակարգի տեղեկատվական բազայում ամրագրված անհատական տվյալների պաշտպանության, փոփոխությունների կատարման և միմյանց փոխանցելու» հրահանգը հաստատելու մասին» Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարի 2005 թվականի փետրվարի 10-ի N 16-Ն և Հայաստանի Հանրապետության ֆինանսների և էկոնոմիկայի նախարարի 2005 թվականի փետրվարի 21-ի N 182-Ն, «Աղքատության ընտանեկան նպաստի և միանվագ դրամական օգնության նշանակման գործերը վարելու ու ձևակերպելու, փոխադարձ հաշվետվությունների իրականացման» հրահանգը հաստատելու մասին» Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարի 2005 թվականի փետրվարի 10-ի N 17-Ն և Հայաստանի Հանրապետության ֆինանսների և էկոնոմիկայի նախարարի 2005 թվականի փետրվարի 21-ի N 183-Ն, «Ընտանիքի սոցիալական անձնագրի լրացման» հրահանգը հաստատելու մասին» Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարի 2005 թվականի փետրվարի 10-ի N 18-Ն և Հայաստանի Հանրապետության ֆինանսների և էկոնոմիկայի նախարարի 2005 թվականի փետրվարի 21-ի N 184-Ն, «Ընտանիքների անապահովության գնահատման» հրահանգը հաստատելու մասին» Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարի 2005 թվականի փետրվարի 10-ի N 19-Ն և Հայաստանի Հանրապետության ֆինանսների և էկոնոմիկայի նախարարի 2005 թվականի փետրվարի 21-ի N 185-Ն համատեղ հրամանները
ՀՐԱՄԱՅՈՒՄ ԵՆՔ`
Ուժը կորցրած ճանաչել
«Աղքատության ընտանեկան նպաստի և միանվագ դրամական օգնության նշանակման գործերը վարելու ու ձևակերպելու, փոխադարձ հաշվետվությունների իրականացման կարգի մասին», «Աղքատության ընտանեկան նպաստի և միանվագ դրամական օգնության վճարման համար բյուջեից միջոցների հատկացման», «ՀՀ տրանսպորտի և կապի նախարարության «ՀայՓոստ» ՓԲԸ փոստային բաժանմունքի և միանվագ դրամական օգնության վճարման կարգի մասին» հրահանգները հաստատելու մասին» Հայաստանի Հանրապետության սոցիալական ապահովության նախարարի 2000 թվականի դեկտեմբերի 20-ի N 101-Պ, Հայաստանի Հանրապետության ֆինանսների և էկոնոմիկայի նախարարի 2000 թվականի նոյեմբերի 10-ի N 274, Հայաստանի Հանրապետության տրանսպորտի և կապի նախարարի 2000 թվականի դեկտեմբերի 21-ի N 383 համատեղ հրամանը,
«Ընտանիքի սոցիալական անձնագրի լրացման» հրահանգի հաստատման մասին» Հայաստանի Հանրապետության սոցիալական ապահովության նախարարի 2000 թվականի սեպտեմբերի 20-ի N 68-Պ, Հայաստանի Հանրապետության ֆինանսների և էկոնոմիկայի նախարարի 2000 թվականի նոյեմբերի 1-ի N 266, Հայաստանի Հանրապետության տրանսպորտի և կապի նախարարի 2000 թվականի հոկտեմբերի 18-ի N 296 համատեղ հրամանը,
«Ընտանիքների անապահովության գնահատման համակարգի» տեղեկատվական բազայում ամրագրված տվյալների փոփոխությունների կատարման և տեղեկատվական հոսքերի փոխանակման» հրահանգը հաստատելու մասին» Հայաստանի Հանրապետության սոցիալական ապահովության նախարարի 2000 թվականի սեպտեմբերի 7-ի N 57-Պ, Հայաստանի Հանրապետության ֆինանսների և էկոնոմիկայի նախարարի 2000 թվականի նոյեմբերի 1-ի N 267, Հայաստանի Հանրապետության տրանսպորտի և կապի նախարարի 2000 թվականի հոկտեմբերի 18-ի N 294 համատեղ հրամանը,
«Ընտանիքի անապահովության գնահատման հրահանգը» հաստատելու մասին» Հայաստանի Հանրապետության սոցիալական ապահովության նախարարի 2000 թվականի սեպտեմբերի 7-ի N 58-Պ, Հայաստանի Հանրապետության ֆինանսների և էկոնոմիկայի նախարարի 2000 թվականի նոյեմբերի 1-ի N 268, Հայաստանի Հանրապետության տրանսպորտի և կապի նախարարի 2000 թվականի հոկտեմբերի 18-ի N 295 համատեղ հրամանը:
