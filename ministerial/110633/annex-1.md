# Հավելված ՀՀ կրթության և գիտության նախարարի 2016թ. նոյեմբերի 14-ի N 1167-Ն հրամանի
ՄԻՋԻՆ ՄԱՍՆԱԳԻՏԱԿԱՆ ԿՐԹՈՒԹՅԱՆ 0728.09.5 «ԱՐՏԱԴՐԱՆՔԻ ՍՏԱՆԴԱՐՏԱՑՈՒՄ ԵՎ ՀԱՄԱՊԱՏԱՍԽԱՆՈՒԹՅԱՆ ՀԱՎԱՍՏՈՒՄ (ՍԵՐՏԻՖԻԿԱՑՈՒՄ)» ՄԱՍՆԱԳԻՏՈՒԹՅԱՆ 0728.09.01.5 «ՏԵԽՆԻԿ-ՓՈՐՁԱԳԵՏ՝ ԱՐՏԱԴՐԱՆՔԻ ՍՏԱՆԴԱՐՏԱՑՄԱՆ ԵՎ ՀԱՄԱՊԱՏԱՍԽԱՆՈՒԹՅԱՆ ՀԱՎԱՍՏԱԳՐՄԱՆ» ՈՐԱԿԱՎՈՐՄԱՆ ՊԵՏԱԿԱՆ ԿՐԹԱԿԱՆ ՉԱՓՈՐՈՇԻՉ
