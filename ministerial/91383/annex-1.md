# Հավելված N 1 ՀՀ ֆինանսների նախարարի 2014 թ. հունիսի 17-ի N 373-Ն հրամանի
Ց Ա Ն Կ
Համայնքի բյուջեի եկամուտները նվազեցնող` Հայաստանի Հանրապետության օրենքների կիրարկման արդյունքում համայնքի 2013 թվականի բյուջեի եկամուտների կորուստների հաշվարկներում կիրառվող ելակետային տվյալների
Տեղական ինքնակառավարման մարմնի կողմից Հայաստանի Հանրապետության մարզպետարաններ տրամադրվող ելակետային տվյալներ
