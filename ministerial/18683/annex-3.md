# Հավելված 3 Հայաստանի Հանրապետության արդարադատության նախարարի 2004 թվականի հունիսի 7-ի թիվ 80-Ն հրամանի
ՀԱՐԿԱԴԻՐ ԿԱՏԱՐՈՂԻ ՎԿԱՅԱԿԱՆԻ ՆԿԱՐԱԳԻՐԸ
1. Վկայականի կազմը կարմիր գույնի է, արտաքին կազմի վրա ոսկեգույն ՀՀ զինանշանն է և ոսկեգույն տառերով գրված են «ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅՈՒՆ» և «ԱՐԴԱՐԱԴԱՏՈՒԹՅԱՆ ՆԱԽԱՐԱՐՈՒԹՅՈՒՆ» բառերը, կազմի հակառակ կողմի վրա ոսկեգույն տառերով գրված է «РЕСПУБЛИКА АРМЕНИЯ, МИНИСТЕРСТВО ЮСТИЦИИ»:
2. Միջուկը երկկողմանի է` 9x6 չափսի, կարմիր վանդակավոր դաշտի ֆոնի վրա` ՀՀ զինանշանի պատկերով, ձախ կողմում անձի լուսանկարն է 3,5x4,5 չափսի` նշվում է համապատասխան նախարարության անվանումը, ծառայության անվանումը, վկայականի համարը, հրազեն կրելու իրավունքը և ուժի մեջ գտնվելու ժամկետը:
3. Աջ կողմում նշվում են անձի տվյալները (ազգանուն, անուն, հայրանուն), հատուկ կոչումը, պաշտոնը:
4. Գլխավոր հարկադիր կատարողի տեղակալի վկայականը ստորագրվում և կնքվում է համապատասխան նախարարի կողմից (Ձև 1), իսկ մյուս ծառայողներինը՝ գլխավոր հարկադիր կատարողի կողմից (Ձև 2):
5. Բոլոր գրառումները կատարվում են հայերեն և ռուսերեն լեզուներով:
