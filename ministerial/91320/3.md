3. Ուժը կորցրած ճանաչել`
1) Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարի 2006 թվականի հունիսի 8-ի «Աշխատանք փնտրող անձի հաշվառման քարտի, գրանցամատյանի, ապահովագրական ստաժը և դրանում հաշվառվող աշխատանքային կամ այլ բնույթի գործունեությունը հիմնավորող փաստաթղթերից փաստանշման ձևերը հաստատելու և Հայաստանի Հանրապետության սոցիալական ապահովության նախարարի 1997 թվականի հունվարի 14-ի N 71-Պ հրամանը և Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարի 2005 թվականի հունվարի 20-ի N 4-Ն հրամանը ուժը կորցրած ճանաչելու մասին» N 107-Ն հրամանի 1-ին, 3-րդ և 4-րդ կետերը.
2) Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարի 2006 թվականի հունիսի 30-ի «Մասնագիտական ուսուցման կազմակերպման մասին հայտի, մասնագիտական ուսուցման ուղեգրի, ավարտված և իրականացման ընթացքում գտնվող մասնագիտական ուսուցման դասընթացների մասին ամփոփ հաշվետվության ձևերը հաստատելու մասին» N 123-Ն հրամանը.
3) Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարի 2006 թվականի օգոստոսի 24-ի «Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարության «Զբաղվածության պետական ծառայություն» գործակալության տարածքային (մարզային) կենտրոնի, գործազուրկի և գործատուի միջև կնքվող թափուր աշխատատեղը համալրելու մասին եռակողմ պայմանագրի օրինակելի և այլ վայր աշխատանքի գործուղվող գործազուրկի նյութական ծախսերի հատուցման ֆինանսավորման մասին հայտ-պահանջագրի ձևերը հաստատելու մասին» N 145-Ն հրամանը.
4) Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարի 2006 թվականի օգոստոսի 24-ի «Գործազուրկի, հաշմանդամի և Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարության «Զբաղվածության պետական ծառայություն» գործակալության տարածքային (մարզային կենտրոնի) տնօրենի միջև կնքվող ձեռնարկատիրական գործունեության պետական գրանցման համար ֆինանսական աջակցություն տրամադրելու մասին պայմանագրի, ֆինանսավորման հայտ-պահանջագրի օրինակելի ձևերը և գործազուրկին, հաշմանդամին ձեռնարկատիրական գործունեությամբ զբաղվելու համար ֆինանսական աջակցություն տրամադրելու վերաբերյալ տարածքային կենտրոնի տնօրենի որոշման ձևաթուղթը հաստատելու մասին» N 146-Ն հրամանը.
5) Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարի 2006 թվականի օգոստոսի 24-ի «Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարության «Զբաղվածության պետական ծառայություն» գործակալության տարածքային (մարզային) կենտրոնի և գործատուի միջև կնքվող աշխատավարձի փոխհատուցման մասին պայմանագրի, ֆինանսավորման մասին հայտ-պահանջագրի և աշխատավարձի փոխհատուցման ծրագրով աշխատող անմրցունակ անձանց մասին տեղեկանքի ձևերը հաստատելու մասին» N 147-Ն հրամանը.
6) Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարի 2011 թվականի հունիսի 1-ի «Աշխատանքի տոնավաճառի կազմակերպման, գործատուի մոտ մասնագիտություն ունեցող, սակայն աշխատանքային փորձ չունեցող գործազուրկների և աշխատանք փնտրող չզբաղված հաշմանդամների աշխատանքային պրակտիկայի կազմակերպման, գործատուի մոտ աշխատանք փնտրող չզբաղված հաշմանդամների համար աշխատատեղերի հարմարեցման կարգերը հաստատելու մասին» N 48-Ն հրամանը:
3. Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարության աշխատանքի և զբաղվածության վարչության պետին` Հայաստանի Հանրապետության օրենքով սահմանված կարգով ապահովել սույն հրամանի ներկայացումը Հայաստանի Հանրապետության արդարադատության նախարարություն` պետական գրանցման:
(3-րդ կետը փոփ. 12.07.21 N 107-Ն)
