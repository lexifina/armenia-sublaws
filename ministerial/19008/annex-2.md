# Հավելված N 2
«Վարչական վարույթի վերաբերյալ գործերի հաշվառման գրանցամատյանների պայմանանշանների ցանկը»
Հայաստանի Հանրապետության բնապահպանության նախարարության աշխատակազմի
I. Ընդերքի պահպանության վարչություն
1. Ընդերքի օգտակար հանածոների շահագործման նպատակով ուսումնասիրության լիցենզիաների հաշվառման գրանցամատյան` ԸՎ-1.
2. Օգտակար հանածոների արդյունահանման հետ չկապված ստորերկրյա կառույցների ստեղծման նպատակով ընդերք օգտագործման լիցենզիաների հաշվառման գրանցամատյան` ԸՎ-2.
3. Ստորերկրյա ջրերի հանքարդյունահանման լիցենզիաների հաշվառման գրանցամատյան` ԸՎ-3.
II. Շրջակա միջավայրի պահպանության վարչություն
4. Մթնոլորտային օդի աղտոտման անշարժ աղբյուրներ ունեցող կազմակերպությունների սահմանային թույլատրելի արտանետումների նորմատիվների նախագծերի հաստատման և արտանետումներ կատարելու թույլտվությունների հաշվառման գրանցամատյան` ՍԹԱ-1.
III. Քարտուղարության իրավաբանական բաժին
5. Ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթների հաշվառման գրանցամատյան` ԻԲ-1.
IV. Ջրային ռեսուրսների կառավարման գործակալություն
6. Ջրօգտագործման թույլտվությունների հաշվառման գրանցամատյան` ՋԹ-1.
V. Կենսառեսուրսների կառավարման գործակալություն
7. Բուսաբանական հավաքածուների և առանձին նմուշների Հայաստանի Հանրապետության տարածքից արտահանելու և Հայաստանի Հանրապետության տարածք ներմուծելու թույլտվությունների հաշվառման գրանցամատյան` ԲԹ-1.
8. Վայրի կենդանիների և կենդանաբանական հավաքածուների ու առանձին նմուշների Հայաստանի Հանրապետության տարածքից արտահանելու և Հայաստանի Հանրապետության տարածք ներմուծելու թույլտվությունների հաշվառման գրանցամատյան` ԿԹ-2.
9. Գյուղատնտեսական և արդյունագործական նպատակով կենդանական աշխարհի օբյեկտների օգտագործման լիցենզիաների հաշվառման գրանցամատյան` ԱԼ-3.
VI. Բնապահպանական պետական տեսչություն
10. Ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթների հաշվառման գրանցամատյան` ԲՊՏ-1.
11. Երևանի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթների հաշվառման գրանցամատյան` ԵՏԲ-2.
12. Արարատի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթների հաշվառման գրանցամատյան` ԱրՏԲ-3.
13. Արմավիրի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթների հաշվառման գրանցամատյան` ԱմՏԲ-4.
14. Արագածոտնի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթների հաշվառման գրանցամատյան` ԱծՏԲ-5.
15. Գեղարքունիքի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթների հաշվառման գրանցամատյան` ԳՏԲ-6.
16. Կոտայքի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթների հաշվառման գրանցամատյան` ԿՏԲ-7.
17. Տավուշի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթների հաշվառման գրանցամատյան` ՏՏԲ-8.
18. Լոռու տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթների հաշվառման գրանցամատյան` ԼՏԲ-9.
19. Շիրակի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթների հաշվառման գրանցամատյան` ՇՏԲ-10.
20. Վայոց Ձորի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթների հաշվառման գրանցամատյան` ՎՁՏԲ-11.
21. Սյունիքի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթների հաշվառման գրանցամատյան` ՍՏԲ-12.
VII. Ատոմային էներգիայի օգտագործման միջուկային և ռադիացիոն անվտանգության տեսչություն
22. Ատոմային էներգիայի օգտագործման ոլորտում տրվող լիցենզիաների հաշվառման գրանցամատյան` ԱՏ-1.
VIII. «Բնապահպանական փորձաքննություն» պետական ոչ առևտրային կազմակերպություն
23. Բնապահպանական փորձաքննության եզրակացությունների տրամադրման հաշվառման գրանցամատյան` ԲՓ-1.
