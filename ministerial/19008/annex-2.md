# Հավելված N 2 Հայաստանի Հանրապետության բնապահպանության նախարարի 2005 թվականի հունվարի 17-ի N 13-Ն հրամանի
ՑԱՆԿ
Հայաստանի Հանրապետության բնապահպանության նախարարության աշխատակազմում վարվող վարչական վարույթի վերաբերյալ գործերի հաշվառման գրանցամատյանների
(վերնագիրը խմբ. 18.01.16 N 8-Ն)
I. Իրավաբանական վարչություն
Իրավական ապահովման բաժին
1. Վարչական վարույթի վերաբերյալ գործերի հաշվառման N 1 գրանցամատյան,
2. Վարչական վարույթի վերաբերյալ գործերի հաշվառման միասնական N 2 գրանցամատյան:
II. Ջրային ռեսուրսների կառավարման գործակալություն
Ջրօգտագործման թույլտվությունների բաժին
3. Ջրօգտագործման թույլտվությունների գրանցամատյան. վարչական վարույթի վերաբերյալ գործերի հաշվառման N 1 գրանցամատյան (ՋԹ-1),
4. Ջրօգտագործման թույլտվությունների գրանցման մատյան. վարչական ակտերի հաշվառման միասնական գրանցամատյան N 2 (ՋԹ-2):
III. Կենսառեսուրսների կառավարման գործակալություն
Կենդանական ռեսուրսների կառավարման բաժին
5. Վայրի կենդանիների և կենդանաբանական հավաքածուների ու առանձին նմուշների Հայաստանի Հանրապետության տարածքից արտահանելու և Հայաստանի Հանրապետության տարածք ներմուծելու թույլտվությունների գրանցամատյան ԿԹ-1 վարչական վարույթի վերաբերյալ գործերի հաշվառման N 1 գրանցամատյան,
6. Վայրի կենդանիների և կենդանաբանական հավաքածուների ու առանձին նմուշների Հայաստանի Հանրապետության տարածքից արտահանելու և Հայաստանի Հանրապետության տարածք ներմուծելու թույլտվությունների գրանցամատյան՝ վարչական ակտերի հաշվառման միասնական N 2 գրանցամատյան,
7. Վայրի կենդանիներ և առանձին վայրի բույսեր, որոնց տեղափոխումը Եվրասիական տնտեսական միության մաքսային տարածքով սահմանափակ է, արտահանման լիցենզիաների հաշվառման գրանցամատյան՝ վարչական վարույթի վերաբերյալ գործերի հաշվառման N 1 գրանցամատյան (առանձին վայրի կենդանիների վերաբերյալ),
8. Վայրի կենդանիներ և առանձին վայրի բույսեր, որոնց տեղափոխումը Եվրասիական տնտեսական միության մաքսային տարածքով սահմանափակ է, արտահանման լիցենզիաների՝ վարչական ակտերի հաշվառման միասնական N 2 գրանցամատյան (առանձին վայրի կենդանիների վերաբերյալ),
9. Հայաստանի Հանրապետության, Բելառուսի Հանրապետության, Ղազախստանի Հանրապետության և Ռուսաստանի Դաշնության Կարմիր գրքում ընդգրկված հազվագյուտ և անհետացող վայրի կենդանիների և բույսերի տեսակներ ու դրանց մասեր և (կամ) ածանցյալներ, որոնց տեղափոխումը Եվրասիական տնտեսական միության մաքսային տարածքով սահմանափակ է, արտահանման լիցենզիաների՝ վարչական վարույթի վերաբերյալ գործերի հաշվառման N 1 գրանցամատյան (վայրի կենդանիների վերաբերյալ),
10. Հայաստանի Հանրապետության, Բելառուսի Հանրապետության, Ղազախստանի Հանրապետության և Ռուսաստանի Դաշնության Կարմիր գրքում ընդգրկված հազվագյուտ և անհետացող վայրի կենդանիների և բույսերի տեսակներ ու դրանց մասեր և (կամ) ածանցյալներ, որոնց տեղափոխումը Եվրասիական տնտեսական միության մաքսային տարածքով սահմանափակ է, արտահանման լիցենզիաների՝ վարչական ակտերի հաշվառման միասնական N 2 գրանցամատյան (վայրի կենդանիների վերաբերյալ),
11. Հայաստանի Հանրապետության բնապահպանության նախարարության կողմից տրամադրվող ՍԻԹԵՍ-ի թույլտվությունների գրանցամատյան` վարչական վարույթի վերաբերյալ գործերի հաշվառման N 1 գրանցամատյան,
12. Հայաստանի Հանրապետության բնապահպանության նախարարության կողմից տրամադրվող ՍԻԹԵՍ-ի թույլտվությունների գրանցամատյան` վարչական ակտերի հաշվառման միասնական N 2 գրանցամատյան:
Բուսական ռեսուրսների կառավարման բաժին
13. Բուսաբանական հավաքածուների և առանձին նմուշների Հայաստանի Հանրապետության տարածքից արտահանելու և Հայաստանի Հանրապետության տարածք ներմուծելու թույլտվությունների հաշվառման գրանցամատյան` ԲԹ-1, վարչական վարույթի վերաբերյալ գործերի հաշվառման N 1 գրանցամատյան,
14. Բուսաբանական հավաքածուների և առանձին նմուշների Հայաստանի Հանրապետության տարածքից արտահանելու և Հայաստանի Հանրապետության տարածք ներմուծելու թույլտվությունների՝ վարչական ակտերի հաշվառման միասնական գրանցամատյան N 2,
15. Վայրի կենդանիներ և առանձին վայրի բույսեր, որոնց տեղափոխումը Եվրասիական տնտեսական միության մաքսային տարածքով սահմանափակ է, արտահանման լիցենզիաների հաշվառման գրանցամատյան՝ վարչական վարույթի վերաբերյալ գործերի հաշվառման N 1 գրանցամատյան (առանձին վայրի բույսերի վերաբերյալ),
16. Վայրի կենդանիներ և առանձին վայրի բույսեր, որոնց տեղափոխումը Եվրասիական տնտեսական միության մաքսային տարածքով սահմանափակ է, արտահանման լիցենզիաների՝ վարչական ակտերի հաշվառման միասնական N 2 գրանցամատյան (առանձին վայրի բույսերի վերաբերյալ),
17. Հայաստանի Հանրապետության, Բելառուսի Հանրապետության, Ղազախստանի Հանրապետության և Ռուսաստանի Դաշնության Կարմիր գրքում ընդգրկված հազվագյուտ և անհետացող վայրի կենդանիների և բույսերի տեսակներ ու դրանց մասեր և (կամ) ածանցյալներ, որոնց տեղափոխումը Եվրասիական տնտեսական միության մաքսային տարածքով սահմանափակ է, արտահանման լիցենզիաների՝ վարչական վարույթի վերաբերյալ գործերի հաշվառման N 1 գրանցամատյան (վայրի բույսերի վերաբերյալ),
18. Հայաստանի Հանրապետության, Բելառուսի Հանրապետության, Ղազախստանի Հանրապետության և Ռուսաստանի Դաշնության Կարմիր գրքում ընդգրկված հազվագյուտ և անհետացող վայրի կենդանիների և բույսերի տեսակներ ու դրանց մասեր և (կամ) ածանցյալներ, որոնց տեղափոխումը Եվրասիական տնտեսական միության մաքսային տարածքով սահմանափակ է, արտահանման լիցենզիաների՝ վարչական ակտերի հաշվառման միասնական N 2 գրանցամատյան (վայրի բույսերի վերաբերյալ):
lV. Բնապահպանական պետական տեսչություն
Վարչարարության և փորձաքննության բաժին
19. Վարչական վարույթի վերաբերյալ գործերի հաշվառման N 1 գրանցամատյան,
20. Վարչական վարույթի վերաբերյալ գործերի հաշվառման միասնական N 2 գրանցամատյան,
Երևանի տարածքային բաժին
21. Երևանի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթի վերաբերյալ գործերի հաշվառման գրանցամատյան N 1,
22. Երևանի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթի վերաբերյալ գործերի հաշվառման միասնական N 2 գրանցամատյան,
Արարատի տարածքային բաժին
23. Արարատի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթի վերաբերյալ գործերի հաշվառման գրանցամատյան N 1,
24. Արարատի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթի վերաբերյալ գործերի հաշվառման միասնական N 2 գրանցամատյան,
Արմավիրի տարածքային բաժին
25. Արմավիրի տարածքային բաժնում ֆիզիկական և իրավաբանական անձանց բողոքների, դիմումների հիման վրա հարուցված վարչական վարույթի վերաբերյալ գործերի հաշվառման գրանցամատյան N 1,
