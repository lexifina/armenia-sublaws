1. Հաստատել.
ա) «Ոչ ֆինանսական ակտիվների դասակարգումը»` համաձայն հավելված N 1-ի,
բ) «Ֆինանսական ակտիվների դասակարգումը»` համաձայն հավելված N 2-ի,
գ) «Պարտավորությունների դասակարգումը»` համաձայն հավելված N 3-ի,
դ) «Սեփական կապիտալի դասակարգումը»` համաձայն հավելված N 4-ի,
դ) «Ընթացիկ ծախսերի դասակարգումը»` համաձայն հավելված N 5-ի,
ե) «Ոչ ֆինանսական ակտիվների գծով ծախսերի դասակարգումը»` համաձայն հավելված N 6-ի,
զ) «Հիմնական գումարի մարման և ֆինանսական ակտիվների ձեռքբերման գծով ծախսերի դասակարգումը»` համաձայն հավելված N 7-ի,
է) «Ընթացիկ եկամուտների դասակարգումը»` համաձայն հավելված N 8-ի,
ը) «Ոչ ֆինանսական ակտիվների իրացումից մուտքերի դասակարգումը»` համաձայն հավելված N 9-ի,
թ) «Փոխառու միջոցներից և ֆինանսական ակտիվների իրացումից մուտքերի դասակարգումը»` համաձայն հավելված N 10-ի,
ժ) «Բյուջետային ծախսերի գործառական դասակարգումը«` համաձայն հավելված N 11-ի:
