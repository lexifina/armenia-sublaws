# ՀԱՎԵԼՎԱԾ N 2
Ձև N 1-ՀՀ-ամփոփ
Տ Ե Ղ Ե Կ Ա Ն Ք
Հայաստանի Հանրապետության 2014 թվականի պետական բյուջեից ՀՀ համայնքների բյուջեներին «Ֆինանսական համահարթեցման մասին» ՀՀ օրենքով սահմանված կարգով ֆինանսական համահարթեցման դոտացիաների գումարների հաշվարկներում օգտագործվող հողի հարկի գծով 2012 թվականի ելակետային տվյալների մասին
հազար դրամերով
N | Մարզի և համայնքների անվանումը | Կազմակեր-պությունների հողի հարկ | Ֆիզիկական անձանց հողի հարկ | Համայնքի ավագանու կողմից կազմակերպությունների համար սահմանված հողի հարկի արտոնություններ | Համայնքի ավագանու կողմից ֆիզիկական անձանց համար սահմանված հողի հարկի արտոնություններ
