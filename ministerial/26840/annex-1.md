# Հավելված Հայաստանի Հանրապետության տարածքային կառավարման նախարարի 2006 թ. օգոստոսի 29-ի N 11-Ն հրամանի
Կ Ա Ր Գ
ՀԱՄԱՅՆՔԱՅԻՆ ԾԱՌԱՅՈՂՆԵՐԻ ԱՏԵՍՏԱՎՈՐՈՒՄ ԱՆՑԿԱՑՆԵԼՈՒ ՀԱՄԱՐ ԹԵՍՏԵՐ ԿԱԶՄԵԼՈՒ (վերնագիրը փոփ. 26.11.25 N 32-Ն)
1. Համայնքային ծառայողների ատեստավորում անցկացնելու համար թեստերը կազմվում են «Համայնքային ծառայության մասին» Հայաստանի Հանրապետության օրենքին (այսուհետ` օրենք) և սույն կարգին համապատասխան:
(1-ին կետը փոփ. 26.11.25 N 32-Ն)
2. Հարցաշարերը կազմում է Հայաստանի Հանրապետության տարածքային կառավարման և ենթակառուցվածքների նախարարության աշխատակազմը:
(2-րդ կետը խմբ. 12.12.08 N 05-Ն, լրաց. 26.11.25 N 32-Ն)
3. Հարցաշարերը, ըստ բնագավառների, բաղկացած են հարցերից (խնդիրներից): Հարցերը պարունակում են համապատասխան բնագավառների վերաբերյալ կոնկրետ հարցադրումներ, իսկ խնդիրները` կոնկրետ իրավիճակների նկարագրություններ:
4․ Համայնքային ծառայության յուրաքանչյուր պաշտոնի համար համայնքայյին ծառայության ատեստավորման անցկացման համար կազմված հարցաշարերն ընդգրկում են`
1) համայնքային ծառայության գլխավոր պաշտոնների խմբի համար` առնվազն 120 հարց (խնդիր).
2) համայնքային ծառայության առաջատար պաշտոնների խմբի համար` առնվազն 90 հարց (խնդիր).
3) համայնքային ծառայության կրտսեր պաշտոնների խմբի համար՝ առնվազն 60 հարց (խնդիր):
(4-րդ կետը փոփ. 12.12.08 N 05-Ն, խմբ. 26.11.25 N 32-Ն)
5. Հարցաշարերի հարցերը (խնդիրները) ընդգրկում են հետևյալ բնագավառները`
ա) Հայաստանի Հանրապետության Սահմանադրություն` 10 տոկոս.
բ) համայնքային ծառայության մասին Հայաստանի Հանրապետության օրենսդրություն` 20 տոկոս.
գ) տեղական ինքնակառավարման մարմինների իրավասությունը սահմանող Հայաստանի Հանրապետության օրենսդրություն՝ 70 տոկոս:
դ) (ենթակետն ուժը կորցրել է 12.12.08 N 05-Ն)
(5-րդ կետը փոփ. 12.12.08 N 05-Ն)
6. Ատեստավորումն անցկացվելուց առնվազն մեկ ամիս առաջ հարցաշարերն իրենց միանշանակ ճիշտ պատասխաններով հրապարակվում են (դրանք կարող են փակցվել համայնքում՝ տեսանելի տեղում):
(6-րդ կետը լրաց. 12.12.08 N 05-Ն, 21.07.09 N 11-Ն, փոփ. 22.05.12 N 05-Ն, 26.11.25 N 32-Ն)
7. Հարցաշարերից հարցերի (խնդիրների) ընտրությունը կատարվում է համակարգչի միջոցով:
8. Հարցերը (խնդիրները) կոդավորվում, համարակալվում են ըստ բնագավառների և ըստ պաշտոնների խմբերի: Համայնքի աշխատակազմը հարցաշարերը զետեղում է համակարգչում:
(8-րդ կետը փոփ. 12.12.08 N 05-Ն, լրաց. 21.07.09 N 11-Ն, փոփ. 22.05.12 N 05-Ն, 26.11.25 N 32-Ն)
9. Համակարգչում առանձին զետեղվում են նաև կոդավորված և համարակալված հարցերի (խնդիրների) 3 կամ 4 ենթադրյալ պատասխան, որոնցից մեկը միանշանակ ճիշտ պատասխանն է:
10. Համակարգչային ծրագրի միջոցով թեստերը կազմվում են համակարգչում նախօրոք զետեղված հարցաշարերի կոդավորված հարցերից (խնդիրներից)՝ պատահական ընտրությամբ: Համակարգչային ծրագիրը, ընտրելով հարցը (խնդիրը), միաժամանակ դուրս է բերում վերջինիս ենթադրյալ պատասխանները և միասնականացնում:
11․ Համայնքային ծառայողների ատեստավորման համար կազմված թեստերում ընդգրկվող հարցերի (խնդիրների) քանակը հետևյալն է`
1) համայնքային ծառայության գլխավոր պաշտոնների խմբի համար՝ 40 հարց (խնդիր).
2) համայնքային ծառայության առաջատար պաշտոնների խմբի համար՝ 30 հարց (խնդիր).
3) համայնքային ծառայության կրտսեր պաշտոնների խմբի համար՝ 20 հարց (խնդիր):
(11-րդ կետը փոփ., լրաց. 12.12.08 N 05-Ն, խմբ. 26.11.25 N 32-Ն)
11․1 Թեստերում ընդգրկվում են սույն կարգի 5-րդ կետում նշված տոկոսային հարաբերակցությամբ բնագավառների հարցեր (խնդիրներ)։
(11.1-ին կետը լրաց. 26.11.25 N 32-Ն)
12. Սույն կարգի 10-րդ կետով նախատեսված կարգով կազմված թեստերի հետ միաժամանակ համակարգչի միջոցով դուրս է բերվում թեստավորման առաջադրանքների ճիշտ պատասխանների ձևանմուշը և անմիջապես զետեղվում կնքված արկղի մեջ:
13. Հանձնաժողովը թեստերը կազմում է մինչև թեստավորման փուլն սկսելը:
14. Յուրաքանչյուր ատեստավորման դեպքում մասնակիցների համար կազմվում է մեկ ընդհանուր թեստ:
(14-րդ կետը փոփ. 26.11.25 N 32-Ն)
15. Թեստավորման առաջադրանքները մասնակցին կամ համայնքային ծառայողին կարող են առաջարկվել գրավոր կամ համակարգչի միջոցով:
(հավելվածը խմբ., փոփ., լրաց. 12.12.08 N 05-Ն, լրաց. 21.07.09 N 11-Ն, փոփ. 22.05.12 N 05-Ն, փոփ., լրաց., խմբ. 26.11.25 N 32-Ն)
