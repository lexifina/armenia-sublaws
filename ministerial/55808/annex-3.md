# Հավելված N 3 ՀՀ արդարադատության նախարարի 2009 թվականի դեկտեմբերի 22-ի N 319-Ն հրամանի
Կ Ա Ր Գ
ՀԻՄՆԱԴՐԱՄՆԵՐԻ ԿՈՂՄԻՑ ՀՐԱՊԱՐԱԿՎՈՂ ԵՎ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԱՐԴԱՐԱԴԱՏՈՒԹՅԱՆ ՆԱԽԱՐԱՐՈՒԹՅՈՒՆ ՆԵՐԿԱՅԱՑՎՈՂ ՀԱՇՎԵՏՎՈՒԹՅԱՆ ՀՐԱՊԱՐԱԿՄԱՆ ԵՎ ՆԵՐԿԱՅԱՑՄԱՆ
1.Հիմնադրամներն իրենց գործունեության մասին հաշվետվությունները, իսկ աուդիտը պարտադիր լինելու դեպքում նաև տարեկան ֆինանսական հաշվետվությունը և աուդիտորի եզրակացությունը, օրենքով սահմանված կարգով հրապարակում են www.azdarar.am հասցեով գտնվող Հայաստանի Հանրապետության հրապարակային ծանուցումների պաշտոնական ինտերնետային կայքում, ինչի արդյունքում Հայաստանի Հանրապետության արդարադատության նախարարությանը կհամարվի գրավոր ծանուցված:
(1-ին կետը խմբ. 03.02.14 N 26-Ն)
2. (կետն ուժը կորցրել է 03.02.14 N 26-Ն)
3. (կետն ուժը կորցրել է 03.02.14 N 26-Ն)
4. ՀՀ արդարադատության նախարարության աշխատակազմի Իրավաբանական անձանց պետական ռեգիստրի գործակալությունը յուրաքանչյուր տարի հաշվետու տարվան հաջորդող ապրիլի 10-ից ոչ ուշ ՀՀ արդարադատության նախարարություն է ներկայացնում տեղեկանք, որը պետք է պարունակի www.azdarar.am հասցեով գտնվող Հայաստանի Հանրապետության հրապարակային ծանուցումների պաշտոնական ինտերնետային կայքում իրենց հաշվետվությունները հրապարակած և չհրապարակած բոլոր հիմնադրամների ցանկերը: Ցանկերում պետք է ներառվեն հիմնադրամի անվանումը, գործադիր մարմնի անունը, գործունեության հասցեն և առկայության դեպքում նաև էլեկտրոնային հասցեն և կապի այլ միջոցները:
(4-րդ կետը լրաց. 03.02.14 N 26-Ն)
