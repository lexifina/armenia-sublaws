# Հավելված N 1 Հաստատված է ՀՀ ԱՆ 2014 թ. մարտի 17-ի N 09-Ն հրամանով
Կ Ա Զ Մ
ԲՆԱԿՉՈՒԹՅԱՆ ՍՈՑԻԱԼԱՊԵՍ ԱՆԱՊԱՀՈՎ ԵՎ ԱՌԱՆՁԻՆ (ՀԱՏՈՒԿ) ԽՄԲԵՐԻ ՑԱՆԿՈՒՄ ՉԸՆԴԳՐԿՎԱԾ ԱՆՁԱՆՑ ՊԵՏՈՒԹՅԱՆ ԿՈՂՄԻՑ ԵՐԱՇԽԱՎՈՐՎԱԾ ԱՆՎՃԱՐ ԿԱՄ ԱՐՏՈՆՅԱԼ ՊԱՅՄԱՆՆԵՐՈՎ ԲԺՇԿԱԿԱՆ ՕԳՆՈՒԹՅՈՒՆ ԵՎ ՍՊԱՍԱՐԿՈՒՄ ՍՏԱՆԱԼՈՒ ՆՊԱՏԱԿՈՎ ԲԺՇԿԱԿԱՆ ԿԱԶՄԱԿԵՐՊՈՒԹՅՈՒՆՆԵՐ ՈՒՂԵԳՐՈՂ ԿԵՆՏՐՈՆԱԿԱՆ ՄՇՏԱԿԱՆ ԳՈՐԾՈՂ ՀԱՆՁՆԱԺՈՂՈՎԻ
1. Արայիկ Բաղրյան - Հայաստանի Հանրապետության առողջապահության նախարարության աշխատակազմի դեղորայքային քաղաքականության և բժշկական տեխնոլոգիաների վարչության պետի պաշտոնակատար (Հանձնաժողովի նախագահ)
2. Կարինե Սարիբեկյան - Հայաստանի Հանրապետության առողջապահության նախարարության աշխատակազմի մոր և մանկան առողջության պահպանման վարչության պետ (Հանձնաժողովի անդամ)
3. Ծաղիկ Վարդանյան - Հայաստանի Հանրապետության առողջապահության նախարարության աշխատակազմի բժշկական օգնության քաղաքականության վարչության պետի պաշտոնակատար (Հանձնաժողովի անդամ)
4. Սեդա Մանուկյան - Հայաստանի Հանրապետության առողջապահության նախարարի օգնական (Հանձնաժողովի անդամ)
5. Աստղիկ Ավագյան - Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի սոցիալական աջակցության վարչության նպաստների բաժնի գլխավոր մասնագետ (Հանձնաժողովի անդամ)
6. Սոնա Մարկոսյան - Հայաստանի Հանրապետության առողջապահության նախարարության աշխատակազմի հասարակայնության հետ կապերի բաժնի գլխավոր մասնագետ (Հանձնաժողովի քարտուղար)
