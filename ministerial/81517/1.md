1. Հաստատել.
1) «Պետական ոչ առևտրային կազմակերպությունների ֆինանսատնտեսական գործունեության վերաբերյալ ծրագրային ցուցանիշների» ներկայացման ձևը (Ձև N 1) համաձայն հավելված N 1-ի,
2) «Պետական ոչ առևտրային կազմակերպությունների դրամական միջոցների հոսքերի մասին հաշվետվության» ներկայացման ձևը (Ձև N 2)` համաձայն հավելված N 2-ի,
3) «Պետական ոչ առևտրային կազմակերպությունների ֆինանսատնտեսական գործունեության վերաբերյալ ծրագրային և փաստացի ցուցանիշների շեղումների մասին հաշվետվության» ներկայացման ձևը (Ձև N 3)` համաձայն հավելված N 3-ի,
4) «Պետական ոչ առևտրային կազմակերպությունների նպատակային և ձեռնարկատիրական գործունեության տարեկան ֆինանսատնտեսական արդյունքների մասին հաշվետվության» ձևը (Ձև N 4)` համաձայն հավելված N 4-ի։
