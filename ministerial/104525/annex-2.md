# Հավելված N 2 ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի 2016 թվականի փետրվարի 11-ի N 25-Ն հրամանի
Ը Ն Թ Ա Ց Ա Կ Ա Ր Գ
ՏԱՐԱԾՔԱՅԻՆ ՄԱԿԱՐԴԱԿՈՒՄ ՍՈՑԻԱԼԱԿԱՆ ՀԱՄԱԳՈՐԾԱԿՑՈՒԹՅԱՆ ՀԱՄԱՁԱՅՆԱԳՐԻ ԸՆԴՈՒՆՄԱՆ
1. Սույնով սահմանվում են Հայաստանի Հանրապետության մարզի (Երևան քաղաքի) տարածաշրջանում (վարչական շրջանում) սոցիալական համագործակցության համաձայնագրի (այսուհետ՝ Համաձայնագիր) ընդունման ընթացակարգը (այսուհետ՝ ընթացակարգ):
2. Միասնական սոցիալական ծառայության տարածքային կենտրոնը (այսուհետ՝ տարածքային կենտրոն) Համաձայնագրի ընդունման նպատակով այդ մասին հայտարարությունը ներկայացնում է Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարություն (այսուհետ՝ նախարարություն), միասնական սոցիալական ծառայություն Հայաստանի Հանրապետության մարզպետին, իսկ Երևանում՝ Երևանի քաղաքապետին՝ պաշտոնական համացանցային կայքում տեղադրելու նպատակով:
(2-րդ կետը փոփ., լրաց. 26.05.21 N 78-Ն)
3. Հայտարարության մեջ նշվում են հրավերը Համաձայնագրին միանալու վերաբերյալ, ինչպես նաև Համաձայնագրի տեքստն ամբողջությամբ:
4. Համաձայնագրին միանալու մասին տարածքային կառավարման և տեղական ինքնակառավարման մարմինների (այսուհետ՝ մարմին), սոցիալական ծառայություններ տրամադրող կազմակերպությունների (այսուհետ՝ կազմակերպություն) պաշտոնական գրությունները, իսկ ֆիզիկական անձանց դեպքում՝ դիմումները, ներկայացվում են տարածքային կենտրոն, որում նշվում է Համաձայնագրին ամբողջությամբ կամ վերապահումով միանալու մասին:
(4-րդ կետը փոփ. 26.05.21 N 78-Ն, լրաց. 27.04.23 N 77-Ն)
5. Տարածքային կենտրոնը հաշվառում և պահում է Համաձայնագրին միանալու մասին գրությունները (դիմումները):
(5-րդ կետը փոփ. 26.05.21 N 78-Ն)
6. Միասնական սոցիալական ծառայությունը՝ ընթացակարգի 4-րդ կետում նշված տարածքային կենտրոններին ներկայացված մարմնի, կազմակերպության գրությունները, ֆիզիկական անձանց դիմումները ստանալու օրվան հաջորդող հինգ աշխատանքային օրվա ընթացքում դրանց պատճենները ներկայացնում է նախարարություն Համաձայնագրին միացած մարմնի, կազմակերպության և ֆիզիկական անձանց տվյալները պաշտոնական համացանցային կայքում տեղադրելու նպատակով:
(6-րդ կետը փոփ. 26.05.21 N 78-Ն, խմբ. 27.04.23 N 77-Ն)
7. Ընթացակարգի 6-րդ կետում նշված տվյալներն են՝
1) մարմնի կամ կազմակերպության դեպքում՝
ա. անվանումը,
բ. իրավաբանական անձանց պետական ռեգիստրում գրանցման օրը, ամիսը, տարին, գրանցման համարը (բացառությամբ՝ մարմինների),
գ. փաստացի գործունեության հասցեն, էլեկտրոնային փոստի հասցեն, հեռախոսահամարը, կայքի անվանումը (առկայության դեպքում),
դ. ներկայացուցչի ազգանունը, անունը,
ե. իրականացված(վող) ծրագրերը.
2) ֆիզիկական անձանց դեպքում՝
ա. ազգանունը, անունը,
բ. հաշվառման հասցեն, էլեկտրոնային փոստի հասցեն, հեռախոսահամարը,
գ. գործունեության նախընտրելի ոլորտը,
դ. կամավորական աշխատանքի տևողությունը (առկայության դեպքում):
8. Տարածքային կենտրոնը Համաձայնագրին միանալու ցանկություն հայտնած մարմնին, կազմակերպությանը կամ ֆիզիկական անձին, նրանց տվյալները համապատասխան պաշտոնական կայքում տեղադրվելուց հետո, երեք աշխատանքային օրվա ընթացքում տեղեկացնում է այդ մասին և տրամադրում Համաձայնագրի մեկ օրինակ վավերացված տարածքային կենտրոնի ղեկավարի կողմից՝ յուրաքանչյուր էջը կնքված տարածքային կենտրոնի կնիքով:
(8-րդ կետը փոփ. 26.05.21 N 78-Ն, լրաց. 27.04.23 N 77-Ն)
9. Համաձայնագրին միանալու օր է համարվում տարածքային կենտրոն այդ մասին գրությունը (դիմումը) ներկայացնելու օրը:
(9-րդ կետը փոփ. 26.05.21 N 78-Ն)
10. Յուրաքանչյուր կողմ Համաձայնագրից մասնակցությունը հետ կանչելու պաշտոնական գրությունը (դիմումը) ներկայացնում է տարածքային կենտրոն:
(10-րդ կետը փոփ. 26.05.21 N 78-Ն)
11. Կողմի մասնակցությունը Համաձայնագրին համարվում է դադարած Կողմի՝ մասնակցությունը հետ կանչելու մասին գրությունը (դիմումը) տարածքային կենտրոն ներկայացնելու պահից:
(11-րդ կետը փոփ. 26.05.21 N 78-Ն)
12. Տարածքային կենտրոնը Համաձայնագրից մասնակցությունը հետ կանչելու պաշտոնական գրությունը (դիմումը) ստանալու օրվան հաջորդող հինգ աշխատանքային օրվա ընթացքում համապատասխան գրառում է կատարում Համաձայնագրին միանալու գրության (դիմումի) հաշվառման մատյանում՝ հաշվառման համապատասխան տեղում և դրա պատճենը ներկայացնում է նախարարություն Համաձայնագրից մասնակցությունը հետ կանչելու հանգամանքը՝ պաշտոնական կայքում նշելու նպատակով:
(12-րդ կետը փոփ. 26.05.21 N 78-Ն)
(հավելվածը փոփ., լրաց. 26.05.21 N 78-Ն, լրաց., խմբ. 27.04.23 N 77-Ն)
