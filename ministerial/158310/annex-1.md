# Հավելված ՀՀ առողջապահության նախարարի 2021 թվականի դեկտեմբերի 01-ի N 87-Ն հրամանի
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԱՌՈՂՋԱՊԱՀՈՒԹՅԱՆ ՆԱԽԱՐԱՐՈՒԹՅՈՒՆ ՎԱՐՉԱԿԱՆ ՎԻՃԱԿԱԳՐԱԿԱՆ ՀԱՇՎԵՏՎՈՒԹՅՈՒՆ
Ներկայացվում է` համաձայն «Պաշտոնական վիճակագրության մասին» Հայաստանի Հանրապետության օրենքի, Հայաստանի Հանրապետության վարչապետի 2018 թվականի հունիսի 11-ի թիվ 728-Լ որոշման հավելվածի 11-րդ կետի 17-րդ ենթակետի:
Ներկայացվում է ՀՀ ԱՆ «Մաշկաբանության ազգային կենտրոն» ՓԲԸ Ով է ներկայացնում _______________________________________ (անվանում) Հարկ վճարողի հաշվառման համար _______________________ Մարզ ________________________________________ Գտնվելու վայր ___________________________________________ Էլեկտրոնային փոստը _____________________________________ Իրավաբանական անձանց պետական ռեգիստրի գործակալությունում գրանցման համարը և նույնականացման (իդենտիֆիկացիոն) կոդը լրացվում է իրավաբանական անձանց պետական ռեգիստրի գործակալության կողմից տրված գրանցման վկայականից | Ձև N 89
եռամսյակային
Ներկայացման ժամկետ` համաձայն Առողջապահության նախարարի հրամանով հաստատված ժամանակացույցի
«Հայաստանի Հանրապետության առողջապահության նախարարության «Առավելապես սեռական ճանապարհով փոխանցվող հիվանդությունների՝ սիֆիլիսի, գոնոկոկային և խլամիդիային վարակների, հայտնաբերմանն ուղղված հետազոտությունների արդյունքների մասին» ձև N 89» եռամսյակային վարչական վիճակագրական հաշվետվության ձև
