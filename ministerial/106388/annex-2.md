# ՀԱՎԵԼՎԱԾ N 2 Ձև N 1-ՀՀ-ամփոփ
ՏԵՂԵԿԱՆՔ
Հայաստանի Հանրապետության 2017 թվականի պետական բյուջեից ՀՀ համայնքների բյուջեներին «Ֆինանսական համահարթեցման մասին» ՀՀ օրենքով սահմանված կարգով ֆինանսական համահարթեցման դոտացիաների գումարների հաշվարկներում օգտագործվող հողի հարկի գծով 2015 թվականի ելակետային տվյալների մասին
հազար դրամներով
N | Մարզի և համայնքների անվանումը | Կազմակերպու-թյունների հողի հարկ | Ֆիզիկական անձանց հողի հարկ | Համայնքի ավագանու կողմից կազմա-կերպությունների համար սահմանված հողի հարկի արտոնություններ | Համայնքի ավագանու կողմից ֆիզիկական անձանց համար սահմանված հողի հարկի արտոնություններ
