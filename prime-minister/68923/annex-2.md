# Հավելված N 2 ՀՀ վարչապետի 2011 թ. հունիսի 13-ի N 530-Ն որոշման
Կ Ա Զ Մ
ԱՍԻԱԿԱՆ ԶԱՐԳԱՑՄԱՆ ԲԱՆԿԻ ԿՈՂՄԻՑ ՀԱՍՏԱՏՎԱԾ ԿԵՆՏՐՈՆԱԿԱՆ ԵՎ ԱՐԵՎՄՏՅԱՆ ԱՍԻԱՅԻ ՏԱՐԱԾԱՇՐՋԱՆՈՒՄ ՀՈՂԵՐԻ ՕՏԱՐՄԱՆ ԵՎ ՏԱՐԱԲՆԱԿԵՑՄԱՆ ԱՆՎՏԱՆԳՈՒԹՅԱՆ ՄԵԽԱՆԻԶՄՆԵՐԻ ՈՒՂՂՈՐԴՄԱՆԸ ԵՎ ՀԱՄԱԿԱՐԳՄԱՆՆ ՈՒՂՂՎԱԾ ՏԱՐԱԾԱՇՐՋԱՆԱՅԻՆ ՏԵԽՆԻԿԱԿԱՆ ԱՋԱԿՑՈՒԹՅԱՆ ԴՐԱՄԱՇՆՈՐՀԱՅԻՆ ԾՐԱԳԻՐԸ ՀԱՄԱԿԱՐԳՈՂ ԱՇԽԱՏԱՆՔԱՅԻՆ ԽՄԲԻ
Ս. Ավետիսյան | - ՀՀ էկոնոմիկայի նախարարի տեղակալ (աշխատանքային խմբի ղեկավար)
Ա. Պետրոսյան | - ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի առաջին տեղակալ
Ա. Առաքելյան | - ՀՀ տրանսպորտի և կապի նախարարի տեղակալ
Ս. Գալստյան | - ՀՀ գյուղատնտեսության նախարարի տեղակալ
Ա. Սամուելյան | - ՀՀ մշակույթի նախարարի տեղակալ
Ս. Քրմոյան | - ՀՀ արդարադատության նախարարի տեղակալ
Լ. Շահվերդյան | - ՀՀ էներգետիկայի և բնական պաշարների նախարարի տեղակալ
Ռ. Ալավերդյան | - ՀՀ քաղաքաշինության նախարարի տեղակալ
Ա. Բախշյան | - ՀՀ տարածքային կառավարման նախարարի տեղակալ
Ա. Գաբրիելյան | - ՀՀ ֆինանսների նախարարության աշխատակազմի իրավաբանական վարչության պետ
Վ. Նիկոյան | - Երևանի քաղաքապետի տեղակալ (համաձայնությամբ)
Ֆ. Բաշոյան | - ՀՀ կառավարությանն առընթեր անշարժ գույքի կադաստրի պետական կոմիտեի նախագահի տեղակալ
Գ. Խաչատրյան | - ՀՀ տարածքային կառավարման նախարարության ջրային տնտեսության պետական կոմիտեի նախագահի տեղակալ
Վ. Լալայան | - ՀՀ էկոնոմիկայի նախարարության աշխատակազմի ներդրումային քաղաքականության վարչության պետ
Վ. Ավետիսյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի ընդերքի և հողերի պահպանության քաղաքականության վարչության պետ
(հավելվածը փոփ. 29.09.14 N 940-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար | Դ. Սարգսյան
