# Հավելված N 1 ՀՀ վարչապետի 2003 թ. հունվարի 10-ի N 5-Ն որոշման
Ց Ա Ն Կ
ջրավազանային կառավարման տարածքային բաժինՆԵՐԻ
(Վերնագիրը փոփ. 25.08.04 N 560-Ն)
1. Սևան-Հրազդանի ջրավազանային կառավարման տարածքային բաժին (ավազանի տարածքը` Սևանա լիճն իր ջրահավաքով, Հրազդան, Մարմարիկ, Քասախ և Ամբերդ գետերն իրենց ջրահավաքներով)
(1-ին կետը փոփ. 25.08.04 N 560-Ն)
2. Հյուսիսային ջրավազանային կառավարման տարածքային բաժին (ավազանի տարածքը՝ Դեբետ, Աղստև գետերն իրենց ջրահավաքներով և Քուռ գետի վտակներն իրենց ջրահավաքներով)
(2-րդ կետը փոփ. 25.08.04 N 560-Ն)
3. Ախուրյանի ջրավազանային կառավարման տարածքային բաժին (ավազանի տարածքը` Ախուրյան, Սելավ-Մաստարա, Մանթաշ գետերն իրենց վտակներով և ջրահավաքներով, Մանթաշ ջրամբարն իր ջրահավաքով)
(3-րդ կետը փոփ. 25.08.04 N 560-Ն)
4. Արարատյան ջրավազանային կառավարման տարածքային բաժին (ավազանի տարածքը` Ազատ, Վեդի, Սևջուր և Արփա գետերն իրենց ջրահավաքներով, Ակնալիճն իր ջրահավաքով)
(4-րդ կետը փոփ. 25.08.04 N 560-Ն)
5. Հարավային ջրավազանային կառավարման տարածքային բաժին (ավազանի տարածքը` Որոտան, Ողջի, Մեղրի գետերն իրենց ջրահավաքներով և Արաքս գետի վտակներն իրենց ջրահավաքներով)
(5-րդ կետը փոփ. 25.08.04 N 560-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
