ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՎԱՐՉԱՊԵՏ
Ո Ր Ո Շ ՈՒ Մ
21 ապրիլի 2004 թվականի N 237-Ն
«ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅՈՒՆՈՒՄ ՍՈՂԱՆՔԱՅԻՆ ԱՂԵՏԻ ԿԱՌԱՎԱՐՄԱՆ ՈՒՍՈՒՄՆԱՍԻՐՈՒԹՅՈՒՆ» ԾՐԱԳԻՐՆ ԻՐԱԿԱՆԱՑՆՈՂ ՃԱՊՈՆԱԿԱՆ ՈՒՍՈՒՄՆԱՍԻՐՈՂ ԽՄԲԻՆ ԱՋԱԿՑՈՂ ՄԻՋԳԵՐԱՏԵՍՉԱԿԱՆ ՀԱՆՁՆԱԺՈՂՈՎ ՍՏԵՂԾԵԼՈՒ ՄԱՍԻՆ
Համաձայն Հայաստանի Հանրապետության կառավարության 2004 թվականի մարտի 18-ի N 348-Ն որոշման 9-րդ կետի «ա» ենթակետի` «Հայաստանի Հանրապետությունում սողանքային աղետի կառավարման ուսումնասիրություն» ծրագրի իրականացման հետ կապված խնդիրների օպերատիվ լուծման նպատակով ստեղծել ճապոնական ուսումնասիրող խմբին աջակցող միջգերատեսչական հանձնաժողով հետևյալ կազմով`
Ս. Քոչարյան | - | ՀՀ քաղաքաշինության նախարարի տեղակալ (հանձնաժողովի նախագահ)
Վ. Տերտերյան | - | ՀՀ տարածքային կառավարման և ենթակառուցվածքների գործունեությունը համակարգող նախարարի տեղակալ (հանձնաժողովի նախագահի տեղակալ)
Մ. Վարդանյան | - | ՀՀ արտաքին գործերի նախարարության աշխատակազմի խաղաղօվկիանոսյան բաժնի վարիչ
Հ. Ավետիսյան | - | ՀՀ բնապահպանության նախարարության աշխատակազմի ընդերքի պահպանության վարչության պետ
Հ. Պետրոսյան | - | ՀՀ տրանսպորտի և կապի նախարարության «Հայաստանի ավտոմոբիլային ճանապարհներ» ՓԲԸ-ի գլխավոր տնօրենի տեղակալ
Մ. Գասպարյան | - | ՀՀ գյուղատնտեսության նախարարության աշխատակազմի հողերի մոնիտորինգի և մելիորացիայի վարչության պետ
Ռ. Գասպարյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի ղեկավարի տեղակալ
Ֆ. Եգորյան | - | ՀՀ կառավարությանն առընթեր անշարժ գույքի կադաստրի պետական կոմիտեի հողաշինարարության և հողային պետական տեսչության վարչության պետ
Ս. Ազարյան | - | ՀՀ կառավարությանն առընթեր արտակարգ իրավիճակների վարչության արտակարգ իրավիճակների կանխման և հետևանքների վերացման վարչության պետ
Ռ. Ջրբաշյան | - | ՀՀ գիտությունների ազգային ակադեմիա, երկրաբանական գիտությունների ինստիտուտի տնօրեն, ակադեմիկոս
Ս. Մարգարյան | - | ՀՀ քաղաքաշինության նախարարության աշխատակազմի գիտատեխնիկական քաղաքականության վարչության բաժնի պետ (հանձնաժողովի քարտուղար)
