# Հավելված N 1 ՀՀ վարչապետի 2010 թվականի օգոստոսի 24-ի N 669-Ն որոշման

Հ. Դարբինյան | - ՀՀ առողջապահության նախարարի առաջին տեղակալ (խորհրդի նախագահ)
Ա. Վանյան | - ՀՀ առողջապահության նախարարության աշխատակազմի պետական հիգիենիկ և հակահամաճարակային տեսչության պետ
Վ. Պողոսյան | - ՀՀ առողջապահության նախարարության աշխատակազմի բժշկական օգնության կազմակերպման վարչության պետ
Կ. Կարապետյան | - ՀՀ արտակարգ իրավիճակների նախարարության աշխատակազմի բնակչության և տարածքների պաշտպանության վարչության մոնիթորինգի կենտրոնի տեխնածին վթարների հակաքիմիական և հակաճառագայթային պաշտպանության բաժնի պետ
Լ. Ավետիսյան | - ՀՀ առողջապահության նախարարության աշխատակազմի պետական հիգիենիկ և հակահամաճարակային տեսչության վարակիչ և ոչ վարակիչ հիվանդությունների համաճարակաբանության բաժնի պետ
Ս. Հովհաննիսյան | - ՀՀ պաշտպանության նախարարության աշխատակազմի զինված ուժերի ռադիացիոն, քիմիական, կենսաբանական պաշտպանության վարչության պետի տեղակալ
Ն. Ադամյան | - ՀՀ արտակարգ իրավիճակների նախարարության աշխատակազմի աղետների բժշկության վարչության գլխավոր մասնագետ
Ս. Հովհաննիսյան | - ՀՀ արտակարգ իրավիճակների նախարարության աշխատակազմի ճգնաժամերի կառավարման ակադեմիայի դասախոս
Հ. Թումոյան | - ՀՀ գյուղատնտեսության նախարարության աշխատակազմի սննդամթերքի անվտանգության և անասնաբուժական պետական տեսչության պետի տեղակալ
Հ. Ոսկանյան | - ՀՀ գյուղատնտեսության նախարարության «Անասնաբուժության և անասնաբուծության գիտական կենտրոն» պետական ոչ առևտրային կազմակերպության լաբորատորիայի վարիչ (համաձայնությամբ)
Գ. Գրիգորյան | - ՀՀ էկոնոմիկայի նախարարության աշխատակազմի գիտելիքի տնտեսության, նորարարության և ձեռներեցության խթանման վարչության գիտելիքի տնտեսության բաժնի պետ
Վ. Հարությունյան | - ՀՀ էկոնոմիկայի նախարարության աշխատակազմի Երևանի «Ա. Ի. Ալիխանյանի անվան ֆիզիկայի ինստիտուտ» պետական ոչ առևտրային կազմակերպության ֆիզիկայի բաժնի պետ, գիտությունների դոկտոր (համաձայնությամբ)
Ի. Հակոբյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի վտանգավոր նյութերի և թափոնների կառավարման վարչության գլխավոր մասնագետ
Ա. Բաղդասարյան | - ՀՀ կառավարությանն առընթեր ազգային անվտանգության ծառայության սահմանապահ զորքերի շտաբի պետի տեղակալ
Դ. Թովմասյան | - ՀՀ կառավարությանն առընթեր ազգային անվտանգության ծառայության գլխավոր վարչության բաժնի աշխատող, մայոր
Վ. Մովսիսյան | - ՀՀ կառավարությանն առընթեր ՀՀ ոստիկանության բժշկական վարչության պետ, բժշկական ծառայության գնդապետ
Ա. Ավագյան | - ՀՀ կառավարությանն առընթեր քաղաքացիական ավիացիայի գլխավոր վարչության «Ավիաբուժ» բժշկական կենտրոն» փակ բաժնետիրական ընկերության ավիացիոն հիգիենիկ-համաճարակային հսկողության պետ (համաձայնությամբ)
Գ. Բաբայան | - ՀՀ տարածքային կառավարման նախարարության ջրային տնտեսության պետական կոմիտեի «Հայջրմուղ-կոյուղի» փակ բաժնետիրական ընկերության ջրի որակի բաժնի պետ, տեխնիկական գիտությունների դոկտոր (համաձայնությամբ)
Գ. Քառյան | - ՀՀ կառավարությանն առընթեր պետական եկամուտների կոմիտեի մաքսային ընթացակարգերի բաժնի պետ
Ա. Մնացականյան | - ՀՀ կառավարությանն առընթեր պետական միջուկային անվտանգության կարգավորման պետական կոմիտեի ճառագայթային անվտանգության վարչության պետ
Ն. Հովհաննիսյան | - ՀՀ առողջապահության նախարարության «Ակադեմիկոս Ս. Խ. Ավդալբեկյանի անվան առողջապահության ազգային ինստիտուտ» փակ բաժնետիրական ընկերության ռադիացիոն բժշկության և այրվածքաբանության ամբիոնի վարիչ, պրոֆեսոր (համաձայնությամբ)
Մ. Շմավոնյան | - ՀՀ առողջապահության նախարարության «Ակադեմիկոս Ս. Խ. Ավդալբեկյանի անվան առողջապահության ազգային ինստիտուտ» փակ բաժնետիրական ընկերության ինֆեկցիոն հիվանդությունների ամբիոնի վարիչ, «Նորք» ինֆեկցիոն կլինիկական հիվանդանոցի ինֆեկցիոն հիվանդությունների բաժնի վարիչ (համաձայնությամբ)
Գ. Մելիք-Անդրեասյան | - ՀՀ առողջապահության նախարարության «Ա. Բ. Ալեքսանյանի անվան համաճարակաբանության, վիրուսաբանության և բժշկական մակաբուծաբանության գիտահետազոտական ինստիտուտ» պետական ոչ առևտրային կազմակերպության տնօրեն (համաձայնությամբ)
Վ. Կոգան | - «Քանաքեռ-Զեյթուն» բժշկական կենտրոն» փակ բաժնետիրական ընկերության հիգիենայի և մասնագիտական հիվանդությունների գիտահետազոտական բաժանմունքի գիտական ղեկավար, բժշկական գիտությունների թեկնածու (համաձայնությամբ)
