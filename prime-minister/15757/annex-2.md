# Հավելված N 2 ՀՀ վարչապետի 2002 թ. սեպտեմբերի 16-ի N 532-Ն որոշման

ՋՐԻ ԱԶԳԱՅԻՆ ԽՈՐՀՐԴԻ
Ա. Մարգարյան | - | ՀՀ վարչապետ (խորհրդի նախագահ)
Հ. Աբրահամյան | - | ՀՀ տարածքային կառավարման և ենթակառուցվածքների գործունեությունը համակարգող նախարար (խորհրդի նախագահի տեղակալ)
Դ. Լոքյան | - | ՀՀ գյուղատնտեսության նախարար
Վ. Այվազյան | - | ՀՀ բնապահպանության նախարար
Ա. Արամյան | - | ՀՀ քաղաքաշինության նախարար
Մ. Միքայելյան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարարի տեղակալ
Ա. Հակոբյան | - | ՀՀ կառավարությանն առընթեր պետական գույքի կառավարման վարչության պետի տեղակալ
Վ. Մովսիսյան | - | ՀՀ վարչապետի խորհրդական
Գ. Մարտիրոսյան | - | ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի նախագահ, ՀՀ վարչապետի խորհրդական
Ա. Ներսիսյան | - | ՀՀ բնապահպանության նախարարության ջրային ռեսուրսների կառավարման գործակալության պետ
Վ. Դավիդյանց | - | ՀՀ գլխավոր պետական սանիտարական բժիշկ
Հ. Թոքմաջյան | - | Հիդրավլիկական հետազոտությունների հայկական ազգային ընկերության նախագահ (համաձայնությամբ)
- | Կարգավորող հանձնաժողովի նախագահ (համաձայնությամբ)
Լ. Գյումիշյան | - | ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի ջրատնտեսական ենթակառուցվածքների գործունեությունը համակարգող վարչության պետ
Ռ. Նազարյան | - | ՀՀ բնական մենաշնորհների կարգավորման հանձնաժողովի նախագահ (համաձայնությամբ)
(Կազմը փոփ. 19.08.03 N 390-Ն, լրաց. N 02.12.03 N 619-Ն)
