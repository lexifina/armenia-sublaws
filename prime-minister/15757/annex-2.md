# Հավելված N 2 ՀՀ վարչապետի 2002 թ. սեպտեմբերի 16-ի N 532-Ն որոշման

Ն. Փաշինյան | - | ՀՀ վարչապետ (խորհրդի նախագահ)
Տ. Ավինյան | - | ՀՀ փոխվարչապետ, Ջրի ազգային խորհրդի նախագահի տեղակալ
Է. Գրիգորյան | - | ՀՀ շրջակա միջավայրի նախարար
Ս. Պապիկյան | - | ՀՀ տարածքային կառավարման և ենթակառուցվածքների նախարար
Տ. Գաբրիելյան | - | ՀՀ էկոնոմիկայի նախարարի տեղակալ
Ա. Ջանջուղազյան | - | ՀՀ ֆինանսների նախարար
Ֆ. Ցոլակյան | - | ՀՀ արտակարգ իրավիճակների նախարար
Վ. Վերմիշյան | - | ՀՀ քաղաքաշինության կոմիտեի նախագահ
Գ. Բաղրամյան | - | ՀՀ հանրային ծառայությունները կարգավորող հանձնաժողովի նախագահ (համաձայնությամբ)
Վ. Մելքոնյան | - | ՀՀ տարածքային կառավարման և ենթակառուցվածքների նախարարության ջրային կոմիտեի նախագահ
Ս. Ղազարյան | - | ՀՀ վարչապետի խորհրդական
Կ. Մուխսյան | - | ՀՀ վարչապետի աշխատակազմի տարածքային զարգացման և շրջակա միջավայրի հարցերի վարչության պետ
Ս. Աթանեսյան | - | ՀՀ տարածքային կառավարման և ենթակառուցվածքների նախարարության պետական գույքի կառավարման կոմիտեի նախագահի տեղակալ
Է. Փիրումյան | - | ՀՀ շրջակա միջավայրի նախարարության ջրային ռեսուրսների կառավարման գործակալության պետի պաշտոնակատար
Ա. Վանյան | - | «Հիվանդությունների վերահսկման և կանխարգելման ազգային կենտրոն» պետական ոչ առևտրային կազմակերպության գլխավոր տնօրեն
Յու. Ջավադյան | - | «Հայջրնախագիծ ինստիտուտ» փակ բաժնետիրական ընկերության տնօրեն (համաձայնությամբ)
Հ. Թոքմաջյան | - | Հիդրավլիկական հետազոտությունների հայկական ազգային ասոցիացիայի նախագահ (համաձայնությամբ)
