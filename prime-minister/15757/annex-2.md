# Հավելված N 2 ՀՀ վարչապետի 2002 թ. սեպտեմբերի 16-ի N 532-Ն որոշման
Կ Ա Զ Մ
ՋՐԻ ԱԶԳԱՅԻՆ ԽՈՐՀՐԴԻ
Տ. Սարգսյան | - ՀՀ վարչապետ (խորհրդի նախագահ)
Ա. Գևորգյան | - ՀՀ փոխվարչապետ, ՀՀ տարածքային կառավարման նախարար
Ս. Թադևոսյան | - ՀՀ քաղաքաշինության նախարար
Ս. Կարապետյան | - ՀՀ գյուղատնտեսության նախարար
Ա. Հարությունյան | - ՀՀ բնապահպանության նախարար
Գ. Մալխասյան | - ՀՀ վարչապետի խորհրդական
Ռ. Նազարյան | - ՀՀ բնական մենաշնորհների կարգավորման հանձնաժողովի նախագահ (համաձայնությամբ)
Ա. Անդրեասյան | - ՀՀ տարածքային կառավարման նախարարության ջրային տնտեսության պետական կոմիտեի նախագահ
Պ. Սաֆարյան | - ՀՀ ֆինանսների նախարարի առաջին տեղակալ
Վ. Նարիմանյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության պետ
Ա. Վանյան | - ՀՀ առողջապահության նախարարության պետական հիգիենիկ և հակահամաճարակային տեսչության պետ
Կ. Մարգարյան | - ՀՀ կառավարության աշխատակազմի տարածքային զարգացման և բնապահպանական վարչության պետ
Ա. Մարկոսյան | - ՀՀ կառավարությանն առընթեր պետական գույքի կառավարման վարչության պետի տեղակալ
Մ. Մկրտումյան | - ՀՀ տարածքային կառավարման նախարարության ջրային տնտեսության պետական կոմիտեի աշխատակազմի ղեկավարին փոխարինող, ֆինանսատնտեսագիտական վարչության պետ-գլխավոր պետական տեսուչի տեղակալ
Վ. Մովսիսյան | - ՀՀ անտառների վերականգնման և զարգացման հիմնադրամի գործադիր տնօրեն (համաձայնությամբ)
Հ. Թոքմաջյան | - Երևանի ճարտարապետության և շինարարության պետական համալսարանի ռեկտոր
(հավելվածը փոփ. 19.08.03 N 390-Ն, լրաց. N 02.12.03 N 619-Ն, լրաց., փոփ. 12.04.04 N 203-Ն, փոփ. 20.07.05 N 553-Ն, 03.02.06 N 67-Ն, լրաց. 06.05.06 N 304-Ն, խմբ. 08.10.07 N 710-Ն, փոփ. 25.10.08 N 839-Ն, 21.03.11 N 208-Ն, խմբ. 17.01.13 N 24-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
