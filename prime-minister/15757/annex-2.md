# Հավելված N 2 ՀՀ վարչապետի 2002 թ. սեպտեմբերի 16-ի N 532-Ն որոշման

Կ. Կարապետյան | - ՀՀ վարչապետ (խորհրդի նախագահ)
Ա. Մինասյան | - ՀՀ բնապահպանության նախարար
Դ. Լոքյան | - ՀՀ տարածքային կառավարման և զարգացման նախարար
Ի. Առաքելյան | - ՀՀ գյուղատնտեսության նախարար
Վ. Արամյան | - ՀՀ ֆինանսների նախարար
Ռ. Նազարյան | -ՀՀ հանրային ծառայությունները կարգավորող հանձնաժողովի նախագահ (համաձայնությամբ)
Ն. Սարգսյան | - ՀՀ կառավարությանն առընթեր քաղաքաշինության պետական կոմիտեի նախագահ
Ա. Հարությունյան | - ՀՀ էներգետիկ ենթակառուցվածքների և բնական պաշարների նախարարության ջրային տնտեսության պետական կոմիտեի նախագահ
Գ. Մարտիրոսյան | - ՀՀ վարչապետի գլխավոր խորհրդական
Կ. Մարգարյան | - ՀՀ կառավարության աշխատակազմի տարածքային զարգացման և բնապահպանական վարչության պետ
Ա. Սիմոնյան | - ՀՀ կառավարությանն առընթեր պետական գույքի կառավարման վարչության պետի տեղակալ
Վ. Նարիմանյան | - ՀՀ էներգետիկ ենթակառուցվածքների և բնական պաշարների նախարարության ջրային տնտեսության պետական կոմիտեի նախագահի տեղակալ
Վ. Դավթյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության պետ
Ա. Վանյան | - «Հիվանդությունների վերահսկման և կանխարգելման ազգային կենտրոն» ՊՈԱԿ-ի գլխավոր տնօրեն
Լ. Վարդանյան | - ՀՀ արտակարգ իրավիճակների նախարարության հիդրոմետ ծառայության տնօրեն
Յու. Ջավադյան | - «Հայջրնախագիծ ինստիտուտ» ՓԲԸ-ի տնօրեն (համաձայնությամբ)
Հ. Թոքմաջյան | - Հիդրավլիկական հետազոտությունների հայկական ազգային ասոցիացիայի նախագահ (համաձայնությամբ)
