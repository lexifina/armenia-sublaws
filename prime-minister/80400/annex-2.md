# Հավելված N 2 ՀՀ վարչապետի 2012 թ. դեկտեմբերի 28-ի N 1295-Ն որոշման

ՀՀ աշխատանքի և սոցիալական հարցերի նախարար (հանձնաժողովի նախագահ)
ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի տեղակալ
ՀՀ կրթության, գիտության, մշակույթի և սպորտի նախարարի տեղակալ
ՀՀ արդարադատության նախարարի տեղակալ
ՀՀ տարածքային կառավարման և ենթակառուցվածքների նախարարի տեղակալ
ՀՀ առողջապահության նախարարի տեղակալ
ՀՀ ոստիկանության պետի տեղակալ
ՀՀ մարդու իրավունքների պաշտպանի աշխատակազմի դեպարտամենտի ղեկավար (համաձայնությամբ)
ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության հավասար հնարավորությունների ապահովման վարչության պետ
ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության հավասար հնարավորությունների ապահովման վարչության երեխաների հիմնահարցերի բաժնի պետ (հանձնաժողովի քարտուղար)
Մ. Անտոնյան | - «Երեխաների աջակցության կենտրոն» հիմնադրամի գործադիր տնօրեն (համաձայնությամբ)
Ն. Աֆանեսյան | - «Հայաստանի մանուկներ» բարեգործական հիմնադրամի սոցիալական աշխատանքի համակարգող» (համաձայնությամբ)
Հ. Սարգսյան | - «Հայկական կարիտաս» բարեսիրական հասարակական կազմակերպության ծրագրի ղեկավար (համաձայնությամբ)
Լ. Սիմոնյան | - Մանկական զարգացման հիմնադրամի տնօրեն (համաձայնությամբ)
Ս. Սարգսյան | - «ՍՕՍ Մանկական Գյուղեր» հայկական բարեգործական հիմնադրամի ազգային տնօրեն (համաձայնությամբ)
Վ. Սեդրակյան | - «Հայաստանի մանկական ասոցիացիա» բարեգործական հասարակական կազմակերպության տնօրեն (համաձայնությամբ)
Ա. Մուրադյան | - Հասանելի համայնքային սոցիալական ծառայություններ» ծրագրի գլխավոր հանձնակատար» (համաձայնությամբ)
(հավելվածը խմբ. 25.10.19 N 1552-Ն, փոփ., լրաց. 14.08.20 N 925-Ն, խմբ. 17.10.22 N 1224-Ն)
