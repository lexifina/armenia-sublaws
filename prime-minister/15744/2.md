2. Ուժը կորցրած ճանաչել Հայաստանի Հանրապետության վարչապետի`
ա) 1998 թվականի օգոստոսի 18-ի «Հայաստանի Հանրապետության կառավարության աշխատակազմի կանոնադրությունն ու կառուցվածքը հաստատելու մասին» N 494 որոշումը.
բ) 1999 թվականի օգոստոսի 18-ի «Հայաստանի Հանրապետության կառավարության աշխատակազմի կառուցվածքը հաստատելու մասին» N 495 որոշումը.
գ) 1999 թվականի սեպտեմբերի 13-ի «Հայաստանի Հանրապետության վարչապետի 1999 թվականի օգոստոսի 18-ի N 495 որոշման մեջ լրացում կատարելու մասին» N 569 որոշումը.
դ) 1999 թվականի սեպտեմբերի 20-ի «Հայաստանի Հանրապետության վարչապետի 1999 թվականի օգոստոսի 18-ի N 495 որոշման մեջ փոփոխություն կատարելու մասին» N 598 որոշումը.

զ) 2000 թվականի նոյեմբերի 20-ի «Հայաստանի Հանրապետության վարչապետի 1999 թվականի օգոստոսի 18-ի N 495 որոշման մեջ փոփոխություն կատարելու մասին» N 780 որոշումը.
է) 2000 թվականի դեկտեմբերի 18-ի «Հայաստանի Հանրապետության վարչապետի 1999 թվականի օգոստոսի 18-ի N 495 որոշման մեջ փոփոխություն կատարելու մասին» N 843 որոշումը.
ը) 2001 թվականի փետրվարի 12-ի «Հայաստանի Հանրապետության վարչապետի 1999 թվականի օգոստոսի 18-ի N 495 որոշման մեջ փոփոխություն կատարելու մասին» N 113 որոշումը.
թ) 2001 թվականի մարտի 12-ի «Հայաստանի Հանրապետության վարչապետի 1999 թվականի օգոստոսի 18-ի N 495 որոշման մեջ փոփոխություն կատարելու մասին» N 191 որոշումը.
ժ) 2001 թվականի նոյեմբերի 6-ի «Հայաստանի Հանրապետության վարչապետի 1999 թվականի օգոստոսի 18-ի N 495 որոշման մեջ փոփոխություն կատարելու մասին» N 791 որոշումը.
