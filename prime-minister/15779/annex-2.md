# Հավելված N 2 ՀՀ վարչապետի 2002 թ. նոյեմբերի 4-ի N 640-Ն որոշման
Կ Ա Զ Մ
ԿԵՆՍԱԹՈՇԱԿԱՅԻՆ ՀԱՄԱԿԱՐԳԻ ԲԱՐԵՓՈԽՈՒՄՆԵՐԻ ՀԱՆՁՆԱԺՈՂՈՎԻ
Ա. Մարգարյան | - ՀՀ վարչապետ (հանձնաժողովի նախագահ)
Հ. Աբրահամյան | - ՀՀ տարածքային կառավարման և ենթակառուցվածքների գործունեությունը համակարգող նախարար
Ռ. Մարտիրոսյան | - ՀՀ սոցիալական ապահովության նախարար
Դ. Հարությունյան | - ՀՀ արդարադատության նախարար
Վ. Խաչատրյան | - ՀՀ ֆինանսների և էկոնոմիկայի նախարար
Ե. Զախարյան | - ՀՀ պետական եկամուտների նախարար
Ա. Կարապետյան | - ՀՀ կառավարության աշխատակազմի սոցիալական հարցերի վարչության պետ
Ֆ. Մուշեղյան | - ՀՀ սոցիալական ապահովագրության պետական հիմնադրամի նախագահ
Տ. Սարգսյան | - ՀՀ կենտրոնական բանկի նախագահ
Է. Մուրադյան | - ՀՀ արժեթղթերի հանձնաժողովի նախագահ
Գ. Թադևոսյան | - ՀՀ Ազգային ժողովի սոցիալական, առողջապահության և բնության պահպանության հարցերի մշտական հանձնաժողովի նախագահ (համաձայնությամբ)
Գ. Մինասյան | - ՀՀ Ազգային ժողովի ֆինանսավարկային, բյուջետային և տնտեսական հարցերի մշտական հանձնաժողովի նախագահ (համաձայնությամբ)
Ա. Ղազարյան | - Հայաստանի արդյունաբերողների և գործարարների (գործատուների) միության նախագահ (համաձայնությամբ)
Մ. Հարությունյան | - ՀԱՄԿ-ի նախագահ (համաձայնությամբ)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
