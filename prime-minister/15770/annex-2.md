# Հավելված N 2 ՀՀ վարչապետի 2002 թ. հոկտեմբերի 21-ի N 614-Ն որոշման
Կ Ա Զ Մ ՎԵՃԵՐ ԼՈՒԾՈՂ ՀԱՆՁՆԱԺՈՂՈՎԻ
Ա.Անդրեասյան | - | ՀՀ տարածքային կառավարման և ենթակառուցվածքների գործունեությունը համակարգող նախարարի տեղակալ (հանձնաժողովի նախագահ)
Ռ. Ղուկասյան | - | ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի նախագահի տեղակալ (հանձնաժողովի նախագահի տեղակալ)
Է. Գևորգյան | - | ՀՀ կառավարության աշխատակազմի իրավաբանական վարչության գլխավոր մասնագետ
Մ. Գասպարյան | - | ՀՀ գյուղատնտեսության նախարարության աշխատակազմի հողերի մոնիտորինգի և մելիորացիայի բաժնի պետ
Ա. Մեսրոպյան | - | ՀՀ պետական եկամուտների նախարարության մեթոդաբանական և տեղեկատվական վարչության ուղղակի հարկերի բաժնի պետ
Է. Փիրումյան | - | ՀՀ բնապահպանության նախարարության ջրային ռեսուրսների պահպանության վարչության պետ
Վ. Դավիդյանց | - | ՀՀ գլխավոր պետական սանիտարական բժիշկ
Գ. Թումանյան | - | ՀՀ քաղաքաշինության նախարարության կոմունալ քաղաքականության վարչության գլխավոր մասնագետ
Ս. Մաճկալյան | - | ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի իրավաբանական վարչության պետ (հանձնաժողովի քարտուղար)
- | համապատասխան մարզպետ (Երևանի քաղաքապետ)
(Կազմը փոփ. 12.02.04 N 61-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
