# Հավելված N 2 ՀՀ վարչապետի 2002 թ. հոկտեմբերի 21-ի N 614-Ն որոշման
Կ Ա Զ Մ ՎԵՃԵՐ ԼՈՒԾՈՂ ՀԱՆՁՆԱԺՈՂՈՎԻ
Վ. Տերտերյան | - | ՀՀ տարածքային կառավարման և ենթակառուցվածքների գործունեությունը համակարգող նախարարի տեղակալ(հանձնաժողովի նախագահ)
Գ. Այվազյան | - | ՀՀ տարածքային կառավարման նախարարության ջրային տնտեսության պետական կոմիտեի նախագահի տեղակալ (հանձնաժողովի նախագահի տեղակալ)
Ն. Մնոյան | - | ՀՀ կառավարության աշխատակազմի իրավաբանական վարչության գլխավոր մասնագետ
Մ. Գասպարյան | - | ՀՀ գյուղատնտեսության նախարարության աշխատակազմի հողերի մոնիտորինգի և մելիորացիայի բաժնի պետ
Ա. Մեսրոպյան | - | ՀՀ պետական եկամուտների նախարարության մեթոդաբանական և տեղեկատվական վարչության ուղղակի հարկերի բաժնի պետ
Է. Փիրումյան | - | ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության ջրային ռեսուրսների քաղաքականության և վերլուծության բաժնի պետ
Ա. Վանյան | - | ՀՀ առողջապահության նախարարության պետական հիգիենիկ և հակահամաճարակային հսկողության տեսչության պետ
Ս. Սրապյան | - | ՀՀ քաղաքաշինության նախարարության աշխատակազմի բնակարանային և կոմունալ քաղաքականության վարչության կոմունալ բաժնի պետ
Ս. Մաճկալյան | - | ՀՀ տարածքային կառավարման նախարարության ջրային տնտեսության պետական կոմիտեի աշխատակազմի իրավաբանական վարչության պետ (հանձնաժողովի քարտուղար)
- | համապատասխան մարզպետ (Երևանի քաղաքապետ)
Ա. Ներսիսյան | - | ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության պետ
Վ. Նարիմանյան | - | ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության պետի տեղակալ
Գ. Մուրադյան | - | ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության ջրօգտագործման թույլտվությունների բաժնի պետ
(Կազմը փոփ. 12.02.04 N 61-Ն, 13.10.04 N 666-Ն, փոփ., լրաց. 25.04.06 N 282-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
