Ա. Ասատրյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարար (խորհրդի նախագահ)
Ա. Պետրոսյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի առաջին տեղակալ
Ֆ. Բերիկյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի տեղակալ
Գ. Գասպարյան | - | ՀՀ ֆինանսների նախարարության աշխատակազմի բյուջետային ծախսերի ֆինանսական ծրագրավորման վարչության սոցիալական ոլորտում բյուջետային ծախսերի ֆինանսական ծրագրավորման բաժնի գլխավոր մասնագետ
Ա. Մինասյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի սոցիալական աջակցության վարչության պետ
Է. Ավետյան | - | ՀՀ ֆինանսների նախարարության աշխատակազմի «Արտասահմանյան ֆինանսական ծրագրերի կառավարման կենտրոն» ԾԻԳ-ի գործադիր տնօրեն
Ս. Հարությունյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության «Զբաղվածության պետական ծառայություն» գործակալության պետ
Ա. Աբրահամյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության սոցիալական ապահովության պետական ծառայության պետ
(հավելվածը փոփ. 09.09.03 N 425-Ն, փոփ., լրաց. 19.04.05 N 259-Ն, խմբ. 24.09.07 N 676-Ն, 24.07.08 N 549-Ն, փոփ. 09.07.09 N 566-Ն, 15.02.10 N 90-Ն, փոփ., լրաց. 03.08.10 N 613-Ն, փոփ. 19.07.12 N 625-Ն, 23.11.12 N 1151-Ն)
