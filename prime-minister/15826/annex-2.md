# Հավելված N 2 ՀՀ վարչապետի 2003 թվականի մարտի 24-ի N 115-Ն որոշման

(Վերնագիրը փոփ. 19.04.05 N 259-Ն)
Ա. Վարդանյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարար (խորհրդի նախագահ)
Ա. Պետրոսյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի առաջին տեղակալ
Ֆ. Բերիկյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի տեղակալ
Ա. Ասատրյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի տեղակալ
Տ. Հարությունյան | - | ՀՀ կառավարության աշխատակազմի սոցիալական հարցերի վարչության գլխավոր մասնագետ
Ա. Սահակյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի խորհրդական
Գ. Գասպարյան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարարության աշխատակազմի բյուջետային ծախսերի ֆինանսական ծրագրավորման վարչության սոցիալական ոլորտում բյուջետային ծախսերի ֆինանսական ծրագրավորման բաժնի գլխավոր մասնագետ
Վ. Առաքելյան | - | ՀՀ կառավարությանն առընթեր պետական գույքի կառավարման վարչության պետի խորհրդական
Ա. Մինասյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի սոցիալական աջակցության վարչության պետ
Հ. Գորոյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի իրավաբանական վարչության պետ
Ռ. Հարությունյան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարարության աշխատակազմի «Արտասահմանյան ֆինանսական ծրագրերի կառավարման կենտրոն» պետական հիմնարկի գործադիր տնօրեն
Ս. Հարությունյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության «Զբաղվածության պետական ծառայություն» գործակալության պետ
Ա. Հարությունյան | - | ՀՀ սոցիալական ապահովագրության պետական հիմնադրամի նախագահի տեղակալ
(Կազմը փոփ. 09.09.03 N 425-Ն, փոփ., լրաց. 19.04.05 N 259-Ն, խմբ. 24.09.07 N 676-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
