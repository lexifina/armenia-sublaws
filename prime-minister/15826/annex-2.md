(Վերնագիրը փոփ. 19.04.05 N 259-Ն)
Ա. Վարդանյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարար (խորհրդի նախագահ)
Ա. Եսայան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի առաջին տեղակալ
Ա. Պետրոսյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի տեղակալ
Ֆ. Բերիկյանին | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի տեղակալ
Տ. Հարությունյան | - | ՀՀ կառավարության աշխատակազմի սոցիալական հարցերի վարչության գլխավոր մասնագետ
Ա. Սահակյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի խորհրդական
Ռ. Բալասանովային | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարության աշխատակազմի բյուջետային ծախսերի ֆինանսական ծրագրավորման վարչության սոցիալական ոլորտում բյուջետային ծախսերի ֆինանսական ծրագրավորման բաժնի գլխավոր մասնագետ
Վ. Առաքելյան | - | ՀՀ պետական գույքի կառավարման նախարարության աշխատակազմի միջազգային համագործակցության վարչության պետ
Ա. Մինասյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի սոցիալական աջակցության վարչության պետ
Հ. Գորոյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի իրավաբանական բաժնի պետ
Ռ. Հարությունյան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարարության աշխատակազմի «Արտասահմանյան ֆինանսական ծրագրերի կառավարման կենտրոն» պետական հիմնարկի գործադիր տնօրեն
Ա. Ասատրյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի սոցիալական ապահովագրության և կենսաթոշակային ապահովության վարչության պետ
Ս. Հարությունյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի «Հայաստանի Հանրապետության զբաղվածության ծառայություն» գործակալության պետ
Ա. Հարությունյան | - | ՀՀ սոցիալական ապահովագրության պետական հիմնադրամի նախագահի տեղակալ
(Կազմը փոփ. 09.09.03 N 425-Ն, փոփ., լրաց. 19.04.05 N 259-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
