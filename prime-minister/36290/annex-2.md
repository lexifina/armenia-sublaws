Գ. Սարգսյան | - | ՀՀ տրանսպորտի և կապի նախարար (խորհրդի նախագահ)
Հ. Բեգլարյան | - | ՀՀ տրանսպորտի և կապի նախարարի առաջին տեղակալ
Ա. Սհոյան | - | ՀՀ Նախագահի աշխատակազմի փորձագիտական-վերլուծական վարչության պետ
Վ. Տերտերյան | - | ՀՀ տարածքային կառավարման նախարարի առաջին տեղակալ
Ս. Ղոնաղչյան | - | ՀՀ կառավարության աշխատակազմի ֆինանսատնտեսագիտական վարչության պետ
Հ. Դավթյան | - | ՀՀ ֆինանսների նախարարի գլխավոր խորհրդական
Ա. Մնացականյան | - | Երևանի քաղաքապետի խորհրդական
Դ. Դանիելյան | - | ՀՀ կառավարությանն առընթեր ՀՀ ոստիկանության «Ճանապարհային ոստիկանություն» ծառայության ճանապարհային երթևեկության կազմակերպման հսկողության բաժնի պետ, ոստիկանության փոխգնդապետ
Ա. Բարսեղյան | - | ՀՀ արդարադատության նախարարության իրավական ակտերի փորձաքննության վարչության հաշվառման, գրանցման և համակարգման բաժնի պետ
Կ. Գևորգյան | - | «Հայաստանի ավտոմոբիլային ճանապարհների տնօրինություն» ՊՈԱԿ-ի գլխավոր տնօրեն
Ա. Բախտամյան | - | «Տրանսպորտի ծրագրերի իրականացման գրասենյակ» պետական հիմնարկի տնօրեն։
(հավելվածը խմբ. 27.08.08 N 664-Ն)
