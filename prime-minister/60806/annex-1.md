# Հավելված ՀՀ վարչապետի 2010 թ. սեպտեմբերի 11-ի N 731-Ն որոշման
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՆԱԽԱԳԱՀԻ, ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԱԶԳԱՅԻՆ ԺՈՂՈՎԻ, ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆ ՊԵՏԱԿԱՆ ԿԱՌԱՎԱՐՉԱԿԱՆ ՀԻՄՆԱՐԿՆԵՐԻ, ԻՆՉՊԵՍ ՆԱԵՎ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆ ԱՆԴԱՄՆԵՐԻ, ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆՆ ԱՌԸՆԹԵՐ ՊԵՏԱԿԱՆ ԿԱՌԱՎԱՐՄԱՆ ՄԱՐՄԻՆՆԵՐԻ, ՕՐԵՆՔՈՎ ՍՏԵՂԾՎԱԾ ՊԵՏԱԿԱՆ ՄԱՐՄԻՆՆԵՐԻ ՂԵԿԱՎԱՐՆԵՐԻ ՈՒ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՄԱՐԶՊԵՏՆԵՐԻ, «ՀԱՅՌՈՒՍԳԱԶԱՐԴ» ՓԱԿ ԲԱԺՆԵՏԻՐԱԿԱՆ ԸՆԿԵՐՈՒԹՅԱՆ ԳԼԽԱՎՈՐ ՏՆՕՐԵՆԻ, Հայաստանի Հանրապետության գիտությունների ազգային ակադեմիայի նախագահի, Երեվանի քաղաքապետի ԾԱՌԱՅՈՂԱԿԱՆ ԱՎՏՈՄՈԲԻԼՆԵՐԻ ՀԱՇՎԱՌՄԱՆ ՀԱՄԱՐԱՆԻՇԵՐԻ ՆԻՇԵՐԸ (վերնագիրը լրաց. 21.05.12 N 440-Ն, 03.10.12 N 976-Ն) (հավելվածը լրաց. 29.12.11 N 1286-Ն, 25.01.12 N 43-Ն, 21.05.12 N 440-Ն, 03.10.12 N 976-Ն, փոփ. 21.06.17 N 615-Ն, լրաց. 16.04.18 N 386-Ն, խմբ. 30.07.18 N 1028-Ն, փոփ., լրաց. 18.01.22 N 58-Ն, փոփ. 30.11.22 N 1413-Ն)
