# Հավելված N 1 ՀՀ վարչապետի 2006 թ. հունիսի 7-ի N 401-Ն որոշման

Վ. Վարդանյան | - ՀՀ քաղաքաշինության նախարար (խորհրդի նախագահ)
Ա. Հակոբյան | - ՀՀ քաղաքաշինության նախարարի տեղակալ (խորհրդի նախագահի տեղակալ)
Հ. Մաթիլյան | - ՀՀ բնապահպանության նախարարի տեղակալ
Ա. Մինասյան | - ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի սոցիալական աջակցության վարչության պետ
Լ. Շահվերդյան | - ՀՀ էներգետիկայի նախարարի տեղակալ
Վ. Վարդանյան | - Երևանի քաղաքապետի տեղակալ
Ա. Վանյան | - ՀՀ առողջապահության նախարարության պետական հիգիենիկ և հակահամաճարակային տեսչության պետ
Ա. Հարությունյան | - ՀՀ տարածքային կառավարման նախարարության աշխատակազմի միգրացիոն գործակալության փախստականների վարչության պետ
Թ. Բաբայան | - Հայաստանի վերականգնվող էներգետիկայի և էներգախնայողության հիմնադրամի տնօրեն (համաձայնությամբ)
Կ. Խաչատրյան | - «Հազարամյակի համայնքներ» զարգացման հիմնադրամի նախագահ (համաձայնությամբ)
Ե. Աթայան | - ՀՀ քաղաքաշինության նախարարության աշխատակազմի բնակարանային ապահովման, բնակարանային ֆոնդի կառավարման և կոմունալ քաղաքականության վարչության պետ (խորհրդի քարտուղար)
(հավելվածը փոփ. 24.09.07 N 674-Ն, 21.08.10 N 661-Ն)
