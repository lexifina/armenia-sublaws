# Հավելված N 2 ՀՀ վարչապետի 2004 թ. օգոստոսի 2-ի N 498-Ն որոշման
Կ Ա Զ Մ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՍՈՑԻԱԼԱԿԱՆ ԱՊԱՀՈՎԱԳՐՈՒԹՅԱՆ ՊԵՏԱԿԱՆ ՀԻՄՆԱԴՐԱՄԻ ԽՈՐՀՐԴԻ
Ա.Մարգարյան | - ՀՀ վարչապետ (խորհրդի նախագահ)
Վ. Խաչիկյան | - ՀՀ սոցիալական ապահովագրության պետական հիմնադրամի նախագահ
Լ. Գևորգյան | - ՀՀ Նախագահի օգնական
Վ. Տերտերյան | - ՀՀ տարածքային կառավարման և ենթակառուցվածքների գործունեությունը նախարարի տեղակալ
Պ. Սաֆարյան | - ՀՀ ֆինանսների և էկոնոմիկայի նախարարի առաջին տեղակալ
Ա. Պետրոսյան | - ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի տեղակալ
Լ. Յոլյան | - ՀՀ առողջապահության նախարարի տեղակալ
Տ. Մուկուչյան | - ՀՀ արդարադատության նախարարի տեղակալ
Ռ. Քոչարյան | - ՀՀ կառավարությանն առընթեր հարկային պետական ծառայության պետի տեղակալ
Ա. Ղազարյան | - Հայաստանի արդյունաբերողների և գործարարների միության նախագահ (համաձայնությամբ)
Բ. Խառատյան | - ՀՀ արհեստակցական միությունների կոնֆեդերացիայի նախագահի տեղակալ (համաձայնությամբ)
(Կազմը խմբ. 10.03.05 N 144-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
