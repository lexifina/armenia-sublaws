# Հավելված N 1 ՀՀ վարչապետի 2005 թ. օգոստոսի 31-ի N 671-Ն որոշման
Կ Ա Զ Մ
ԱՐՏԱԿԱՐԳ ԻՐԱՎԻՃԱԿՆԵՐԻ ՀԵՏԵՎԱՆՔՈՎ ԱՌԱՋԱՑԱԾ ԱՂԵՏԻ ԳՈՏՈՒՄ ՋՐԱՅԻՆ ՌԵՍՈՒՐՍՆԵՐԻ ՎԻՃԱԿԻ ԳՆԱՀԱՏՄԱՆ, ԲԱՑԱՍԱԿԱՆ ՀԵՏԵՎԱՆՔՆԵՐԻ ՀՆԱՐԱՎՈՐԻՆՍ ԱՐԱԳ ՎԵՐԱՑՄԱՆ, ԺԱՄԿԵՏՆԵՐԻ ՍԱՀՄԱՆՄԱՆ ԵՎ ԱՐՏԱԿԱՐԳ ԻՐԱՎԻՃԱԿՆԵՐԻ ՀԵՏԵՎԱՆՔՆԵՐԻ ՎԵՐԱՑՄԱՆԸ ԽՈՉԸՆԴՈՏՈՂ ԳՈՐԾՈՆՆԵՐԻ ՀԱՅՏՆԱԲԵՐՄԱՆ ՆՊԱՏԱԿՈՎ ՍՏԵՂԾՎՈՂ` ՄՇՏԱՊԵՍ ԳՈՐԾՈՂ ՄԻՋԳԵՐԱՏԵՍՉԱԿԱՆ ՀԱՆՁՆԱԺՈՂՈՎԻ
Վ. Գաբրիելյան | - ՀՀ տարածքային կառավարման նախարարության արտակարգ իրավիճակների վարչության պետի տեղակալ, գնդապետ (հանձնաժողովի նախագահ)
Լ. Նազարյան | - ՀՀ տարածքային կառավարման նախարարության արտակարգ իրավիճակների վարչության բնակչության և տարածքների պաշտպանության վարչության տեխնածին վթարների հակաքիմիական և հակաճառագայթային պաշտպանության բաժնի պետ (հանձնաժողովի նախագահի տեղակալ)
Գ. Պետրոսյան | - ՀՀ գյուղատնտեսության նախարարի տեղակալ
Հ. Մաթիլյան | - ՀՀ բնապահպանության նախարարի տեղակալ
Կ. Գևորգյան | - ՀՀ քաղաքաշինության նախարարի տեղակալ
Վ. Դավիդյանց | - ՀՀ գլխավոր պետական սանիտարական բժիշկ
Հ. Մուսայելյան | - ՀՀ էներգետիկայի նախարարի տեղակալ
Մ. Գասպարյան | - ՀՀ գյուղատնտեսության նախարարության աշխատակազմի հողերի օգտագործման և մելիորացիայի վարչության պետ
Ս. Գրիգորյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության ջրավազանային պլանավորման կառավարման բաժնի պետ
Ս. Սրապյան | - ՀՀ քաղաքաշինության նախարարության աշխատակազմի բնակարանային և կոմունալ քաղաքականության վարչության կոմունալ բաժնի պետ
Ս. Ավագյան | - ՀՀ առողջապահության նախարարության աշխատակազմի պետական հիգիենիկ և հակահամաճարակային տեսչության կոմունալ հիգիենայի բաժնի պետ
Հ.Հարությունյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության ջրավազանային պլանավորման կառավարման բաժնի պետի տեղակալ
Ն. Բակունց | - ՀՀ առողջապահության նախարարության աշխատակազմի պետական հիգիենիկ և հակահամաճարակային տեսչության կոմունալ հիգիենայի բաժնի գլխավոր մասնագետ
Գ. Մկրտչյան | - «Որոտանի հիդրոԷլեկտրակայանների համակարգ» փակ բաժնետիրական ընկերության գլխավոր ճարտարագետ
Վ. Անանյան | - «Երևանի ջրմուղկոյուղի» փակ բաժնետիրական ընկերության արտադրատեխնիկական բաժնի պետ
Գ. Բաղդասարյան | - «Միջազգային էներգետիկական կորպորացիա» փակ բաժնետիրական ընկերության արտադրության կառավարման տնօրինության տնօրեն
Ա. Թարվերդյան | - «Հայջրնախագիծ ինստիտուտ» փակ բաժնետիրական ընկերության գլխավոր ճարտարագետի տեղակալ
Ա. Սանագյան | - «Հայհիդրոէներգանախագիծ» փակ բաժնետիրական ընկերության նախագծի գլխավոր ճարտարագետ
Լ. Ալիխանյան | - «Հայջրմուղկոյուղի» փակ բաժնետիրական ընկերության տեխնիկական հետազոտությունների բաժնի պետ
Ա. Մանուչարյան | - «Հայջրնախագիծ ինստիտուտ» փակ բաժնետիրական ընկերության ոռոգման բաժնի վարիչ
Գ. Գևորգյան | - «Հայջրնախագիծ ինստիտուտ» փակ բաժնետիրական ընկերության հիդրոտեխնիկական կառուցվածքների բաժնի վարիչ
Ա. Մելքումով | - «Ոռոգումջրառ» փակ բաժնետիրական ընկերության ջրամբարների բաժնի պետի տեղակալ
(հավելվածը փոփ. 19.04.13 N 298-Ն)
