# Հավելված N 1 ՀՀ վարչապետի 2006 թ. հոկտեմբերի 10-ի N 747-Ն որոշման
Կ Ա Զ Մ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՎԱՐՉԱՊԵՏԻՆ ԿԻՑ` ՀԱՇՄԱՆԴԱՄՆԵՐԻ ՀԱՐՑԵՐՈՎ ԶԲԱՂՎՈՂ ԽՈՐՀՐԴԻ
Մ. Պետրոսյան | - ՀՀ Ազգային ժողովի սոցիալական, առողջապահության և բնության պահպանության հարցերի մշտական հանձնաժողովի նախագահ (համաձայնությամբ)
Պ. Սաֆարյան | - ՀՀ ֆինանսների և էկոնոմիկայի նախարարի առաջին տեղակալ
Վ. Տերտերյան | - ՀՀ տարածքային կառավարման նախարարի առաջին տեղակալ
Հ. Դարբինյան | - ՀՀ առողջապահության նախարարի առաջին տեղակալ
Ֆ. Բերիկյան | - ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի տեղակալ
Կ. Արեյան | - Երևանի քաղաքապետի առաջին տեղակալ
Ա. Կարապետյան | - ՀՀ կառավարության աշխատակազմի սոցիալական հարցերի վարչության պետ (խորհրդի աշխատանքները համակարգող)
Է. Շարմազանով | - ՀՀ վարչապետի օգնական
Ջ. Բաղդասարյան | - ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի հաշմանդամների և տարեցների հիմնահարցերի վարչության պետ
Ս. Հարությունյան | - ՀՀ պաշտպանության նախարարության զինծառայողների սոցիալական պաշտպանության վարչության պետ
Հ. Աբրահամյան | - «Հայաստանի հաշմանդամների «Փյունիկ» միություն» ՀԿ-ի նախագահ (համաձայնությամբ)
Ս. Օհանյան | - «Փարոս» ՀԿ-ի նախագահ (համաձայնությամբ)
Ա. Աբրահամյան | - «Փրկություն» ՀԿ-ի նախագահ (համաձայնությամբ)
Ա. Ալավերդյան | - «Ունիսոն» ՀԿ-ի նախագահ (համաձայնությամբ)
Ս. Թադևոսյան | - «Հույսի կամուրջ» ՀԿ-ի նախագահ (համաձայնությամբ)
Մ. Պահուտյան | - «Կամք և կորով» ՀԿ-ի նախագահ (համաձայնությամբ)
Ա. Մկրտչյան | - «Սկարպ» ՀԿ-ի նախագահ (համաձայնությամբ)
Լ. Ներսիսյան | - «Աստղիկ» ՀԿ-ի նախագահ (համաձայնությամբ)
Ս. Ժամկոչյան | - «Հավատ» ՀԿ-ի նախագահ (համաձայնությամբ)
Ն. Պեպանյան | - «Լուսաստղ» ՀԿ-ի նախագահ (համաձայնությամբ)
Ս. Մաղաքյան | - «Լիարժեք կյանք» ՀԿ-ի նախագահ (համաձայնությամբ)
Շ. Վարագյան | - «Հայաստանի խուլերի միություն» ՀԿ-ի նախագահ (համաձայնությամբ)
Ա. Հակոբյան | - «Հայաստանի կույրերի միություն» ՀԿ-ի նախագահ (համաձայնությամբ)
Հ. Շարբաթյան | - «Հաշմանդամների հայկական ասոցիացիա» ՀԿ-ի նախագահ (համաձայնությամբ)
Հ. Կիրակոսյան | - «Առաքելություն Հայաստան» բարեգործական ՀԿ-ի նախագահ (համաձայնությամբ)
Խ. Մկրտչյան | - «Երկրապահ կամավորական միություն» ՀԿ-ի վարչության փոխնախագահ (համաձայնությամբ)
Գ. Հովհաննիսյան | - «Հայաստանի ազգային պարալիմպիկ կոմիտե» ՀԿ-ի փոխնախագահ (համաձայնությամբ)
