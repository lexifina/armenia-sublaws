# Հավելված N 2 ՀՀ վարչապետի N 986-Ն որոշման
Կ Ա Ր Գ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՊԵՏԱԿԱՆ ՊԱՀՊԱՆՈՒԹՅԱՆ ԾԱՌԱՅՈՒԹՅԱՆ ԾԱՌԱՅՈՂՆԵՐԻՆ ԱՏԵՍՏԱՎՈՐՄԱՆ ԱՐԴՅՈՒՆՔՆԵՐՈՎ ՀԱՇՎԱՐԿՎՈՂ ՀԱՎԵԼԱՎՃԱՐԻ ՀԱՇՎԱՐԿՄԱՆ
1. Սույնով կարգավորվում են Հայաստանի Հանրապետության պետական պահպանության ծառայության (այսուհետ՝ ծառայություն) ծառայողներին ատեստավորման արդյունքներով հաշվարկվող հավելավճարի հաշվարկման հետ կապված հարաբերությունները (այսուհետ՝ կարգ):
2. «Հատուկ պետական պաշտպանության ենթակա անձանց անվտանգության ապահովման մասին» օրենքի 17.1-ին հոդվածի 10-րդ մասի 1-ին և 2-րդ կետերով նախատեսված եզրակացություններից որևէ մեկը կայացվելու դեպքում ծառայության մարդկային ռեսուրսների կառավարման ստորաբաժանումը՝ ատեստավորման արձանագրությունը և գրավոր եզրակացություններն ստանալուց հետո 3 աշխատանքային օրվա ընթացքում, գրությամբ ծառայության ֆինանսական գործունեության համար պատասխանատու ստորաբաժանում է ուղարկում դրանց պատճենները:
3. Սույն կարգի 2-րդ կետով նախատեսված փաստաթղթերն ստանալու հիման վրա ֆինանսական գործունեության համար պատասխանատու ստորաբաժանումն ապահովում է կամավոր ատեստավորում անցած զինծառայողի համապատասխան չափով հավելավճարի հաշվարկման և վճարման գործընթացը:
4. Հավելավճարը հաշվարկվում է այդ իրավունքը ձեռք բերելու օրվանից և վճարվում է «Հատուկ պետական պաշտպանության ենթակա անձանց անվտանգության ապահովման մասին» օրենքի 17.1-ին հոդվածի 10-րդ մասի 1-ին և 2-րդ կետերով նախատեսված եզրակացություններից որևէ մեկը կայացվելու օրվան հաջորդող ամսվա 1-ից՝ աշխատավարձի (դրամական ապահովության) վճարման հետ միաժամանակ:
5. Ատեստավորման արդյունքներով ատեստավորման հանձնաժողովի կողմից «Հատուկ պետական պաշտպանության ենթակա անձանց անվտանգության ապահովման մասին» օրենքի 17.1-ին հոդվածի 10-րդ մասի 3-րդ կետով նախատեսված եզրակացությունը կայացվելու դեպքում՝ ծառայության ծառայողների պաշտոն զբաղեցնող, հավելավճար հաշվարկելու նպատակով ատեստավորված և սահմանված չափով հավելավճար ստացող զինծառայողների համար հաշվարկված հավելավճարի հաշվարկումը և վճարումը դադարում է վճարման երկու տարի ժամկետը լրանալու պահից:
6. Զինծառայողներին վճարվող աշխատավարձի մեջ Հայաստանի Հանրապետության կառավարության որոշմամբ սահմանված չափերով հավելավճարի հաշվարկման դեպքում Հայաստանի Հանրապետության կառավարության 2014 թվականի հուլիսի 3-ի N 710-Ն որոշմամբ սահմանված լրավճարները և Հայաստանի Հանրապետության կառավարության 2014 թվականի հուլիսի 3-ի N 712-Ն որոշմամբ սահմանված հավելումները չեն հաշվարկվում:
Հայաստանի Հանրապետության վարչապետի աշխատակազմի ղեկավար | Ա. Հարությունյան
