# Հավելված N 2 ՀՀ վարչապետի N 986-Ն որոշման
Կ Ա Ր Գ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՊԵՏԱԿԱՆ ՊԱՀՊԱՆՈՒԹՅԱՆ ԾԱՌԱՅՈՒԹՅԱՆ ԾԱՌԱՅՈՂՆԵՐԻՆ ԱՏԵՍՏԱՎՈՐՄԱՆ ԱՐԴՅՈՒՆՔՆԵՐՈՎ ՀԱՇՎԱՐԿՎՈՂ ՀԱՎԵԼԱՎՃԱՐԻ ՀԱՇՎԱՐԿՄԱՆ
1. Սույնով կարգավորվում են Հայաստանի Հանրապետության պետական պահպանության ծառայության (այսուհետ՝ ծառայություն) ծառայողներին ատեստավորման արդյունքներով հաշվարկվող հավելավճարի հաշվարկման հետ կապված հարաբերությունները (այսուհետ՝ կարգ):
2. «Հատուկ պետական պաշտպանության ենթակա անձանց անվտանգության ապահովման մասին» օրենքի 17.1-ին հոդվածի 13-րդ մասի 1-ին կետով նախատեսված եզրակացությունը կայացվելու դեպքում ծառայության մարդկային ռեսուրսների կառավարման ստորաբաժանումը՝ ատեստավորման արձանագրությունը և գրավոր եզրակացություններն ստանալուց հետո 3 աշխատանքային օրվա ընթացքում, գրությամբ ծառայության ֆինանսական գործունեության համար պատասխանատու ստորաբաժանում է ուղարկում դրանց պատճենները:
(2-րդ կետը փոփ. 09.04.25 N 286-Ն)
3. Սույն կարգի 2-րդ կետով նախատեսված փաստաթղթերն ստանալու հիման վրա ֆինանսական գործունեության համար պատասխանատու ստորաբաժանումն ապահովում է կամավոր ատեստավորում անցած զինծառայողի համապատասխան չափով հավելավճարի հաշվարկման և վճարման գործընթացը:
4. Հավելավճարը հաշվարկվում և վճարվում է «Հատուկ պետական պաշտպանության ենթակա անձանց անվտանգության ապահովման մասին» օրենքի 17.1-ին հոդվածի 13-րդ մասի 1-ին կետով նախատեսված եզրակացությունը կայացվելու օրվան հաջորդող ամսվա 1-ից՝ աշխատավարձի (դրամական ապահովության) վճարման հետ միաժամանակ:
(4-րդ կետը խմբ. 09.04.25 N 286-Ն)
5. Ատեստավորման արդյունքներով ատեստավորման հանձնաժողովի կողմից «Հատուկ պետական պաշտպանության ենթակա անձանց անվտանգության ապահովման մասին» օրենքի 17.1-ին հոդվածի 13-րդ մասի 2-րդ կետով նախատեսված եզրակացությունը կայացվելու դեպքում՝ ծառայության ծառայողների պաշտոն զբաղեցնող, հավելավճար հաշվարկելու նպատակով ատեստավորված և սահմանված չափով հավելավճար ստացող զինծառայողների համար հաշվարկված հավելավճարի հաշվարկումը և վճարումը դադարում է վճարման երկու տարի ժամկետը լրանալու պահից:
(5-րդ կետը փոփ. 09.04.25 N 286-Ն)
5.1. Եթե ատեստավորման արդյունքներով կայացվել է «ենթակա է հավելավճար հաշվարկելու» եզրակացությունը, որից հետո ծառայողին տրամադրվել է հղիության և ծննդաբերության կամ մինչև երեք տարեկան երեխայի խնամքի արձակուրդ, կամ ծառայողը թողնվել է կադրերի տրամադրության տակ, կամ կասեցվել է նրա պաշտոնավարումը, ապա հավելավճարի հաշվարկման ժամկետն այդ ժամանակահատվածում կասեցվում է: Այն վերսկսվում է սույն կետում նշված հանգամանքները վերանալու օրվանից:
(5.1-ին կետը լրաց. 09.04.25 N 286-Ն)
6. Զինծառայողներին վճարվող աշխատավարձի մեջ Հայաստանի Հանրապետության կառավարության որոշմամբ սահմանված չափերով հավելավճարի հաշվարկման դեպքում Հայաստանի Հանրապետության կառավարության 2014 թվականի հուլիսի 3-ի N 710-Ն որոշմամբ սահմանված լրավճարները և Հայաստանի Հանրապետության կառավարության 2014 թվականի հուլիսի 3-ի N 712-Ն որոշմամբ սահմանված հավելումները չեն հաշվարկվում:
(հավելվածը փոփ., խմբ., լրաց. 09.04.25 N 286-Ն)
