# Հավելված ՀՀ վարչապետի 2010 թ. փետրվարի 4-ի N 58-Ն որոշման

ԿԵՆՍԱԹՈՇԱԿԱՅԻՆ ԲԱՐԵՓՈԽՈՒՄՆԵՐԻ ԿԱՌԱՎԱՐՄԱՆ ԽՈՐՀՐԴԻ
Ա. Ասատրյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարար (խորհրդի նախագահ)
Ա. Օրբելյան | - | ՀՀ արդարադատության նախարարի տեղակալ
Վ. Արամյան | - | ՀՀ ֆինանսների նախարարի տեղակալ
Կ. Մինասյան | - | ՀՀ էկոնոմիկայի նախարարի առաջին տեղակալ
Վ. Միրումյան | - | ՀՀ կառավարությանն առընթեր պետական եկամուտների կոմիտեի նախագահի տեղակալ
Ա. Անանյան | - | ՀՀ վարչապետի օգնական, կենսաթոշակային բարեփոխումների հանրային իրազեկման ծրագիրն իրականացնող աշխատանքային խմբի ղեկավար
Ա. Օսիկյան | ՀՀ կառավարությանն առընթեր ՀՀ ոստիկանության պետի տեղակալ
Ա. Միրզախանյան | - | ՀՀ կառավարության աշխատակազմի սոցիալական հարցերի վարչության պետ
Վ. Աբրահամյան | - | ՀՀ կենտրոնական բանկի խորհրդի անդամ (համաձայնությամբ)
Տ. Պետրոսյան | - | Հայաստանի կենտրոնական դեպոզիտարիայի կենսաթոշակային համակարգի սպասարկման բաժնի պետ (համաձայնությամբ)
Ս. Սաիյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության սոցիալական ապահովության պետական ծառայության պետի առաջին տեղակալ (խորհրդի քարտուղար)
(հավելվածը լրաց. 19.02.10 N 109-Ն, փոփ. 23.07.10 N 587-Ն, 02.12.11 N 1164-Ն, փոփ., լրաց. 16.04.12 N 349-Ն, փոփ. 20.10.12 N 1041-Ն)
