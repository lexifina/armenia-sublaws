Ա. Ասատրյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի տեղակալ (խորհրդի նախագահ)
Գ. Մալխասյան | - | ՀՀ արդարադատության նախարարի առաջին տեղակալ
Վ. Արամյան | - | ՀՀ ֆինանսների նախարարի տեղակալ
Մ. Թումասյան | - | ՀՀ էկոնոմիկայի նախարարի տեղակալ
Կ. Մինասյան | - | ՀՀ կառավարությանն առընթեր պետական եկամուտների կոմիտեի նախագահի առաջին տեղակալ
Ա. Անանյան | - | ՀՀ վարչապետի օգնական, կենսաթոշակային բարեփոխումների հանրային իրազեկման ծրագիրն իրականացնող աշխատանքային խմբի ղեկավար
Տ. Հարությունյան | - | ՀՀ կառավարության աշխատակազմի սոցիալական հարցերի վարչության գլխավոր մասնագետ
Ա. Չիլինգարյան | - | ՀՀ կենտրոնական բանկի խորհրդի անդամ (համաձայնությամբ)
Հ. Ոսկանյան | - | Հայաստանի կենտրոնական դեպոզիտարիայի կենսաթոշակային համակարգի սպասարկման բաժնի պետ (համաձայնությամբ)
Ս. Սաիյան | - | ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի սոցիալական ապահովագրության և կենսաթոշակային ապահովության վարչության պետ (խորհրդի քարտուղար)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար | Դ. Սարգսյան
