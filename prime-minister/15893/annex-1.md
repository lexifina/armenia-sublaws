# Հավելված N 1 ՀՀ վարչապետի 2004 թ. փետրվարի 12-ի N 63-Ն որոշման
Կ Ա Զ Մ
ԱՆԴՐՍԱՀՄԱՆԱՅԻՆ ՋՐԱՅԻՆ ՀԱՄԱԿԱՐԳԻ ՕԳՏԱԳՈՐԾՄԱՆ ՀԱՄԱՏԵՂ ՄՇՏԱԿԱՆ ԳՈՐԾՈՂ ՄԻՋՊԵՏԱԿԱՆ ՀԱՆՁՆԱԺՈՂՈՎՆԵՐԻ ՀԱՅԿԱԿԱՆ ԿՈՂՄԻ` ԸՍՏ ՇԱՀԱԳՈՐԾՎՈՂ ՀԱՄԱԿԱՐԳԻ
I. Ախուրյանի ջրամբարի շահագործման համար
Է. Սարգսյան | - «Ախուրյան-Արաքս-ջրառ» ՓԲԸ-ի տնօրեն (հայկական կողմի նախագահ)
Ե. Կարապետյան | - «Ախուրյան-Արաքս-ջրառ» ՓԲԸ-ի տնօրենի տեղակալ` միջպետական ջրաչափության գծով
Ս. Խաչատրյան | - «Ախուրյան-Արաքս-ջրառ» ՓԲԸ-ի միջպետական խմբի պետ
Հ. Սարգսյան | - Ախուրյանի ջրամբարի պետ
Ռ. Գրիգորյան | - ՀՀ «Հայպետհիդրոմետ» ՊՈԱԿ-ի ՀՌՈՒԿ-ի պետական ջրային կադաստրի և հաշվեկշռի բաժնի պետ
Ս. Սահակյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության Ախուրյանի ջրավազանային կառավարման բաժնի պետ
Է. Ոսկանյան | - թարգմանիչ
II. Հոկտեմբերյանի (Սարդարապատի) կարգավորիչի շահագործման համար
Է. Սարգսյան | - «Ախուրյան-Արաքս-ջրառ» ՓԲԸ-ի տնօրեն (հայկական կողմի նախագահ)
Ե. Կարապետյան | - «Ախուրյան-Արաքս-ջրառ» ՓԲԸ-ի տնօրենի տեղակալ` միջպետական ջրաչափության գծով
Ս. Խաչատրյան | - «Ախուրյան-Արաքս-ջրառ» ՓԲԸ-ի միջպետական խմբի պետ
Վ. Ավետյան | - «Ախուրյան-Արաքս-ջրառ» ՓԲԸ-ի Արմավիրի ջրանցքի գլխամասային հիդրոհանգույցի պետ
Ռ. Գրիգորյան | - ՀՀ «Հայպետհիդրոմետ» ՊՈԱԿ-ի ՀՌՈՒԿ-ի պետական ջրային կադաստրի և հաշվեկշռի բաժնի պետ
Լ. Գուրգենյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության ջրավազանային պլանավորման կառավարման բաժնի առաջատար մասնագետ
Է. Ոսկանյան | - թարգմանիչ
(հավելվածը խմբ. 28.09.06 N 714-Ն, փոփ. 18.12.06 N 1002-Ն, խմբ. 25.08.11 N 803-Ն)
