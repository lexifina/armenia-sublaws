# Հավելված N 2 ՀՀ վարչապետի 2004 թ. փետրվարի 12-ի N 63-Ն որոշման
Կ Ա Զ Մ
ԱԽՈՒՐՅԱՆԻ ՋՐԱՄԲԱՐԻ ՇԱՀԱԳՈՐԾՄԱՆ ԵՎ ՀՈԿՏԵՄԲԵՐՅԱՆԻ (ՍԱՐԴԱՐԱՊԱՏԻ) ՇԱՀԱԳՈՐԾՄԱՆ ՄՇՏԱԿԱՆ ԳՈՐԾՈՂ ՄԻՋՊԵՏԱԿԱՆ ՀԱՆՁՆԱԺՈՂՈՎՆԵՐԻ ԳՈՐԾՈՒՆԵՈՒԹՅԱՆՆ ՕԺԱՆԴԱԿՈՂ ՓՈՐՁԱԳԵՏՆԵՐԻ
Ռ. Ավետիսյան | - ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի աշխատակազմի վերահսկողության վարչության պետ
Ա. Զակեոսյան | - ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի աշխատակազմի ֆինանսատնտեսագիտական, հաշվառման և իրացման համակարգման վարչության խմելու և ոռոգման ջրերի իրացման, բաժանորդային և էլեկտրաէներգիայի հաշվառման համակարգման բաժնի պետ
Է. Բադալյան | - ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի աշխատակազմի ջրատնտեսական ենթակառուցվածքների գործունեությունը համակարգող վարչության ոռոգման համակարգերի բաժնի պետ
Գ. Մուրադյան | - ՀՀ բնապահպանության նախարարության ջրային ռեսուրսների կառավարման գործակալության ջրօգտագործման թույլտվությունների և պայմանագրերի բաժնի պետ
Վ. Պետրոսյան | - «Ոռոգում-ջրառ» ՓԲԸ-ի գլխավոր տնօրենի տեղակալ` շահագործման գծով
Մ. Տոնոյան | - «Ջրային տնտեսության զարգացման և բարեփոխումների ԾԻԳ» պետական հիմնարկի շինարարության վերահսկման ճարտարագետ
Գ. Գևորգյան | - «Հայջրնախագիծ» ինստիտուտ» ՓԲԸ-ի գլխամասային ջրհավաք հանգույցի նախագծի գլխավոր ճարտարագետ
Զ. Զազյան | - «Հայջրնախագիծ» ինստիտուտ» ՓԲԸ-ի Արմավիրի մայր ջրանցքի նախագծի գլխավոր ճարտարագետ
Ռ. Անդրեասյան | - «Ոռոգում-ջրառ» ՓԲԸ-ի ջրամբարների բաժնի պետ
Գ. Հակոբյան | - «Ոռոգում-ջրառ» ՓԲԸ-ի ոռոգման ջրի բաշխման, օգտագործման, հաշվառման և ջրաչափության բաժնի պետ
Հ. Հարությունյան | - ՀՀ բնապահպանության նախարարության ջրային ռեսուրսների կառավարման գործակալության ջրավազանային հսկողության բաժնի գլխավոր մասնագետ
Ն. Բակունց | - ՀՀ առողջապահության նախարարության պետական հիգիենիկ և հակահամաճարակային տեսչության գլխավոր մասնագետ
