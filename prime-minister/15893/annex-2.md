# Հավելված N 2 ՀՀ վարչապետի 2004 թ. փետրվարի 12-ի N 63-Ն որոշման
Կ Ա Զ Մ
ԱԽՈՒՐՅԱՆԻ ՋՐԱՄԲԱՐԻ ՇԱՀԱԳՈՐԾՄԱՆ ԵՎ ՀՈԿՏԵՄԲԵՐՅԱՆԻ (ՍԱՐԴԱՐԱՊԱՏԻ) ՇԱՀԱԳՈՐԾՄԱՆ ՄՇՏԱԿԱՆ ԳՈՐԾՈՂ ՄԻՋՊԵՏԱԿԱՆ ՀԱՆՁՆԱԺՈՂՈՎՆԵՐԻ ԳՈՐԾՈՒՆԵՈՒԹՅԱՆՆ ՕԺԱՆԴԱԿՈՂ ՓՈՐՁԱԳԵՏՆԵՐԻ
Մ. Սահակյան | - ՀՀ տարածքային կառավարման նախարարության ջրային տնտեսության պետական կոմիտեի աշխատակազմի տեսչական վերահսկողության վարչության պետ-գլխավոր պետական տեսուչի տեղակալ
Յու. Պեպանյան | - ՀՀ տարածքային կառավարման նախարարության ջրային տնտեսության պետական կոմիտեի աշխատակազմի ջրատնտեսական ենթակառուցվածքների գործունեությունը համակարգող վարչության պետի տեղակալ - ոռոգման և կոլեկտորադրենաժային համակարգերի բաժնի պետ
Ա. Զակեոսյան | - ՀՀ տարածքային կառավարման նախարարության ջրային տնտեսության պետական կոմիտեի աշխատակազմի ֆինանսատնտեսագիտական, հաշվառման և իրացման համակարգման վարչության խմելու և ոռոգման ջրերի իրացման, բաժանորդային էլեկտրաէներգիայի հաշվառման համակարգման բաժնի պետ
Գ. Մուրադյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության ջրօգտագործման թույլտվությունների բաժնի պետ
Մ. Տոնոյան | - «Ջրային տնտեսության զարգացման և բարեփոխումների ԾԻԳ» պետական հիմնարկի շինարարության վերահսկման ճարտարագետ
Գ. Գևորգյան | - «Հայջրնախագիծ» ինստիտուտ» ՓԲԸ-ի գլխամասային ջրհավաք հանգույցի նախագծի գլխավոր ճարտարագետ
Զ. Զազյան | - «Հայջրնախագիծ» ինստիտուտ» ՓԲԸ-ի Արմավիրի մայր ջրանցքի նախագծի գլխավոր ճարտարագետ
Հ. Հարությունյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության ջրավազանային պլանավորման կառավարման բաժնի պետի տեղակալ
Ն. Բակունց | - ՀՀ առողջապահության նախարարության պետական հիգիենիկ և հակահամաճարակային տեսչության իրավական ապահովման և փաստաթղթային հոսքերի կառավարման բաժնի պետ
(Հավելվածը խմբ. 28.09.06 N 714-Ն)
