# Հավելված N 2 ՀՀ վարչապետի 2004 թ. փետրվարի 12-ի N 63-Ն որոշման
Կ Ա Զ Մ
ԱԽՈՒՐՅԱՆԻ ՋՐԱՄԲԱՐԻ ԵՎ ՀՈԿՏԵՄԲԵՐՅԱՆԻ (ՍԱՐԴԱՐԱՊԱՏԻ) ԿԱՐԳԱՎՈՐԻՉԻ ՇԱՀԱԳՈՐԾՄԱՆ ՄՇՏԱԿԱՆ ԳՈՐԾՈՂ ՄԻՋՊԵՏԱԿԱՆ ՀԱՆՁՆԱԺՈՂՈՎՆԵՐԻ ԳՈՐԾՈՒՆԵՈՒԹՅԱՆՆ ՕԺԱՆԴԱԿՈՂ ՓՈՐՁԱԳԵՏՆԵՐԻ
Մ. Մկրտումյան | - ՀՀ տարածքային կառավարման նախարարության ջրային տնտեսության պետական կոմիտեի աշխատակազմի ֆինանսատնտեսագիտական վարչության պետ - գլխավոր պետական տեսուչի տեղակալ
Կ. Դաղբաշյան | - ՀՀ տարածքային կառավարման նախարարության ջրային տնտեսության պետական կոմիտեի աշխատակազմի ոռոգման և կոլեկտորադրենաժային համակարգերի վարչության պետ
Ս. Հովհաննիսյան | - «Սևան-Հրազդանյան-ջրառ» ՓԲԸ-ի տնօրեն
Վ. Սարգսյան | - «Ախուրյան-Արաքս-ջրառ» ՓԲԸ-ի ջրաչափության մասնագետ
Վ. Մակարյան | - «Ախուրյան-Արաքս-ջրառ» ՓԲԸ-ի ջրաչափության մասնագետ
Գ. Մուրադյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության ջրօգտագործման թույլտվությունների բաժնի պետ
Մ. Տոնոյան | - «Ջրային տնտեսության ծրագրերի իրականացման գրասենյակ» պետական հիմնարկի շինարարության վերահսկման ճարտարագետ
Ջ. Զազյան | - «Հայջրնախագիծ ինստիտուտ» ՓԲԸ-ի Արմավիրի մայր ջրանցքի նախագծի գլխավոր ճարտարագետ
Հ. Հարությունյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության ջրավազանային պլանավորման կառավարման բաժնի պետի տեղակալ
Ն. Բակունց | - ՀՀ առողջապահության նախարարության պետական հիգիենիկ և հակահամաճարակային տեսչության իրավական ապահովման և փաստաթղթային հոսքերի կառավարման բաժնի պետ
Դ. Հովհաննիսյան | - թարգմանիչ
(հավելվածը խմբ. 28.09.06 N 714-Ն, 25.08.11 N 803-Ն)
