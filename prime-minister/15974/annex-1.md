# Հավելված N 1 ՀՀ վարչապետի 2005 թ. հունվարի 25-ի N 43-Ն որոշման
Կ Ա Զ Մ
ԱՂՔԱՏՈՒԹՅԱՆ ՀԱՂԹԱՀԱՐՄԱՆ ՌԱԶՄԱՎԱՐԱԿԱՆ ԾՐԱԳՐԻ ԻՐԱԿԱՆԱՑՄԱՆ ԱՇԽԱՏԱՆՔՆԵՐԻ ՀԱՄԱԿԱՐԳՄԱՆ ԽՈՐՀՐԴԻ
Ա. Մարգարյան | - ՀՀ վարչապետ (խորհրդի նախագահ)
Վ. Խաչատրյան | - ՀՀ ֆինանսների և էկոնոմիկայի նախարար (խորհրդի նախագահի տեղակալ)
Ա. Վարդանյան | - ՀՀ աշխատանքի և սոցիալական հարցերի նախարար
Գ. Մխեյան | - ՀՀ Ազգային ժողովի սոցիալական, առողջապահության և բնության պահպանման հարցերի մշտական հանձնաժողովի նախագահ (համաձայնությամբ)
Ա. Մկրտչյան | - ՀՀ Ազգային ժողովի գիտության, կրթության, մշակույթի և երիտասարդության հարցերի մշտական հանձնաժողովի անդամ (համաձայնությամբ)
Յու. Շուքուրյան | - ՀՀ գիտությունների ազգային ակադեմիայի փոխպրեզիդենտ (համաձայնությամբ)
Ա. Ղազարյան | - Հայաստանի արդյունաբերողների և գործարարների (գործատուների) միության նախագահ (համաձայնությամբ)
Մ. Հարությունյան | - Հայաստանի արհեստակցական միությունների կոնֆեդերացիայի նախագահ (համաձայնությամբ)
Ս. Դարբինյան | - Վանաձորի քաղաքապետ, Հայաստանի համայնքների հանրապետական ասոցիացիայի վարչության անդամ (համաձայնությամբ)
Վ. Սողոմոնյան | - Գյուղի հարցերի հասարակական կազմակերպությունների խմբի ներկայացուցիչ, Ֆերմերների ազգային միության նախագահ (համաձայնությամբ)
Լ. Ներսիսյան | - Հատուկ կարիքներով խմբերի պաշտպանության հարցերի հասարակական կազմակերպությունների խմբի ներկայացուցիչ, «Աստղիկ» հաշմանդամ երեխաների ծնողների միություն» հասարակական կազմակերպության նախագահ (համաձայնությամբ)
Մ. Ղազարյան | - Մարդու իրավունքների հարցերի հասարակական կազմակերպությունների խմբի ներկայացուցիչ, Հայաստանի երիտասարդական ազգային խորհրդի փոխնախագահ (համաձայնությամբ)
Հ. Ջավադյան | - Փոքր և միջին գործարարության հարցերի հասարակական կազմակերպությունների խմբի ներկայացուցիչ, Կիրառական հետազոտությունների և ագրոբիզնեսի հիմնադրամի տնօրեն (համաձայնությամբ)
Կ. Դանիելյան | - Բնապահպանական հարցերի հասարակական կազմակերպությունների խմբի ներկայացուցիչ, «Հանուն կայուն մարդկային զարգացման ասոցիացիա» հասարակական կազմակերպության նախագահ (համաձայնությամբ)
Հայր Թորգոմ աբեղա Տոնիկյան | - Հայ առաքելական եկեղեցու ներկայացուցիչ (համաձայնությամբ)
(Հավելվածը խմբ. 11.06.05 N 426-Ն, փոփ. 03.05.06 N 295-Ն)
