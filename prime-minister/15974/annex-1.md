# Հավելված N 1 ՀՀ վարչապետի 2005 թ. հունվարի 25-ի N 43-Ն որոշման
Կ Ա Զ Մ
ԱՂՔԱՏՈՒԹՅԱՆ ՀԱՂԹԱՀԱՐՄԱՆ ՌԱԶՄԱՎԱՐԱԿԱՆ ԾՐԱԳՐԻ ԻՐԱԿԱՆԱՑՄԱՆ ԱՇԽԱՏԱՆՔՆԵՐԻ ՀԱՄԱԿԱՐԳՄԱՆ ԽՈՐՀՐԴԻ
Խորհրդի նախագահ | - ՀՀ վարչապետ
Խորհրդի նախագահի տեղակալ | - ՀՀ ֆինանսների և էկոնոմիկայի նախարար
Խորհրդի անդամներ | - ՀՀ աշխատանքի և սոցիալական հարցերի նախարար
- ՀՀ Ազգային ժողովի երկու ներկայացուցիչ (համաձայնությամբ)
- ՀՀ գիտությունների ազգային ակադեմիայի նախագահի տեղակալ (համաձայնությամբ)
- Հայաստանի արդյունաբերողների և գործարարների (գործատուների) միության նախագահ (համաձայնությամբ)
- Հայաստանի արհեստակցական միությունների կոնֆեդերացիայի նախագահ (համաձայնությամբ)
- Վանաձորի քաղաքապետ, Հայաստանի համայնքների հանրապետական ասոցիացիայի վարչության անդամ (համաձայնությամբ)
- Գյուղի հարցերի հասարակական կազմակերպությունների խմբի ներկայացուցիչ, Ֆերմերների ազգային միության նախագահ (համաձայնությամբ)
- Հատուկ կարիքներով խմբերի պաշտպանության հարցերի հասարակական կազմակերպությունների խմբի ներկայացուցիչ, «Աստղիկ» հաշմանդամ երեխաների ծնողների միություն» հասարակական կազմակերպության նախագահ (համաձայնությամբ)
- Մարդու իրավունքների հարցերի հասարակական կազմակերպությունների խմբի ներկայացուցիչ, Հայաստանի երիտասարդական ազգային խորհրդի փոխնախագահ (համաձայնությամբ)
- Փոքր և միջին գործարարության հարցերի հասարակական կազմակերպությունների խմբի ներկայացուցիչ, Կիրառական հետազոտությունների և ագրոբիզնեսի հիմնադրամի տնօրեն (համաձայնությամբ)
- Բնապահպանական հարցերի հասարակական կազմակերպությունների խմբի ներկայացուցիչ, «Հանուն կայուն մարդկային զարգացման ասոցիացիա» հասարակական կազմակերպության նախագահ (համաձայնությամբ)
- Հայ Առաքելական եկեղեցու ներկայացուցիչ (համաձայնությամբ):
(Հավելվածը խմբ. 11.06.05 N 426-Ն, փոփ. 03.05.06 N 295-Ն, խմբ. 28.12.07 N 915-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
