# Հավելված N 2 ՀՀ վարչապետի 2009 թ. հունիսի 23-ի N 507-Ն որոշման
Ա Ն Հ Ա Տ Ա Կ Ա Ն Կ Ա Զ Մ
«ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԵՎ ՀԱՄԱՇԽԱՐՀԱՅԻՆ ԲԱՆԿԻ ՄԻՋԵՎ ՍՏՈՐԱԳՐՎԱԾ «ՔԱՂԱՔԱԿԱՆՈՒԹՅԱՆ ԵՎ ՄԱՐԴԿԱՅԻՆ ՌԵՍՈՒՐՍՆԵՐԻ ԶԱՐԳԱՑՄԱՆ (PHRD) ԴՐԱՄԱՇՆՈՐՀ ՏԵԽՆՈԼՈԳԻԱՅԻ ՄՐՑՈՒՆԱԿՈՒԹՅԱՆ ԲԱՐՁՐԱՑՄԱՆ ԾՐԱԳՐԻ ՆԱԽԱՊԱՏՐԱՍՏՄԱՆ ՀԱՄԱՐ» TF 093097 ԴՐԱՄԱՇՆՈՐՀԱՅԻՆ ԾՐԱԳՐԻ ԿԱՌԱՎԱՐՄԱՆ ԽՈՐՀՐԴԻ
Տ. Դավթյան | - ՀՀ էկոնոմիկայի նախարար (խորհրդի նախագահ)
Վ. Դանիելյան | - ՀՀ էկոնոմիկայի նախարարի տեղակալ
Վ. Արամյան | - ՀՀ ֆինանսների նախարարի տեղակալ
Վ. Մարության | - ՀՀ տրանսպորտի և կապի նախարարի տեղակալ
Ս. Արաբաջյան | - ՀՀ հանրային ծառայությունները կարգավորող հանձնաժողովի անդամ
Լ. Հունանյան | - ՀՀ կառավարության աշխատակազմի ֆինանսատնտեսագիտական վարչության պետի տեղակալ
Բ. Փափազյան | - Հայաստանի ազգային մրցունակության հիմնադրամի գործադիր տնօրեն (համաձայնությամբ)
Բ. Ենգիբարյան | - Ձեռնարկությունների ինկուբատոր հիմնադրամի տնօրեն (համաձայնությամբ)
Է. Ավետյան | - ՀՀ ֆինանսների նախարարության «Արտասահմանյան ֆինանսական ծրագրերի կառավարման կենտրոն» պետական հիմնարկի գործադիր տնօրեն (համաձայնությամբ)
(հավելվածը փոփ. 29.12.09 N 1084-Ն, 14.04.10 N 246-Ն, 10.01.11 N 2-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար | Դ. Սարգսյան
