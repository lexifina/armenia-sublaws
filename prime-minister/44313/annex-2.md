# Հավելված N 2 ՀՀ վարչապետի 2008 թ. հունիսի 3-ի N 306-Ն որոշման
Կ Ա Զ Մ Ե Ր
ՆԱԽԱՐԱՐԱԿԱՆ ԿՈՄԻՏԵՆԵՐԻ
1. Ֆինանսատնտեսական կոմիտե`
ՀՀ ֆինանսների նախարար
ՀՀ էկոնոմիկայի նախարար
ՀՀ էներգետիկայի և բնական պաշարների նախարար
ՀՀ գյուղատնտեսության նախարար
ՀՀ տրանսպորտի և կապի նախարար
ՀՀ արդարադատության նախարար
ՀՀ կառավարությանն առընթեր պետական եկամուտների կոմիտեի նախագահ
ՀՀ կառավարության աշխատակազմի ղեկավար
2. Սոցիալական կոմիտե`
ՀՀ աշխատանքի և սոցիալական հարցերի նախարար
ՀՀ առողջապահության նախարար
ՀՀ կրթության և գիտության նախարար
ՀՀ մշակույթի նախարար
ՀՀ սպորտի և երիտասարդության հարցերի նախարար
ՀՀ ֆինանսների նախարար
ՀՀ արդարադատության նախարար
ՀՀ կառավարության աշխատակազմի ղեկավար
3. Տարածքային զարգացման և բնապահպանական կոմիտե`
ՀՀ տարածքային կառավարման նախարար
ՀՀ բնապահպանության նախարար
ՀՀ քաղաքաշինության նախարար
ՀՀ էներգետիկայի և բնական պաշարների նախարար
ՀՀ ֆինանսների նախարար
ՀՀ արդարադատության նախարար
ՀՀ կառավարության աշխատակազմի ղեկավար
ՀՀ կառավարությանն առընթեր անշարժ գույքի կադաստրի պետական կոմիտեի նախագահ
ՀՀ գյուղատնտեսության նախարար
Հայաստանի Հանրապետության կառավարությանն առընթեր ճարտարապետության պետական կոմիտեի նախագահ
4. Պետաիրավական կոմիտե`
ՀՀ պաշտպանության նախարար
ՀՀ արտակարգ իրավիճակների նախարար
ՀՀ ոստիկանության պետ
ՀՀ կառավարությանն առընթեր ազգային անվտանգության տնօրեն
ՀՀ ֆինանսների նախարար
ՀՀ արդարադատության նախարար
ՀՀ կառավարության աշխատակազմի ղեկավար
(հավելվածը փոփ. 14.10.11 N 976-Ն, լրաց. 05.03.13 N 177-Ն, 13.02.14 N 104-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար | Դ. Սարգսյան
