# Հավելված N 2 ՀՀ վարչապետի 2004 թվականի դեկտեմբերի 9-ի N 819-Ն որոշման

ԵՐԵՎԱՆԻ «ՋՐՄՈՒՂ-ԿՈՅՈՒՂԻ» ՓԱԿ ԲԱԺՆԵՏԻՐԱԿԱՆ ԸՆԿԵՐՈՒԹՅԱՆ ԿՈՂՄԻՑ ՕԳՏԱԳՈՐԾՎՈՂ ՋՐԱՅԻՆ ՀԱՄԱԿԱՐԳԵՐԻ ՕԳՏԱԳՈՐԾՄԱՆ ԻՐԱՎՈՒՆՔԸ ՄՐՑՈՒՅԹՈՎ` ՎԱՐՁԱԿԱԼՈՒԹՅԱՄԲ ՓՈԽԱՆՑՄԱՆ ԳՈՐԾԸՆԹԱՑԸ ԿԱԶՄԱԿԵՐՊՈՂ ՄԻՋԳԵՐԱՏԵՍՉԱԿԱՆ ՀԱՆՁՆԱԺՈՂՈՎԻ
Հ. Աբրահամյան | - ՀՀ տարածքային կառավարման և ենթակառուցվածքների գործունեությունը համակարգող նախարար (հանձնաժողովի նախագահ)
Ա. Անդրեասյան | - ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի նախագահ (հանձնաժողովի նախագահի տեղակալ)
Գ. Մարտիրոսյան | - ՀՀ վարչապետի խորհրդական
Գ. Մալխասյան | - ՀՀ արդարադատության նախարարի առաջին տեղակալ
Մ. Միքայելյան | - ՀՀ ֆինանսների և էկոնոմիկայի նախարարի տեղակալ
Ն. Գրիգորյան | - ՀՀ հանրային ծառայությունները կարգավորող հանձնաժողովի նախագահի տեղակալ (համաձայնությամբ)
Վ. Վարդանյան | - Երևանի քաղաքապետի տեղակալ
Ա. Մարկոսյան | - ՀՀ կառավարությանն առընթեր պետական գույքի կառավարման վարչության պետի տեղակալ
Ա. Ներսիսյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի ջրային ռեսուրսների կառավարման գործակալության պետ
Վ. Ավոյան | - «Համայնքային զարգացման ծրագրի ղեկավարման գրասենյակ» պետական հիմնարկի տնօրեն (հանձնաժողովի քարտուղար)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
