# Հավելված N 2 ՀՀ վարչապետի 2005 թ. հոկտեմբերի 28-ի N 835-Ն որոշման

Գ. Պետրոսյան | - ՀՀ աշխատանքի և սոցիալական հարցերի նախարար (հանձնաժողովի նախագահ)
Գ. Մալխասյան | - ՀՀ արդարադատության նախարարի առաջին տեղակալ
Ս. Բարսեղյան | - ՀՀ տարածքային կառավարման նախարարի տեղակալ
Ֆ. Բերիկյան | - ՀՀ աշխատանքի և սոցիալական հարցերի նախարարի տեղակալ
Հ. Դարբինյան | - ՀՀ առողջապահության նախարարի առաջին տեղակալ
Ա. Երիցյան | - ՀՀ կառավարությանն առընթեր ՀՀ ոստիկանության պետի առաջին տեղակալ
Տ. Հարությունյան | - ՀՀ կառավարության աշխատակազմի սոցիալական հարցերի վարչության գլխավոր մասնագետ
Ժ. Ասատրյան | - ՀՀ ֆինանսների նախարարության աշխատակազմի բյուջետային ծախսերի ֆինանսական ծրագրավորման վարչության պետ
Ն. Հովհաննիսյան | - ՀՀ կրթության և գիտության նախարարության աշխատակազմի հանրակրթության վարչության պետ
Ն. Դուրյան | -ՀՀ կառավարությանն առընթեր ՀՀ ոստիկանության ՔՀԳՎ-ի 3-րդ վարչության պետի տեղակալ
Վ. Սուքիասյան | - ՀՀ մշակույթի նախարարության աշխատակազմի մշակութային ծրագրերի կառավարման և մոնիթորինգի վարչության պետ
Լ. Ղազարյան | - ՀՀ աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի ընտանիքի, կանանց և երեխաների հիմնահարցերի վարչության պետ(հանձնաժողովի քարտուղար)
(Կազմը խմբ. 24.09.07 N 671-Ն, 23.06.09 N 509-Ն)
