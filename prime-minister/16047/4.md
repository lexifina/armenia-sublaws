Ուժը կորցրած ճանաչել Հայաստանի Հանրապետության վարչապետի 1999 թվականի հունվարի 26-ի «Անչափահաս երեխաների հետ տարվող աշխատանքները համակարգող հանրապետական հանձնաժողով ստեղծելու մասին» N 42, 1999 թվականի ապրիլի 26-ի «Հայաստանի Հանրապետության վարչապետի 1999 թվականի հունվարի 26-ի N 42 որոշման մեջ լրացումներ և փոփոխություն կատարելու մասին» N 247, 2001 թվականի փետրվարի 22-ի «Հայաստանի Հանրապետության վարչապետի 1999 թվականի հունվարի 26-ի N 42 որոշման մեջ փոփոխություն կատարելու մասին» N 148, 2001 թվականի օգոստոսի 10-ի «Հայաստանի Հանրապետության վարչապետի 1999 թվականի հունվարի 26-ի N 42 որոշման մեջ փոփոխություններ կատարելու մասին» N 593 և 2002 թվականի մայիսի 21-ի «Հայաստանի Հանրապետության վարչապետի 1999 թվականի հունվարի 26-ի N 42 որոշման մեջ փոփոխություններ կատարելու մասին» N 305 որոշումները։
