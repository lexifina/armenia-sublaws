# Հավելված ՀՀ վարչապետի 2002 թ. հունիսի 25-ի N 394-Ն որոշման
Կ Ա Ր Գ
Հայաստանի Հանրապետության կառավարության եվ Հայաստանի Հանրապետության վարչապետի որոշումների, հանձնարարականների ԿԱՏԱՐՄԱՆ, ԻՆՉՊԵՍ ՆԱԵՎ ԳՈՐԾԱԴԻՐ ԻՇԽԱՆՈՒԹՅԱՆ ՄԱՐՄԻՆՆԵՐԻ ԸՆԹԱՑԻԿ ԳՈՐԾՈՒՆԵՈՒԹՅԱՆ ՆԿԱՏՄԱՄԲ ՎԵՐԱՀՍԿՈՂՈՒԹՅԱՆ (վերնագիրը լրաց. 02.09.09 N 724-Ն)
I. Ընդհանուր դրույթներ
1. Հայաստանի Հանրապետության կառավարության և Հայաստանի Հանրապետության վարչապետի որոշումների ու հանձնարարականների կատարման, ինչպես նաև գործադիր իշխանության մարմինների ընթացիկ գործունեության նկատմամբ վերահսկողությունն իրականացնում է Հայաստանի Հանրապետության կառավարության աշխատակազմը (այսուհետ՝ աշխատակազմ):
(1-ին կետը լրաց. 02.09.09 N 724-Ն)
2. Աշխատակազմն իր գործունեության ընթացքում ղեկավարվում է Հայաստանի Հանրապետության օրենսդրությամբ և իր կանոնադրությամբ:
3. Հայաստանի Հանրապետության կառավարության և Հայաստանի Հանրապետության վարչապետի որոշումների ու հանձնարարականների կատարման, ինչպես նաև գործադիր իշխանության մարմինների ընթացիկ գործունեության նկատմամբ վերահսկողության ընդհանուր ղեկավարումն իրականացնում է Հայաստանի Հանրապետության վարչապետը:
(3-րդ կետը լրաց. 02.09.09 N 724-Ն)
4. Հայաստանի Հանրապետության կառավարության և Հայաստանի Հանրապետության վարչապետի որոշումների ու հանձնարարականների կատարման, ինչպես նաև գործադիր իշխանության մարմինների ընթացիկ գործունեության նկատմամբ վերահսկողության անմիջական ղեկավարումն իրականացնում է Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավարը:
(4-րդ կետը լրաց. 02.09.09 N 724-Ն)
5. Հայաստանի Հանրապետության կառավարության և Հայաստանի Հանրապետության վարչապետի որոշումների ու հանձնարարականների կատարման, ինչպես նաև գործադիր իշխանության մարմինների ընթացիկ գործունեության նկատմամբ վերահսկողության աշխատանքային ծրագրերը հաստատում է Հայաստանի Հանրապետության վարչապետը՝ Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավարի ներկայացմամբ:
(5-րդ կետը լրաց. 02.09.09 N 724-Ն)
6. Աշխատակազմը Հայաստանի Հանրապետության կառավարության և Հայաստանի Հանրապետության վարչապետի որոշումների ու հանձնարարականների կատարման, ինչպես նաև գործադիր իշխանության մարմինների ընթացիկ գործունեության նկատմամբ վերահսկողությունն իրականացնում է իր համապատասխան կառուցվածքային ստորաբաժանումների (ստորաբաժանման) (այսուհետ՝ կառուցվածքային ստորաբաժանում) միջոցով:
(6-րդ կետը լրաց. 02.09.09 N 724-Ն)
II. Աշխատակազմի խնդիրները Հայաստանի Հանրապետության կառավարության եվ Հայաստանի Հանրապետության վարչապետի որոշումների ու հանձնարարականների կատարման, ԻՆՉՊԵՍ ՆԱԵՎ ԳՈՐԾԱԴԻՐ ԻՇԽԱՆՈՒԹՅԱՆ ՄԱՐՄԻՆՆԵՐԻ ԸՆԹԱՑԻԿ ԳՈՐԾՈՒՆԵՈՒԹՅԱՆ նկատմամբ վերահսկողության ոլորտում (վերնագիրը լրաց. 02.09.09 N 724-Ն)
7. Հայաստանի Հանրապետության կառավարության և Հայաստանի Հանրապետության վարչապետի որոշումների ու հանձնարարականների կատարման, ինչպես նաև գործադիր իշխանության մարմինների ընթացիկ գործունեության նկատմամբ վերահսկողության ոլորտում աշխատակազմի խնդիրներն են՝
ա) Հայաստանի Հանրապետության կառավարության և Հայաստանի Հանրապետության վարչապետի որոշումների ու հանձնարարականների կատարման, ինչպես նաև գործադիր իշխանության մարմինների ընթացիկ գործունեության նկատմամբ վերահսկողությունը.
բ) Հայաստանի Հանրապետության կառավարության և Հայաստանի Հանրապետության վարչապետի որոշումների ու հանձնարարականների կատարման, ինչպես նաև գործադիր իշխանության մարմինների ընթացիկ գործունեության ընթացքում տեղ գտած թերությունների բացահայտումը, դրանց վերացման նպատակով Հայաստանի Հանրապետության վարչապետին և Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավարին առաջարկություններ ներկայացնելը.
գ) Հայաստանի Հանրապետության կառավարության որոշումների, Հայաստանի Հանրապետության վարչապետի որոշումների և հանձնարարականների կատարումն ապահովելու նպատակով Հայաստանի Հանրապետության նախարարություններում, պետական կառավարման այլ մարմիններում սահմանված կարգով ուսումնասիրությունների կատարումը.
դ) Հայաստանի Հանրապետության կառավարությանը և Հայաստանի Հանրապետության վարչապետին վերապահված լիազորությունների լիարժեք և արդյունավետ իրականացման ապահովումը:
(7-րդ կետը լրաց. 02.09.09 N 724-Ն)
III. Աշխատակազմի գործառույթները Հայաստանի Հանրապետության կառավարության եվ Հայաստանի Հանրապետության վարչապետի որոշումների ու հանձնարարականների կատարման նկատմամբ վերահսկողության ոլորտում
8. Սույն կարգի 7-րդ կետում նշված խնդիրների իրականացման նպատակով աշխատակազմի կառուցվածքային ստորաբաժանումն իրականացնում է հետևյալ գործառույթները՝
ա) Հայաստանի Հանրապետության վարչապետի և Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավարի հանձնարարությամբ անցկացնում է ուսումնասիրություններ, այդ թվում` նաև գործադիր իշխանության մարմինների լիազորությունների (գործառույթների) իրականացման ընթացակարգերի վերաբերյալ, կատարում է վերլուծություններ, կատարում նրանց հանձնարարականները, կազմակերպում արդյունքների քննարկում, որոնց հիման վրա Հայաստանի Հանրապետության վարչապետին և Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավարին ներկայացնում է զեկուցագիր, տեղեկանք և առաջարկություններ: Հայաստանի Հանրապետության վարչապետի և Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավարի համաձայնությամբ ուսումնասիրություններ կարող են կատարվել նաև աշխատակազմի կառուցվածքային ստորաբաժանման նախաձեռնությամբ.
բ) ուսումնասիրություններ է կատարում Հայաստանի Հանրապետության նախարարություններում, պետական կառավարման այլ մարմիններում, վերլուծում է Հայաստանի Հանրապետության կառավարության և Հայաստանի Հանրապետության վարչապետի որոշումների ու հանձնարարականների կատարման ընթացքը, ամփոփում արդյունքները և ներկայացնում համապատասխան առաջարկություններ.
գ) Հայաստանի Հանրապետության վարչապետի և Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավարի հանձնարարականների կատարումը վերահսկելու նպատակով հրավիրում և անցկացնում է խորհրդակցություններ, առանձին դեպքերում, ելնելով հարցի կարևորությունից, Հայաստանի Հանրապետության վարչապետին կամ Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավարին ներկայացնում է առաջարկություն նրանց կողմից խորհրդակցություն հրավիրվելու վերաբերյալ՝ շահագրգիռ կողմերի մասնակցությամբ.
դ) Հայաստանի Հանրապետության վարչապետի հանձնարարականների կատարումը չապահովելու կամ անբավարար կատարելու դեպքում Հայաստանի Հանրապետության վարչապետին ներկայացնում է առաջարկություններ խախտումներ թույլ տված, իրենց աշխատանքում թերացած պաշտոնատար անձանց պատասխանատվության ենթարկելու վերաբերյալ: Հետամուտ է լինում բացահայտված թերությունների վերացմանը և պարբերաբար Հայաստանի Հանրապետության վարչապետին ու Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավարին զեկուցում հանձնարարականների կատարման արդյունքների մասին.
ե) վերահսկում է Հայաստանի Հանրապետության վարչապետին և Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավարին հասցեագրված դիմումներում, բողոքներում և առաջարկություններում նշված հարցերի լուծման գործընթացը.
զ) անհրաժեշտության դեպքում ուսումնասիրություններին մասնակից է դարձնում համապատասխան փորձագետների.
է) նշված գործառույթների իրականացումն ապահովելու նպատակով աշխատակազմի կառուցվածքային ստորաբաժանման ղեկավարը, Հայաստանի Հանրապետության վարչապետի և Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավարի հանձնարարությամբ, Հայաստանի Հանրապետության նախարարություններից, պետական կառավարման այլ մարմիններից կարող է պահանջել համապատասխան փաստաթղթեր և անհրաժեշտ տեղեկատվություն:
