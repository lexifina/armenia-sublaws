# Հավելված N 1 ՀՀ վարչապետի 2002 թ. հունիսի 27-ի N 405-Ն որոշման
Կ Ա Զ Մ
դպրոցականների ամառային հանգստի կազմակերպման միջգերատեսչական հանձնաժողովի
Հ. Աբրահամյան | - ՀՀ տարածքային կառավարման նախարար (հանձնաժողովի նախագահ)
Վ. Խաչիկյան | - ՀՀ Ազգային ժողովի պատգամավոր (համաձայնությամբ)
Վ. Բարսեղյան | - ՀՀ մշակույթի, երիտասարդության հարցերի և սպորտի նախարարի տեղակալ
Ա. Եսայան | - ՀՀ սոցիալական ապահովության նախարարի տեղակալ
Ա. Երիցյան | - ՀՀ ներքին գործերի նախարարի տեղակալ
Ա. Թոփուզյան | - ՀՀ կրթության և գիտության նախարարի տեղակալ
Վ. Դավիդյանց | - ՀՀ գլխավոր պետական սանիտարական բժիշկ
Մ. Երանոսյան | - ՀՀ ֆինանսների և էկոնոմիկայի նախարարության բյուջետային ծրագրավորման գլխավոր վարչության պետ
Կ. Շահգալդյան | - ՀՀ Կոտայքի մարզպետ
Ս. Հայրապետյան | - ՀՀ սոցիալական ապահովագրության պետական հիմնադրամի նախագահի խորհրդական
Ա. Կարապետյան | - ՀՀ կառավարության աշխատակազմի սոցիալական հարցերի վարչության պետ (հանձնաժողովի քարտուղար)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
