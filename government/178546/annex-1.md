# Հավելված ՀՀ կառավարության 2023 թվականի հունիսի 1-ի N 864-Ն որոշման
ՄԻԱՍՆԱԿԱՆ ՀԱՇՎՈՒՄ ԿԱՄ ՎԱՐՉԱԿԱՆ ԱԿՏԻ ՄԻԱՍՆԱԿԱՆ ՀԱՇՎՈՒՄ ԱՌԿԱ ԳՈՒՄԱՐՆԵՐԻ ՎԵՐԱԴԱՐՁԸ ՀԱՐԿԱՅԻՆ ՄԱՐՄԻՆ ՆԵՐԿԱՅԱՑՎԱԾ ԱՅԼ ՀԱՇՎԻՆ ԻՐԱԿԱՆԱՑՆԵԼՈՒ ԴԵՊՔԵՐԸ ԵՎ ԿԱՐԳԸ (վերնագիրը լրաց. 07.12.23 N 2114-Ն)
1. Սույն կարգով կարգավորվում են միասնական հաշվում կամ վարչական ակտի միասնական հաշվում առկա գումարների վերադարձը հարկային մարմին ներկայացված այլ հաշվին իրականացնելու դեպքերը և կարգը սահմանելու հետ կապված հարաբերությունները։
(1-ին կետը լրաց. 07.12.23 N 2114-Ն)
2. Սույն կարգի 3-րդ կետում չնշված դեպքերում՝ հարկ վճարողներին միասնական հաշվում կամ վարչական ակտի միասնական հաշվում առկա գումարների վերադարձն իրականացվում է իրենց անվամբ բացված բանկային հաշիվներին։
(2-րդ կետը լրաց. 07.12.23 N 2114-Ն)
3. Միասնական հաշվում կամ վարչական ակտի միասնական հաշվում առկա գումարների վերադարձը հարկ վճարողի կողմից հարկային մարմին ներկայացված՝ իր բանկային հաշվից տարբերվող այլ հաշվին իրականացվում է հետևյալ դեպքերում՝
1) բանկային հաշիվներ չունեցող կազմակերպություններին գումարների վերադարձն իրականացվում է՝
ա․ կազմակերպությունների վերակազմակերպման դեպքում՝ իրավահաջորդ կազմակերպության բանկային հաշվին,
բ․ լուծարված կազմակերպությունների դեպքում՝ կազմակերպության մասնակցի բանկային հաշվին՝ մյուս մասնակիցների համաձայնությամբ (եթե առկա են մեկից ավելի մասնակիցներ),
գ․ լուծարված պետական կառավարման համակարգի մարմինների, տեղական ինքնակառավարման մարմինների, հիմնադրամների, հասարակական կազմակերպությունների դեպքում՝ համապատասխան գանձապետական հաշիվներին,
դ. հաշվառումից հանված՝ ոչ ռեզիդենտ կազմակերպությունների մասնաճյուղերի և ներկայացուցչությունների դեպքում՝ դրանց հիմնադրի կամ հիմնադրի կողմից լիազորված անձի բանկային հաշվին՝ մյուս հիմնադիրների համաձայնությամբ (եթե առկա են մեկից ավելի հիմնադիրներ).
2) անհատ ձեռնարկատիրոջ կամ նոտարի մահվան դեպքում՝ ժառանգի անձնագրային տվյալներով բացված բանկային հաշվին՝ մյուս ժառանգների համաձայնությամբ (եթե առկա են մեկից ավելի ժառանգներ).
3) բանկային հաշիվներ չունեցող հաշվառումից հանված անհատ ձեռնարկատերերին և պաշտոնից ազատված նոտարներին գումարների վերադարձն իրականացվում է վերջիններիս՝ որպես ֆիզիկական անձ, անձնագրային տվյալներով բացված բանկային հաշիվներին.
4) պետական ոչ առևտրային կազմակերպություններին և համայնքային ոչ առևտրային կազմակերպություններին գումարների վերադարձը կարող է իրականացվել նաև նրանց գանձապետական հաշիվներին։
(3-րդ կետը լրաց. 17.11.23 N 1973-Ն, 07.12.23 N 2114-Ն)
4. Միասնական հաշվում կամ վարչական ակտի միասնական հաշվում առկա գումարները վերադարձվում են սույն կարգին համապատասխան այդ գումարներն ստանալու իրավասություն ունեցող անձանց՝ նրանց կողմից հարկային մարմին ներկայացված՝ Հայաստանի Հանրապետության կառավարությանն առընթեր պետական եկամուտների կոմիտեի նախագահի 2017 թվականի հուլիսի 27-ի N 246-Ն հրամանով հաստատված դիմումի հիման վրա, բացառությամբ սույն կարգի 3-րդ կետի 1-ին ենթակետի «գ» պարբերությունում նշված դեպքի։
(4-րդ կետը լրաց. 07.12.23 N 2114-Ն)
5. Սույն կարգի 3-րդ կետի 1-ին ենթակետի «ա», «բ» և «դ» պարբերություններում և 2-րդ ենթակետում նշված դեպքերում սույն կարգի 4-րդ կետում նշված դիմումը հարկային մարմին է ներկայացվում թղթային տարբերակով, և դիմումին կից ներկայացվում են նաև իրավահաջորդությունը, մասնակից, հիմնադիր (ոչ ռեզիդենտ կազմակերպությունների մասնաճյուղերի և ներկայացուցչությունների դեպքում՝ դրանց հիմնադիր կամ հիմնադրի կողմից լիազորված անձ) հանդիսանալու փաստը, ժառանգությունը և անձի նույնականացումը հավաստող համապատասխան փաստաթղթերը, ինչպես նաև բանկի կողմից տրված տեղեկանք, որը կհավաստի, որ ներկայացված բանկային հաշիվը պատկանում է դիմումատուին։
(5-րդ կետը փոփ., լրաց. 17.11.23 N 1973-Ն)
6. Սույն կարգի 3-րդ կետի 3-րդ և 4-րդ ենթակետերում նշված դեպքերում սույն կարգի 4-րդ կետում նշված դիմումը հարկային մարմին է ներկայացվում էլեկտրոնային տարբերակով։
7. Էլեկտրոնային տարբերակով ներկայացված դիմումում նշված հաշվի՝ դիմումատուին պատկանելիության և վավերականության հավաստման նպատակով սույն կարգի 3-րդ կետի 3-րդ ենթակետում նշված դեպքում դիմումատուի համաձայնությամբ հարկային մարմինն առցանց եղանակով (WEB ծառայության միջոցով) հարցում է կատարում Հայաստանի Հանրապետության կենտրոնական բանկ։
(7-րդ կետը լրաց. 07.12.23 N 2114-Ն)
8․ Էլեկտրոնային տարբերակով ներկայացված դիմումում նշված հաշվի՝ դիմումատուին պատկանելիության և վավերականության հավաստման նպատակով սույն կարգի 3-րդ կետի 4-րդ ենթակետում նշված դեպքում հարկային մարմինն առցանց եղանակով (WEB ծառայության միջոցով) հարցում է կատարում Հայաստանի Հանրապետության ֆինանսների նախարարություն։
(հավելվածը լրաց., փոփ. 17.11.23 N 1973-Ն, լրաց. 07.12.23 N 2114-Ն)
Հայաստանի Հանրապետության վարչապետի աշխատակազմի ղեկավար | Ա. Հարությունյան
