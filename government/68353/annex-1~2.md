# Հավելված N 1 կենսաթոշակների վճարման ծառայությունների մատուցման պայմանագրի
Ց Ա Ն Կ
ՊԱՏՎԻՐԱՏՈՒԻ ԿՈՂՄԻՑ ԷԼԵԿՏՐՈՆԱՅԻՆ ԵՂԱՆԱԿՈՎ ՆԵՐԿԱՅԱՑՎՈՂ ՏՎՅԱԼՆԵՐԻ
1. Բանկի անվանումը
2. Կենսաթոշակառուի կամ շահառուի (եթե շահառուն բանկում արդեն ունի իր անվամբ բացված բանկային հաշիվ) անունը, ազգանունը (հայրանունը), անձը հաստատող փաստաթղթի սերիան և համարը, սոցիալական ապահովության քարտի կամ սոցիալական քարտ չունենալու մասին տեղեկանքի համարը, առկայության դեպքում` կենսաթոշակառուի փոխարեն կենսաթոշակն ստանալու՝ օրենքով այդ իրավունքն ունեցող անձի անունը, ազգանունը (հայրանունը), անձը հաստատող փաստաթղթի սերիան և համարը
(2-րդ կետը լրաց. 20.01.16 N 76-Ն)
3. Կենսաթոշակառուի կամ շահառուի (եթե շահառուն բանկում արդեն ունի իր անվամբ բացված բանկային հաշիվ) բանկային հաշվի համարը
(3-րդ կետը լրաց. 20.01.16 N 76-Ն)
4. Վճարման ենթակա կենսաթոշակի գումարը (այդ թվում` տվյալ ամսվան նախորդող ժամանակահատվածի համար)` ըստ ժամանակահատվածի և տեսակների
5. Վճարման ենթակա ընդհանուր գումարը
(հավելվածը լրաց. 20.01.16 N 76-Ն)
