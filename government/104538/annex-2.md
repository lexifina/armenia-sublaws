# Հավելված N 2 ՀՀ կառավարության 2016 թվականի մարտի 10-ի N 294-Ն որոշման
Կ Ա Զ Մ
ՀՈԳԱԲԱՐՁՈՒՆԵՐԻ ԽՈՐՀՐԴԻ
1. Հայաստանի Հանրապետության վարչապետի աշխատակազմի ղեկավար (խորհրդի նախագահ)
(1-ին կետը փոփ. 10.08.17 N 950-Ն, 09.08.18 N 901-Ն)
2. Հայաստանի Հանրապետության տնտեսական զարգացման և ներդրումների նախարար
(2-րդ կետը փոփ. 16.02.17 N 140-Ն)
3. Հայաստանի Հանրապետության վարչապետի աշխատակազմի ղեկավարի առաջին տեղակալ
(3-րդ կետը փոփ. 16.02.17 N 140-Ն, 09.08.18 N 901-Ն)
4. Հայաստանի Հանրապետության ֆինանսների նախարարի առաջին տեղակալ
5. Հայաստանի Հանրապետության արդարադատության նախարարի առաջին տեղակալ
(հավելվածը փոփ. 16.02.17 N 140-Ն, 10.08.17 N 950-Ն, 09.08.18 N 901-Ն)
