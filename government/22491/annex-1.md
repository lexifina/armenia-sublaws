# Հավելված ՀՀ կառավարության 2006 թվականի հունվարի 26-ի N 75-Ն որոշման
ՕՏԱՐԵՐԿՐՅԱ ՊԵՏՈՒԹՅՈՒՆՆԵՐԻ ՈՒՍՈՒՄՆԱԿԱՆ ՀԱՍՏԱՏՈՒԹՅՈՒՆՆԵՐ ՊԵՏԱԿԱՆ ՊԱՏՎԵՐԻ ՇՐՋԱՆԱԿՆԵՐՈՒՄ ՈՒՍՄԱՆ ԵՎ ՎԵՐԱՊԱՏՐԱՍՏՄԱՆ ԳՈՐԾՈՒՂՎԱԾ ՓՐԿԱՐԱՐԱԿԱՆ ԾԱՌԱՅՈՂՆԵՐԻՆ ԴՐԱՄԱԿԱՆ ՎՃԱՐՆԵՐԻ ՉԱՓԸ ԵՎ ՎՃԱՐՄԱՆ ԿԱՐԳԸ (վերնագիրը փոփ. 03.07.14 N 656-Ն, լրաց. 13.02.20 N 145-Ն)
1. Սույն իրավական ակտով սահմանվում են օտարերկրյա պետությունների ուսումնական հաստատություններ պետական պատվերի շրջանակներում ուսման և վերապատրաստման գործուղված փրկարարական ծառայողներին դրամական վճարների չափի և վճարման հետ կապված հարաբերությունները:
(1-ին կետը փոփ. 03.07.14 N 656-Ն, լրաց. 13.02.20 N 145-Ն)
2. Հայաստանի Հանրապետության պետական բյուջեով նախատեսված հատկացումների սահմաններում օտարերկրյա պետությունների ուսումնական հաստատություններ պետական պատվերի շրջանակներում ուսման և վերապատրաստման գործուղված փրկարարական ծառայողներին վճարվում են հետևյալ դրամական վճարները`
NN ը/կ | Պաշտոնների խումբը | Դրամական վճարը (դրամ)
Ռուսաստանի Դաշնության ուսումնական հաստատությունների ունկնդիրների համար | այլ օտարերկրյա պետությունների ուսումնական հաստատությունների ունկնդիրների համար

2. | Փրկարարական ծառայության գլխավոր պաշտոններ | 135 000 | 180 000

(2-րդ կետը փոփ. 03.07.14 N 656-Ն, լրաց., խմբ. 13.02.20 N 145-Ն)
3. Հայաստանի Հանրապետության պետական բյուջեով նախատեսված հատկացումների սահմաններում` օտարերկրյա պետությունների ռազմաուսումնական հաստատություններում ուսանող կուրսանտ փրկարարական ծառայողների ամսական կրթաթոշակները սահմանել 99 000 դրամի չափով:
(3-րդ կետը փոփ. 13.02.20 N 145-Ն)
4. Ուսման և վերապատրաստման ընթացքում պահպանվում են օտարերկրյա պետությունների ռազմաուսումնական հաստատությունների ունկնդիր փրկարարական ծառայողների պաշտոնային դրույքաչափը:
(4-րդ կետը փոփ. 03.07.14 N 656-Ն, լրաց. 13.02.20 N 145-Ն)
5. Օտարերկրյա պետությունների ռազմաուսումնական հաստատություններում սովորող կամ վերապատրաստվող փրկարարական ծառայողների դրամական վճարումները և կրթաթոշակները վճարվում են Հայաստանի Հանրապետության ներքին գործերի նախարարության ֆինանսական ստորաբաժանման կողմից` կանխիկ կամ գանձապետական համակարգի միջոցով` փոխանցումներով:
(5-րդ կետը փոփ. 09.08.12 N 1014-Ն, 03.07.14 N 656-Ն, լրաց., փոփ. 13.02.20 N 145-Ն, փոփ. 06.07.23 N 1094-Ն)
6. Տվյալ ամսվա համար նախատեսված դրամական վճարումները և կրթաթոշակները փրկարարական ծառայողին վճարվում կամ նրա հաշվի համարին փոխանցվում են մինչև տվյալ ամսվա 30-ը:
(6-րդ կետը փոփ. 03.07.14 N 656-Ն)
