# Հավելված N 2 ՀՀ կառավարության 2004 թվականի հունիսի 10-ի N 891-Ն որոշման

Հայաստանի Հանրապետության վարչապետ (խորհրդի նախագահ) Հայաստանի Հանրապետության փոխվարչապետ, Հայաստանի Հանրապետության տարածքային կառավարման նախարար Հայաստանի Հանրապետության գյուղատնտեսության նախարար Հայաստանի Հանրապետության բնապահպանության նախարար Հայաստանի Հանրապետության կառավարությանն առընթեր անշարժ գույքի կադաստրի պետական կոմիտեի նախագահ Երևանի քաղաքապետ (համաձայնությամբ) Հայաստանի Հանրապետության Արագածոտնի մարզպետ Հայաստանի Հանրապետության Uյունիքի մարզպետ Հայաստանի Հանրապետության Տավուշի մարզպետ Հայաստանի Հանրապետության Վայոց ձորի մարզպետ Հայաստանի Հանրապետության Կոտայքի մարզպետ Հայաստանի Հանրապետության Գեղարքունիքի մարզպետ Հայաստանի Հանրապետության Լոռու մարզպետ Հայաստանի Հանրապետության քաղաքաշինության նախարարի տեղակալ «Հայանտառ» պետական ոչ առևտրային կազմակերպության տնօրեն (համաձայնությամբ) «Կանաչազարդ երկիր» հասարակական կազմակերպության նախագահ (համաձայնությամբ) «Հայաստանի կանաչների միություն» հասարակական կազմակերպության նախագահ (համաձայնությամբ) «Հանուն կայուն մարդկային զարգացման ասոցիացիա» հասարակական կազմակերպության նախագահ (համաձայնությամբ)
(Հավելվածը լրաց. 04.11.04 N 1521-Ն, խմբ. 09.08.07 N 924-Ն, փոփ. 03.07.08 N 696-Ն, 16.07.09 N 797-Ն, խմբ. 10.05.12 N 581-Ն)
