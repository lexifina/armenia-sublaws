# Հավելված N 2 ՀՀ կառավարության 2004 թվականի հունիսի 10-ի N 891-Ն որոշման

Տ. Սարգսյան | - | ՀՀ վարչապետ (խորհրդի նախագահ)
Ա. Գևորգյան | - | ՀՀ փոխվարչապետ, տարածքային կառավարման նախարար
Ա. Գրիգորյան | - | ՀՀ գյուղատնտեսության նախարար
Ա. Հարությունյան | - | ՀՀ բնապահպանության նախարար
Մ. Վարդանյան | - | ՀՀ կառավարությանն առընթեր անշարժ գույքի կադաստրի պետական կոմիտեի նախագահ
Ե. Զախարյան | - | Երևանի քաղաքապետ
Գ. Գյոզալյան | - | ՀՀ Արագածոտնի մարզպետ
Ս. Խաչատրյան | - | ՀՀ Սյունիքի մարզպետ
Ա. Ղուլարյան | - | ՀՀ Տավուշի մարզպետ
Վ. Մաթևոսյան | - | ՀՀ Վայոց ձորի մարզպետ
Կ. Շահգալդյան | - | ՀՀ Կոտայքի մարզպետ
Ն. Պողոսյան | - | ՀՀ Գեղարքունիքի մարզպետ
Ա. Քոչարյան | - | ՀՀ Լոռու մարզպետ
Ռ. Ալավերդյան | - | ՀՀ քաղաքաշինության նախարարի տեղակալ
Ս. Գալստյան | - | ՀՀ գյուղատնտեսության նախարարի տեղակալ
Մ. Մաթևոսյան | - | «Հայանտառ» ՊՈԱԿ-ի տնօրեն
Ս. Սարգսյան | - | «Կանաչազարդ երկիր» հասարակական կազմակերպության նախագահ (համաձայնությամբ)
Զ. Բալայան | - | գրող, Հայաստանի գրողների միության անդամ (համաձայնությամբ)
Հ. Սանասարյան | - | Կանաչների միության նախագահ (համաձայնությամբ)
Կ. Դանիելյան | - | Հանուն կայուն մարդկային զարգացման ասոցիացիայի նախագահ (համաձայնությամբ)
(Կազմը լրաց. 04.11.04 N 1521-Ն, խմբ. 09.08.07 N 924-Ն, փոփ. 03.07.08 N 696-Ն)
