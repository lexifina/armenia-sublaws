# Հավելված N 2 ՀՀ կառավարության 2002 թվականի օգոստոսի 15-ի N 1316-Ն որոշման

I. Տեսչության կառուցվածքային ստորաբաժանումներ
Կենտրոնական ապարատ
Համաճարակաբանության բաժին
Մանուկների և դեռահասների հիգիենայի բաժին
Կոմունալ հիգիենայի բաժին
Սննդի հիգիենայի բաժին
Աշխատանքի հիգիենայի և ճառագայթային անվտանգության բաժին
Տեղեկատվական-վերլուծական բաժին
Հանրային առողջության բաժին
II. Տարածքային մարմիններ
Արագածոտնի մարզային կենտրոն
Արարատի մարզային կենտրոն
Արմավիրի մարզային կենտրոն
Գեղարքունիքի մարզային կենտրոն
Լոռու մարզային կենտրոն
Կոտայքի մարզային կենտրոն
Շիրակի մարզային կենտրոն
Սյունիքի մարզային կենտրոն
Վայոց ձորի մարզային կենտրոն
Տավուշի մարզային կենտրոն
Երևանի Արաբկիրի տարածքային կենտրոն
Երևանի Նոր Նորքի և Ավանի տարածքային կենտրոն
Երևանի Էրեբունու և Նուբարաշենի տարածքային կենտրոն
Երևանի Շենգավիթի տարածքային կենտրոն
Երևանի Կենտրոնի և Նորք-Մարաշի տարածքային կենտրոն
Երևանի Մալաթիա-Սեբաստիայի տարածքային կենտրոն
Երևանի Աջափնյակ-Դավթաշենի տարածքային կենտրոն
Օդային և գծային հաղորդակցության կենտրոն
Հայկական ատոմային էլեկտրակայանի կենտրոն
(Կառուցվածքը փոփ. 21.11.02 N 1812-Ն)
