# Հավելված N 1 ՀՀ կառավարության 2005 թվականի օգոստոսի 18-ի N 2085-Ն որոշման
ԲՆԱՊԱՀՊԱՆԱԿԱՆ ՊԵՏԱԿԱՆ ՏԵՍՈՒՉԻ ՀԱՄԱԶԳԵՍՏԻ ՆԿԱՐԱԳԻՐԸ
Սույն իրավական ակտով սահմանվում են բնապահպանական պետական տեսչության տղամարդ և կին պետական տեսուչների ամառային և ձմեռային համազգեստների նկարագրերը:
1. Բնապահպանական պետական տեսչության տղամարդ տեսուչի ձմեռային համազգեստը`
ա) գլխարկ` ականջակալներով` մահուդից, բաղկացած է թասակից, ականջակալներից և ճակատային մասից (հովհար): Ականջակալները և հովհարը մշակված են արհեստական մորթուց: Թասակը չորստապականի է, հովհարի առջևի կենտրոնական մասում ամրացվում է գլխարկանշան (N 3 հավելված, նկար N 1),
բ) կիսավերարկու` կանաչավուն գույնի բրդյա կտորից, տաք ներդիրով, կոճկվում է կափույրով ծածկվող շղթայով: Լանջափեշերի ներքևի մասում` մեծ վրադիր կափույրներով գրպաններ, իսկ վերևի մասում` թեք ներկարված փոքր գրպաններ: Աստառը` մետաքսյա, ձախ կողմում ունի ծոցագրպան: Կիսավերարկուի ձախ թևքի վերևի մասում կտորի վրա կարված է բնապահպանական պետական տեսչության տարբերանշանը (N 3 հավելված, նկար N 1),
գ) տաբատ` կանաչավուն գույնի բրդյա կտորից, տաք ներդիրով, ուղիղ ուրվագծով, գոտին` գոտեմակօղերով, մետաքսե աստառով, կոճկվում է կոճակով և շղթայով: Արտաքին գրպանները` ուղիղ: Հետևամասի աջ կողմում կոճակով կոճկվող կափույրով գրպան (N 3 հավելված, նկար N 1),
դ) վերնաշապիկ` երկարաթև` բաց կանաչավուն գույնի բրդյա կտորից, ծալովի օձիքով, ձախ կրծքամասում` կոճակով կոճկվող արտաքին գրպան, կոճկվում է 8 կոճակով: Թևքերը երկար, ուղիղ թևքածալերով (N 3 հավելված, նկար N 1),
ե) բաճկոն` կանաչավուն գույնի բրդյա կտորից, միափեշ, միակողմ 4 կոճակով, հետծալված օձիքով: Կրծքամասի 2 կողմում տեղադրված են ներկարված շերտակարերով, իսկ փեշերի ներքևի մասում` վրադիր գրպաններ՝ կափույրներով: Աստառը` մետաքսյա, ձախ կողմում ունի ծոցագրպան (N 3 հավելված, նկար N 1),
զ) ձմեռային կիսաճտքավոր կոշիկ` սև գույնի կաշվից, տաք, բնական մորթուց (ոչխարի) ներդիրով: Ներբանները ռելիեֆային, կոճկվում է շղթայով (N 3 հավելված, նկար N 1)։
2. Բնապահպանական պետական տեսչության տղամարդ տեսուչի ամառային համազգեստը`
ա) գլխարկ` բրդյա, ամենօրյա` մուգ կանաչավուն կտորից, դարչնագույն երիզով և գլխարկաբոլորքով: Կազմված է սև, լաքապատ գլխարկահովհարից և գլխարկաբոլորքից: Գլխարկաբոլորքը դարչնագույն է` 2 մմ լայնքով կարմիր մահուդից կարված երիզով: Գլխարկի կենտրոնում ամրացվում է գլխարկանշան: Գլխարկահովհարը սև է, լաքապատ (N 3 հավելված, նկար N 2),
բ) տաբատ` գարնանային` կանաչ բամբակյա կտորից` ուղիղ ուրվագծով: Գոտին գոտեմակօղերով, կոճկվում է 2 կոճակով և շղթայով: Արտաքին գրպանները` ուղիղ: Հետևամասի աջ կողմում` կոճակով կոճկվող կափույրով գրպան (N 3 հավելված, նկար N 2),
գ) վերնաշապիկ` կարճաթև` կանաչ բամբակյա կտորից, ծալովի օձիքով, կրծքամասում՝ կոճակով կոճկվող կափույրով գրպան, կոճկվում է 8 կոճակով, թևքերը կարճ, ուղիղ թևքածալով (N 3 հավելված, նկար N 2),
դ) բաճկոն` գարնանային-աշնանային` կանաչ գույնի բամբակյա կտորից, ուղիղ ուրվագծով, կոճկվում է 4 կոճակով: Օձիքը՝ ծալովի, լանջափեշերի ներքևի մասերում՝ վրադիր կափույրներով գրպաններ, իսկ վերևի մասում` թեք ներկարված փոքր գրպաններով: Աստառը մետաքսյա, ձախ կողմում ունի ծոցագրպան (N 3 հավելված, նկար N 2),
ե) ամառային կոշիկ` սև կամ մուգ դարչնագույն կաշվից, երեսամասը` ամբողջական առաջամասով (N 3 հավելված, նկար N 2)։
3. Բնապահպանական պետական տեսչության կին տեսուչի ձմեռային համազգեստը`
ա) գլխարկ` ականջակալներով, ձմեռային` մահուդից, բաղկացած է թասակից, ականջակալներից և ճակատային մասից (հովհար): Ականջակալները և հովհարը մշակված են արհեստական մորթուց: Թասակը չորստապականի է, հովհարի առջևի կենտրոնական մասում ամրացվում է գլխարկանշան (N 3 հավելված, նկար N 3),
բ) կիսավերարկու` ձմեռային` մուգ կանաչավուն կտորից, հանովի մորթե օձիքով, ուղիղ ուրվագծով և տաք ներդիրով: Կոճկվում է կափույրով ծածկվող շղթայով: Լանջափեշերի ներքևի մասերում` մեծ, վրադիր գրպաններ, վերևի մասում` թեք ներկարված փոքր գրպաններ: Աստառը` մետաքսից, ձախ կողմում ունի ծոցագրպան: Կիսավերարկուի ձախ թևքի վերևի մասում կտորի վրա կարված է բնապահպանական պետական տեսչության տարբերանշանը (N 3 հավելված, նկար N 3),
գ) կիսաշրջազգեստ` բրդյա, ամենօրյա` կանաչավուն գույնի, ուղիղ կտրվածքով, երկկողմանի սեղմոններով, հետևամասում՝ կափույրով ճեղքվածքով: Աստառը` մետաքսից: Ձախ կողմից կոճկվում է շղթայով (N 3 հավելված, նկար N 3),
դ) բաճկոն` բրդյա, ամենօրյա` մուգ կանաչավուն բրդյա կտորից: Միափեշ, միակողմ 3 ոսկեգույն կոճակով, վրադիր օձիքով: Կրծքամասը` սեղմոններով, փեշերի ներքևի մասերում` ներկարվող, կափույրով թեք գրպաններ: Աստառը` մետաքսյա, ձախ կողմում ունի ծոցագրպան (N 3 հավելված, նկար N 3),
ե) վերնաշապիկ` երկարաթև` սպիտակ մետաքսից, օձիքը` հետ ծալված, կրծքամասերում` սեղմոններով, կոճկվում է կափույրով ծածկված 8 կոճակով (N 3 հավելված, նկար N 3),
զ) կիսաճտքավոր կոշիկ` սև գույնի բնական կաշվից: Երեսամասը` ամբողջական կամ կտրված քթամասով, երկարացված ձևավոր հետևամասերով, կրունկը` մինչև 5,5 սմ բարձրության: Լեզվակը միացված է առաջամասին (N 3 հավելված, նկար N 3)։
4. Բնապահպանական պետական տեսչության կին տեսուչի ամառային համազգեստը`
ա) բաճկոն` սինթետիկ` կառուցվածքով և ձևով նման է սույն իրավական ակտի 3-րդ կետի «դ» ենթակետում նկարագրված բրդյա բաճկոնին (N 3 հավելված, նկար N 4),
բ) կիսաշրջազգեստ` բամբակյա, ամենօրյա` մուգ կանաչավուն գույնի, ուղիղ կարվածքով, երկկողմանի սեղմոններով, աստառով: Գոտին` գոտեմակօղերով, կողամասում կոճկվում է մեկ կոճակով և շղթայով (N 3 հավելված, նկար N 4),
գ) վերնաշապիկ` կարճաթև` սպիտակ մետաքսից, օձիքը` հետ ծալված, կրծքամասերում՝ սեղմոններով, կոճկվում է կափույրով ծածկված 8 կոճակով (N 3 հավելված, նկար N 4),
դ) կոշիկ` սև գույնի կաշվից: Երեսամասը` ամբողջական, հետևամասի և առաջամասի հետ ծալված եզրերով: Ներբանը ձևավորված է պոլիուրէթանից` սոսնձով միացման մեթոդով: Կրունկը` մինչև 5 սմ բարձրության, փաթաթված երեսամասի նյութով (N 3 հավելված, նկար N 4)։
5. Բնապահպանական պետական տեսուչի դաշտային ամառային համազգեստը`
դաշտային կոստյում` բամբակյա մուգ կանաչ գույնի գործվածքից, տրիկոտաժե կիսաթև շապիկով, կեպիով (N 3 հավելված, նկարներ NN 6 և 8),
ա) բաճկոն` բամբակյա մուգ կանաչ գույնի կտորից, միափեշ, հետծալված օձիքով, բաճկոնի առջևի մասում տեղադրված է շղթա` 2 կոճգամով և կպչուն կոճկվածքով, կրծքավանդակին՝ 2 վրադիր գրպան` կափույրներով և կոճգամներով, 2 ներկարված կողային գրպանով: Ձախ թևքի վերևի մասում` կտորի վրա կարված է բնապահպանական պետական տեսչության տարբերանշանը (N 3 հավելված, նկարներ NN 6 և 8),
բ) տաբատ` ուղիղ կարվածքով` 2 կողային գրպանով և հետևի մասում` մեկ գրպանով, առջևի մասում տեղադրված է շղթա (N 3 հավելված, նկարներ NN 6 և 8),
գ) կաշվե գոտի` բնական կաշվից` 50 մմ լայնությամբ, երկանցք, մետաղյա ճարմանդով և զենքի համար նախատեսված պատյանով (N 3 հավելված, նկարներ NN 6 և 8),

6. Բնապահպանական պետական տեսուչի դաշտային ձմեռային համազգեստը`
դաշտային կոստյում` բրդյա մուգ կանաչ գույնի գործվածքից, գլխարկով (ականջակալներով) (N 3 հավելված, նկարներ NN 5 և 7),
