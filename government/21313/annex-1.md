# Հավելված N 1 ՀՀ կառավարության 2005 թվականի օգոստոսի 18-ի N 2085-Ն որոշման
ԲՆԱՊԱՀՊԱՆՈՒԹՅԱՆ ԵՎ ԸՆԴԵՐՔԻ ՊԵՏԱԿԱՆ ՏԵՍՈՒՉԻ ՀԱՄԱԶԳԵՍՏԻ ՆԿԱՐԱԳԻՐԸ (վերնագիրը փոփ. 30.11.17 N 1588-Ն)
1. Գլխարկ` մուգ կանաչավուն օքսֆորդ կտորից: Կազմված է գլխարկահովարից և երկու կողմերից փոքր երկուական օդանցքերից։ Գլխարկի կենտրոնում ամրացվում է Բնապահպանության և ընդերքի տեսչական մարմնի տարբերանշանը (N 3 հավելված, նկարներ NN 1, 2, 3 և 4):
2. Տաբատ` մուգ կանաչավուն օքսֆորդ կտորից: Առջևամասի վերևի արտաքին 2 գրպանները թեք են, ներքևի 4 գրպանները շրջվում են հետևամաս, կոճկվում են շղթայով և կպչուկով: Հետևամասի աջ և ձախ կողմերում` կպչուկով կոճկվող գրպաններ, ներսում՝ փոքր, չկոճկվող գրպաններ (N 3 հավելված, NN 1, 2, 3 և 4):
3. Գոտին՝ բնական կաշվից, գոտեմակօղերով, ռեզիններով և զենքի համար նախատեսված պատյանով: Կոճկվում է 1 կոճակով և շղթայով:
4. Շապիկ` կանաչավուն կամ սպիտակ լակոստ կտորից, կարճաթև: Վզի բացվածքը` ուղիղ և օձիքով։ Շապիկի աջ կրծքամասում՝ Բնապահպանության և ընդերքի տեսչական մարմնի տարբերանշանը (N 3 հավելված, նկար NN 2 և 4):
5. Բաճկոն` մուգ կանաչավուն օքսֆորդ կտորից: Կոճկվում է շղթայով: Թևերը և ներքևի հատվածը՝ ռեզինե։ Ձախ թևի վերին հատվածում՝ կպչուն կտորին, ասեղնագործված է Հայաստանի Հանրապետության զինանշանը։ Աջ թևի վերին հատվածում՝ կպչուն կտորին, ասեղնագործված է Բնապահպանության և ընդերքի տեսչական մարմնի տարբերանշանը։ Առաջնամասում՝ տարբերանշանների երկայնությամբ, առկա են 2 հորիզոնական շղթայով կոճկվող գրպաններ։ Ներսի սինտիպոնը՝ 4 սմ (N 3 հավելված, նկար NN 1 և 3):
(հավելվածը փոփ., խմբ. 30.11.17 N 1588-Ն, փոփ., լրաց. 25.06.20 N 1091-Ն, խմբ. 27.01.21 N 100-Ն)
