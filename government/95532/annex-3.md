# Հավելված N 3 ՀՀ կառավարության 2015 թվականի հունվարի 30-ի N 71-Ն որոշման
Ց Ա Ն Կ
ԵՎՐԱՍԻԱԿԱՆ ՏՆՏԵՍԱԿԱՆ ՄԻՈՒԹՅԱՆ (ՄԱՔՍԱՅԻՆ ՄԻՈՒԹՅԱՆ) ՏԵԽՆԻԿԱԿԱՆ ԿԱՆՈՆԱԿԱՐԳԵՐԻ, ՈՐՈՆՑ ՊԱՀԱՆՋՆԵՐԻ ՊԱՀՊԱՆՄԱՆ ՆԿԱՏՄԱՄԲ ՊԵՏԱԿԱՆ ՎԵՐԱՀՍԿՈՂՈՒԹՅՈՒՆ ԻՐԱԿԱՆԱՑՆՈՂ ԼԻԱԶՈՐ ՄԱՐՄԻՆ Է ՍԱՀՄԱՆՎԵԼ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԱՐՏԱԿԱՐԳ ԻՐԱՎԻՃԱԿՆԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԱՇԽԱՏԱԿԱԶՄԻ ՊԵՏԱԿԱՆ ՀՐԴԵՀԱՅԻՆ ԵՎ ՏԵԽՆԻԿԱԿԱՆ ԱՆՎՏԱՆԳՈՒԹՅԱՆ ՏԵՍՉՈՒԹՅՈՒՆԸ (վերնագիրը խմբ. 17.08.17 N 1020-Ն)
1. Մաքսային միության հանձնաժողովի 2011 թվականի օգոստոսի 16-ի N 770 որոշմամբ հաստատված «Հրատեխնիկական արտադրատեսակների անվտանգության մասին» (ՄՄ ՏԿ 006/2011) Մաքսային միության տեխնիկական կանոնակարգ
2. Մաքսային միության հանձնաժողովի 2011 թվականի հոկտեմբերի 18-ի N 825 որոշմամբ հաստատված «Պայթյունավտանգ միջավայրերում աշխատանքի համար նախատեսված սարքավորումների անվտանգության մասին» (ՄՄ ՏԿ 012/2011) Մաքսային միության տեխնիկական կանոնակարգ
3. Եվրասիական տնտեսական հանձնաժողովի խորհրդի 2013 թվականի հուլիսի 2-ի N 41 որոշմամբ հաստատված «Ավելցուկային ճնշման տակ աշխատող սարքավորումների անվտանգության մասին» (ՄՄ ՏԿ 032/2013) Մաքսային միության տեխնիկական կանոնակարգ
4. Մաքսային միության հանձնաժողովի 2011 թվականի հոկտեմբերի 18-ի N 824 որոշմամբ հաստատված «Վերելակների անվտանգություն» (ՄՄ ՏԿ 011/2011) Մաքսային միության տեխնիկական կանոնակարգ
5. Եվրասիական տնտեսական հանձնաժողովի խորհրդի 2012 թվականի հուլիսի 20-ի N 57 որոշմամբ հաստատված «Պայթուցիկ նյութերի և դրանց հիմքով արտադրատեսակների անվտանգության մասին» (ՄՄ ՏԿ 028/2012) Մաքսային միության տեխնիկական կանոնակարգ
6. Մաքսային միության հանձնաժողովի 2011 թվականի դեկտեմբերի 9-ի N 878 որոշմամբ հաստատված «Անհատական պաշտպանության միջոցների անվտանգության մասին» (ՄՄ ՏԿ 019/2011) Մաքսային միության տեխնիկական կանոնակարգ
(հավելվածը լրաց. 09.04.15 N 369-Ն, խմբ. 17.08.17 N 1020-Ն)
