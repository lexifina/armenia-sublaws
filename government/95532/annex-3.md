# Հավելված N 3 ՀՀ կառավարության 2015 թվականի հունվարի 30-ի N 71-Ն որոշման
Ց Ա Ն Կ
ԵՎՐԱՍԻԱԿԱՆ ՏՆՏԵՍԱԿԱՆ ՄԻՈՒԹՅԱՆ (ՄԱՔՍԱՅԻՆ ՄԻՈՒԹՅԱՆ) ՏԵԽՆԻԿԱԿԱՆ ԿԱՆՈՆԱԿԱՐԳԵՐԻ, ՈՐՈՆՑ ՊԱՀԱՆՋՆԵՐԻ ՊԱՀՊԱՆՄԱՆ ՆԿԱՏՄԱՄԲ ՊԵՏԱԿԱՆ ՎԵՐԱՀՍԿՈՂՈՒԹՅՈՒՆ ԻՐԱԿԱՆԱՑՆՈՂ ԼԻԱԶՈՐ ՄԱՐՄԻՆ Է ՍԱՀՄԱՆՎԵԼ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՏԱՐԱԾՔԱՅԻՆ ԿԱՌԱՎԱՐՄԱՆ ԵՎ ԱՐՏԱԿԱՐԳ ԻՐԱՎԻՃԱԿՆԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԱՇԽԱՏԱԿԱԶՄԻ ՊԵՏԱԿԱՆ ՀՐԴԵՀԱՅԻՆ ԵՎ ՏԵԽՆԻԿԱԿԱՆ ԱՆՎՏԱՆԳՈՒԹՅԱՆ ՏԵՍՉՈՒԹՅՈՒՆԸ
1. Մաքսային միության (Եվրասիական տնտեսական միության) հանձնաժողովի 2011 թվականի օգոստոսի 16-ի N 770 որոշմամբ հաստատված «Պիրոտեխնիկական (հրագործական) արտադրանքի անվտանգության մասին» Մաքսային միության տեխնիկական կանոնակարգ
2. Մաքսային միության (Եվրասիական տնտեսական միության) հանձնաժողովի 2011 թվականի հոկտեմբերի 18-ի N 825 որոշմամբ հաստատված «Պայթյունավտանգ միջավայրերում աշխատանքի համար նախատեսված սարքավորումների անվտանգության մասին» Մաքսային միության տեխնիկական կանոնակարգ
3. Մաքսային միության (Եվրասիական տնտեսական միության) հանձնաժողովի 2013 թվականի հուլիսի 2-ի N 41 որոշմամբ հաստատված «Բարձր ճնշման տակ աշխատող սարքավորումների անվտանգության մասին» Մաքսային միության տեխնիկական կանոնակարգ
4. Մաքսային միության (Եվրասիական տնտեսական միության) հանձնաժողովի 2011 թվականի հոկտեմբերի 18-ի N 824 որոշմամբ հաստատված «Վերելակների անվտանգության մասին» Մաքսային միության տեխնիկական կանոնակարգ
5. Մաքսային միության (Եվրասիական տնտեսական միության) հանձնաժողովի 2012 թվականի հուլիսի 20-ի N 57 որոշմամբ հաստատված «Պայթյունավտանգ նյութերի և դրանց հիման վրա պատրաստված արտադրանքի անվտանգության մասին» Մաքսային միության տեխնիկական կանոնակարգ
6. Մաքսային միության (Եվրասիական տնտեսական միության) հանձնաժողովի 2011 թվականի դեկտեմբերի 9-ի N 878 որոշմամբ հաստատված «Անձնական պաշտպանության միջոցների անվտանգության մասին» Մաքսային միության տեխնիկական կանոնակարգ
(հավելվածը լրաց. 09.04.15 N 369-Ն)
