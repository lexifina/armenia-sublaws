# Հավելված ՀՀ կառավարության 2011 թվականի օգոստոսի 25-ի N 1302-Ն որոշման
Ա Ն Հ Ա Տ Ա Կ Ա Ն Կ Ա Զ Մ
ՀԱՅ-ՎՐԱՑԱԿԱՆ ՊԵՏԱԿԱՆ ՍԱՀՄԱՆԻ «ԲԱԳՐԱՏԱՇԵՆ», «ԳՈԳԱՎԱՆ» ԵՎ «ԲԱՎՐԱ» ՍԱՀՄԱՆԱՅԻՆ ԱՆՑՄԱՆ ԿԵՏԵՐԻ ՇԻՆԱՐԱՐԱԿԱՆ ԱՇԽԱՏԱՆՔՆԵՐԻ ԻՐԱԿԱՆԱՑՄԱՆ ՆՊԱՏԱԿՈՎ ՍՏԵՂԾՎԱԾ ՄՐՑՈՒԹԱՅԻՆ ՀԱՆՁՆԱԺՈՂՈՎԻ
Գ. Խաչատրյան | - ՀՀ կառավարությանն առընթեր պետական եկամուտների կոմիտեի նախագահ (հանձնաժողովի նախագահ)
Ա. Բախշյան | - ՀՀ տարածքային կառավարման նախարարի տեղակալ
Լ. Շահվերդյան | - ՀՀ էներգետիկայի և բնական պաշարների նախարարի տեղակալ
Ռ. Սինոյան | - ՀՀ տրանսպորտի և կապի նախարարի տեղակալ
Ա. Պետրոսյան | - ՀՀ էկոնոմիկայի նախարարի տեղակալ
Շ. Քոչարյան | - ՀՀ արտաքին գործերի նախարարի տեղակալ
Ա. Բաղդասարյան | - ՀՀ գյուղատնտեսության նախարարության աշխատակազմի հողերի օգտագործման և մելիորացիայի վարչության մելիորացիայի բաժնի պետ
Գ. Քամալյան | - ՀՀ քաղաքաշինության նախարարության աշխատակազմի շինարարության քաղաքականության բաժնի պետ
Ռ. Աբովյան | - ՀՀ առողջապահության նախարարության պետական հիգիենիկ և հակահամաճարակային տեսչության վարակիչ և ոչ վարակիչ հիվանդությունների համաճարակաբանության բաժնի պետի տեղակալ
Հ. Հայրապետյան | - ՀՀ գյուղատնտեսության նախարարության սննդամթերքի անվտանգության պետական ծառայության պետի տեղակալ
Ա. Ավագյան | - ՀՀ կառավարությանն առընթեր ազգային անվտանգության ծառայության գլխավոր վարչության բաժնի պետ
Ա. Վարդանյան | - ՀՀ արտակարգ իրավիճակների նախարարության Հայաստանի փրկարար ծառայության աշխատակազմի նյութատեխնիկական ապահովման վարչության պետ
Ա. Գրիգորյան | - ՀՀ կառավարությանն առընթեր պետական եկամուտների կոմիտեի նախագահի խորհրդական (հանձնաժողովի քարտուղար)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար | Դ. Սարգսյան
