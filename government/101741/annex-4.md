# Հավելված N 4 ՀՀ կառավարության 2015 թվականի նոյեմբերի 12-ի N 1301-Ն որոշման
Կ Ա Ր Գ
ԵՐՐՈՐԴ ԵՐԿՐՆԵՐԻՑ ՔԱՂԱՔԱՑԻԱԿԱՆ ԵՎ ԾԱՌԱՅՈՂԱԿԱՆ ԶԵՆՔԻ, ԴՐԱ ՀԻՄՆԱԿԱՆ (ԲԱՂԿԱՑՈՒՑԻՉ) ՄԱՍԵՐԻ ՈՒ ՓԱՄՓՈՒՇՏՆԵՐԻ ՆԵՐԿՐՄԱՆ, ԱՐՏԱՀԱՆՄԱՆ ԵՎ (ԿԱՄ) ՏԱՐԱՆՑԻԿ ՓՈԽԱԴՐՄԱՆ ԵԶՐԱԿԱՑՈՒԹՅԱՆ (ԹՈՒՅԼԱՏՐՈՂ ՓԱՍՏԱԹՂԹԻ) ԼՐԱՑՄԱՆ
(վերնագիրը փոփ. 27.04.23 N 634-Ն)
1. Սույն կարգով կարգավորվում են Հայաստանի Հանրապետության մաքսային տարածք երրորդ երկրներից քաղաքացիական և ծառայողական զենքի, դրա հիմնական (բաղկացուցիչ) մասերի ու փամփուշտների ներկրման, արտահանման և (կամ) տարանցիկ փոխադրման համար տրվող եզրակացության (թույլատրող փաստաթղթի) (այսուհետ` եզրակացություն) լրացման հետ կապված հարաբերությունները:
(1-ին կետը փոփ. 27.04.23 N 634-Ն)
2. Եզրակացությունը տրվում է Եվրասիական տնտեսական միության արտաքին առևտրային գործունեության ապրանքների անվանացանկի մեկ ծածկագրով դասակարգվող ապրանքի համար` համաձայն Հայաստանի Հանրապետության կառավարության 2015 թվականի նոյեմբերի 12-ի N 1301-Ն որոշման N 2 հավելվածի:
3. Եզրակացության մեջ փոփոխություններ չեն կատարվում:
4. Եզրակացության մեջ փոփոխություններ կատարելու անհրաժեշտության դեպքում, սույն կարգին համապատասխան, լրացվում է նոր եզրակացություն` նախկին եզրակացությունն անվավեր ճանաչելով:
5. Տվյալների բացակայության դեպքում լրացման ենթակա տողի ամբողջ երկայնքով դրվում է գիծ:
6. Հաջորդ տողում լրացվում է եզրակացությունը տվող Եվրասիական տնտեսական միության անդամ պետության պետական լիազոր մարմնի անվանումը (օրինակ՝ Հայաստանի Հանրապետության ոստիկանություն (Полиция Республики Армения):
(6-րդ կետը փոփ. 15.04.22 N 497-Ն)
7. «Տրվել է (выдано)» տողում լրացվում է դիմումատու իրավաբանական անձի անվանումը, հարկ վճարողի հաշվառման համարը, գտնվելու վայրը, երկիրը, իսկ ֆիզիկական անձի դեպքում` անուն, հայրանուն, ազգանունը, հաշվառման վայրի հասցեն, երկիրը:
8. «Տեղափոխման ձևը (вид перемещения)» տողում լրացվում է տեղափոխման ձևը` ներկրում կամ արտահանում, ժամանակավոր ներկրում կամ ժամանակավոր արտահանում, տարանցիկ փոխադրում:
(8-րդ կետը փոփ. 27.04.23 N 634-Ն)
9. «Ապրանքի անվանումը (Наименование товара)» տողում լրացվում է տեղափոխվող քաղաքացիական և ծառայողական զենքի, դրա հիմնական (բաղկացուցիչ) մասերի ու փամփուշտների անվանումը` Հայաստանի Հանրապետության կառավարության 2015 թվականի նոյեմբերի 12-ի N 1301-Ն որոշման N 2 հավելվածով հաստատված` ԵԱՏՄ ԱՏԳ ԱԱ-ի ծածկագրին համապատասխան` նշելով քանակը և չափի միավորը: Այն դեպքում, երբ ապրանքի տեսականու վերաբերյալ ամբողջ տեղեկությունը չի տեղավորվում ապրանքի անվանման համար նախատեսված տողում, ապա այն ներկայացվում է եզրակացությանը կից հավելվածի տեսքով, որի մասին նշված տողում կատարվում է հետևյալ բովանդակությամբ գրառում. «Տես հավելվածը՝ _____ թերթ (см. приложение « » листах):
10. «Ստացողը/ուղարկողը (получатель/отправитель)» տողում լրացվում է ապրանքը ստացող կամ ուղարկող օտարերկրյա իրավաբանական անձի անվանումը, երկիրը, հասցեն: Նշված տողը լրացվում է Եվրասիական տնտեսական միության անդամ պետության եզրակացություն տվող պետական մարմնի հայեցողությամբ` հաշվի առնելով տեղափոխվող ապրանքատեսակներին ներկայացվող պահանջները:
11. «Նշանակման/ուղարկման երկիրը (Страна назначения/отправления)» տողում նշվում է նշանակման/ուղարկման վերջնական կետ հանդիսացող երկրի անվանումը:
12. «Ներկրման (արտահանման) նպատակը (Цель ввоза (вывоза)» տողում նշվում է ապրանքի հետ կապված հետևյալ նպատակային գործողություններից որևէ մեկը` ներկրում, արտահանում, ժամանակավոր ներկրում, ժամանակավոր արտահանում:
(12-րդ կետը փոփ. 27.04.23 N 634-Ն)
13. «Ժամանակավոր ներկրման (ժամանակավոր արտահանման) ժամկետը (Срок временного ввоза (вывоза)» տողում նշվում է ապրանքի ժամանակավոր ներկրման (ժամանակավոր արտահանման) պարտավորությունների դադարեցման ավարտի ամսաթիվը։
(13-րդ կետը փոփ. 27.04.23 N 634-Ն)
14. «Լրացուցիչ տեղեկություններ (Дополнительная информация)» տողում նշվում է եզրակացություն ստանալու համար ներկայացված դիմումի ամսաթիվը և գրանցման համարը, ինչպես նաև նախորդ տողերում նշված տեղեկությունների հստակեցմանն ուղղված պարզաբանումներ և այլ տեղեկություններ:
15. «Տարանցիկ երկիրը (Страна транзита)» տողում նշվում է Եվրասիական տնտեսական միության անդամ այն պետության անունը, որի տարածքով իրականացվելու է տարանցիկ փոխադրումը:
16. «Ստորագրությունը (Подпись) Ամսաթիվը (Дата)» տողում դրվում է Եվրասիական տնտեսական միության անդամ պետության պետական պաշտոնատար անձի անձնական ստորագրությունը, ով լիազորված է ստորագրել այդ փաստաթուղթը, և ամսաթիվը:
17. «Եզրակացությունն ուժի մեջ է մինչև (Заключение действительно по)» տողում նշվում է եզրակացության գործողության ավարտի ամսաթիվը:
18. «Ա. Ա. Հ. (Ф.И.О.)» և «Պաշտոնը (Должность)» տողերում լրացվում են եզրակացությունը ստորագրող Եվրասիական տնտեսական միության անդամ պետության պետական մարմնի պաշտոնատար անձի ազգանունը, անվան և հայրանվան սկզբնատառերը, պաշտոնը:
19. Եվրասիական տնտեսական միության անդամ պետության պետական պաշտոնատար անձի կողմից ստորագրված եզրակացությունը վավերացվում է պետական կառավարման լիազոր մարմնի կնիքով:
(հավելվածը լրաց. 15.12.16 N 1354-Ն, փոփ. 15.04.22 N 497-Ն, 27.04.23 N 634-Ն)
