«Հայաստանի փրկարար ծառայության մասին» Հայաստանի Հանրապետության օրենքի 41-րդ հոդվածի 1-ին մասին, 42-րդ և 43-րդ հոդվածներին համապատասխան` Հայաստանի Հանրապետության կառավարությունը որոշում է. 1. Սահմանել` ա) փրկարարական ծառայության ծառայողի պաշտոնային դրույքաչափը` ըստ պաշտոնների` համաձայն N 1 հավելվածի. բ) փրկարարական ծառայության կոչման հավելավճարի չափը` համաձայն N 2 հավելվածի. գ) փրկարարական ծառայության ծառայողին յուրաքանչյուր ամիս տրվող սննդի փոխհատուցման գումարի չափը` 10.000 դրամ: 2. Փրկարար ծառայության տեխնիկական սպասարկում իրականացնող անձանց դրույքաչափերը նշանակվում են հանրապետական գործադիր մարմինների տեխնիկական սպասարկում իրականացնող անձանց համար Հայաստանի Հանրապետության կառավարության կողմից սահմանված դրույքաչափերին համապատասխան: (2-րդ կետը փոփ. 20.12.12 N 1627-Ն) 3. Իրավունք վերապահել Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության փրկարար ծառայության տնօրենին Հայաստանի Հանրապետության պետական բյուջեով նախատեսված աշխատավարձի ֆոնդի սահմաններում փրկարար ծառայողներին և փրկարարի կոչում չունեցող աշխատողներին վճարելու լրավճարներ, հավելավճարներ և տալու պարգևավճարներ` Հայաստանի Հանրապետության կառավարության կողմից սահմանված չափով: (3-րդ կետը փոփ. 21.08.08 N 1042-Ն, խմբ. 21.10.10 N 1399-Ն, փոփ. 21.04.11 N 475-Ն, 20.12.12 N 1627-Ն) 3.1. Սահմանել, որ սույն որոշման 3-րդ կետում նախատեսված լրավճարների, հավելավճարների վճարումից և պարգևատրումները տալուց հետո տնտեսված գումարները բյուջետային տարվա վերջին օրը փոխանցվում են Հայաստանի Հանրապետության պետական բյուջե: (3.1-ին կետը լրաց. 21.10.10 N 1399-Ն) 3.2. Փրկարար ծառայության ծառայողների առողջության, տարիքի, ժամկետը լրանալու, հաստիքների կամ թվաքանակի կրճատման պատճառով ծառայությունից սահմանված կարգով արձակվելու, ինչպես նաև երկարամյա ծառայության կենսաթոշակի անցնելու դեպքում ծառայողներին դրամական օգնություն տրամադրելիս դրամական բավարարման հաշվարկման հիմք են ընդունվում սույն որոշման N 1.1 հավելվածով սահմանված մեծությունը և N 2 հավելվածով սահմանված կոչման հավելավճարը: (3.2-րդ կետը լրաց. 20.12.12 N 1627-Ն, խմբ. 27.06.13 N 660-Ն) 4. Սույն որոշումն ուժի մեջ է մտնում պաշտոնական հրապարակմանը հաջորդող օրվանից, և դրա գործողությունը տարածվում է 2006 թվականի հունվարի 1-ից հետո ծագած հարաբերությունների վրա։
