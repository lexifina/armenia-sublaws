# Հավելված N 2 ՀՀ կառավարության 2005 թվականի նոյեմբերի 9-ի N 1932-Ն որոշման
Ա Ն Հ Ա Տ Ա Կ Ա Ն Կ Ա Զ Մ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅՈՒՆՈՒՄ ԱՊՕՐԻՆԻ ՀԱՏՈՒՄՆԵՐԻ ԴԵՄ ՊԱՅՔԱՐԻ ԱՇԽԱՏԱՆՔՆԵՐԸ ՀԱՄԱԿԱՐԳՈՂ ԱՆՏԱՌՆԵՐԻ ՊԵՏԱԿԱՆ ՄՈՆԻԹՈՐԻՆԳԻ ԽՈՐՀՐԴԻ
Դ. Լոքյան | - ՀՀ գյուղատնտեսության նախարար (խորհրդի նախագահ)
Ս. Պապյան | - ՀՀ բնապահպանության նախարարի առաջին տեղակալ (խորհրդի նախագահի տեղակալ)
Գ. Մալխասյան | - ՀՀ արդարադատության նախարարի առաջին տեղակալ
Գ. Ասլանյան | - ՀՀ տարածքային կառավարման նախարարի տեղակալ
Ա. Աղաբեկյան | - ՀՀ պաշտպանության նախարարի տեղակալ, գեներալ-լեյտենանտ
Ս. Գալստյան | - ՀՀ գյուղատնտեսության նախարարի տեղակալ
Լ. Շահվերդյան | - ՀՀ էներգետիկայի նախարարի տեղակալ
Հ. Վարյան | - ՀՀ ոստիկանության պետի տեղակալ, ոստիկանության գեներալ-մայոր
Ա. Ալավերդյան | - ՀՀ կառավարությանն առընթեր հարկային պետական ծառայության պետի տեղակալ
Գ. Խաչատրյան | - ՀՀ կառավարությանն առընթեր մաքսային պետական կոմիտեի նախագահի տեղակալ
Մ. Մաթևոսյան | - «Հայանտառ» պետական ոչ առևտրային կազմակերպության տնօրեն
Ս. Սարգսյան | - «Կանաչազարդ երկիր» հասարակական կազմակերպության նախագահ (համաձայնությամբ)
Հ. Սանասարյան | - Կանաչների միության նախագահ (համաձայնությամբ)
Կ. Դանիելյան | - Հանուն կայուն մարդկային զարգացման ասոցիացիայի նախագահ (համաձայնությամբ)
Ա. Թարզյան | - «Բնության բարեկամներ» հասարակական կազմակերպության նախագահ (համաձայնությամբ)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
