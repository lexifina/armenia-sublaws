# Հավելված ՀՀ կառավարության 2015 թվականի դեկտեմբերի 24-ի N 1527-Ն որոշման
Կ Ա Ր Գ
ՄԻԱՍՆԱԿԱՆ ՍՈՑԻԱԼԱԿԱՆ ԾԱՌԱՅՈՒԹՅՈՒՆՆԵՐԻ ԿՈՂՄԻՑ ԻՐԱԿԱՆԱՑՎՈՂ ՓՈՐՁԱՔՆՆՈՒԹՅՈՒՆՆԵՐԻՆ ՓՈՐՁԱՔՆՆՈՒԹՅՈՒՆ ԱՆՑՆՈՂ ԱՆՁԱՆՑ ԿՈՂՄԻՑ ԻՐԵՆՑ ԸՆՏՐԱԾ ԲՈՒԺՈՂ ԲԺԻՇԿՆԵՐԻՆ ԿԱՄ ԱՅԼ ԲԺԻՇԿ ՄԱՍՆԱԳԵՏՆԵՐԻՆ ՈՐՊԵՍ ՆԵՐԿԱՅԱՑՈՒՑԻՉ ՆԵՐԳՐԱՎԵԼՈՒ
(վերնագիրը փոփ. 25.03.21 N 396-Ն)
1. Սույն կարգով կարգավորվում են միասնական սոցիալական ծառայությունների կողմից իրականացվող փորձաքննություններին փորձաքննություն անցնող անձանց կողմից իրենց ընտրած բուժող բժիշկներին կամ այլ բժիշկ մասնագետներին որպես ներկայացուցիչ ներգրավելու հետ կապված հարաբերությունները:
(1-ին կետը փոփ. 25.03.21 N 396-Ն)
2. Միասնական սոցիալական ծառայության կողմից իրականացվող փորձաքննություններին փորձաքննվող անձանց կողմից իրենց ընտրած բուժող բժիշկներին կամ այլ բժիշկ մասնագետներին որպես ներկայացուցիչ ներգրավելու հնարավորության մասին փորձաքննվող անձը կամ նրա օրինական ներկայացուցիչն իրազեկվում է բժշկասոցիալական փորձաքննության դիմումը ներկայացնելիս:
(2-րդ կետը փոփ. 25.03.21 N 396-Ն)
3. Միասնական սոցիալական ծառայություն դիմելուց հետո եռօրյա ժամկետում փորձաքննվող անձը կամ նրա օրինական ներկայացուցիչը միասնական սոցիալական ծառայությանը տրամադրում է (գրավոր և (կամ) էլեկտրոնային փոստով և (կամ) հեռախոսազանգով) իր ներկայացուցչի տվյալները (անունը, ազգանունը, հայրանունը, պաշտոնը, մասնագիտացումը, աշխատանքի վայրը, մշտական բնակության վայրի հասցեն, հեռախոսահամարը):
(3-րդ կետը փոփ. 25.03.21 N 396-Ն)
4. Բժշկասոցիալական փորձաքննության ժամանակ փորձաքննվող անձի ներկայացուցիչն ունի օրենքով իրեն վերապահված իրավունքներ և պարտականություններ:
5. Փորձաքննվող անձի ներկայացուցչի մասնակցությունն անձի փորձաքննությանը գրանցվում է այդ նպատակի համար նախատեսված լիազոր մարմնի կողմից հաստատված գրանցամատյանում և ստորագրվում նրա կողմից:
(հավելվածը փոփ. 25.03.21 N 396-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Դ. Հարությունյան
