# Հավելված ՀՀ կառավարության 2015 թվականի հունիսի 4-ի N 592-Ն որոշման
ԺԱՄԱՆԱԿԱՎՈՐ ՊԱՀՊԱՆՈՒԹՅԱՆ ՊԱՀԵՍՏՆԵՐԻՆ ԵՎ մաքսային պահեստներին ՆԵՐԿԱՅԱՑՎՈՂ ՊԱՀԱՆՋՆԵՐԸ (վերնագիրը լրաց. 05.04.18 N 388-Ն, փոփ. 16.09.21 N 1530-Ն)
1. Ժամանակավոր պահպանության բաց տեսակի պահեստի ընդհանուր մակերեսը պետք է լինի առնվազն 10000 քառ. մետր, այդ թվում՝ փակ տարածքներինը` 2000 քառ. մետր: Ժամանակավոր պահպանության փակ տեսակի պահեստի ընդհանուր մակերեսը պետք է լինի առնվազն 5000 քառ. մետր, այդ թվում` փակ տարածքներինը` 1000 քառ. մետր:
(1-ին կետը փոփ. 05.04.18 N 388-Ն)
1.1. Բաց տեսակի մաքսային պահեստների ընդհանուր մակերեսը պետք է լինի առնվազն 1000 քառ. մետր, իսկ փակ տեսակի մաքսային պահեստների ընդհանուր մակերեսը՝ առնվազն 200 քառ. մետր:
(1.1-ին կետը լրաց. 05.04.18 N 388-Ն, փոփ. 16.09.21 N 1530-Ն)
2. Սույն պահանջների 1-ին կետում նշված չափանիշների պահպանման համար ըստ Հայաստանի Հանրապետության մարզերի սահմանվում են գոտիականության հետևյալ չափանիշները՝
1) Երևան քաղաք, Հայաստանի Հանրապետության Արագածոտնի, Կոտայքի, Արմավիրի և Արարատի մարզեր՝ 100 տոկոս.
2) Հայաստանի Հանրապետության Շիրակի, Լոռու, Տավուշի, Գեղարքունիքի, Վայոց ձորի և Սյունիքի մարզեր՝ 50 տոկոս:
3. Սույն պահանջների կիրառման առումով՝ փակ տարածքում ներառվում են`
1) ժամանակավոր պահպանության պահեստի, մաքսային պահեստի, ազատ պահեստի կազմակերպչի վարչական ապարատի զբաղեցրած տարածքը.
2) ապրանքի պահպանության համար նախատեսված պահեստային շինության տարածքը.
3) փակ շինության` զննման համար նախատեսված տարածքը.
4) մաքսային մարմիններին հատկացված տարածքը.
5) մաքսային ներկայացուցիչների և ինքնահայտարարագրման գրասենյակի տարածքը.
6) այլ տարածքներ:
(3-րդ կետը լրաց., փոփ. 05.04.18 N 388-Ն)
4. Ժամանակավոր պահպանության պահեստի կազմակերպիչը պետք է ապահովի`
1) ժամանակավոր պահպանության ամբողջ տարածքում կատարվող գործողությունները հեռակառավարվող տեսախցիկներով տեսագրելու և ձայնագրելու հնարավորություն, ընդ որում, տեսագրված և ձայնագրված նյութերը պետք է պահպանվեն յուրաքանչյուր օրվա համար առանձին` համակարգչում կամ ցանկացած արտաքին կրիչի վրա, որը հնարավորություն կընձեռի պարզորոշ դիտելու և լսելու կատարված տեսագրությունն ու ձայնագրությունը` համարակալելով ըստ այդ օրերի ամսաթվերի: Տեսագրություններում պետք է նշվեն նաև տեսագրման ամսաթիվը և ժամը: Տեսագրված և ձայնագրված նյութերը պետք է պահպանվեն կազմակերպչի մոտ` առնվազն 90 օր.
2) կշռելու հնարավորություն ունեցող էլեկտրոնային (առնվազն 15000 գործարքի հիշողությամբ) տարբեր կշեռքների առկայությունը, այդ թվում` ավտոմեքենաներ կշռող` առնվազն 80 տոննա, իսկ երկաթգծի առկայության դեպքում` առնվազն 150 տոննա կշռելու հնարավորություն ունեցող կշեռք.
3) փոսորակների, հարթակների, փակ շինությունների (անգարների) առկայությունը`
ա. սույն պահանջների 2-րդ կետի 1-ին ենթակետում նշված վայրերում գործող ժամանակավոր պահպանության պահեստների դեպքում՝ առնվազն 5 ավտոմեքենայի միաժամանակյա զննման համար.
բ. սույն պահանջների 2-րդ կետի 2-րդ ենթակետում նշված վայրերում գործող ժամանակավոր պահպանության պահեստների դեպքում՝ առնվազն մեկ ավտոմեքենայի զննման համար.
4) մանրակրկիտ զննման համար անհրաժեշտ սարքերի ու սարքավորումների ներդրումը (ռենտգենային, ռադիոակտիվ միջոցների հայտնաբերման և այլն)` վերադաս մաքսային մարմնի սահմանած պահանջներին համապատասխան.
5) մաքսային մարմինների աշխատողներին անհրաժեշտ կապի և էլեկտրոնային տեխնիկական սարքավորումների տրամադրումը, ինտերնետային և ռադիոհեռահաղորդման կապով ապահովումը` մաքսային ձևակերպումները տեղում կազմակերպելու համար.
6) իր կողմից մատուցվող ծառայությունների դիմաց սահմանված սակագների մասին տեղեկատվության հրապարակայնությունը` վերադաս մաքսային մարմնի սահմանած կարգով.
7) ապրանքների բեռնման-բեռնաթափման համար անհրաժեշտ տրանսպորտային միջոցների և բեռների տեղափոխման կամ փոխադրման համար անհրաժեշտ այլ տեխնիկական միջոցների առկայությունը.
8) ժամանակավոր պահպանության պահեստի գործունեության վայրում հսկիչ-դրամարկղային մեքենայի առկայությունը:
(4-րդ կետը փոփ. 05.04.18 N 388-Ն)
5. Սույն հավելվածի 1-ին, 2-րդ և 4-րդ կետերով սահմանված պահանջները տարածվում են նաև մաքսային պահեստների կազմակերպիչների նկատմամբ, եթե այդպիսի մաքսային պահեստները հանդիսանում են ժամանակավոր պահպանության վայրեր:
(5-րդ կետը լրաց. 05.04.18 N 388-Ն)
(հավելվածը փոփ., լրաց. 05.04.18 N 388-Ն, փոփ. 16.09.21 N 1530-Ն)
