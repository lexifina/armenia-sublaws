# Հավելված N 1 ՀՀ կառավարության 2006 թվականի նոյեմբերի 30-ի N 1679-Ն որոշման

Ա. Դարբինյան | - ՀՀ բնապահպանության նախարարի տեղակալ (հանձնաժողովի նախագահ)
Ս. Բարսեղյան | - ՀՀ տարածքային կառավարման նախարարի տեղակալ
Ք. Նուրիջանյան | - ՀՀ Նախագահի վերահսկողական ծառայության 1-ին բաժնի վարիչ
Ա. Աշուղյան | - ՀՀ առևտրի և տնտեսական զարգացման նախարարության աշխատակազմի բնօգտագործման էկոնոմիկայի և հանքային արդյունաբերության վարչության պետ
Հ. Ավետիսյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի ընդերքի պահպանության վարչության պետ
Ե. Տերտերյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի Երկրաբանական գործակալության պետ
Գ. Ադիբեկյան | - ՀՀ առևտրի և տնտեսական զարգացման նախարարության աշխատակազմի Կոնցեսիոն գործակալության պարտավորությունների կատարման հսկողության բաժնի պետ
