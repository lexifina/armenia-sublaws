# Հավելված N 1 ՀՀ կառավարության 2016 թվականի հոկտեմբերի 27-ի N 1109-Ն որոշման
Ց Ա Ն Կ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՊԵՏԱԿԱՆ ԻՇԽԱՆՈՒԹՅԱՆ ՄԱՐՄԻՆՆԵՐԻ ՍՊԱՍԱՐԿՄԱՆ ԳՐԱՍԵՆՅԱԿՆԵՐԻ ԳՈՐԾԱՌՈՒՅԹՆԵՐ ԻՐԱԿԱՆԱՑՆՈՂ ՕՊԵՐԱՏՈՐՆԵՐԻ
1. «ՀԱՅՓՈՍՏ» փակ բաժնետիրական ընկերություն
2. «ԱՐԴՇԻՆԲԱՆԿ» փակ բաժնետիրական ընկերություն
3. «ԱՄԵՐԻԱԲԱՆԿ» փակ բաժնետիրական ընկերություն
4. «ԿՈՆՎԵՐՍ ԲԱՆԿ» փակ բաժնետիրական ընկերություն
5. «Անելիք բանկ» փակ բաժնետիրական ընկերություն
6. «Հայէկոնոմբանկ» բաց բաժնետիրական ընկերություն
7. ԱՐԱՐԱՏԲԱՆԿ բաց բաժնետիրական ընկերություն
8. Հայաստանի Հանրապետության կառավարությանն առընթեր անշարժ գույքի կադաստրի պետական կոմիտե
9. «Մոբի Դրամ» փակ բաժնետիրական ընկերություն
10. «Յունիբանկ» բաց բաժնետիրական ընկերություն:
(հավելվածը լրաց. 26.01.17 N 41-Ն, 23.06.17 N 712-Ն, 01.02.18 N 70-Ն, 04.10.18 N 1083-Ն)
