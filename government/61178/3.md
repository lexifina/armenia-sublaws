3. Սահմանել, որ`
1) սույն որոշմամբ սահմանված կարգով չհաշվառվելու (միայն տրանսպորտային միջոցի նկատմամբ սեփականության իրավունքը «Ճանապարհային երթևեկության անվտանգության ապահովման մասին» Հայաստանի Հանրապետության օրենքի 13-րդ հոդվածով սահմանված կարգով գրանցվելու), տրանսպորտային միջոցը հաշվառումից ժամանակավոր հանվելու, ինչպես նաև խոտանման հիմքով տրանսպորտային միջոցը հաշվառումից հանվելու դեպքում համապատասխան տրանսպորտային միջոցը համարվում է «Ավտոտրանսպորտային միջոցների օգտագործումից բխող պատասխանատվության պարտադիր ապահովագրության մասին» Հայաստանի Հանրապետության օրենքի իմաստով պետական հաշվառումից հանված (չհաշվառված).
2) տրանսպորտային միջոցի նկատմամբ սեփականության իրավունքը «Ճանապարհային երթևեկության անվտանգության ապահովման մասին» Հայաստանի Հանրապետության օրենքի 13-րդ հոդվածով սահմանված կարգով գրանցելու, սակայն չհաշվառելու դեպքում տրանսպորտային միջոցի սեփականատիրոջը (ներկայացուցչին) տրանսպորտային միջոցը կայանման վայր տեղափոխելու համար տրվում են մեկօրյա ժամկետով «ժամանակավոր» համարանիշեր.
3) տրանսպորտային միջոցի նկատմամբ սեփականության իրավունքը գրանցված, սակայն չհաշվառված տրանսպորտային միջոցը պետական գրանցումից հանելու կամ հաշվառման ներկայացնելու նպատակով տրանսպորտային միջոցի սեփականատիրոջը (ներկայացուցչին) տրանսպորտային միջոցը կայանման վայրից տեղափոխելու համար տրվում են մեկօրյա ժամկետով «ժամանակավոր» համարանիշեր:
(3-րդ կետը խմբ. 21.04.11 N 618-Ն, փոփ. 15.03.12 N 306-Ն, 26.09.19 N 1335-Ն)
3.1. Սահմանել, որ Հայաստանի Հանրապետության ներքին գործերի նախարարության ստորաբաժանումները, տրանսպորտային միջոցի պետական գրանցման և պետական հաշվառման գործողություններ կատարելիս, տվյալ գործողության կատարմանը նախորդող ժամանակահատվածի համար ավտոտրանսպորտային միջոցի օգտագործումից բխող պատասխանատվության պարտադիր ապահովագրության պայմանագրի կամ կտրոնի առկայությունը չեն ստուգում:
(3.1-ին կետը լրաց. 15.03.12 N 306-Ն, փոփ. 05.09.24 N 1419-Ն)
3.2. Սահմանել, որ`
1) որոշման N 11 հավելվածում նշված՝ 11-րդ և 12-րդ տեսակների հաշվառման համարանիշերը հատկացվում են Հայաստանի Հանրապետության ներքին գործերի նախարարության կողմից.
2) որոշման N 11 հավելվածում նշված՝ 22-րդ, 22.1-ին, 23-րդ, 24-րդ, 25-րդ, 26-րդ, 29.2-րդ և 29.3-րդ տեսակների հաշվառման համարանիշերը հատկացվում են Հայաստանի Հանրապետության պաշտպանության նախարարության կողմից.
3) որոշման N 11 հավելվածում նշված մյուս տեսակների հաշվառման համարանիշերը հատկացվում են Հայաստանի Հանրապետության ներքին գործերի նախարարության կողմից, բացառությամբ որոշման N 11 հավելվածում նշված՝ 30-րդ, 30.1-ին և 32-րդ տեսակների հաշվառման համարանիշերի, որոնք կարող են հատկացվել նաև տրանսպորտային միջոցների առևտրային գործունեություն իրականացնող տնտեսավարող սուբյեկտների և մաքսային մարմինների կողմից:
4) (ենթակետն ուժը կորցրել է 12.04.24 N 503-Ն)
(3.2-րդ կետը լրաց. 19.03.14 N 343-Ն, փոփ. 11.05.18 N 569-Ն, լրաց. 29.08.19 N 1133-Ն, փոփ. 26.09.19 N 1335-Ն, լրաց. 24.08.22 N 1321-Ն, փոփ. 01.12.22 N 1834-Ն, 12.04.24 N 503-Ն, 05.09.24 N 1419-Ն)
3.3. Սահմանել, որ Հայաստանի Հանրապետության պետական կամ տեղական ինքնակառավարման մարմիններին, կազմակերպություններին պատկանող հափշտակված տրանսպորտային միջոցները՝ հետախուզում հայտարարվելու դեպքում սահմանված կարգով ժամանակավոր (մինչև հայտնաբերումը) դուրս են գրվում տվյալ պետական կամ տեղական ինքնակառավարման մարմնի կամ կազմակերպության հաշվեկշռից:
(3.3-րդ կետը լրաց. 04.06.15 N 621-Ն)
3.4. Սահմանել, որ Հայաստանի Հանրապետության ներքին գործերի նախարարության ստորաբաժանումները, տրանսպորտային միջոցի պետական գրանցման և պետական հաշվառման գործողություններ կատարելիս, փոխադրամիջոցի (տրանսպորտային միջոցի) գույքահարկի պարտավորությունների ամբողջական կատարման փաստը հավաստող փաստաթուղթ չեն պահանջում, եթե տրանսպորտային միջոցի գույքահարկի պարտավորությունների ամբողջական կատարման վերաբերյալ տեղեկատվությունը հասանելի է էլեկտրոնային առցանց եղանակով։
(3.4-րդ կետը լրաց. 10.03.22 N 308-Ն, փոփ. 05.09.24 N 1419-Ն)
3.5. Սահմանել, որ`
1) սույն որոշման իմաստով հաշվառման վկայագիր է հանդիսանում նաև դրա թվային տարբերակը (թվային հաշվառման վկայագիր), որը սույն որոշմամբ սահմանված N 7 հավելվածով նկարագրված հաշվառման վկայագրի փոխարեն կամ այն տրամադրելու հետ միաժամանակ հասանելի է դարձվում տրանսպորտային միջոցի սեփականատիրոջը.
2) թվային հաշվառման վկայագիրը հասանելի է Հայաստանի Հանրապետության ներքին գործերի նախարարության պաշտոնական կայքում՝ նույնականացման քարտի (ID) կամ բջջային նույնականացման քարտի (Mobile ID) միջոցով (խիստ նույնականացում)` «ԵսԵմ» ազգային նույնականացման հարթակում նույնականացում անցնելուց հետո կամ ծառայությունների մատուցման համար ստեղծված պետական բջջային հավելվածի միջոցով.
3) միայն թվային հաշվառման վկայագիր ունեցող տրանսպորտային միջոցի սեփականատերը (ներկայացուցիչը) ցանկացած ժամանակ կարող է Հայաստանի Հանրապետության ներքին գործերի նախարարության հաշվառման-քննական գործառույթ իրականացնող տարածքային ցանկացած ստորաբաժանումից ստանալ սույն որոշման N 7 հավելվածին համապատասխան հաշվառման վկայագիր.
4) տրանսպորտային միջոցի հաշվառման գործողության ժամանակ միայն թվային հաշվառման վկայագիր ստանալու ցանկություն հայտնելու դեպքում տպագրման սրահում հաշվառման վկայագրի տպագրման պատվեր չի տրվում, իսկ տրանսպորտային միջոցի հաշվառման գործողության ժամանակ հաշվառման վկայագիրը ներկայացնելու պահանջը չի տարածվում միայն թվային հաշվառման վկայագիր ունեցող անձանց վրա։
(3.5-րդ կետը լրաց. 08.05.25 N 570-Ն)
3․6․ Սահմանել, որ՝
1) Հայաստանի Հանրապետությունում գրանցված (հաշվառված) այն տրանսպորտային միջոցները, որոնց համար 2023 թվականի հոկտեմբերի 1-ից սկսած չի կնքվել ավտոտրանսպորտային միջոցների օգտագործումից բխող պատասխանատվության պարտադիր ապահովագրության պայմանագիր, և այդ տրանսպորտային միջոցով կատարված որևէ իրավախախտման դեպք չի արձանագրվել, և դրանք չեն անցել տեխնիկական զննություն, և դրանց համար փոխադրամիջոցների գույքահարկ (գույքահարկ) չի վճարվել, և տրանսպորտային միջոցների սեփականության իրավունքի պետական գրանցման և պետական հաշվառման (վերահաշվառման) էլեկտրոնային ռեգիստրում որևէ գործողություն չի կատարվել, սեփականատիրոջ դիմում-հայտարարության (ձև N 1) հիման վրա համարել 2023 թվականի հոկտեմբերի 1-ի դրությամբ խոտանված և հանել տրանսպորտային միջոցների սեփականության իրավունքի պետական գրանցման և պետական հաշվառման (վերահաշվառման) համակարգչային շտեմարանի գործող հատվածից․
2) սույն կետի 1-ին ենթակետի գործողությունը չի տարածվում այն տրանսպորտային միջոցների վրա, որոնց վերջին սահմանահատումը, Հայաստանի Հանրապետության սահմանային էլեկտրոնային կառավարման տեղեկատվական համակարգի տվյալների համաձայն, 2023 թվականի հոկտեմբերի 1-ից սկսած Հայաստանի Հանրապետությունից ելքի սահմանահատում է․
3) սույն կետի 1-ին ենթակետով նախատեսված տրանսպորտային միջոցներն ի հայտ գալու (ավտոտրանսպորտային միջոցների օգտագործումից բխող պատասխանատվության պարտադիր ապահովագրության պայմանագիր կնքվելու կամ դրանով իրավախախտում կատարվելու կամ տեխնիկական զննություն անցնելու կամ դրանց համար փոխադրամիջոցների գույքահարկ (գույքահարկ) վճարվելու կամ տրանսպորտային միջոցների սեփականության իրավունքի պետական գրանցման և պետական հաշվառման (վերահաշվառման) էլեկտրոնային ռեգիստրում որևէ գործողություն կատարվելու կամ դրա օգտագործումը որևէ այլ կերպ փաստվելու) դեպքում այդ տրանսպորտային միջոցները վերադարձվում են տրանսպորտային միջոցների սեփականության իրավունքի պետական գրանցման և պետական հաշվառման (վերահաշվառման) համակարգչային շտեմարանի գործող հատված։
(3.6-րդ կետը լրաց. 30.07.26. N 1116-Ն)
