# Հավելված N 2 ՀՀ կառավարության 2006 թվականի դեկտեմբերի 21-ի N 1851-Ն որոշման
Հայաստանի Հանրապետության 2007 թվականի պետական բյուջեի եկամուտների հավաքագրման եռամսյակային բաշխումն՝ Ըստ եկամուտների ձեվավորման աղբյուրների դասակարգման առանձին խմբերի
(Հավելվածը փոփ. 15.02.07 N 173-Ն, 03.05.07 N 519-Ն, 31.05.07 N 692-Ն, 14.06.07 N 732-Ն, 02.08.07 N 855-Ն, 11.10.07 N 1166-Ն, 11.10.07 N 1219-Ն, 27.12.07 N 1606-Ն)
