# Հավելված N 5 Աղյուսակ N 01-01 - Աղյուսակ N 14-06
(N 03-03 աղյուսակը փոփ. 26.04.07 N 621-Ն)
Աղյուսակ N 15
Հայաստանի Հանրապետության 2007 թվականի պետական բյուջեի կատարման եռամսյակային (աճողական) համամասնություններԸ կապիտալ ծախսերի գծով ԸՍՏ ծրագրերի եվ կատարողների (առանց նպատակային վարկերի եվ դրամաշնորհների, Երեվանի համաքաղաքային նշանակության ծախսերի եվ Մեծ Բրիտանիայի ու Հյուսիսային ԻռլանԴիայի Միացյալ Թագավորության կողմից Հայաստանի ՀանրապետությանԸ ֆինանսական օգնության կարգով տրամադրված նվիրաբերության միջոցների հաշվին 2007 թվականին իրականացվելիք ծախսերի)
(Աղյուսակը փոփ. 08.02.07 N 301-Ն, 15.03.07 N 374-Ն, 05.04.07 N 540-Ն, 17.05.07 N 584-Ն, 24.05.07 N 602-Ն, 26.07.07 N 846-Ն, 02.08.07 N 857-Ն, 02.08.07 N 858-Ն, 02.08.07 N 859-Ն, 16.08.07 N 918-Ն, 16.08.07 N 919-Ն)
Աղյուսակ N 16
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ 2007 ԹՎԱԿԱՆԻ ՊԵՏԱԿԱՆ ԲՅՈՒՋԵՈՎ ՆԱԽԱՏԵՍՎԱԾ ՕՏԱՐԵՐԿՐՅԱ ՊԵՏՈՒԹՅՈՒՆՆԵՐԻ ԵՎ ՄԻՋԱԶԳԱՅԻՆ ՖԻՆԱՆՍԱԿԱՆ ԿԱԶՄԱԿԵՐՊՈՒԹՅՈՒՆՆԵՐԻ ԱՋԱԿՑՈՒԹՅԱՄԲ ԻՐԱԿԱՆԱՑՎՈՂ ՎԱՐԿԱՅԻՆ ԾՐԱԳՐԵՐԻ ԵՌԱՄՍՅԱԿԱՅԻՆ (ԱՃՈՂԱԿԱՆ) ՀԱՄԱՄԱՍՆՈՒԹՅՈՒՆՆԵՐԸ
(Աղյուսակը փոփ. 01.02.07 N 132-Ն)
Աղյուսակ N 17
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ 2007 ԹՎԱԿԱՆԻ ՊԵՏԱԿԱՆ ԲՅՈՒՋԵՈՎ ՆԱԽԱՏԵՍՎԱԾ ՕՏԱՐԵՐԿՐՅԱ ՊԵՏՈՒԹՅՈՒՆՆԵՐԻ ԵՎ ՄԻՋԱԶԳԱՅԻՆ ՖԻՆԱՆՍԱԿԱՆ ԿԱԶՄԱԿԵՐՊՈՒԹՅՈՒՆՆԵՐԻ ԱՋԱԿՑՈՒԹՅԱՄԲ ԻՐԱԿԱՆԱՑՎՈՂ ԴՐԱՄԱՇՆՈՐՀԱՅԻՆ ԾՐԱԳՐԵՐԻ ԵՌԱՄՍՅԱԿԱՅԻՆ (ԱՃՈՂԱԿԱՆ) ՀԱՄԱՄԱՍՆՈՒԹՅՈՒՆՆԵՐԸ
Աղյուսակ N 18
«Հայաստանի Հանրապետության 2007 թվականի պետական բյուջեի մասին» ՀՀ օրենքով նախատեսված պետական նշանակության ավտոճանապարհների պահպանման եվ շահագործման ծախսերի եռամսյակային (աճողական) համամասնությունները
(Աղյուսակը փոփ. 17.05.07 N 584-Ն)
Աղյուսակ N 19
«Հայաստանի Հանրապետության 2007 թվականի պետական բյուջեի մասին» ՀՀ օրենքով նախատեսված այն ծրագրերի, որոնց գծով հատկացումների գԼԽավոր կարգադրիչ հանդիսացող համապատասխան պետական կառավարման մարմինների կողմից այդ հատկացումների գումարներԸ տնՏեսվարող սուբյեկտներին սույն որոշման համաձայն տրամադրվելու են դրամաշնորհների տեսքով` առանց մրցույթի
Աղյուսակ N 20
Հայաստանի Հանրապետության 2007 թվականի պետական բյուջեով նախատեսված Մեծ ԲրիՏանիայի եվ Հյուսիսային Իռլանդիայի Միացյալ Թագավորության կողմից Հայաստանի Հանրապետությանը ֆինանսական օգնության կարգով տրամադրված նվիրաբերության միջոցների հաշվին իրականացվող ՀՀ Գեղարքունիքի եվ Տավուշի մարզերում մարզային զարգացման ծրագրի գծով նախատեսված հատկացումների եռամսյակային (աճողական) համամասնություններն ըստ առանձին միջոցառումների եվ օբյեկտների
(Աղյուսակը փոփ. 23.08.07 N 954-Ն)
Աղյուսակ N 21
«Հայաստանի Հանրապետության 2007 թվականի պետական բյուջեի մասին» ՀՀ օրենքի N 1 հավելվածով «Հայաստանի Հանրապետության համայնքային բյուջեներին սուբվենցիաների տրամադրում» ծրագրով սահմանված հատկացումների եռամսյակային (աճողական) համամասնություններն՝ ըստ առանձին համայնքների, տրամադրման նպատակների եվ տրամադրող պետական կառավարման մարմինների
(Աղյուսակը խմբ.15.02.07 N 157-Ն)
Աղյուսակ N 22
Երեվանի համաքաղաքային նշանակության ծախսերի եռամսյակային (աճողական) համամասնություններն՝ ըստ ուղղությունների
(Աղյուսակը փոփ. 15.02.07 N 173-Ն, 14.06.07 N 732-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
