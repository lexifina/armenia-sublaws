# Հավելված N 2 ՀՀ կառավարության 2006 թվականի դեկտեմբերի 21-ի N 1851-Ն որոշման

(Հավելվածը փոփ. 15.02.07 N 173-Ն, 03.05.07 N 519-Ն, 31.05.07 N 692-Ն)
