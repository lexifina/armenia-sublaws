# Հավելված N 5 ՀՀ կառավարության 2006 թվականի դեկտեմբերի 21-ի N 1851-Ն որոշման
Աղյուսակ N 1
Հայաստանի ՀանրաՊետության 2007 թվականի պետական բյուջեով նախատեսված հատկացումների կատարման եռամսյակային (աճողական) համամասնություններն ըստ բյուջետային ծախսերի գործառական դասակարգման խմբերի եվ ենթախմբերի, ֆինանսավորվող ծրագրերի, դրանք իրականացնող մարմինների (Աղյուսակը փոփ. 11.01.07 N 18-Ն, 18.01.07 N 66-Ն)
