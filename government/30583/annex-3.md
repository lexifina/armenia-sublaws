# Հավելված N 3 ՀՀ կառավարության 2006 թվականի դեկտեմբերի 21-ի N 1851-Ն որոշման
Հայաստանի Հանրապետության 2007 թվականի պետական բյուջեով նաԽատեսված հատկացումների կատարման եռամսյակային (աճողական) համամասնություններն ըստ բյուջետային ծաԽսերի գործառական դասակարգման Խմբերի եվ ենթաԽմբերի
(Հավելվածը փոփ. 15.02.07 N 173-Ն, 22.02.07 N 193-Ն, 03.05.07 N 519-Ն, 31.05.07 N 692-Ն, 14.06.07 N 732-Ն)
