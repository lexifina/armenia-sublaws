# Հավելված մայրության նպաստն անկանխիկ եղանակով վճարելու ծառայությունների մատուցման մասին պայմանագրի
Ց Ա Ն Կ
ՎՃԱՐՄԱՆ ՑՈՒՑԱԿՈՒՄ ՆԵՐԱՌՎՈՂ ՏՎՅԱԼՆԵՐԻ
1. Բանկի անվանումը
2. Շահառուի անունը, ազգանունը (հայրանունը), անձը հաստատող փաստաթղթի սերիան և համարը, հանրային ծառայությունների համարանիշը կամ հանրային ծառայությունների համարանիշ չստանալու մասին տեղեկանքի համարը
3. Շահառուի բանկային հաշվի համարը (միայն այն դեպքում, երբ մայրության նպաստը վճարվում է մայրության նպաստն անկանխիկ եղանակով վճարելու ծառայությունների մատուցման մասին պայմանագրի 2-րդ կետի 1-ին ենթակետի հիման վրա)
4. Վճարման ենթակա նպաստի գումարի չափը
