# Հավելված N 2 ՀՀ կառավարության 2007 թվականի նոյեմբերի 8-ի N 1301-Ն որոշման
Կ Ա Ր Գ
ՎՐԱՀՈՒՂԱՐԿԱՎՈՐՄԱՆ
1. Սույն կարգով uահմանվում է վրահուղարկավորման կազմակերպման կարգը:
2. Նոր հուղարկավորության կազմակերպումը ստանձնած անձի ցանկությամբ և գերեզման օգտագործողի համաձայնությամբ վրահուղարկավորումն իրականացվում է տվյալ գերեզմանում նախկինում մահացածի թաղումից առնվազն տասնհինգ տարի հետո` Հայաստանի Հանրապետության կառավարության 2006 թվականի նոյեմբերի 23-ի N 1910-Ն որոշմամբ սահմանված կարգով:
(2-րդ կետը խմբ. 31.03.22 N 425-Ն)
3. Վրահուղարկավորումը թույլատրում է գերեզմանատան տնօրինությունը` մահացածի հուղարկավորության կազմակերպումն ստանձնողի դիմումի, գերեզման օգտագործողի համաձայնության, մահացածի մահվան վկայականի, նախկինում մահացածի մահվան վկայականի, գերեզմանի վկայականի և բնակչության սանիտարահամաճարակային անվտանգության ապահովման և հանրային առողջապահության բնագավառում գործունեություն իրականացնող Հայաստանի Հանրապետության առողջապահության նախարարության ենթակայության պետական կազմակերպության (այսուհետ՝ պետական կազմակերպություն) կողմից տրված վրահուղարկավորում իրականացնելու հնարավորության մասին եզրակացության հիման վրա` եզրակացությունն ստանալուց հետո մեկօրյա ժամկետում:
(3-րդ կետը փոփ. 30.11.17 N 1514-Ն, փոփ., լրաց. 31.03.22 N 425-Ն, խմբ. 31.07.25 N 1064-Ն)
4. Վրահուղարկավորում իրականացնելու հնարավորության կամ անհնարինության մասին եզրակացություն ստանալու համար գերեզմանատան տնօրինությունը վրահուղարկավորում իրականացնելու թույլտվության դիմումի ստացման օրը կից գրությամբ էլեկտրոնային եղանակով պետական կազմակերպություն է ներկայացնում մահացածի հուղարկավորության կազմակերպումն ստանձնողի դիմումը, մահացածի մահվան վկայականը, նախկինում մահացածի մահվան վկայականը և գերեզմանի վկայականը` դրանք ուղարկելով պետական կազմակերպության պաշտոնական էլեկտրոնային փոստի հասցեով։
(4-րդ կետը փոփ. 30.11.17 N 1514-Ն, փոփ., լրաց. 31.03.22 N 425-Ն, խմբ. 31.07.25 N 1064-Ն)
4.1. Պետական կազմակերպությունը սույն կարգի 4-րդ կետում նշված գերեզմանատան տնօրինության գրությունն ստանալու պահից մեկ օրվա ընթացքում վրահուղարկավորում իրականացնելու հնարավորության կամ անհնարինության մասին եզրակացությունը ներկայացնում է գերեզմանատան տնօրինություն էլեկտրոնային եղանակով` ուղարկելով գերեզմանատան տնօրինության պաշտոնական էլեկտրոնային փոստի հասցեով։
(4.1-ին կետը լրաց. 31.07.25 N 1064-Ն)
4.2. Պետական կազմակերպության կողմից տրվում է վրահուղարկավորում իրականացնելու անհնարինության մասին եզրակացությունը, եթե՝
1) տվյալ գերեզմանում նախկինում մահացածի թաղումից չի անցել առնվազն տասնհինգ տարի.
2) նախկինում մահացածի կամ վրահուղարկավորման ենթակա մահացածի մահվան պատճառը եղել է մարդու համար ախտածնության I-II խմբերի միկրոօրգանիզմներով (ժանտախտի, խոլերայի, դեղին տենդի) հարուցված վարակներից որևէ մեկը.
3) սույն կարգի 4-րդ կետով սահմանված փաստաթղթերն ամբողջական կամ ընթեռնելի չլինելու դեպքում։
(4.2-րդ կետը լրաց. 31.07.25 N 1064-Ն)
4.3. Սույն կարգի 4.2-րդ կետով սահմանված վրահուղարկավորում իրականացնելու անհնարինության հիմքերի բացակայության դեպքում պետական կազմակերպության կողմից տրվում է վրահուղարկավորում իրականացնելու հնարավորության մասին եզրակացությունը։
(4.3-րդ կետը լրաց. 31.07.25 N 1064-Ն)
4.4. Պետական կազմակերպության կողմից վրահուղարկավորում իրականացնելու հնարավորության կամ անհնարինության մասին եզրակացությունը տրվում է անվճար։
(4.4-րդ կետը լրաց. 31.07.25 N 1064-Ն)
5. (կետն ուժը կորցրել է 31.07.25 N 1064-Ն)
6. Վրահուղարկավորումը թույլատրվում է միայն բաց և մասնակի փակ գերեզմանատներում:
7. Աճյունասափորը (մահացածի մարմնի դիակիզումից հետո) ընտանեկան գերեզմանում` վրահուղարկավորման միջոցով տեղադրելու համար հատկացվում է նախկինում մահացածի գերեզմանի տարածքից 1 քառ. մետր տարածք:
8. Գերեզմանատան տնօրինությունը մահվան վկայականի հիման վրա թաղումների և գերեզմանատեղերի գրանցման մատյանում և գերեզմանի վկայականում կատարում է համապատասխան գրանցումներ վրահուղարկավորման մասին:
(հավելվածը փոփ. 30.11.17 N 1514-Ն, փոփ., խմբ., լրաց. 31.03.22 N 425-Ն, 31.07.25 N 1064-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
