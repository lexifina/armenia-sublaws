19 նոյեմբերի 2014 թվականի N 1300-Ն
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ 2014 ԹՎԱԿԱՆԻ ՊԵՏԱԿԱՆ ԲՅՈՒՋԵՈՒՄ ԵՎ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆ 2013 ԹՎԱԿԱՆԻ ԴԵԿՏԵՄԲԵՐԻ 19-Ի N 1414-Ն ՈՐՈՇՄԱՆ ՄԵՋ ՓՈՓՈԽՈՒԹՅՈՒՆՆԵՐ ՈՒ ԼՐԱՑՈՒՄՆԵՐ ԿԱՏԱՐԵԼՈՒ ՄԱՍԻՆ (վերնագիրը խմբ. 25.12.14 N 1532-Ն)
Համաձայն «Հայաստանի Հանրապետության 2014 թվականի պետական բյուջեի մասին» Հայաստանի Հանրապետության օրենքի 9-րդ հոդվածի 12-րդ մասի, Հայաստանի Հանրապետության կառավարության 2014 թվականի օգոստոսի 7-ի N 821-Ն որոշման 5-րդ կետի 3-րդ ենթակետի և Հայաստանի Հանրապետության կառավարության 1999 թվականի հունիսի 10-ի N 404 որոշմանը համապատասխան՝ Հայաստանի Հանրապետության կառավարությունը որոշում է.
