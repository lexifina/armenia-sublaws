# Հավելված ՀՀ կառավարության 2019 թվականի դեկտեմբերի 26-ի N 1936-Ն որոշման
Կ Ա Ր Գ
«ՊԵՏԱԿԱՆ ՏՈՒՐՔԻ ՄԱՍԻՆ» ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՕՐԵՆՔԻ 29-ՐԴ ՀՈԴՎԱԾԻ ԱՌԱՋԻՆ ՊԱՐԲԵՐՈՒԹՅԱՆ «Զ» ԿԵՏՈՎ ՆԱԽԱՏԵՍՎԱԾ ԱՐՏՈՆՈՒԹՅՈՒՆՆԵՐԻ ԿԻՐԱՌՄԱՆ ԺԱՄԿԵՏՆԵՐԻ, ԱՎԻԱՓՈԽԱԴՐՈՂԻ, ՉՎԵՐԹՆԵՐԻ ՀԱՃԱԽԱԿԱՆՈՒԹՅԱՆ ՊԱՀԱՆՋՆԵՐԻ ԵՎ ՉՍՊԱՍԱՐԿՎՈՂ ՈՒՂՂՈՒԹՅԱՆ ՎԵՐԱԲԵՐՅԱԼ ԵՎ ԱՅԼ ԱՆՀՐԱԺԵՇՏ ՏԵՂԵԿԱՏՎՈՒԹՅԱՆ ՀՐԱՊԱՐԱԿՄԱՆ
1. Սույն կարգով կարգավորվում են «Պետական տուրքի մասին» Հայաստանի Հանրապետության 1997 թվականի դեկտեմբերի 27-ի ՀՕ-186 օրենքի 29-րդ հոդվածի առաջին պարբերության «զ» կետով նախատեսված արտոնությունների կիրառման ժամկետների, ավիափոխադրողի, չվերթերի հաճախականության պահանջների և չսպասարկվող ուղղության վերաբերյալ և այլ անհրաժեշտ տեղեկատվության հրապարակման կարգի հետ կապված հարաբերությունները:
2. Սույն կարգի իմաստով չսպասարկված ուղղություններ են համարվում այն օդանավակայանները, որտեղ ցանկացած ավիաընկերության կողմից իրականացված չվերթերի քանակը միաժամանակ IATA ամառային ժամանակահատվածում (մարտի վերջին կիրակի օրվանից ներառյալ հոկտեմբերի վերջին շաբաթ օրը) չի գերազանցում 14-ը և IATA ձմեռային ժամանակահատվածում՝ (հոկտեմբերի վերջին կիրակի օրվանից ներառյալ մարտի վերջին շաբաթ օրը) 10-ը:
3. Չվերթերի հաճախականության նվազագույն պահանջներն են՝ ավիափոխադրողները չվերթի մեկնարկի օրվանից IATA ամառային և IATA ձմեռային ժամանակահատվածում իրականացնում են առնվազն 40 չվերթ: Նշված քանակից նվազեցվում են անհաղթահարելի ուժի հետևանքով չիրականացված չվերթերը։
(3-րդ կետը խմբ. 11.06.26 N 825-Ն)
4. Ավիափոխադրողներին տրամադրված արտոնությունների վերաբերյալ տեղեկատվությունը հրապարակվում է «Ավիացիայի մասին» օրենքով սահմանված Հայաստանի Հանրապետությունում ավիացիայի (բացառությամբ ռազմականի) բնագավառի քաղաքականությունը մշակող և իրականացնող նախարարության (այսուհետ՝ լիազոր մարմին) կայքում։
(4-րդ կետը փոփ. 08.08.24 N 1234-Ն, խմբ. 11.06.26 N 825-Ն)
5. Օրենքով 36 ամսով տրված արտոնության ժամկետը մինչև երկու անգամ ներառյալ 24 ամսով երկարաձգելու հարցը պետք է քննարկվի լիազոր մարմնի կողմից՝ հիմք ընդունելով տվյալ ուղղությամբ մեկնող ուղևորներին տրամադրվող արտոնության արդյունքում ուղևորահոսքի ցուցանիշը, ինչպես նաև տնտեսության վրա նշված ցուցանիշի ունեցած ազդեցության վերաբերյալ Հայաստանի Հանրապետության էկոնոմիկայի նախարարության եզրակացությունը։
(5-րդ կետը փոփ. 08.08.24 N 1234-Ն, խմբ. 23.04.25 N 487-Ն, 11.06.26 N 825-Ն)
(հավելվածը փոփ. 08.08.24 N 1234-Ն, խմբ. 23.04.25 N 487-Ն, 11.06.26 N 825-Ն)
