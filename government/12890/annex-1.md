# Հավելված ՀՀ կառավարության 2004 թվականի սեպտեմբերի 9-ի N 1272-Ն որոշման
Կ Ա Զ Մ
ԱՍԻԱԿԱՆ ՍԵՅՍՄՈԼՈԳԻԱԿԱՆ ՀԱՆՁՆԱԺՈՂՈՎԻ 5-ՐԴ ՄԻՋԱԶԳԱՅԻՆ ԳԱԳԱԹՆԱԺՈՂՈՎԻ ԿԱԶՄԱԿԵՐՊՉԱԿԱՆ ՀԱՆՁՆԱԺՈՂՈՎԻ ՀԱՅԿԱԿԱՆ ԿՈՂՄԻ
Ս. Բալասանյան | - | Հայկական սեյսմոլոգիայի և երկրի ֆիզիկայի ասոցիացիայի նախագահ (հանձնաժողովի նախագահ, համաձայնությամբ)
Ա. Թանանյան | - | ՀՀ կառավարությանն առընթեր արտակարգ իրավիճակների վարչության պետի տեղակալ (հանձնաժողովի համանախագահ)
Ա. Առաքելյան | - | ՀՀ Ազգային ժողովի պատգամավոր (համաձայնությամբ)
Ս. Օհանյան | - | ՀՀ կառավարության աշխատակազմի քաղաքաշինության և բնական ռեսուրսների վարչության պետ
Ա. Անտոնյան | - | ՀՀ կառավարությանն առընթեր արտակարգ իրավիճակների վարչության «Սեյսմիկ պաշտպանության ազգային ծառայություն» գործակալության պետ
Ա. Ավանեսյան | - | Հայկական սեյսմոլոգիայի և երկրի ֆիզիկայի ասոցիացիայի գլխավոր գիտական քարտուղար (համաձայնությամբ)
Ա. Ավետիսյան | - | Երևանի պետական համալսարանի միջազգային կապերի գծով պրոռեկտոր
Ա. Արշակյան | - | Երևանի Վ. Բրյուսովի անվան պետական լեզվաբանական համալսարանի առաջին պրոռեկտոր
Ա. Բաղդասարյան | - | Հայկական սեյսմոլոգիայի և երկրի ֆիզիկայի ասոցիացիայի ֆինանսական մենեջեր (համաձայնությամբ)
Մ. Գրիգորյան | - | Երևանի պետական համալսարանի երկրաբանական ֆակուլտետի դեկան
Գ. Թադևոսյան | - | Հայաստանի շինարարների ասոցիացիայի նախագահի խորհրդական (համաձայնությամբ)
Հ. Կաջոյան | - | Հայկական սեյսմոլոգիայի և երկրի ֆիզիկայի ասոցիացիայի անդամ (համաձայնությամբ)
Բ. Հարությունյան | - | «Կուրորտաբանության և ֆիզիկական բժշկության գիտահետազոտական ինստիտուտ» ՓԲԸ-ի տնօրեն
Հ. Մաթևոսյան | - | ՀՀ կառավարությանն առընթեր արտակարգ իրավիճակների վարչության ճգնաժամային իրավիճակների կառավարման ինստիտուտի ռեկտոր
Ս. Նազարեթյան | - | ՀՀ կառավարությանն առընթեր արտակարգ իրավիճակների վարչության «Սեյսմիկ պաշտպանության հյուսիսային ծառայություն» պետական ոչ առևտրային կազմակերպության գործադիր տնօրեն
Վ. Պողոսյան | - | Հայաստանի շինարարների ասոցիացիայի «Երևանշին» ԲԲԸ-ի գլխավոր տնօրեն (համաձայնությամբ)
Կ. Սարաֆյան | - | «Հայսեյսմշին և կառուցվածքների պաշտպանության գիտահետազոտական ինստիտուտ» ՓԲԸ-ի կենտրոնի պետ
Հ. Պետրոսյան | - | ՀՀ կառավարությանն առընթեր անշարժ գույքի կադաստրի պետական կոմիտեի «Գեոդեզիայի և քարտեզագրման կենտրոն» պետական ոչ առևտրային կազմակերպության գործադիր տնօրեն
Ա. Մելիքսեթյան | - | Հայկական սեյսմոլոգիայի և երկրի ֆիզիկայի ասոցիացիայի գործադիր տնօրեն, հանձնաժողովի պատասխանատու քարտուղար (համաձայնությամբ)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
