# Հավելված ՀՀ կառավարության 2018 թվականի ապրիլի 26-ի N 498-Ն որոշման
Կ Ա Ր Գ
ՔԱՂԱՔԱՑԻՈՒԹՅԱՆ ՀԱՐՑԵՐՈՎ ՄԻՋԳԵՐԱՏԵՍՉԱԿԱՆ ՀԱՆՁՆԱԺՈՂՈՎԻ ԿԱԶՄԱՎՈՐՄԱՆ ԵՎ ԳՈՐԾՈՒՆԵՈՒԹՅԱՆ
1. Սույն կարգով կանոնակարգվում են Քաղաքացիության հարցերով միջգերատեսչական հանձնաժողովի (այսուհետ՝ հանձնաժողով) կազմավորման և գործունեության կազմակերպման հետ կապված հարաբերությունները։
2. Հանձնաժողովը խորհրդակցական մարմին է, որի գործունեության նպատակը Հայաստանի Հանրապետության քաղաքացիություն ստանալու կամ դադարեցնելու վերաբերյալ դիմումների կապակցությամբ, ինչպես նաև «Քաղաքացիության մասին» օրենքի 23-րդ հոդվածի 2-րդ մասով սահմանված կարգով քաղաքացիությունը դադարեցնելու վերաբերյալ միգրացիայի և քաղաքացիության բնագավառում պետական կառավարման լիազոր մարմնի (այսուհետ՝ ծառայություն) եզրակացությունների քննարկումն է, դրանց վերաբերյալ ամփոփ եզրակացություններ կազմելը և դրանք ծառայություն ներկայացնելը:
(2-րդ կետը փոփ. 25.07.19 N 945-Ն, փոփ., լրաց. 20.07.23 N 1192-Ն)
3. Հանձնաժողովն իր գործունեության ընթացքում ղեկավարվում է Հայաստանի Հանրապետության օրենսդրությամբ:
4. Հանձնաժողովը կազմված է հանձնաժողովի ղեկավարից, անդամներից և քարտուղարից։ Հանձնաժողովի կազմում ընդգրկվում են Հայաստանի Հանրապետության վարչապետի աշխատակազմի, Հայաստանի Հանրապետության արդարադատության նախարարության, Հայաստանի Հանրապետության պաշտպանության նախարարության, Հայաստանի Հանրապետության արտաքին գործերի նախարարության, ներքին գործերի նախարարության և Հայաստանի Հանրապետության ազգային անվտանգության ծառայության ներկայացուցիչներ։
(4-րդ կետը խմբ. 25.07.19 N 945-Ն, փոփ. 20.07.23 N 1192-Ն)
5. Հանձնաժողովի կազմը հաստատում է Հայաստանի Հանրապետության վարչապետը։
(5-րդ կետը փոփ. 25.07.19 N 945-Ն)
6. Հանձնաժողովի կազմում ընդգրկված անձինք հանձնաժողովի աշխատանքներին մասնակցում են հասարակական հիմունքներով:
6.1. Հայաստանի Հանրապետության քաղաքացիություն ստանալու կամ դադարեցնելու վերաբերյալ դիմումների կապակցությամբ, ինչպես նաև «Քաղաքացիության մասին» օրենքի 23-րդ հոդվածի 2-րդ մասով սահմանված կարգով քաղաքացիությունը դադարեցնելու վերաբերյալ ծառայության կազմած եզրակացությունները հանձնաժողովում քննարկվում են դրանք ստանալուց հետո 10 աշխատանքային օրվա ընթացքում:
(6.1-ին կետը լրաց. 19.03.20 N 341-Ն, փոփ., լրաց. 20.07.23 N 1192-Ն)
7. Հանձնաժողովի գործառույթների իրականացումն ապահովվում է էլեկտրոնային ընթացակարգերի միջոցով, բացառությամբ այն դեպքերի, երբ հանձնաժողովի ղեկավարն իր նախաձեռնությամբ կամ հանձնաժողովի անդամներից մեկի միջնորդությամբ հրավիրում է հանձնաժողովի նիստ:
(7-րդ կետը խմբ. 19.03.20 N 341-Ն)
7.1 Հանձնաժողովի քարտուղարը ծառայության կողմից կազմված բոլոր եզրակացությունների ուսումնասիրության արդյունքում կազմում է ամփոփ հաշվետվություն և, խորհրդակցելով հանձնաժողովի ղեկավարի հետ, հաշվետվությունը և քվեարկության դրվող հարցերն էլեկտրոնային եղանակով ներկայացնում է հանձնաժողովի անդամների պաշտոնական էլեկտրոնային հասցեներին: Հաշվետվության մեջ ներառվում է ծառայության կողմից ներկայացված քաղաքացիություն ստանալու և դադարեցնելու վերաբերյալ բացասական եզրակացությունների ընդհանուր թիվը, համապատասխան դիմումը չբավարարելու իրավական հիմքը և հնարավոր վիճահարույց գործերի վերաբերյալ տեղեկատվություն, իսկ «Քաղաքացիության մասին» օրենքի 23-րդ հոդվածի 2-րդ մասով սահմանված կարգով քաղաքացիությունը դադարեցնելու վերաբերյալ եզրակացության առկայության դեպքում՝ քաղաքացիության դադարեցման գործընթաց հարուցելու իրավական հիմքը և գործընթացի ընթացքի վերաբերյալ տեղեկատվություն:
(7.1-ին կետը լրաց. 19.03.20 N 341-Ն, փոփ., խմբ. 20.07.23 N 1192-Ն)
7.2. Հանձնաժողովի անդամները սույն կարգի 7.1-ին կետով սահմանված կարգով ամփոփ հաշվետվությունն ստանալու պահից երեք աշխատանքային օրվա ընթացքում լրացնում և ստորագրում են քվեաթերթիկը (Ձև N 1)՝ էլեկտրոնային եղանակով ուղարկելով հանձնաժողովի մյուս անդամներին և քարտուղարին:
(7.2-րդ կետը լրաց. 19.03.20 N 341-Ն, 14.01.21 N 24-Ն)
8. Հանձնաժողովի նիստ հրավիրվելու դեպքում նիստի հրավիրման օրվա, վայրի և ժամանակի մասին հանձնաժողովի քարտուղարը հանձնաժողովի անդամներին ծանուցում է նիստից առնվազն 3 օր առաջ:
(8-րդ կետը խմբ. 19.03.20 N 341-Ն)
9. (կետն ուժը կորցրել է 19.03.20 N 341-Ն)
10. Հանձնաժողովի նիստերը հրավիրում և անցկացնում է հանձնաժողովի ղեկավարը, իսկ նրա բացակայության դեպքում` հանձնաժողովի անդամներից մեկը` մեծամասնության համաձայնությամբ:
(10-րդ կետը փոփ. 14.01.21 N 24-Ն)
11. Հանձնաժողովը կարող է որոշում ընդունել, եթե քվեարկությանը մասնակցել են հանձնաժողովի անդամների կեսից ավելին: Հանձնաժողովի որոշումներն ընդունվում են քվեարկությանը մասնակցող հանձնաժողովի անդամների ձայների պարզ մեծամասնությամբ: Հավասար ձայների դեպքում վճռորոշ է հանձնաժողովի ղեկավարի ձայնը: Հանձնաժողովի քարտուղարը քվեարկությանը չի մասնակցում:
(11-րդ կետը խմբ. 19.03.20 N 341-Ն)
12. Քվեարկության վերաբերյալ հանձնաժողովի քարտուղարի կողմից կազմվում է արձանագրություն և եզրակացություն: Արձանագրությունն ստորագրվում է հանձնաժողովի ղեկավարի և քարտուղարի կողմից, որից հետո այն հանձնաժողովի եզրակացության, ծառայության կողմից կազմված եզրակացությունների ու հանձնաժողովի անդամների ստորագրած քվեաթերթիկների հետ` ներկայացվում են ծառայություն:
(12-րդ կետը խմբ. 19.03.20 N 341-Ն, 14.01.21 N 24-Ն, փոփ. 20.07.23 N 1192-Ն)
