# Հավելված N 2 ՀՀ կառավարության 2002 թվականի նոյեմբերի 21-ի N 1809-Ն որոշման

I. Կառուցվածքային ստորաբաժանումներ
- Տրանսպորտի վարչություն
- Կապի և տեղեկատվայնացման վարչություն
- Ճանապարհային ոլորտի քաղաքականության վարչություն
- Երկաթուղու վարչություն
- Փոստի վարչություն
- Արտաքին կապերի և ծրագրերի վարչություն
- Ֆինանսատնտեսագիտական և հաշվապահական հաշվառման վարչություն
- Իրավաբանական վարչություն
- Ներքին աուդիտի բաժին
- Քարտուղարություն
- Անձնակազմի կառավարման բաժին
- Հասարակության հետ կապերի բաժին
- Առաջին բաժին
- Զորահավաքային նախապատրաստության և քաղաքացիական պաշտպանության բաժին
- Ճանապարհային ոլորտը կարգավորող բաժին
Առանձնացված ստորաբաժանումներ
- Հայաստանի Հանրապետության տրանսպորտային տեսչություն
- Լիցենզավորման գործակալություն
(հավելվածը փոփ. 30.01.03 N 70-Ն, լրաց. 15.05.03 N 786-Ն, փոփ. 02.12.04 N 1800-Ն, լրաց. 14.04.05 N 451-Ն, խմբ. 03.06.10 N 756-Ն, լրաց. 05.05.11 N 541-Ն, փոփ., խմբ. 14.07.11 N 1029-Ն, փոփ., լրաց. 13.03.14 N 268-Ն)
