1. Սահմանել հանրապետական գործադիր մարմիններում հայեցողական պաշտոններ զբաղեցնող, ինչպես նաև հանրապետական գործադիր մարմինների և մարզպետարանների աշխատակազմերում քաղաքացիական աշխատանք կատարող և տեխնիկական սպասարկում իրականացնող անձանց նվազագույն պաշտոնային դրույքաչափերը` համաձայն N 1 հավելվածի:
(1-ին կետը խմբ. 11.05.06 N 894-Ն, 10.05.07 N 610-Ն, փոփ. 01.11.07 N 1263-Ն, 06.12.12 N 1527-Ն)
1.1. Սահմանել Հայաստանի Հանրապետության կառավարությանն առընթեր Հայաստանի Հանրապետության ոստիկանությունում (այսուհետ` ոստիկանություն) տեխնիկական սպասարկում իրականացնող անձանց և ոստիկանության (զինվորական) կոչում չունեցող աշխատողների նվազագույն պաշտոնային դրույքաչափերը՝ համաձայն N 2 հավելվածի:
(1.1-ին կետը լրաց. 01.11.07 N 1263-Ն)
1.2. Սահմանել ոստիկանությունում աշխատած տարիների համար ոստիկանությունում տեխնիկական սպասարկում իրականացնող անձանց և ոստիկանության (զինվորական) կոչում չունեցող աշխատողների պաշտոնային դրույքաչափերի նկատմամբ նախատեսվող հավելումները՝ համաձայն N 3 հավելվածի։
(1.2-րդ կետը լրաց. 01.11.07 N 1263-Ն)
1.3. Սույն որոշման 1.1-ին կետով նախատեսված անձանց Հայաստանի Հանրապետության պետական բյուջեով նախատեսված աշխատավարձի ֆոնդի սահմաններում կամ աշխատավարձի ֆոնդի տնտեսված միջոցների հաշվին պաշտոնային դրույքաչափերից բարձր աշխատավարձ նշանակելու, բարեխիղճ աշխատանքի համար խրախուսելու, ինչպես նաև առողջության համար վնասակար կամ առողջության համար առանձնապես վնասակար կամ առանձնապես ծանր աշխատանքի կատարման համար սույն որոշման 3.3-րդ կետով նախատեսված չափերով հավելումներ վճարելու իրավունքները վերապահել Հայաստանի Հանրապետության ոստիկանության պետին:
(1.3-րդ կետը լրաց. 01.11.07 N 1263-Ն)
