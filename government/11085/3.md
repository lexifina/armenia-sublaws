3. Իրավունք վերապահել հանրապետական գործադիր մարմինների ղեկավարներին, մարզպետներին, Հայաստանի Հանրապետության դատական դեպարտամենտի ղեկավարին, Հայաստանի Հանրապետության դատական դեպարտամենտի առանձնացված ստորաբաժանումների ղեկավարներին Հայաստանի Հանրապետության պետական բյուջեով նախատեսված աշխատավարձի ֆոնդի սահմաններում սահմանել հանրապետական գործադիր մարմիններում հայեցողական պաշտոններ զբաղեցնող, հանրապետական գործադիր մարմինների և մարզպետարանների աշխատակազմերում քաղաքացիական աշխատանք կատարող, ինչպես նաև հանրապետական գործադիր մարմինների, մարզպետարանների աշխատակազմերում, Հայաստանի Հանրապետության դատական դեպարտամենտում տեխնիկական սպասարկում իրականացնող անձանց նվազագույն պաշտոնային դրույքաչափից բարձր դրույքաչափ:
(3-րդ կետը խմբ. 11.05.06 N 894-Ն, փոփ. 10.05.07 N 610-Ն, խմբ. 17.01.08 N 33-Ն, փոփ. 06.12.12 N 1527-Ն)
3.1. Իրավունք վերապահել հանրապետական գործադիր մարմինների ղեկավարներին, մարզպետներին, Հայաստանի Հանրապետության դատական դեպարտամենտի ղեկավարին, Հայաստանի Հանրապետության դատական դեպարտամենտի առանձնացված ստորաբաժանումների ղեկավարներին աշխատավարձի ֆոնդի տնտեսված միջոցների հաշվին խրախուսել հանրապետական գործադիր մարմիններում հայեցողական պաշտոններ զբաղեցնող, հանրապետական գործադիր մարմինների և մարզպետարանների աշխատակազմերում քաղաքացիական աշխատանք կատարող, հանրապետական գործադիր մարմինների, մարզպետարանների աշխատակազմերում, Հայաստանի Հանրապետության դատական դեպարտամենտում տեխնիկական սպասարկում իրականացնող անձանց` բարեխիղճ աշխատանքի համար:
(3.1-ին կետը լրաց. 11.05.06 N 894-Ն, փոփ. 10.05.07 N 610-Ն, խմբ. 17.01.08 N 33-Ն, փոփ. 06.12.12 N 1527-Ն)
3². Հանրապետական գործադիր մարմիններում հայեցողական պաշտոններ զբաղեցնողներին, հանրապետական գործադիր մարմինների ղեկավարների տեղակալների օգնականներին տրվում է լրացուցիչ միանվագ արձակուրդային վճար` միջին ամսական աշխատավարձի չափով:
(3² կետը լրաց. 11.05.06 N 894-Ն, փոփ. 10.05.07 N 610-Ն)
3.2.1. ոստիկանությունում տեխնիկական սպասարկում իրականացնող անձանց և ոստիկանության (զինվորական) կոչում չունեցող աշխատողներին տրվում է լրացուցիչ միանվագ արձակուրդային վճար` պաշտոնային դրույքաչափի չափով:
(3.2.1-ին կետը լրաց. 01.11.07 N 1263-Ն)
3.3. Հանրապետական գործադիր մարմիններում հայեցողական պաշտոններ զբաղեցնող, հանրապետական գործադիր մարմինների և մարզպետարանների աշխատակազմերում քաղաքացիական աշխատանք կատարող, ինչպես նաև հանրապետական գործադիր մարմինների, մարզպետարանների աշխատակազմերում, Հայաստանի Հանրապետության դատական դեպարտամենտում տեխնիկական սպասարկում իրականացնող անձանց առողջության համար վնասակար աշխատանքի կատարման դեպքում տալ հավելում` պաշտոնային դրույքաչափի 12 տոկոսի չափով, առողջության համար առանձնապես վնասակար և առանձնապես ծանր աշխատանքի կատարման դեպքում` պաշտոնային դրույքաչափի 24 տոկոսի չափով, իսկ բարձր լեռնային վայրերում աշխատելու դեպքում` պաշտոնային դրույքաչափի 20 տոկոսի չափով, բայց ոչ ավելի, քան Հայաստանի Հանրապետությունում սահմանված նվազագույն ամսական աշխատավարձի ութապատիկը:
(3.3-րդ կետը լրաց. 11.05.06 N 894-Ն, փոփ. 10.05.07 N 610-Ն, խմբ. 17.01.08 N 33-Ն, փոփ. 06.12.12 N 1527-Ն)
