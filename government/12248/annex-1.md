# Հավելված ՀՀ կառավարության 2004 թվականի մարտի 25-ի N 372-Ն որոշման
Կ Ա Ր Գ
ՍԵԼԵԿՑԻՈՆ ՆՎԱՃՄԱՆ ԱՐՏՈՆԱԳՐԻ ԽՆԴՐԱՐԿՄԱՆ ՀԱՅՏԻ ԿՐԿՆԱԿԱՆ ՓՈՐՁԱՔՆՆՈՒԹՅԱՆ ԱՆՑԿԱՑՄԱՆ
(վերնագիրը փոփ. 02.03.17 N 202-Ն)
I. ԸՆԴՀԱՆՈՒՐ ԴՐՈՒՅԹՆԵՐ
1. Սելեկցիոն նվաճման արտոնագրի խնդրարկման հայտի (այսուհետ` հայտ) կրկնական փորձաքննությունն անցկացնում է Հայաստանի Հանրապետության գյուղատնտեսության նախարարությունը (այսուհետ` լիազորված մարմին)` հայտի ընդունման օրվանից հետո «Սելեկցիոն նվաճումների պահպանության մասին» Հայաստանի Հանրապետության օրենքի 9-րդ հոդվածի 8-րդ կետով և 10-րդ հոդվածի 1-ին կետով սահմանված ժամկետներում:
(1-ին կետը փոփ. 02.03.17 N 202-Ն)
2. Կրկնական փորձաքննության ընդունվող հայտի առաջնայնության ժամկետը համարվում է առաջին հայտը լիազորված մարմին ներկայացնելու օրը:
(2-րդ կետը փոփ. 02.03.17 N 202-Ն)
II. ՀԱՅՏԻ ԿՐԿՆԱԿԱՆ ՓՈՐՁԱՔՆՆՈՒԹՅՈՒՆԸ
(վերնագիրը փոփ. 02.03.17 N 202-Ն)
3. Հայտի կրկնական փորձաքննություն է նշանակվում լիազորված մարմնի ղեկավարի որոշմամբ՝ առաջին հայտի նյութերի հիման վրա՝ հետևյալ փաստաթղթերի առկայության դեպքում`
ա) հայտատուի դիմումը հայտի կրկնական փորձաքննություն նշանակելու մասին.
բ) լիազորված մարմնի որոշումը սելեկցիոն նվաճմանն արտոնագիր տալը մերժելու մասին:
(3-րդ կետը փոփ. 02.03.17 N 202-Ն)
III. ՀԱՅՏԱՏՈՒԻ ԻՐԱՎՈՒՆՔՆԵՐԸ
4. Հայտը կրկնական փորձաքննության և դրան կից փաստաթղթերը լիազորված մարմին ներկայացնելու իրավունք ունի սելեկցիոները, նրա կողմից լիազորված անձը:
(4-րդ կետը փոփ. 02.03.17 N 202-Ն)
5. Հայտատուն կրկնական փորձաքննության ընթացքում իր նախաձեռնությամբ կամ լիազորված մարմնի հարցման հիման վրա իրավունք ունի`
ա) հայտին կից փաստաթղթերում կատարելու ուղղումներ, լրացումներ կամ այլ փոփոխություններ, եթե դրանք չեն փոխում սելեկցիոն նվաճման էությունը.
բ) անձամբ կամ լիազորված անձի միջոցով մասնակցելու հայտի կրկնական փորձաքննության ընթացքում առաջացող հարցերի քննարկմանը.
գ) ծանոթանալու հայտի կրկնական փորձաքննության արդյունքներին:
(5-րդ կետը փոփ. 02.03.17 N 202-Ն)
IV. ՀԱՅՏԻ ԿՐԿՆԱԿԱՆ ՓՈՐՁԱՔՆՆՈՒԹՅԱՆ ԿԱԶՄԱԿԵՐՊՄԱՆ ԸՆԹԱՑԱԿԱՐԳԸ
(վերնագիրը փոփ. 02.03.17 N 202-Ն)
6. Լիազորված մարմինը հայտն ընդունելուց հետո մեկամսյա ժամկետում կազմակերպում է հայտի կրկնական փորձաքննություն, որի ընթացքում որոշվում են`
ա) պահանջվող փաստաթղթերի առկայությունը հայտի նյութերում.
բ) փաստաթղթերի ձևակերպման ճշտությունն ու համապատասխանությունը սահմանված հետևյալ պահանջներին՝
եթե հայտի կրկնական փորձաքննությունից հետո պարզվում է, որ հայտին կից փաստաթղթերը համապատասխանում են սահմանված պահանջներին, ապա լիազորված մարմինը «Սելեկցիոն նվաճումների պահպանության մասին» Հայաստանի Հանրապետության օրենքի 9-րդ հոդվածով սահմանված կարգով և ժամկետներում ընդունում է որոշում հայտի պաշտոնական հրապարակման մասին,
եթե հայտի կրկնական փորձաքննությունից հետո պարզվում է, որ հայտին կից փաստաթղթերը չեն համապատասխանում սահմանված պահանջներին, ապա լիազորված մարմինը «Սելեկցիոն նվաճումների պահպանության մասին» Հայաստանի Հանրապետության օրենքի 9-րդ հոդվածով սահմանված կարգով և ժամկետներում ընդունում է որոշում սելեկցիոն նվաճման արտոնագիր տալը մերժելու մասին:
(6-րդ կետը փոփ. 02.03.17 N 202-Ն)
7. Հայտի կրկնական փորձաքննության մասին որոշում ընդունվում է լիազորված մարմնի կողմից՝ փորձագիտական եզրակացության հիման վրա:
(7-րդ կետը փոփ. 02.03.17 N 202-Ն)
8. Սելեկցիոն նվաճման արտոնագիր տալու (արտոնագիր տալը մերժելու) մասին փորձագիտական եզրակացության ձևը սահմանում է լիազորված մարմինը:
9. Լիազորված մարմինը հայտի կրկնական փորձաքննության նյութերը պահպանում է`
ա) սելեկցիոն նվաճման արտոնագիր տալը մերժելու դեպքում՝ 6 տարի.
բ) սելեկցիոն նվաճման արտոնագիր տալու մասին դրական որոշում ընդունելու դեպքում՝ արտոնագրի՝ «Սելեկցիոն նվաճումների պահպանության մասին» Հայաստանի Հանրապետության օրենքով սահմանված գործողության ժամկետի ընթացքում։
(9-րդ կետը փոփ. 02.03.17 N 202-Ն)
10. Հայտին կից փաստաթղթերին ծանոթանալու կարգը սահմանում է լիազորված մարմինը:
11. Ընդունված հայտին կից փաստաթղթերը չեն վերադարձվում:
12. (կետն ուժը կորցրել է 02.03.17 N 202-Ն)
V. ՊԱՇՏՈՆԱԿԱՆ ՏԵՂԵԿՈՒԹՅՈՒՆՆԵՐԻ ՀՐԱՊԱՐԱԿՈՒՄԸ
13. Լիազորված մարմինը, հայտի կրկնական փորձաքննություն նշանակելու և դրա արդյունքների վերաբերյալ լիազորված մարմնի կողմից ընդունված որոշումների մասին, որոշումների ընդունումից հետո մեկ աշխատանքային օրվա ընթացքում, հայտում նշված եղանակով՝ կապի միջոցների օգտագործմամբ (այդ թվում՝ հայտատուի նշած հեռախոսահամարին հաղորդագրություն ուղարկելով) կամ էլեկտրոնային համակարգի միջոցով (այդ թվում՝ հայտատուի նշած էլեկտրոնային փոստի միջոցով) կամ Հայաստանի Հանրապետության օրենսդրությամբ սահմանված այլ էլեկտրոնային կապի միջոցներով հայտատուին տեղեկացնում է դրա մասին: Լիազորված մարմինը որոշման ընդունումից հետո երեք աշխատանքային օրվա ընթացքում այն փոստով ուղարկում է հայտատուին, եթե հայտատուն հայտում նշում կատարելու միջոցով ցանկություն չի հայտնել նույն ժամկետում որոշումն ստանալ լիազորված մարմնում՝ առձեռն: Լիազորված մարմինը որոշումները հրապարակում է «Սելեկցիոն նվաճումների պահպանության մասին» Հայաստանի Հանրապետության օրենքի 19-րդ հոդվածով սահմանված ժամկետներում:
(13-րդ կետը խմբ. 02.03.17 N 202-Ն)
14. Հայտի կրկնական փորձաքննություն նշանակելու մասին լիազորված մարմնի ընդունած որոշման պաշտոնական հրապարակումից հետո ցանկացած անձ կարող է ծանոթանալ հայտին կից փաստաթղթերին:
(14-րդ կետը փոփ. 02.03.17 N 202-Ն)
(հավելվածը փոփ., խմբ. 02.03.17 N 202-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
