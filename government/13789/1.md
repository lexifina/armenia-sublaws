1. Ստեղծել Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության «Հայաստանի փրկարար ծառայության աշխատակազմ» պետական կառավարչական հիմնարկ: (1-ին կետը փոփ. 22.12.05 N 2309-Ն, 15.05.08 N 533-Ն) 2. Հաստատել`
ա) Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության Հայաստանի փրկարար ծառայության կանոնադրությունը` համաձայն N 1 հավելվածի.
բ) Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության Հայաստանի փրկարար ծառայության աշխատակազմի կառուցվածքը` համաձայն N 2 հավելվածի: (2-րդ կետը փոփ. 22.12.05 N 2309-Ն, 15.05.08 N 533-Ն) 3. (կետն ուժը կորցրել է 26.08.10 N 1097-Ն)
4. Հայաստանի Հանրապետության կառավարության 2005 թվականի մարտի 10-ի «Հայաստանի Հանրապետության կառավարությանն առընթեր արտակարգ իրավիճակների վարչության պետական հակահրդեհային ծառայությունը վերակազմակերպելու, Հայաստանի Հանրապետության կառավարությանն առընթեր արտակարգ իրավիճակների վարչության պետական հրդեհային տեսչություն ստեղծելու, այդ տեսչության կանոնադրությունը և կառուցվածքը հաստատելու մասին» N 383-Ն որոշման մեջ կատարել հետևյալ փոփոխությունները`
ա) որոշման վերնագրում «արտակարգ իրավիճակների վարչության պետական հրդեհային տեսչություն ստեղծելու» բառերից առաջ «կառավարությանն առընթեր» բառերը փոխարինել «արտակարգ իրավիճակների նախարարության» բառերով.
բ) որոշման 1-ին կետում «կառավարությանն առընթեր արտակարգ իրավիճակների վարչության պետական հրդեհային տեսչության» բառերը փոխարինել «արտակարգ իրավիճակների նախարարության արտակարգ իրավիճակների վարչության պետական հրդեհային տեսչության» բառերով.
գ) որոշման 2-րդ կետի «ա» և «բ» ենթակետերում, որոշմամբ հաստատված կանոնադրության վերնագրում և 1-ին կետում, որոշմամբ հաստատված կառուցվածքի վերնագրում «կառավարությանն առընթեր» բառերը փոխարինել «արտակարգ իրավիճակների նախարարության» բառերով.
դ) կանոնադրության 2-րդ կետում «վարչության պետի» բառերը փոխարինել «Հայաստանի Հանրապետության տարածքային կառավարման նախարարի» բառերով:
(4-րդ կետը փոփ.15.05.08 N 533-Ն)
5. Ուժը կորցրած ճանաչել Հայաստանի Հանրապետության կառավարության 2003 թվականի հունվարի 16-ի «Հայաստանի Հանրապետության կառավարությանն առընթեր արտակարգ իրավիճակների վարչության կանոնադրությունը և կառուցվածքը հաստատելու մասին» N 67-Ն որոշումը:
6. Սույն որոշումն ուժի մեջ է մտնում պաշտոնական հրապարակմանը հաջորդող օրվանից:
