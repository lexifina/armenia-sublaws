# Հավելված N 2 ՀՀ կառավարության 2002 թվականի դեկտեմբերի 13-ի N 1950-Ն որոշման
Կ Ա Զ Մ
«ԽՄԵԼՈՒ ՋՐԻ ՄԱՏԱԿԱՐԱՐՄԱՆ, ՋՐԱՀԵՌԱՑՄԱՆ, ԿԵՂՏԱՋՐԵՐԻ ՄԱՔՐՄԱՆ ԵՎ ՈՌՈԳՄԱՆ ՋՐԻ ՄԱՏԱԿԱՐԱՐՄԱՆ ԾԱՌԱՅՈՒԹՅՈՒՆՆԵՐԻ ԴԻՄԱՑ ԱՌԱՋԱՑԱԾ ՊԱՐՏԱՎՈՐՈՒԹՅՈՒՆՆԵՐԻ ԳԾՈՎ ՎՃԱՐՄԱՆ ԱՐՏՈՆՈՒԹՅՈՒՆՆԵՐ ՍԱՀՄԱՆԵԼՈՒ ՄԱՍԻՆ» ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՕՐԵՆՔՈՎ ՆԱԽԱՏԵՍՎԱԾ ԳՈՐԾԸՆԹԱՑՆԵՐԸ ԿԱՌԱՎԱՐՈՂ ՄԻՋԳԵՐԱՏԵՍՉԱԿԱՆ ՀԱՆՁՆԱԺՈՂՈՎԻ
Գ. Խաչատրյան | - | ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի նախագահի առաջին տեղակալ (հանձնաժողովի նախագահ)
Ս. Ղոնախչյան | - | ՀՀ կառավարության աշխատակազմի տնտեսագիտական վարչության պետ
Ռ. Դավթյան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարարության ճյուղային տնտեսական ծրագրերի վարչության պետ
Կ. Խտրյան | - | ՀՀ արդարադատության նախարարության օրենսդրական հարցերի վարչության պետ
Մ. Մկրտումյան | - | ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի ֆինանսատնտեսագիտական, հաշվառման և իրացման համակարգման վարչության պետ
Գ. Գրիգորյան | - | ՀՀ սոցիալական ապահովության նախարարության սոցիալական աջակցության վարչության պետի տեղակալ
Ա. Մեսրոպյան | - | ՀՀ կառավարությանն առընթեր հարկային պետական ծառայության բաժնի պետ
(Կազմը փոփ. 17.06.04 N 899-Ն)
