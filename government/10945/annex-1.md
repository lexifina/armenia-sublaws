# Հավելված N 1 ՀՀ կառավարության 2003 թվականի մայիսի 15-ի N 635-Ն որոշման

ՀԱՐԿԱՅԻՆ ՕՐԵՆՍԳՐՔԻ ՄՇԱԿՄԱՆ ՀԱՄԱՐ ՊԱՏԱՍԽԱՆԱՏՈՒ ԱՇԽԱՏԱՆՔԱՅԻՆ ԽՄԲԻ
Տ. Խաչատրյան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարարի տեղակալ (աշխատանքային խմբի ղեկավար)
Գ. Մալխասյան | - | ՀՀ արդարադատության նախարարի առաջին տեղակալ
Գ. Վարդանյան | - | ՀՀ առևտրի և տնտեսական զարգացման նախարարի տեղակալ
Ա. Ալավերդյան | - | ՀՀ կառավարությանն առընթեր հարկային պետական ծառայության պետի տեղակալ
Ս. Կարայան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարարության պետական եկամուտների քաղաքականության վարչության պետ
Փ. Թադևոսյան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարարության պետական եկամուտների քաղաքականության վարչության պետի տեղակալ-ոչ հարկային եկամուտների և մաքսային քաղաքականության բաժնի պետ
Վ. Միրումյան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարարության հարկերի մեթոդաբանության բաժնի պետ
Ա. Բալյան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարարության միջազգային հարկային հարաբերությունների գծով խորհրդատու
Ա. Մուրադյան | - | ՀՀ կառավարությանն առընթեր հարկային պետական ծառայության անուղղակի հարկերի և կանխիկ գործարքների վարչարարության բաժնի պետ
Ա. Մեսրոպյան | - | ՀՀ կառավարությանն առընթեր հարկային պետական ծառայության ուղղակի հարկերի վարչարարության բաժնի պետ
Ա. Զարգարյան | - | ՀՀ կառավարությանն առընթեր հարկային պետական ծառայության հարկային վարչարարության բարեփոխումների բաժնի պետ
Ա. Մանուկյան | - | ՀՀ կառավարությանն առընթեր հարկային պետական ծառայության գույքային հարկերի և ոչ հարկային եկամուտների բաժնի պետ
Լ. Միրզոյան | - | ՀՀ կառավարությանն առընթեր հարկային պետական ծառայության ոլորտային վերլուծության բաժնի գլխավոր հարկային տեսուչ
Հ. Քոթանյան | - | ՀՀ կառավարությանն առընթեր հարկային պետական ծառայության ոլորտային վերլուծության բաժնի գլխավոր հարկային տեսուչ
Գ. Քառյան | - | ՀՀ կառավարությանն առընթեր մաքսային պետական կոմիտեի մաքսային գործի կատարելագործման բաժնի պետ
