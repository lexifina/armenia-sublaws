# Հավելված N 3 ՀՀ կառավարության 2003 թվականի մարտի 7-ի N 232-Ն որոշման
Կ Ա Ր Գ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅՈՒՆՈՒՄ ՔԱՂԱՔԱԿԱՆ ԱՊԱՍՏԱՆԻ ԻՐԱՎՈՒՆՔ ՍՏԱՆԱԼՈՒ ՄԱՍԻՆ ԳՈՐԾ ԿԱԶՄԵԼՈՒ ԵՎ ՎԱՐԵԼՈՒ
1. Սույն կարգը հաստատված է «Քաղաքական ապաստանի մասին» Հայաստանի Հանրապետության օրենքի 5-րդ հոդվածի 6-րդ կետին համապատասխան և սահմանում է Հայաստանի Հանրապետությունում քաղաքական ապաստանի իրավունք ստանալու համար Հայաստանի Հանրապետության տարածքային կառավարման նախարարության կառավարման ոլորտում գործող «Միգրացիոն պետական ծառայություն» պետական մարմին (այսուհետ` ծառայություն) դիմելու, ծառայությունում բացված անձնական գործը կազմելու և վարելու կարգը:
(1-ին կետը փոփ. 03.05.07 N 573-Ն, 17.12.09 N 1472-Ն)
2. Հայաստանի Հանրապետությունում քաղաքական ապաստանի իրավունք ստանալու համար օտարերկրյա քաղաքացու` Հայաստանի Հանրապետության կառավարության 2003 թվականի մարտի 7-ի N 232-Ն որոշմամբ հաստատված ձևի դիմումի հիման վրա ծառայությունում բացվում և կազմվում է անձնական գործ:
(2-րդ կետը փոփ. 03.05.07 N 573-Ն, 17.12.09 N 1472-Ն)
3. Անձնական գործի կազմման և վարման աշխատանքները կազմակերպում է Հայաստանի Հանրապետության տարածքային կառավարման նախարարության կառավարման ոլորտում գործող «Միգրացիոն պետական ծառայություն» պետական մարմնի պետը (կամ նրա տեղակալը):
(3-րդ կետը փոփ. 03.05.07 N 573-Ն, 17.12.09 N 1472-Ն)
4. Քաղաքական ապաստանի իրավունք ստանալու համար դիմումը, դրան կցվող փաստաթղթերը ծառայության կողմից սահմանված կարգով մուտքագրվելուց հետո 5 օրվա ընթացքում համապատասխան պաշտոնատար անձը քաղաքական ապաստանի իրավունք հայցողի (այսուհետ` հայցող) հետ անցկացնում է հարցազրույց` պարզելու այն հանգամանքները, որոնց պատճառով հայցողը հեռացել է իր քաղաքացիության կամ մշտական բնակության երկրից և դիմել է Հայաստանի Հանրապետությունում քաղաքական ապաստանի իրավունք ստանալու խնդրանքով:
(4-րդ կետը փոփ. 03.05.07 N 573-Ն, 17.12.09 N 1472-Ն)
5. Հարցազրույցն անցկացվում է սահմանված կարգով հայցողին տրամադրված ժամանակավոր կացարանում կամ ծառայությունում: Հայցողը նախապես գրավոր տեղեկացվում է հարցազրույցի անցկացման վայրի և օրվա մասին:
Հարցազրույցի արդյունքում կազմվում է արձանագրություն:
(5-րդ կետը փոփ. 03.05.07 N 573-Ն, 17.12.09 N 1472-Ն)
6. Ծառայությունը յուրաքանչյուր դիմումի առնչությամբ անհրաժեշտ ստուգումներ կատարելու նպատակով հարցումներ է հղում Հայաստանի Հանրապետության կառավարությանն առընթեր ազգային անվտանգության ծառայություն, Հայաստանի Հանրապետության կառավարությանն առընթեր Հայաստանի Հանրապետության ոստիկանություն և Հայաստանի Հանրապետության արտաքին գործերի նախարարություն` հայցողին քաղաքական ապաստանի իրավունք ստանալու մասին նրանց եզրակացություններն ստանալու համար:
(6-րդ կետը փոփ. 03.05.07 N 573-Ն, 17.12.09 N 1472-Ն)
7. Ծառայության համապատասխան պաշտոնատար անձը հայցողի մասին իրավասու պետական մարմինների եզրակացություններն ստանալուց հետո մեկամսյա ժամկետում ամփոփում է հայցողի հետ անցկացված հարցազրույցի արդյունքներն ու ստացած եզրակացությունների հիման վրա կազմում է առաջարկություն և այն ներկայացնում Հայաստանի Հանրապետության տարածքային կառավարման նախարարին` այն այնուհետև Հայաստանի Հանրապետությունում քաղաքական ապաստանի իրավունք տալու վերաբերյալ առաջարկությամբ Հայաստանի Հանրապետության Նախագահին ներկայացնելու համար:
(7-րդ կետը փոփ. 03.05.07 N 573-Ն, խմբ. 17.12.09 N 1472-Ն)
8. Առաջարկությունը կազմված է ներածական, նկարագրական, պատճառաբանական և եզրափակիչ մասերից:
Առաջարկության ներածական մասում պետք է նշվեն առաջարկությունը կազմող մարմնի անվանումը, քաղաքական ապաստանի իրավունք ստանալու համար դիմում ներկայացրած անձի անունը, ազգանունը, հայրանունը, քաղաքացիությունը, մշտական բնակության երկիրը, ծննդյան տարեթիվը, ամիսը, ամսաթիվը, դիմումի ստացման տարեթիվը, ամիսը և ամսաթիվը:
Առաջարկության նկարագրական մասում պետք է նշվի քաղաքական ապաստանի իրավունք ստանալու համար դիմումի համառոտ շարադրանքը:
Առաջարկության պատճառաբանական մասում պետք է նշվեն ծառայության կողմից պարզված գործի հանգամանքները, հիմնավորումները, «Քաղաքական ապաստանի մասին» Հայաստանի Հանրապետության օրենքի և այլ օրենքների այն հոդվածները, որոնցով ծառայությունն առաջնորդվել է գործի քննարկման ընթացքում:
Առաջարկության եզրափակիչ մասը պետք է պարունակի օտարերկրյա քաղաքացու` Հայաստանի Հանրապետությունում քաղաքական ապաստանի իրավունք ստանալու համար դիմումը բավարարելու կամ մերժելու մասին եզրահանգումները, որտեղ պետք է նշվեն դրանց համար օրենքով նախատեսված հիմքերը, ինչպես նաև առաջարկության կազմման ամսաթիվը, ամիսը, տարեթիվը:
Առաջարկությունը, ՀՀ տարածքային կառավարման նախարարի ստորագրությամբ, սահմանված կարգով ներկայացվում է Հայաստանի Հանրապետության Նախագահին:
(8-րդ կետը փոփ. 03.05.07 N 573-Ն, 17.12.09 N 1472-Ն)
9. Դիմումի մասին Հայաստանի Հանրապետության Նախագահի որոշումն ընդունվելուց հետո (քաղաքական ապաստանի իրավունք տալու կամ այն մերժելու մասին) ծառայությունը`
ա) հայցողի անձնական գործն առանձնացնում և պահում է քաղաքական ապաստանի իրավունք ստացած անձանց գործերի մեջ, եթե Հայաստանի Հանրապետության Նախագահը քաղաքական ապաստանի իրավունք տալու մասին որոշում է ընդունել.
բ) հայցողի անձնական գործն առանձնացնում և պահում է քաղաքական ապաստանի իրավունք չստացած անձանց գործերի մեջ, եթե Հայաստանի Հանրապետության Նախագահը քաղաքական ապաստանի իրավունք տալը մերժելու մասին որոշում է ընդունել:
(9-րդ կետը փոփ. 03.05.07 N 573-Ն, 17.12.09 N 1472-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
