# Հավելված N 2 ՀՀ կառավարության 2002 թվականի սեպտեմբերի 5-ի N 1516-Ն որոշման

ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԳՅՈՒՂԱՏՆՏԵՍՈՒԹՅԱՆ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԱՇԽԱՏԱԿԱԶՄԻ
I. Կառուցվածքային ստորաբաժանումներ
1. Վարչություններ
Գյուղատնտեսության զարգացման ծրագրերի վարչություն
Բուսաբուծության և բույսերի պաշտպանության վարչություն
Անասնաբուծության և անասնաբուժության վարչություն
Ագրովերամշակման զարգացման և սննդամթերքի անվտանգության վարչություն
Հողերի օգտագործման և մելիորացիայի վարչություն
Անտառաբուծության վարչություն
Գիտության և կրթության վարչություն
Ֆինանսատնտեսագիտական և հաշվապահական հաշվառման վարչություն
Իրավաբանական վարչություն
Արտաքին կապերի վարչություն
2. Քարտուղարություն
3. Բաժիններ
Անձնակազմի կառավարման բաժին
Հասարակայնության հետ կապերի բաժին
Տնտեսական բաժին
Համակարգչային սպասարկումների և տեղեկատվական հոսքերի կառավարման բաժին
II. Առանձնացված ստորաբաժանումներ
Գյուղատնտեսական տեխնիկայի պետական տեսչություն
Պետական գյուղատնտեսական գործակալություն
III. Հայաստանի Հանրապետության գյուղատնտեսության նախարարության կառավարման ոլորտում պետական մարմիններ
Սննդամթերքի անվտանգության պետական ծառայություն
(Կառուցվածքը լրաց. 21.11.02 N 1888-Ն, խմբ. 29.01.04 N 96-Ն, խմբ. 13.01.05 N 101-Ն, խմբ., փոփ., լրաց. 12.01.06 N 109-Ն, լրաց. 02.11.06 N 1555-Ն, խմբ., փոփ. 28.12.06 N 1898-Ն, փոփ. 04.03.10 N 210-Ն, խմբ. 01.07.10 N 877-Ն, փոփ., լրաց. 30.12.10 N 1730-Ն)
