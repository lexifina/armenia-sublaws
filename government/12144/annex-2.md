# Հավելված N 2 ՀՀ կառավարության 2004 թվականի փետրվարի 19-ի N 212-Ն որոշման

Մ. Թոփուզյան | - | ՀՀ կառավարության աշխատակազմի ղեկավար-նախարար (հանձնաժողովի նախագահ)
Գ. Բադալյան | - | ՀՀ առևտրի և տնտեսական զարգացման նախարարի տեղակալ (հանձնաժողովի նախագահի տեղակալ)
Ա. Կիրակոսյան | - | ՀՀ արտաքին գործերի նախարարի տեղակալ
Բ. Ոսկանյան | - | ՀՀ կառավարության աշխատակազմի վարչական մարմինների վարչության պետ
Պ. Շադյան | - | ՀՀ պաշտպանության նախարարության ռազմաարդյունաբերական վարչության պետ
Ա. Գևորգյան | - | ՀՀ էներգետիկայի նախարարության աշխատակազմի ատոմային էներգետիկայի վարչության պետ
Ս. Ֆահրադյան | - | ՀՀ կառավարությանն առընթեր մաքսային պետական կոմիտեի մաքսասակագնային կարգավորման վարչության պետ
Տ. Աղաջանյան | - | ՀՀ կառավարությանն առընթեր ազգային անվտանգության ծառայության գլխավոր վարչության բաժնի պետ
Մ. Սարգսյան | - | ՀՀ առևտրաարդյունաբերական պալատի նախագահ (համաձայնությամբ)
Ռ. Վարդազարյան | - | ՀՀ կառավարության աշխատակազմի վարչական մարմինների վարչության գլխավոր մասնագետ (հանձնաժողովի քարտուղար)
(Կազմը փոփ. 25.01.05 N 57-Ն, 07.07.05 N 965-Ն, 24.11.05 N 2038-Ն)
