# Հավելված N 2 ՀՀ կառավարության 2004 թվականի փետրվարի 19-ի N 212-Ն որոշման

Դ. Սարգսյան | - | ՀՀ կառավարության աշխատակազմի ղեկավար (հանձնաժողովի նախագահ)
Գ. Բադալյան | - | ՀՀ էկոնոմիկայի նախարարի տեղակալ (հանձնաժողովի նախագահի տեղակալ)
Ա. Կիրակոսյան | - | ՀՀ արտաքին գործերի նախարարի տեղակալ
Ա. Վահանյան | - | ՀՀ կառավարության աշխատակազմի պետաիրավական վարչության պետ
Պ. Շադյան | - | ՀՀ պաշտպանության նախարարության ռազմաարդյունաբերական վարչության պետ
Ա. Գևորգյան | - | ՀՀ էներգետիկայի և բնական պաշարների նախարարության ատոմային էներգետիկայի վարչության պետ
Գ. Սաղոյան | - | ՀՀ կառավարությանն առընթեր պետական եկամուտների կոմիտեի մաքսային հսկողության վարչության պետ
Տ. Աղաջանյան | - | ՀՀ կառավարությանն առընթեր ազգային անվտանգության ծառայության գլխավոր վարչության բաժնի պետ
Մ. Սարգսյան | - | ՀՀ առևտրաարդյունաբերական պալատի նախագահ (համաձայնությամբ)
Լ. Շահինյան | - | ՀՀ կառավարության աշխատակազմի պետաիրավական վարչության առաջատար մասնագետ (հանձնաժողովի քարտուղար)
(կազմը փոփ. 25.01.05 N 57-Ն, 07.07.05 N 965-Ն, 24.11.05 N 2038-Ն, 25.01.08 N 61-Ն, 22.05.08 N-490-Ն, 20.11.08 N 1335-Ն, 08.10.09 N 1204-Ն)
