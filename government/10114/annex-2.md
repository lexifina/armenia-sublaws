# Հավելված N 2 ՀՀ կառավարության 2002 թվականի սեպտեմբերի 12-ի N 1579-Ն որոշման
Կ Ա Ռ ՈՒ Ց Վ Ա Ծ Ք
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿՐԹՈՒԹՅԱՆ ԵՎ ԳԻՏՈՒԹՅԱՆ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԱՇԽԱՏԱԿԱԶՄԻ
I. Կառուցվածքային ստորաբաժանումներ
1. Վարչություններ
Հանրակրթության վարչություն
Նախնական և միջին մասնագիտական կրթության վարչություն
Բարձրագույն և հետբուհական մասնագիտական կրթության վարչություն
Մարզառազմական և արտաուսումնական դաստիարակության վարչություն
Միջազգային համագործակցության և սփյուռքի վարչություն
Ֆինանսատնտեսագիտական և հաշվապահական հաշվառման վարչություն
Անձնակազմի կառավարման վարչություն
Օրենսդրության և իրավաբանական վարչություն
Հասարակայնության հետ կապերի և տեղեկատվության վարչություն
(1-ին կետը փոփ. 18.10.07 N 1269-Ն)
2. Քարտուղարություն
Նախարարության աշխատակազմի քարտուղարություն
3. Բաժիններ
Զարգացման ծրագրերի բաժին
Պետական նմուշի փաստաթղթերի, արտակարգ իրավիճակների և պարգևատրումների համակարգման բաժին
(3-րդ կետը լրաց. 28.09.06 N 1372-Ն, փոփ. 11.10.07 N 1275-Ն)
II. Առանձնացված ստորաբաժանումներ
1. Գործակալություններ
ՀՀ բարձրագույն որակավորման հանձնաժողով
Լիցենզավորման և հավատարմագրման ծառայություն
2. Տեսչություններ
Լեզվի պետական տեսչություն
Կրթության պետական տեսչություն
(2-րդ կետը լրաց. 30.12.04 N 1927-Ն, խմբ. 24.11.05 N 2290-Ն)
III. ՀՀ կրթության և գիտության նախարարության կառավարման ոլորտում գործող պետական մարմին
Գիտության պետական կոմիտե:
(III-րդ բաժինը լրաց. 18.10.07 N 1269-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
