# Հավելված ՀՀ կառավարության 2006 թվականի հուլիսի 27-ի N 1098-Ն որոշման
Կ Ա Ր Գ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՀԱՄԱՅՆՔՆԵՐԻ ՎԱՐՉԱԿԱՆ ՏԱՐԱԾՔՈՒՄ ԳՏՆՎՈՂ` ՊԵՏԱԿԱՆ ՍԵՓԱԿԱՆՈՒԹՅՈՒՆ ՀԱՄԱՐՎՈՂ ԱՆՇԱՐԺ ԳՈՒՅՔԻ, ԻՐԱՎԱԲԱՆԱԿԱՆ ԱՆՁԱՆՑ ԿԱՆՈՆԱԴՐԱԿԱՆ ԿԱՊԻՏԱԼՈՒՄ ՊԵՏԱԿԱՆ ՄԱՍՆԱԿՑՈՒԹՅԱՆ, ԱՅԴ ԹՎՈՒՄ` ԱՆԱՎԱՐՏ ՇԻՆԱՐԱՐՈՒԹՅԱՆ ՕԲՅԵԿՏՆԵՐԻ ՄԱՍՆԱՎՈՐԵՑՈՒՄԻՑ ՍՏԱՑՎՈՂ ՄԻՋՈՑՆԵՐԻ ՏՆՕՐԻՆՄԱՆ (վերնագիրը փոփ. 15.10.09 N 1176-Ն, 07.03.24 N 321-Ն)
1. Սույն կարգով կարգավորվում է Հայաստանի Հանրապետության համայնքների վարչական տարածքում գտնվող` պետական սեփականություն համարվող անշարժ գույքի, այդ թվում` անավարտ շինարարության օբյեկտների, ինչպես նաև իրավաբանական անձանց կանոնադրական կապիտալում պետական մասնակցության մասնավորեցումից ստացվող մուտքերի` 30 տոկոս կազմող ֆինանսական միջոցների տնօրինման գործընթացը:
(1-ին կետը փոփ. 15.10.09 N 1176-Ն, 07.03.24 N 321-Ն)
2. Սույն կարգի 1-ին կետում նշված ֆինանսական միջոցների օգտագործման վերաբերյալ առաջարկությունները Հայաստանի Հանրապետության կառավարության քննարկմանն են ներկայացվում կապիտալ ծախսերի ծրագրերի (այսուհետ` ծրագիր) տեսքով, որոնց իրականացմամբ մասամբ կամ ամբողջապես լուծվում են համայնքի բնակչության խմելու և ոռոգման ջրի, համայնքային նշանակության ճանապարհների, մանկապարտեզների, ինչպես նաև այլ ենթակառուցվածքների հիմնախնդիրները:
3. Ֆինանսական միջոցների արդյունավետ օգտագործումն ապահովելու նպատակով Հայաստանի Հանրապետության կառավարության քննարկմանը ներկայացվող ծրագրերը պետք է բխեն Հայաստանի Հանրապետության կառավարության հավանությանն արժանացած մարզային, տարածաշրջանային զարգացման և այլ ծրագրերից, իսկ նախահաշիվները պետք է կազմվեն Հայաստանի Հանրապետության պետական բյուջեի միջոցների հաշվին իրականացվող կապիտալ շինարարության համար սահմանված նորմատիվների շրջանակներում: Նույն գումարի սահմաններում քննարկման համար մշակվում են 2 կամ ավելի ծրագրեր` տվյալ համայնքի համար առավել արդյունավետն ընտրելու նպատակով:
4. Հայաստանի Հանրապետության տարածքային կառավարման և ենթակառուցվածքների նախարարության պետական գույքի կառավարման կոմիտեն (այսուհետ՝ կոմիտե) մասնավորեցումից ստացված գումարների փոխանցման մասին տեղեկատվությունը 10-օրյա ժամկետում տրամադրում է Հայաստանի Հանրապետության տարածքային կառավարման և ենթակառուցվածքների նախարարությանը, ինչպես նաև համապատասխան համայնքին:
(4-րդ կետը խմբ. 07.03.24 N 321-Ն)
5. Առաջարկել`
1) Երևանի քաղաքապետին` կոմիտեի կողմից ներկայացված տեղեկատվությունն ստանալուց հետո երկամսյա ժամկետում Երևանի ավագանու նիստի քննարկմանը ներկայացնել ծրագիրը և այն հաստատվելու օրվանից 10-օրյա ժամկետում ներկայացնել Հայաստանի Հանրապետության տարածքային կառավարման և ենթակառուցվածքների նախարարին.
2) համայնքի ղեկավարին` կոմիտեի կողմից տեղեկատվությունն ստանալուց հետո երկամսյա ժամկետում համայնքի ավագանու նիստի քննարկմանը ներկայացնել ծրագիրը և այն հաստատվելու օրվանից 10-օրյա ժամկետում ներկայացնել համապատասխան մարզպետին:
(5-րդ կետը խմբ. 15.10.09 N 1176-Ն, 07.03.24 N 321-Ն)
6. Մարզպետը 5-օրյա ժամկետում ստուգում է ծրագրի (ծրագրերի) համապատասխանությունը սույն կարգի 2-րդ և 3-րդ կետերի դրույթներին և ներկայացնում Հայաստանի Հանրապետության տարածքային կառավարման և ենթակառուցվածքների նախարարություն:
(6-րդ կետը փոփ. 07.03.24 N 321-Ն)
7. Հայաստանի Հանրապետության տարածքային կառավարման և ենթակառուցվածքների նախարարությունը, քննարկելով ներկայացված ծրագրի (ծրագրերի) համապատասխանությունը սույն կարգի պահանջներին, 10-օրյա ժամկետում այն (դրանք) ներկայացնում է շահագրգիռ մարմինների քննարկմանը, այնուհետև՝ ստացված առաջարկությունները ամփոփելուց հետո, սահմանված կարգով, այն (դրանք) ներկայացնում է Հայաստանի Հանրապետության կառավարության քննարկմանը:
(7-րդ կետը լրաց. 15.10.09 N 1176-Ն, խմբ. 07.03.24 N 321-Ն)
8. Ծրագրերի կատարման նկատմամբ հսկողությունն իրականացնում է Հայաստանի Հանրապետության տարածքային կառավարման և ենթակառուցվածքների նախարարը:
(8-րդ կետը փոփ. 15.10.09 N 1176-Ն, 07.03.24 N 321-Ն)
(հավելվածը փոփ., խմբ., լրաց. 15.10.09 N 1176-Ն, փոփ., խմբ. 07.03.24 N 321-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
