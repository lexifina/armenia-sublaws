ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅՈՒՆ
Ո Ր Ո Շ ՈՒ Մ
3 հուլիսի 2014 թվականի N 712-Ն
ԶԻՆՎԱԾ ՈՒԺԵՐՈՒՄ, ԱԶԳԱՅԻՆ ԱՆՎՏԱՆԳՈՒԹՅԱՆ, ՈՍՏԻԿԱՆՈՒԹՅԱՆ ՄԱՐՄԻՆՆԵՐՈՒՄ, ՊԵՏԱԿԱՆ ՊԱՀՊԱՆՈՒԹՅԱՆ, ԱՐՏԱՔԻՆ ՀԵՏԱԽՈՒԶՈՒԹՅԱՆ, ՔՐԵԱԿԱՏԱՐՈՂԱԿԱՆ ԵՎ ՓՐԿԱՐԱՐ ԾԱՌԱՅՈՒԹՅՈՒՆՆԵՐՈՒՄ ԾԱՌԱՅՈՒԹՅԱՆ ԱՌԱՆՁՆԱՀԱՏԿՈՒԹՅՈՒՆՆԵՐՈՎ ՊԱՅՄԱՆԱՎՈՐՎԱԾ ՀԱՎԵԼՈՒՄՆԵՐԻ ՏՐԱՄԱԴՐՄԱՆ ԴԵՊՔԵՐԸ, ԴՐԱՆՑ ՎՃԱՐՄԱՆ ՉԱՓԵՐԸ ԵՎ ԿԱՐԳԸ ՍԱՀՄԱՆԵԼՈՒ ՄԱՍԻՆ
(վերնագիրը փոփ. 27.09.18 N 1147-Ն, խմբ. 29.11.18 N 1420-Ն, լրաց. 22.09.23 N 1607-Ն, 09.11.23 N 1947-Ն)
«Զինվորական ծառայության և զինծառայողի կարգավիճակի մասին» Հայաստանի Հանրապետության օրենքի 61-րդ հոդվածի 18-րդ մասի և «Պետական պաշտոններ և պետական ծառայության պաշտոններ զբաղեցնող անձանց վարձատրության մասին» Հայաստանի Հանրապետության օրենքի 16-րդ հոդվածի 5-րդ մասի պահանջներին համապատասխան` Հայաստանի Հանրապետության կառավարությունը որոշում է.
(նախաբանը փոփ. 29.11.18 N 1420-Ն)
