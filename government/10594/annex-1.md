# Հավելված ՀՀ կառավարության 2003 թվականի հունվարի 16-ի N 42-Ն որոշման
ԱՌԱՆՑ ԲԱՐՁՐԱԳՈՒՅՆ ԿՐԹՈՒԹՅԱՆ ՈՍՏԻԿԱՆՈՒԹՅԱՆ ԳԼԽԱՎՈՐ ԽՄԲՈՒՄ ՊԱՇՏՈՆ ԶԲԱՂԵՑՆՈՂ ԾԱՌԱՅՈՂՆԵՐԻՆ ԱՎԵԼԻ ԲԱՐՁՐ ՊԱՇՏՈՆԻ ՆՇԱՆԱԿԵԼՈՒ ՆՊԱՏԱԿՈՎ ԵՐԿԱՄՅԱ ՊԱՐՏԱԴԻՐ ՈՒՍՈՒՑՈՒՄ ԱՆՑՆԵԼՈՒ ԿԱՐԳՆ ՈՒ ՊԱՅՄԱՆՆԵՐԸ
(վերնագիրը փոփ. 01.09.05 N 1421-Ն)
1. Սույն իրավական ակտով սահմանվում են առանց բարձրագույն կրթության ոստիկանության գլխավոր խմբում պաշտոն զբաղեցնող ծառայողներին (այսուհետ՝ ծառայողներ) ավելի բարձր պաշտոնի նշանակելու նպատակով երկամյա պարտադիր ուսուցում անցնելու կարգն ու պայմանները:
(1-ին կետը փոփ. 01.09.05 N 1421-Ն)
2. Առանց բարձրագույն կրթության ոստիկանության գլխավոր խմբում պաշտոն զբաղեցնող ծառայողներն ատեստավորման դրական արդյունքների դեպքում Հայաստանի Հանրապետության օրենքով սահմանված կարգով կարող են նշանակվել ավելի բարձր պաշտոնի՝ ոստիկանության ուսումնական հաստատությունում երկամյա պարտադիր ուսուցում անցնելուց հետո:
(2-րդ կետը փոփ. 01.09.05 N 1421-Ն)
3. Ծառայողը զեկուցագրով դիմում է իր անմիջական ղեկավարին՝ երկամյա ուսուցում անցնելու ցանկության մասին: Ղեկավարի կողմից ոստիկանության կադրային ծառայություն են ուղարկվում ծառայողի ուսումնառության վերաբերյալ միջնորդագիր և ծառայողական բնութագիր:
(3-րդ կետը փոփ. 01.09.05 N 1421-Ն)
4. Ծառայողին ուսումնառության ուղարկելու վերաբերյալ եզրակացությունը հաստատվում է Հայաստանի Հանրապետության ոստիկանության պետի կողմից՝ ոստիկանության կադրային ծառայության ներկայացմամբ:
(4-րդ կետը փոփ. 01.09.05 N 1421-Ն)
5. Ծառայողին ուսումնառության ընդգրկելու մասին հրամանը տրվում է ուսումնական հաստատության ղեկավարի կողմից:
6. Ծառայողների ուսուցումն իրականացվում է հեռակա ուսուցման ձևով՝ ուսումնական հաստատությունում հեռակա ուսուցման համար սահմանված կարգով:
7. Ուսուցումը կազմակերպվում է ըստ ուսումնական հաստատությունում առկա մասնագիտացումների՝ օպերատիվ-հետախուզական գործունեություն, վարչաիրավական, համազորային-հրամանատարական:
8. Ուսուցման գործընթացը կազմակերպվում է սույն կարգով, ուսումնառության վերաբերյալ օրենսդրական ու գերատեսչական ակտերով և ուսումնաթեմատիկ պլաններով:
Ուսումնական պլանները մշակում է ուսումնական հաստատությունը՝ ոստիկանության կադրային ծառայության հետ համատեղ: Ուսումնական պլանը հաստատվում է Հայաստանի Հանրապետության ոստիկանության պետի կամ նրա տեղակալի կողմից:
Առարկայական ծրագրերը և թեմատիկ պլանները մշակվում են ուսումնական հաստատությունում և հաստատվում ուսումնական հաստատության ղեկավարի կողմից:
(8-րդ կետը փոփ. 01.09.05 N 1421-Ն)
9. Յուրաքանչյուր քննաշրջանի ավարտից հետո ուսումնական հաստատության կողմից ծառայողներին տրվում է ուսումնական պլանով նախատեսված պահանջների կատարման մասին տեղեկանք՝ ծառայության վայր ներկայացնելու համար:
10. Ուսումնառության ընթացքում բավարար առաջադիմություն ցուցաբերած այն ծառայողներին, ովքեր կատարել են ուսումնական պլանով նախատեսված բոլոր պահանջները՝ ստուգողական և կուրսային աշխատանքների, ստուգարքների և քննությունների հանձնումը, թույլատրվում է մասնակցել ավարտական քննություններին:
11. Ավարտական քննությունները հանձնած ծառայողներին տրվում է վկայական՝ համապատասխան որակավորմամբ, որը հիմք է հանդիսանում ծառայողին ավելի բարձր պաշտոնի նշանակելու համար:
12. Ուսումնառության ընթացքում անբավարար առաջադիմություն ցուցաբերած ծառայողների ուսումնառությունը դադարեցվում է:
13. Ծառայողի ազատումն ուսումնական հաստատությունից, ինչպես նաև նրա ուսումնառության դադարեցումը կատարվում է ուսումնական հաստատության կանոնակարգի համաձայն՝ ընդ որում՝
ա) ծառայողներն ազատվում են ուսումնառությունից ուսումնական հաստատության ղեկավարի միջնորդագրով, որն ուղարկվում է Հայաստանի Հանրապետության ոստիկանության կադրային ծառայություն՝ կից ներկայացնելով հեռացման հիմքերը (ֆակուլտետի խորհրդի որոշում, ծառայողական քննության եզրակացություն և այլն):
Կադրային ծառայության կողմից ծառայողին ուսումնառությունից ազատելու մասին եզրակացությունը ներկայացվում է ՀՀ ոստիկանության պետի հաստատմանը.
բ) ծառայողի ուսումնառությունը դադարեցվում է իր զեկուցագրի համաձայն:
(13-րդ կետը փոփ. 01.09.05 N 1421-Ն)
14. Ուսումնական հաստատությունից ազատված ծառայողը նույն ուսումնական հաստատությունում վերականգնման ենթակա չէ:
(հավելվածը փոփ. 01.09.05 N 1421-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
