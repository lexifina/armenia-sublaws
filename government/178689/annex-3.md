# Հավելված N 3 ՀՀ կառավարության 2023 թվականի հունիսի 1-ի N 889-Ն որոշման
Կ Ա Ր Գ
ՊԵՏԱԿԱՆ ՌԱԶՄԱԿԱՆԱՑՎԱԾ ԿԱԶՄԱԿԵՐՊՈՒԹՅՈՒՆՆԵՐԻ ՍՊԱՌԱԶԻՆՈՒԹՅԱՆ ՄԵՋ ԳՏՆՎՈՂ ԶԵՆՔԻ ՇՐՋԱՆԱՌՈՒԹՅԱՆ ՆԿԱՏՄԱՄԲ ՎԵՐԱՀՍԿՈՂՈՒԹՅԱՆ ԿԱՐԳԸ
1. Սույն կարգով կարգավորվում են պետական ռազմականացված կազմակերպությունների (այսուհետ՝ կազմակերպություն) սպառազինության մեջ գտնվող զենքի շրջանառության նկատմամբ վերահսկողության հետ կապված հարաբերությունները:
2. Կազմակերպությունների սպառազինության համար պատասխանատու ստորաբաժանումը պատասխանատվություն է կրում զենքի հաշվառման, շարժի, տեխնիկական վիճակի, հաշվետվությունները ժամանակին ներկայացնելու համար:
3. Կազմակերպությունների սպառազինության համար պատասխանատու ստորաբաժանումները մինչև հաջորդ տարվա մարտի 1-ը տարեկան հաշվետվություն են ներկայացնում կազմակերպությունների ղեկավարներին։
4. Կազմակերպությունների սպառազինության պահեստ ընդունվող զենքը պետք է լինի լրակազմով և փաթեթավորված:
5. Կազմակերպությունների ստորաբաժանումներում գտնվող զենքի հաշվառումը, աշխատակիցներին զենք տալու, աշխատակիցների կողմից զենքը հանձնելու հետ կապված հարաբերությունները կարգավորվում են կազմակերպությունների ղեկավարների հրամանով։
6. Փորձաքննությունների և ուսումնասիրությունների նպատակով ստացված, ինչպես նաև թանգարաններում և քրեագիտական հավաքածուներում ներառված զենքի հաշվառման, պահպանման, ընդունման, հանձնման կարգը սահմանվում է կազմակերպությունների ղեկավարների հրամանով:
