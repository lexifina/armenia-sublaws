# Հավելված ՀՀ կառավարության 2004 թվականի ապրիլի 29-ի N 637-Ն որոշման
Կ Ա Ր Գ
ՕԳՏԱԿԱՐ ՀԱՆԱԾՈՆԵՐԻ ՊԱՇԱՐՆԵՐԻ ՊԵՏԱԿԱՆ ՀԱՇՎԵԿՇՌԻ ՎԱՐՄԱՆ
1. Սույն կարգով կանոնակարգվում է Հայաստանի Հանրապետությունում օգտակար հանածոների պաշարների պետական հաշվեկշռի վարման ընթացակարգը:
2. Օգտակար հանածոների պաշարների պետական հաշվեկշիռը վարում է Հայաստանի Հանրապետության էներգետիկայի և բնական պաշարների նախարարությունը:
Օգտակար հանածոների պաշարների պետական հաշվեկշիռը յուրաքանչյուր տարվա համար կազմվում է ընդերքօգտագործողների կողմից ներկայացվող օգտակար հանածոների պաշարների հաշվեկշռի վերաբերյալ հաշվետվությունների (այսուհետ` հաշվետվություն) հիման վրա։ Այն պետք է պարունակի տեղեկություններ արդյունաբերական նշանակություն ունեցող հանքավայրերում պարփակված` բոլոր տեսակների օգտակար հանածոների պաշարների քանակի, որակի և ուսումնասիրվածության աստիճանի, գործող կամ նախագծվող արդյունաբերական կազմակերպության հետախուզված ու նախնական գնահատված պաշարներով ապահովվածության մասին:
Օգտակար հանածոների տարեկան հաշվետվության ձևերը հաստատում է Հայաստանի Հանրապետության էներգետիկայի և բնական պաշարների նախարարը:
(2-րդ կետը փոփ. 29.01.10 N 65-Ն, խմբ., փոփ. 03.06.10 N 671-Ն)
3. Օգտակար հանածոների պաշարների հաշվառումը կատարվում է հանքավայրերի օգտակար հանածոների պաշարների դասակարգմանը (A, B, C1 և C2) համապատասխան:
(3-րդ կետը փոփ. 03.06.10 N 671-Ն)
4. Օգտակար հանածոների պաշարների վերաբերյալ պետական փորձաքննական եզրակացությունը հիմք է ծառայում դրանց` պետական հաշվեկշռում գրանցման համար:
Հաշվառման ենթակա են բոլոր տեսակների օգտակար հանածոների հաստատված պաշարները:
5. Օգտակար հանածոների պաշարները հաշվառվում են յուրաքանչյուր տարվա հունվարի 1-ի դրությամբ` ըստ հանքավայրերի ու տեղամասերի, ինչպես նաև ըստ օգտակար հանածոների տեսակների, դրանց քանակի և որակական տվյալների:
Ամփոփված տվյալների հիման վրա կազմվում է պաշարների պետական հաշվեկշիռ:
Օգտակար հանածոների մարված (արդյունահանված և ընդերքում կորսված) պաշարների դուրսգրումը կատարվում է ընդերքօգտագործողների ներկայացրած մարկշեյդերական չափագրումների (հիմնավորում) արդյունքում կազմված հաշվետվությունների հիման վրա:
(5-րդ կետը փոփ. 03.06.10 N 671-Ն)
6. Ընդերքօգտագործող կազմակերպությունները հաշվետվությունները մինչև հաշվետու տարվան հաջորդող փետրվարի 15-ը ներկայացնում են Հայաստանի Հանրապետության էներգետիկայի և բնական պաշարների նախարարություն, որը ամփոփում և մինչև ապրիլի 1-ը կատարում է համապատասխան փոփոխություններ պաշարների պետական հաշվեկշռում` տեղեկությունները 10-օրյա ժամկետում տեղադրելով ինտերնետային կայքում:
(6-րդ կետը փոփ. 29.01.10 N 65-Ն, խմբ. 03.06.10 N 671-Ն)
7. Հաշվետվությունը լրացվում է ընդերքօգտագործող կազմակերպությունների կողմից յուրաքանչյուր հանքավայրի (տեղամասի) համար առանձին: Հաշվետվությունն ստորագրում է կազմակերպության ղեկավարը, գլխավոր երկրաբանը, իսկ պինդ օգտակար հանածոների դեպքում` նաև մարկշեյդերական չափագրում կատարողը:
Յուրաքանչյուր օգտակար հանածոյի, ինչպես նաև միևնույն տեսակի, բայց տարբեր որակական հատկանիշներ և արդյունաբերական նշանակություն ունեցող օգտակար հանածոների համար կազմվում է առանձին հաշվետվություն:
(7-րդ կետը փոփ. 03.06.10 N 671-Ն)
8. Պաշարների պետական հաշվեկշռում հանքավայրերը խմբավորվում են ըստ մարզերի, որոնցում հանքավայրերը բաշխվում են ըստ արդյունաբերական իրացման հետևյալ դասակարգման`
հետախուզվող,
շահագործվող,
պահուստային:
(8-րդ կետը փոփ. 03.06.10 N 671-Ն)
9. Արդյունաբերական նշանակությունը կորցրած կամ հետագա երկրաբանահետախուզական աշխատանքների և արդյունահանման արդյունքում չհաստատված պաշարների դուրսգրումը կատարվում է պետական փորձաքննական եզրակացության հիման վրա` պաշարների պետական հաշվեկշռում համապատասխան փոփոխություններ կատարելու համար:
(հավելվածը փոփ. 29.01.10 N 65-Ն, խմբ., փոփ. 03.06.10 N 671-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
