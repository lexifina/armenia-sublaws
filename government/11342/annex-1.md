# Հավելված N 1 ՀՀ կառավարության 2003 թվականի սեպտեմբերի 11-ի N 1187-Ն որոշման
«ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ 2003 ԹՎԱԿԱՆԻ ՊԵՏԱԿԱՆ ԲՅՈՒՋԵԻ ՄԱՍԻՆ» ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՕՐԵՆՔԻ N 1 ՀԱՎԵԼՎԱԾՈՒՄ ԿԱՏԱՐՎՈՂ ՎԵՐԱԲԱՇԽՈՒՄԸ ԵՎ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆ 2003 ԹՎԱԿԱՆԻ ՓԵՏՐՎԱՐԻ 6-Ի N 184-Ն ՈՐՈՇՄԱՆ N 5 ՀԱՎԵԼՎԱԾՈՒՄ ԿԱՏԱՐՎՈՂ ՓՈՓՈԽՈՒԹՅՈՒՆՆԵՐԸ (1-ին հավելվածն ուժը կորցրել է 26.02.04 N 231-Ն)
