# Հավելված N 2 ՀՀ կառավարության 2016 թվականի հուլիսի 14-ի N 742-Ն որոշման
Կ Ա Ռ ՈՒ Ց Վ Ա Ծ Ք
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԱՐԴԱՐԱԴԱՏՈՒԹՅԱՆ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ՊՐՈԲԱՑԻԱՅԻ ՊԵՏԱԿԱՆ ԾԱՌԱՅՈՒԹՅԱՆ
1. Ծառայության մարմիններ`
1) կենտրոնական մարմին
2) Երևանի քաղաքային մարմին
3) մարզային մարմիններ
2. Կենտրոնական մարմնի կառուցվածքային ստորաբաժանումներ`
1) կազմակերպամեթոդական բաժին
2) հաշվառման և վիճակագրության բաժին
3) էլեկտրոնային մոնիթորինգի և տեղեկատվական տեխնոլոգիաների բաժին
4) ընդհանուր բաժին
5) նյութատեխնիկական մատակարարման և շահագործման բաժին
3. (կետն ուժը կորցրել է 12.04.18 N 412-Ն)
4. Մարզային մարմիններ`
1) Արագածոտնի մարզային մարմին
2) Արարատի մարզային մարմին
3) Արմավիրի մարզային մարմին
4) Գեղարքունիքի մարզային մարմին
5) Լոռու մարզային մարմին
6) Կոտայքի մարզային մարմին
7) Շիրակի մարզային մարմին
8) Սյունիքի մարզային մարմին
9) Վայոց ձորի մարզային մարմին
10) Տավուշի մարզային մարմին
(հավելվածը փոփ. 12.04.18 N 412-Ն)
