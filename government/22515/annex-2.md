# Հավելված N 2 ՀՀ կառավարության 2002 թվականի սեպտեմբերի 19-ի N 1797-Ն որոշման
Կ Ա Ռ ՈՒ Ց Վ Ա Ծ Ք ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԳԵՂԱՐՔՈՒՆԻՔԻ ՄԱՐԶՊԵՏԱՐԱՆԻ ԱՇԽԱՏԱԿԱԶՄԻ I. Կառուցվածքային ստորաբաժանումներ 1. Վարչություններ Ֆինանսական և սոցիալ-տնտեսական զարգացման վարչությունՔաղաքաշինության վարչությունԳյուղատնտեսության վարչությունԲնապահպանության վարչությունԿրթության, մշակույթի և սպորտի վարչությունԱռողջապահության և սոցիալական ապահովության վարչություն Տեղական ինքնակառավարման և հանրապետական գործադիր մարմինների տարածքային ծառայությունների գործունեության համակարգման վարչություն(1-ին կետը փոփ. 16.01.03 N 31-Ն) 2. Քարտուղարություն 3. Բաժիններ Տրանսպորտի և ճանապարհաշինության բաժինՀողաշինության և հողօգտագործման բաժին - մարզային հողային պետական տեսչությունԵրեխաների իրավունքների պաշտպանության բաժին(3-րդ կետը լրաց. 27.10.05 N 1833-Ն) II. Առանձնացված ստորաբաժանումներ Գավառի սոցիալական ծառայությունների տարածքային գործակալությունՍևանի սոցիալական ծառայությունների տարածքային գործակալությունՃամբարակի սոցիալական ծառայությունների տարածքային գործակալությունՄարտունու սոցիալական ծառայությունների տարածքային գործակալությունՎարդենիսի սոցիալական ծառայությունների տարածքային գործակալություն(2-րդ բաժինը փոփ. 29.12.05 N 2337-Ն)
