Ս. Օհանյան | - | ՀՀ պաշտպանության նախարար (հանձնաժողովի նախագահ)
Յու. Խաչատուրով | - | ՀՀ զինված ուժերի գլխավոր շտաբի պետ (հանձնաժողովի նախագահի տեղակալ)
Ս. Չալյան | - | ՀՀ զինվորական կոմիսար
Ա. Սարգսյան | - | ՀՀ կառավարությանն առընթեր ՀՀ ոստիկանության պետ
Գ. Հակոբյան | - | ՀՀ կառավարությանն առընթեր ազգային անվտանգության ծառայության տնօրեն
Հ. Քուշկյան | - | ՀՀ առողջապահության նախարար
Ա. Հովսեփյան | - | ՀՀ գլխավոր դատախազ
Է. Նալբանդյան | - | ՀՀ արտաքին գործերի նախարար
Մ. Վարդանյան | - | ՀՀ տրանսպորտի և կապի նախարար
Ա. Աշոտյան | - | ՀՀ կրթության և գիտության նախարար
Հ. Կարապետյան | - | ՀՀ Ազգային ժողովի պաշտպանության, ազգային անվտանգության և ներքին գործերի մշտական հանձնաժողովի նախագահ (համաձայնությամբ)
Վ. Ասցատրյան | - | ՀՀ կառավարության աշխատակազմի ազգային փոքրամասնությունների և կրոնի հարցերի վարչության պետ
Ա. Վահանյան | - | ՀՀ կառավարության աշխատակազմի պետաիրավական վարչության պետ (հանձնաժողովի քարտուղար)
