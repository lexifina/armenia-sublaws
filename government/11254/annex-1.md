# Հավելված ՀՀ կառավարության 2003 թվականի օգոստոսի 21-ի N 1055-Ն որոշման
Կ Ա Ր Գ
ԸՆԴԵՐՔԻ ԵՐԿՐԱԲԱՆԱԿԱՆ ՈՒՍՈՒՄՆԱՍԻՐՈՒԹՅԱՆ ԱՇԽԱՏԱՆՔՆԵՐԻ ՊԵՏԱԿԱՆ ԳՐԱՆՑՄԱՆ ԵՎ ՀԱՇՎԱՌՄԱՆ
1. Սույն կարգով կանոնակարգվում է Հայաստանի Հանրապետության տարածքում իրավաբանական անձանց (այդ թվում՝ օտարերկրյա) և Հայաստանի Հանրապետության քաղաքացիների (այսուհետ՝ ընդերքօգտագործողներ) կողմից կատարվող ընդերքի երկրաբանական ուսումնասիրության աշխատանքների պետական գրանցման և հաշվառման գործընթացը:
2. Ընդերքի երկրաբանական ուսումնասիրության աշխատանքների պետական գրանցումն ու հաշվառումն իրականացնում է Հայաստանի Հանրապետության էներգետիկայի և բնական պաշարների նախարարությունը (այսուհետ` լիազոր մարմին):
(2-րդ կետը փոփ. 29.01.10 N 65-Ն, 30.06.11 N 894-Ն)
3. Երկրաբանական ուսումնասիրության նպատակով տրամադրված ընդերքօգտագործման իրավունքը հավաստող փաստաթղթերի լրակազմ փաթեթի պատճենի առկայության դեպքում լիազոր մարմինը 10-օրյա ժամկետում կատարում է ընդերքի երկրաբանական ուսումնասիրության աշխատանքների պետական գրանցում` ըստ ուսումնասիրության ձևերի:
(3-րդ կետը խմբ. 30.06.11 N 894-Ն)
4. Ընդերքի երկրաբանական ուսումնասիրության աշխատանքները գրանցվում են պետական գրանցման գրանցամատյանում, և տրվում է գրանցման մասին տեղեկանք՝ 3 օրինակից. առաջինը տրամադրվում է ընդերքօգտագործողին, 2-րդ օրինակը` պետական գրանցում կատարող մարմնին, իսկ 3-րդ օրինակը` հանքային իրավունք տրամադրող մարմնին:
(4-րդ կետը խմբ. 30.06.11 N 894-Ն)
5. Ընդերքի երկրաբանական ուսումնասիրության աշխատանքների արդյունքների մասին ամփոփ տեղեկատվությունը (հաշվետվություն) Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով ենթակա է հաշվառման` հաշվետվությունների հաշվառման գրանցամատյանում:
(5-րդ կետը խմբ. 30.06.11 N 894-Ն)
6. (կետն ուժը կորցրել է 30.06.11 N 894-Ն)
7. Ընդերքի տեղամասի երկրաբանական ուսումնասիրության աշխատանքների պետական գրանցումը կատարվում է մեկ անգամ:
8. Երկրաբանական ուսումնասիրության նպատակով տրամադրված ընդերքօգտագործման իրավունքը հավաստող փաստաթղթերի փաթեթում փոփոխության կատարման դեպքում աշխատանքը վերագրանցվում է սույն կարգի 3-րդ կետի համաձայն:
(8-րդ կետը խմբ. 30.06.11 N 894-Ն)
9. Երկրաբանական ուսումնասիրության աշխատանքների մասին հաշվետվությունների յուրաքանչյուր հատորի տիտղոսաթերթի վրա պետք է նշված լինի պետական գրանցման համարը:
(9-րդ կետը փոփ. 30.06.11 N 894-Ն)
10. (կետն ուժը կորցրել է 30.06.11 N 894-Ն)
11. (կետն ուժը կորցրել է 30.06.11 N 894-Ն)
12. Սույն կարգի 5-րդ կետում նշված ամփոփ տեղեկատվությունը (հաշվետվություն) լիազոր մարմնում պահպանվում է անժամկետ:
(12-րդ կետը խմբ. 30.06.11 N 894-Ն)
13. Պետական և ծառայողական գաղտնիք պարունակող երկրաբանական ուսումնասիրության աշխատանքները գրանցվում ու նյութերը հաշվառվում են Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով:
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
