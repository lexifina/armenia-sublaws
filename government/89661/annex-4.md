# Հավելված N 4 ՀՀ կառավարության 2014 թվականի ապրիլի 3-ի N 368-Ն որոշման
«ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ 2014 ԹՎԱԿԱՆԻ ՊԵՏԱԿԱՆ ԲՅՈՒՋԵԻ ՄԱՍԻՆ» ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՕՐԵՆՔԻ 8-ՐԴ ՀՈԴՎԱԾԻ ԱՂՅՈՒՍԱԿՈՒՄ ԵՎ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆ 2013 ԹՎԱԿԱՆԻ ԴԵԿՏԵՄԲԵՐԻ 19-Ի N 1414-Ն ՈՐՈՇՄԱՆ N 4 ՀԱՎԵԼՎԱԾՈՒՄ ԿԱՏԱՐՎՈՂ ՓՈՓՈԽՈՒԹՅՈՒՆՆԵՐԸ (հավելվածն ուժը կորցրել է 25.12.14 N 1532-Ն)
