# Հավելված ՀՀ կառավարության 2006 թվականի փետրվարի 9-ի N 146-Ն որոշման
Կ Ա Ր Գ ԾԱՌԱՅՈՒԹՅԱՆ ԺԱՄԱՆԱԿ ԶՈՀՎԱԾ (ՄԱՀԱՑԱԾ) ՓՐԿԱՐԱՐԱԿԱՆ ԾԱՌԱՅՈՂՆԵՐԻ ՀՈՒՂԱՐԿԱՎՈՐՈՒԹՅԱՆ, ԳԵՐԵԶՄԱՆՆԵՐԻ ԲԱՐԵԿԱՐԳՄԱՆ, ՏԱՊԱՆԱՔԱՐԵՐԻ ՊԱՏՐԱՍՏՄԱՆ ԵՎ ՏԵՂԱԴՐՄԱՆ ՀԵՏ ԿԱՊՎԱԾ ԾԱԽՍԵՐԻ ՓՈԽՀԱՏՈՒՑՄԱՆ
1. Սույն կարգով սահմանվում են փրկարարական ծառայության ընթացքում զոհված (մահացած), օրենքով սահմանված կարգով մահացած ճանաչված փրկարարական ծառայողների (այսուհետ` զոհված փրկարարական ծառայողներ) հուղարկավորության, գերեզմանների բարեկարգման, տապանաքարերի պատրաստման և տեղադրման հետ կապված` Հայաստանի Հանրապետության պետական բյուջեի միջոցների հաշվին կատարվող ծախսերի չափն ու վճարման կարգը:
2. Փրկարարական ծառայության ընթացքում զոհված (մահացած) փրկարարական ծառայողների հուղարկավորության հետ կապված ծախսերը հատուցվում են Հայաստանի Հանրապետության պետական բյուջեի հաշվին` 700.000 դրամի չափով (բյուջետային տարում նախատեսված միջին ծրագրային ցուցանիշի հաշվարկով):
(2-րդ կետը փոփ. 21.12.06 N 1828-Ն)
3. Փրկարարական ծառայության ընթացքում զոհված ծառայողների (բացառությամբ «Եռաբլուր» պանթեոնում և այլ քաղաքների եղբայրական գերեզմանոցներում հուղարկավորվածների) գերեզմանների բարեկարգման, տապանաքարերի պատրաստման և տեղադրման համար նրանց ընտանիքների անդամներին Հայաստանի Հանրապետության պետական բյուջեից հատկացվում է 1.400.000 դրամ (բյուջետային տարում նախատեսված միջին ծրագրային ցուցանիշի հաշվարկով):
(3-րդ կետը փոփ. 21.12.06 N 1828-Ն)
4. Զոհված փրկարարական ծառայողների հուղարկավորության, գերեզմանների բարեկարգման, տապանաքարերի պատրաստման և տեղադրման հետ կապված ծախսերի փոխհատուցման նպատակով փրկարար ծառայության հանրապետական գործադիր մարմինը կազմում ու ֆինանսավորման նպատակով Աշխատանքի և սոցիալական հարցերի նախարարություն է ներկայացնում այն զոհված (մահացած) փրկարարական ծառայողների ցուցակները, որոնց ընտանիքներին նախատեսվում է Հայաստանի Հանրապետության պետական բյուջեից փոխհատուցել հուղարկավորության, գերեզմանների բարեկարգման, տապանաքարերի պատրաստման և տեղադրման հետ կապված ծախսերը: Ցուցակներում նշվում են զոհված (մահացած) փրկարարական ծառայողների անձնական տվյալները (անունը, ազգանունը, հայրանունը), մահվան տարեթիվը, մահվան վկայականի համարը, յուրաքանչյուր զոհված (մահացած) փրկարարական ծառայողի մասով փոխհատուցման ենթակա գումարի չափը, զոհված (մահացած) փրկարարական ծառայողի ընտանիքի՝ փոխհատուցման գումար ստացող ընտանիքի անդամի անունը, ազգանունը, հայրանունը, անձնագրի համարը, բնակության և էլեկտրոնային հասցեն (առկայության դեպքում), գումարն ստացողի բանկային ռեկվիզիտները, իսկ դրա բացակայության դեպքում՝ Հայաստանի Հանրապետության այն տարածաշրջանը, որտեղ գործող բանկերից շահառուն նախընտրում է ստանալ գումարը:
(4-րդ կետը փոփ. 21.08.08 N 1042-Ն, 25.09.14 N 1039-Ն, խմբ. 23.07.15 N 818-Ն, փոփ. 05.12.19 N 1719-Ն)
5. Աշխատանքի և սոցիալական հարցերի նախարարությունն ստացված տեղեկատվության հիման վրա փոխհատուցման ենթակա գումարները փոխանցում է սույն որոշման 1-ին կետով հաստատված հավելվածի 4-րդ կետում նշված գումարը ստացողի բանկային հաշվին, իսկ դրա բացակայության դեպքում՝ այն բանկի հաշվին, որտեղից շահառուն անձնագիրը ներկայացնելու դեպքում կարող է ստանալ գումարը:
(5-րդ կետը խմբ. 23.07.15 N 818-Ն, փոփ. 05.12.19 N 1719-Ն)
6. (կետն ուժը կորցրել է 23.07.15 N 818-Ն)
7. Աշխատանքի և սոցիալական հարցերի նախարարությունը գործող ընթացակարգերի պահանջներին համապատասխան՝ սահմանված կարգով վճարման հիմք հանդիսացող փաստաթղթերն ստանալուց հետո, հասանելիք գումարը հինգ աշխատանքային օրվա ընթացքում վճարում է շահառուին և այդ մասին երկու աշխատանքային օրվա ընթացքում պատվիրված նամակով իրազեկում է վերջինիս:
(7-րդ կետը փոփ. 21.08.08 N 1042-Ն, 25.09.14 N 1039-Ն, խմբ. 23.07.15 N 818-Ն, փոփ. 05.12.19 N 1719-Ն)
8. Եթե զոհված փրկարարական ծառայողների գերեզմանները բարեկարգված են նրանց ընտանիքների անդամների ուժերով, ապա համապատասխան փաստաթղթեր ներկայացվելու դեպքում փոխհատուցվում է գերեզմանների կառուցապատման աշխատանքների փաստացի արժեքը, բայց հաստատված ծախսերի նորմատիվներից ոչ ավելի:
9. Հայաստանի Հանրապետությունից դուրս այլ վայրերում փրկարարական ծառայողների հուղարկավորության, գերեզմանների բարեկարգման, տապանաքարերի պատրաստման և տեղադրման ծախսերը փոխհատուցվում են զոհվածների ընտանիքների բնակության վայրում:
Ծառայողական պարտականությունները կատարելիս անհայտ կորած և օրենքով սահմանված կարգով մահացած ճանաչված փրկարարական ծառայողների ընտանիքներին փոխհատուցումը կատարվում է սույն կարգի 3-րդ կետով նախատեսված գումարի չափով:
(հավելվածը փոփ. 21.12.06 N 1828-Ն, 21.08.08 N 1042-Ն, 25.09.14 N 1039-Ն, խմբ., փոփ. 23.07.15 N 818-Ն, փոփ. 05.12.19 N 1719-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
