# Հավելված N 1 ՀՀ կառավարության 2010 թվականի օգոստոսի 26-ի N 1072-Ն որոշման
Կ Ա Ն Ո Ն Ա Դ Ր ՈՒ Թ Յ ՈՒ Ն ԵՎ Ն Կ Ա Ր Ա Գ Ր ՈՒ Թ Յ ՈՒ Ն ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԱՐՏԱԿԱՐԳ ԻՐԱՎԻՃԱԿՆԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԴՐՈՇԻ (վերնագիրը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 1. Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության դրոշը պատվի և արժանապատվության, արիության ու նվիրումի խորհրդանիշ է: Դրոշը Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության յուրաքանչյուր աշխատողի սրբազան պարտքի հիշեցումն է հայրենիքին անձնուրաց ծառայելու, արտակարգ իրավիճակներում բնակչության պաշտպանության և քաղաքացիական պաշտպանության միջոցառումներն անվերապահորեն կատարելու, յուրաքանչյուր մարդու կյանքը, առողջությունն ու գույքը փրկելու, կյանքին սպառնացող վտանգի պայմաններում ծառայողական կամ քաղաքացիական պարտքն իրականացնելու մասին: (1-ին կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 2. Դրոշը Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարությանը հանձնում է Հայաստանի Հանրապետության վարչապետը կամ նրա կողմից լիազորված անձը: (2-րդ կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 3. Դրոշի հետ հանձնվում է Հայաստանի Հանրապետության վարչապետի ստորագրությամբ վկայագիր: 4. Դրոշը մշտապես պահվում է Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարությունում: (4-րդ կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 5. Դրոշի պահման, պահպանման և օգտագործման կարգը սահմանում է Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարը: (5-րդ կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 6. Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության յուրաքանչյուր ծառայող պարտավոր է պահպանել և պաշտպանել դրոշը: (6-րդ կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 7. Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության դրոշը բաղկացած է երկդեմ պաստառից և ծոպափնջերով քուղերից, կտորի գույնի համակարգչային հարաբերակցությունն է` C = 98 տոկոս, M = 96 տոկոս, Y = 45 տոկոս, K = 18 տոկոս: Դրոշի պաստառն ուղղանկյունաձև է, երկարությունը 1450 մմ է, լայնությունը՝ 1150 մմ` համաձայն ձևի: (7-րդ կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 8. Դրոշը կարված է երկտակ մետաքսե մուգ կապույտ կտորից՝ երեք կողմից երիզված ոսկեգույն ծոպերով: Պաստառի երեսի կողմի կենտրոնական մասում ոսկեգույն մետաքսաթելով ասեղնագործված են «ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԱՐՏԱԿԱՐԳ ԻՐԱՎԻՃԱԿՆԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅՈՒՆ» բառերը. տառերի բարձրությունը 70 մմ է, լայնությունը՝ 50 մմ: Դրոշի ձախ անկյունում պատկերված է Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության խորհրդանիշը՝ 240 x 160 մմ չափերով: (8-րդ կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 9. Դրոշի պաստառի հակառակ կողմի կենտրոնական մասում պատկերված է Հայաստանի Հանրապետության զինանշանը՝ 300 x 300 մմ չափերով: Հայաստանի Հանրապետության զինանշանի վերին մասում ոսկեգույն մետաքսաթելով կամարաձև ասեղնագործված են «ՀԱՆՈՒՆ ՀԱՅՐԵՆԻՔԻ» բառերը. տառերի բարձրությունը 60 մմ է, լայնությունը՝ 40 մմ: (հավելվածը լրաց. 25.09.15 N 1108-Ն, փոփ., խմբ.19.05.16 N 695-Ն) Ձև Դ Ր Ո Շ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԱՐՏԱԿԱՐԳ ԻՐԱՎԻՃԱԿՆԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ (վերնագիրը խմբ. 25.09.15 N 1108-Ն,19.05.16 N 695-Ն) Նկ. 1. Դրոշի երեսի կողմ Նկ. 2. Դրոշի հակառակ կողմ (հավելվածը խմբ. 25.09.15 N 1108-Ն,19.05.16 N 695-Ն) Կ Ա Ն Ո Ն Ա Դ Ր ՈՒ Թ Յ ՈՒ Ն ԵՎ Ն Կ Ա Ր Ա Գ Ր ՈՒ Թ Յ ՈՒ Ն ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԱՐՏԱԿԱՐԳ ԻՐԱՎԻՃԱԿՆԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԽՈՐՀՐԴԱՆԻՇԻ (վերնագիրը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 1. Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության խորհրդանիշը (այսուհետ` խորհրդանիշ) այն նշանն է, որը ցույց է տալիս ծառայողների, ինչպես նաև նյութատեխնիկական և այլ գույքի պատկանելությունը Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարությանը: (1-ին կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 2. Խորհրդանիշը դրվում է Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարի աշխատասենյակում, ինչպես նաև պատկերվում է Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության դրոշի (դրոշակի) վրա: (2-րդ կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 3. Խորհրդանիշի պատկերը զետեղվում է Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության կենտրոնական ապարատի անմիջական ենթակայության ստորաբաժանումների, նախարարության կառուցվածքային և այլ ստորաբաժանումների անկյունադրոշմակների կամ անկյունադրոշմակով դրոշմաթղթերի վրա: (3-րդ կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 4. Խորհրդանիշը դրվում է Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության ծառայողների համազգեստի, ավտոմեքենաների և այլ հատուկ տեխնիկայի վրա: (4-րդ կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 5. Թույլատրվում է խորհրդանիշի պատկերի կիրառումը տպագրական, գովազդային- տեղեկատվական և հուշանվերային արտադրանքի (ծրագրեր, օրացույցներ, կրծքանշաններ, ժամացույցներ, թղթապանակներ և այլն), տեսաժապավենների վրա` համաձայնեցնելով Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության հետ: (5-րդ կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 6. Խորհրդանիշի պատկերի կիրառման այլ դեպքերը սահմանվում են Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարի կողմից: (6-րդ կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) 7. Խորհրդանիշը պահպանվում է օրենքով սահմանված կարգով: 8. Խորհրդանիշն իրենից ներկայացնում է արծիվ, որի երկարությունը 90 մմ է, լայնությունը` 120 մմ: Այն խորհրդանշում է քաղաքացիական պաշտպանության ու արտակարգ իրավիճակների բնագավառները: Արծվի կենտրոնում պատկերված է Հայաստանի Հանրապետության պետական դրոշը: Արծվի թևի մոտ պատկերված է ութաթև աստղ: Աստղի միջնամասում պատկերված է նարնջագույն շրջան, որի կենտրոնում քաղաքացիական պաշտպանությունը և փրկարարությունը խորհրդանշող հավասարակողմ եռանկյունաձև կապույտ տարբերանշանն է՝ կողմի 20 մմ երկարությամբ: Արծվի թևի ներքևի հատվածում N «7» տառաչափով, հայերենով գրված է «ԱԻՆ»: (8-րդ կետը խմբ. 19.05.16 N 695-Ն) 9. (կետն ուժը կորցրել է 25.09.15 N 1108-Ն) 10. Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության անձնակազմը համազգեստի վրա խորհրդանշանը, որպես տարբերանշան, կրում է ուսաեզրից 80 մմ ներքև, ձախ բազկի կենտրոնում: (10-րդ կետը լրաց. 25.09.15 N 1108-Ն, փոփ.19.05.16 N 695-Ն) (հավելվածը լրաց., խմբ., փոփ. 25.09.15 N 1108-Ն, փոփ., խմբ.19.05.16 N 695-Ն) Ձև Խ Ո Ր Հ Ր Դ Ա Ն Ի Շ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԱՐՏԱԿԱՐԳ ԻՐԱՎԻՃԱԿՆԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ (վերնագիրը խմբ. 25.09.15 N 1108-Ն,19.05.16 N 695-Ն) (հավելվածը խմբ. 25.09.15 N 1108-Ն,19.05.16 N 695-Ն)
