# Հավելված N 3 ՀՀ կառավարության 2004 թվականի հուլիսի 15-ի N 1045-Ն որոշման
Ց Ա Ն Կ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅՈՒՆՈՒՄ ԱՌՈՂՋՈՒԹՅԱՆ ԱՌԱՋՆԱՅԻՆ ՊԱՀՊԱՆՄԱՆ ԿԱԶՄԱԿԵՐՊՄԱՆ ՈՒ ՖԻՆԱՆՍԱՎՈՐՄԱՆ ՆՈՐ ՄԵԹՈԴՆԵՐԻ ՄՇԱԿՄԱՆ 2003-2004 ԹՎԱԿԱՆՆԵՐԻ ՓՈՐՁԱՐԱՐԱԿԱՆ ԾՐԱԳՐԻ ՇՐՋԱՆԱԿՆԵՐՈՒՄ ԲՆԱԿՉՈՒԹՅԱՆ ԱԶԱՏ ՀԱՎԱՔԱԳՐՈՒՄ ԻՐԱԿԱՆԱՑՆՈՂ ԵՎ ԱՌՈՂՋՈՒԹՅԱՆ ԱՌԱՋՆԱՅԻՆ ՊԱՀՊԱՆՄԱՆ ԾԱՌԱՅՈՒԹՅՈՒՆՆԵՐ ՄԱՏՈՒՑՈՂ ԲԺՇԿԻ ԸՆՏՐՈՒԹՅԱՆ ՍԿԶԲՈՒՆՔԸ ՓՈՐՁԱՐԱՐԱԿԱՆ ԿԱՐԳՈՎ ՆԵՐԴՆՈՂ ԲՈՒԺՀԱՍՏԱՏՈՒԹՅՈՒՆՆԵՐԻ
Երևանի քաղաքապետարանի «Գրիգոր Նարեկացի» բժշկական կենտրոն» փակ բաժնետիրական ընկերության Սարի թաղի պոլիկլինիկա և Նոր Արեշի պոլիկլինիկա
«Երևանի Մխիթար Հերացու անվան պետական բժշկական համալսարան» պետական ոչ առևտրային կազմակերպության համալսարանական N 2 կլինիկական հիվանդանոց
Հայաստանի Հանրապետության Լոռու մարզի «Վանաձորի N 1 պոլիկլինիկա» փակ բաժնետիրական ընկերություն
Հայաստանի Հանրապետության Լոռու մարզի «Գուգարք» կենտրոնական պոլիկլինիկա» փակ բաժնետիրական ընկերություն
Հայաստանի Հանրապետության Լոռու մարզի «Վանաձորի N 3 պոլիկլինիկա» փակ բաժնետիրական ընկերություն
Հայաստանի Հանրապետության Լոռու մարզի «Վանաձորի N 5 պոլիկլինիկա» փակ բաժնետիրական ընկերություն
