# Հավելված ՀՀ կառավարության 2003 թվականի հունվարի 16-ի N 133-Ն որոշման
Կ Ա Զ Մ
«ԱՐՓԱ-ՍԵՎԱՆ» ԹՈՒՆԵԼԻ ՏԵԽՆԻԿԱԿԱՆ ՎԻՃԱԿԸ ԳՆԱՀԱՏՈՂ ՄԻՋԳԵՐԱՏԵՍՉԱԿԱՆ ՀԱՆՁՆԱԺՈՂՈՎԻ
Ռ. Ղուկասյան | - | ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի նախագահի տեղակալ (հանձնաժողովի նախագահ)
Է. Բադալյան | - | ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի ջրատնտեսական համակարգերի շահագործման համակարգման վարչության ոռոգման բաժնի պետ
Թ. Մարգարյան | - | ՀՀ քաղաքաշինության նախարարության «Հիդրոտեխնիկական կառույցներ» պետական հիմնարկի տնօրենի տեղակալ
Է. Մանվելյան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարարության գյուղատնտեսության, ջրային տնտեսության և բնապահպանության ծրագրերի վարչության պետի տեղակալ
Վ. Սարգսյան | - | ՀՀ բնապահպանության նախարարության հիդրոօդերևութաբանության և շրջակա միջավայրի մոնիտորինգի գործակալության հիդրոլոգիայի և ջրային ռեսուրսների կենտրոնի պետ
Թ. Մկրտչյան | - | ՀՀ արդյունաբերության մեջ աշխատանքների անվտանգ կատարման և լեռնային հսկողության տեսչության լեռնային տեսչության պետ
Յու. Ջավադյան | - | «Հայջրնախագիծ ինստիտուտ» փակ բաժնետիրական ընկերության գլխավոր տնօրեն (համաձայնությամբ)
Ռ. Հարությունյան | - | «Հայկական սեյսմակայուն շինարարության և կառուցվածքների պահպանության գիտահետազոտական ինստիտուտ» փակ բաժնետիրական ընկերության լաբորատորիայի վարիչ
Մ. Խաչատրյան | - | «Հայհիդրոէներգանախագիծ» փակ բաժնետիրական ընկերության ինժեներահետախուզական բաժնի վարիչ (համաձայնությամբ)
Գ. Պետրոսյան | - | «Արփա-Սևան» բաց բաժնետիրական ընկերության նախագծային բաժնի պետ և նախագծերի գլխավոր ճարտարագետ (համաձայնությամբ).
Լ. Մանուկյան | - | «Լեռնամետալուրգիայի ինստիտուտ» փակ բաժնետիրական ընկերության բաց լեռնային աշխատանքների և գեոմեխանիկայի լաբորատորիայի վարիչ (համաձայնությամբ)
Վ. Զուրաբյանին | - | «Որոտան-Արփա-Սևան» թունելների շահագործման վարչություն» պետական հիմնարկի տնօրեն (հանձնաժողովի քարտուղար).
(Կազմը խմբ., փոփ. 29.05.03 N 650-Ն)
