# Հավելված ՀՀ կառավարության 2002 թվականի դեկտեմբերի 19-ի N 2100-Ն որոշման
Կ Ա Ր Գ
ՄԱՔՍԱՅԻՆ ԾԱՌԱՅՈՒԹՅԱՆ ՀԱՏՈՒԿ ԿՈՉՈՒՄ ՇՆՈՐՀԵԼԻՍ ՄԱՔՍԱՅԻՆ ԾԱՌԱՅՈՂԻ ՆԱԽԿԻՆ ԱՇԽԱՏԱՆՔԻ ԿԱՄ ԾԱՌԱՅՈՒԹՅԱՆ ՎԱՅՐՈՒՄ ՇՆՈՐՀՎԱԾ ԴԱՍԱՅԻՆ, ՀԱՏՈՒԿ ԿԱՄ ԶԻՆՎՈՐԱԿԱՆ ԿՈՉՈՒՄԸ ՀԱՇՎԻ ԱՌՆԵԼՈՒ
1. Սույն կարգով սահմանվում է մաքսային ծառայության հատուկ կոչում շնորհելիս մաքսային ծառայողի նախկին աշխատանքի կամ ծառայության վայրում շնորհված դասային, հատուկ կամ զինվորական կոչումը հաշվի առնելու կարգը:
2. Մաքսային ծառայողին մաքսային ծառայության հատուկ կոչում շնորհելիս մաքսային ծառայողի նախկին աշխատանքի կամ ծառայության վայրում շնորհված դասային, հատուկ կամ զինվորական կոչումը հաշվի է առնվում, եթե այն բարձր չէ մաքսային ծառայության տվյալ պաշտոնին հասանելիք առավելագույն կոչումից:
3. Մաքսային ծառայության տվյալ պաշտոնի համար սահմանված առավելագույն հատուկ կոչումից բարձր կոչում ունենալու դեպքում մաքսային ծառայողի նախկին ծառայության վայրում շնորհված դասային, հատուկ կամ զինվորական կոչումը հաշվի առնելով՝ մաքսային ծառայողին շնորհվում է տվյալ պաշտոնին համապատասխան առավելագույն հատուկ կոչում:
Այլ պետական մարմիններում շնորհված զինվորական կամ հատուկ կոչումները (դասային կոչումները) հավասարապես համապատասխանում են մաքսային ծառայության հատուկ կոչումներին:
4. Մաքսային ծառայության տվյալ պաշտոնի համար սահմանված առավելագույն հատուկ կոչումից բարձր կոչում ունենալու դեպքում մաքսային ծառայողի նախկին ծառայության վայրում շնորհված հատուկ կամ զինվորական կոչումը հաշվի առնելով՝ մաքսային ծառայողին վերադաս մաքսային մարմնի ղեկավարի հայեցողությամբ կարող է շնորհվել տվյալ պաշտոնին համապատասխան առավելագույն հատուկ կոչումից բարձր կոչում (բացառությամբ մաքսային ծառայության գեներալ-մայորի հատուկ կոչման), եթե տվյալ պաշտոնի հիմնական նկարագիրը (անձնագիրը) համապատասխանում է նախկին աշխատանքի կամ ծառայության վայրի պաշտոնի նկարագրին:
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
