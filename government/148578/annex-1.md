# Հավելված N 1 ՀՀ կառավարության 2020 թվականի դեկտեմբերի 24-ի N 2136-Ն որոշման
Կ Ա Զ Մ
ՀԱՆՐԱՊԵՏԱԿԱՆ ԶՈՐԱԿՈՉԱՅԻՆ ՀԱՆՁՆԱԺՈՂՈՎԻ
Վ. Հարությունյան | - ՀՀ պաշտպանության նախարար (հանձնաժողովի նախագահ)
Օ. Գասպարյան | - ՀՀ զինված ուժերի գլխավոր շտաբի պետ (հանձնաժողովի նախագահի տեղակալ)
Ա. Ավթանդիլյան | - ՀՀ ՊՆ զորակոչային և զորահավաքային համալրման ծառայության պետ
Վ. Ղազարյան | - ՀՀ ոստիկանության պետ
Ա. Աբազյան | - ՀՀ ազգային անվտանգության ծառայության տնօրեն
Ա. Դավթյան | - ՀՀ գլխավոր դատախազ (համաձայնությամբ)
Վ. Դումանյան | - ՀՀ կրթության, գիտության, մշակույթի և սպորտի նախարար
Հ. Արշակյան | - ՀՀ բարձր տեխնոլոգիական արդյունաբերության նախարար
Ա. Ավանեսյան | - ՀՀ առողջապահության նախարար
Ա. Այվազյան | - ՀՀ արտաքին գործերի նախարար
Ս. Պապիկյան | - ՀՀ տարածքային կառավարման և ենթակառուցվածքների նախարար
Ա. Սարգսյան | - ՀՀ ՊՆ զորակոչային և զորահավաքային համալրման ծառայության զորակոչի վարչության պետ (հանձնաժողովի քարտուղար)
(հավելվածը փոփ. 11.03.21 N 324-Ն)
Հայաստանի Հանրապետության վարչապետի աշխատակազմի ղեկավար | Է. Աղաջանյան
