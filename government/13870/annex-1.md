# Հավելված N 1 ՀՀ կառավարության 2005 թվականի հունիսի 1-ի N 739-Ն որոշման
Կ Ա Ր Գ
6 ԿՎ ԵՎ ԲԱՐՁՐ ԼԱՐՄԱՆ ՆՈՐ ԿԱՌՈՒՑՎՈՂ ԵՎ ՎԵՐԱԿԱՌՈՒՑՎՈՂ ԷԼԵԿՏՐԱՏԵՂԱԿԱՅԱՆՔՆԵՐԻ ԳՈՐԾԱՐԿՄԱՆ ԵԶՐԱԿԱՑՈՒԹՅՈՒՆ ՏԱԼՈՒ
1. Սույն կարգը մշակված է «Էներգետիկայի բնագավառում և էներգասպառման ոլորտում պետական տեխնիկական վերահսկողության մասին» Հայաստանի Հանրապետության օրենքի 6-րդ հոդվածի պահանջին համապատասխան և սահմանում է 6 կՎ և բարձր լարման նոր կառուցվող և վերակառուցվող էլեկտրատեղակայանքների գործարկման եզրակացություն տալու գործընթացը:
(1-ին կետը փոփ. 26.05.06 N 682-Ն)
1¹. Սույն կարգում օգտագործվող հասկացություններն ունեն հետևյալ իմաստները`
էլեկտրատեղակայանք` էլեկտրական էներգիայի արտադրության կամ կերպափոխման, հաղորդման, բաշխման կամ սպառման համար նախատեսված էներգատեղակայանք,
էլեկտրատնտեսություն` էլեկտրատեղակայանքների և օժանդակ կառույցների համալիր:
(1¹-ին կետը լրաց. 26.05.06 N 682-Ն)
2. Սույն կարգի գործողությունը տարածվում է էլեկտրաէներգետիկական համակարգում գործունեություն իրականացնող անձանց ու տեխնոլոգիական և կենցաղային նպատակներով էլեկտրական էներգիա սպառողների (այսուհետ՝ սպառողներ) վրա:
3. Էլեկտրաէներգետիկական համակարգում գործունեություն իրականացնող անձանց և էլեկտրական էներգիա սպառողների 6 կՎ և բարձր լարման էլեկտրատեղակայանքների (այսուհետ` Էլեկտրատեղակայանքներ) գործարկման եզրակացությունը` գործարկման թույլտվությունը տրվում է Հայաստանի Հանրապետության քաղաքաշինության, տեխնիկական և հրդեհային անվտանգության տեսչական մարմնի կողմից (այսուհետ՝ տեսչական մարմին):
(3-րդ կետը փոփ. 26.05.06 N 682-Ն, 15.01.09 N 52-Ն, 10.12.20 N 2010-Ն)
4. Նոր կառուցվող և վերակառուցվող Էլեկտրատեղակայանքները պետք է կառուցվեն նախագծին համապատասխան:
5. Էլեկտրատեղակայանքները գործարկմանը պատրաստ լինելու դեպքում դրանց սեփականատերը (լիազորված անձը) գրավոր դիմում է տեսչական մարմին` միաժամանակ ներկայացնելով 6 կՎ և բարձր լարման էլեկտրատեղակայանքների կառուցման ու վերակառուցման համար տրված էլեկտրասնման տեխնիկական պայմանները: Դիմումը կարող է ներկայացվել առձեռն, փոստով կամ էլեկտրոնային փոստի միջոցով:
(5-րդ կետը փոփ. 26.05.06 N 682-Ն, խմբ. 10.09.15 N 1047-Ն, փոփ. 10.12.20 N 2010-Ն)
6. Էլեկտրատեղակայանքների սեփականատիրոջ դիմումն ստանալուց հետո հինգ աշխատանքային օրվա ընթացքում տեսչական մարմնի ծառայողը կատարում է էլեկտրատեղակայանքների ակնադիտական ուսումնասիրություն և կազմում ակտ-կարգադրագիր, որում, համաձայն Հայաստանի Հանրապետության կառավարության 2005 թվականի հունիսի 1-ի N 739-Ն որոշման N 2 հավելվածի ցանկի, նշվում են էլեկտրոնային փոստի միջոցով, իսկ առանձին դեպքերում` փոստի, թղթային ձևով, տեսչական մարմին ներկայացված տեխնիկական փաստաթղթերի անվանումները, ինչպես նաև տեղադրված և հավաքակցված էլեկտրատեղակայանքների համապատասխանությունը նախագծին, տեխնիկական պայմաններին և տեխնիկական կանոնակարգերին: Տեսչական մարմնի կողմից ընդունելի են համարվում անվտանգության որևէ նորմի խախտմանը չհանգեցնող նախագծից այն տարբերությունները, որոնք փաստացի առկա են և գրավոր հիմնավորված: Ակտ-կարգադրագրի դրական եզրակացության հիման վրա տրվում է Հայաստանի Հանրապետության կառավարության 2005 թվականի հունիսի 1-ի N 739-Ն որոշման N 3 հավելվածով նախատեսված էլեկտրատեղակայանքի գործարկման եզրակացությունը:
(6-րդ կետը փոփ., լրաց. 31.10.13 N 1196-Ն, խմբ. 10.09.15 N 1047-Ն, 12.10.17 N 1294-Ն, փոփ.10.12.20 N 2010-Ն)
7. Տեսչական մարմնի կողմից Էլեկտրատեղակայանքների գործարկման եզրակացություն տալու նպատակով իրականացվող գործընթացը կատարվում է էլեկտրատնտեսության պատասխանատու անձի (սեփականատիրոջ և (կամ) լիազորված պաշտոնատար անձի) մասնակցությամբ:
(7-րդ կետը փոփ. 26.05.06 N 682-Ն, 10.12.20 N 2010-Ն)
8. Անհրաժեշտության դեպքում, երբ Էլեկտրատեղակայանքի (հանգույցի) ակնադիտական ուսումնասիրության արդյունքում ի հայտ են գալիս դրանց փաստացի բավարար տեխնիկական վիճակից շեղումներ, տեսչական մարմնի ծառայողի պահանջով կարող է կատարվել Էլեկտրատեղակայանքի (հանգույցի) անհատական փորձարկում՝ շահագործող անձնակազմի կողմից` պահպանելով փորձարկումների անվտանգությունը: Տեսչական մարմնի ծառայողն իրավունք չունի նշված փորձարկումների շրջանակներում ինքնուրույն կատարելու որևէ աշխատանք:
(8-րդ կետը փոփ. 10.12.20 N 2010-Ն)
9. Էլեկտրատեղակայանքների` նախագծին, տեխնիկական կանոնակարգերին և տրված տեխնիկական պայմաններին անհամապատասխանության, նախատեսված հավաքակցման աշխատանքների թերի կատարման, էլեկտրատնտեսության պատասխանատու անձի կամ շահագործող անձնակազմի բացակայության դեպքում տեսչական մարմնի ծառայողը կազմում է բացասական եզրակացությամբ ակտ-կարգադրագիր` նշելով թերությունները:
(9-րդ կետը փոփ.12.10.17 N 1294-Ն, 10.12.20 N 2010-Ն)
10. Ակտ-կարգադրագրում նշված թերությունների վերացման մասին էլեկտրատեղակայանքների սեփականատիրոջ (լիազորված անձի) գրավոր դիմումից հետո, տեսչական մարմնի ծառայողը թերությունների վերացումը հաստատելու և գործարկման եզրակացություն տալու նպատակով երեք աշխատանքային օրվա ընթացքում կատարում է էլեկտրատեղակայանքների ակնադիտական ուսումնասիրություն, և թերությունների վերացումը հաստատելու դեպքում տրվում է էլեկտրատեղակայանքի գործարկման եզրակացություն:
(10-րդ կետը փոփ. 31.10.13 N 1196-Ն, խմբ. 10.09.15 N 1047-Ն, փոփ. 10.12.20 N 2010-Ն)
11. 6 կՎ և բարձր լարման նոր կառուցվող և վերակառուցվող էլեկտրատեղակայանքները գործարկվում են տեսչական մարմնի կողմից տրված էլեկտրատեղակայանքի գործարկման եզրակացության առկայության դեպքում:
