# Հավելված N 1 ՀՀ կառավարության 2018 թվականի մայիսի 3-ի N 536-Ն որոշման
Կ Ա Զ Մ
ՀԱՆՐԱՊԵՏԱԿԱՆ ԶՈՐԱԿՈՉԱՅԻՆ ՀԱՆՁՆԱԺՈՂՈՎԻ
Դ. Տոնոյան | - ՀՀ պաշտպանության նախարար (հանձնաժողովի նախագահ)
Ա. Դավթյան | - ՀՀ զինված ուժերի գլխավոր շտաբի պետ (հանձնաժողովի նախագահի տեղակալ)
Ա. Թորոսյան | - ՀՀ առողջապահության նախարար
Ա. Հակոբյան | - ՀՀ տրանսպորտի, կապի և տեղեկատվական տեխնոլոգիաների նախարար
Ա. Հարությունյան | - ՀՀ կրթության և գիտության նախարար
Զ. Մնացականյան | - ՀՀ արտաքին գործերի նախարար
Ս. Պապիկյան | - ՀՀ տարածքային կառավարման և զարգացման նախարար
Հ. Մուրադյան | - ՀՀ զինվորական կոմիսար
Վ. Օսիպյան | - ՀՀ ոստիկանության պետ
Ա. Վանեցյան | - ՀՀ ազգային անվտանգության ծառայության տնօրեն
Ա. Դավթյան | - ՀՀ գլխավոր դատախազ (համաձայնությամբ)
Կ. Նահապետյան | - ՀՀ Ազգային ժողովի պաշտպանության, ազգային անվտանգության և ներքին գործերի մշտական հանձնաժողովի նախագահ (համաձայնությամբ)
Ա. Սարգսյան | - ՀՀ զինվորական կոմիսարիատի զորակոչի բաժնի պետ (հանձնաժողովի քարտուղար)
(հավելվածը խմբ. 21.06.18 N 694-Ն)
