# Հավելված ՀՀ կառավարության 2023 թվականի ապրիլի 27-ի N 641-Ն որոշման
Կ Ա Ր Գ
ՈՒՍՈՒՄՆԱԿԱՆ ՀԱՍՏԱՏՈՒԹՅՈՒՆՆԵՐԻՆ ՆԱԽՆԱԿԱՆ ԶԻՆՎՈՐԱԿԱՆ ՊԱՏՐԱՍՏՈՒԹՅԱՆ ՆՊԱՏԱԿՈՎ ՈՒՍՈՒՄՆԱԿԱՆ ԶԵՆՔ ԵՎ ուսումնական փամփուշտներ ՀԱՏԿԱՑՆԵԼՈՒ (վերնագիրը լրաց. 14.06.24 N 903-Ն)
1․ Սույն կարգով կարգավորվում են Հայաստանի Հանրապետության ուսումնական հաստատություններին նախնական զինվորական պատրաստության նպատակով ուսումնական զենքի և ուսումնական փամփուշտների հատկացման կարգի հետ կապված հարաբերությունները։
(1-ին կետը լրաց. 14.06.24 N 903-Ն)
2. (կետն ուժը կորցրել է 14.06.24 N 903-Ն)
3. Ուսումնական զենքի և ուսումնական փամփուշտների անհրաժեշտ քանակության հաշվառումը կատարում է Հայաստանի Հանրապետության կրթության, գիտության, մշակույթի և սպորտի նախարարությունը:
(3-րդ կետը լրաց. 14.06.24 N 903-Ն)
4. Հաշվառման հիման վրա, ուսումնական զենքի և ուսումնական փամփուշտների պահանջվող քանակությունը ճշտելուց հետո, յուրաքանչյուր ուսումնական տարվա սկզբին Հայաստանի Հանրապետության կրթության, գիտության, մշակույթի և սպորտի նախարարությունը հայտ է ներկայացնում Հայաստանի Հանրապետության պաշտպանության նախարարություն։
(4-րդ կետը լրաց. 14.06.24 N 903-Ն)
5. Հայաստանի Հանրապետության պաշտպանության նախարարությունն ստանալով հայտը Հայաստանի Հանրապետության ներքին գործերի նախարարության ոստիկանությանը (այսուհետ՝ ոստիկանություն) հատկացնում է Հայաստանի Հանրապետության ուսումնական հաստատությունների համար նախատեսված ուսումնական զենքը և ուսումնական փամփուշտները:
(5-րդ կետը լրաց. 14.06.24 N 903-Ն)
6. Ոստիկանությունն ուսումնական հաստատություններին ուսումնական զենքի և ուսումնական փամփուշտների հատկացումն իրականացնում է ոստիկանության կառուցվածքային տարածքային ստորաբաժանումների միջոցով։
(6-րդ կետը լրաց. 14.06.24 N 903-Ն)
7. Ոստիկանության կառուցվածքային տարածքային ստորաբաժանման համապատասխան ծառայողն ստուգում է ուսումնական հաստատություններում ուսումնական զենքի և ուսումնական փամփուշտների պահման պայմանները և կազմում համապատասխան ակտ:
(7-րդ կետը լրաց. 14.06.24 N 903-Ն)
8․ Զենք և ուսումնական փամփուշտներ պահելու պայմանների համապատասխանության դեպքում ուսումնական զենքը և ուսումնական փամփուշտները հանձնվում է ուսումնական հաստատության զենքի և ուսումնական փամփուշտների պահպանության համար պատասխանատու անձին և սահմանված կարգով կատարվում է հաշվառում:
(8-րդ կետը լրաց. 14.06.24 N 903-Ն)
9. Ուսումնական հաստատությունները վարում են ուսումնական զենքի և ուսումնական փամփուշտների, այդ թվում՝ նաև ի պահ հանձնված ուսումնական զենքի և ուսումնական փամփուշտների հաշվառման մատյան։
(9-րդ կետը լրաց. 14.06.24 N 903-Ն)
(հավելվածը լրաց. 14.06.24 N 903-Ն)
