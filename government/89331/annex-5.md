# Հավելված N 5 ՀՀ կառավարության 2014 թվականի մարտի 6-ի N 275-Ն որոշման N 3 հավելվածի
Երեխայի ծննդյան միանվագ նպաստի անկանխիկ վճարման և պետական աջակցության հաշվի բացման (ընտանեկան դրամագլխի սպասարկման) պայմանագրի
Ց Ա Ն Կ
ԸՆՏԱՆԵԿԱՆ ԴՐԱՄԱԳԼԽԻ ԳՈՒՄԱՐԻ ՎՃԱՐՄԱՆ ՑՈՒՑԱԿՈՒՄ ՆԵՐԱՌՎՈՂ ՏՎՅԱԼՆԵՐԻ (ԼԻԱԶՈՐ ՄԱՐՄՆԻ ԿՈՂՄԻՑ ՏՐՎՈՒՄ Է ԲԱՆԿԻՆ)
1. Բանկի անվանումը
2. Պետական աջակցության հաշվի համարը
3. Հաշվետիրոջ ազգանունը, անունը (հայրանունը), անձը հաստատող փաստաթղթի սերիան և համարը, հանրային ծառայությունների համարանիշը կամ հանրային ծառայությունների համարանիշ չստանալու մասին տեղեկանքի համարը
4. Ընտանեկան դրամագլուխը տնօրինելու իրավունք ունեցող անձի ազգանունը, անունը (հայրանունը), անձը հաստատող փաստաթղթի սերիան և համարը (տրվում է բացառապես այն դեպքում, երբ հաշվետիրոջ հետ Հայաստանի Հանրապետությունում նույն բնակության վայրում բնակվող (հաշվառված) ծնողը ընտանեկան դրամագլուխը տնօրինելու իրավունք է ձեռք բերում նպաստը նշանակելու դիմումի հիման վրա), հանրային ծառայությունների համարանիշը կամ հանրային ծառայությունների համարանիշ չստանալու մասին տեղեկանքի համարը
(4-րդ կետը լրաց. 29.12.15 N 1564-Ն)
5. Պետական աջակցության հաշվին մուտքագրման ենթակա ընտանեկան դրամագլխի գումարը:
