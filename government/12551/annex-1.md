# Հավելված ՀՀ կառավարության 2004 թվականի հունիսի 3-ի N 829-Ն որոշման

Կ. Խոդիկյան | - | ՀՀ մշակույթի և երիտասարդության հարցերի նախարարի տեղակալ
Ջ. Մովսիսյան | - | ՀՀ արտաքին գործերի նախարարության աշխատակազմի սփյուռքի հետ կապերի գործակալության պետ
Պ. Սաֆարյան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարարի առաջին տեղակալ
Ռ. Ալավերդյան | - | ՀՀ քաղաքաշինության նախարարի տեղակալ
Ա. Գյուրջյան | - | ՀՀ Նախագահի աշխատակազմի ղեկավարի տեղակալ
Մ. Մխիթարյան | - | ՀՀ Ազգային ժողովի պատգամավոր (համաձայնությամբ)
Ա. Հարությունյան | - | Հանրային հեռուստառադիոընկերության խորհրդի նախագահ
Ա. Սահակյան | - | Երևանի քաղաքապետի տեղակալ
Ա. Կարապետյան | - | ՀՀ կառավարության աշխատակազմի սոցիալական հարցերի վարչության պետ
Գերաշնորհ Տ. Փառեն եպիսկոպոս Ավետիքյան | - | Մայր աթոռ Սուրբ Էջմիածնի վարչակազմակերպական գործերի կառավարիչ (համաձայնությամբ)
- | Մեծի Տանն Կիլիկիո կաթողիկոսության ներկայացուցիչ (համաձայնությամբ)
Հայր Վարդան սրբազան Քեշիշյան | - | Հայ Կաթողիկե եկեղեցու և համայնքի առաջնորդի աջակից (համաձայնությամբ)
Ա. Ղազարյան | - | Հայ բարեգործական ընդհանուր միության հայաստանյան ներկայացուցչության տնօրեն (համաձայնությամբ)
Լ. Գալստյան | - | Համազգային հայ կրթական և մշակութային միության հայաստանյան վարչության նախագահ (համաձայնությամբ)
Ռ. Միրզախանյան | - | Հայաստանի Թեքեյան մշակութային միության նախագահ (համաձայնությամբ)
Ն. Մելքումյան | - | «Հայաստան» համահայկական հիմնադրամի գործադիր տնօրեն (համաձայնությամբ)
Ե. Ղազանչյան | - | Հայաստանի թատերական գործիչների միության նախագահ (համաձայնությամբ)
Վ. Խանամիրյան | - | Հայաստանի պարարվեստի գործիչների միության նախագահ (համաձայնությամբ)
Ռ. Ամիրխանյան | - | Հայաստանի կոմպոզիտորների և երաժիշտների միության նախագահ (համաձայնությամբ)
Լ. Անանյան | - | Հայաստանի գրողների միության նախագահ (համաձայնությամբ)
Կ. Աղամյան | - | Հայաստանի նկարիչների միության նախագահ (համաձայնությամբ)
Մ. Մինասյան | - | Հայաստանի ճարտարապետների միության նախագահ (համաձայնությամբ)
Ռ. Գևորգյանց | - | Հայաստանի կինեմատոգրաֆիստների միության նախագահ (համաձայնությամբ)
Ս. Սարաջյան | - | Երևանի Կոմիտասի անվան կոնսերվատորիայի ռեկտոր
Ս. Սարգսյան | - | Երևանի թատրոնի և կինոյի պետական ինստիտուտի ռեկտոր
Ա. Իսաբեկյան | - | Երևանի գեղարվեստի պետական ակադեմիայի ռեկտոր
Ա. Խաչատրյան | - | «Նաիրի» ԲԲԸ-ի խորհրդի նախագահ (համաձայնությամբ)
Ա. Ապոյան | - | «Աշտարակ կաթ» ՓԲԸ-ի գործադիր տնօրեն (համաձայնությամբ)
