# Հավելված ՀՀ կառավարության 2004 թվականի հունիսի 3-ի N 829-Ն որոշման
Ա Ն Հ Ա Տ Ա Կ Ա Ն Կ Ա Զ Մ
«ՄԵԿ ԱԶԳ, ՄԵԿ ՄՇԱԿՈՒՅԹ» ՀԻՄՆԱԴՐԱՄԻ ՀՈԳԱԲԱՐՁՈՒՆԵՐԻ ԽՈՐՀՐԴԻ
Հ. Հակոբյան | - ՀՀ սփյուռքի նախարար
Ա. Պողոսյան | - ՀՀ մշակույթի նախարարի տեղակալ
Ս. Մանասերյան | - ՀՀ արտաքին գործերի նախարարի տեղակալ
Ռ. Ալավերդյան | - ՀՀ քաղաքաշինության նախարարի տեղակալ
Ա. Գյուրջյան | - ՀՀ Նախագահի աշխատակազմի ղեկավարի տեղակալ (համաձայնությամբ)
Կ. Աճեմյան | - ՀՀ Ազգային ժողովի պատգամավոր (համաձայնությամբ)
Ս. Սիմոնյան | - ՀՀ կառավարության աշխատակազմի սոցիալական վարչության գլխավոր մասնագետ
Վ. Վարդանյան | - Երևանի քաղաքապետի տեղակալ (համաձայնությամբ)
Գերաշնորհ Տ. Փառեն եպիսկոպոս Ավետիքյան | - Մայր աթոռ Սուրբ Էջմիածնի վարչակազմակերպական գործերի կառավարիչ (համաձայնությամբ)
Հայր Վահան ծայրագույն վարդապետ Օհանյան | - Հայ Կաթողիկե եկեղեցու Հայաստանի, Վրաստանի և Արևելյան Եվրոպայի թեմի առաջնորդ (համաձայնությամբ)
Հ. Երդոկյան | - Հայկական բարեգործական ընդհանուր միության հայաստանյան ներկայացուցչության փոխտնօրեն (համաձայնությամբ)
Լ. Գալստյան | - Համազգային հայ կրթական և մշակութային միության հայաստանյան վարչության նախագահ (համաձայնությամբ)
Ռ. Միրզախանյան | - Հայաստանի Թեքեյան մշակութային միության նախագահ (համաձայնությամբ)
Ա. Վարդանյան | - «Հայաստան» համահայկական հիմնադրամի գործադիր տնօրեն (համաձայնությամբ)
Ե. Ղազանչյան | - Հայաստանի թատերական գործիչների միության անդամ (համաձայնությամբ)
Վ. Խանամիրյան | - Հայաստանի պարարվեստի միության նախագահ (համաձայնությամբ)
Ռ. Ամիրխանյան | - Հայաստանի կոմպոզիտորների և երաժշտագետների միավորման նախագահ (համաձայնությամբ)
Լ. Անանյան | - Հայաստանի գրողների միության նախագահ (համաձայնությամբ)
Կ. Աղամյան | - Հայաստանի նկարիչների միության նախագահ (համաձայնությամբ)
Մ. Մինասյան | - Հայաստանի ճարտարապետների միության նախագահ (համաձայնությամբ)
Ռ. Գևորգյանց | - Հայաստանի կինեմատոգրաֆիստների միության նախագահ (համաձայնությամբ)
Ս. Սարաջյան | - Երևանի Կոմիտասի անվան պետական կոնսերվատորիայի ռեկտոր (համաձայնությամբ)
Ա. Երզնկյան | - Երևանի թատրոնի և կինոյի պետական ինստիտուտի պրոռեկտոր (համաձայնությամբ)
Ա. Իսաբեկյան | - Երևանի գեղարվեստի պետական ակադեմիայի ռեկտոր (համաձայնությամբ)
Ա. Աղասյան | - ՀՀ ԳԱԱ-ի արվեստի ինստիտուտի տնօրեն (համաձայնությամբ)
Կ. Գևորգյան | - Հայաստանի պարարվեստի գործիչների և պարագետների միության նախագահ (համաձայնությամբ)
Դ. Շահբազյան | - «Հայրենիք-սփյուռք կենտրոն» ՊՈԱԿ-ի տնօրեն (համաձայնությամբ)
Ա. Ափոյան | - «Աշտարակ կաթ» ՓԲԸ-ի գործադիր տնօրեն (համաձայնությամբ)
(հավելվածը խմբ. 03.03.11 N 303-Ն)
