# Հավելված N 1 ՀՀ կառավարության 2004 թվականի նոյեմբերի 4-ի N 1630-Ն որոշման

ՀԱՄԱՊԱՏԱՍԽԱՆՈՒԹՅԱՆ ՀԱՎԱՍՏՄԱՆ ԲՆԱԳԱՎԱՌՈՒՄ ՍԵՐՏԻՖԻԿԱՑՄԱՆ ՄԱՐՄԻՆՆԵՐԻ ԵՎ ՓՈՐՁԱՐԿՄԱՆ ԼԱԲՈՐԱՏՈՐԻԱՆԵՐԻ ՀԱՎԱՏԱՐՄԱԳՐՄԱՆ ԽՈՐՀՐԴԻ
Տ. Դավթյան | - ՀՀ էկոնոմիկայի նախարար (խորհրդի նախագահ)
Գ. Բադալյան | - ՀՀ էկոնոմիկայի նախարարի տեղակալ (խորհրդի նախագահի տեղակալ)
Ա. Շահինյան | - ՀՀ գիտությունների ազգային ակադեմիայի ակադեմիկոս-քարտուղար (համաձայնությամբ)
Ս. Գալստյան | - ՀՀ գյուղատնտեսության նախարարի տեղակալ
Ա. Ավետիսյան | - ՀՀ տրանսպորտի և կապի նախարարի տեղակալ
Ա. Վանյան | - ՀՀ առողջապահության նախարարության պետական հիգիենիկ և հակահամաճարակային տեսչության պետ
Լ. Վարդանյան | - ՀՀ էներգետիկայի և բնական պաշարների նախարարության աշխատակազմի զարգացման վարչության պետ
Է. Սնգրյան | - ՀՀ արտակարգ իրավիճակների նախարարության Հայաստանի փրկարար ծառայության աշխատակազմի բնակչության և տարածքների պաշտպանության վարչության մոնիտորինգի կենտրոնի պետ-վարչության պետի տեղակալ, փ/ծ գնդապետ
Ա. Առաքելյան | -ՀՀ բնապահպանության նախարարության աշխատակազմի բնապահպանական ռազմավարական ծրագրերի և մոնիթորինգի վարչության շրջակա միջավայրի պահպանության տնտեսական մեխանիզմների, ստանդարտների և տեխնիկական կանոնակարգերի բաժնի գլխավոր մասնագետ
Օ. Կարապետյան | - ՀՀ քաղաքաշինության նախարարության աշխատակազմի ինժեներատեխնիկական աշխատանքների և տեխնիկական նորմավորման մեթոդաբանության բաժնի գլխավոր մասնագետ
Գ. Մինասյան | - «Հայաստանի շինարարների միություն» իրավաբանական անձանց միության տնօրեն (համաձայնությամբ)
Մ. Հակոբյան | - «Աննա» սպառողների ազգային ասոցիացիա» հասարակական կազմակերպության նախագահ (համաձայնությամբ)
Ա. Պողոսյան | - Հայաստանի «Սպառողների ասոցիացիա» հասարակական կազմակերպության նախագահ (համաձայնությամբ)
Ց. Գևորգյան | - «Հայաստանի վաճառականներ» հասարակական կազմակերպության նախագահ (համաձայնությամբ)
Ն. Մկրտչյան | - ՀՀ էկոնոմիկայի նախարարության աշխատակազմի հավատարմագրման գործակալության պետ (խորհրդի քարտուղար)
(Կազմը խմբ. 20.07.06 N 1015-Ն, փոփ. 06.07.07 N 780-Ն, խմբ. 25.02.10 N 173-Ն, 05.05.11 N 568-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
