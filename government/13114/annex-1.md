# Հավելված N 1 ՀՀ կառավարության 2004 թվականի նոյեմբերի 4-ի N 1630-Ն որոշման

ՀԱՄԱՊԱՏԱՍԽԱՆՈՒԹՅԱՆ ՀԱՎԱՍՏՄԱՆ ԲՆԱԳԱՎԱՌՈՒՄ ՍԵՐՏԻՖԻԿԱՑՄԱՆ ՄԱՐՄԻՆՆԵՐԻ ԵՎ ՓՈՐՁԱՐԿՄԱՆ ԼԱԲՈՐԱՏՈՐԻԱՆԵՐԻ ՀԱՎԱՏԱՐՄԱԳՐՄԱՆ ԽՈՐՀՐԴԻ
Կ. Ճշմարիտյան | - ՀՀ առևտրի և տնտեսական զարգացման նախարար (խորհրդի նախագահ)
Գ. Բադալյան | - ՀՀ առևտրի և տնտեսական զարգացման նախարարի տեղակալ (խորհրդի նախագահի տեղակալ)
Ա. Շահինյան | - ՀՀ գիտությունների ազգային ակադեմիայի թղթակից անդամ
Ս. Գալստյան | - ՀՀ գյուղատնտեսության նախարարի տեղակալ
Վ. Առաքելյան | - ՀՀ տրանսպորտի և կապի նախարարի տեղակալ
Ա. Վանյան | - ՀՀ առողջապահության նախարարության պետական հիգիենիկ և հակահամաճարակային տեսչության պետ
Ռ. Դայան | - ՀՀ առևտրի և տնտեսական զարգացման նախարարության աշխատակազմի ստանդարտացման, չափագիտության և համապատասխանության հավաստման վարչության պետ
Ա. Առաքելյան | - ՀՀ բնապահպանության նախարարության աշխատակազմի նորմատիվամեթոդական վարչության ստանդարտների և տեխնիկական կանոնակարգերի բաժնի պետ
Օ. Կարապետյան | - ՀՀ քաղաքաշինության նախարարության աշխատակազմի տեխնիկական նորմավորման և ստանդարտացման բաժնի պետ
Գ. Մինասյան | - Հայաստանի շինարարների միության տնօրեն (համաձայնությամբ)
Մ. Հակոբյան | - Սպառողների ազգային ասոցիացիայի նախագահ (համաձայնությամբ)
Ա. Եղոյան | - «Սպառողների իրավունքների պաշտպանություն» հասարակական կազմակերպության նախագահ (համաձայնությամբ)
Ա. Պողոսյան | - Սպառողների միության նախագահ (համաձայնությամբ)
Ց. Գևորգյան | - «Հայաստանի վաճառականներ» հասարակական կազմակերպության նախագահ (համաձայնությամբ)
Ն. Մկրտչյան | - ՀՀ առևտրի և տնտեսական զարգացման նախարարության աշխատակազմի Հայաստանի Հանրապետության հավատարմագրման գործակալության պետ (խորհրդի քարտուղար)
(Կազմը խմբ. 20.07.06 N 1015-Ն)
