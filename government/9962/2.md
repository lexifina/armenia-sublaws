2. Հաստատել «Հայաստանի Հանրապետության պետական հանրակրթական ուսումնական հաստատություն» պետական ոչ առևտրային կազմակերպության օրինակելի կանոնադրությունը՝ համաձայն N 3 հավելվածի:
2.1. Հաստատել «Հայաստանի Հանրապետության հատուկ դպրոց-ռեսուրս կենտրոն» պետական ոչ առևտրային կազմակերպության օրինակելի կանոնադրությունը՝ համաձայն N 4 հավելվածի և Կառավարման նոր համակարգի անցում չկատարած ուսումնական հաստատությունների կառավարումը՝ համաձայն N 5 հավելվածի, «Կրթահամալիր» պետական ոչ առևտրային կազմակերպության օրինակելի կանոնադրությունը՝ համաձայն N 6 հավելվածի:
(2.1-ին կետը լրաց. 18.04.24 N 567-Ն, 21.05.26 N 714-Ն)
2.2. Սահմանել, որ սույն որոշմամբ հաստատված N 3 hավելվածի դրույթները տարածվում են բոլոր այն ուսումնական հաստատությունների վրա, որոնք անցում են կատարում «Հանրակրթության մասին» օրենքով սահմանված կառավարման նոր համակարգի: Կառավարման նոր համակարգի անցում չկատարած ուսումնական հաստատությունների վրա տարածվում են սույն որոշմամբ հաստատված N 3 hավելվածի դրույթները` բացառությամբ նշված hավելվածի 4-րդ գլխի կարգավորումների, որոնք սահմանվում են N 5 hավելվածով:
(2.2-րդ կետը լրաց. 18.04.24 N 567-Ն)
2.3. Սահմանել, որ ուսումնական հաստատությունների (այդ թվում՝ բարձրագույն ուսումնական հաստատությունների) կազմում որպես մասնաճյուղ գործող հանրակրթական, մասնագիտական ուսումնական հաստատությունները և նախակրթարաններն իրենց գործունեության ընթացքում առաջնորդվում են տվյալ կրթական մակարդակը կարգավորող օրենսդրությամբ և համապատասխան օրինակելի կանոնադրությամբ, եթե օրենքով այլ բան նախատեսված չէ:
(2.3-րդ կետը լրաց. 21.05.26 N 714-Ն)
