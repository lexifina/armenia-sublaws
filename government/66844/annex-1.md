# Հավելված N 1 ՀՀ կառավարության 2011 թվականի մարտի 24-ի N 305-Ն որոշման
Կ Ա Ր Գ
պետական մարմիններին ԱՄՐԱՑՎԱԾ` ԲՆԱԿԵԼԻ ՏԱՐԱԾՔՆԵՐԻ ՆՎԻՐԱՏՎՈՒԹՅԱՆ (վերնագիրը փոփ. 11.09.14 N 1011-Ն, 22.04.22 N 544-Ն)
1. Սույն կարգով (այսուհետ` կարգ) կարգավորվում են պետական մարմիններին ամրացված` բնակելի տարածքների (այսուհետ` բնակելի տարածքներ) նվիրատվության հետ կապված հարաբերությունները:
(1-ին կետը փոփ. 11.09.14 N 1011-Ն, 22.04.22 N 544-Ն)
2. Բնակելի տարածքները կարող են նվիրվել՝
1) համապատասխան տարածքում հաշվառված և մինչև 2017 թվականի դեկտեմբերի 1-ը փաստացի բնակվող Հայաստանի Հանրապետության այն քաղաքացիներին (բացառությամբ սահմանամերձ համայնքներում բնակվողների, որոնց համար փաստացի բնակվելու ժամկետի սահմանափակում չի նախատեսվում), որոնք պետական աջակցությամբ իրականացված բնակապահովման ծրագրերի շրջանակներում երբևէ բնակարան (բնակելի տուն) ձեռք չեն բերել կամ բնակարան (բնակելի տուն) ձեռք բերելու համար ֆինանսական աջակցություն չեն ստացել, ինչպես նաև սեփա-կանության իրավունքով չունեն անշարժ գույք (բացառությամբ բնակելի տարածքների նկատմամբ ընդհանուր կամ բաժնային սեփա-կանության իրավունքով իրենց պատկանող բաժնեմասի, չկառուցապատված հողամասերի, բնակելի նշանակության օժանդակ շինությունների, ինչպես նաև ոչ բնակելի նշանակություն ունեցող շենքերի, շինությունների).
2) սույն կարգի համաձայն նվիրատվությամբ բնակելի տարածքներ նախկինում ձեռք բերված անձանց, որոնց նվիրատվությունից հետո բնակության նույն հասցեում սահմանված կարգով որպես բարելավում հատկացված է տարածք:
(2-րդ կետը փոփ. 11.09.14 N 1011-Ն, լրաց. 27.05.15 N 560-Ն, խմբ. 25.07.19 N 971-Ն)
3. Բնակելի տարածքում բնակվող և սույն կարգի 2-րդ կետի պահանջները բավարարող` Հայաստանի Հանրապետության քաղաքացիները տարածքի նվիրատվության համար դիմում են ներկայացնում տվյալ բնակելի տարածքը տնօրինող պետական կառավարման մարմին` ներկայացնելով հետևյալ փաստաթղթերը`
1) դիմում.
2) անձնագրի պատճենը` հաշվառման էջով, կամ նույնականացման քարտի պատճենը.
3) մեկից ավելի ընտանիքի անդամների դեպքում` ընտանիքի չափահաս անդամների անձնագրերի պատճենները` հաշվառման էջով կամ նույնականացման քարտերի պատճենները.
4) ընտանիքի անչափահաս անդամների ծննդյան վկայականների կամ անձնագրերի կամ նույնականացման քարտերի պատճենները.
5) տեղեկանք բնակության վայրից` տվյալ բնակելի տարածքում բնակվելու վերաբերյալ, ինչպես նաև նվիրվող բնակելի տարածքի հատակագիծը՝ կազմված և հաստատված Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով.
6) (ենթակետն ուժը կորցրել է 25.07.19 N 971-Ն)
7) (ենթակետն ուժը կորցրել է 25.07.19 N 971-Ն)
8) նվիրվող տարածքի վարձակալված լինելու դեպքում` նաև տեղեկանք վարձավճարի մասով պարտք չունենալու վերաբերյալ.
9) նույնականացման քարտ ներկայացրած անձանց համար՝ տեղեկանք համապատասխան լիազոր պետական մարմնի կողմից տրված` համապատասխան տարածքում հաշվառված լինելու վերաբերյալ.
10) սեփա-կանության իրավունքով պատկանող հողամաս ունենալու դեպքում` տեղեկանք համայնքի ղեկավարից՝ հողամասի չկառուցապատված լինելու մասին:
(3-րդ կետը փոփ., լրաց. 11.09.14 N 1011-Ն, 27.05.15 N 560-Ն, փոփ. 25.07.19 N 971-Ն)
4. Պետական կառավարման մարմինն ուսումնասիրում է ներկայացված փաստաթղթերը, որոնք սույն կարգի պահանջներին համապատասխանելու դեպքում բնակիչների ամբողջական ցանկի, նրանց կողմից զբաղեցված սենյակների մակերեսների և հաշվեկշռային արժեքների վերաբերյալ տեղեկատվության, ինչպես նաև անշարժ գույքի նկատմամբ իրավունքի պետական գրանցման վկայականների հետ միասին մեկամսյա ժամկետում ներկայացնում է Հայաստանի Հանրապետության պետական գույքի կառավարման կոմիտե:
(4-րդ կետը լրաց. 11.09.14 N 1011-Ն, փոփ. 25.07.19 N 971-Ն)
5. Հայաստանի Հանրապետության պետական գույքի կառավարման կոմիտեն սույն կարգի 4-րդ կետում նշված փաստաթղթերն ստանալուց հետո դրանց հիման վրա Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով մշակում և շրջանառության մեջ է դնում համապատասխան տարածքները բնակիչներին նվիրելու մասին Հայաստանի Հանրապետության կառավարության որոշման նախագիծ:
(5-րդ կետը փոփ. 25.07.19 N 971-Ն)
6. Որոշման 1-ին կետի 3-րդ ենթակետով հաստատված N 3 հավելվածում նշված անձինք նվիրվող բնակելի տարածքի հատակագիծը` կազմված և հաստատված Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով ներկայացնում են բնակելի տարածքը տնօրինող պետական կառավարման մարմնին: Բնակելի տարածքը տնօրինող պետական կառավարման մարմինը հատակագծի (ցանկով նշված մակերեսների տարբերություններ առաջանալու դեպքում՝ հիմք ընդունել նշված հասցեների սահմանված կարգով գրանցված համապատասխան վկայականի հատակագծի մակերեսը մինչև 3% թույլատրելի շեղումով) և որոշման 1-ին կետի 1-ին ենթակետով հաստատված N 1 հավելվածի 3-րդ կետով պահանջվող փաստաթղթերի առկայության դեպքում մինչև 2024 թվականի դեկտեմբերի 30-ը կնքում է նվիրատվության պայմանագիր՝ համաձայն Հայաստանի Հանրապետության կառավարության 2011 թվականի դեկտեմբերի 22-ի N 1851-Ն որոշման՝ դրանում նախատեսելով, որ գույքային իրավունքների պետական գրանցման ծախսերն իրականացվելու են նվիրառու հանդիսացող բնակիչների կողմից:
(6-րդ կետը փոփ. 24.05.12 N 639-Ն, 11.09.14 N 1011-Ն, խմբ. 25.07.19 N 971-Ն, լրաց., փոփ. 09.04.20 N 544-Ն, փոփ. 24.06.21 N 1043-Ն, լրաց., փոփ. 29.06.23 N 1053-Ն)
7. Որոշման 1-ին կետի 3-րդ ենթակետով հաստատված N 3 հավելվածում նշված հանրակացարանի զբաղեցրած և սպասարկման համար անհրաժեշտ գույքի (հողամասի և ընդհանուր օգտագործման տարածքների) նկատմամբ ընդհանուր բաժնային սեփա-կանության իրավունքն օրենքով սահմանված կարգով անցնում է հանրակացարանների առանձին տարածքների նկատմամբ սեփա-կանության իրավունք ձեռք բերողներին:
(7-րդ կետը լրաց. 25.07.19 N 971-Ն)
(հավելվածը փոփ. 24.05.12 N 639-Ն, փոփ., լրաց. 11.09.14 N 1011-Ն, 27.05.15 N 560-Ն, խմբ., փոփ., լրաց. 25.07.19 N 971-Ն, լրաց., փոփ. 09.04.20 N 544-Ն, փոփ. 24.06.21 N 1043-Ն, 22.04.22 N 544-Ն, լրաց., փոփ. 29.06.23 N 1053-Ն)
