# Հավելված ՀՀ կառավարության 2003 թվականի հունիսի 5-ի N 666-Ն որոշման
Ց Ա Ն Կ
N 2 ԵՎ 3 ԿԱՌԱՎԱՐԱԿԱՆ ՏԱՆ ՇԵՆՔԻՑ ՊԵՏԱԿԱՆ ՄԱՐՄԻՆՆԵՐԻՆ ԱՆՀԱՏՈՒՅՑ ՕԳՏԱԳՈՐԾՄԱՆ ՏՐԱՄԱԴՐՎՈՂ ՏԱՐԱԾՔՆԵՐԻ
(վերնագիրը փոփ. 03.05.07 N 573-Ն)
NN ը/կ | Պետական մարմնի անվանումը | Անհատույց օգտագործման տրամադրվող տարածքի նկարագիրը
1. | ՀՀ առողջապահության նախարարություն | N 3 կառավարական շենքի նորակառույց մասնաշենքի 2-րդ հարկը (31 սենյակ)
2. | ՀՀ առևտրի և տնտեսական զարգացման նախարարություն | N 3 կառավարական շենքի գործող մասնաշենքի 2-րդ հարկի ձախակողմյան թևը (13 սենյակ)
3. | ՀՀ բնապահպանության նախարարություն | N 3 կառավարական շենքի նորակառույց մասնաշենքի 5-րդ հարկը (31 սենյակ) և գործող մասնաշենքի 5-րդ հարկը (27 սենյակ) 8-րդ հարկի կենտրոնական հատվածի 100 քառ. մետր տարածքը
4. | ՀՀ գյուղատնտեսության նախարարություն | N 3 կառավարական շենքի նորակառույց մասնաշենքի 1-ին հարկը (31 սենյակ)
5. | ՀՀ կրթության և գիտության նախարարություն | N 3 կառավարական շենքի նորակառույց մասնաշենքի 6-րդ հարկը (31 սենյակ) և 7-րդ հարկից 4 սենյակ 8-րդ հարկի կենտրոնական հատվածի 100 քառ. մետր տարածքը
6. | ՀՀ մշակույթի, երիտասարդության հարցերի և սպորտի նախարարություն | N 3 կառավարական շենքի նորակառույց մասնաշենքի 7-րդ հարկից 27 սենյակ 8-րդ հարկի կենտրոնական հատվածի 170 քառ. մետր տարածքը
7. | ՀՀ սոցիալական ապահովության նախարարություն | N 3 կառավարական շենքի նորակառույց մասնաշենքի 3-րդ հարկը (31 սենյակ) և գործող մասնաշենքի 3-րդ հարկի ձախակողմյան թևը (13 սենյակ)
7.1 | ՀՀ տարածքային կառավարման նախարարություն | N 2 կառավարման մասնաշենքից 2280 քառ. մետր տարածք (48 սենյակ և 6 սանհանգույց)
8. | ՀՀ քաղաքաշինության նախարարություն | N 3 կառավարական շենքի նորակառույց մասնաշենքի 4-րդ հարկը (31 սենյակ) և գործող մասնաշենքի 4-րդ հարկը (27 սենյակ)
9. | ՀՀ ազգային վիճակագրական ծառայություն | N 3 կառավարական շենքի գործող մասնաշենքի 6-րդ և 7-րդ հարկերը (54 սենյակ) 8-րդ հարկից 120 քառ. մետր օժանդակ տարածքը
