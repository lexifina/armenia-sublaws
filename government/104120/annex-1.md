# Հավելված ՀՀ կառավարության 2016 թվականի մարտի 3-ի N 188-Ն որոշման
Ց Ա Ն Կ
ԹՈՒՅԼՏՎՈՒԹՅՈՒՆ ՉՊԱՀԱՆՋՈՂ ՕԴԱՅԻՆ ՀԱՂՈՐԴԱԿՑՈՒԹՅՈՒՆՆԵՐԻ ՈՐՈՇ ՏԵՍԱԿՆԵՐԻ
1. Փրկարարական և անհետաձգելի վթարավերականգնողական, որոնողափրկարարական և հրդեհաշիջման աշխատանքների իրականացման նպատակներով օդային հաղորդակցություն.
2. Բնակչության տարահանման նպատակով օդային հաղորդակցություն.
3. Ոստիկանության գործառույթներով պայմանավորված օդային հաղորդակցություն.
4. Պետական մարմիններում կամ պետական կառավարչական հիմնարկներում շահագործվող օդանավերով շտապ և անհետաձգելի բժշկական օգնության համար պացիենտի տեղափոխման, շտապ և անհետաձգելի բժշկական օգնության համար բժիշկների տեղափոխման նպատակով օդային հաղորդակցություն.
5. Պետական մարմիններում կամ պետական կառավարչական հիմնարկներում շահագործվող օդանավերով, կենսաբանական, քիմիական, ճառագայթային գործոնով պայմանավորված` արտակարգ իրավիճակների ժամանակ Հայաստանի Հանրապետության կառավարության 2012 թվականի հունիսի 22-ի N 777-Ն որոշման պահանջներին համապատասխան, կանխարգելիչ և հակահամաճարակային միջոցառումներ իրականացնելու համար անձանց տեղափոխման նպատակով օդային հաղորդակցություն:
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Դ. Հարությունյան
