2. Հայաստանի Հանրապետության կառավարության մի շարք որոշումներում կատարել հետևյալ փոփոխությունները և լրացումները՝
1) Հայաստանի Հանրապետության կառավարության 2019 թվականի հոկտեմբերի 3-ի «Հայաստանի Հանրապետության 2019 թվականի պետական բյուջեում վերաբաշխում և Հայաստանի Հանրապետության կառավարության 2018 թվականի դեկտեմբերի 27-ի N 1515-Ն որոշման մեջ փոփոխություններ կատարելու մասին» N 1328-Ն որոշման N 2 հավելվածի աղյուսակում «Բաժին» և «Խումբ» սյունակներում «04» և «09» թվերը համապատասխանաբար փոխարինել «06» և «04» թվերով.
2) Հայաստանի Հանրապետության կառավարության 2019 թվականի հուլիսի 11-ի «Հայաստանի Հանրապետության 2019 թվականի պետական բյուջեում վերաբաշխում, Հայաստանի Հանրապետության կառավարության 2018 թվականի դեկտեմբերի 27-ի N 1515-Ն որոշման մեջ փոփոխություններ և լրացումներ կատարելու և Հայաստանի Հանրապետության կրթության, գիտության մշակույթի և սպորտի նախարարության գիտության կոմիտեին գումար հատկացնելու մասին» N 891-Ն որոշման N 4 հավելվածի աղյուսակում «1139» ծրագրի «11001» միջոցառումը հանել.
3) Հայաստանի Հանրապետության կառավարության 2019 թվականի ապրիլի 11-ի «Հայաստանի Հանրապետության 2019 թվականի պետական բյուջեում վերաբաշխում, Հայաստանի Հանրապետության կառավարության 2018 թվականի դեկտեմբերի 27-ի N 1515-Ն որոշման մեջ փոփոխություններ և լրացումներ կատարելու և Հայաստանի Հանրապետության տարածքային կառավարման և զարգացման նախարարությանը գումար հատկացնելու մասին» N 379-Ն որոշման 4-րդ կետում «միջոցներից» բառը փոխարինել «Հարկային եկամուտներ և պետական տուրքեր» եկամտատեսակի գծով մուտքերից» բառերով, իսկ «Այլ եկամուտներ» բառերը՝ «Այլ հարկային եկամուտներ» բառերով.
4) Հայաստանի Հանրապետության կառավարության 2019 թվականի մայիսի 30-ի «Հայաստանի Հանրապետության 2019 թվականի պետական բյուջեում վերաբաշխում, Հայաստանի Հանրապետության կառավարության 2018 թվականի դեկտեմբերի 27-ի N 1515-Ն որոշման մեջ փոփոխություններ և լրացումներ կատարելու և Հայաստանի Հանրապետության մշակույթի նախարարությանը գումար հատկացնելու մասին» N 660-Ն որոշման 4-րդ կետում «միջոցներից» բառը փոխարինել «Հարկային եկամուտներ և պետական տուրքեր» եկամտատեսակի գծով մուտքերից» բառերով, իսկ «Այլ եկամուտներ» բառերը՝ «Այլ հարկային եկամուտներ» բառերով.
