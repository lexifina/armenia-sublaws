# Հավելված N 3 ՀՀ կառավարության 2006 թվականի մարտի 2-ի N 276-Ն որոշման
Ը Ն Թ Ա Ց Ա Կ Ա Ր Գ
ԲԺՇԿԱՍՈՑԻԱԼԱԿԱՆ ՓՈՐՁԱՔՆՆՈՒԹՅԱՆ ԳՈՐԾԸՆԹԱՑՆ ԻՐԱԿԱՆԱՑՆԵԼՈՒ ՀԱՏՈՒԿ
1. Հայաստանի Հանրապետության կառավարության 2006 թվականի մարտի 2-ի N 276-Ն որոշմամբ սահմանված՝ անձի բժշկասոցիալական փորձաքննության դիմումները բժշկասոցիալական փորձաքննության բաժիններին ներկայացվում են փոստային կամ էլեկտրոնային եղանակով։
(1-ին կետը փոփ. 14.01.21 N 10-Ն)
2. Դիմումների հիման վրա բժշկասոցիալական փորձաքննությունները և վերափորձաքննությունները (այդ թվում՝ փորձաքննական խորհրդատվության նպատակով և քրեակատարողական հիմնարկներում իրականացվող վերափորձաքննությունները) իրականացվում են եռամսյա ժամկետում, բացառությամբ չարորակ նորագոյացություններ (արմատական բուժումից հետո, մետաստազներով, ախտադարձներով, բուժման անարդյունավետության կամ բուժման ոչ ենթակա դեպքերում, խիստ արտահայտված ինտոքսիկացիայով, կախեքսիայով, ուռուցքի քայքայումով), վերականգնողական միջոցառումների հեռանկարի բացակայության` օրգանիզմի ֆունկցիայի կայուն խիստ արտահայտված խանգարումներ ունեցող անձանց, անաշխատունակության թերթիկի ժամկետը երկարաձգելու, «հաշմանդամ երեխա» կարգավիճակից հետո 18 տարին լրանալու դեպքերում իրականացվող բժշկասոցիալական փորձաքննությունների (վերափորձաքննությունների)։
3. Ստեղծվում են արտակարգ դրության պայմաններում բժշկասոցիալական փորձաքննության հերթապահ բաժիններ (մասնագետներին ընտրելիս հաշվի առնելով տարիքային, առողջական խնդիրներով պայմանավորված առանձնահատկությունները)՝ սույն հավելվածի 2-րդ կետով սահմանված բացառությունների դեպքերում բժշկասոցիալական փորձաքննություններ իրականացնելու նպատակով։
(3-րդ կետը փոփ. 14.01.21 N 10-Ն)
(հավելվածը լրաց. 26.03.20 N 381-Ն, փոփ. 14.01.21 N 10-Ն)
