# Հավելված N 1 ՀՀ կառավարության 2023 թվականի նոյեմբերի 30-ի N 2067-Ն որոշման
Կ Ա Ր Գ
ՀԱՆՐԱՊԵՏԱԿԱՆ, ՃՅՈՒՂԱՅԻՆ ԵՎ ՏԱՐԱԾՔԱՅԻՆ ԿՈԼԵԿՏԻՎ ՊԱՅՄԱՆԱԳՐԵՐԻ ՀԱՇՎԱՌՄԱՆ
1. Սույն կարգով կարգավորվում են հանրապետական, ճյուղային և տարածքային կոլեկտիվ պայմանագրերի հաշվառման հետ կապված հարաբերությունները։
2. Հանրապետական, ճյուղային և տարածքային կոլեկտիվ պայմանագրերի հաշվառումն իրականացնում է աշխատանքային օրենսդրության, աշխատանքային իրավունքի նորմեր պարունակող այլ նորմատիվ իրավական ակտերի, կոլեկտիվ և աշխատանքային պայմանագրերի պահանջների կատարման նկատմամբ պետական վերահսկողություն իրականացնող տեսչական մարմինը (այսուհետ՝ տեսչական մարմին)՝ համապատասխան դիմումը և կոլեկտիվ պայմանագիրը ներկայացվելու դեպքում:
3. Հանրապետական, ճյուղային կամ տարածքային կոլեկտիվ պայմանագիրը ստորագրման պահից տասն օրվա ընթացքում հաշվառման է ներկայացնում կողմ համարվող գործատուների միությունը՝ այդ մասին սույն կետում նշված ժամկետում միաժամանակ գրավոր տեղեկացնելով կոլեկտիվ պայմանագրի կողմ համարվող արհեստակցական միությանը:
4. Եթե սույն կարգի 3-րդ կետում նշված ժամկետում գործատուների միությունը պայմանագիրը հաշվառման չի ներկայացնում, ապա հանրապետական, ճյուղային կամ տարածքային կոլեկտիվ պայմանագիրը հաշվառման կարող է ներկայացնել պայմանագրի կողմ համարվող արհեստակցական միությունը: Արհեստակցական միությունը հանրապետական, ճյուղային կամ տարածքային կոլեկտիվ պայմանագիրը հաշվառման է ներկայացնում սույն կարգի 3-րդ կետում նշված ժամկետը լրանալուց հետո` հինգ օրվա ընթացքում:
5. Տեսչական մարմնում հանրապետական, ճյուղային և տարածքային կոլեկտիվ պայմանագրերի հաշվառման համար վարվում է մեկ միասնական էլեկտրոնային մատյան (այսուհետ` մատյան)։
6. Մատյանում լրացվում են հանրապետական, ճյուղային և տարածքային կոլեկտիվ պայմանագրերի վերաբերյալ հետևյալ տվյալները՝
1) կոլեկտիվ պայմանագրի կնքման ամսաթիվը, ամիսը, տարեթիվը.
2) կոլեկտիվ պայմանագրի կողմերը.
3) կոլեկտիվ պայմանագրի տեսակը (հանրապետական, ճյուղային կամ տարածքային).
4) կոլեկտիվ պայմանագրի գործողության ժամկետը.
5) կոլեկտիվ պայմանագրի վաղաժամկետ լուծման դեպքում՝ վաղաժամկետ լուծման ամսաթիվը, ամիսը, տարեթիվը։
7. Հանրապետական, ճյուղային և տարածքային կոլեկտիվ պայմանագրերի հաշվառման համար տեսչական մարմին ներկայացվող դիմումը պետք է պարունակի՝
1) դիմողի լրիվ անվանումը.
2) նշում այն մասին, որ դիմումին կից ներկայացվում է կոլեկտիվ պայմանագիրը՝ հաշվառման համար.
3) հաշվառման ենթակա կոլեկտիվ պայմանագրի կողմերի տվյալները (անվանումները (անունները), հեռախոսահամարները, հասցեները, էլեկտրոնային փոստի հասցեները).
4) դիմումին կից ներկայացվող կոլեկտիվ պայմանագրի էջերի թիվը.
5) դիմումը կազմելու տարին, ամիսը և ամսաթիվը.
6) դիմումը ներկայացնող գործատուների միության (եթե կոլեկտիվ պայմանագիրը հաշվառման է ներկայացնում գործատուների միությունը) կամ արհեստակցական միության (եթե կոլեկտիվ պայմանագիրը հաշվառման է ներկայացնում արհեստակցական միությունը) իրավասու պաշտոնատար անձի ստորագրությունը, անվան սկզբնատառը, ազգանունը։
8. Հանրապետական, ճյուղային կամ տարածքային կոլեկտիվ պայմանագրերի հաշվառման համար դիմումը տեսչական մարմին կարող է ներկայացվել առձեռն, փոստային կապի միջոցով կամ էլեկտրոնային եղանակով (տեսչական մարմնի կայքում հրապարակված պաշտոնական էլեկտրոնային փոստի հասցեով), որի դեպքում դիմումին կից ներկայացվում է հանրապետական, ճյուղային կամ տարածքային կոլեկտիվ պայմանագրի ստորագրված և էլեկտրոնային պատկերատպված (սկանավորված) օրինակը։
9. Հանրապետական, ճյուղային կամ տարածքային կոլեկտիվ պայմանագրերի հաշվառման նպատակով տեսչական մարմին ներկայացված դիմումի՝ սույն կարգի 7-րդ կետի պահանջներին համապատասխանությունը և դիմումին կից ներկայացված կոլեկտիվ պայմանագրի էջերի ամբողջականությունը ստուգելուց հետո՝ տեսչական մարմինն իրականացնում է համապատասխան կոլեկտիվ պայմանագրի հաշվառումը մատյանում (բացառությամբ սույն կարգի 10-րդ կետով նախատեսված դեպքի)՝ դիմումը տեսչական մարմին մուտքագրվելու օրվան հաջորդող 20 աշխատանքային օրվա ընթացքում՝ այդ մասին պաշտոնական գրությամբ տեղեկացնելով դիմում ներկայացնողին։ Նույն գրությամբ միաժամանակ դիմում ներկայացնողին վերադարձվում է նաև հաշվառման ներկայացված կոլեկտիվ պայմանագիրն այն դեպքում, երբ այն հաշվառման է ներկայացվել առձեռն կամ փոստային կապի միջոցով։
10. Դիմումին կից ներկայացված կոլեկտիվ պայմանագրի էջերի ոչ ամբողջական լինելու կամ էջերի միջև անհամապատասխանությունների կամ դիմումի՝ սույն կարգի 7-րդ կետի պահանջներին չհամապատասխանելու դեպքերում տեսչական մարմինը, դիմումը տեսչական մարմին մուտքագրվելու օրվան հաջորդող 20 աշխատանքային օրվա ընթացքում, պաշտոնական գրությամբ դիմողին տեղեկացնում է համապատասխան խնդրի մասին՝ վերադարձնելով նաև հաշվառման համար ներկայացված կոլեկտիվ պայմանագիրն այն դեպքում, երբ այն հաշվառման է ներկայացվել առձեռն կամ փոստային կապի միջոցով, որից հետո համապատասխան կոլեկտիվ պայմանագրի հաշվառման համար դիմողի կողմից ներկայացվում է նոր դիմում՝ ընդհանուր հիմունքներով՝ տեսչական մարմնի պատասխան գրությունն ստանալուց հետո հինգ աշխատանքային օրվա ընթացքում։
11. Հաշվառված կոլեկտիվ պայմանագրի պատճենը պահվում է տեսչական մարմնում։
12. Հանրապետական, ճյուղային կամ տարածքային կոլեկտիվ պայմանագրերի հաշվառման նպատակով տեսչական մարմին ներկայացված դիմումի՝ սույն կարգի 7-րդ կետի պահանջներին համապատասխանության և դիմումին կից ներկայացված կոլեկտիվ պայմանագրի էջերի ամբողջական լինելու դեպքում՝ կոլեկտիվ պայմանագրի հաշվառման մերժումը որևէ պատճառաբանությամբ արգելվում է:
13. Սույն կարգի դրույթներին համապատասխան՝ իրականացվում է նաև հանրապետական, ճյուղային կամ տարածքային կոլեկտիվ պայմանագրերում կատարված փոփոխությունների և լրացումների, ինչպես նաև պայմանագրերի գործողության ժամկետի երկարաձգման հաշվառումը։
14. Հանրապետական, ճյուղային կամ տարածքային կոլեկտիվ պայմանագրերի վաղաժամկետ լուծման դեպքում, եթե կոլեկտիվ պայմանագիրը հաշվառման ներկայացրած կողմն այդ մասին տեղեկացնում է տեսչական մարմնին, մատյանի համապատասխան դաշտում տեսչական մարմնի կողմից լրացվում են համապատասխան կոլեկտիվ պայմանագրի վաղաժամկետ լուծման ամսաթիվը, ամիսը, տարեթիվը։
Հայաստանի Հանրապետության վարչապետի աշխատակազմի ղեկավար | Ա. Հարությունյան
