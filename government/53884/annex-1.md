# Հավելված N 1 ՀՀ կառավարության 2009 թվականի սեպտեմբերի 17-ի N 1075-Ն որոշման
«ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ 2009 ԹՎԱԿԱՆԻ ՊԵՏԱԿԱՆ ԲՅՈՒՋԵԻ ՄԱՍԻՆ» ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՕՐԵՆՔԻ N 1 ՀԱՎԵԼՎԱԾՈՒՄ ԿԱՏԱՐՎՈՂ ՎԵՐԱԲԱՇԽՈՒՄԸ ԵՎ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆ 2008 ԹՎԱԿԱՆԻ ԴԵԿՏԵՄԲԵՐԻ 25-Ի N 1573-Ն ՈՐՈՇՄԱՆ N 5 ՀԱՎԵԼՎԱԾՈՒՄ ԿԱՏԱՐՎՈՂ ՓՈՓՈԽՈՒԹՅՈՒՆՆԵՐԸ «ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ 2009 ԹՎԱԿԱՆԻ ՊԵՏԱԿԱՆ ԲՅՈՒՋԵԻ ՄԱՍԻՆ» ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՕՐԵՆՔԻ N 1 ՀԱՎԵԼՎԱԾԻ N 13 ԱՂՅՈՒՍԱԿՈՒՄ ԿԱՏԱՐՎՈՂ ՎԵՐԱԲԱՇԽՈՒՄԸ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆ 2008 ԹՎԱԿԱՆԻ ԴԵԿՏԵՄԲԵՐԻ 25-Ի N 1573-Ն ՈՐՈՇՄԱՆ N 5 ՀԱՎԵԼՎԱԾԻ N 12 ԱՂՅՈՒՍԱԿՈՒՄ ԿԱՏԱՐՎՈՂ ՓՈՓՈԽՈՒԹՅՈՒՆՆԵՐԸ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՀԱՄԱՅՆՔՆԵՐՈՒՄ (ԲՆԱԿԱՎԱՅՐԵՐՈՒՄ) ԲԱԶՄԱԿԻ ՕԳՏԱԳՈՐԾՄԱՆ ԱՆՀԱՏԱԿԱՆ ԲՆԱԿԵԼԻ ՏՆԵՐԻ ՆԱԽԱԳԾԵՐԻ ԿԱՏԱԼՈԳԻ ՍՏԵՂԾՄԱՆ ԾԱՌԱՅՈՒԹՅՈՒՆՆԵՐԻ ՁԵՌՔԲԵՐՄԱՆ ԾԱԽՍԵՐԸ (Հավելվածը փոփ. 15.04.10 N 406-Ն)
