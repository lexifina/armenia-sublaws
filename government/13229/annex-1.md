# Հավելված N 1 ՀՀ կառավարության 2004 թվականի դեկտեմբերի 9-ի N 1792-Ն որոշման
Կ Ա Ր Գ ՌԱԴԻՈԱԿՏԻՎ ՆՅՈՒԹԵՐԻ ԿԱՄ ՌԱԴԻՈԱԿՏԻՎ ՆՅՈՒԹԵՐ ՊԱՐՈՒՆԱԿՈՂ ՍԱՐՔԵՐԻ ՊԱՀԵՍՏԱՎՈՐՄԱՆ ԼԻՑԵՆԶԱՎՈՐՄԱՆ (վերնագիրը փոփ. 18.03.11 N 249-Ն)
I. ԸՆԴՀԱՆՈՒՐ ԴՐՈՒՅԹՆԵՐ
1. Սույն կարգով սահմանվում են Հայաստանի Հանրապետությունում ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորման լիցենզավորմանը ներկայացվող պահանջները:
(1-ին կետը փոփ. 18.03.11 N 249-Ն)
2. Ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորման լիցենզիան տրվում է բարդ ընթացակարգով, ատոմային էներգիայի օգտագործման բնագավառի կարգավորող մարմնի (այսուհետ` կարգավորող մարմին) կողմից:
(2-րդ կետը փոփ. 18.03.11 N 249-Ն)
3. Սույն կարգը մշակված է «Լիցենզավորման մասին» և «Խաղաղ նպատակներով ատոմային էներգիայի անվտանգ օգտագործման մասին» Հայաստանի Հանրապետության օրենքների պահանջներին համապատասխան:
4. Սույն կարգի դրույթները տարածվում են կարգավորող հսկողությունից ազատման մակարդակներին (այսուհետ` ազատման մակարդակ) հավասար կամ դրանք գերազանցող բնութագրեր ունեցող ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորման վրա:
(4-րդ կետը փոփ. 18.03.11 N 249-Ն)
5. Ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի ազատման մակարդակները սահմանվում են ճառագայթային անվտանգության նորմերով:
(5-րդ կետը փոփ. 18.03.11 N 249-Ն)
6. Ազատման մակարդակներից ցածր բնութագրեր ունեցող ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորման համար լիցենզիա չի պահանջվում:
(6-րդ կետը փոփ. 18.03.11 N 249-Ն)
II. ԼԻՑԵՆԶԻԱ ՍՏԱՆԱԼՈՒ ՀԱՄԱՐ ԱՆՀՐԱԺԵՇՏ ՓԱՍՏԱԹՂԹԵՐԸ ԵՎ ՊԱՐՏԱԴԻՐ ՊԱՀԱՆՋՆԵՐԸ
7. Ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորման գործունեության լիցենզիա ստանալու համար կարգավորող մարմին ներկայացվում է հայտ (ձևը կցվում է), որում նշվում են`
ա) իրավաբանական անձի համար` իրավաբանական անձի անվանումը, կազմակերպական-իրավական ձևը, պետական գրանցման համարը, հարկ վճարողի հաշվառման համարի վերաբերյալ տեղեկատվություն, գտնվելու և գործունեության իրականացման վայրերը, ինչ տիպի ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորում է նախատեսվում իրականացնել.
բ) անհատ ձեռնարկատիրոջ կամ ֆիզիկական անձի համար` անունը, հայրանունը, ազգանունը, պետական հաշվառման համարը, հարկ վճարողի հաշվառման համարի կամ սոցիալական քարտի համարի վերաբերյալ տեղեկատվություն, անձնագրի սերիան և համարը, բնակության և գործունեության իրականացման վայրերը, ինչ տիպի ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորում է նախատեսվում իրականացնել:
(7-րդ կետը լրաց. 16.11.06 N 1664-Ն, փոփ. 18.03.11 N 249-Ն, լրաց. 27.12.12 N 1677-Ն)
8. Հայտին կից պետք է ներկայացվեն`
ա) («ա» ենթակետն ուժը կորցրել է 28.04.11 N 636-Ն)
բ) օգտագործվելիք պահման կետի (պահեստարան, սենք, սրահ, հատուկ առանձնացված տեղ) նախագիծը կամ անվտանգության բնութագրերը և դրանց մասին անվտանգության փորձաքննական եզրակացությունը.
գ) պահման կետի անձնակազմի մասնագիտական որակավորումը, այդ թվում` ճառագայթային անվտանգության նորմերի և կանոնների իմացությունը հաստատող փաստաթղթերի պատճենները.
դ) լիցենզիա ստանալու համար պետական տուրքի վճարման անդորրագիրը:
(8-րդ կետը փոփ. 28.04.11 N 636-Ն)
III. ԼԻՑԵՆԶԻԱ ՍՏԱՆԱԼՈՒ ՄԱՍԻՆ ՀԱՅՏԻ ՔՆՆԱՐԿՈՒՄԸ
9. Ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորման լիցենզիա ստանալու մասին հայտը քննարկվում է կարգավորող մարմնի կողմից` հայտը մուտքագրվելու օրվանից 30-օրյա ժամկետում:
(9-րդ կետը փոփ. 18.03.11 N 249-Ն)
10. Ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորման լիցենզիա ստանալու մասին հայտի քննարկման ժամանակ դիտարկվում են`
ա) հայտի և դրան կից փաստաթղթերի համապատասխանությունը սույն կարգի և այլ օրենսդրական ակտերի պահանջներին.
բ) հայտատուի իրավունքը` ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորման գործունեությամբ զբաղվելու.
գ) պահման կետի համապատասխանությունը ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորման անվտանգության նորմերի ու կանոնների պահանջներին.
դ) ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահման կետի անձնակազմի որակավորումն ու ճառագայթային անվտանգության նորմերի ու կանոնների իմացությունը:
(10-րդ կետը փոփ. 18.03.11 N 249-Ն)
11. Ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորման լիցենզիա ստանալու մասին հայտի քննարկման ժամանակ, ներկայացված տվյալների ճշտման կամ լրացուցիչ տեղեկությունների ստացման նպատակով, կարգավորող մարմինն իրավասու է անցկացնելու պահման կետի տեսչական ստուգում:
(11-րդ կետը փոփ. 18.03.11 N 249-Ն)
12. Կարգավորող մարմինը քննարկման արդյունքների հիման վրա ընդունում է որոշում լիցենզիա տալու կամ լիցենզիա ստանալու մասին հայտը մերժելու մասին:
13. Լիցենզիա ստանալու մասին հայտը մերժվում է`
ա) եթե պահման կետը չի համապատասխանում անվտանգության նորմերի և կանոնների պահանջներին.
բ) «Լիցենզավորման մասին» Հայաստանի Հանրապետության օրենքի 29-րդ հոդվածի 1-ին մասով նախատեսված հիմքերի առկայության դեպքում:
14. Ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորման լիցենզիան տրվում է 10 տարի ժամկետով:
(14-րդ կետը փոփ. 18.03.11 N 249-Ն)
15. Ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորման լիցենզիան վերաձևակերպվում կամ դրա գործողությունը կասեցվում կամ դադարեցվում է համաձայն «Լիցենզավորման մասին» Հայաստանի Հանրապետության օրենքի:
(15-րդ կետը փոփ. 18.03.11 N 249-Ն)
IV. ԼԻՑԵՆԶԻԱՅԻ ՊԱՅՄԱՆՆԵՐԻ ԵՎ ՊԱՀԱՆՋՆԵՐԻ ԿԱՏԱՐՄԱՆ ՆԿԱՏՄԱՄԲ ՎԵՐԱՀՍԿՈՂՈՒԹՅՈՒՆԸ
16. Ռադիոակտիվ նյութերի կամ ռադիոակտիվ նյութեր պարունակող սարքերի պահեստավորման լիցենզիայի պայմանների և պահանջների կատարումը վերահսկվում է կարգավորող մարմնի կողմից` օրենքով սահմանված կարգով:
(16-րդ կետը փոփ. 18.03.11 N 249-Ն)
