# Հավելված N 1 ՀՀ կառավարության 2003 թվականի մարտի 7-ի N 312-Ն որոշման
Ց Ա Ն Կ
«ՊԱՏՄԱՄՇԱԿՈՒԹԱՅԻՆ ԱՐԳԵԼՈՑ-ԹԱՆԳԱՐԱՆՆԵՐԻ ԵՎ ՊԱՏՄԱԿԱՆ ՄԻՋԱՎԱՅՐԻ ՊԱՀՊԱՆՈՒԹՅԱՆ ԾԱՌԱՅՈՒԹՅՈՒՆ» ՊԵՏԱԿԱՆ ՈՉ ԱՌԵՎՏՐԱՅԻՆ ԿԱԶՄԱԿԵՐՊՈՒԹՅԱՆ ՄԱՍՆԱՃՅՈՒՂԵՐԻ
1. «Գառնի» պատմամշակութային արգելոց-թանգարան
2. (կետն ուժը կորցրել է 18.05.17 N 541-Ն)
3. «Զվարթնոց» պատմամշակութային արգելոց-թանգարան
4. «Մեծամոր» պատմահնագիտական արգելոց-թանգարան
5. «Գլաձորի համալսարան» պատմամշակութային արգելոց-թանգարան
6. «Գոշավանք» պատմաճարտարապետական արգելոց
7. «Արփի» բնապատմական արգելոց
8. Պատմական միջավայրի պահպանության Երևանի մարզային ծառայություն
9. Պատմական միջավայրի պահպանության Արագածոտնի մարզային ծառայություն
10. Պատմական միջավայրի պահպանության Արարատի մարզային ծառայություն
11. Պատմական միջավայրի պահպանության Արմավիրի մարզային ծառայություն
12. Պատմական միջավայրի պահպանության Գեղարքունիքի մարզային ծառայություն
13. Պատմական միջավայրի պահպանության Լոռու մարզային ծառայություն
14. Պատմական միջավայրի պահպանության Կոտայքի մարզային ծառայություն
15. Պատմական միջավայրի պահպանության Շիրակի մարզային ծառայություն
16. Պատմական միջավայրի պահպանության Սյունիքի մարզային ծառայություն
17. Պատմական միջավայրի պահպանության Վայոց ձորի մարզային ծառայություն
18. Պատմական միջավայրի պահպանության Տավուշի մարզային ծառայություն
19. «Զորաց քարեր» բնակատեղի պատմամշակութային արգելոց
21. «Լոռի բերդ» քաղաքատեղի» պատմամշակութային արգելոց
22. «Ագարակ» պատմամշակութային արգելոց
23. «Ամբերդ ամրոց» պատմամշակութային արգելոց
24. «Բերդ» պատմամշակութային արգելոց
25. «Բջնի-ամրոց» պատմամշակութային արգելոց
26. «Սմբատաբերդ» պատմամշակութային արգելոց
27. «Դաշտադեմ ամրոց» պատմամշակութային արգելոց
28. «Մայրաքաղաք Դվին» պատմամշակութային արգելոց
29. «Աղձք» պատմամշակութային արգելոց
30. «Արտաշատ Մայրաքաղաք» պատմամշակութային արգելոց
31. «Երերույք» պատմամշակութային արգելոց
32. «Հին Խնձորեսկ» պատմամշակութային արգելոց
33. «Բերդկունք ամրոց» պատմամշակութային արգելոց
34. «Նորատուսի խաչքարեր» պատմամշակութային արգելոց
35. «Տափի բերդ» պատմամշակութային արգելոց
(հավելվածը լրաց. 26.06.09 N 853-Ն, 16.09.10 N 1426-Ն, 24.11.16 N 1204-Ն, փոփ., լրաց. 18.05.17 N 541-Ն, լրաց. 08.06.18 N 642-Ն, 22.04.21 N 644-Ն, 26.05.22 N 731-Ն, 30.03.23 N 418-Ն, 29.08.24 N 1383-Ն, 05.12.24 N 1924-Ն)
