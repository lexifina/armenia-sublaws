# Հավելված ՀՀ կառավարության 2006 թվականի ապրիլի 27-ի N 557-Ն որոշման
Կ Ա Ր Գ
ԼԻԱԶՈՐ ՄԱՐՄՆԻ ՈՒՍՈՒՄՆԱԿԱՆ ՀԱՍՏԱՏՈՒԹՅՈՒՆՈՒՄ ՓՐԿԱՐԱՐ ԾԱՌԱՅՈՒԹՅԱՆ ԿՐԹԱԿԱՆ ԾՐԱԳՐՈՎ ՍՈՎՈՐՈՂԻ ԿԱՄ ԱՅԼ ՈՒՍՈՒՄՆԱԿԱՆ ՀԱՍՏԱՏՈՒԹՅՈՒՆՆԵՐ ԳՈՐԾՈՒՂՎԱԾ ԾԱՌԱՅՈՂԻ ԿՈՂՄԻՑ ՈՒՍՄԱՆ ԿԱՄ ՎԵՐԱՊԱՏՐԱՍՏՄԱՆ (ՈՐԱԿԱՎՈՐՄԱՆ) ՀԱՄԱՐ ՊԵՏՈՒԹՅԱՆ ԿԱՏԱՐԱԾ ԾԱԽՍԵՐԻ ՓՈԽՀԱՏՈՒՑՄԱՆ
(վերնագիրը փոփ. 25.09.14 N 1039-Ն, 06.07.23 N 1134-Ն, խմբ. 05.06.25 N 711-Ն)
1. Սույն կարգով սահմանվում է Լիազոր մարմնի ուսումնական հաստատությունում փրկարար ծառայության կրթական ծրագրով սովորողի, այլ ուսումնական հաստատություններ գործուղված ծառայողի, ուսումնական հաստատությունում ուսումը կամ օտարերկրյա պետությունում կազմակերպված ուսուցումը և վերապատրաստումն ավարտած ծառայողի կողմից ուսման կամ վերապատրաստման (որակավորման) համար պետության կատարած ծախսերի փոխհատուցման կարգը:
(1-ին կետը փոփ. 25.09.14 N 1039-Ն, 06.07.23 N 1134-Ն, խմբ. 05.06.25 N 711-Ն)
2. Սովորողը և փրկարարական ծառայողը պետության կատարած ծախսերը փոխհատուցում է «Փրկարար ծառայության մասին» Հայաստանի Հանրապետության օրենքի 71-րդ հոդվածի 1-ին մասով նախատեսված դեպքերում` սույն կարգի 2.1-ին կետով նախատեսված բանաձևով հաշվարկված՝ փոխհատուցման ենթակա գումարի չափով:
(2-րդ կետը փոփ. 25.09.14 N 1039-Ն, խմբ. 05.06.25 N 711-Ն)
2.1. Փոխհատուցման ենթակա գումարի չափը որոշվում է հետևյալ բանաձևով՝
ՓԵԳ = ՓԾ - (ՓԾ X ՓԾԾՕ/ՊԾՕ), որտեղ՝
ՓԵԳ-ը (փոխհատուցման ենթակա գումար) փրկարար ծառայողի կողմից փոխհատուցման ենթակա գումարի չափն է,
ՓԾ-ն (փաստացի ծախսերը) փրկարար ծառայողի ուսման կամ վերապատրաստման (որակավորման) համար պետության կատարած փաստացի ծախսերն են,
ՓԾԾՕ-ն (փրկարար ծառայությունում ծառայած օրերը) ուսման կամ վերապատրաստման (որակավորման) ավարտից հետո փրկարար ծառայողի փրկարար ծառայությունում ծառայած օրերի թիվն է,
ՊԾՕ-ն (պարտադիր ծառայության օրեր) ուսման կամ վերապատրաստման (որակավորման) ավարտից հետո պայմանագրով նախատեսված պարտադիր ծառայության օրերի թիվն է:
(2.1-ին կետը լրաց. 05.06.25 N 711-Ն)
3. Սովորողի և ծառայության միջև կնքվում է պայմանագիր, որում պարտադիր ներառվում են`
ա) «Փրկարար ծառայության մասին» Հայաստանի Հանրապետության օրենքով և սույն կարգով նախատեսված այն պայմանները, որոնց դեպքում` պետության կատարած ծախսերը փոխհատուցվում են.
բ) (ենթակետն ուժը կորցրել է 05.06.25 N 711-Ն)
գ) այն հանգամանքը, որ պետության կատարած ծախսերի փոխհատուցումը կատարվելու է փաստացի ուսումնառության կամ վերապատրաստման ժամանակահատվածի համար.
դ) հետուսումնառության պարտադիր ծառայության սահմանված ժամկետները` համաձայն «Փրկարար ծառայության մասին» Հայաստանի Հանրապետության օրենքի 71-րդ հոդվածի 2-րդ մասի «ա» կետով սահմանված պայմանների.
ե) այն պայմանները, որոնց դեպքում պետության կատարած ծախսերը չեն փոխհատուցվում` համաձայն «Փրկարար ծառայության մասին» Հայաստանի Հանրապետության օրենքի 71-րդ հոդվածի 2-րդ մասի «բ» կետով սահմանված պայմանների.
զ) 18 տարին չլրացած անչափահաս սովորողների ծնողների կամ որդեգրողների և հոգաբարձուների պարտականությունները` համաձայն Հայաստանի Հանրապետության քաղաքացիական օրենսգրքի 1068-րդ հոդվածի.
է) պետության կատարած ծախսերի փոփոխման դեպքում` Հայաստանի Հանրապետության քաղաքացիական օրենսգրքով սահմանված կարգով նոր պայմանագիր կնքելը.
ը) դասընթացի մեկնարկի օրը, ամիսը, տարեթիվը, պայմանագրի գործողության ժամկետը.
թ) փոխհատուցման ենթակա գումարի չափի որոշման բանաձևը.
ժ) դասընթացի տեսակը` ուսում կամ վերապատրաստում (որակավորում):
(3-րդ կետը փոփ. 25.09.14 N 1039-Ն, փոփ., լրաց. 05.06.25 N 711-Ն)
4. Փրկարարական ծառայության անցնող այն քաղաքացին, որը պետք է անցնի ուսումնական փորձաշրջան, և ներքին գործերի բնագավառում պետական կառավարման լիազոր մարմնի (այսուհետ՝ Լիազոր մարմին) ուսումնական հաստատություն ընդունվող դիմորդը փաստաթղթերը ներկայացնելիս գրավոր տեղեկացվում են սույն կարգով նախատեսված ծախսերի փոխհատուցման պայմանների մասին:
(4-րդ կետը փոփ. 25.09.14 N 1039-Ն, 06.07.23 N 1134-Ն, 05.06.25 N 711-Ն)
5. Ուսման գործուղվող ծառայողի, ուսումնական փորձաշրջան անցնողի հետ պայմանագիրը կնքվում է մինչև համապատասխան փաստաթղթերի ձևակերպումը, իսկ քննությունները հանձնած և մրցույթով անցած դիմորդների հետ` մինչև Լիազոր մարմնի ուսումնական հաստատությունում նրանց` որպես սովորող հրամանագրումը:
(5-րդ կետը փոփ. 05.06.25 N 711-Ն)
6. Ուսումնառության ընթացքում ուսման, վերապատրաստման (որակավորման) կամ ուսումնական փորձաշրջանի համար սահմանված ծախսերի փոփոխման դեպքում ուսման կամ վերապատրաստման (որակավորման) գործուղված ծառայողի, Լիազոր մարմնի ուսումնական հաստատությունում սովորողի, այդ թվում` այլ ուսումնական հաստատություն գործուղվածի, ուսումնական փորձաշրջան անցնողի և Հայաստանի փրկարար ծառայության միջև Հայաստանի Հանրապետության քաղաքացիական օրենսգրքով սահմանված կարգով կնքվում է նոր պայմանագիր:
(6-րդ կետը փոփ. 05.06.25 N 711-Ն)
7. Սույն կարգով նախատեսված դեպքերում պայմանագրով սահմանված ժամկետում փոխհատուցման գումարը փոխհատուցողի կողմից կանխիկ կամ փոխանցմամբ Հայաստանի Հանրապետության դրամով վճարվում է Լիազոր մարմնին:
(7-րդ կետը խմբ. 05.06.25 N 711-Ն)
8. Ուսումնական հաստատությունից ազատված սովորողը պետության կատարած ծախսերը փոխհատուցում է ուսումնառության փաստացի ժամանակահատվածի համար:
9. Մեղադրական դատավճիռն օրինական ուժի մեջ մտնելու պատճառով, «Փրկարար ծառայության մասին» Հայաստանի Հանրապետության օրենքով սահմանված կարգով փրկարարական ծառայությունից, ուսումնական հաստատությունից հեռացվելու կամ ազատվելու դեպքում` պետության կատարած ծախսերը փոխհատուցվում են Հայաստանի Հանրապետության քաղաքացիական օրենսդրությամբ սահմանված կարգով:
(9-րդ կետը փոփ. 25.09.14 N 1039-Ն)
