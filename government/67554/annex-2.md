# Հավելված N 2 ՀՀ կառավարության 2011 թվականի ապրիլի 28-ի N 517-Ն որոշման
Կ Ա Զ Մ
ՍԵՎԱՆԱ ԼՃԻ ՎԵՐԱԿԱՆԳՆՄԱՆ, ՊԱՀՊԱՆՄԱՆ ԵՎ ԶԱՐԳԱՑՄԱՆ ՀԻՄՆԱԴՐԱՄԻ ՀՈԳԱԲԱՐՁՈՒՆԵՐԻ ԽՈՐՀՐԴԻ
Հ. Աբրահամյան | - ՀՀ վարչապետ
Ա. Գևորգյան | - ՀՀ փոխվարչապետ, ՀՀ տարածքային կառավարման նախարար
Ա. Գրիգորյան | - ՀՀ բնապահպանության նախարար
Ա. Երիցյան | - ՀՀ արտակարգ իրավիճակների նախարար
Ս. Կարապետյան | - ՀՀ գյուղատնտեսության նախարար
Հ. Հակոբյան | - ՀՀ սփյուռքի նախարար
Կ. Ճշմարիտյան | - ՀՀ էկոնոմիկայի նախարար
Ա. Մուրադյան | - ՀՀ առողջապահության նախարար
Հ. Պողոսյան | - ՀՀ մշակույթի նախարար
Հ. Հակոբյան | - ՀՀ Ազգային ժողովի պատգամավոր (համաձայնությամբ)
Խ. Հարությունյան | - ՀՀ Ազգային ժողովի պատգամավոր (համաձայնությամբ)
Ռ. Գրիգորյան | - ՀՀ Գեղարքունիքի մարզպետ
Ռ. Մարտիրոսյան | - ՀՀ գիտությունների ազգային ակադեմիայի նախագահ (համաձայնությամբ)
Վ. Մովսիսյան | - ՀՀ Նախագահին առընթեր Սևանա լճի հիմնահարցերի հանձնաժողովի նախագահ (համաձայնությամբ)
Ս. Համբարձումյան | - ՀՀ գիտությունների ազգային ակադեմիայի ակադեմիկոս (համաձայնությամբ)
Զ. Բալայան | - գրող, հրապարակախոս (համաձայնությամբ)
Կ. Դանիելյան | - Հանուն կայուն մարդկային զարգացման ասոցիացիայի նախագահ (համաձայնությամբ)
(հավելվածը խմբ. 04.06.14 N 570-Ն)
