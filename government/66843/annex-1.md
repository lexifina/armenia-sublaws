# Հավելված N 1 ՀՀ կառավարության 2011 թվականի մարտի 31-ի N 324-Ն որոշման
Ն Կ Ա Ր Ա Գ Ի Ր
«ԳՈՌԱՎԱՆԻ ԱՎԱԶՈՒՏՆԵՐ» ՊԵՏԱԿԱՆ ԱՐԳԵԼԱՎԱՅՐԻ ՍԱՀՄԱՆՆԵՐԻ
«Գոռավանի ավազուտներ» պետական արգելավայրի տարածքը գտնվում է Հայաստանի Հանրապետության Արարատի մարզի Գոռավանի գյուղական համայնքի բնակավայրի հարավ-արևելյան մասում:
Տարածքի ընդհանուր մակերեսը կազմում է 95.99 հեկտար (որից` 21.95 հեկտարը` դամբարանադաշտ):
«Ա» հանգուցային սահմանակետից, որը գտնվում է կոլեկտիվ այգեգործության հողամասի հարավարևմտյան եզրագծի մոտով անցնող անօգտագործելի հողաշերտի վրա, սահմանագիծը թեքվում է դեպի հարավ-արևելք, անօգտագործելի տարածքով անցնում 46.0 մ, հասնում N 1 սահմանակետին, ապա թեքվում է դեպի հարավ-արևմուտք, անցնում 96.0 մ, հասնում N 2 սահմանակետին, այնուհետև կրկին թեքվում է դեպի հարավ-արևելք, ուղիղ գծով անցնում 806.0 մ, հասնում N 3 սահմանակետին: N 3 սահմանակետից սահմանագիծը թեքվում է դեպի հարավ-արևմուտք, ուղիղ գծով անցնում 314.0 մ, հասնում N 4 սահմանակետին, ապա թեքվում է դեպի հյուսիս-արևմուտք, ուղիղ գծով անցնում 350.0 մ, հասնում N 5 սահմանակետին: N 5 սահմանակետից սահմանագիծը կորաձև թեքվում է հյուսիս-արևմուտքից դեպի հարավ-արևմուտք, անօգտագործելի հողատարածքով` N 6-9 սահմանակետերով անցնում 341.0 մ, հասնում N 10 սահմանակետին, որտեղից թեքվում է դեպի հարավ-արևմուտք, ուղիղ գծով` անօգտագործելի տարածքով անցնում 395.0 մ, հասնում N 11 սահմանակետին: N 11 սահմանակետից սահմանագիծը թեքվում է դեպի արևմուտք, ուղիղ գծով անցնում 742.0 մ, հասնում հանքավայրից դեպի հյուսիս-արևելք գտնվող N 12 սահմանակետին, ապա թեքվում է դեպի հյուսիս-արևմուտք, նույն անօգտագործելի հողատարածքով անցնում 221.0 մ, հասնում սեփականաշնորհված վարելահողի եզրին գտնվող N 13 սահմանակետին: N 13 սահմանակետից սահմանագիծը վարելահողի եզրագծով թեքվում է դեպի հյուսիս-արևելք, ապա հյուսիս, հետո` հյուսիս-արևմուտք, NN 14 և 15 սահմանակետերով անցնում 186.0 մ, հասնում վարելահողի եզրի N 16 սահմանակետին: N 16 սահմանակետից սահմանագիծը թեքվում է դեպի հյուսիս-արևելք, սեփականաշնորհված վարելահողի հարավային եզրագծի ոլորապտույտների NN 17-32 սահմանակետերով անցնում է 637.0 մ, հասնում վարելահողի և բնակավայրի անօգտագործելի հողերի հատման կետում գտնվող N 33 սահմանակետին, այստեղից թեքվում է դեպի հյուսիս-արևելք, անօգտագործելի տարածքի եզրագծով` NN 34-36 սահմանակետերով անցնում 467.0 մ, հասնում N 37 սահմանակետին: N 37 սահմանակետից սահմանագիծը թեքվում է դեպի հարավ-արևելք, ապա հյուսիս-արևելք, վարելահողի և պետարգելավայրի արանքով անցնող անօգտագործելի հողերի հարավային եզրագծի NN 38-42 սահմանակետերով անցնում է 487.0 մ, հասնում «Ա» հանգուցային սահմանակետին:
«Ա» - «Ա» սահմանագծի ընդհանուր երկարությունը կազմում է 5088,0 մ:
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար | Դ. Սարգսյան
