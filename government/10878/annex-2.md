# Հավելված N 2 ՀՀ կառավարության 2003 թվականի ապրիլի 23-ի N 524-Ն որոշման
Կ Ա Ռ ՈՒ Ց Վ Ա Ծ Ք
ՇՈՒԿԱՅԻ ՎԵՐԱՀՍԿՈՂՈՒԹՅԱՆ ՊԵՏԱԿԱՆ ՏԵՍՉՈՒԹՅԱՆ
(Վերնագիրը փոփ. 15.05.08 N 550-Ն, խմբ. 15.12.11 N 1792-Ն)
Կառուցվածքային ստորաբաժանումներ
1. Փաստաթղթաշրջանառության և իրավական համակարգման բաժին
2. Մոնիթորինգի, ռիսկերի գնահատման և տեղեկատվության բաժին
3. Վերահսկողության բաժին
4. Թանկարժեք մետաղների վերահսկողության բաժին
5. Չափագիտական կանոնների և նորմերի վերահսկողության բաժին
(հավելվածը խմբ. 12.08.04 N 1166-Ն, 10.05.07 N 599-Ն, 15.12.11 N 1792-Ն)
