# Հավելված ՀՀ կառավարության 2012 թվականի հուլիսի 19-ի N 985-Ն որոշման
Կ Ա Ր Գ
ՄԻ ՇԱՐՔ ՄԻՋԱԶԳԱՅԻՆ ԿԱԶՄԱԿԵՐՊՈՒԹՅՈՒՆՆԵՐԻ ԿՈՂՄԻՑ ԱՌԱՋԱԴՐՎԱԾ ԿԱՊԻ ԵՎ ՏԵՂԵԿԱՏՎԱԿԱՆ ՀԵՌԱՀԱՂՈՐԴԱԿՑԱԿԱՆ ՏԵԽՆՈԼՈԳԻԱՆԵՐԻ ՈԼՈՐՏԻ ՑՈՒՑԱՆԻՇՆԵՐԻ ՀԱՎԱՔԱԳՐՄԱՆ ԵՎ ՎԱՐՉԱԿԱՆ ՎԻՃԱԿԱԳՐԱԿԱՆ ՌԵԳԻՍՏՐԻ ՎԱՐՄԱՆ
I. ԸՆԴՀԱՆՈՒՐ ԴՐՈՒՅԹՆԵՐ
1. Սույն կարգով սահմանվում է մի շարք միջազգային կազմակերպությունների կողմից առաջադրված կապի և տեղեկատվական հեռահաղորդակցական տեխնոլոգիաների ոլորտի ցուցանիշների (այսուհետ` ցուցանիշներ) հավաքագրման և վարչական վիճակագրական ռեգիստրի վարման կարգը:
2. Վարչական վիճակագրական ռեգիստրը տեղեկություններ է պարունակում Հայաստանի Հանրապետությունում կապի և տեղեկատվական հեռահաղորդակցական տեխնոլոգիաների ոլորտի ցուցանիշների մասին:
3. Վարչական վիճակագրական ռեգիստրի տեղեկությունները (այսուհետ` ռեգիստրի տեղեկություններ) թարմացվում են Հայաստանի Հանրապետության կրթության, գիտության, մշակույթի և սպորտի նախարարության, Հայաստանի Հանրապետության առողջապահության նախարարության, Հայաստանի Հանրապետության ֆինանսների նախարարության և Հայաստանի Հանրապետության հանրային ծառայությունները կարգավորող հանձնաժողովի կողմից ներկայացված տեղեկությունների, ինչպես նաև Հայաստանի Հանրապետության վիճակագրական կոմիտեի հրապարակած պաշտոնական վիճակագրության հիման վրա:
(3-րդ կետը փոփ. 10.10.18 N 1142-Ն, խմբ. 14.11.19 N 1589-Ն)
4. Հեռահաղորդակցության միջազգային միության (ՀՄՄ), Կապի տարածաշրջանային համագործակցության և այլ միջազգային կազմակերպությունների կողմից ներկայացված առաջարկությունների հիման վրա կարող է սահմանված կարգով փոփոխվել Հայաստանի Հանրապետության բարձր տեխնոլոգիական արդյունաբերության նախարարի կողմից հաստատված` կապի և տեղեկատվական հեռահաղորդակցական տեխնոլոգիաների ոլորտի ցուցանիշների ձևաչափը:
(4-րդ կետը փոփ. 10.10.18 N 1142-Ն, 14.11.19 N 1589-Ն)
5. Ռեգիստրի տեղեկությունները բաց են համընդհանուր ծանոթացման համար:
6. Ռեգիստրի տեղեկությունները մինչև տվյալ տարվա օգոստոսի 20-ը տեղադրվում են Հայաստանի Հանրապետության բարձր տեխնոլոգիական արդյունաբերության նախարարության www.hti.am կայքում «ՏՀՏ ցուցանիշներ» բաժնում, որը ներառում է նախորդ տարվա ցուցանիշների ամփոփ տվյալները:
(6-րդ կետը փոփ. 16.04.15 N 382-Ն, 10.10.18 N 1142-Ն, 14.11.19 N 1589-Ն)
7. Ցուցանիշների լրացման և (կամ) փոփոխման դեպքում Հայաստանի Հանրապետության բարձր տեխնոլոգիական արդյունաբերության նախարարությունը (այսուհետ` լիազոր մարմին) 10-օրյա ժամկետում կայքում կատարում է համապատասխան փոփոխություններ:
(7-րդ կետը փոփ. 10.10.18 N 1142-Ն, 14.11.19 N 1589-Ն)
8. Ռեգիստրի տեղեկությունները Հայաստանի Հանրապետության օրենսդիր և գործադիր իշխանության մարմիններին, Հեռահաղորդակցության միջազգային միությանը, Կապի տարածաշրջանային համագործակցությանը և այլ միջազգային կազմակերպությունների տրամադրվում են անվճար:
9. Լիազոր մարմինը յուրաքանչյուր տարի մինչև օգոստոսի 15-ը ամփոփում է համապատասխան մարմինների կողմից ներկայացված և իր դիտարկումների արդյունքում հավաքագրված նախորդ տարվա վերաբերյալ ցուցանիշները:
(9-րդ կետը փոփ. 16.04.15 N 382-Ն)
10. Ամփոփված ցուցանիշները փոփոխվում և (կամ) լրացվում են մինչև տվյալ տարվա հուլիսի 15-ից մինչև օգոստոսի 15-ը` համապատասխան մարմինների կողմից ներկայացված առաջարկությունների և դիտարկումների հիման վրա:
(10-րդ կետը փոփ. 16.04.15 N 382-Ն)
II. ՎԱՐՉԱԿԱՆ ՎԻՃԱԿԱԳՐՈՒԹՅՈՒՆ ԻՐԱԿԱՆԱՑՆՈՂ ՄԱՐՄՆԻ ԻՐԱՎՈՒՆՔՆԵՐԸ ԵՎ ՊԱՐՏԱԿԱՆՈՒԹՅՈՒՆՆԵՐԸ
11. Լիազոր մարմինն իրավունք ունի ստանալու վարչական ռեգիստրների վարման համար անհրաժեշտ տվյալներ և տեղեկություններ Հայաստանի Հանրապետության կառավարության 2012 թվականի հուլիսի 19-ի N 985-Ն որոշման 3-րդ և 5-րդ կետերում նշված մարմիններից և պետական հիմնարկներից:
12. Լիազոր մարմինը պարտավոր է հրապարակել իրենց կողմից իրականացված վարչական բնույթի դիտարկումների արդյունքները` մինչև հաջորդ տարվա օգոստոսի 20-ը։
(12-րդ կետը փոփ. 16.04.15 N 382-Ն)
13. Վարչական վիճակագրություն իրականացնող մարմինը պարտավոր է ռեգիստրի տեղեկությունների և ցուցանիշների վերաբերյալ դիտարկումները և այլ աշխատանքներ իրականացնել «Էլեկտրոնային հաղորդակցության մասին» Հայաստանի Հանրապետության օրենքի և այլ իրավական ակտերի պահանջներին համապատասխան, ինչպես նաև առաջնորդվել «Պաշտոնական վիճակագրության մասին» օրենքով։
(13-րդ կետը փոփ. 10.10.18 N 1142-Ն)
III. ՎԱՐՉԱԿԱՆ ՌԵԳԻՍՏՐԻ ՎԱՐՄԱՆ ԿԱՐԳԸ
14. Վարչական վիճակագրական ռեգիստրում տվյալները գրանցվում են գրանցամատյանում կամ էլեկտրոնային եղանակով տվյալների շտեմարանում՝ հավաքագրվող ցուցանիշների ձևաչափին համապատասխան:
(14-րդ կետը փոփ. 10.10.18 N 1142-Ն)
15. Փոփոխությունները կատարվում են հետևյալ կարգով՝
1) անհրաժեշտության դեպքում փոփոխությունները կատարվում են լիազոր մարմնի կողմից այդ ժամանակաշրջանի (ժամանակաշրջանների) վիճակագրական դիտարկման արդյունքների հիման վրա.
2) վարչական ռեգիստրում տվյալների փոփոխությունը կատարվում է 10-օրյա ժամկետում:
(հավելվածը փոփ. 16.04.15 N 382-Ն, 10.10.18 N 1142-Ն, փոփ., խմբ. 14.11.19 N 1589-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար | Դ. Սարգսյան
