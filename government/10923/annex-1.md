# Հավելված ՀՀ կառավարության 2003 թվականի մայիսի 2-ի N 608-Ն որոշման
Կ Ա Ր Գ
ԿԱՌՈՒՑԱՊԱՏՄԱՆ ՆԱԽԱԳԾԻ ՄՇԱԿՄԱՆ, ՓՈՐՁԱՔՆՆՈՒԹՅԱՆ, ՀԱՄԱՁԱՅՆԵՑՄԱՆ, ՀԱՍՏԱՏՄԱՆ ԵՎ ՓՈՓՈԽՄԱՆ
1. Սույն կարգը սահմանում է կառուցապատման նախագծի մշակմանը, դրա կազմին ու բովանդակությանը, ինչպես նաև նախագծի փորձաքննության, համաձայնեցման, հաստատման և փոփոխման ընթացակարգերին ներկայացվող հիմնական պահանջները:
2. Կառուցապատման նախագիծը ճարտարապետաշինարարական փաստաթուղթ է, որը մշակվում է հաստատված քաղաքաշինական ծրագրային, փաստաթղթերի` համայնքի (բնակավայրի) գլխավոր հատակագծի և գոտևորման նախագծի հիման վրա` դրանցով սահմանված պահանջների պահպանմամբ` նոր կամ վերակառուցվող բնակելի, հասարակական, արտադրական շենքերի խմբերի, ռեկրեացիոն-առողջարանային, մարզահամալիրների և այլ նշանակության քաղաքաշինական օբյեկտների համար: Կառուցապատման նախագիծը կարող է մշակվել նաև համայնքի սահմաններից դուրս գտնվող տարածքների համար:
(2-րդ կետը փոփ. 13.07.06 N 1001-Ն)
2¹. Հաստատված քաղաքաշինական ծրագրային փաստաթղթերի բացակայության դեպքում կառուցապատման նախագիծը մշակվում է Հայաստանի Հանրապետության կառավարության 1998 թվականի հուլիսի 30-ի N 479 որոշմամբ հաստատված կարգի պահանջներին համապատասխան:
(2¹ կետը լրաց. 13.07.06 N 1001-Ն)
2². Հայաստանի Հանրապետության միջպետական և հանրապետական նշանակության ընդհանուր օգտագործման պետական ավտոմոբիլային ճանապարհներին հարող տարածքներում կառուցապատման նախագիծը մշակվում է Հայաստանի Հանրապետության կառավարության 2005 թվականի դեկտեմբերի 29-ի N 2404-Ն որոշմամբ սահմանված պահանջներին համապատասխան:
(2² կետը լրաց. 13.07.06 N 1001-Ն)
3. Կառուցապատման նախագիծը մշակվում է նախագծվող տարածքի (այսուհետ` կառուցապատման տարածք)` սահմանված կարգով հաստատված կարմիր գծերի կամ հողամասի (հողամասերի) սահմաններում և որոշում է քաղաքաշինական համալիրների ճարտարապետահատակագծային ու ծավալատարածական հորինվածքային լուծումները, օբյեկտների կառուցման, վերակառուցման (քանդման) հերթականությունը, գործառական նշանակությունը և ինժեներական կառուցվածքները, տարածքի ինժեներական նախապատրաստումն ու բարեկարգումը, տրանսպորտային և հետիոտն շարժման ուղղությունները, շինարարության կազմակերպման կարգը և տեխնիկատնտեսական խոշորացված ցուցանիշները:
Կառուցապատման նախագծով ամրագրված լուծումները պետք է ապահովեն Հայաստանի Հանրապետության օրենսդրության և նորմատիվ-տեխնիկական փաստաթղթերի պահանջների կատարումը:
(3-րդ կետը լրաց. 13.07.06 N 1001-Ն)
4. Սահմանված կարգով հաստատված կարմիր գծերի բացակայության դեպքում կառուցապատման նախագծի կազմում առանձին գծագրով մշակվում է կառուցապատման տարածքի կարմիր գծերի նախագիծ: Հայաստանի Հանրապետությունում կարմիր գծերի նախագծի մշակման կարգը սահմանվում է քաղաքաշինության բնագավառի պետական լիազորված մարմնի գերատեսչական ակտով:
(4-րդ կետը փոփ. 13.07.06 N 1001-Ն)
5. Կառուցապատման նախագծի կազմին և բովանդակությանը ներկայացվող հիմնական պահանջները բերված են սույն կարգի N 1 հավելվածում:
(5-րդ կետը լրաց., փոփ. 13.07.06 N 1001-Ն)
6. Կառուցապատման նախագիծը մշակվում է ըստ անհրաժեշտության` կառուցապատողի իրավասություններով օժտված օրենքով սահմանված սուբյեկտների (այսուհետ` պատվիրատու) պատվերով` Հայաստանի Հանրապետության կառավարության 2002 թվականի օգոստոսի 29-ի N 1473-Ն որոշմամբ սահմանված կարգով տրամադրված ճարտարապետահատակագծային առաջադրանքի հիման վրա:
(6-րդ կետը լրաց. 13.07.06 N 1001-Ն)
6¹. Պետական կամ համայնքային բյուջեի (այդ թվում` վարկային և դրամաշնորհային) միջոցների հաշվին կամ, դրանց ներգրավմամբ նախատեսվող օբյեկտների նախագծման դեպքում, պատվիրատուն կառուցապատման նախագիծը մշակողին (այսուհետ` կատարող) ընտրում է «Գնումների մասին» Հայաստանի Հանրապետության օրենքով սահմանված կարգով: Նշված միջոցների հաշվին քաղաքաշինական գործունեության իրականացման դեպքում կառուցապատման նախագծի կազմում պարտադիր մշակվում են նաև նախահաշվային փաստաթղթերը:
(6¹ կետը լրաց. 13.07.06 N 1001-Ն)
6². Կառուցապատման նախագիծը կարող է մշակվել մեկ` «Աշխատանքային նախագիծ» փուլով կամ, երկու` «Նախագիծ» և «Աշխատանքային փաստաթղթեր» փուլերով: Կառուցապատման նախագծի փուլերը մշակվում են Հայաստանի Հանրապետության կառավարության 1998 թվականի դեկտեմբերի 21-ի N 812-Ն որոշմամբ սահմանված կարգին համապատասխան:
Կառուցապատման նախագծի «Աշխատանքային նախագիծ» և «Աշխատանքային փաստաթղթեր» փուլերում ներառվում են նաև ճարտարապետահատակագծային առաջադրանքով նախատեսված օբյեկտների նախագծերի աշխատանքային փաստաթղթերը կամ կրկնակի (բազմակի) կիրառման օբյեկտների տեղակապման նախագծերը:
(6² կետը լրաց. 13.07.06 N 1001-Ն)
6³. Հայաստանի Հանրապետության օրենսդրությամբ սահմանված քաղաքաշինական գործունեության հատուկ կարգավորման օբյեկտների տարածքներում, կառուցապատման տարածքի համար Հայաստանի Հանրապետության կառավարության 2001 թվականի մայիսի 14-ի N 408 որոշմամբ սահմանված կարգով հաստատված գոտևորման նախագծերի բացակայության դեպքում, ինչպես նաև Հայաստանի Հանրապետության կառավարության 1998 թվականի դեկտեմբերի 21-ի N 812 որոշմամբ հաստատված հատուկ և կարևորագույն նշանակություն ունեցող օբյեկտներ ներառող համալիրներ նախագծելիս մշակվում է նաև «Կառուցապատման էսքիզային նախագիծ (կառուցապատման սխեմա)» փուլը` օբյեկտի ծավալատարածական և ճարտարապետահատակագծային ընդհանրական լուծումների ամրագրմամբ: Ընդ որում, ճարտարապետահատակագծային առաջադրանքով կամ նախագծային կապալի պայմանագրով նախատեսված դեպքերում, ելնելով կառուցապատման տարածքի քաղաքաշինական իրադրության կարևորությունից և նախագծվող օբյեկտի ծավալից, նշանակությունից և բարդությունից, կառուցապատման սխեման կարող է մշակվել նաև որպես ինքնուրույն փաստաթուղթ:
Հայաստանի Հանրապետության կառավարությունն օրենքով սահմանված դեպքերում կառուցապատման նախագծերը (կառուցապատման սխեմաները) հաստատելիս միաժամանակ, ըստ անհրաժեշտության, փոփոխում է կառուցապատման տարածքում ներառված հողերի նպատակային նշանակությունը: Նշված փոփոխություններն ընդգրկվում են համապատասխան համայնքի, մարզի հողային ֆոնդի տվյալներում և հողային հաշվեկշռում:
(6³ կետը լրաց. 13.07.06 N 1001-Ն, փոփ. 09.04.09 N 355-Ն)
7. (7-րդ կետն ուժը կորցրել է 13.07.06 N 1001-Ն)
8. Պատվիրատուն`
ա) սահմանված կարգով ընտրված` Հայաստանի Հանրապետության օրենսդրությամբ սահմանված` կապիտալ շինարարության բնագավառում քաղաքաշինական փաստաթղթերի մշակման համապատասխան լիցենզիա ունեցող կատարողին հանձնում է ճարտարապետահատակագծային առաջադրանքը, ինչպես նաև պատվիրատուի կողմից կազմված նախագծման առաջադրանքը.
բ) կատարողին է տրամադրում նախագծման համար անհրաժեշտ ելակետային նյութերը: Նախագծման համար անհրաժեշտ ելակետային նյութերի կազմը բերված է սույն կարգի N 2 հավելվածում.
գ) կատարողի հետ սահմանված կարգով կնքում է պայմանագիր.
դ) պատվիրատուի և կատարողի համաձայնությամբ` կատարողը կարող է հավաքել ելակետային նյութերը կամ դրանց մի մասը:
