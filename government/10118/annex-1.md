# Հավելված ՀՀ կառավարության 2002 թվականի հոկտեմբերի 3-ի N 1584-Ն որոշման
Կ Ա Ր Գ
ՀԱՐԿԱՅԻՆ ԳԱՂՏՆԻՔ ՀԱՆԴԻՍԱՑՈՂ ՏԵՂԵԿՈՒԹՅՈՒՆՆԵՐԻ ՕԳՏԱԳՈՐԾՄԱՄԲ ԱՇԽԱՏԱՆՔՆԵՐ ԿԱՏԱՐԵԼՈՒ ԻՐԱՎԱՍՈՒԹՅՈՒՆ ՈՒՆԵՑՈՂ ՊԵՏԱԿԱՆ ՄԱՐՄԻՆՆԵՐԻՆ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՖԻՆԱՆՍՆԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԿՈՂՄԻՑ ՀԱՐԿԱՅԻՆ ԳԱՂՏՆԻՔ ՀԱՆԴԻՍԱՑՈՂ ՏԵՂԵԿՈՒԹՅՈՒՆՆԵՐԻ ՏՐԱՄԱԴՐՄԱՆ
(վերնագիրը փոփ. 26.06.14 N 638-Ն)
1. Սույն կարգով կանոնակարգվում է Հայաստանի Հանրապետության ֆինանսների նախարարության (այսուհետ՝ Հայաստանի Հանրապետության ֆինանսների նախարարություն) կողմից հարկային գաղտնիք հանդիսացող տեղեկությունների օգտագործմամբ աշխատանքներ կատարելու իրավասություն ունեցող պետական մարմիններին, այդ թվում` Հայաստանի Հանրապետության կենտրոնական բանկին (այսուհետ՝ տեղեկություն ստացող մարմիններ) հարկային գաղտնիք հանդիսացող տեղեկությունների (այսուհետ՝ տեղեկություն) տրամադրումը։
(1-ին կետը փոփ., լրաց. 26.06.14 N 638-Ն)
2. Տեղեկություն ստացող մարմնի ղեկավարը կամ նրան փոխարինող պաշտոնատար անձն օրենքով սահմանված տեղեկությունները Հայաստանի Հանրապետության ֆինանսների նախարարությունից ստանալու համար ներկայացնում է դիմում, որտեղ նշվում են պահանջվող տեղեկության տեսակը, ժամանակահատվածը։ Եթե պահանջվող տեղեկությունը վերաբերում է իրավաբանական անձանց, ապա նշվում են իրավաբանական անձի անվանումը, հարկ վճարողի հաշվառման համարը, գտնվելու վայրը, իսկ ֆիզիկական անձանց դեպքում՝ ֆիզիկական անձի անկետային տվյալները, ինչպես նաև այն իրավական ակտերը, որոնց հիման վրա տվյալ տեղեկություն ստացող մարմնին նման տեղեկություն ստանալու իրավասություն է վերապահված։
(2-րդ կետը փոփ. 26.06.14 N 638-Ն)
2.1. Օրենքով Հայաստանի Հանրապետության տնտեսական մրցակցության պաշտպանության պետական հանձնաժողովին վերապահված իրավասությունների իրականացման համար անհրաժեշտ տեղեկություններ ստանալու համար ներկայացվող դիմումը կարող է չներառել իրավաբանական և ֆիզիկական անձանց վերաբերող` սույն կարգի 2-րդ կետով սահմանված տվյալները` բացառությամբ հարկ վճարողի հաշվառման համարի:
(2.1-ին կետը լրաց. 10.11.11 N 1637-Ն)
2.2. Հայաստանի Հանրապետության տնտեսական մրցակցության պաշտպանության պետական հանձնաժողովը` Հայաստանի Հանրապետության ֆինանսների նախարարություն տեղեկություններ է ներկայացնում սույն կարգով ստացված տեղեկությունների հիման վրա արձանագրված խախտումների վերաբերյալ` ռիսկերի վրա հիմնված ստուգումների պլանավորման և անցկացման համար: Փոխադարձ տեղեկությունների ներկայացման ձևը հաստատվում է Հայաստանի Հանրապետության տնտեսական մրցակցության պաշտպանության պետական հանձնաժողովի և Հայաստանի Հանրապետության ֆինանսների նախարարության համատեղ հրամանով:
(2.2-րդ կետը լրաց. 10.11.11 N 1637-Ն, փոփ. 26.06.14 N 638-Ն)
3. Տեղեկություն ստացող մարմնի կողմից ներկայացված դիմումում սույն որոշման 2-րդ կետով սահմանված որևէ վավերապայմանի բացակայության (անճշտության) դեպքում, բացառությամբ սույն կարգի 2.1-ին կետի՝ Հայաստանի Հանրապետության ֆինանսների նախարարության կողմից դիմումն ստանալուն հաջորդող 2 աշխատանքային օրվա ընթացքում տեղեկություն ստացող մարմին է ներկայացվում գրավոր մերժում՝ համապատասխան պատճառաբանությամբ։
(3-րդ կետը լրաց. 10.11.11 N 1637-Ն, փոփ. 26.06.14 N 638-Ն)
4. Հայաստանի Հանրապետության ֆինանսների նախարարությունը սույն կարգի համաձայն ստացված դիմումի հիման վրա 5-օրյա ժամկետում Հայաստանի Հանրապետության ֆինանսների նախարարության տեղեկատվական բազայում առկա տեղեկատվության հիման վրա գրավոր տրամադրում է դիմումում նշված տեղեկությունը կամ պահանջվող տեղեկության բացակայության (համապատասխան հաշվառում չվարելու) մասին գրավոր տեղեկացնում է դիմողին։
(4-րդ կետը փոփ. 26.06.14 N 638-Ն)
5. Տեղեկություն ստացող մարմնի կողմից երկրորդ և ավելի անգամ նույն տեղեկությունը պահանջվելու դեպքում տեղեկությունը Հայաստանի Հանրապետության ֆինանսների նախարարության կողմից տրամադրվում է, եթե դրանում կատարվել է փոփոխություն։
(5-րդ կետը փոփ. 26.06.14 N 638-Ն)
6. Հայաստանի Հանրապետության ֆինանսների նախարարության կողմից Հայաստանի Հանրապետության հարկային օրենսդրությամբ նախատեսված դեպքում՝ փոփոխության ենթակա տեղեկություններ տրամադրելիս տեղեկություն ստացողին տեղյակ է պահվում դրա մասին։
(6-րդ կետը փոփ. 26.06.14 N 638-Ն)
7. Հայաստանի Հանրապետության ֆինանսների նախարարությունն իրավապահ մարմիններին տեղեկություն տրամադրում է Հայաստանի Հանրապետության քրեական դատավարության օրենսգրքի հիման վրա։
(7-րդ կետը փոփ. 26.06.14 N 638-Ն)
8. Տեղեկություն ստացող մարմնի կողմից հարկային գաղտնիք հանդիսացող տեղեկության բացահայտումը (հրապարակումը) առաջացնում է Հայաստանի Հանրապետության օրենքով սահմանված պատասխանատվություն։
(հավելվածը լրաց. 10.11.11 N 1637-Ն, փոփ., լրաց. 26.06.14 N 638-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
