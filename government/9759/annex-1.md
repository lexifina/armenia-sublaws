# Հավելված ՀՀ կառավարության 2002 թվականի հուլիսի 18-ի N 1087-Ն որոշման
Կ Ա Ր Գ
ԻՐԱՎԱԲԱՆԱԿԱՆ ԱՆՁԱՆՑ ԵՎ ԱՆՀԱՏ ՁԵՌՆԱՐԿԱՏԵՐԵՐԻ ԿՈՂՄԻՑ «ԳԱՖԷՍՃԵԱՆ ԹԱՆԳԱՐԱՆ» ՀԻՄՆԱԴՐԱՄԻՆ ԱՊՐԱՆՔՆԵՐԻ ՄԱՏԱԿԱՐԱՐՄԱՆ ԵՎ ԾԱՌԱՅՈՒԹՅՈՒՆՆԵՐԻ ՄԱՏՈՒՑՄԱՆ ԳՈՐԾԱՐՔՆԵՐՆ ԱՎԵԼԱՑՎԱԾ ԱՐԺԵՔԻ ՀԱՐԿԻՑ ԱԶԱՏԵԼՈՒ ՀԱՄԱՐ ՀԻՄՔ ԸՆԴՈՒՆՎՈՂ ՏԵՂԵԿԱՆՔԻ ՏՐԱՄԱԴՐՄԱՆ
1. «Գաֆէսճեան թանգարան» հիմնադրամին հարկային, մաքսային և պարտադիր վճարների գծով արտոնություններ տրամադրելու մասին» Հայաստանի Հանրապետության օրենքի 2-րդ հոդվածով նախատեսված՝ թանգարանային և շարժասանդուղքների կասկադի (այսուհետ՝ համալիր) կառուցման և համալիրի գործունեության իրականացման համար «Գաֆէսճեան թանգարան» հիմնադրամին իրավաբանական անձանց և անհատ ձեռնարկատերերի կողմից իրականացված՝ ապրանքների մատակարարման և ծառայությունների մատուցման գործարքներն ավելացված արժեքի հարկից ազատելու համար հիմք է ընդունվում սույն կարգի N 1 հավելվածում ներկայացված տեղեկանքը: Ընդ որում, ավելացված արժեքի հարկից ազատման արտոնություն կիրառող անձանց մոտ նշված տեղեկանքի առկայությունը պարտադիր է:
2. Արտոնությունների կիրառման համար հիմք հանդիսացող՝ սույն կարգի N 1 հավելվածում ներկայացված տեղեկանքը (այսուհետ՝ տեղեկանք) կարող է ներբեռնվել Հայաստանի Հանրապետության ֆինանսների նախարարության պաշտոնական կայքէջից և լրացվել տպագիր կամ ձեռագիր տարբերակներով:
(2-րդ կետը խմբ. 11.04.19 N 378-Ն)
3. (կետն ուժը կորցրել է 11.04.19 N 378-Ն)
4. (կետն ուժը կորցրել է 11.04.19 N 378-Ն)
5. Հիմնադրամի կողմից իրականացված յուրաքանչյուր գործարքի (ձեռքբերման) համար լրացվում է մեկ տեղեկանք: Տեղեկանքը լրացվում է երեք բնօրինակից, որի մեկ օրինակը տրվում է ապրանքներ մատակարարող կամ ծառայություններ մատուցող անձանց (ապրանքների ներմուծման դեպքում՝ մաքսային կամ հարկային մարմին), երկրորդ օրինակը պահվում է «Գաֆէսճեան թանգարան» հիմնադրամում, իսկ երրորդը ներկայացվում է հարկային մարմին՝ մինչև տեղեկանքի դուրսգրման ամսվան հաջորդող ամսվա 15-ը ներառյալ: Յուրաքանչյուր գործարքի համար լրացված հաշվարկային փաստաթղթերը պետք է լինեն նույնական, առանձին-առանձին կնքված ու ստորագրված: Տեղեկանքի սխալ լրացման դեպքում հիմնադրամի կողմից դրա երեք օրինակն էլ ճանաչվում են անվավեր՝ համապատասխան նշում կատարելով դրանց վրա:
(5-րդ կետը խմբ. 11.04.19 N 378-Ն)
6. Հարկային մարմինը հիմնադրամի կողմից ներկայացված տեղեկանքների պատճեններն ստանալուց հետո մեկամսյա ժամկետում դրանք տրամադրում է Հայաստանի Հանրապետության ֆինանսների նախարարությանը:
(6-րդ կետը խմբ. 11.04.19 N 378-Ն)
(հավելվածը խմբ., փոփ. 11.04.19 N 378-Ն)
