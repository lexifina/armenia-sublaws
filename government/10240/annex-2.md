# Հավելված N 2 ՀՀ կառավարության 2002 թվականի հոկտեմբերի 3-ի N 1788-Ն որոշման
Կ Ա Ռ ՈՒ Ց Վ Ա Ծ Ք ԵՐԵՎԱՆԻ ՔԱՂԱՔԱՊԵՏԱՐԱՆԻ ԱՇԽԱՏԱԿԱԶՄԻ I. Կառուցվածքային ստորաբաժանումներ 1. Վարչություններ Անշարժ գույքի կառավարման վարչություն Առողջապահության և սոցիալական ապահովության վարչություն Առևտրի և սպասարկումների վարչություն Բնապահպանության վարչություն Իրավաբանական վարչություն Կրթության վարչություն Ճարտարապետության և քաղաքաշինության վարչություն Քաղաքաշինության և հողի վերահսկողության վարչություն Մշակույթի, երիտասարդության հարցերի և սպորտի վարչություն Տրանսպորտի վարչություն Ֆինանսական և սոցիալ-տնտեսական զարգացման վարչություն Արտաքին կապերի վարչություն Տեղեկատվության և հասարակայնության հետ կապերի վարչություն Շինարարության և բարեկարգման վարչություն Կոմունալ տնտեսության վարչություն (1-ին կետը փոփ., լրաց. 26.05.06 N 792-Ն) 2. Քարտուղարություն 3. Բաժիններ Առաջին բաժին Կազմակերպատեսչական բաժին Երեխաների իրավունքների պաշտպանության բաժին Անձնակազմի կառավարման բաժին (3-րդ կետը լրաց. 27.10.05 N 1833-Ն, 22.02.07 N 195-Ն) (բաժինը լրաց. 27.10.05 N 1833-Ն, 22.02.07 N 195-Ն)
