# Հավելված N 1 ՀՀ կառավարության 2007 թվականի հունիսի 21-ի N 771-Ն որոշման
Կ Ա Ր Գ
ՕԶՈՆԱՅԻՆ ՇԵՐՏԸ ՔԱՅՔԱՅՈՂ ՆՅՈՒԹԵՐԻ ԱՌԱՔՄԱՆ` ՆԵՐՄՈՒԾՄԱՆ, ԿԱՄ ԱՐՏԱՀԱՆՄԱՆ, ԿԱՄ ՏԱՐԱՆՑԻԿ ՓՈԽԱԴՐՄԱՆ ԹՈՒՅԼՏՎՈՒԹՅԱՆ ՏՐԱՄԱԴՐՄԱՆ
1. Սույն կարգով կարգավորվում են օզոնային շերտը քայքայող նյութերի առաքման` ներմուծման կամ արտահանման կամ տարանցիկ փոխադրման թույլտվության (այսուհետ` առաքման թույլտվություն) տրամադրման հետ կապված հարաբերությունները:
1.1. Սույն կարգով սահմանված դրույթները չեն տարածվում Հայաստանի Հանրապետության կառավարության 2014 թվականի դեկտեմբերի 25-ի N 1524-Ն որոշմամբ սահմանված` արտաքին առևտրային նպատակով ապրանքների արտահանման և (կամ) ներմուծման լիցենզիաների տրամադրման գործընթացների վրա:
(1.1-ին կետը լրաց. 11.02.16 N 137-Ն)
2. Առաքման թույլտվություն ստանալու համար ներմուծողը կամ արտահանողը կամ տարանցիկ փոխադրողը (այսուհետ` հայտատու) Հայաստանի Հանրապետության շրջակա միջավայրի նախարարություն (այսուհետ` լիազոր պետական մարմին) է ներկայացնում առաքման թույլտվության տրամադրման հայտ` համաձայն ձևի:
(2-րդ կետը փոփ. 10.10.19 N 1442-Ն)
3. Լիազոր պետական մարմինը հայտն ստանալու օրվան հաջորդող 5 աշխատանքային օրվա ընթացքում`
1) եթե ներմուծման կամ արտահանման կամ տարանցիկ փոխադրման տվյալ գործարքը համապատասխանում է «Օզոնային շերտը քայքայող նյութերի մասին» Հայաստանի Հանրապետության օրենքի պահանջներին, ապա հայտատուին տրամադրում է առաքման թույլտվություն.
2) եթե ներմուծման կամ արտահանման կամ տարանցիկ փոխադրման տվյալ գործարքն ունի «Օզոնային շերտը քայքայող նյութերի մասին» Հայաստանի Հանրապետության օրենքով արգելված պայմաններ, կամ ներմուծողին տվյալ տարվա համար տրամադրված անհատական չափաքանակը (քվոտան) սպառվել է, ապա հայտի մերժման պատճառների մասին գրավոր տեղեկացնում է հայտատուին:
4. Առաքման թույլտվությունը կազմվում է 3 օրինակից: 2 օրինակը տրամադրվում է հայտատուին, իսկ մեկը պահվում լիազոր պետական մարմնում: Առաքումն իրականացնելիս` հայտատուն առաքման թույլտվության մեկ օրինակը հանձնում է մաքսային մարմին:
