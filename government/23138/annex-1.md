# Հավելված ՀՀ կառավարության 2006 թվականի փետրվարի 9-ի N 325-Ն որոշման
ՉԱՓԵՐ, ՎՃԱՐՄԱՆ ԿԱՐԳ ՈՒ ՊԱՅՄԱՆՆԵՐ ՓՐԿԱՐԱՐԱԿԱՆ ԾԱՌԱՅՈՂՆԵՐԻ ՊԱՐՏԱԴԻՐ ՊԵՏԱԿԱՆ ԱՊԱՀՈՎԱԳՐՈՒԹՅԱՆ ԵՎ ԱՊԱՀՈՎԱԳՐԱԿԱՆ ԳՈՒՄԱՐՆԵՐԻ (վերնագիրը խմբ. 30.07.20 N 1253-Ն)
1. Սույն կարգով սահմանվում են փրկարարական ծառայողների պարտադիր պետական ապահովագրության և ապահովագրական գումարների չափերը, վճարման կարգն ու պայմանները:
(1-ին կետը լրաց. 30.07.20 N 1253-Ն)
2. Փրկարարական ծառայողները ենթակա են պարտադիր պետական ապահովագրության` ծառայողական պարտականությունները կատարելու ժամանակ կամ ծառայության ընթացքում զոհվելու (մահանալու) դեպքերից:
(2-րդ կետը փոփ. 05.05.11 N 667-Ն, 28.06.12 N 795-Ն, 10.12.15 N 1446-Ն, խմբ. 30.07.20 N 1253-Ն)
2.1. Ծառայողական պարտականությունները կատարելու ժամանակ կամ ծառայության ընթացքում զոհված (մահացած) փրկարարական ծառայողների ընտանիքներին ապահովագրության գումարները վճարվում են հետևյալ չափերով՝
1) ծառայողական պարտականությունները կատարելու ժամանակ զոհված (մահացած) փրկարարական ծառայողի ընտանիքին` երկու միլիոն դրամի չափով.
2) ծառայության ընթացքում զոհված (մահացած) փրկարարական ծառայողի ընտանիքին` մեկ միլիոն դրամի չափով:
(2.1-ին կետը լրաց. 30.07.20 N 1253-Ն)
3. Ծառայողական պարտականությունները կատարելու ընթացքում, ինչպես նաև «Փրկարար ծառայության մասին» Հայաստանի Հանրապետության օրենքով սահմանված դեպքերում հաշմանդամ դարձած փրկարարական ծառայողները նույնպես ենթակա են պարտադիր պետական ապահովագրության` աշխատունակության կորստի չափին համապատասխան, որը սահմանվում է ընդհանուր գումարների նկատմամբ հետևյալ տոկոսային հարաբերությամբ`
ա. առաջին խմբի հաշմանդամներին` սույն կարգի 2.1-ին կետի 2-րդ ենթակետում նախատեսված գումարի 50 տոկոսի չափով,
բ. երկրորդ խմբի հաշմանդամներին` սույն կարգի 2.1-ին կետի 2-րդ ենթակետում նախատեսված գումարի 40 տոկոսի չափով,
գ. երրորդ խմբի հաշմանդամներին` սույն կարգի 2.1-ին կետի 2-րդ ենթակետում նախատեսված գումարի 30 տոկոսի չափով:
Միանվագ պարտադիր պետական ապահովագրական գումար չի վճարվում, եթե փրկարարական ծառայողի զոհվելը (մահանալը) կամ հաշմանդամ դառնալը նրա կողմից կատարված կանխամտածված օրինազանցության հետևանք է:
(3-րդ կետը փոփ. 25.09.14 N 1039-Ն, խմբ. 10.12.15 N 1446-Ն, փոփ. 30.07.20 N 1253-Ն)
4. Աշխատանքի և սոցիալական հարցերի նախարարությունը փրկարար ծառայության հանրապետական գործադիր մարմնի կողմից ներկայացված ցուցակների հիման վրա միանվագ պետական պարտադիր ապահովագրական գումարներ է հատկացնում փրկարարական ծառայողներին:
(4-րդ կետը խմբ. 23.07.15 N 819-Ն, փոփ. 05.12.19 N 1719-Ն)
5. Աշխատանքի և սոցիալական հարցերի նախարարության կողմից հատկացված միանվագ պետական պարտադիր ապահովագրական գումարները վճարվում են փրկարար ծառայության հանրապետական գործադիր մարմնի կողմից կազմված ու Աշխատանքի և սոցիալական հարցերի նախարարություն ներկայացված զոհված (մահացած) կամ հաշմանդամություն ունեցող փրկարարական ծառայողների ցուցակի համաձայն: Հաշմանդամ դարձած փրկարարական ծառայողների ցուցակում նշվում են փրկարարական ծառայողի հաշմանդամության վերաբերյալ բժշկասոցիալական փորձաքննական հանձնաժողովի կողմից տրված տեղեկանքի ու ստացած վնասվածքի կամ խեղման կամ ձեռք բերած հիվանդության պատճառական կապի մասին համապատասխան պետական մարմնի ռազմաբժշկական հանձնաժողովի փորձաքննական ակտի տվյալները, հաշմանդամ դարձած փրկարարական ծառայողին վճարման ենթակա գումարի չափը, գումարն ստացողի` հաշմանդամի կամ նրա կողմից լիազորված անձի անունը, ազգանունը, հայրանունը, անձնագրի համարը, բնակության և էլեկտրոնային հասցեն (առկայության դեպքում), գումարն ստացողի բանկային ռեկվիզիտները, իսկ դրա բացակայության դեպքում` Հայաստանի Հանրապետության այն տարածաշրջանը, որտեղ գործող բանկերից շահառուն նախընտրում է ստանալ գումարը, իսկ զոհված (մահացած) փրկարարական ծառայողների ցուցակում նշվում է յուրաքանչյուր զոհված փրկարարական ծառայողի մասով` փոխհատուցման ենթակա գումարի չափը, զոհված (մահացած) փրկարարական ծառայողների անձնական տվյալները` անունը, ազգանունը, հայրանունը, մահվան տարեթիվը, մահվան վկայականի համարը, զոհված (մահացած) փրկարարական ծառայողների ընտանիքի` փոխհատուցման գումար ստացող անդամի անունը, ազգանունը, հայրանունը, անձնագրի համարը, բնակության և էլեկտրոնային հասցեն (առկայության դեպքում), գումարն ստացողի բանկային ռեկվիզիտները, իսկ դրա բացակայության դեպքում` Հայաստանի Հանրապետության այն տարածաշրջանը, որտեղ գործող բանկերից շահառուն նախընտրում է ստանալ գումարը: Աշխատանքի և սոցիալական հարցերի նախարարությունը գործող ընթացակարգերի պահանջներին համապատասխան՝ սահմանված կարգով վճարման հիմք հանդիսացող փաստաթղթերն ստանալուց հետո գումարը հինգ աշխատանքային օրվա ընթացքում վճարում է շահառուին և դրա մասին երկու աշխատանքային օրվա ընթացքում՝ պատվիրված նամակով իրազեկում է վերջինիս:
(5-րդ կետը խմբ. 23.07.15 N 819-Ն, փոփ. 05.12.19 N 1719-Ն, 30.07.20 N 1253-Ն)
(հավելվածը փոփ. 05.05.11 N 667-Ն, 28.06.12 N 795-Ն, 25.09.14 N 1039-Ն, խմբ. 23.07.15 N 819-Ն, փոփ., խմբ. 10.12.15 N 1446-Ն, փոփ. 05.12.19 N 1719-Ն, լրաց., խմբ., փոփ. 30.07.20 N 1253-Ն)
