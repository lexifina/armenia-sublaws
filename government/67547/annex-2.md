# Հավելված N 2 ՀՀ կառավարության 2011 թվականի ապրիլի 28-ի N 461-Ն որոշման
Կ Ա Ռ ՈՒ Ց Վ Ա Ծ Ք
Հայաստանի Հանրապետության գյուղատնտեսության նախարարության «ԳՅՈՒՂԱԿԱՆ ՏԱՐԱԾՔՆԵՐԻ ՏՆՏԵՍԱԿԱՆ ԶԱՐԳԱՑՄԱՆ ԾՐԱԳՐԵՐԻ ԻՐԱԿԱՆԱՑՄԱՆ ԳՐԱՍԵՆՅԱԿ» ՊԵՏԱԿԱՆ ՀԻՄՆԱՐԿԻ
(վերնագիրը փոփ. 09.08.18 N 879-Ն, 15.02.19 N 138-Ն)
Կառուցվածքային ստորաբաժանումներ
1. Ֆինանսահաշվային բաժին
2. Շինարարության վերահսկման բաժին
3. Մոնիթորինգի և գնահատման, ծրագրերի համակարգման, զարգացման բաժին
4. Գնումների բաժին
5. Գյուղական ֆինանսավորման բաժին
6. Գործերի կառավարման բաժին
(հավելվածը խմբ. 15.12.11 N 1783-Ն, 13.09.13 N 1007-Ն, փոփ. 09.08.18 N 879-Ն, 15.02.19 N 138-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար | Դ. Սարգսյան
