# Հավելված N 1 ՀՀ կառավարության 2005 թվականի հունիսի 23-ի N 981-Ն որոշման
Կ Ա Ր Գ
ՄՇԱԿՈՒԹԱՅԻՆ ԱՐԺԵՔՆԵՐԻ ԱՐՏԱՀԱՆՄԱՆ ԿԱՄ ԺԱՄԱՆԱԿԱՎՈՐ ԱՐՏԱՀԱՆՄԱՆ ԻՐԱՎՈՒՆՔԻ վկայագրի (եզրակացությԱն (թույլատրող փաստաթղթԻ) ՏՐՄԱՆ (վերնագիրը փոփ. 12.11.15 N 1327-Ն)
1. Սույն կարգով սահմանվում է մշակութային արժեքների արտահանման կամ ժամանակավոր արտահանման իրավունքի վկայագրեր (եզրակացություններ (թույլատրող փաստաթղթեր) տալու կարգը:
(1-ին կետը փոփ. 12.11.15 N 1327-Ն)
2. Մշակութային արժեքների արտահանման եզրակացություն (թույլատրող փաստաթուղթ) ստանալու համար կազմակերպությունը կամ ֆիզիկական անձը (այսուհետ` հայտատու) հայտը և ուղեկցող փաստաթղթերը կարող է ներկայացնել առձեռն, փոստով, ինչպես նաև էլեկտրոնային եղանակով՝ Հայաստանի Հանրապետության արտաքին առևտրի ազգային մեկ պատուհան էլեկտրոնային հարթակում (www.trade.gov.am) հասանելի «Թույլատվական փաստաթղթեր» (www.sw.gov.am) համակարգի միջոցով ենթահայտ լրացնելու միջոցով՝ Հայաստանի Հանրապետության կառավարության կողմից սահմանված կարգով նույնականացում անցնելով՝ նույնականացման քարտի միջոցով՝ Հայաստանի Հանրապետության կրթության, գիտության, մշակույթի և սպորտի նախարարություն (այսուհետ՝ լիազորված պետական մարմին):
(2-րդ կետը փոփ. 09.12.10 N 1631-Ն, փոփ., լրաց. 12.11.15 N 1327-Ն, փոփ. 13.08.20 N 1357-Ն, խմբ. 21.10.21 N 1712-Ն)
3. Հայտի գրանցման և պահպանման ընթացակարգը սահմանում է լիազորված պետական մարմինը:
4. Հայտը պետք է պարունակի հետևյալ տեղեկատվությունը`
ա) հայտատուի լրիվ անվանումը, գտնվելու վայրը և պետական գրանցման համարը (ֆիզիկական անձանց համար՝ անունը, ազգանունը, բնակության վայրի հասցեն, հեռախոսահամարը, անձնագրի սերիան և համարը).
բ) մշակութային արժեքի անվանումը, քանակը, արտահանման նպատակը, արտահանման երկիրը, հայտարարություն սեփականության մասին.
գ) հայտին կից ներկայացվող փաստաթղթերի ցանկը:
(4-րդ կետը փոփ. 12.11.15 N 1327-Ն)
5. Հայտատուն հայտին կից ներկայացնում է՝
ա) արտահանման համար հայտագրված մշակութային արժեքի փորձագիտական եզրակացության պատճենը` բնօրինակի ներկայացմամբ, որը, գործընթացն ավարտելուց հետո, վերադարձվում է հայտատուին.
բ) նույն մշակութային արժեքի 2 գունավոր լուսանկար` 10 x 15 չափսի, տարանցիկ փոխադրման դեպքում՝ 3 օրինակ.
գ) պետական տուրքի վճարման անդորրագրի պատճենը կամ պետական վճարումների էլեկտրոնային համակարգի կողմից գեներացված անդորրագիրը:
(5-րդ կետը լրաց. 15.09.11 N 1471-Ն, խմբ. 12.11.15 N 1327-Ն, լրաց. 21.10.21 N 1712-Ն)
5.1. Լիազորված պետական մարմնի համապատասխան ստորաբաժանման բաժինը, հայտատուի հայտին կից ներկայացված փաստաթղթերի հիման վրա, մեկ աշխատանքային օրվա ընթացքում իրականացնում է հայտագրված առարկայի և հափշտակված, կորած, գողացված մշակութային առարկաների շտեմարանի տվյալների համեմատական ստուգում: Նշված շտեմարանում դրանց առկայության դեպքում դրա մասին գրավոր տեղեկացվում է համապատասխան իրավապահ մարմիններին, իսկ բացակայության դեպքում կազմվում է դրանք գողացված չլինելու մասին տեղեկանք:
(5.1-րդ կետը լրաց. 09.12.10 N 1631-Ն, փոփ. 13.08.20 N 1357-Ն)
5.2. Հայտատուի հայտին կից ներկայացված փաստաթղթերի` մշակութային արժեքը գողացված չլինելու մասին տեղեկանքի հիման վրա մեկ աշխատանքային օրվա ընթացքում քննարկվում և նախապատրաստվում է առարկան մշակութային արժեք համարելու և արտահանման իրավունքի վկայագրով (եզրակացությամբ (թույլատրող փաստաթղթով) կամ առանց արտահանման կամ ժամանակավոր արտահանման իրավունքի վկայագրի (եզրակացության (թույլատրող փաստաթղթի) արտահանելու վերաբերյալ որոշումը, որը ներկայացվում է լիազորված պետական մարմնի ղեկավարի համապատասխան տեղակալին` հաստատման:
(5.2-րդ կետը լրաց. 09.12.10 N 1631-Ն, փոփ. 12.11.15 N 1327-Ն, 13.08.20 N 1357-Ն)
5.3. Լիազորված պետական մարմնի համապատասխան ստորաբաժանման բաժնի պետի կողմից առարկան առանց արտահանման իրավունքի վկայագրի (եզրակացության (թույլատրող փաստաթղթի) արտահանելու մասին որոշման դեպքում` օրենքով սահմանված կարգով մեկ աշխատանքային օրվա ընթացքում նախապատրաստվում և տրվում է առարկան արտահանելու համար համապատասխան թույլտվություն, իսկ արտահանման իրավունքի վկայագրով (եզրակացությամբ (թույլատրող փաստաթղթով) արտահանվող մշակութային արժեք լինելու մասին որոշման դեպքում երեք աշխատանքային օրվա ընթացքում նախապատրաստվում և տրվում է մշակութային արժեքի արտահանման կամ ժամանակավոր արտահանման իրավունքի վկայագիր (եզրակացություն (թույլատրող փաստաթուղթ): Հայտատուի ցանկության դեպքում եզրակացությունը (թույլատրող փաստաթուղթը) կարող է տրամադրվել ռուսերենով:
(5.3-րդ կետը լրաց. 09.12.10 N 1631-Ն, փոփ., լրաց. 12.11.15 N 1327-Ն, փոփ. 13.08.20 N 1357-Ն)
6. Հայտատուն պետական սեփականություն համարվող պետական կամ այլ պահոցներում մշտապես պահպանվող մշակութային արժեքների ժամանակավոր արտահանման իրավունքի վկայագիր (եզրակացություն (թույլատրող փաստաթուղթ) ստանալու համար հայտին կցում է «Մշակութային արժեքների արտահանման և ներմուծման մասին» Հայաստանի Հանրապետության օրենքի 13-րդ հոդվածով պահանջվող փաստաթղթերը:
(6-րդ կետը փոփ. 12.11.15 N 1327-Ն)
7. Պետական սեփականություն համարվող` պետական կամ այլ պահոցներում մշտապես պահպանվող, պետական սեփականություն չհամարվող` պահպանական ցուցակում գրանցված կամ գրանցման ենթակա մշակութային արժեքների, ինչպես նաև մշակութային արժեքների պահպանական ցուցակում չգրանցված կամ գրանցման ոչ ենթակա մշակութային արժեքների ժամանակավոր արտահանումն իրականացվում է մշակութային արժեքների ժամանակավոր արտահանման իրավունքի վկայագրով (եզրակացությամբ (թույլատրող փաստաթղթով)` Հայաստանի Հանրապետության մաքսային օրենսդրությամբ սահմանված կարգով:
(7-րդ կետը փոփ. 12.11.15 N 1327-Ն)
8. Լիազորված պետական մարմնի համապատասխան ստորաբաժանման բաժինը հաշվառում է պետական սեփականություն համարվող` պետական կամ այլ պահոցներում մշտապես պահպանվող, պետական սեփականություն չհամարվող` պահպանական ցուցակում գրանցված կամ գրանցման ենթակա մշակութային արժեքները, ինչպես նաև միջոցներ ձեռնարկում սահմանված ժամկետում չվերադարձված մշակութային արժեքների հետբերման նպատակով:
(8-րդ կետը փոփ. 13.08.20 N 1357-Ն)
9. Հայտատուի ցանկությամբ` նվագարանի փորձագիտական եզրակացության բնօրինակի հիման վրա, լիազոր պետական մարմինը տալիս է «Նվագարանի վկայական»` լուսանկարով, որը վավերական է, եթե լուսանկարի վրա առկա է լիազորված պետական մարմնի ստորաբաժանման բաժնի կնիքը:
Նվագարանի վկայականի ձևը և տալու կարգը սահմանում է լիազորված պետական մարմինը:
Նվագարանի վկայականը տրամադրվում է հայտն ընդունվելուց հետո հինգ աշխատանքային օրվա ընթացքում:
(9-րդ կետը լրաց. 09.12.10 N 1631-Ն, փոփ. 13.08.20 N 1357-Ն)
10. Մշակութային արժեքների արտահանման կամ ժամանակավոր արտահանման իրավունքի վկայագիր (եզրակացություն (թույլատրող փաստաթուղթ) տալու համար գանձվում է պետական տուրք` «Պետական տուրքի մասին» Հայաստանի Հանրապետության օրենքով սահմանված կարգով և չափով:
(10-րդ կետը փոփ. 12.11.15 N 1327-Ն)
11. Հայտատուն ներկայացնում է պետական տուրքի վճարման անդորրագիրը, պատճենը կամ պետական վճարումների էլեկտրոնային համակարգի կողմից գեներացված անդորրագիրը և ստանում մշակութային արժեքների արտահանման կամ ժամանակավոր արտահանման իրավունքի վկայագիրը (եզրակացությունը (թույլատրող փաստաթուղթը), մշակութային արժեքի փորձագիտական եզրակացության բնօրինակը և մշակութային արժեքի լուսանկարը՝ շրջերեսին մշակութային արժեքի տվյալների (արժեքի անվանումը կամ վերնագիրը, հեղինակը, ստեղծման ժամանակը, ստեղծման վայրը, նյութը, քանակը (բաղկացուցիչ մասերը), չափերը (քաշը), վիճակը, պահոցից արտահանվող մշակութային արժեքների դեպքում` ծածկագիրը) վավերացմամբ:
(11-րդ կետը փոփ., լրաց. 12.11.15 N 1327-Ն)
12. Վկայագիրը (եզրակացությունը (թույլատրող փաստաթուղթը) վավերական է, եթե դրա վրա կա լիազորված պետական մարմնի ստորաբաժանման բաժնի կնիքը և ստորաբաժանման բաժնի պետի կամ նրան փոխարինող մասնագետի ստորագրությունը:
(12-րդ կետը փոփ. 12.11.15 N 1327-Ն, 13.08.20 N 1357-Ն)
13. Վկայագրին (եզրակացությանը (թույլատրող փաստաթղթին) կցվող լուսանկարը վավերական է, եթե դրա վրա կա «Թույլատրվում է արտահանել» կամ «Թույլատրվում է ժամանակավոր արտահանել» դրոշմակնիքը՝ լիազորված պետական մարմնի ստորաբաժանման բաժնի պետի կամ նրան փոխարինող մասնագետի ստորագրությամբ:
(13-րդ կետը փոփ. 12.11.15 N 1327-Ն, 13.08.20 N 1357-Ն)
14. Մեկ վկայագրով (եզրակացությամբ (թույլատրող փաստաթղթով) կարելի է արտահանել մեկ և մեկից ավելի տարբեր մշակութային արժեքներ` համաձայն հայտի:
(14-րդ կետը փոփ. 12.11.15 N 1327-Ն)
15. Մեկից ավելի մշակութային արժեքների արտահանման կամ ժամանակավոր արտահանման դեպքում վկայագրին (եզրակացությանը (թույլատրող փաստաթղթին) կցվում է մշակութային արժեքների ցուցակ՝ սույն կարգի 11-րդ կետում նշված մշակութային արժեքի տվյալներով: Ցուցակը վավերական է, եթե դրա վրա կա լիազորված պետական մարմնի ստորաբաժանման բաժնի պետի կամ նրան փոխարինող մասնագետի ստորագրությունը և «Թույլատրվում է արտահանել» կամ «Թույլատրվում է ժամանակավոր արտահանել» դրոշմակնիքը:
(15-րդ կետը փոփ. 12.11.15 N 1327-Ն, 13.08.20 N 1357-Ն)
16. Հայտատուն վկայագրի (եզրակացության (թույլատրող փաստաթղթի) պատճենի վրա ստորագրում է՝ փաստելով վկայագիր (եզրակացություն (թույլատրող փաստաթուղթ) ստանալը:
(16-րդ կետը փոփ. 12.11.15 N 1327-Ն)
17. Մշակութային արժեքների արտահանման իրավունքի կամ ժամանակավոր արտահանման իրավունքի վկայագիրը (եզրակացությունը (թույլատրող փաստաթուղթը) ենթակա է մեկանգամյա օգտագործման:
Մշակութային արժեքների արտահանման դեպքում արտահանման իրավունքի վկայագիրն (եզրակացությունը (թույլատրող փաստաթուղթը) ուժի մեջ է մեկ տարի:
Մշակութային արժեքի ժամանակավոր արտահանման դեպքում վկայագիրն (եզրակացությունը (թույլատրող փաստաթուղթը) ուժի մեջ է հայտատուի հայտում նշված ժամանակահատվածում, որը չի կարող գերազանցել Հայաստանի Հանրապետության մաքսային օրենսգրքով սահմանված առավելագույն ժամկետը:
(17-րդ կետը փոփ. 12.11.15 N 1327-Ն)
18. Մշակութային արժեքների արտահանման կամ ժամանակավոր արտահանման իրավունքի վկայագրի (եզրակացության (թույլատրող փաստաթղթի) կրկնօրինակն ստանալու համար հայտատուն դիմում է լիազորված պետական մարմին:
(18-րդ կետը փոփ. 12.11.15 N 1327-Ն)
18.1. Մշակութային արժեքների արտահանման կամ ժամանակավոր արտահանման իրավունքի վկայագրի (եզրակացության (թույլատրող փաստաթղթի) կրկնօրինակը տրամադրվում է հայտն ընդունվելուց հետո երկու աշխատանքային օրվա ընթացքում:
(18.1-ին կետը լրաց. 09.12.10 N 1631-Ն, փոփ. 12.11.15 N 1327-Ն)
18.2. Նվագարանի վկայականի կրկնօրինակը տրամադրվում է հայտն ընդունվելուց հետո երեք աշխատանքային օրվա ընթացքում:
(18.2-րդ կետը լրաց. 09.12.10 N 1631-Ն)
19. Հայտի ընդունումը կատարվում է սույն կարգի 4-րդ և 5-րդ կետերի պահանջների համաձայն՝ գործի վրա ավելացնելով հայտատուի հիմնական գործի համարը:
20. Վկայագրի (եզրակացության (թույլատրող փաստաթղթի) կրկնօրինակն ստանալու համար հայտատուն վճարում է «Պետական տուրքի մասին» Հայաստանի Հանրապետության օրենքով սահմանված պետական տուրքը: Վկայագրի (եզրակացության (թույլատրող փաստաթղթի) վերին ձախ անկյունում գրվում է՝ «Կրկնօրինակ»:
(20-րդ կետը փոփ. 12.11.15 N 1327-Ն)
(հավելվածը փոփ., լրաց. 09.12.10 N 1631-Ն, լրաց. 15.09.11 N 1471-Ն, փոփ., լրաց., խմբ. 12.11.15 N 1327-Ն, փոփ. 13.08.20 N 1357-Ն, խմբ., լրաց. 21.10.21 N 1712-Ն)
