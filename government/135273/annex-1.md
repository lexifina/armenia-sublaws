# Հավելված ՀՀ կառավարության 2019 թվականի հոկտեմբերի 10-ի N 1381-Ն որոշման
Կ Ա Ր Գ
ԸՆՏԱՆԻՔՈՒՄ ԲՌՆՈՒԹՅԱՆ ԴԵՊՔԵՐԻ ԿԵՆՏՐՈՆԱՑՎԱԾ ՀԱՇՎԱՌՄԱՆ
I. ԸՆԴՀԱՆՈՒՐ ԴՐՈՒՅԹՆԵՐ
1. Սույն կարգով կարգավորվում են սոցիալական հարցերի ոլորտում լիազոր հանրապետական գործադիր մարմնի (այսուհետ՝ Լիազոր մարմին) կողմից ընտանիքում բռնության դեպքերի կենտրոնացված հաշվառման հետ կապված հարաբերությունները:
2. Ընտանիքում բռնության դեպքերի կենտրոնացված հաշվառման նպատակը՝ ընտանիքում բռնության դեպքերի տարածվածության և ընտանիքում բռնությանը նպաստող գործոնների բացահայտման, ընտանիքում բռնության կանխարգելման, ընտանիքում բռնություն գործադրած և ընտանիքում բռնության ենթարկված անձանց վերաբերյալ տվյալների ամփոփման ապահովումն է:
(2-րդ կետը լրաց., փոփ. 18.01.24 N 70-Ն)
3. Տվյալների գաղտնիությունն ապահովելու նպատակով տեղեկատվություն տրամադրող մարմինը կամ կազմակերպությունը Լիազոր մարմնին անձնական տվյալներ պարունակող տեղեկատվական փաթեթը ներկայացնում է էլեկտրոնային՝ տեղեկատվական համապատասխան համակարգում ներբեռնած տվյալների ապանձնավորում ապահովելով՝ լրացնելով սույն հավելվածի Թերթիկ N 1-ը:
(3-րդ կետը լրաց., փոփ. 18.01.24 N 70-Ն)
II. ԸՆՏԱՆԻՔՈՒՄ ԲՌՆՈՒԹՅԱՆ ԴԵՊՔԵՐԻ ԿԵՆՏՐՈՆԱՑՎԱԾ ՀԱՇՎԱՌՈՒՄԸ ԵՎ ՏՎՅԱԼՆԵՐԻ ՏՐԱՄԱԴՐՈՒՄԸ
4. Ընտանիքում բռնության դեպքերի կենտրոնացված հաշվառումն իրականացնում է Լիազոր մարմինը՝ Հայաստանի Հանրապետության ներքին գործերի նախարարության ոստիկանության (այսուհետ՝ ոստիկանություն), Հայաստանի Հանրապետության քննչական կոմիտեի (այսուհետ՝ քննչական կոմիտե), Հայաստանի Հանրապետության դատախազության (այսուհետ՝ դատախազություն), Հայաստանի Հանրապետության դատական դեպարտամենտի (այսուհետ՝ դատական դեպարտամենտ), օրենքով սահմանված ապաստարանների (այսուհետ՝ ապաստարաններ), ինչպես նաև վերջիններիս կողմից չգրանցված՝ օրենքով սահմանված աջակցության կենտրոնների (այսուհետ՝ աջակցության կենտրոն), խնամակալության և հոգաբարձության մարմինների, Հայաստանի Հանրապետության առողջապահության նախարարության, Հայաստանի Հանրապետության կրթության, գիտության, մշակույթի և սպորտի նախարարության կողմից տրամադրված տվյալների հիման վրա:
(4-րդ կետը փոփ. 30.06.22 N 996-Ն, լրաց. 18.01.24 N 70-Ն)
5. Լիազոր մարմինը տեղեկատվությունը ստանում է տեղեկատվական համակարգի միջոցով, որի անխափան գործունեության համար պատասխանատու է «Նորք» սոցիալական ծառայությունների տեխնոլոգիական և իրազեկման կենտրոն» հիմնադրամը: Տեղեկատվությունը հավաքագրվում է հանրային ծառայությունների համարանիշով կամ անձը հաստատող փաստաթղթի տվյալներով և կարող է ամփոփվել Թերթիկ N 1-ում նախատեսված ցանկացած դաշտի՝ հատկանիշի կամ տեղեկատվության, կամ դրանց համակցության հիման վրա: Տեղեկատվության ամփոփման և հրապարակման համար պատասխանատու է Լիազոր մարմինը:
(5-րդ կետը խմբ. 18.01.24 N 70-Ն)
6. Թերթիկ N 1-ը լրացվում է ընտանիքում բռնության յուրաքանչյուր դեպքի և դրա ընթացքի վերաբերյալ: Նույն անձանց միջև ընտանիքում բռնության նոր դեպք արձանագրելու դեպքում սույն հավելվածի Թերթիկ N 1-ը լրացվում է կրկին, և այդ թերթիկները համակարգի միջոցով ֆիքսվելու են որպես փոխկապակցված՝ հանրային ծառայությունների համարանիշերով կամ անձը հաստատող փաստաթղթի տվյալներով:
(6-րդ կետը փոփ. 30.06.22 N 996-Ն, խմբ. 18.01.24 N 70-Ն)
7. Սույն կարգի 4-րդ կետում նշված մարմինները՝ յուրաքանչյուրն իր իրավասության շրջանակներում, լրացնում են էլեկտրոնային հարթակում տեղադրված Թերթիկ N 1-ը: Ոստիկանությունն առաջնային լրացնում է Թերթիկ N 1-ի 1-20-րդ և 24-26-րդ դաշտերը, իսկ հետագայում՝ ըստ տեղեկատվության հասանելիության կամ պարզման՝ նաև 21-23-րդ և 27-34-րդ դաշտերը, քննչական կոմիտեն լրացնում է Թերթիկ N 1-ի 35-րդ, 36-րդ, 38-56-րդ դաշտերը, դատախազությունը լրացնում է Թերթիկ N 1-ի 37-րդ և 37.1-ին դաշտերը, դատական դեպարտամենտը լրացնում է Թերթիկ N 1-ի 4-րդ, 28-րդ, 31-րդ և 57-81-րդ դաշտերը, իսկ աջակցության կենտրոնները և ապաստարանները՝ Թերթիկ N 1-ի 1-19-րդ, 21-23-րդ և 82-83-րդ դաշտերը:
(7-րդ կետը փոփ., խմբ. 30.06.22 N 996-Ն, խմբ. 18.01.24 N 70-Ն)
7.1. Սույն կարգի 7-րդ կետում նշված մարմինների կողմից չգրանցած տեղեկատվությունն անհրաժեշտության դեպքում ներկայացվում է աջակցության կենտրոնների, խնամակալության և հոգաբարձության մարմինների, Հայաստանի Հանրապետության առողջապահության նախարարության և Հայաստանի Հանրապետության կրթության, գիտության, մշակույթի և սպորտի նախարարության կողմից: Աջակցության կենտրոնները լրացնում են Թերթիկ N 1-ի 21-23-րդ, 82-րդ և 83-րդ դաշտերը, խնամակալության և հոգաբարձության մարմինները՝ Թերթիկ N 1-ի 7-9-րդ դաշտերը, Հայաստանի Հանրապետության առողջապահության նախարարությունը՝ Թերթիկ N 1-ի 20-րդ դաշտը և Հայաստանի Հանրապետության կրթության, գիտության, մշակույթի և սպորտի նախարարությունը՝ Թերթիկ N 1-ի 20-րդ դաշտը:
(7.1-ին կետը լրաց. 18.01.24 N 70-Ն)
7.2. Սույն կարգի 7-րդ և 7.1-ին կետերում նշված յուրաքանչյուր մարմնի համար տեսանելի են Թերթիկ N 1-ի՝ իր կողմից լրացվող դաշտերը և տեսանելի չեն այլ մարմինների կողմից լրացվող դաշտերը: Յուրաքանչյուր մարմնում, բացի Թերթիկ N 1-ը լրացնող պատասխանատու անձից, մարմնի իրավասությանը վերաբերող դաշտերը տեսանելի են նրա վերադասին, ով վրիպակների, անճշտությունների կամ այլ բացթողումների հայտնաբերման դեպքում կարող է ճշտումներ կամ ուղղումներ իրականացնել այդ դաշտերում: Լիազոր մարմնի ոլորտը համակարգող տեղակալի, համապատասխան վարչության և բաժնի պետերի և բաժնի ծառայողների համար տեսանելի են Թերթիկ N 1-ի բոլոր տվյալները:
(7.2-րդ կետը լրաց. 18.01.24 N 70-Ն)

11. Լիազոր մարմինը սույն կարգի 7-րդ կետով ստացված տեղեկատվության հիման վրա իրականացնում է ընտանիքում բռնության դեպքերի կենտրոնացված հաշվառում և դրանց ընթացքի վերաբերյալ ամփոփ վիճակագրության վարում:

Լիազոր մարմինն առնվազն յուրաքանչյուր կիսամյակ տեղեկատվությունն ամփոփելուց հետո՝ իր պաշտոնական կայքում հրապարակում է կիսամյակային և տարեկան վիճակագրական հաշվետվություններն ընտանիքում բռնության դեպքերի վերաբերյալ: Լիազոր մարմինը կարող է հրապարակել ընթացիկ հաշվետվություններ՝ ցանկացած ժամանակահատվածի համար և ցանկացած ծավալով:
