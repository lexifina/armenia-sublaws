# Հավելված ՀՀ կառավարության 2019 թվականի հոկտեմբերի 10-ի N 1381-Ն որոշման
Կ Ա Ր Գ
ԸՆՏԱՆԻՔՈՒՄ ԲՌՆՈՒԹՅԱՆ ԴԵՊՔԵՐԻ ԿԵՆՏՐՈՆԱՑՎԱԾ ՀԱՇՎԱՌՄԱՆ
I. ԸՆԴՀԱՆՈՒՐ ԴՐՈՒՅԹՆԵՐ
1. Սույն կարգով կարգավորվում են սոցիալական հարցերի ոլորտում լիազոր հանրապետական գործադիր մարմնի (այսուհետ՝ Լիազոր մարմին) կողմից ընտանիքում բռնության դեպքերի կենտրոնացված հաշվառման հետ կապված հարաբերությունները:
2. Ընտանիքում բռնության դեպքերի կենտրոնացված հաշվառման նպատակը՝ ընտանիքում բռնության դեպքերի տարածվածության և բռնությանը նպաստող գործոնների բացահայտման, ընտանիքում բռնության կանխարգելման, բռնություն գործադրած և բռնության ենթարկված անձանց վերաբերյալ տվյալների ամփոփման միջոցով պաշտպանության և աջակցության տրամադրման ապահովումն է:
3. Տվյալների գաղտնիությունն ապահովելու նպատակով տեղեկատվություն տրամադրող մարմինը Լիազոր մարմնին անձնական տվյալներ պարունակող տեղեկատվական փաթեթը ներկայացնում է թղթային՝ «հրապարակման ոչ ենթակա» դրոշմագրով, որը նշվում է փակ ծրարի և Թերթիկ N 1-ի, Թերթիկ N 2-ի և Թերթիկ N 3-ի վրա՝ վերևի աջ անկյունում:
II. ԸՆՏԱՆԻՔՈՒՄ ԲՌՆՈՒԹՅԱՆ ԴԵՊՔԵՐԻ ԿԵՆՏՐՈՆԱՑՎԱԾ ՀԱՇՎԱՌՈՒՄԸ ԵՎ ՏՎՅԱԼՆԵՐԻ ՏՐԱՄԱԴՐՈՒՄԸ
4. Ընտանիքում բռնության դեպքերի կենտրոնացված հաշվառումն իրականացնում է Լիազոր մարմինը՝ Հայաստանի Հանրապետության ոստիկանության (այսուհետ՝ ոստիկանություն), Հայաստանի Հանրապետության քննչական կոմիտեի (այսուհետ՝ քննչական կոմիտե), Հայաստանի Հանրապետության դատախազության, Հայաստանի Հանրապետության դատական դեպարտամենտի (այսուհետ՝ դատական դեպարտամենտ), ինչպես նաև վերջիններիս կողմից չգրանցված՝ օրենքով սահմանված աջակցության կենտրոնների (այսուհետ՝ աջակցության կենտրոն), խնամակալության և հոգաբարձության մարմինների, Հայաստանի Հանրապետության առողջապահության նախարարության, Հայաստանի Հանրապետության կրթության, գիտության, մշակույթի և սպորտի նախարարության կողմից տրամադրված տվյալների հիման վրա:
(4-րդ կետը փոփ. 30.06.22 N 996-Ն)
5. Տեղեկատվության հավաքագրումը սկսվում է սույն որոշումն ուժի մեջ մտնելուց անմիջապես հետո և առաջին անգամ տրամադրվում է տեղեկատվության հավաքագրման մեկնարկից վեց ամիս անց: Դրանից հետո տեղեկատվությունը տրամադրվում է առնվազն յուրաքանչյուր կիսամյակ՝ մինչև հաշվետու կիսամյակին հաջորդող ամսվա 30-ը: Լիազոր մարմինը տեղեկատվությունը ստանալուց հետո մեկ ամսվա ընթացքում ամփոփում է այն և հրապարակում:
6. Թերթիկ N 1-ը, Թերթիկ N 2-ը և Թերթիկ N 3-ը լրացվում են յուրաքանչյուր դեպքի և դրա ընթացքի վերաբերյալ: Նույն անձանց միջև նոր դեպք արձանագրելու դեպքում հավելվածի Թերթիկ N 1-ը և Թերթիկ N 3-ը լրացվում են միայն ավելացված տվյալների մասով Թերթիկ N 1-ի դեպքում սկսած 8-րդ կետից՝ քրեական վարույթի համարի դեպքում՝ դեպքի գրանցման օրվա և համարի նշումով, իսկ Թերթիկ N 3-ի դեպքում՝ սկսած 6-րդ կետից: Թերթիկ N 2-ը լրացվում է ամբողջությամբ:
Թերթիկ N 1-ը և Թերթիկ N 2-ը սույն հավելվածի 7-րդ և 8-րդ կետերով սահմանված մարմինները լրացնում են յուրաքանչյուրն ըստ իր իրավասության:
(6-րդ կետը փոփ. 30.06.22 N 996-Ն)
7. Ոստիկանությունը, դատախազությունը, քննչական կոմիտեն ընտանիքում բռնության դեպքերի վերաբերյալ տեղեկատվությունը տրամադրում են Լիազոր մարմնին՝ համաձայն սույն հավելվածի Թերթիկ N 1-ի:
Ոստիկանությունը տրամադրում է ընտանիքում բռնության այն դեպքերի վերաբերյալ տվյալները, որոնց կապակցությամբ կիրառել է պաշտպանության միջոցներ:
Դատախազությունը տրամադրում է ընտանիքում բռնության հատկանիշներ պարունակող հանցանքներով դատախազի կողմից հանրային կարգով քրեական հետապնդում իրականացնելու վերաբերյալ տվյալները:
Քննչական կոմիտեն տրամադրում է իր կողմից իրականացվող քրեական վարույթով ընտանիքում բռնության դեպքերի և դրանց ընթացքի վերաբերյալ տվյալները:
(7-րդ կետը փոփ., խմբ. 30.06.22 N 996-Ն)
8. Դատական դեպարտամենտն ընտանիքում բռնության դեպքերով (վարույթներով) դատարանների կողմից կայացված և օրինական ուժի մեջ մտած պաշտպանական որոշումների և քրեական վարույթներով դատական ակտերի վերաբերյալ տեղեկատվությունը տրամադրում է Լիազոր մարմնին՝ համաձայն սույն հավելվածի Թերթիկ N 2-ի:
(8-րդ կետը փոփ. 30.06.22 N 996-Ն)
9. Աջակցության կենտրոնը՝ տվյալ կառույցներ դիմած ընտանիքում բռնության դեպքերի վերաբերյալ տեղեկատվությունը տրամադրում է Լիազոր մարմնին՝ համաձայն սույն հավելվածի Թերթիկ N 3-ի:
10. Խնամակալության և հոգաբարձության մարմինները, առողջապահության նախարարությունը, կրթության, գիտության, մշակույթի և սպորտի նախարարությունը ընտանիքում բռնության դեպքերի վերաբերյալ իրենց հայտնի դարձած տեղեկատվությունը տրամադրում են Լիազոր մարմնին՝ համաձայն սույն հավելվածի Թերթիկ N 3-ի:
11. Լիազոր մարմինը սույն կարգի 7-րդ, 8-րդ, 9-րդ և 10-րդ կետերով ստացված տեղեկատվության հիման վրա իրականացնում է ընտանիքում բռնության դեպքերի կենտրոնացված հաշվառում և դրանց ընթացքի վերաբերյալ վիճակագրության վարում:
12. Լիազոր մարմինը յուրաքանչյուր կիսամյակ տեղեկությունները ստանալուց և ամփոփելուց հետո՝ իր պաշտոնական կայքում հրապարակում է սույն հավելվածի 5-րդ կետով սահմանված ժամանակահատվածի վիճակագրական հաշվետվությունը ընտանիքում բռնության դեպքերի վերաբերյալ՝ համաձայն սույն հավելվածի Թերթիկ N 4-ի:
