# Հավելված N 2 ՀՀ կառավարության 2002 թվականի սեպտեմբերի 19-ի N 1794-Ն որոշման
Կ Ա Ռ ՈՒ Ց Վ Ա Ծ Ք ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՎԱՅՈՑ ՁՈՐԻ ՄԱՐԶՊԵՏԱՐԱՆԻ ԱՇԽԱՏԱԿԱԶՄԻ I. Կառուցվածքային ստորաբաժանումներ 1. Վարչություններ Ֆինանսական և սոցիալ-տնտեսական զարգացման վարչությունՔաղաքաշինության վարչությունԳյուղատնտեսության և բնապահպանության վարչությունԿրթության, մշակույթի և սպորտի վարչությունԱռողջապահության և սոցիալական ապահովության վարչություն Տեղական ինքնակառավարման և հանրապետական գործադիր մարմինների տարածքային ծառայությունների գործունեության համակարգման վարչություն 2. Քարտուղարություն 3. Բաժիններ Տրանսպորտի և ճանապարհաշինության բաժինՀողաշինության և հողօգտագործման բաժին-մարզային հողային պետական տեսչությունԵրեխաների իրավունքների պաշտպանության բաժինԱնձնակազմի կառավարման բաժինՏեղեկատվության և հասարակայնության հետ կապերի բաժին(3-րդ կետը լրաց. 27.10.05 N 1833-Ն, 07.12.06 N 1751-Ն, 20.09.07 N 1083-ն) II. Առանձնացված ստորաբաժանումներ Եղեգնաձորի սոցիալական ծառայությունների տարածքային գործակալությունՎայքի սոցիալական ծառայությունների տարածքային գործակալություն(2-րդ բաժինը փոփ. 29.12.05 N 2337-Ն, 29.06.06 N 928-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
