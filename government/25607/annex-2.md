# Հավելված N 2 ՀՀ կառավարության 2006 թվականի հուլիսի 6-ի N 1008-Ն որոշման

Ս. Սարգսյան | - | ՀՀ վարչապետ (խորհրդի նախագահ)
Հ. Աբրահամյան | - | ՀՀ փոխվարչապետ, ՀՀ տարածքային կառավարման նախարար
Վ. Խաչատրյան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարար
Ա. Մանուկյան | - | ՀՀ տրանսպորտի և կապի նախարար
Դ. Լոքյան | - | ՀՀ գյուղատնտեսության նախարար
Վ. Ներսիսյանց | - | ՀՀ Նախագահի տնտեսական հարցերով գլխավոր խորհրդական
Վ. Սողոմոնյան | - | «Ֆերմերների ազգային միավորում» հասարակական կազմակերպության ներկայացուցիչ (համաձայնությամբ)
Կ. Նազարյան | - | «Հայաստանի միջեկեղեցական բարեգործական կլոր սեղան» հիմնադրամի ներկայացուցիչ (համաձայնությամբ)
Ա. Ոսկանյան | - | «Ագրոզարգացում» հասարակական կազմակերպության ներկայացուցիչ (համաձայնությամբ)
Հ. Ջավադյան | - | Կիրառական հետազոտությունների և ագրոբիզնեսի հիմնադրամի ներկայացուցիչ (համաձայնությամբ)
Ա. Հովհաննիսյան | - | «Հայաստանի ավագանիների ասոցիացիա» հասարակական կազմակերպության ներկայացուցիչ (համաձայնությամբ)
(N2 Հավելվածը խմբ. 15.11.07 N 1325-Ն)
