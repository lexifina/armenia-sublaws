# Հավելված N 2 ՀՀ կառավարության 2006 թվականի հուլիսի 6-ի N 1008-Ն որոշման
Ա Ն Հ Ա Տ Ա Կ Ա Ն Կ Ա Զ Մ «ՀԱԶԱՐԱՄՅԱԿԻ ՄԱՐՏԱՀՐԱՎԵՐ» ՀԻՄՆԱԴՐԱՄ-ՀԱՅԱՍՏԱՆ» ՊԵՏԱԿԱՆ ՈՉ ԱՌԵՎՏՐԱՅԻՆ ԿԱԶՄԱԿԵՐՊՈՒԹՅԱՆ ԿԱՌԱՎԱՐՄԱՆ ԽՈՐՀՐԴԻ
Ա. Մարգարյան | - ՀՀ վարչապետ (խորհրդի նախագահ)
Հ. Աբրահամյան | - ՀՀ տարածքային կառավարման նախարար
Վ. Խաչատրյան | - ՀՀ ֆինանսների և էկոնոմիկայի նախարար
Ա. Մանուկյան | - ՀՀ տրանսպորտի և կապի նախարար
Դ. Լոքյան | - ՀՀ գյուղատնտեսության նախարար
Վ. Ներսիսյանց | - ՀՀ Նախագահի տնտեսական հարցերով գլխավոր խորհրդական
Տ. Ղազարյան | - «Շենիկ» ջրօգտագործողների ընկերությունների միության ներկայացուցիչ (համաձայնությամբ)
Ն. Վարդանյան | - «Հայաստանի անտառներ» բնապահպանական հասարակական կազմակերպության ներկայացուցիչ (համաձայնությամբ)
Վ. Համբարձումյան | - Ֆերմերների ազգային միավորման ներկայացուցիչ (համաձայնությամբ)
Վ. Համբարձումյան | - «Գյուղատնտեսական ասոցիացիաների ֆեդերացիա» իրավաբանական անձանց միության ներկայացուցիչ (համաձայնությամբ)
Կ. Նազարյան | - «Հայաստանի միջեկեղեցական բարեգործական կլոր սեղան» հիմնադրամի ներկայացուցիչ (համաձայնությամբ)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
