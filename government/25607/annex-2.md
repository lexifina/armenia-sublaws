Տ. Սարգսյան | - | ՀՀ վարչապետ (խորհրդի նախագահ)
Վ. Ներսիսյանց | - | ՀՀ նախագահի տնտեսական հարցերով գլխավոր խորհրդական (խորհրդի նախագահի տեղակալ)
Ա. Գևորգյան | - | ՀՀ փոխվարչապետ, ՀՀ տարածքային կառավարման նախարար
Տ. Դավթյան | - | ՀՀ ֆինանսների նախարար
Ն. Երիցյան | - | ՀՀ էկոնոմիկայի նախարար
Գ. Սարգսյան | - | ՀՀ տրանսպորտի և կապի նախարար
Ա. Գրիգորյան | - | ՀՀ գյուղատնտեսության նախարար
Կ. Զադոյան | - | «Հայաստանի երիտասարդ իրավաբանների ասոցիացիա» հասարակական կազմակերպության ներկայացուցիչ (համաձայնությամբ)
Վ. Ենգիբարյան | - | «Հայաստանի եվրոպական շարժում» հասարակական կազմակերպության ներկայացուցիչ (համաձայնությամբ)
Պ. Շահինյան | - | «Ճանապարհային անվտանգության ազգային խորհուրդ» հասարակական կազմակերպության ներկայացուցիչ (համաձայնությամբ)
Շ. Միքայելյան | - | «Աշխատանք և հայրենիք» հասարակական կազմակերպության ներկայացուցիչ (համաձայնությամբ)
Ա. Ոսկանյան | - | «Տավուշի զարգացման» հասարակական կազմակերպության ներկայացուցիչ (համաձայնությամբ)
