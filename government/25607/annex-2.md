# Հավելված N 2 ՀՀ կառավարության 2006 թվականի հուլիսի 6-ի N 1008-Ն որոշման

«ՀԱԶԱՐԱՄՅԱԿԻ ՄԱՐՏԱՀՐԱՎԵՐ» ՀԻՄՆԱԴՐԱՄ-ՀԱՅԱՍՏԱՆ» ՊԵՏԱԿԱՆ ՈՉ ԱՌԵՎՏՐԱՅԻՆ ԿԱԶՄԱԿԵՐՊՈՒԹՅԱՆ ԿԱՌԱՎԱՐՄԱՆ ԽՈՐՀՐԴԻ
Տ. Սարգսյան | - ՀՀ վարչապետ (խորհրդի նախագահ)
Վ. Ներսիսյանց | - ՀՀ Նախագահի տնտեսական հարցերով գլխավոր խորհրդական (խորհրդի նախագահի տեղակալ)
Ա. Գևորգյան | - ՀՀ փոխվարչապետ, ՀՀ տարածքային կառավարման նախարար
Գ. Ալավերդյան | - ՀՀ գյուղատնտեսության նախարար
Տ. Դավթյան | - ՀՀ ֆինանսների նախարար
Ն. Երիցյան | - ՀՀ էկոնոմիկայի նախարար
Ա. Անդրեասյան | - ՀՀ տարածքային կառավարման նախարարության ջրային տնտեսության պետական կոմիտեի նախագահ
Մ. Ատովմյան | - Հատուկ կարիքներով մարդկանց աջակցության «Ունիսոն» հասարակական կազմակերպության ներկայացուցիչ (համաձայնությամբ)
Գ. Բալայան | - «Վառվող աստղ» հասարակական կազմակերպության ներկայացուցիչ (համաձայնությամբ)
Պ. Բարսեղյան | - «Հասարակության համախմբում» հասարակական կազմակերպության ներկայացուցիչ (համաձայնությամբ)
Վ. Ենգիբարյան | - «Հայաստանի եվրոպական շարժում» հասարակական կազմակերպության ներկայացուցիչ (համաձայնությամբ)
Մ. Զադոյան | - Գյումրու «Մաշտոցի դպրոց» հիմնադրամի ներկայացուցիչ (համաձայնությամբ)
(հավելվածը խմբ. 15.11.07 N 1325-Ն, 15.05.08 N 436-Ն, 30.10.08 N 1228-Ն, փոփ. 04.06.09 N 627-Ն, խմբ. 11.11.10 N 1449-Ն)
