# Հավելված N 1 ՀՀ կառավարության 2006 թվականի հոկտեմբերի 5-ի N 1423-Ն որոշման
Կ Ա Ր Գ ՄԻՋԻՆ ՈՒ ԲԱՐՁՐ ՃՆՇՄԱՆ ԳԱԶԻ ՀԱՄԱԿԱՐԳԵՐԻ` ՆՈՐ ԿԱՌՈՒՑՎՈՂ ԵՎ ՎԵՐԱԿԱՌՈՒՑՎՈՂ ԷՆԵՐԳԱՏԵՂԱԿԱՅԱՆՔՆԵՐԻ ԳՈՐԾԱՐԿՄԱՆ ԵԶՐԱԿԱՑՈՒԹՅՈՒՆ ՏԱԼՈՒ (վերնագիրը փոփ. 23.08.07 N 946-Ն)
1. Սույն կարգը մշակված է «Էներգետիկայի բնագավառում և էներգասպառման ոլորտում պետական տեխնիկական վերահսկողության մասին» Հայաստանի Հանրապետության օրենքի 6-րդ հոդվածի 1-ին մասի «գ» կետի պահանջին համապատասխան և կարգավորում է միջին ու բարձր ճնշման գազի համակարգերի` նոր կառուցվող և վերակառուցվող էներգատեղակայանքների գործարկման եզրակացություն տալու հետ կապված հարաբերությունները:
(1-ին կետը փոփ. 23.08.07 N 946-Ն)
2. Սույն կարգի գործողությունը տարածվում է էներգետիկայի բնագավառում գործունեություն իրականացնող անձանց ու տեխնոլոգիական նպատակներով գազ սպառողների (այսուհետ՝ սպառողներ) վրա:
3. Էներգետիկայի բնագավառում գործունեություն իրականացնող անձանց և սպառողների միջին ու բարձր ճնշման գազի համակարգերի` նոր կառուցվող և վերակառուցվող էներգատեղակայանքների (այսուհետ՝ գազի տեղակայանքներ) գործարկումն իրականացվում է Հայաստանի Հանրապետության քաղաքաշինության, տեխնիկական և հրդեհային անվտանգության տեսչական մարմնի (այսուհետ՝ տեսչական մարմին) կողմից տրված գործարկման եզրակացության՝ գործարկման թույլտվության առկայության դեպքում:
(3-րդ կետը փոփ. 23.08.07 N 946-Ն, 15.01.09 N 52-Ն, 10.12.20 N 2010-Ն)
4. Նոր կառուցվող և վերակառուցվող գազի տեղակայանքները պետք է կառուցվեն Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով` գազամատակարարող կազմակերպության կողմից տրված միացման տեխնիկական պայմաններին (առաջադրանքին) և դրա հիման վրա կազմված նախագծին համապատասխան:
5. Գազի տեղակայանքների՝ գործարկմանը պատրաստ լինելու դեպքում դրանց սեփականատերը (լիազորված անձը) գրավոր դիմում է տեսչական մարմին` միաժամանակ ներկայացնելով գազամատակարարման տեխնիկական պայմանները (տեխնիկական առաջադրանքը): Դիմումը կարող է ներկայացվել առձեռն, փոստով կամ էլեկտրոնային փոստի միջոցով:
(5-րդ կետը խմբ. 10.09.15 N 1046-Ն, փոփ. 10.12.20 N 2010-Ն)
6. Գազի տեղակայանքների սեփականատիրոջ (լիազորված անձի) դիմումն ստանալուց հետո հինգ աշխատանքային օրվա ընթացքում տեսչական մարմնի ծառայողը (ծառայողները) կատարում է (կատարում են) գազի տեղակայանքների տեխնիկական ստուգում (ուսումնասիրություն) և կազմում ակտ-կարգադրագիր, որում նշվում են ներկայացված փաստաթղթերի անվանումները, տեղադրված և հավաքակցված տեղակայանքների համապատասխանությունը նախագծին և տեխնիկական կանոնակարգերին: Գազի տեղակայանքների սեփականատերը (լիազորված անձը) ծառայողին (ծառայողներին) է տրամադրում գործարկման եզրակացություն տալու համար պահանջվող փաստաթղթերի ցանկով` համաձայն N 2 հավելվածի, նախատեսված փաստաթղթերի պատճենները: Ծառայողը (ծառայողները) փաստաթղթերի իսկությունը պարզելու նպատակով տեղում դրանք համեմատում է փաստաթղթերի բնօրինակների հետ: Ակտ-կարգադրագրի դրական եզրակացության հիման վրա, սույն կետում նշված ժամկետում, տրվում է գազի տեղակայանքի գործարկման եզրակացությունը` համաձայն Հայաստանի Հանրապետության կառավարության 2006 թվականի հոկտեմբերի 5-ի N 1423-Ն որոշման N 3 հավելվածի` թույլատրելով դրա գործարկումը:
(6-րդ կետը փոփ., լրաց. 31.10.13 N 1196-Ն, խմբ. 10.09.15 N 1046-Ն, փոփ. 10.12.20 N 2010-Ն)
7. Տեսչական մարմնի կողմից գազի տեղակայանքների գործարկման եզրակացություն տալու նպատակով իրականացվող գործընթացը կատարվում է գազի տնտեսության պատասխանատու անձի (սեփականատիրոջ և (կամ) լիազորված պաշտոնատար անձի) մասնակցությամբ:
(7-րդ կետը փոփ. 10.12.20 N 2010-Ն)
8. Գազի տեղակայանքների՝ նախագծին կամ տեխնիկական կանոնակարգերին չհամապատասխանելու, հավաքակցման աշխատանքների թերի կատարման, գազի տնտեսության պատասխանատու անձի կամ շահագործող անձնակազմի բացակայության դեպքում տեսչական մարմնի ծառայողը (ծառայողները) կազմում է (կազմում են) բացասական եզրակացությամբ ակտ-կարգադրագիր՝ նշելով թերությունները և հինգ աշխատանքային օրվա ընթացքում այն ներկայացնում գազի տեղակայանքների սեփականատիրոջը:
(8-րդ կետը փոփ. 31.10.13 N 1196-Ն, 10.12.20 N 2010-Ն)
9. Ակտ-կարգադրագրում նշված թերությունների վերացման մասին գազի տեղակայանքների սեփականատիրոջ գրավոր դիմումից հետո տեսչական մարմնի ծառայողը (ծառայողները), թերությունների վերացումը հաստատելու և գործարկման եզրակացություն տալու նպատակով, երեք աշխատանքային օրվա ընթացքում կատարում է (կատարում են) գազի տեղակայանքների ուսումնասիրություն, և թերությունների վերացումը հաստատելու դեպքում տրվում է էներգատեղակայանքի գործարկման եզրակացություն:
(9-րդ կետը փոփ. 31.10.13 N 1196-Ն, խմբ. 10.09.15 N 1046-Ն, փոփ. 10.12.20 N 2010-Ն)
(հավելվածը փոփ. 23.08.07 N 946-Ն, 15.01.09 N 52-Ն, փոփ., լրաց. 31.10.13 N 1196-Ն, խմբ. 10.09.15 N 1046-Ն, փոփ. 10.12.20 N 2010-Ն)
