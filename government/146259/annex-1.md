# Հավելված ՀՀ կառավարության 2020 թվականի սեպտեմբերի 27-ի N 1586-Ն որոշման
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅՈՒՆՈՒՄ ՀԱՅՏԱՐԱՐԱԾ ՌԱԶՄԱԿԱՆ ԴՐՈՒԹՅԱՆ ԺԱՄԱՆԱԿ ԿԻՐԱՌՎՈՂ ՄԻՋՈՑԱՌՈՒՄՆԵՐԸ, ԻՐԱՎՈՒՆՔՆԵՐԻ ՈՒ ԱԶԱՏՈՒԹՅՈՒՆՆԵՐԻ ԺԱՄԱՆԱԿԱՎՈՐ ՍԱՀՄԱՆԱՓԱԿՈՒՄՆԵՐԸ, ՌԱԶՄԱԿԱՆ ԴՐՈՒԹՅԱՆ ԻՐԱՎԱԿԱՆ ՌԵԺԻՄՆ ԱՊԱՀՈՎՈՂ ՄԻՋՈՑՆԵՐԸ ԵՎ ՄԱՐՄԻՆՆԵՐԸ
I. ՄԱՍՆԱԿԻ ԶՈՐԱՀԱՎԱՔԻ ՀԱՅՏԱՐԱՐՈՒՄԸ ԵՎ ԱՆՑԿԱՑՈՒՄԸ
(վերնագիրը փոփ. 10.12.20 N 2003-Ն)
1. Հայաստանի Հանրապետությունում հայտարարվում է մասնակի զորահավաք:
(1-ին կետը փոփ. 10.12.20 N 2003-Ն)
2. Գործողության մեջ է դրվում Հայաստանի Հանրապետության զինված ուժերի կիրառման պլանը՝ ըստ զինված ուժերի կիրառման համար անհրաժեշտ ռազմավարական ուղղությունների:
(2-րդ կետը լրաց. 10.12.20 N 2003-Ն)
3. Հայաստանի Հանրապետության զինված ուժերը, մասնակի փոխադրվում են պատերազմական ժամանակաշրջանի կազմի և կառուցվածքի:
(3-րդ կետը փոփ. 10.12.20 N 2003-Ն)
4. Հայտարարվում է պահեստազորի սպայական, ենթասպայական և շարքային կազմի մինչև 55 տարեկան պահեստազորում հաշվառված քաղաքացիների զորահավաքային զորակոչ՝ ըստ զինված ուժերի կիրառման համար անհրաժեշտ ռազմավարական ուղղությունների համալրման անհրաժեշտության:
(4-րդ կետը լրաց. 10.12.20 N 2003-Ն)
5. Հայաստանի Հանրապետության պաշտպանության նախարարն ապահովում է պատերազմական ժամանակի հաստիքներին կցագրված պահեստազորայինների՝ ըստ զինված ուժերի կիրառման համար անհրաժեշտ ռազմավարական ուղղությունների համալրման անհրաժեշտության, զորահավաքային զորակոչը՝ զինված ուժերի զորահավաքային պլաններով նախատեսված ժամկետներում:
(5-րդ կետը լրաց., փոփ. 10.12.20 N 2003-Ն)
6. Ապահովվում է «Պաշտպանության մասին» օրենքի 27-րդ հոդվածով սահմանված ռազմատրանսպորտային պարտավորություն ունեցող մարմինների տրանսպորտային միջոցների ներգրավումը՝ սահմանված կարգով և ըստ զինված ուժերի կարիքների առաջնային անհրաժեշտության:
II. ՊԵՏԱԿԱՆ ԵՎ ՏԱՐԱԾՔԱՅԻՆ ԿԱՌԱՎԱՐՄԱՆ, ՏԵՂԱԿԱՆ ԻՆՔՆԱԿԱՌԱՎԱՐՄԱՆ ՄԱՐՄԻՆՆԵՐԻ, ԿԱԶՄԱԿԵՐՊՈՒԹՅՈՒՆՆԵՐԻ ԳՈՐԾՈՒՆԵՈՒԹՅԱՆ ՓՈԽԱԴՐՈՒՄԸ ՌԱԶՄԱԿԱՆ ԴՐՈՒԹՅԱՆ ԱՇԽԱՏԱՆՔԱՅԻՆ ՌԵԺԻՄԻ
7. Պետական և տարածքային կառավարման, տեղական ինքնակառավարման մարմինների, կազմակերպությունների գործունեությունը փոխադրվում է ռազմական դրության աշխատանքային ռեժիմի սկսած 2020 թվականի սեպտեմբերի 27-ի ժամը 16.00-ից՝ «Պաշտպանության մասին» օրենքի 7-րդ հոդվածի 1-ին մասի 9-րդ կետի «ե» ենթակետի հիման վրա ընդունված Հայաստանի Հանրապետության կառավարության որոշմանը համապատասխան:
III. ՀԱՎԱՔՆԵՐ ԵՎ ԳՈՐԾԱԴՈՒԼՆԵՐ ԻՐԱԿԱՆԱՑՆԵԼՈՒ ՍԱՀՄԱՆԱՓԱԿՈՒՄՆԵՐԸ ԵՎ ԱՐԳԵԼՔՆԵՐԸ
(գլուխն ուժը կորցրել է 02.12.20 N 1917-Ն)
IV. ՀՐԱՊԱՐԱԿՈՒՄՆԵՐԻ, ՀԱՂՈՐԴՈՒՄՆԵՐԻ ԻՐԱԿԱՆԱՑՄԱՆ ՍԱՀՄԱՆԱՓԱԿՈՒՄՆԵՐԸ
(գլուխն ուժը կորցրել է 02.12.20 N 1917-Ն)
V. ՔԱՂԱՔԱՑԻԱԿԱՆ ՊԱՇՏՊԱՆՈՒԹՅԱՆ ՄԻՋՈՑԱՌՈՒՄՆԵՐԸ
11. Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարությունը քաղաքացիական պաշտպանության միջոցառումների և վթարավերականգնողական և այլ անհետաձգելի աշխատանքների իրականացման համար իրականացնում է քաղաքացիական պաշտպանության ստորաբաժանումների և փրկարար ուժերի համալրում և լիակատար մարտական պատրաստականության փոխադրում: Քաղաքացիական պաշտպանության միջոցառումների և վթարավերականգնողական և այլ անհետաձգելի աշխատանքների իրականացման համար քաղաքացիական պաշտպանության ստորաբաժանումները և փրկարար ուժերը բերվում են լրիվ պատրաստականության:
12. Որպես քաղաքացիական պաշտպանության պետեր՝ պետական և տարածքային կառավարման մարմինների, տեղական ինքնակառավարման մարմինների և կազմակերպությունների ղեկավարներն իրենց իրավասության սահմաններում ճշգրտում և գործողության մեջ են դնում քաղաքացիական պաշտպանության բոլոր մակարդակներում քաղաքացիական պաշտպանության պլանները, պլան-ժամանակացույցերը, քաղաքացիական պաշտպանության ծառայությունների քաղաքացիական պաշտպանության պլանները, տարհանման պլանները:
VI. ՌԱԶՄԱԿԱՆ ԴՐՈՒԹՅԱՆ ԻՐԱՎԱԿԱՆ ՌԵԺԻՄՆ ԱՊԱՀՈՎՈՂ ՄԱՐՄԻՆՆԵՐԸ
13. Ռազմական դրության իրավական ռեժիմն ապահովելու նպատակով օգտագործվում են Հայաստանի Հանրապետության պաշտպանության նախարարության, Հայաստանի Հանրապետության ազգային անվտանգության ծառայության, Հայաստանի Հանրապետության ոստիկանության, Հայաստանի Հանրապետության արդարադատության նախարարության, Հայաստանի Հանրապետության առողջապահության նախարարության, քաղաքացիական պաշտպանության և արտակարգ իրավիճակների ու այլ պետական լիազոր մարմինների ուժերն ու միջոցները:
14. Հասարակական կարգի պահպանության և հասարակական անվտանգության ապահովումն իրականացվում է Հայաստանի Հանրապետության ոստիկանության, Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարության, Դատական ակտերի հարկադիր կատարման ծառայության ուժերի կողմից:
VII. ԱԶԱՏ ՏԵՂԱՇԱՐԺՎԵԼՈՒ ԻՐԱՎՈՒՆՔԻ ՍԱՀՄԱՆԱՓԱԿՈՒՄԸ
(գլուխը լրաց. 02.10.20 N 1626-Ն)
15. (կետն ուժը կորցրել է 02.12.20 N 1917-Ն)
16. Հայաստանի Հանրապետության ամբողջ տարածքում կարող են կիրառվել ազատ տեղաշարժվելու իրավունքի սահմանափակումներ: Հայաստանի Հանրապետության ազգային անվտանգության ծառայությունը, Հայաստանի Հանրապետության ոստիկանությունը, Հայաստանի Հանրապետության պաշտպանության նախարարությունը, Հայաստանի Հանրապետության արտակարգ իրավիճակների նախարարությունը կարող են անձանց արգելել Հայաստանի Հանրապետության որևէ վարչատարածքային միավոր կամ որևէ առանձին տարածք (ճանապարհ) մուտք գործելը կամ դուրս գալը՝ պետական անվտանգության երաշխավորման, մարդկանց կյանքի և անվտանգության ապահովման անհրաժեշտությամբ պայմանավորված:
17. Սույն գլխով նախատեսված ռեժիմն ապահովելու նպատակով կարող են նաև տեղադրվել հատուկ անցակետեր:
VIII․ ՍՆՆԴԱՄԹԵՐՔԻ, ԴԵՂՈՐԱՅՔԻ, ԱՌԱՋԻՆ ԱՆՀՐԱԺԵՇՏՈՒԹՅԱՆ ԱՊՐԱՆՔՆԵՐԻ ՎԱՃԱՌՔԸ, ՁԵՌՔԲԵՐՈՒՄԸ ԵՎ ՇՐՋԱՆԱՌՈՒԹՅՈՒՆԸ
(բաժինը լրաց. 10.10.20 N 1667-Ն)
18. Գործողության մեջ է դրվում Հայաստանի Հանրապետության կառավարության 2020 թվականի հոկտեմբերի 3-ի N 1632-Ն որոշումը, բացառությամբ N 1 հավելվածի 3-րդ և 4-րդ կետերի։
(հավելվածը լրաց. 02.10.20 N 1626-Ն, 08.10.20 N 1655-Ն, 10.10.20 N 1667-Ն, փոփ. 02.12.20 N 1917-Ն, փոփ., լրաց. 10.12.2020 N 2003-Ն )
Հայաստանի Հանրապետության վարչապետի աշխատակազմի ղեկավար | Է. Աղաջանյան
Պաշտոնական հրապարակման օրը՝ 27 սեպտեմբերի 2020 թվական:
