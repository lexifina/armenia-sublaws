1. ՃԱՐՏԱՐԱՊԵՏՈՒԹՅՈՒՆ (ԿԱՌՈՒՑՎԱԾՔ)
1. Կառավարության փոխգործելիության հարթակի ճարտարապետություն (X-Road Architecture)
2. Անվտանգության սերվերի ճարտարապետություն (Security Server Architecture)
3. Կապուղու կարգաբերման ճարտարապետություն (Configuration Proxy Architecture)
4. Կենտրոնական սերվերի ճարտարապետություն (Central Server Architecture)
5. Իրադարձությունների լոգավորման աուդիտ (Audit Log Events)
II. ԱՐՁԱՆԱԳՐՈՒԹՅՈՒՆՆԵՐ

8. Կառավարչական ծառայությունների արձանագրություն (Protocol for Management Services)
9. Ծառայությունների մետատվյալների արձանագրություն (Service Metadata Protocol)
10. Կոնֆիգուրացիայի ներբեռնման արձանագրություն (Protocol for Downloading Configuration)

12. Կենտրոնական սերվերի օգտվողի ուղեցույց (Central Server User Guide)
