# Հավելված N 2 ՀՀ կառավարության 2012 թվականի հունիսի 28-ի N 810-Ն որոշման
Կ Ա Ր Գ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՖԻՆԱՆՍՆԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԿՈՂՄԻՑ ՀԱՏՈՒՑՎՈՂ ԳՈՒՄԱՐԻ ԻՐ ՄԱՍՆԱԲԱԺԻՆԸ ԵՐԱՇԽԻՔԱՅԻՆ ՖՈՆԴԻՆ ՎՃԱՐԵԼՈՒ ԵՎ ԵՐԱՇԽԻՔԱՅԻՆ ՖՈՆԴԻ ԿՈՂՄԻՑ ՀԱՏՈՒՑՎՈՂ ԸՆԴՀԱՆՈՒՐ ԳՈՒՄԱՐԸ ՄԱՍՆԱԿԻՑՆԵՐԻ ՌԵԵՍՏՐԸ ՎԱՐՈՂԻՆ ՓՈԽԱՆՑԵԼՈՒ
(վերնագիրը խմբ. 13.09.13 N 991-Ն)
I. ԸՆԴՀԱՆՈՒՐ ԴՐՈՒՅԹՆԵՐ
1. Սույն կարգով կարգավորվում են Հայաստանի Հանրապետության ֆինանսների նախարարության և երաշխիքային ֆոնդի կողմից Հայաստանի Հանրապետության կուտակային կենսաթոշակային համակարգի պարտադիր բաղադրիչի մասնակիցների ռեեստրը վարողին` մասնակցի կատարած պարտադիր կուտակային վճարների ամբողջ գումարի` ճշգրտված տարեկան գնաճով, և նրա կենսաթոշակային հաշվում առկա պարտադիր կենսաթոշակային ֆոնդի (ֆոնդերի) փայերի հաշվարկային արժեքների հանրագումարի տարբերության (այսուհետ` հատուցվող գումար)` օրենքի 49-րդ հոդվածի 2-րդ մասով սահմանված մասնաբաժնին համապատասխանող չափով տարբերության գումարի` Հայաստանի Հանրապետության ֆինանսների նախարարության մասնաբաժնի` երաշխիքային ֆոնդին վճարելու և երաշխիքային ֆոնդի կողմից հատուցվող ընդհանուր գումարը մասնակիցների ռեեստրը վարողին փոխանցելու հետ կապված հարաբերությունները:
(1-ին կետը խմբ. 13.09.13 N 991-Ն)
2. Սույն կարգում օգտագործվող հասկացությունները համապատասխանում են օրենքով նախատեսված սահմանումներին:
II. ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՖԻՆԱՆՍՆԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԿՈՂՄԻՑ ԵՐԱՇԽԻՔԱՅԻՆ ՖՈՆԴԻՆ ՀԱՏՈՒՑՎՈՂ ԳՈՒՄԱՐԻ ԻՐ ՄԱՍՆԱԲԱԺՆԻ ՎՃԱՐՈՒՄԸ
(վերնագիրը խմբ. 13.09.13 N 991-Ն)
3. Հայաստանի Հանրապետության ֆինանսների նախարարությունը երաշխիքային ֆոնդից Հայաստանի Հանրապետության կառավարության 2012 թվականի հունիսի 28-ի N 810-Ն որոշման N 1 հավելվածի 3-րդ բաժնով սահմանված վճարման հայտն ստանալուց հետո երեք աշխատանքային օրվա ընթացքում հատուցվող գումարի` Հայաստանի Հանրապետության պետական բյուջեի հաշվին հատուցվող մասնաբաժինը վճարում է երաշխիքային ֆոնդի` Հայաստանի Հանրապետության կենտրոնական բանկում բացված դրամական հաշվին (այսուհետ` հաշիվ)՝ Բանկ-մեյլ համակարգով:
(3-րդ կետը խմբ. 13.09.13 N 991-Ն)
III. ԵՐԱՇԽԻՔԱՅԻՆ ՖՈՆԴԻ ԿՈՂՄԻՑ ՄԱՍՆԱԿԻՑՆԵՐԻ ՌԵԵՍՏՐԸ ՎԱՐՈՂԻՆ ՀԱՏՈՒՑՎՈՂ ԸՆԴՀԱՆՈՒՐ ԳՈՒՄԱՐԻ ՎՃԱՐՈՒՄԸ
(վերնագիրը խմբ. 13.09.13 N 991-Ն)
4. Երաշխիքային ֆոնդի և Հայաստանի Հանրապետության պետական բյուջեի հաշվին հատուցվող ընդհանուր գումարը վճարվում է օրենքի 52-րդ հոդվածի 3-րդ մասով սահմանված ժամկետում մասնակիցների ռեեստրը վարողի հաշվին՝ Բանկ-մեյլ համակարգով՝ նշելով մասնակիցների ռեեստրը վարողի տեղեկատվական համակարգի կողմից յուրաքանչյուր հատուցման դեպքի առնչությամբ գեներացված եզակի հղման համարը:
(4-րդ կետը խմբ. 13.09.13 N 991-Ն)
(հավելվածը խմբ. 13.09.13 N 991-Ն)
