# Հավելված ՀՀ կառավարության 2016 թվականի փետրվարի 25-ի N 169-Ն որոշման
Կ Ա Ր Գ
Պետական եկամուտների կոմիտեի ԿՈՂՄԻՑ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՍՆՆԴԱՄԹԵՐՔԻ ԱՆՎՏԱՆԳՈՒԹՅԱՆ ՏԵՍՉԱԿԱՆ ՄԱՐՄՆԻՆ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅՈՒՆ ՆԵՐՄՈՒԾՎԱԾ ՍՆՆԴԱՄԹԵՐՔԻ, ԱՆԱՍՆԱԲՈՒԺԱԿԱՆ ԵՎ բուսասանիտարիայի բնագավառի ՀՍԿՈՂՈՒԹՅԱՆ (ՎԵՐԱՀՍԿՈՂՈՒԹՅԱՆ) ԵՆԹԱԿԱ ԱՊՐԱՆՔՆԵՐԻ ՎԵՐԱԲԵՐՅԱԼ ՏԵՂԵԿԱՏՎՈՒԹՅԱՆ ՏՐԱՄԱԴՐՄԱՆ
(վերնագիրը փոփ. 04.05.17 N 480-Ն, 14.01.21 N 47-Ն, 20.10.22 N 1619-Ն)
1. Սույն կարգով կարգավորվում են Պետական եկամուտների կոմիտեի կողմից Հայաստանի Հանրապետության սննդամթերքի անվտանգության տեսչական մարմնին (այսուհետ` լիազոր մարմին) Հայաստանի Հանրապետություն ներմուծված սննդամթերքի, անասնաբուժական և բուսասանիտարիայի բնագավառի հսկողության (վերահսկողության) ենթակա ապրանքների վերաբերյալ տեղեկատվության տրամադրման հետ կապված հարաբերությունները:
(1-ին կետը փոփ. 04.05.17 N 480-Ն, 14.01.21 N 47-Ն, 20.10.22 N 1619-Ն)
2. Կոմիտեն լիազոր մարմնին է տրամադրում «Բացթողում` ներքին սպառման համար», «Մաքսային տարանցում» և «Վերամշակում՝ ներքին սպառման համար» մաքսային ընթացակարգերով Հայաստանի Հանրապետություն ներմուծված արտաքին տնտեսական գործունեության ապրանքային անվանացանկի (ԱՏԳ ԱԱ) 31-րդ խմբի և 3808 ծածկագրի ապրանքների, ինչպես նաև Հայաստանի Հանրապետության կառավարության 2014 թվականի հոկտեմբերի 30-ի N 1205-Ն որոշման N 1 հավելվածի, Հայաստանի Հանրապետության կառավարության 2014 թվականի հոկտեմբերի 30-ի N 1237-Ն որոշման N 3 հավելվածի և Հայաստանի Հանրապետության գյուղատնտեսության նախարարության սննդամթերքի անվտանգության պետական ծառայության պետի 2013 թվականի նոյեմբերի 22-ի N 700-Ն հրամանի հավելվածի ցանկերում նշված սննդամթերքի, անասնաբուժական և բուսասանիտարիայի բնագավառի հսկողության (վերահսկողության) ենթակա ապրանքների վերաբերյալ տեղեկատվությունը (այսուհետ՝ տեղեկատվություն):
(2-րդ կետը փոփ., լրաց. 04.05.17 N 480-Ն, փոփ. 20.10.22 N 1619-Ն)
3. Տեղեկատվությունը կոմիտեն լիազոր մարմնին է տրամադրում յուրաքանչյուր ամսվա համար՝ մինչև դրան հաջորդող ամսվա 15-ը, էլեկտրոնային եղանակով կամ կրիչով՝ համաձայն NN 1 և 2 ձևերի:
(3-րդ կետը փոփ. 04.05.17 N 480-Ն)
