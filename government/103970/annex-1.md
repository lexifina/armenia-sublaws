# Հավելված ՀՀ կառավարության 2016 թվականի փետրվարի 25-ի N 169-Ն որոշման
Կ Ա Ր Գ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՖԻՆԱՆՍՆԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԿՈՂՄԻՑ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԳՅՈՒՂԱՏՆՏԵՍՈՒԹՅԱՆ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ՍՆՆԴԱՄԹԵՐՔԻ ԱՆՎՏԱՆԳՈՒԹՅԱՆ ՊԵՏԱԿԱՆ ԾԱՌԱՅՈՒԹՅԱՆԸ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅՈՒՆ ՆԵՐՄՈՒԾՎԱԾ ՍՆՆԴԱՄԹԵՐՔԻ, ՍՆՆԴԱՄԹԵՐՔԻ ՀԵՏ ԱՆՄԻՋԱԿԱՆ ՇՓՄԱՆ ՄԵՋ ԳՏՆՎՈՂ ՆՅՈՒԹԵՐԻ, ԱՆԱՍՆԱԲՈՒԺԱԿԱՆ ԵՎ ԲՈՒՍԱՍԱՆԻՏԱՐԱԿԱՆ ԿԱՐԱՆՏԻՆ ՀՍԿՈՂՈՒԹՅԱՆ (ՎԵՐԱՀՍԿՈՂՈՒԹՅԱՆ) ԵՆԹԱԿԱ ԱՊՐԱՆՔՆԵՐԻ ՎԵՐԱԲԵՐՅԱԼ ՏԵՂԵԿԱՏՎՈՒԹՅԱՆ ՏՐԱՄԱԴՐՄԱՆ
1. Սույն կարգով կարգավորվում են Հայաստանի Հանրապետության ֆինանսների նախարարության կողմից (այսուհետ` նախարարություն) Հայաստանի Հանրապետության գյուղատնտեսության նախարարության սննդամթերքի անվտանգության պետական ծառայությանը (այսուհետ` լիազոր մարմին) Հայաստանի Հանրապետություն ներմուծված սննդամթերքի, սննդամթերքի հետ անմիջական շփման մեջ գտնվող նյութերի, անասնաբուժական և բուսասանիտարական կարանտին հսկողության (վերահսկողության) ենթակա ապրանքների վերաբերյալ տեղեկատվության տրամադրման հետ կապված հարաբերությունները:
2. Նախարարությունը լիազոր մարմնին է տրամադրում «Բացթողում` ներքին սպառման համար» և «Վերամշակում՝ ներքին սպառման համար» մաքսային ընթացակարգերով Հայաստանի Հանրապետություն ներմուծված արտաքին տնտեսական գործունեության ապրանքային անվանացանկի (ԱՏԳ ԱԱ) 31-րդ խմբի և 3808 ծածկագրի ապրանքների, ինչպես նաև Հայաստանի Հանրապետության կառավարության 2014 թվականի հոկտեմբերի 30-ի N 1205-Ն որոշման N 1 հավելվածի, Հայաստանի Հանրապետության կառավարության 2014 թվականի հոկտեմբերի 30-ի N 1211-Ն որոշման հավելվածի N 1 աղյուսակի, Հայաստանի Հանրապետության կառավարության 2014 թվականի հոկտեմբերի 30-ի N 1237-Ն որոշման N 3 հավելվածի և Հայաստանի Հանրապետության գյուղատնտեսության նախարարության սննդամթերքի անվտանգության պետական ծառայության պետի 2013 թվականի նոյեմբերի 22-ի N 700-Ն հրամանի հավելվածի ցանկերում նշված սննդամթերքի, սննդամթերքի հետ անմիջական շփման մեջ գտնվող նյութերի, անասնաբուժական և բուսասանիտարական կարանտին հսկողության (վերահսկողության) ենթակա ապրանքների վերաբերյալ տեղեկատվությունը (այսուհետ՝ տեղեկատվություն):
3. Տեղեկատվությունը նախարարությունը լիազոր մարմնին է տրամադրում յուրաքանչյուր ամսվա համար՝ մինչև դրան հաջորդող ամսվա 15-ը, էլեկտրոնային եղանակով կամ կրիչով՝ համաձայն ձևի:
4. Լիազոր մարմինը յուրաքանչյուր կիսամյակի համար մինչև դրան հաջորդող ամսվա 20-ը էլեկտրոնային եղանակով կամ կրիչով նախարարությանը տրամադրում է տեղեկատվություն հավելվածի 2-րդ կետի համաձայն տրամադրված տեղեկատվության հիման վրա իրականացված պետական վերահսկողության ընթացքում հայտնաբերված խախտումների վերաբերյալ:
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Դ. Հարությունյան
