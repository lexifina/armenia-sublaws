# Հավելված N 3 ՀՀ կառավարության 2019 թվականի փետրվարի 28-ի N 162-Ն որոշման
Ց Ա Ն Կ
ԴԵՂԻ ՊԵՏԱԿԱՆ ԳՐԱՆՑՄԱՆ, ՎԵՐԱԳՐԱՆՑՄԱՆ, ՀԱՎԱՍՏԱԳՐԻ ԺԱՄԿԵՏԻ ԵՐԿԱՐԱՁԳՄԱՆ ՆՊԱՏԱԿՈՎ ԻՐԱԿԱՆԱՑՎՈՂ ՓՈՐՁԱՔՆՆՈՒԹՅԱՆ, ԻՆՉՊԵՍ ՆԱԵՎ ՀԵՏԳՐԱՆՑՈՒՄԱՅԻՆ ՓՈՓՈԽՈՒԹՅՈՒՆՆԵՐԻ ՆԵՐԿԱՅԱՑՄԱՆ ԵՎ ՓՈՐՁԱՔՆՆՈՒԹՅԱՆ ՀԱՄԱՐ ԱՆՀՐԱԺԵՇՏ ՓԱՍՏԱԹՂԹԵՐԻ
1. ԴԵՂԻ ԳՐԱՆՑՄԱՆ ՀԱՄԱՐ ՊԱՀԱՆՋՎՈՂ ՓԱՍՏԱԹՂԹԵՐ
1. Հայտ` գրանցման դեպքի և դեղի վերաբերյալ տեղեկություններով.
2. Փաստաթղթերի փաթեթ (դոսյե)` համաձայն ԱյՍիԷյչ համընդհանուր տեխնիկական փաստաթղթի.
3. Այլ երկրի իրավասու մարմնի կողմից կամ ԱՀԿ նախաորակավորման ընթացքում կատարված փորձաքննության հաշվետվությունը և դրա մաս կազմող հաստատված սպեցիֆիկացիաների կամ որակի նորմատիվ փաստաթղթի ու կիրառման հրահանգների բնօրինակը և դրանց թարգմանված տարբերականները, եթե ռուսերեն կամ անգլերեն չեն (պարտադիր է պարզեցված ընթացակարգի դեպքում).
(3-րդ կետը լրաց. 28.11.24 N 1873-Ն)
4. Փորձաքննության համար սահմանված պետական տուրքի վճարման փաստը հավաստող փաստաթուղթը:
(4-րդ կետը խմբ. 28.11.24 N 1873-Ն)
2. ԴԵՂԻ ՎԵՐԱԳՐԱՆՑՄԱՆ ՀԱՄԱՐ ՊԱՀԱՆՋՎՈՂ ՓԱՍՏԱԹՂԹԵՐ
1. Հայտ՝ վերագրանցման և դեղի վերաբերյալ տեղեկություններով.
2. Դոսյեի Մոդուլ 1-ը` համաձայն ԱյՍիԷյչ համընդհանուր տեխնիկական փաստաթղթի.
3. Կողմնակի ազդեցությունների դիտարկման հաշվետվությունը` լիազոր մարմնի կողմից հաստատված ձևաչափով.
4. Փորձաքննության համար սահմանված պետական տուրքի վճարման փաստը հավաստող փաստաթուղթը:
(4-րդ կետը խմբ. 28.11.24 N 1873-Ն)
3. ՀԱՎԱՍՏԱԳՐԻ ԺԱՄԿԵՏԻ ԵՐԿԱՐԱՁԳՄԱՆ ՀԱՄԱՐ ՊԱՀԱՆՋՎՈՂ ՓԱՍՏԱԹՂԹԵՐ
1. Դիմում.
2. Փորձաքննության համար սահմանված պետական տուրքի վճարման փաստը հավաստող փաստաթուղթը:
(2-րդ կետը խմբ. 28.11.24 N 1873-Ն)
4. ՀԵՏԳՐԱՆՑՈՒՄԱՅԻՆ ՓՈՓՈԽՈՒԹՅՈՒՆՆԵՐԻ ՆԵՐԿԱՅԱՑՄԱՆ ԺԱՄԱՆԱԿ ՊԱՀԱՆՋՎՈՂ ՓԱՍՏԱԹՂԹԵՐ
1. Հայտ՝ նկարագրելով փոփոխության (փոփոխությունների) տեսակը՝ Եվրասիական տնտեսական հանձնաժողովի խորհրդի 2016 թվականի նոյեմբերի 3-ի N 78 որոշման թիվ 19 հավելվածի համաձայն.
(1-ին կետը լրաց. 28.11.24 N 1873-Ն)
2. Փոփոխության (փոփոխությունների) վերաբերյալ փաստաթղթեր, ներառելով՝ համապատասխան հիմնավորումները և (կամ) պարզաբանումները.
3. Փորձաքննության համար սահմանված պետական տուրքի վճարման փաստը հավաստող փաստաթուղթը:
(3-րդ կետը խմբ. 28.11.24 N 1873-Ն)
(հավելվածը լրաց., խմբ. 28.11.24 N 1873-Ն)
