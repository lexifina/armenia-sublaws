# Հավելված N 2 ՀՀ կառավարության 2006 թվականի հոկտեմբերի 5-ի N 1492-Ն որոշման
Ց Ա Ն Կ 5.8 ՄՎՏ-ԻՑ ԲԱՐՁՐ ԴՐՎԱԾՔԱՅԻՆ ՀԶՈՐՈՒԹՅԱՆ ՋԵՐՄԱՄԱՏԱԿԱՐԱՐՄԱՆ ՀԱՄԱԿԱՐԳԵՐԻ` ՆՈՐ ԿԱՌՈՒՑՎՈՂ ԵՎ ՎԵՐԱԿԱՌՈՒՑՎՈՂ ԷՆԵՐԳԱՏԵՂԱԿԱՅԱՆՔՆԵՐԻ ԳՈՐԾԱՐԿՄԱՆ ԵԶՐԱԿԱՑՈՒԹՅՈՒՆ ՏԱԼՈՒ ՀԱՄԱՐ ՊԱՀԱՆՋՎՈՂ ՏԵԽՆԻԿԱԿԱՆ ՓԱՍՏԱԹՂԹԵՐԻ (վերնագիրը փոփ. 23.08.07 N 944-Ն)
Ջերմատեղակայանքների սեփականատիրոջ (լիազոր անձի) գրավոր դիմումը լիազոր մարմին ջերմատեղակայանքները տեխնիկական ստուգման (ուսումնասիրության) ենթարկելու մասին
Տեխնիկական պայմանները (առաջադրանքը)
Ջերմատեղակայանքների փորձաքննություն, այդ թվում` բնապահպանական, անցած նախագիծը` կազմված լիցենզավորված կազմակերպության (անձի) կողմից
(պարբերությունն ուժը կորցրել է 31.10.13 N 1196-Ն)
Ջերմատեղակայանքների կազմում առկա 6 կՎ և բարձր լարման էլեկտրատեղակայանքների գործարկման եզրակացությունը
Ջերմատեղակայանքների` տեխնիկական կանոնակարգերով սահմանված փորձարկումների արձանագրությունները
Ջերմատեղակայանքների` Հայաստանի Հանրապետության կառավարության 2003 թվականի մայիսի 8-ի N 626-Ն որոշմամբ սահմանված օբյեկտը շահագործման ընդունող հանձնաժողովի ակտի պատճենը
(հավելվածը փոփ. 23.08.07 N 944-Ն, 31.10.13 N 1196-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
