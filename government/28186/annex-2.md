# Հավելված N 2 ՀՀ կառավարության 2006 թվականի հոկտեմբերի 5-ի N 1492-Ն որոշման
Ց Ա Ն Կ 5.8 ՄՎՏ-ԻՑ ԲԱՐՁՐ ԴՐՎԱԾՔԱՅԻՆ ՀԶՈՐՈՒԹՅԱՆ ՋԵՐՄԱՄԱՏԱԿԱՐԱՐՄԱՆ ՀԱՄԱԿԱՐԳԵՐԻ` ՆՈՐ ԿԱՌՈՒՑՎՈՂ ԵՎ ՎԵՐԱԿԱՌՈՒՑՎՈՂ ԷՆԵՐԳԱՏԵՂԱԿԱՅԱՆՔՆԵՐԻ ԳՈՐԾԱՐԿՄԱՆ ԵԶՐԱԿԱՑՈՒԹՅՈՒՆ ՏԱԼՈՒ ՀԱՄԱՐ ՊԱՀԱՆՋՎՈՂ ՏԵԽՆԻԿԱԿԱՆ ՓԱՍՏԱԹՂԹԵՐԻ (վերնագիրը փոփ. 23.08.07 N 944-Ն)
1. Ջերմատեղակայանքները գործարկմանը պատրաստ լինելու դեպքում դրանց սեփականատերը (լիազորված անձը) լիազոր մարմին է ներկայացնում՝
1) դիմում՝ ջերմատեղակայանքները տեխնիկական ստուգման ենթարկելու մասին.
2) տեխնիկական պայմանները (առաջադրանքը):
2. Ջերմատեղակայանքների տեխնիկական ստուգման ժամանակ դրանց սեփականատերը (լիազորված անձը) մասնագետ-տեսուչին է տրամադրում`
1) ջերմատեղակայանքների փորձաքննություն, այդ թվում` բնապահպանական, անցած նախագծի պատճենը` կազմված լիցենզավորված կազմակերպության (անձի) կողմից.
2) ջերմատեղակայանքների` տեխնիկական կանոնակարգերով սահմանված փորձարկումների արձանագրությունների պատճենները:
(հավելվածը փոփ. 23.08.07 N 944-Ն, 31.10.13 N 1196-Ն, խմբ. 10.09.15 N 1036-Ն)
