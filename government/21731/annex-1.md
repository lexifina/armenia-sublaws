# Հավելված ՀՀ կառավարության 2005 թվականի դեկտեմբերի 15-ի N 2296-Ն որոշման
Կ Ա Ր Գ բնապահպանության ԵՎ ընդերքի պետական ՏԵՍՈՒՉԻ ԿՈՂՄԻՑ ՖԻԶԻԿԱԿԱՆ ՈՒԺԻ, ՀԱՏՈՒԿ ՄԻՋՈՑՆԵՐԻ ԵՎ ԱՌԱՋԻՆ ԲՈՒԺՕԳՆՈՒԹՅՈՒՆ ՑՈՒՑԱԲԵՐԵԼՈՒ ՀՄՏՈՒԹՅՈՒՆ ՁԵՌՔ ԲԵՐԵԼՈՒ (վերնագիրը փոփ. 30.11.17 N 1588-Ն)
1. Սույն կարգով սահմանվում է «Բնապահպանական վերահսկողության մասին» Հայաստանի Հանրապետության օրենքով և այլ իրավական ակտերով սահմանված կարգով բնապահպանական վերահսկողական գործառույթներ իրականացնող բնապահպանության և ընդերքի պետական տեսուչների կողմից ֆիզիկական ուժի, հատուկ միջոցներ կրելու, պահելու, գործադրելու (կիրառելու) և առաջին բուժօգնություն ցուցաբերելու (այսուհետ` հատուկ պատրաստություն) նպատակով տեսական և գործնական հմտություններ ձեռք բերելու ընթացակարգը:
(1-ին կետը փոփ. 30.11.17 N 1588-Ն)
2. Հատուկ պատրաստության դասընթացները կազմակերպվում են` համաձայն Հայաստանի Հանրապետության բնապահպանության և ընդերքի տեսչական մարմնի ղեկավարի և Հայաստանի Հանրապետության ոստիկանության պետի համատեղ հաստատված ուսումնական տարեկան ծրագրերի, որոնք կազմվում են մինչև հաջորդ տարվա պետական բյուջեի ձևավորման հայտը ներկայացնելը:
(2-րդ կետը փոփ. 17.02.22 N 171-Ն)
3. Հատուկ պատրաստության դասընթացներին բնապահպանության և ընդերքի պետական տեսուչները մասնակցում են Հայաստանի Հանրապետության բնապահպանության և ընդերքի տեսչական մարմնի ղեկավարի կողմից հաստատված ցանկով, որը համապատասխան ուսումնական հաստատություն է ներկայացվում դասընթացներն սկսվելուց մեկ ամիս առաջ:
(3-րդ կետը փոփ. 30.11.17 N 1588-Ն, 17.02.22 N 171-Ն)
4. Սույն կարգի 3-րդ կետում նշված` Հայաստանի Հանրապետության բնապահպանության և ընդերքի տեսչական մարմնի ղեկավարի կողմից հաստատված ցանկում յուրաքանչյուր 20 դասաժամանոց ուսումնական ծրագրում ընդգրկվում են 5 բնապահպանական տեսուչ։
(4-րդ կետը փոփ. 17.02.22 N 171-Ն)
5. Սույն կարգի 3-րդ կետում նշված` Հայաստանի Հանրապետության բնապահպանության և ընդերքի տեսչական մարմնի ղեկավարի կողմից հաստատված ցանկում յուրաքանչյուր ուսումնական տարվա համար ընդգրկվում են բնապահպանության և ընդերքի պետական տեսուչների ընդհանուր թվի 1/3-ը։
(5-րդ կետը փոփ. 30.11.17 N 1588-Ն, 17.02.22 N 171-Ն)
6. Բնապահպանության և ընդերքի պետական տեսուչը համարվում է դասընթացները յուրացրած, եթե ուսումնական դասընթացների արդյունքում նրան տրվել է հատուկ պատրաստության դասընթացներն ավարտելը հաստատող փաստաթուղթ:
(6-րդ կետը փոփ. 30.11.17 N 1588-Ն)
7. Հատուկ պատրաստության դասընթացներն ավարտել հաստատող փաստաթուղթն ուժի մեջ է այն տալու օրվանից հաշված 3 տարի։
8. Հատուկ պատրաստության ուսումնական դասընթացներին բնապահպանության և ընդերքի պետական տեսուչի մասնակցության ժամանակահատվածը համարվում է աշխատանքային:
(8-րդ կետը փոփ. 30.11.17 N 1588-Ն)
(հավելվածը փոփ. 30.11.17 N 1588-Ն, 17.02.22 N 171-Ն)
