# Հավելված N 2 ՀՀ կառավարության 2011 թվականի հունիսի 2-ի N 787-Ն որոշման
Կ Ա Ր Գ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԲՆԱԿԱՎԱՅՐԵՐԻ` ԲԵՌՆԱՏԱՐ ԱՎՏՈՄՈԲԻԼՆԵՐԻ ԵՐԹԵՎԵԿՈՒԹՅՈՒՆՆ ԱՐԳԵԼՎԱԾ ՓՈՂՈՑՆԵՐՈՒՄ ԲԵՌՆԱՓՈԽԱԴՐՈՒՄՆԵՐԻ ԻՐԱԿԱՆԱՑՄԱՆ ՆՊԱՏԱԿՈՎ ԲԵՌՆԱՏԱՐ ԱՎՏՈՄՈԲԻԼՆԵՐԻ ԵՐԹԵՎԵԿՈՒԹՅՈՒՆԸ ԹՈՒՅԼԱՏՐՈՂ ԺԱՄԱՆԱԿԱՎՈՐ ԹՈՒՅԼՏՎՈՒԹՅՈՒՆ ՏԱԼՈՒ
1. Սույն կարգով սահմանվում է Հայաստանի Հանրապետության բնակավայրերի` բեռնատար ավտոմոբիլների երթևեկությունն արգելված փողոցներում բեռնափոխադրումների իրականացման նպատակով բեռնատար ավտոմոբիլների երթևեկությունը թույլատրող ժամանակավոր թույլտվություն (այսուհետ` ժամանակավոր թույլտվություն) տալու ընթացակարգը:
2. Ժամանակավոր թույլտվություն ստանալու համար ավտոմոբիլի սեփականատերը (լիազորված անձը) Էլեկտրոնային հարցումների միասնական հարթակի միջոցով (այսուհետ՝ հարթակ) Հայաստանի Հանրապետության ներքին գործերի նախարարության ոստիկանության համայնքային ոստիկանության գլխավոր վարչություն (այսուհետ՝ համայնքային ոստիկանություն) է ներկայացնում դիմում, որում նշվում են սեփականատիրոջ ազգանունը, անունը, հայրանունը, ավտոմոբիլի մակնիշը, հաշվառման համարանիշը, բեռնափոխադրում իրականացնելու նպատակը, ժամկետը, վայրը` սկզբնակետն ու վերջնակետը, երթուղին, ինչպես նաև ժամանակավոր թույլտվություն ստանալը հիմնավորող այլ տեղեկություններ:
(2-րդ կետը փոփ. 24.10.24 N 1686-Ն, լրաց. 12.06.25 N 775-Ն)
3. Դիմումին կից ներկայացվում են ավտոմոբիլի հաշվառման վկայագրի պատճենը, ինչպես նաև այլ փաստաթղթերի (եթե այդպիսիք առկա են) պատճենները, որոնք հիմնավորում են բեռնատար ավտոմոբիլների երթևեկությունն արգելված փողոցներում բեռնափոխադրում իրականացնելու անհրաժեշտությունը:
(3-րդ կետը փոփ. 12.06.25 N 775-Ն)
4. Պահանջվող տեղեկությունները կամ փաստաթղթերը թերի ներկայացնելու դեպքում անձին տրվում է 5-օրյա ժամկետ` փաստաթղթերն ամբողջությամբ ներկայացնելու համար:
5. Դիմումն ստանալու օրվանից 3 աշխատանքային օրվա ընթացքում համայնքային ոստիկանությունը կատարում է հետևյալ գործողություններից որևէ մեկը`
1) տալիս է ժամանակավոր թույլտվություն.
2) ընդունում է որոշում ժամանակավոր թույլտվություն տալը մերժելու մասին:
(5-րդ կետը փոփ. 24.10.24 N 1686-Ն)
6. Եթե դիմողի առաջարկած երթուղով կամ ժամանակահատվածում բեռնափոխադրման իրականացման նպատակով ժամանակավոր թույլտվություն տալը հնարավոր չէ, ապա համայնքային ոստիկանությունը դրա մասին տեղեկացնում է դիմողին` նրան առաջարկելով նոր երթուղի կամ այլ ժամանակահատված:
(6-րդ կետը փոփ. 24.10.24 N 1686-Ն)
7. Ժամանակավոր թույլտվություն տալը մերժվում է, եթե`
1) բեռնափոխադրման ժամանակ կարող է վտանգվել ճանապարհային երթևեկության մասնակիցների կյանքն ու առողջությունը կամ կարող է դադարեցվել կամ սահմանափակվել (առաջանալ խցանումներ) ճանապարհային երթևեկությունը.
2) անձը սույն կարգով սահմանված ժամկետում չի ներկայացնում կամ թերի է ներկայացնում պահանջվող տեղեկությունները կամ փաստաթղթերը.
3) դիմողի առաջարկած երթուղով կամ ժամանակահատվածում բեռնափոխադրման իրականացման նպատակով ժամանակավոր թույլտվություն տալը հնարավոր չէ, և նա հրաժարվում է համայնքային ոստիկանության կողմից առաջարկված երթուղով կամ այլ ժամանակահատվածում փոխադրման իրականացման նպատակով ժամանակավոր թույլտվություն ստանալուց.
4) բեռնափոխադրումները կարող են իրականացվել առանց ժամանակավոր թույլտվություն ստանալու` այլ երթուղով:
(7-րդ կետը փոփ. 24.10.24 N 1686-Ն)
8. Տրված ժամանակավոր թույլտվությունները գրանցվում են Հայաստանի Հանրապետության բնակավայրերի` բեռնատար ավտոմոբիլների երթևեկությունն արգելված փողոցներում բեռնափոխադրումների իրականացման նպատակով բեռնատար ավտոմոբիլների երթևեկության ժամանակավոր թույլտվությունների հաշվառման էլեկտրոնային մատյանում:
(8-րդ կետը լրաց. 12.06.25 N 775-Ն)
9. (կետն ուժը կորցրել է 12.06.25 N 775-Ն)
10. Յուրաքանչյուր ամսվա մինչև 5-ը համայնքային ոստիկանությունը Հայաստանի Հանրապետության համայնքներին տեղեկատվություն է տրամադրում իրենց տարածքներում երթևեկելու համար նախորդ ամսվա ընթացքում 15 օրվանից ավելի ժամկետով տրված ժամանակավոր թույլտվությունների մասին:
(10-րդ կետը փոփ. 24.10.24 N 1686-Ն, 12.06.25 N 775-Ն)
11. Սույն կարգի 5-րդ կետի 2-րդ ենթակետով նախատեսված որոշման ձևը հաստատում է Հայաստանի Հանրապետության ներքին գործերի նախարարության ոստիկանության պետը:
(11-րդ կետը փոփ. 24.10.24 N 1686-Ն, 12.06.25 N 775-Ն)
12․ Թերի ներկայացված փաստաթղթերն ամբողջությամբ ներկայացնելու վերաբերյալ իրազեկումը, նոր երթուղի կամ այլ ժամանակահատված առաջարկելու վերաբերյալ իրազեկումը, ժամանակավոր թույլտվությունը կամ ժամանակավոր թույլտվություն տալը մերժելու մասին որոշումը համայնքային ոստիկանությունն ուղարկում է ավտոմոբիլի սեփականատիրոջ (լիազորված անձի) կողմից դիմումի մեջ նշված էլեկտրոնային փոստի հասցեին։
(12-րդ կետը լրաց. 12.06.25 N 775-Ն)
(հավելվածը փոփ. 24.10.24 N 1686-Ն, լրաց., փոփ. 12.06.25 N 775-Ն )
