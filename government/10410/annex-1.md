# Հավելված ՀՀ կառավարության 2002 թվականի նոյեմբերի 28-ի N 2018-Ն որոշման
Ց Ա Ն Կ
ՈՍՏԻԿԱՆՈՒԹՅԱՆ ԳԼԽԱՎՈՐ, ԱՎԱԳ ԵՎ ԿՐՏՍԵՐ ԽՄԲԵՐԻ ՊԱՇՏՈՆՆԵՐԻՆ ՀԱՎԱՍԱՐԵՑՎԱԾ ՊԱՇՏՈՆՆԵՐԻ
1. Ոստիկանության գլխավոր խմբի պաշտոններ
Վարչության պետ, ոստիկանության Երևան քաղաքի և մարզային վարչության պետ | - | ոստիկանության ուսումնական հաստատության պետ գլխավոր ոստիկանապետի խորհրդական
Վարչության պետի տեղակալ | - | ոստիկանության ուսումնական հաստատության պետի տեղակալ ոստիկանության զորքերի հրամանատարի տեղակալ գլխավոր ոստիկանապետի օգնական
Բաժնի պետ | - | գնդի հրամանատար ոստիկանության ուսումնական հաստատության ֆակուլտետի, ամբիոնի պետ, պրոֆեսոր, պրոֆեսորի տեղակալ, դոցենտ, ավագ դասախոս
2. Ոստիկանության ավագ խմբի պաշտոններ
Բաժնի պետի տեղակալ | - | գնդի հրամանատարի տեղակալ առանձին գումարտակի հրամանատար
Բաժանմունքի պետ | - | գլխավոր ոստիկանապետի տեղակալի օգնական գումարտակի հրամանատար ոստիկանության զորքերի ծառայության պետ առանձին գումարտակի հրամանատարի տեղակալ
Բաժանմունքի պետի տեղակալ, հատուկ կարևորագույն գործերով ավագ քննիչ, հատուկ կարևորագույն գործերով ավագ օպերլիազոր, հատուկ հանձնարարություններով ավագ տեսուչ | - | գումարտակի հրամանատարի տեղակալ ոստիկանության ուսումնական հաստատության կուրսի պետ դասախոս առանձին վաշտի հրամանատար
Ավագ տեսուչ, ավագ քննիչ, ավագ օպերլիազոր | - | գլխավոր ոստիկանապետի ռեֆերենտ գնդի հրամանատարի օգնական ոստիկանության ուսումնական հաստատության կուրսի պետի տեղակալ հերթապահ մասի պետի օգնական ավագ փորձագետ ավագ սպա ավագ ինժեներ ավագ իրավախորհրդատու ավագ պետավտոտեսուչ ավագ գիտաշխատող վաշտի հրամանատար վաշտի հրամանատարի տեղակալ
Տեսուչ, քննիչ, օպերլիազոր | - | դասակի հրամանատար դասակի հրամանատարի տեղակալ ակումբի պետ կապի պետ իրավախորհրդատու պետավտոտեսուչ փորձագետ գիտաշխատող սպա կաբինետի ղեկավար ինժեներ լաբորատորիայի ղեկավար
3. Ոստիկանության կրտսեր խմբի պաշտոններ
Կրտսեր տեսուչ | - | դասակի հրամանատարի օգնական ճանապարհապարեկային ծառայության տեսուչ ավագ օպերատոր հրաձգարանի պետ կապի հանգույցի պետ ռադիոկայանի պետ դեղատան պետ պահակապետ վերակարգի պետ ավագ տեխնիկ ավագ վարպետ
Ավագ ոստիկան | - | հրահանգիչ հատուկ կապի մասնագետ հերթապահի օգնական ջոկի հրամանատար ավագ պահակապետի օգնական բուժակ
Ոստիկան | - | օպերատոր վարորդ հրաձիգ
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
