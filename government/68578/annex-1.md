# Հավելված ՀՀ կառավարության 2011 թվականի մայիսի 26-ի N 740-Ն որոշման
Կ Ա Ր Գ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՖԻՆԱՆՍՆԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԿՈՂՄԻՑ ՊԵՏԱԿԱՆ ԿԱՐԻՔՆԵՐԻ ՀԱՄԱՐ ԱՊՐԱՆՔՆԵՐԻ ԿՈՂՄՆՈՐՈՇԻՉ ԳՆԵՐԻ ՍԱՀՄԱՆՄԱՆ ՆՊԱՏԱԿՈՎ ՏԵՂԵԿՈՒԹՅՈՒՆՆԵՐԻ ՀԱՎԱՔԱԳՐՄԱՆ (վերնագիրը փոփ. 16.02.17 N 138-Ն)
1. Սույն կարգով սահմանվում է Հայաստանի Հանրապետության ֆինանսների նախարարության (այսուհետ` նախարարություն) կողմից պետական կարիքների համար ապրանքների կողմնորոշիչ գների սահմանման նպատակով Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով գրանցված իրավաբանական անձանցից, անհատ ձեռնարկատերերից տեղեկությունների հավաքագրումը:
(1-ին կետը փոփ. 16.02.17 N 138-Ն)
2. Նախարարությունն ապրանքների կողմնորոշիչ գներն ու սակագները սահմանում է իրավաբանական անձանց, անհատ ձեռնարկատերերի կողմից կամավոր հիմունքներով տրամադրված, ինչպես նաև պետական մարմիններից ստացված տեղեկությունների ու սպառողական շուկայի ուսումնասիրության հիման վրա:
(2-րդ կետը փոփ. 16.02.17 N 138-Ն)
3. Տեղեկությունները հավաքագրվում են սույն կարգի 2-րդ կետում նշված սուբյեկտներից` ընտրանքային կարգով` ելնելով գործունեության առանձին տեսակներից:
4. Տեղեկություններ ստանալու համար գրավոր հարցում է ուղարկվում տեղեկություններ տրամադրող սուբյեկտներին:
5. Նախարարության կողմից ընդունվում են տեղեկություն տրամադրող սուբյեկտի ղեկավարի կամ վերջինիս լիազորած անձի կողմից ստորագրված կամ տեղեկություն տրամադրող սուբյեկտի կայքում տեղադրված գնացուցակները:
(5-րդ կետը լրաց. 25.04.13 N 423-Ն, փոփ. 16.02.17 N 138-Ն)
6. Այն դեպքում, երբ գնացուցակները կազմվում են սպառողական շուկան ուսումնասիրելու արդյունքում, դրանք ստորագրվում են սպառողական շուկան ուսումնասիրող, նախարարության գների ուսումնասիրման և վերլուծության գործակալության (այսուհետ՝ գործակալություն) կողմից ստեղծված հանձնաժողովի կողմից, ինչպես նաև հաստատվում գործակալության պետի կողմից: Հանձնաժողովի արձանագրությունում նշվում են ուսումնասիրության անցկացման ու կազմման ամսաթվերը, ինչպես նաև սպառողական շուկայի օբյեկտների գտնվելու վայրերը:
(6-րդ կետը լրաց. 25.04.13 N 423-Ն, փոփ. 16.02.17 N 138-Ն)
7. Նախարարությունը գնացուցակներն ընդունում է առձեռն, փոստով, էլեկտրոնային փոստով, ֆաքսով:
(7-րդ կետը փոփ. 16.02.17 N 138-Ն)
8. Սույն կարգով չնախատեսված եղանակով ստացված փաստաթղթերը նախարարության կողմից վերլուծությունների կատարման հիմք չեն:
(8-րդ կետը փոփ. 16.02.17 N 138-Ն)
