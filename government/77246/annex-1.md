# Հավելված N 1 ՀՀ կառավարության 2012 թվականի հուլիսի 19-ի N 899-Ն որոշման
Կ Ա Ր Գ
ԲՅՈՒՋԵՏԱՅԻՆ ԳՈՐԾԸՆԹԱՑԻ ՇՐՋԱՆԱԿՆԵՐՈՒՄ ՇԱՀՈՒԹԱԲԱԺԻՆՆԵՐԻ ԳԾՈՎ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՊԵՏԱԿԱՆ ԲՅՈՒՋԵԻ ՄՈՒՏՔԵՐԻ ԵՎ ԴՐԱՆՑ ԵՌԱՄՍՅԱԿԱՅԻՆ ՀԱՄԱՄԱՍՆՈՒԹՅՈՒՆՆԵՐԻ ԾՐԱԳՐԱՎՈՐՄԱՆ
1. Սույն կարգով կարգավորվում են բյուջետային գործընթացի շրջանակներում ընթացիկ (կանխատեսումների կատարման) տարվան հաջորդող երեք տարվա ընթացքում (այսուհետ` միջնաժամկետ հեռանկար) պետական մասնակցությամբ առևտրային կազմակերպությունների կողմից Հայաստանի Հանրապետության պետական բյուջե վճարման ենթակա շահութաբաժինների չափերի, ինչպես նաև տարեկան շահութաբաժինների եռամսյակային համամասնությունների ծրագրավորման հարաբերությունները:
2. 50 տոկոս և ավելի պետական մասնակցությամբ բոլոր առևտրային կազմակերպությունները (այսուհետ` պետական կազմակերպություններ) մինչև յուրաքանչյուր ընթացիկ տարվան նախորդող տարվա դեկտեմբերի 15-ը բաժնետոմսերի կառավարման լիազորություն ունեցող պետական մարմին (այսուհետ` լիազորված մարմին) են ներկայացնում միջնաժամկետ հեռանկարում այդ կազմակերպությունների կողմից Հայաստանի Հանրապետության պետական բյուջե վճարման ենթակա շահութաբաժինների կանխատեսումային չափերը` համաձայն Հայաստանի Հանրապետության կառավարության 2012 թվականի հուլիսի 19-ի N 899-Ն որոշման (այսուհետ՝ որոշում) N 2 հավելվածի ձևաչափի, կամ՝ տեղեկատվություն շահութաբաժիններ չվճարելու պատճառների (ֆինանսատնտեսական հիմքերի կամ օրենսդրական սահմանափակումների) մասին: Մինչև 50 տոկոս պետական մասնակցությամբ առևտրային կազմակերպությունները (այսուհետ` ոչ պետական կազմակերպություններ) միջնաժամկետ հեռանկարում պետական բաժնեմասին համապատասխան Հայաստանի Հանրապետության պետական բյուջե վճարման ենթակա շահութաբաժինների տարեկան կանխատեսումները սույն կետում նշված ժամկետում լիազորված մարմին են ներկայացնում տեղեկատվության ձևով` հիմնավորելով շահութաբաժինների կանխատեսվող չափերը կամ շահութաբաժիններ չվճարելու պատճառները:
3. Միջնաժամկետ հեռանկարում պետական կազմակերպությունների կողմից Հայաստանի Հանրապետության պետական բյուջե վճարման ենթակա շահութաբաժինների տարեկան չափերը կանխատեսվում են ըստ տարեկան շահութաբաժինների հաշվարկման բազայի բաղադրիչների (Հայաստանի Հանրապետության կառավարության 2011 թվականի մարտի 3-ի N 202-Ն որոշման N 1 հավելվածի 7-րդ և 8-րդ կետերով նախատեսված) և դրանց վրա ազդող հիմնական գործոնների վերլուծության ու գնահատման արդյունքների: Այդ թվում`
1) տարեկան շահութաբաժնի հաշվարկման բազայի հիմնական բաղադրիչի (զուտ շահույթը (վնասը) շահութահարկի գծով ծախսի նվազեցումից հետո) մեծությունը կանխատեսվող տարիներից յուրաքանչյուրի համար գնահատվում է` ելնելով ընթացիկ տարվա ծրագրված ցուցանիշի ակնկալվող կատարողականի մեծությունից, ընթացիկ և դրան նախորդող երեք տարվա զուտ շահույթի (վնասի) փաստացի աճի (նվազման) դինամիկայից և ընթացիկ տարվան հաջորդող տարիներին պետական կազմակերպության գործունեության վրա ազդող հիմնական գործոնների (առաջարկի և պահանջարկի, արտադրանքի ինքնարժեքի, իրացման գնի, ծավալի փոփոխություններ և այլն) հնարավոր ազդեցությունից (օրինակ, 2013-2015 թվականների միջնաժամկետ ծախսերի ծրագրի (այսուհետ՝ ՄԺԾԾ) շրջանակներում կատարվող կանխատեսումներում հարկավոր է հաշվի առնել զուտ շահույթի (վնասի) 2012 թվականի ծրագրված մեծությունը և զուտ շահույթի (վնասի) փաստացի աճի (նվազման) 2009-2012 թվականների դինամիկան և 2013-2015 թվականների առանձին գործոնների հնարավոր ազդեցությունը).
2) յուրաքանչյուր տարվա վերջի դրությամբ զուտ շահույթին ավելացումները (Հայաստանի Հանրապետության կառավարության 2006 թվականի հունիսի 22-ի N 1238-Ն որոշման 4-րդ կետով հաստատված` ծախսերի առավելագույն թույլատրելի սահմանաչափերը գերազանցող գումարները, նույն որոշման 6-րդ կետով սահմանված ծախսերը, որոնք պետք է իրականացվեն շահութաբաժնի հաշվարկումից հետո պետական կազմակերպության տրամադրության տակ մնացող զուտ շահույթի հաշվին) միջնաժամկետ հեռանկարի կանխատեսվող տարիներից յուրաքանչյուրի համար գնահատվում են` ելնելով ընթացիկ տարվան նախորդող երեք տարվա դրանց փաստացի աճի (նվազման) դինամիկայից.
3) միջնաժամկետ հեռանկարի կանխատեսվող յուրաքանչյուր տարվան նախորդող տարվա վերջի դրությամբ կուտակվող վնասների կանխատեսվող չափերը գնահատվում են` ելնելով ընթացիկ (ծրագրված) և դրան նախորդող երեք տարվա վերջի դրությամբ կուտակված վնասների աճի (նվազման) դինամիկայից և այդ վնասների նվազեցման համար պետական կազմակերպության կողմից նախատեսված միջոցառումների (գործոնների) իրականացման ծրագրերից.
4) Հայաստանի Հանրապետության կառավարության 2011 թվականի մարտի 3-ի N 202-Ն որոշման N 1 հավելվածի 8-րդ կետով նախատեսված շահութաբաժնի հաշվարկման բազայի վերանայումները կանխատեսվում են` ելնելով կանխատեսվող տարվան նախորդող 5 տարում (այդ թվում` որոշման N 2 հավելվածով նախատեսված` ընթացիկ և ընթացիկ տարվան նախորդող եռամյա ժամանակահատվածում) վնասների շարունակական կուտակման և կանխատեսվող տարվա զուտ շահույթին ավելացումների և տարվա վերջին կուտակվող վնասի դրական տարբերության առկայությունը պայմանավորող գործոնների հնարավոր ազդեցությունից (չափերից).
5) (ենթակետն ուժը կորցրել է 04.08.22 N 1200-Ն)
(3-րդ կետը փոփ. 04.08.22 N 1200-Ն)
4. Շահութաբաժինների հաշվարկման բազայի բաղադրիչների վրա ազդող գործոնների գնահատման արդյունքների դինամիկայի էական (կտրուկ) փոփոխությունների հիմնական պատճառները (պարզաբանումները) պետք է ներկայացվեն որոշման N 2 հավելվածի համապատասխան սյունակում:
5. Լիազորված մարմինները քննարկում (անհրաժեշտության դեպքում` ճշգրտում) և մինչև յուրաքանչյուր ընթացիկ տարվա հունվարի 15-ը որոշման N 3 հավելվածի ձևաչափի համաձայն Հայաստանի Հանրապետության ֆինանսների նախարարություն (այսուհետ` նախարարություն) են ներկայացնում իրենց համակարգի պետական և ոչ պետական կազմակերպությունների կողմից միջնաժամկետ հեռանկարում Հայաստանի Հանրապետության պետական բյուջե վճարման ենթակա շահութաբաժինների չափերի կանխատեսման ամփոփ արդյունքները` դրանց կցելով համակարգի յուրաքանչյուր պետական կազմակերպության համար որոշման N 2 հավելվածի ձևաչափով կազմված կանխատեսումները, իսկ ոչ պետական կազմակերպությունների համար` սույն հավելվածի 2-րդ կետով նախատեսված տեղեկատվությունը:
6. Լիազորված մարմինների կողմից իրենց համակարգի պետական կազմակերպությունների շահութաբաժինների տարեկան կանխատեսվող չափերի վերանայման (ճշգրտման) համար հիմք են տվյալ ճյուղի զարգացման ռազմավարությունը (զարգացման տեմպեր, պետական կազմակերպությունների օպտիմալացում, մասնավորեցում, իրականացվող պետական ներդրումային ծրագրեր և այլն), միջպետական համաձայնագրերի առկայությունը, շուկայական կոնյունկտուրայի ճյուղային միտումները և այլն:
7. Նախարարությունը լիազորված մարմինների կողմից ներկայացված ամփոփ կանխատեսումներն ընդունում է որպես հիմք կամ լիազորված մարմիններին առաջարկում է պետական կազմակերպությունների մասով վերանայել (ճշգրտել) դրանք:
8. Նախարարությունը կարող է առաջարկել վերանայել (ճշգրտել) ամփոփ կանխատեսումները` ելնելով լիազորված մարմինների համակարգի պետական և ոչ պետական կազմակերպությունների կողմից ընթացիկ տարվան նախորդող 3 տարվա ընթացքում`
1) շահութաբաժինների գծով կանխատեսված և տարեկան ընդհանուր ժողովների որոշումներով հաստատված չափերի տարբերություններից.
2) շահութաբաժինների գծով առկա և դեռևս չմարված պարտավորությունների չափերից.
3) Հայաստանի Հանրապետության օրենսդրությամբ սահմանված ժամկետներում շահութաբաժինների գծով առաջացած պարտավորությունների փաստացի կատարման դինամիկայից.
4) զուտ ակտիվների և կանոնադրական (բաժնեհավաք) կապիտալների հարաբերակցության փոփոխություններից:
9. Նախարարությունը, ամփոփելով ՄԺԾԾ-ի և դրա առաջին տարվա Հայաստանի Հանրապետության պետական բյուջեի նախագծերի հիմքում դրվող շահութաբաժինների գծով բյուջետային մուտքերի ծրագրված (կանխատեսվող) չափերի մասին տեղեկատվությունը, Հայաստանի Հանրապետության բյուջետային օրենսդրությամբ սահմանված ժամկետներում և կարգով այն ներառում է ՄԺԾԾ-ի (ըստ տարիների` մեկ թվով) և դրա առաջին տարվա Հայաստանի Հանրապետության պետական բյուջեի նախագծերում:
10. Պետական կազմակերպությունները, հիմք ընդունելով նախարարության առաջարկները, ինչպես նաև ընթացիկ տարում շահութաբաժինների հաշվարկման բազայի բաղադրիչների վրա ազդող հիմնական գործոնների փոփոխությունների վերլուծության արդյունքները, մինչև ընթացիկ տարվա հունիսի 15-ը վերանայում (ճշգրտում) և որոշման N 2 հավելվածի ձևաչափով կրկին լիազորված մարմին են ներկայացնում միջնաժամկետ հեռանկարի առաջին տարվա (անհրաժեշտության դեպքում` նաև 2-րդ և 3-րդ տարիների) ընթացքում Հայաստանի Հանրապետության պետական բյուջե վճարման ենթակա շահութաբաժնի ճշգրտված կանխատեսումները կամ համապատասխան տեղեկատվությամբ վերահաստատում են սույն հավելվածի 2-րդ կետի համաձայն ներկայացված կանխատեսումները: Ոչ պետական կազմակերպությունները սույն կետում նշված ժամկետում լիազորված մարմնին են ներկայացնում տեղեկատվություն միջնաժամկետ հեռանկարի առաջին տարվա (անհրաժեշտության դեպքում` նաև 2-րդ և 3-րդ տարիների) ընթացքում Հայաստանի Հանրապետության պետական բյուջե վճարման ենթակա շահութաբաժնի ճշգրտված կանխատեսումների կամ սույն հավելվածի 2-րդ կետի համաձայն ներկայացված կանխատեսումներն անփոփոխ թողնելու մասին:
11. Լիազորված մարմինները քննարկում (անհրաժեշտության դեպքում` ճշգրտում) և մինչև ընթացիկ տարվա հուլիսի 1-ը որոշման N 3 հավելվածի ձևաչափով նախարարություն են ներկայացնում միջնաժամկետ հեռանկարի առաջին տարվա (անհրաժեշտության դեպքում` նաև 2-րդ և 3-րդ տարիների) ընթացքում Հայաստանի Հանրապետության պետական բյուջե վճարման ենթակա շահութաբաժնի տարեկան գումարների կանխատեսումները` դրանց կցելով ըստ պետական և ոչ պետական կազմակերպությունների կանխատեսումների վերանայման հիմքերը (պետական կազմակերպությունների մասով` որոշման N 2 հավելվածի ձևաչափով, իսկ ոչ պետական կազմակերպությունների մասով` համապատասխան տեղեկատվություն), կամ համապատասխան տեղեկատվությամբ վերահաստատում են դրանք:
12. Նախարարությունը, ամփոփելով միջնաժամկետ հեռանկարի առաջին տարվա Հայաստանի Հանրապետության պետական բյուջեի նախագծի հիմքում դրվող շահութաբաժինների գծով բյուջետային մուտքերի ճշգրտված չափերի մասին տեղեկատվությունը, Հայաստանի Հանրապետության բյուջետային օրենսդրությամբ սահմանված ժամկետներում և կարգով այն ներառում է Հայաստանի Հանրապետության պետական բյուջեի նախագծում:
13. Նախարարությունը Հայաստանի Հանրապետության պետական բյուջե տարեկան շահութաբաժինների եռամսյակային մուտքերի համամասնությունները կանխատեսում է՝ գնահատելով հետևյալ գործոնների հնարավոր ազդեցությունն ըստ եռամսյակների՝
1) առաջին և երկրորդ եռամսյակներ` տարեկան շահութաբաժինների կանխավճարներ, միջանկյալ շահութաբաժինների վճարում, նախորդ տարիների պարտավորությունների մարում.
2) երրորդ եռամսյակ` տարեկան շահութաբաժինների գծով պարտավորությունների հիմնական մասի մարում.
3) չորրորդ եռամսյակ` տարեկան շահութաբաժինների գծով առկա և դեռևս չմարված պարտավորությունների կատարում, մուտքեր պարտավորությունների ուշացման դիմաց հաշվարկված օրական տոկոսներից:
(հավելվածը փոփ. 04.08.22 N 1200-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար | Դ. Սարգսյան
