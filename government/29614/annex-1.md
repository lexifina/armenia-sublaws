# Հավելված ՀՀ կառավարության 2006 թվականի դեկտեմբերի 7-ի N 1739-Ն որոշման
Կ Ա Ր Գ ԹԱՓՈՆՆԵՐԻ ՊԵՏԱԿԱՆ ՀԱՇՎԱՌՄԱՆ
1. Սույն կարգով կանոնակարգվում են թափոնների պետական հաշվառման հետ կապված հարաբերությունները:
1.1. Սույն կարգում օգտագործված հասկացությունները կիրառվում են «Թափոնների մասին» օրենքով սահմանված իմաստով։
(1.1-ին կետը լրաց. 14.05.26 N 670-Ն)
2. Թափոնների պետական հաշվառման հիմնական նպատակը թափոնների գոյացման, պահման, օգտահանման կամ հեռացման ծավալների վերաբերյալ տեղեկատվական բանկի ստեղծումն է, որն անհրաժեշտ է թափոնների պետական կադաստրի ստեղծման և վարման համար:
(2-րդ կետը լրաց. 14.05.26 N 670-Ն)
3. Պետական հաշվառման ենթակա են Հայաստանի Հանրապետության տարածքում առաջացող, պահվող, օգտահանվող կամ հեռացվող արտադրության (այդ թվում` ընդերքօգտագործման) և սպառման թափոնների ծավալները:
(3-րդ կետը փոփ. 10.09.15 N 1042-Ն, լրաց. 14.05.26 N 670-Ն)
4. Թափոնների պետական հաշվառումն իրականացնում է Հայաստանի Հանրապետության շրջակա միջավայրի նախարարությունը (այսուհետ` լիազոր մարմին)` սույն կարգի համաձայն:
(4-րդ կետը փոփ. 10.10.19 N 1442-Ն)
5. Թափոնների պետական հաշվառումն իրականացվում է վտանգավոր թափոններ առաջացնող և թափոնների (արտադրության (այդ թվում` ընդերքօգտագործման) և սպառման) պահում, օգտահանում կամ հեռացում իրականացնող իրավաբանական անձանց և անհատ ձեռնարկատերերի կողմից ներկայացված Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով հաստատված` «Թափոնների առաջացման, պահման, օգտահանման և հեռացման մասին» N 1 ձևի-թափոն տարեկան վարչական վիճակագրական հաշվետվությունների (այսուհետ` վարչական վիճակագրական հաշվետվություններ) տվյալների հիման վրա:
(5-րդ կետը փոփ. 10.09.15 N 1042-Ն, 14.05.26 N 670-Ն)
6. Վարչական վիճակագրական հաշվետվությունները կազմվում են «Շրջակա միջավայրի կառավարման ոլորտի թվային ծառայությունների հարթակ» էլեկտրոնային համակարգի (այսուհետ՝ էլեկտրոնային հարթակ) միջոցով՝ լիազոր մարմնի կողմից հաստատված ձևին և լրացման հրահանգին համապատասխան և ներկայացվում լիազոր մարմին:
(6-րդ կետը փոփ. 24.07.25 N 1001-Ն, լրաց. 14.05.26 N 670-Ն)
7. Վարչական վիճակագրական հաշվետվությունները ներկայացվում են մինչև հաշվետու տարվան հաջորդող տարվա փետրվարի 25-ը:
8. Պաշտոնական վիճակագրության մշակող, արտադրող, տարածող և համակարգող մարմնին, ինչպես նաև բնապահպանական նորմերի պահպանման ու կատարման նկատմամբ վերահսկողություն իրականացնող տեսչական մարմնին, իրենց օրենսդրական գործառույթներն իրականացնելու նպատակով, հասանելիություն է տրվում էլեկտրոնային հարթակի՝ վարչական վիճակագրական հաշվետվությունների ներկայացման բաժնում գեներացվող և պահվող տվյալներին։
(8-րդ կետը լրաց. 14.05.26 N 670-Ն)
(հավելվածը փոփ. 10.09.15 N 1042-Ն, 10.10.19 N 1442-Ն, 24.07.25 N 1001-Ն, լրաց., փոփ. 14.05.26 N 670-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
