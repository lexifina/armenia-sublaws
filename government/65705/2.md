2.1) Հայաստանի Հանրապետության մակերևութային ջրային մարմինների կարգավիճակների ջրի որակի նորմերը՝ ըստ կենսաբանական տարրերի՝ համաձայն N 2.1 հավելվածի.
3) Հյուսիսային ջրավազանային կառավարման տարածքի Դեբեդ գետի ավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 3 հավելվածի.
4) Հյուսիսային ջրավազանային կառավարման տարածքի Աղստև գետի ավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 4 հավելվածի.
5) Հյուսիսային ջրավազանային կառավարման տարածքի Կուր գետի փոքր վտակների ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 5 հավելվածի.
6) Ախուրյանի ջրավազանային կառավարման տարածքի Ախուրյան գետի ավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 6 հավելվածի.
7) Ախուրյանի ջրավազանային կառավարման տարածքի Մեծամոր գետի ավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 7 հավելվածի.
8) Հրազդանի ջրավազանային կառավարման տարածքի Քասախ գետի ավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 8 հավելվածի.
9) Հրազդանի ջրավազանային կառավարման տարածքի Մարմարիկ գետի ավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 9 հավելվածի.
10) Հրազդանի ջրավազանային կառավարման տարածքի Հրազդան գետի ավազանի (Գեղամավանի դերիվացիոն ջրանցքի) գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 10 հավելվածի.
11) Հրազդանի ջրավազանային կառավարման տարածքի Հրազդան գետի ավազանի (միջին ներքին հոսանքի) գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 11 հավելվածի.
12) Սևանի ջրավազանային կառավարման տարածքի Ձկնագետ գետի ավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 12 հավելվածի.
12.1) Սևանի ջրավազանային կառավարման տարածքի Սևանա լճի ջրերի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 12.1 հավելվածի.
12.2) Սևանի ջրավազանային կառավարման տարածքի Գավառագետ գետի ավազանի գետերի ջրերի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 12.2 հավելվածի.
13) Սևանի ջրավազանային կառավարման տարածքի Մասրիկ գետի ավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 13 հավելվածի.
14) Սևանի ջրավազանային կառավարման տարածքի Սոթք գետի ավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 14 հավելվածի.
15) Սևանի ջրավազանային կառավարման տարածքի Վարդենիսի լեռներից սկսվող (Կարճաղբյուրի, Մարտունու, Վարդենիսի) գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 15 հավելվածի.
16) Սևանի ջրավազանային կառավարման տարածքի Գեղամա լեռներից սկսվող (Արգիճի) գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 16 հավելվածի.
17) Արարատյան ջրավազանային կառավարման տարածքի Ազատ գետի գետավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 17 հավելվածի.
18) Արարատյան ջրավազանային կառավարման տարածքի Վեդի գետի գետավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 18 հավելվածի.
19) Արարատյան ջրավազանային կառավարման տարածքի Արփա գետի գետավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 19 հավելվածի.
20) Հարավային ջրավազանային կառավարման տարածքի Որոտան գետի գետավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 20 հավելվածի.
21) Հարավային ջրավազանային կառավարման տարածքի Սիսիան գետի գետավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 21 հավելվածի.
22) Հարավային ջրավազանային կառավարման տարածքի Գորիս գետի գետավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 22 հավելվածի.
23) Հարավային ջրավազանային կառավարման տարածքի Ողջի գետի գետավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 23 հավելվածի.
24) Հարավային ջրավազանային կառավարման տարածքի Գեղի գետի գետավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 24 հավելվածի.
25) Հարավային ջրավազանային կառավարման տարածքի Մեղրի գետի գետավազանի գետերի ջրի որակի նորմերը՝ ըստ ֆիզիկաքիմիական տարրերի` համաձայն N 25 հավելվածի:
