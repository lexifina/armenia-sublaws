# Հավելված N 1 ՀՀ կառավարության 2020 թվականի ապրիլի 23-ի N 593-Ն որոշման
Կ Ա Զ Մ
ՀԱՆՐԱՊԵՏԱԿԱՆ ԶՈՐԱԿՈՉԱՅԻՆ ՀԱՆՁՆԱԺՈՂՈՎԻ
Դ. Տոնոյան | - ՀՀ պաշտպանության նախարար (հանձնաժողովի նախագահ)
Օ. Գասպարյան | - ՀՀ զինված ուժերի գլխավոր շտաբի պետ (հանձնաժողովի նախագահի տեղակալ)
Ա. Ավթանդիլյան | - ՀՀ պաշտպանության նախարարության զորակոչային և զորահավաքային համալրման ծառայության պետ
Վ. Ղազարյան | - ՀՀ ոստիկանության պետ
Ա. Քյարամյան | - ՀՀ ազգային անվտանգության ծառայության տնօրեն
Ա. Դավթյան | - ՀՀ գլխավոր դատախազ (համաձայնությամբ)
Ա. Հարությունյան | - ՀՀ կրթության, գիտության, մշակույթի և սպորտի նախարար
Հ. Արշակյան | - ՀՀ բարձր տեխնոլոգիական արդյունաբերության նախարար
Ա. Թորոսյան | - ՀՀ առողջապահության նախարար
Զ. Մնացականյան | - ՀՀ արտաքին գործերի նախարար
Ս. Պապիկյան | - ՀՀ տարածքային կառավարման և ենթակառուցվածքների նախարար
Ա. Սարգսյան | - ՀՀ պաշտպանության նախարարության զորակոչային և զորահավաքային համալրման ծառայության զորակոչի վարչության պետ (հանձնաժողովի քարտուղար)
(հավելվածը խմբ. 30.07.20 N 1265-Ն)
