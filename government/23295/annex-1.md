# Հավելված ՀՀ կառավարության 2006 թվականի մարտի 23-ի N 365-Ն որոշման
Կ Ա Ր Գ ԳՈՐԾԱԶՐԿՈՒԹՅԱՆ ՆՊԱՍՏԻ ՎՃԱՐՄԱՆ I. ԸՆԴՀԱՆՈՒՐ ԴՐՈՒՅԹՆԵՐ
1. Սույն կարգով կարգավորվում են Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարության «Զբաղվածության պետական ծառայություն» գործակալության (այսուհետ` գործակալություն) զբաղվածության մարզային և տարածքային կենտրոնների (այսուհետ` տարածքային կենտրոն) կողմից նպաստառու գործազուրկներին «Բնակչության զբաղվածության և գործազրկության դեպքում սոցիալական պաշտպանության մասին» Հայաստանի Հանրապետության օրենքով երաշխավորվող գործազրկության նպաստի վճարման հետ կապված հարաբերությունները:
(1-ին կետը փոփ. 27.03.08 N 285-Ն)
2. Գործազրկության նպաստը տրվում է Հայաստանի Հանրապետության պետական բյուջեի միջոցներից և նախատեսվում է զբաղվածության կարգավորման ամենամյա պետական ծրագրերում:
(2-րդ կետը փոփ. 27.03.08 N 285-Ն)
3. Գործազրկության նպաստի վճարումն իրականացվում է «Գնումների մասին» Հայաստանի Հանրապետության օրենքով սահմանված կարգով ընտրված վճարման ծառայություններ մատուցող կազմակերպության (այսուհետ` կազմակերպություն) կողմից:
4. Ոչ լրիվ ամսվա համար գործազրկության նպաստի չափը որոշվում է գործազրկության նպաստի ամսական գումարը բաժանելով 30.4-ի (միջին ամսական օրերի թվի) վրա և բազմապատկելով այն օրերի թվով (հաշվարկի մեջ ներառվում են շաբաթ և կիրակի օրերը), որոնց համար գործազուրկն ունի գործազրկության նպաստ ստանալու իրավունք:
(4-րդ կետը փոփ. 14.05.09 N 518-Ն)
4.1. Գործազրկության նպաստի ստացման ժամանակահատվածում գործազրկության նպաստի վերահաշվարկման նոր հիմքեր ի հայտ գալու դեպքում վերահաշվարկված գործազրկության նպաստը վճարվում է գործազրկության նպաստի ստացման ժամանակահատվածի ավարտին հաջորդող ամսվանից:
(4.1-ին կետը լրաց. 10.06.11 N 818-Ն)
4.2. Գործազրկության նպաստի ստացման ժամանակահատվածի ավարտից հետո գործազրկության նպաստի նշանակման նոր հիմքեր ի հայտ գալու դեպքում վերահաշվարկված գործազրկության նպաստը վճարվում է նոր հիմքեր ի հայտ գալու ամսվան հաջորդող ամսվանից:
(4.2-րդ կետը լրաց. 10.06.11 N 818-Ն)
II. ԳՈՐԾԱԶՐԿՈՒԹՅԱՆ ՆՊԱՍՏԻ ՎՃԱՐՈՒՄԸ
5. Տարածքային կենտրոնն աշխատանք փնտրող անձի հաշվառման քարտի հիման վրա կազմում է տվյալ ամսվա, նախորդ ժամանակահատվածի համար չստացված և վերահաշվարկված գործազրկության նպաստ ստացողի, ինչպես նաև «Բնակչության զբաղվածության և գործազրկության դեպքում սոցիալական պաշտպանության մասին» Հայաստանի Հանրապետության օրենքի 37-րդ հոդվածում նշված անձին վճարվող գործազրկության նպաստի վճարման ցուցակը (այսուհետ` վճարման ցուցակ) (ձև N 1)` և մինչև յուրաքանչյուր ամսվան հաջորդող ամսվա 5-ը ներկայացնում է կազմակերպության մասնաճյուղին:
(5-րդ կետը փոփ. 14.05.09 N 518-Ն, փոփ., լրաց. 10.06.11 N 818-Ն)
6. Տարածքային կենտրոնը տվյալ ամսվա, նախորդ ժամանակահատվածի համար չստացված և վերահաշվարկված գործազրկության նպաստի վճարման և կազմակերպության կողմից գործազրկության նպաստի վճարման ծառայությունների (այսուհետ` ծառայություն) համար անհրաժեշտ գումարի ֆինանսավորման հայտ-պահանջագիրը (ձև N 2)` կից գրությամբ, մինչև յուրաքանչյուր ամսվան հաջորդող ամսվա 5-ը ներկայացնում է գործակալության պետին:
(6-րդ կետը փոփ., լրաց. 10.06.11 N 818-Ն)
7. Գործակալությունը 5 աշխատանքային օրվա ընթացքում ամփոփում է տարածքային կենտրոններից ստացված ֆինանսավորման հայտ-պահանջագրերը և Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարություն (այսուհետ` նախարարություն) է ներկայացնում գործազրկության նպաստի ֆինանսավորման հայտ-պահանջագիրը (ձև N 3) և ծառայության դիմաց վճարվող գումարի ֆինանսավորման հայտ-պահանջագրերը (N 4 ձև):
(7-րդ կետը փոփ. 27.03.08 N 285-Ն, 14.05.09 N 518-Ն, լրաց., փոփ. 10.06.11 N 818-Ն)
8. Նախարարությունը սույն կարգի 7-րդ կետում նշված ֆինանսավորման հայտ-պահանջագիրը գործակալությունից ստանալուց հետո 5 աշխատանքային օրվա ընթացքում Հայաստանի Հանրապետության ֆինանսների նախարարության տեղական գանձապետական բաժիններում Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի անվամբ բացված գանձապետական հաշվին է փոխանցում ֆինանսավորման հայտ-պահանջագրով նախատեսված միջոցները: Ծառայության դիմաց վճարի ֆինանսավորման հայտ-պահանջագրի հիման վրա նախարարությունը կենտրոնական գանձապետարան է ներկայացնում բյուջետային փոխանցագիր:
(8-րդ կետը փոփ. 27.03.08 N 285-Ն, փոփ., լրաց. 14.05.09 N 518-Ն, խմբ. 10.06.11 N 818-Ն)
9. Գործակալությունը գործազրկության նպաստի և ծառայության դիմաց վճարման ենթակա գումարը 3 աշխատանքային օրվա ընթացքում փոխանցում է կազմակերպության հաշվարկային հաշվին:
(9-րդ կետը խմբ. 14.05.09 N 518-Ն)
10. Կազմակերպությունը սույն կարգի 9-րդ կետում նշված գումարն ստանալու օրվանից հետո 15 աշխատանքային օրվա ընթացքում իր մասնաճյուղերի միջոցով կատարում է գործազրկության նպաստի վճարում` վճարման ցուցակում ընդգրկված`
ա) նպաստառու գործազուրկին` անձը հաստատող փաստաթղթի հիման վրա.
բ) նպաստառու գործազուրկի փոխարեն այլ անձին` նպաստառու գործազուրկի կողմից Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով տրված լիազորագրի և լիազորագիր ներկայացնողի անձը հաստատող փաստաթղթի հիման վրա.
գ) նպաստ ստանալու իրավունք ունեցած և մահացած նպաստառու գործազուրկի փոխարեն նրա ընտանիքի չափահաս անդամին կամ մահացածի կնոջը (ամուսնուն), ծնողներից որևէ մեկին կամ անչափահաս երեխաների օրինական ներկայացուցչին, խնամակալին կամ հոգաբարձուին` նրանց անձնագրի և նպաստառու գործազուրկի մահվան վկայականի հիման վրա:
11. Կազմակերպության մասնաճյուղը սույն կարգի 10-րդ կետում նշված ժամկետները լրանալուց հետո 3 աշխատանքային օրվա ընթացքում տարածքային կենտրոնի լիազոր ներկայացուցչի հետ միասին կազմում է գործազրկության նպաստի վճարման մասին փոխադարձ հաշվետվության ակտ:
12. Կազմակերպության մասնաճյուղը յուրաքանչյուր ամսվա վճարման ցուցակի պատճենը, և վճարման մասին փոխադարձ հաշվետվության ակտը` այն կազմելուց հետո 3 աշխատանքային օրվա ընթացքում վերադարձնում է տարածքային կենտրոն:
(12-րդ կետը փոփ. 14.05.09 N 518-Ն)
13. Կազմակերպությունը գործազրկության նպաստի վճարման համար նախատեսված ժամկետները լրանալուց հետո 3 աշխատանքային օրվա ընթացքում մասնաճյուղերում առկա մնացորդ գումարները փոխանցում է Հայաստանի Հանրապետության ֆինանսների նախարարության տեղական գանձապետական բաժնում Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարության աշխատակազմի անվամբ բացված գանձապետական հաշվին, իսկ չվճարված գործազրկության նպաստի մնացորդ գումարների վերաբերյալ, ըստ տարածքային կենտրոնների, տեղեկատվություն է ներկայացնում գործակալություն:
(13-րդ կետը փոփ. 14.05.09 N 518-Ն)
