# Հավելված ՀՀ կառավարության 2011 թվականի մարտի 31-ի N 342-Ն որոշման
Կ Ա Ռ ՈՒ Ց Վ Ա Ծ Ք
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ շրջակա միջավայրի ՆԱԽԱՐԱՐՈՒԹՅԱՆ «ԲՆԱՊԱՀՊԱՆԱԿԱՆ ԾՐԱԳՐԵՐԻ ԻՐԱԿԱՆԱՑՄԱՆ ԳՐԱՍԵՆՅԱԿ» ՊԵՏԱԿԱՆ ՀԻՄՆԱՐԿԻ (վերնագիրը փոփ. 10.10.19 N 1442-Ն)
1. Բյուջետային ծրագրերի իրականացման բաժին
2. Դոնորների օժանդակությամբ իրականացվող ծրագրերի բաժին
3. Էկոկրթական ծրագրերի բաժին
4. Գործերի կառավարման և գնումների բաժին
(հավելվածը փոփ. 10.10.19 N 1442-Ն)
