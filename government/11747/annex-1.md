# Հավելված N 1 ՀՀ կառավարության 2003 թվականի դեկտեմբերի 18-ի N 1781-Ն որոշման

ՈՐՈՏԱՆԻ ՀԻԴՐՈՀԱՆԳՈՒՅՑԻ ԵՎ ԱՐՓԱ-ՍԵՎԱՆ ԹՈՒՆԵԼԻ ՀԱՎԱՏԱՐՄԱԳՐԱՅԻՆ ԿԱՌԱՎԱՐՄԱՆ ՀԱՆՁՆԵԼՈՒ ՄՐՑՈՒՅԹԻ ԳՆԱՀԱՏՄԱՆ ՄԻՋԳԵՐԱՏԵՍՉԱԿԱՆ ՀԱՆՁՆԱԺՈՂՈՎԻ
Ռ. Ղուկասյան | - | ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի նախագահի տեղակալ (հանձնաժողովի նախագահ)
Ռ. Դավթյան | - | ՀՀ ֆինանսների և էկոնոմիկայի նախարարության աշխատակազմի ճյուղային տնտեսական ծրագրերի վարչության պետ
Ս. Կարապետյան | - | ՀՀ քաղաքաշինության նախարարության «Հիդրոտեխնիկական կառույցներ» պետական հիմնարկի տնօրեն
Մ. Գասպարյան | - | ՀՀ գյուղատնտեսության նախարարության աշխատակազմի հողերի մոնիտորինգի և մելիորացիայի բաժնի պետ
Ա. Ներսիսյան | - | ՀՀ բնապահպանության նախարարության ջրային ռեսուրսների կառավարման գործակալության պետ
Գ. Նազարյան | - | ՀՀ կառավարությանն առընթեր պետական գույքի կառավարման վարչության աշխատակազմի պետական գույքի կառավարման քաղաքականության մշակման բաժնի պետ
Ս. Ազարյան | - | ՀՀ կառավարությանն առընթեր արտակարգ իրավիճակների վարչության արտակարգ իրավիճակների կանխման և հետևանքների վերացման վարչության պետ
Է. Պապյան | - | ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի աշխատակազմի ֆինանսատնտեսագիտական, հաշվառման և իրացման համակարգման վարչության պետի տեղակալ
Է. Բադալյան | - | ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի աշխատակազմի ջրատնտեսական ենթակառուցվածքների գործունեությունը համակարգող վարչության ոռոգման համակարգերի բաժնի պետ
Ռ. Սավթալյան | - | ՀՀ կառավարությանն առընթեր ջրային տնտեսության պետական կոմիտեի աշխատակազմի իրավաբանական վարչության օրենսդրության հարցերի և պայմանագրային բաժնի պետ
Յու. Ջավադյան | - | «Հայջրնախագիծ ինստիտուտ» ՓԲԸ-ի գլխավոր տնօրեն
Տ. Քալանթարյան | - | «Ջրային տնտեսության զարգացման և բարեփոխումների ԾԻԳ» պետական հիմնարկի տնօրենի տեղակալ
Գ. Գրիգորյան | - | «Որոտան-Արփա-Սևան» թունելների շահագործման վարչություն» պետական հիմնարկի տնօրենի տեղակալ
Ա. Սանահյան | - | «Հայհիդրոէներգանախագիծ» ՓԲԸ-ի գլխավոր ինժեներ
Հ. Ավետիսյան | - | «Պետական գնումների գործակալություն» պետական ոչ առևտրային կազմակերպության աշխատանքների բաժնի առաջատար մասնագետ (հանձնաժողովի քարտուղար)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
