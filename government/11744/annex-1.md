# Հավելված N 1 ՀՀ կառավարության 2003 թվականի նոյեմբերի 21-ի N 1779-Ն որոշման
Ց Ա Ն Կ
ՄԱՔՍԱՅԻՆ ՀՍԿՈՂՈՒԹՅՈՒՆ ԻՐԱԿԱՆԱՑՆԵԼՈՒ ՀԱՄԱՐ ԱՆՀՐԱԺԵՇՏ ՓԱՍՏԱԹՂԹԵՐԻ
1. Հայաստանի Հանրապետության մաքսատներում` որպես արտաքին տնտեսական գործունեության մասնակից գրանցվելու համար անհրաժեշտ փաստաթղթերն են`
ա) կազմակերպության կանոնադրությունը (պատճենը),
բ) պետական գրանցման վկայականը (պատճենը),
գ) հարկ վճարողի հաշվառման համարը (պատճենը),
դ) տեղեկանք կազմակերպության հաշվարկային հաշվի մասին` տրված սպասարկող բանկի կողմից:
2. Կազմակերպությունների և անհատ ձեռնարկատերերի կողմից ներմուծվող ապրանքների և տրանսպորտային միջոցների նկատմամբ մաքսային հսկողություն իրականացնելու համար անհրաժեշտ փաստաթղթերն են`
ա) մաքսային հայտարարագիրը, Հայաստանի Հանրապետության մաքսային օրենսդրությամբ նախատեսված դեպքերում` նաև մաքսային արժեքի մանրամասնությունների հայտարարագիրը,
բ) ապրանքի ձեռքբերման հաշիվ-ապրանքագիրը կամ պայմանագիրը, կամ դրան փոխարինող համապատասխան այլ փաստաթուղթ,
գ) ապրանքի տեղափոխումը հիմնավորող փաստաթուղթը (ապրանքատրանսպորտային բեռնագիր),
դ) Հայաստանի Հանրապետության օրենսդրությամբ նախատեսված դեպքերում` ոչ սակագնային կարգավորման նպատակով պահանջվող փաստաթղթերի բնօրինակները` թույլտվություն, լիցենզիա, հավաստագիր (սերտիֆիկատ), եզրակացություն, վկայագիր և այլն,
ե) ակցիզային հարկով հարկման և պարտադիր դրոշմավորման ենթակա` ներմուծված ապրանքների համար ակցիզային դրոշմանիշերի ձեռքբերման անդորրագիրը և ձեռք բերված ակցիզային դրոշմանիշերի օգտագործման մասին հաշվետվությունը,
զ) մաքսային վճարների վճարված լինելը հավաստող կամ Հայաստանի Հանրապետության մաքսային օրենսդրությամբ նախատեսված դեպքերում` դրանց վճարումը երաշխավորող փաստաթղթերը:
3. Կազմակերպությունների և անհատ ձեռնարկատերերի կողմից արտահանվող ապրանքների և տրանսպորտային միջոցների նկատմամբ մաքսային հսկողություն իրականացնելու համար անհրաժեշտ փաստաթղթերն են`
ա) մաքսային հայտարարագիրը,
բ) ապրանքի ձեռքբերման հաշիվ-ապրանքագիրը կամ պայմանագիրը, կամ դրան փոխարինող համապատասխան այլ փաստաթուղթ,
գ) ապրանքի տեղափոխումը հիմնավորող փաստաթուղթը (ապրանքատրանսպորտային բեռնագիր),
դ) Հայաստանի Հանրապետության օրենսդրությամբ նախատեսված դեպքերում` ոչ սակագնային կարգավորման նպատակով պահանջվող փաստաթղթերի բնօրինակները` թույլտվություն, լիցենզիա, վկայագիր, հավաստագիր: Ծագման երկրի հավաստագիր չի պահանջվում` բացառությամբ իրենց բնութագրով` Հայաստանի Հանրապետության օրենսդրությամբ սահմանված` երկակի նշանակության ապրանքների և տեխնոլոգիաների շարքը դասվող ապրանքների, ինչպես նաև այն դեպքերում, երբ հավաստագիր պահանջվում է Հայաստանի Հանրապետության անունից կնքված և վավերացված միջազգային պայմանագրերով,
ե) մաքսային վճարների վճարված լինելը հավաստող կամ Հայաստանի Հանրապետության մաքսային օրենսդրությամբ նախատեսված դեպքերում` դրանց վճարումը երաշխավորող փաստաթղթերը:
4. Ֆիզիկական անձանց կողմից ներմուծվող ապրանքների և տրանսպորտային միջոցների նկատմամբ մաքսային հսկողություն իրականացնելու համար անհրաժեշտ փաստաթղթերն են`
ա) մաքսային հայտարարագիրը, Հայաստանի Հանրապետության օրենսդրությամբ նախատեսված դեպքերում` նաև մաքսային արժեքի մանրամասնությունների հայտարարագիրը,
բ) ապրանքի ձեռքբերման հաշիվ-ապրանքագիրը կամ պայմանագիրը, կամ դրան փոխարինող համապատասխան այլ փաստաթուղթ,
գ) Հայաստանի Հանրապետության օրենսդրությամբ նախատեսված դեպքերում` ոչ սակագնային կարգավորման նպատակով պահանջվող փաստաթղթերի բնօրինակները` թույլտվություն, լիցենզիա, եզրակացություն, հավաստագիր (սերտիֆիկատ), վկայագիր և այլն,
դ) մաքսային վճարների վճարված լինելը հավաստող կամ Հայաստանի Հանրապետության մաքսային օրենսդրությամբ նախատեսված դեպքերում` դրանց վճարումը երաշխավորող փաստաթղթերը:
5. Ֆիզիկական անձանց կողմից արտահանվող ապրանքների և տրանսպորտային միջոցների նկատմամբ մաքսային հսկողություն իրականացնելու համար անհրաժեշտ փաստաթղթերն են`
ա) Հայաստանի Հանրապետության մաքսային օրենսդրությամբ նախատեսված դեպքերում` մաքսային հայտարարագիրը,
բ) Հայաստանի Հանրապետության օրենսդրությամբ նախատեսված դեպքերում` ոչ սակագնային կարգավորման նպատակով պահանջվող փաստաթղթերի բնօրինակները` թույլտվություն, լիցենզիա, վկայագիր, հավաստագիր: Ծագման երկրի սերտիֆիկատ չի պահանջվում` բացառությամբ իրենց բնութագրով` Հայաստանի Հանրապետության օրենսդրությամբ սահմանված` երկակի նշանակության ապրանքների և տեխնոլոգիաների շարքը դասվող ապրանքների, ինչպես նաև այն դեպքերում, երբ հավաստագիր պահանջվում է Հայաստանի Հանրապետության անունից կնքված և վավերացված միջազգային պայմանագրերով,
գ) մաքսային վճարների վճարված լինելը հավաստող կամ Հայաստանի Հանրապետության մաքսային օրենսդրությամբ նախատեսված դեպքերում` դրանց վճարումը երաշխավորող փաստաթղթերը:
6. Հայաստանի Հանրապետության մաքսային օրենսգրքին համապատասխան` անձի անհրաժեշտ լիազորությունները հաստատող փաստաթղթերն են`
ա) անձնագիրը կամ անձը հաստատող այլ փաստաթուղթ,
բ) անձի` որպես հայտարարատու հանդես գալու համար անհրաժեշտ լիազորությունները հաստատող փաստաթուղթը (լիազորագիր կամ նմանատիպ այլ փաստաթուղթ, մաքսային մասնագետի որակավորում ունենալը հաստատող փաստաթուղթ):
7. Մաքսային գործի հետ կապված լիցենզավորման ենթակա գործունեության տեսակների նկատմամբ վերահսկողություն իրականացնելու համար անհրաժեշտ, լիցենզավորման ենթակա գործունեություն իրականացնող անձանցից պահանջվող փաստաթղթերն են`
ա) գործունեության տվյալ տեսակով զբաղվելու լիցենզիան (պատճենը),
բ) մաքսային պահեստներում, ազատ մաքսային պահեստներում, անմաքս առևտրի խանութներում և ազատ տնտեսական գոտիներում Հայաստանի Հանրապետության մաքսային օրենսդրությանը համապատասխան վարվող գրանցամատյաններն ու մաքսային մարմիններ ներկայացման ենթակա ապրանքների շարժի մասին հաշվետվությունները:
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
