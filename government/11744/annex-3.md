# Հավելված N 3 ՀՀ կառավարության 2003 թվականի նոյեմբերի 21-ի N 1779-Ն որոշման
Կ Ա Ր Գ
ՄԱՔՍԱՅԻՆ ՀՍԿՈՂՈՒԹՅՈՒՆ ԻՐԱԿԱՆԱՑՆԵԼՈՒ ՀԱՄԱՐ ԱՆՀՐԱԺԵՇՏ ՓԱՍՏԱԹՂԹԵՐԸ ԵՎ ՏԵՂԵԿՈՒԹՅՈՒՆՆԵՐԸ ՄԱՔՍԱՅԻՆ ՄԱՐՄԻՆՆԵՐԻՆ ՏՐԱՄԱԴՐԵԼՈՒ
1. Սույն կարգով սահմանվում է մաքսային մարմիններին մաքսային հսկողություն իրականացնելու համար անհրաժեշտ փաստաթղթերի և տեղեկությունների տրամադրման կարգը:
2. Մաքսային հսկողության իրականացման համար`
ա) անհրաժեշտ փաստաթղթերը և տեղեկություններն ապրանքներ տեղափոխող անձանց կողմից ներկայացվում են Հայաստանի Հանրապետության այն մաքսային մարմիններ, որոնց կողմից` Հայաստանի Հանրապետության մաքսային օրենսդրությամբ սահմանված կարգով իրականացվում են Հայաստանի Հանրապետության մաքսային սահմանով տեղափոխվող ապրանքների մաքսային ձևակերպումները և (կամ) տեղափոխումը.
բ) մաքսային և ազատ մաքսային պահեստներում, ազատ տնտեսական գոտիներում, ինչպես նաև անմաքս առևտրի խանութներում ապրանքների շարժին վերաբերող փաստաթղթերն ու տեղեկությունները ներկայացվում են Հայաստանի Հանրապետության կառավարությանն առընթեր մաքսային պետական կոմիտե` նրա կողմից սահմանված կարգով.
գ) Հայաստանի Հանրապետություն ներմուծվող` ակցիզային հարկով հարկման և պարտադիր դրոշմավորման ենթակա ապրանքների համար ակցիզային դրոշմանիշերի ձեռքբերմանն ու օգտագործմանը վերաբերող փաստաթղթերը և տեղեկությունները մաքսային մարմիններ են ներկայացվում Հայաստանի Հանրապետության կառավարության կողմից սահմանված կարգով.
դ) սույն կետում չնշված` Հայաստանի Հանրապետության այլ անձինք, մաքսային հսկողության իրականացման համար անհրաժեշտ փաստաթղթերը և տեղեկությունները մաքսային մարմիններ են ներկայացնում իրենց նախաձեռնությամբ կամ մաքսային մարմինների պահանջով` Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով:
3. Հայաստանի Հանրապետության մաքսային սահմանով ապրանքներ տեղափոխող անձինք մաքսային հսկողություն իրականացնելու համար անհրաժեշտ տեղեկությունները ներկայացնում են Հայաստանի Հանրապետության կառավարությանն առընթեր մաքսային պետական կոմիտեի կողմից սահմանված ձևի հայտարարագրերով և (կամ) մաքսային նպատակների իրականացման համար անհրաժեշտ` Հայաստանի Հանրապետության մաքսային օրենսդրությամբ սահմանված այլ փաստաթղթերով, ինչպես նաև ֆիզիկական անձանց բանավոր հարցմամբ:
4. Մաքսային հսկողություն իրականացնելու համար անհրաժեշտ տեղեկությունները պարզելու և ստանալու նպատակով Հայաստանի Հանրապետության մաքսային մարմիններն իրավունք ունեն իրենց նախաձեռնությամբ` Հայաստանի Հանրապետության մաքսային օրենսդրությամբ սահմանված դեպքերում և կարգով իրականացնելու օրենքով սահմանված գործողություններ:
5. Հայաստանի Հանրապետության մաքսային մարմինների պաշտոնատար անձինք իրավունք ունեն անձանցից պահանջելու և ստանալու միայն Հայաստանի Հանրապետության մաքսային օրենսդրությամբ նախատեսված փաստաթղթեր ու տեղեկություններ:
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
