# Հավելված N 3 ՀՀ կառավարության 2017 թվականի սեպտեմբերի 7-ի N 1151-Ն որոշման
Կ Ա Ր Գ
ՔԱՂԱՔԱՑԻՆԵՐԻ ԿՈՂՄԻՑ ՎԵՐԱԴԱՐՁՎԱԾ աջակցող միջոցԸ ԺԱՄԱՆԱԿԱՎՈՐ ՏՐԱՄԱԴՐԵԼՈՒ (վերնագիրը փոփ. 20.12.18 N 1516-Ն)
1. Սույն կարգով սահմանվում է քաղաքացիների կողմից վերադարձված աջակցող միջոցը ժամանակավոր օգտագործման համար տրամադրելու ընթացակարգը:
(1-ին կետը փոփ. 20.12.18 N 1516-Ն)
2. Հայաստանի Հանրապետության կառավարության 2017 թվականի սեպտեմբերի 7-ի N 1151-Ն որոշման N 1 հավելվածի 32-րդ կետով նախատեսված դեպքերում քաղաքացին, իր ցանկությամբ, կարող է նախորդ ստացած աջակցող միջոցը վերադարձնել հավաստագիր տրամադրող մարմին:
(2-րդ կետը փոփ. 20.12.18 N 1516-Ն)
3. Վերադարձված աջակցող միջոցի վերաբերյալ տվյալները հավաստագիր տրամադրող մարմինը գրանցում է քաղաքացիների կողմից վերադարձված աջակցող միջոցի հաշվառման գրանցամատյանում՝ համաձայն սույն կարգի N 3 ձևի:
(3-րդ կետը փոփ. 20.12.18 N 1516-Ն)
4. Ժամանակավոր օգտագործման համար աջակցող միջոց տրամադրվում է անձի բնակության վայրի առաջնային բժշկական օգնությունը և սպասարկումն իրականացնող կամ մասնագիտացված բժշկական կազմակերպության (հաստատության) կողմից տրված մասնագիտական եզրակացության (այսուհետ` մասնագիտական եզրակացություն) հիման վրա:
(4-րդ կետը փոփ. 20.12.18 N 1516-Ն)
5. Ժամանակավոր օգտագործման համար աջակցող միջոցները տրամադրվում են առավելագույնը 6 ամիս ժամկետով, ընդ որում, ժամկետը նշվում է սույն կարգի 4-րդ կետով սահմանված կազմակերպությունների կողմից տրված մասնագիտական եզրակացության մեջ: Եթե քաղաքացուն աջակցող միջոցն անհրաժեշտ է ավելի երկար ժամկետով, ապա նա հավաստագիր տրամադրող մարմին է ներկայացնում նոր մասնագիտական եզրակացություն:
(5-րդ կետը փոփ. 20.12.18 N 1516-Ն)
6. Ժամանակավոր օգտագործման համար տրամադրված աջակցող միջոցի վերաբերյալ տվյալները հավաստագիր տրամադրող մարմինը գրանցում է ժամանակավոր օգտագործման համար տրամադրված աջակցող միջոցների հաշվառման գրանցամատյանում՝ համաձայն սույն կարգի N 4 ձևի:
(6-րդ կետը փոփ. 20.12.18 N 1516-Ն)
7. Գրանցամատյաններում անճշտությունների, սխալ գրառումների ուղղումը կատարվում է հավաստագիր տրամադրող մարմնի կողմից` սխալ կամ ոչ ճիշտ լրացված գրառումները վերցնելով փակագծերի մեջ՝ հաջորդ ազատ նոր տողում ավելացնելով ճիշտ գրառումները: Կատարված ոչ ճիշտ գրառման կողքին դրվում է ուղղումը կատարողի ստորագրությունը, ամսաթիվը, ամիսը, տարեթիվը և պաշտոնը:
(7-րդ կետը փոփ. 20.12.18 N 1516-Ն)
