# Հավելված ՀՀ կառավարության 2012 թվականի հոկտեմբերի 10-ի N 1281-Ն որոշման
ԳՈՒՅՆ ԵՎ Ձ Ե Վ
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՏԱՐԱԾՔՈՒՄ ԱՎՏՈԿԱՅԱՆԱՏԵՂԻ (ՈՐԻ ՀԱՄԱՐ ՆԱԽԱՏԵՍՎՈՒՄ Է ՏԵՂԱԿԱՆ ՎՃԱՐԻ ԳԱՆՁՈՒՄ) ԳԵՏՆԱՆՇՄԱՆ
(վերնագիրը փոփ. 10.12.20 N 2004-Ն, լրաց. 22.08.24 N 1334-Ն)
1. Փողոցի երթևեկելի մասում կազմակերպված վճարովի ավտոկայանատեղի զբաղեցրած տարածքն առանձնացվում է փողոցի երթևեկելի հարևան գոտուց` ավտոկայանատեղի երկայնական սահմանագծի կարմիր կամ կապույտ գույնի խզվածքներով գետնանշմամբ, եթե սույն հավելվածով այլ բան նախատեսված չէ: Եթե փողոցի երթևեկելի մասում կազմակերպված վճարովի ավտոկայանատեղում թույլատրվում է ավտոտրանսպորտային միջոցների՝ միմյանց նկատմամբ զուգահեռ տեղաբաշխմամբ կայանում, ապա ավտոկայանատեղի տարածքն առանձնացվում է նաև լայնակի սահմանագծով` կարմիր կամ կապույտ գույնի հոծ գետնանշմամբ, եթե սույն հավելվածով այլ բան նախատեսված չէ:
(1-ին կետը խմբ. 22.08.24 N 1334-Ն)
2. Հրապարակներում կազմակերպված վճարովի ավտոկայանատեղերը սահմանազատվում են կարմիր կամ կապույտ գույնի գետնանշմամբ` ավտոտրանսպորտային միջոցների մուտքի-ելքի ուղիների կողմից` խզվածքներով, ավտոկայանատեղի տարածքի սահմանագիծը հրապարակում` հոծ գծով, եթե սույն հավելվածով այլ բան նախատեսված չէ:
(2-րդ կետը խմբ. 22.08.24 N 1334-Ն)
3. Ելնելով ավտոկայանատեղի տարածքի առանձնահատկություններից և նպատակահարմարությունից, կարող է իրականացվել վճարովի ավտոկայանատեղի զբաղեցրած ամբողջ տարածքի` կարմիր կամ կապույտ ներկանյութով, այդ թվում՝ կարմիր կամ կապույտ գույնի ասֆալտաբետոնյա կամ այլ ծածկույթներով սահմանազատում, եթե սույն հավելվածով այլ բան նախատեսված չէ:
(3-րդ կետը խմբ. 22.08.24 N 1334-Ն)
4. Համայնքներում սույն հավելվածի 1-ին, 2-րդ և 3-րդ կետերում նշված վճարովի ավտոկայանատեղերի զբաղեցրած տարածքի՝ կարմիր կամ կապույտ գույնի գետնանշմամբ սահմանազատումն իրականացվում է ըստ համայնքի ավագանու որոշմամբ սահմանված գոտիավորման՝ համապատասխանաբար «Ա» գոտում գտնվող վճարովի ավտոկայանատեղերի համար կարմիր, իսկ «Բ» գոտում գտնվող վճարովի ավտոկայանատեղերի համար՝ կապույտ գույնի գետնանշմամբ:
(4-րդ կետը լրաց. 22.08.24 N 1334-Ն)
5. Ծառայողական ավտոկայանատեղերի զբաղեցրած տարածքը սույն հավելվածի 1-ին և 2-րդ կետերով սահմանված պահանջներին համապատասխան առանձնացվում է սպիտակ գույնի խզվածքներով կամ հոծ գետնանշմամբ: Համայնքներում կազմակերպված ծառայողական ավտոկայանատեղիի զբաղեցրած տարածքի առանձնահատկություններից և նպատակահարմարությունից ելնելով, կարող է իրականացվել ծառայողական ավտոկայանատեղի զբաղեցրած ամբողջ տարածքի` սպիտակ ներկանյութով, այդ թվում՝ սպիտակ գույնի ասֆալտաբետոնյա կամ այլ ծածկույթներով սահմանազատում:
(5-րդ կետը լրաց. 22.08.24 N 1334-Ն)
6. Էլեկտրամոբիլների լիցքավորման կայաններից էլեկտրամոբիլների լիցքավորման ապահովման հնարավորությամբ կազմակերպված վճարովի ավտոկայանատեղերի զբաղեցրած տարածքը սույն հավելվածի 1-ին և 2-րդ կետերով սահմանված պահանջներին համապատասխան առանձնացվում է կանաչ գույնի խզվածքներով կամ հոծ գետնանշմամբ:
(6-րդ կետը լրաց. 22.08.24 N 1334-Ն)
7․ Սույն որոշմամբ սահմանված ավտոկայանատեղիի գետնանշումներն իրականացվում են ԳՕՍՏ Ռ 51256-18, ՀՍՏ ԳՕՍՏ Ռ 52289-2022, ԳՕՍՏ 32830-2014 և ԳՕՍՏ 32848-2014 ստանդարտների պահանջներին համապատասխան:
(7-րդ կետը լրաց. 22.08.24 N 1334-Ն)
(հավելվածը փոփ. 10.12.20 N 2004-Ն, լրաց., խմբ. 22.08.24 N 1334-Ն)
