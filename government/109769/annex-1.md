# Հավելված N 1 ՀՀ կառավարության 2016 թվականի նոյեմբերի 18-ի N 1224-Ն որոշման

Վ. Սարգսյան | - ՀՀ պաշտպանության նախարար (հանձնաժողովի նախագահ)
Մ. Հակոբյան | - ՀՀ զինված ուժերի գլխավոր շտաբի պետ (հանձնաժողովի նախագահի տեղակալ)
Հ. Մուրադյան | - ՀՀ զինվորական կոմիսար
Վ. Գասպարյան | - ՀՀ կառավարությանն առընթեր ՀՀ ոստիկանության պետ
Գ. Կուտոյան | - ՀՀ կառավարությանն առընթեր ազգային անվտանգության ծառայության տնօրեն
Ա. Դավթյան | - ՀՀ գլխավոր դատախազ
Լ. Ալթունյան | - ՀՀ առողջապահության նախարար
Վ. Մարտիրոսյան | - ՀՀ տրանսպորտի, կապի և տեղեկատվական տեխնոլոգիաների նախարար
Լ. Մկրտչյան | - ՀՀ կրթության և գիտության նախարար
Է. Նալբանդյան | - ՀՀ արտաքին գործերի նախարար
Դ. Լոքյան | - ՀՀ տարածքային կառավարման և զարգացման նախարար
Կ. Նահապետյան | - ՀՀ Ազգային ժողովի պաշտպանության, ազգային անվտանգության և ներքին գործերի մշտական հանձնաժողովի նախագահ (համաձայնությամբ)
Ս. Բարսեղյան | - ՀՀ կառավարության աշխատակազմի պետաիրավական վարչության պետի պաշտոնակատար
Վ. Ասցատրյան | - ՀՀ կառավարության աշխատակազմի ազգային փոքրամասնությունների և կրոնի հարցերի բաժնի պետ
Ա. Ավթանդիլյան | - ՀՀ զինվորական կոմիսարիատի զորակոչային բաժնի պետ, գնդապետ (հանձնաժողովի քարտուղար)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Դ. Հարությունյան
