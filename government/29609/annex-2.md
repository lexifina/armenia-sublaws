# Հավելված N 2 ՀՀ կառավարության 2006 թվականի նոյեմբերի 9-ի N 1735-Ն որոշման
Կ Ա Ր Գ
ԵՐԵԽԱՆԵՐԻ ԽՆԱՄՔԻ ԵՎ ՊԱՇՏՊԱՆՈՒԹՅԱՆ ԳԻՇԵՐՕԹԻԿ ՀԱՍՏԱՏՈՒԹՅՈՒՆՆԵՐՈՒՄ ԵՐԵԽԱՆԵՐԻ ՏԵՂԱՎՈՐՄԱՆ
1. Երեխաների խնամքի և պաշտպանության գիշերօթիկ հաստատությունը (այսուհետ` գիշերօթիկ հաստատություն) իրականացնում է ընտանիքների անապահովության գնահատման համակարգում հաշվառված, սոցիալապես անապահով ընտանիքի` դպրոցահասակ երեխաների խնամքը և դաստիարակությունը:
(1-ին կետը փոփ. 02.06.11 N 804-Ն)
2. Երեխաները գիշերօթիկ հաստատությունում տեղավորվում են Հայաստանի Հանրապետության կառավարության 2005 թվականի մարտի 24-ի «Հայաստանի Հանրապետությունում երեխաների խնամք և պաշտպանություն իրականացնող հաստատությունների տիպերի ցանկը, դրանցում երեխաների տեղավորման չափանիշները հաստատելու և Հայաստանի Հանրապետության կառավարության 2002 թվականի դեկտեմբերի 26-ի N 2179-Ն որոշման մեջ լրացում և փոփոխություններ կատարելու մասին» N 381-Ն որոշմամբ սահմանված ընդունելության չափանիշներին համապատասխան:
3. Գիշերօթիկ հաստատությունը կազմակերպում է երեխայի կրթությունը մոտակա հանրակրթական դպրոցում:
4. Երեխային գիշերօթիկ հաստատությունում տեղավորելու համար երեխայի ծնողը կամ օրինական ներկայացուցիչը երեխայի բնակության վայրի մարզպետարան, իսկ Երևանում` Երևանի քաղաքապետարան է ներկայացնում հետևյալ փաստաթղթերը`
ա) դիմում,
բ) ծննդյան վկայական (բնօրինակը և պատճենը),
գ) բժշկական տեղեկանքներ երեխայի առողջական վիճակի մասին,
դ) բնակության վայրից տեղեկանք ընտանիքի անդամների մասին,
ե) տեղեկանք ընտանեկան նպաստի իրավունք ունենալու մասին (առկայության դեպքում),
զ) ծնողի կամ երեխայի օրինական ներկայացուցչի անձը հաստատող փաստաթղթի պատճենը,
է) տեղեկանք երեխայի բնակության վայրի շրջապատի համաճարակային վիճակի մասին:
(4-րդ կետը փոփ. 30.04.09 N 467-Ն)
5. Մարզպետարանը, իսկ Երևանում` Երևանի քաղաքապետարանը, սույն կարգի 4-րդ կետի «ե» ենթակետով սահմանված տեղեկանքի բացակայության դեպքում, 3 օրվա ընթացքում դիմում է երեխայի բնակության վայրի սոցիալական ծառայությունների տարածքային գործակալություն` երեխայի ընտանիքի անապահովության գնահատում իրականացնելու և սոցիալական աջակցության խորհրդի կողմից առաջարկություն ստանալու համար:
(5-րդ կետը փոփ. 30.04.09 N 467-Ն)
6. Մարզպետարանը, իսկ Երևանում` Երևանի քաղաքապետարանը սույն կարգի 4-րդ և 5-րդ կետերով սահմանված փաստաթղթերի հիման վրա 5 օրվա ընթացքում կատարում է երեխայի կյանքի պայմանների ուսումնասիրություն և տալիս եզրակացություն երեխային գիշերօթիկ հաստատությունում տեղավորելու մասին:
(6-րդ կետը փոփ. 30.04.09 N 467-Ն)
7. Մարզպետարանը, իսկ Երևանում` Երևանի քաղաքապետարանը երեխային գիշերօթիկ հաստատությունում տեղավորելու մասին եզրակացությունը և սույն կարգի 4-րդ ու 5-րդ կետերով նախատեսված փաստաթղթերը եռօրյա ժամկետում ներկայացնում է Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարություն (այսուհետ` նախարարություն):
(7-րդ կետը փոփ. 30.04.09 N 467-Ն)
8. Նախարարությունը մարզպետարանի, իսկ Երևանում` Երևանի քաղաքապետարանի կողմից ստացված եզրակացության և փաստաթղթերի հիման վրա եռօրյա ժամկետում երեխային ուղեգրում է գիշերօթիկ հաստատություն` կցելով երեխային վերաբերող բոլոր փաստաթղթերը: Սույն կարգի 6-րդ կետում նշված եզրակացությունն օրենսդրորեն հիմնավորված չլինելու դեպքում նախարարությունը երեխայի փաստաթղթերը հետ է ուղարկում մարզպետարան, իսկ Երևանում` Երևանի քաղաքապետարան:
(8-րդ կետը փոփ. 30.04.09 N 467-Ն)
9. Գիշերօթիկ հաստատությունում տեղավորման ենթակա նույն ընտանիքի երեխաները (քույրեր և եղբայրներ) տեղավորվում են միևնույն հաստատությունում` բացառությամբ այն դեպքերի, երբ բժշկական հակացուցումներով այդ երեխաների խնամքն ու դաստիարակությունն անհնար է իրականացնել միասին:
10. Երեխայի ընդունելությունը գիշերօթիկ հաստատություն ձևակերպվում է տնօրենի հրամանով:
11. Մարզպետարանը, իսկ Երևանում` Երևանի քաղաքապետարանը գիշերօթիկ հաստատությունում տեղավորվող երեխայի ծնողներին գրավոր նախազգուշացնում է այն մասին, որ, եթե նրանք խուսափեն իրենց երեխային այցելելուց կամ ուսումնական արձակուրդների ժամանակահատվածում երեխային ընտանիքում պահելուց, ապա երեխան կարող է տեղափոխվել մանկատուն կամ հանձնվել ընտանիք` դաստիարակության` Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով, առանց ծնողներին լրացուցիչ տեղեկացնելու:
(11-կետը փոփ. 06.12.07 N 1426-Ն, 30.04.09 N 467-Ն)
12. Գիշերօթիկ հաստատությունում տեղավորված երեխային բուժման նպատակով հիվանդանոց տեղափոխելու անհրաժեշտության դեպքում տնօրինությունը դրա մասին անհապաղ տեղեկացնում է երեխայի ծնողներին:
13. Գիշերօթիկ հաստատությունում տեղավորված երեխան գիշերօթիկ հաստատությունից դուրս է գրվում ծնողների դիմումի և ծնողների բնակության վայրի մարզպետարանի, իսկ Երևանում` Երևանի քաղաքապետարանի եզրակացության հիման վրա, որի մեկ օրինակը տրվում է նախարարությանը:
(13-րդ կետը փոփ. 30.04.09 N 467-Ն)
14. Գիշերօթիկ հաստատությունում երեխաների խնամքն իրականացվում է Հայաստանի Հանրապետության կառավարության 2004 թվականի օգոստոսի 5-ի «Հայաստանի Հանրապետության կառավարության լիազորած պետական կառավարման մարմին ճանաչելու և մանկատներում երեխաների խնամքի ու դաստիարակության համար անհրաժեշտ պետական սոցիալական նվազագույն չափորոշիչները հաստատելու մասին» N 1324-Ն որոշմամբ սահմանված չափորոշիչներին համապատասխան:
(հավելվածը փոփ. 06.12.07 N 1426-Ն, 30.04.09 N 467-Ն, 02.06.11 N 804-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
