# Հավելված N 1 ՀՀ կառավարության 2014 թվականի հուլիսի 3-ի N 692-Ն որոշման
«ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ 2014 ԹՎԱԿԱՆԻ ՊԵՏԱԿԱՆ ԲՅՈՒՋԵԻ ՄԱՍԻՆ» ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՕՐԵՆՔԻ N 1 ՀԱՎԵԼՎԱԾՈՒՄ ԿԱՏԱՐՎՈՂ ՎԵՐԱԲԱՇԽՈՒՄԸ ԵՎ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆ 2013 ԹՎԱԿԱՆԻ ԴԵԿՏԵՄԲԵՐԻ 19-Ի N 1414-Ն ՈՐՈՇՄԱՆ N 5 ՀԱՎԵԼՎԱԾՈՒՄ ԿԱՏԱՐՎՈՂ ՓՈՓՈԽՈՒԹՅՈՒՆՆԵՐԸ (հավելվածն ուժը կորցրել է 25.12.14 N 1532-Ն)
