# Հավելված N 2 ՀՀ կառավարության 2016 թվականի հունվարի 20-ի N 37-Ն որոշման
«ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ 2016 ԹՎԱԿԱՆԻ ՊԵՏԱԿԱՆ ԲՅՈՒՋԵԻ ՄԱՍԻՆ» ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՕՐԵՆՔԻ N 1 ՀԱՎԵԼՎԱԾՈՒՄ ԵՎ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆ 2015 ԹՎԱԿԱՆԻ ԴԵԿՏԵՄԲԵՐԻ 24-Ի N 1555-Ն ՈՐՈՇՄԱՆ N 5 ՀԱՎԵԼՎԱԾՈՒՄ ԿԱՏԱՐՎՈՂ ՓՈՓՈԽՈՒԹՅՈՒՆՆԵՐԸ
(հավելվածն ուժը կորցրել է 29.12.16 N 1396-Ն)
