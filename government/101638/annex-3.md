# Հավելված N 3 ՀՀ կառավարության 2015 թվականի հոկտեմբերի 29-ի N 1292-Ն որոշման
Չ Ա Փ Ո Ր Ո Շ Ի Չ Ն Ե Ր
ԽՆԱՄՔԻ ԿԱՐԻՔ ՈՒՆԵՑՈՂ ՏԱՐԵՑ, ՉԱՇԽԱՏՈՂ (ԲԱՑԱՌՈՒԹՅԱՄԲ ՏՆԱՅԻՆ ՊԱՅՄԱՆՆԵՐՈՒՄ ԱՇԽԱՏՈՂ) ԱՆՁԱՆՑ ԵՎ (ԿԱՄ) ՀԱՇՄԱՆԴԱՄՈՒԹՅՈՒՆ ՈՒՆԵՑՈՂ ԱՆՁԱՆՑ ՏՆԱՅԻՆ ՊԱՅՄԱՆՆԵՐՈՒՄ ԽՆԱՄՔ ՏՐԱՄԱԴՐՈՂ ԿԱԶՄԱԿԵՐՊՈՒԹՅՈՒՆՆԵՐԻ ՀԱՍՏԻՔԱՅԻՆ ՄԻԱՎՈՐՆԵՐԻ
(հավելվածն ուժը կորցրել է 28.12.23 N 2341-Ն)
