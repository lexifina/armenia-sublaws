# Հավելված ՀՀ կառավարության 2006 թվականի ապրիլի 6-ի N 604-Ն որոշման
Ց Ա Ն Կ ԱՇԽԱՏԱԺԱՄԱՆԱԿԻ ԿՐՃԱՏ ՏԵՎՈՂՈՒԹՅՈՒՆ ՈՒՆԵՑՈՂ` ԱՌՈՂՋՈՒԹՅԱՆ ՀԱՄԱՐ ՎՆԱՍԱԿԱՐ ԾԱՌԱՅՈՒԹՅՈՒՆՆԵՐԻ, ԱՇԽԱՏԱՆՔՆԵՐԻ
1. Սույն ցանկով սահմանվում են Հայաստանի Հանրապետության ներքին գործերի նախարարության փրկարար ծառայությունում աշխատաժամանակի կրճատ տևողություն ունեցող` առողջության համար վնասակար ծառայությունները, աշխատանքները:
(1-ին կետը փոփ. 25.09.14 N 1039-Ն, 06.07.23 N 1112-Ն)
2. Հայաստանի Հանրապետության ներքին գործերի նախարարության փրկարար ծառայությունում աշխատաժամանակի կրճատ տևողություն ունեցող ծառայությունների, աշխատանքների տեսակներն են`
ա) աղետի գոտում իրականացվող աշխատանքներ,
բ) կենսաբանական ախտահարված օջախի հետազոտման աշխատանքներ,
գ) քիմիական, ճառագայթային, կենսաբանական ախտահարված և ճառագայթված օջախներում իրականացվող աշխատանքներ,
դ) լաբորատոր պայմաններում հնարավոր քիմիական, կենսաբանական, ճառագայթային ախտահարված նմուշների ստուգման աշխատանքներ,
ե) վարակվածության օջախից դուրս գտնվող հատուկ մշակման կետում հանդերձանքի ախտահանման աշխատանքներ,
զ) քիմիական, ճառագայթային, կենսաբանական ախտահարված և ճառագայթված օջախների տեսակի, տեղի և մակարդակի որոշման, ճառագայթաակտիվ վարակի տարածման ուղիների սպառնալիքի գնահատման աշխատանքներ,
է) բարձր լեռնային շրջաններում իրականացվող աշխատանքներ,
ը) ֆրեզագրեգատներին և օդամղիչներին առնչվող աշխատանքներ,
թ) ջրասուզական և ջրափրկարարական աշխատանքներ,
ժ) հրդեհաշիջման աշխատանքներ:
(2-րդ կետը փոփ. 25.09.14 N 1039-Ն, 06.07.23 N 1112-Ն)
(հավելվածը փոփ. 25.09.14 N 1039-Ն, 06.07.23 N 1112-Ն)
