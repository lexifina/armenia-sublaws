# Հավելված N 2 ՀՀ կառավարության 2002 թվականի հուլիսի 11-ի N 1229-Ն որոշման
Կ Ա Ռ ՈՒ Ց Վ Ա Ծ Ք ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԱՌԵՎՏՐԻ ԵՎ ՏՆՏԵՍԱԿԱՆ ԶԱՐԳԱՑՄԱՆ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԱՇԽԱՏԱԿԱԶՄԻ
I. Կառուցվածքային ստորաբաժանումներ
1. Տնտեսական քաղաքականության և զարգացման պլանավորման վարչություն
2. Ճյուղային և տարածքային տնտեսական զարգացման վարչություն
3. Արտաքին տնտեսական համագործակցության և ներդրումային քաղաքականության վարչություն
4. Գիտության և ինովացիոն քաղաքականության վարչություն
5. Ռազմատնտեսական ծրագրերի վարչություն
6. Բնօգտագործման էկոնոմիկայի և հանքային արդյունաբերության վարչություն
7. Առևտրային քաղաքականության և ներքին շուկայի կարգավորման վարչություն
8. Օրենսդրության և իրավաբանական վարչություն
9. Ֆինանսատնտեսագիտական և հաշվապահական հաշվառման վարչություն
10. Եվրամիության և Առևտրի համաշխարհային կազմակերպության հետ համագործակցության վարչություն
11. Զբոսաշրջության վարչություն
12. Ստանդարտացման և տեխնիկական անվտանգության վարչություն
13. Կազմակերպատնտեսական վարչություն
14. Քարտուղարություն
15. Տեղեկատվական տեխնոլոգիաների զարգացման վարչություն
16. Անձնակազմի կառավարման բաժին
17. Առաջին բաժին
18. Տեղեկատվության և հասարակայնության հետ կապերի բաժին
II. Առանձնացված ստորաբաժանումներ
1. Մտավոր սեփականության գործակալություն
2. Առևտրի համաշխարհային կազմակերպության ծանուցման գործակալություն
3. Հավատարմագրման գործակալություն
4. Կոնցեսիոն գործակալություն
5. Որակի տեսչություն
6. Ակնագործության և ոսկեգործության զարգացման գործակալություն
(Կառուցվածքը լրաց., խմբ. 19.12.02 N 2041-Ն, լրաց. 31.07.03 N 956-Ն, 12.08.04 N 1165-Ն, փոփ., լրաց. 29.12.05 N 2336-Ն, խմբ. 12.04.07 N 439-Ն, լրաց. 13.09.07 N 1053-Ն,)
