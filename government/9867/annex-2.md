# Հավելված N 2 ՀՀ կառավարության 2002 թվականի հուլիսի 11-ի N 1229-Ն որոշման
Կ Ա Ռ ՈՒ Ց Վ Ա Ծ Ք
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԷԿՈՆՈՄԻԿԱՅԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԱՇԽԱՏԱԿԱԶՄԻ
I. ԿԱՌՈՒՑՎԱԾՔԱՅԻՆ ՍՏՈՐԱԲԱԺԱՆՈՒՄՆԵՐ
1. Վարչություններ
Տնտեսական զարգացման քաղաքականության վարչություն
Ներդրումային քաղաքականության վարչություն
(տողը հանվել է 02.05.13 N 489-Ն)
Արդյունաբերության քաղաքականության վարչություն
Տեղեկատվական տեխնոլոգիաների և ինովացիոն քաղաքականության վարչություն
(տողը հանվել է 02.05.13 N 489-Ն)
Առևտրի և շուկաների կարգավորման վարչություն
Զբոսաշրջության վարչություն
Ռազմատնտեսական և զորահավաքային ծրագրերի վարչություն
Որակի ենթակառուցվածքի և տեխնիկական կանոնակարգման վարչություն
Միջազգային տնտեսական համագործակցության վարչություն
Եվրամիության հետ համագործակցության վարչություն
Իրավաբանական վարչություն
Ֆինանսաբյուջետային վարչություն
Անձնակազմի կառավարման վարչություն
Կազմակերպատնտեսական վարչություն
Գործարար միջավայրի բարելավման ու փոքր և միջին ձեռնարկատիրության զարգացման վարչություն
2. Քարտուղարություն
3. Բաժիններ
Տեղեկատվության և հասարակայնության հետ կապերի բաժին
Առաջին բաժին
Ներքին աուդիտի բաժին
II. ԱՌԱՆՁՆԱՑՎԱԾ ՍՏՈՐԱԲԱԺԱՆՈՒՄՆԵՐ
Մտավոր սեփականության գործակալություն
Լիցենզավորման և թույլտվությունների գործակալություն
Շուկայի և սպառողների շահերի պաշտպանության պետական տեսչություն
(հավելվածը լրաց., խմբ. 19.12.02 N 2041-Ն, լրաց. 31.07.03 N 956-Ն, 12.08.04 N 1165-Ն, փոփ., լրաց. 29.12.05 N 2336-Ն, խմբ. 12.04.07 N 439-Ն, լրաց. 13.09.07 N 1053-Ն, խմբ. 15.05.08 N 550-Ն, 25.09.08 N 1096-Ն, լրաց. 01.10.09 N 1241-Ն, խմբ. 28.10.10 N 1461-Ն, 27.01.11 N 69-Ն, լրաց. 16.02.12 N 152-Ն, փոփ. 19.07.12 N 890-Ն, փոփ., լրաց. 02.05.13 N 489-Ն)
