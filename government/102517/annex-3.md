# Հավելված N 3 ՀՀ կառավարության 2015 թվականի դեկտեմբերի 17-ի N 1474-Ն որոշման
Ց Ա Ն Կ
ՓԱԿ ԲԱԺՆԵՏԻՐԱԿԱՆ ԸՆԿԵՐՈՒԹՅՈՒՆՆԵՐԻ ԿԱՆՈՆԱԴՐԱԿԱՆ ԿԱՊԻՏԱԼՆԵՐՈՒՄ ՆԵՐԴՐՎՈՂ ՆՈՐԱԿԱՌՈՒՅՑ ՇԵՆՔԵՐԻ
1. Հայաստանի Հանրապետության Գեղարքունիքի մարզի «Գավառի բժշկական կենտրոն» փակ բաժնետիրական ընկերության դիարանի նորակառույց մասնաշենքը` 96,686,058 դրամ սկզբնական արժեքով, ներդնել Հայաստանի Հանրապետության Գեղարքունիքի մարզի «Գավառի բժշկական կենտրոն» փակ բաժնետիրական ընկերության կանոնադրական կապիտալում:
2. Հայաստանի Հանրապետության Սյունիքի մարզի «Գորիսի բժշկական կենտրոն» փակ բաժնետիրական ընկերության դիարանի նորակառույց մասնաշենքը` 68,569,045.80 դրամ սկզբնական արժեքով, ներդնել Հայաստանի Հանրապետության Սյունիքի մարզի «Գորիսի բժշկական կենտրոն» փակ բաժնետիրական ընկերության կանոնադրական կապիտալում:
3. Հայաստանի Հանրապետության Լոռու մարզի Ախթալայի գյուղական համայնքի «Ախթալայի առողջության կենտրոն» փակ բաժնետիրական ընկերության նորակառույց շենքը` 43,385,733.67 դրամ սկզբնական արժեքով, ներդնել Հայաստանի Հանրապետության Լոռու մարզի Ախթալայի գյուղական համայնքի «Ախթալայի առողջության կենտրոն» փակ բաժնետիրական ընկերության կանոնադրական կապիտալում:
4. Հայաստանի Հանրապետության Տավուշի մարզի Բերդի քաղաքային համայնքի «Բերդի բժշկական կենտրոն» փակ բաժնետիրական ընկերության նորակառույց մասնաշենքը` 300,000,000 դրամ սկզբնական արժեքով, ներդնել Հայաստանի Հանրապետության Տավուշի մարզի Բերդի քաղաքային համայնքի «Բերդի բժշկական կենտրոն» փակ բաժնետիրական ընկերության կանոնադրական կապիտալում:
