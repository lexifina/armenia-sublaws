# Հավելված ՀՀ կառավարության 2002 թվականի հոկտեմբերի 31-ի N 1698-Ն որոշման
Կ Ա Ր Գ
ՀԱՐԿԱՅԻՆ ԾԱՌԱՅՈՒԹՅԱՆ ՄԱՐՄՆԻ ԾԱՌԱՅՈՂԱԿԱՆ ՔՆՆՈՒԹՅՈՒՆ ԱՆՑԿԱՑՆՈՂ ՀԱՆՁՆԱԺՈՂՈՎԻ ԱՆԴԱՄՆԵՐԻ ԹԵԿՆԱԾՈՒՆԵՐԻ ԱՌԱՋԱՐԿՄԱՆ
1. Սույն կարգով կանոնակարգվում է հարկային ծառայության մարմնի ծառայողական քննություն անցկացնող հանձնաժողովի անդամների թեկնածուների առաջարկման կարգը:
2. «Հարկային ծառայության մասին» Հայաստանի Հանրապետության օրենքի համաձայն հարկային ծառայության մարմնի ծառայողական քննություն անցկացնող հանձնաժողովի անհատական կազմը հաստատում է Հայաստանի Հանրապետության հարկային ծառայության (այսուհետ՝ հարկային ծառայություն) մարմնի ղեկավարը՝ վերադաս հարկային մարմնի համապատասխան կառուցվածքային ստորաբաժանման ղեկավարների կողմից առաջարկված թեկնածուներից:
(2-րդ կետը փոփ. 23.10.08 N 1192-Ն)
3. Սույն կարգի համաձայն վերադաս հարկային մարմնի հարկ վճարողների սպասարկման և հարկման ընթացակարգերի, հարկային տեսչությունների աշխատանքների կազմակերպման և ընթացիկ հսկողության, ստուգումների կազմակերպման և դիտարկման, գերատեսչական հսկողության, տեղեկատվական տեխնոլոգիաների, իրավաբանական, քննչական, օպերատիվ հետախուզության վարչությունների ղեկավարները հարկային մարմնի ղեկավարին են ներկայացնում հարկային ծառայության մարմնի ծառայողական քննություն անցկացնող հանձնաժողովի անդամի թեկնածու (թեկնածուներ), որը՝
ա) (ենթակետն ուժը կորցրել է 25.03.04 N 390-Ն)
բ) սույն կարգի 4-րդ կետում նշված ժամկետում պետք է ունենա հարկային ծառայության առնվազն 3 տարվա անընդմեջ աշխատանքային ստաժ.
գ) սույն կարգի 4-րդ կետում նշված ժամկետին նախորդող 2 տարվա ընթացքում չպետք է ենթարկված լինի կարգապահական պատասխանատվության:
դ) (ենթակետն ուժը կորցրել է 20.09.12 N 1197-Ն)
(3-րդ կետը փոփ. 30.01.03 N 129-Ն, փոփ. 25.03.04 N 390-Ն, խմբ., լրաց. 23.10.08 N 1192-Ն, խմբ., փոփ. 20.09.12 N 1197-Ն)
4. Սույն կարգի 3-րդ կետում նշված վերադաս հարկային մարմնի համապատասխան ստորաբաժանումների ղեկավարները յուրաքանչյուր տարվա դեկտեմբեր ամսվա առաջին աշխատանքային օրը հարկային ծառայության մարմնի ղեկավարին ներկայացնում են առաջարկություն հարկային ծառայության մարմնի ծառայողական քննություն անցկացնող հանձնաժողովի անդամի թեկնածուի վերաբերյալ:
Հարկային ծառայության մարմնի ծառայողական քննություն անցկացնող հանձնաժողովի կազմը յուրաքանչյուր տարի 1/3-ով ենթակա է փոփոխության՝ հարկային ծառայության մարմնի ղեկավարի որոշած հերթականությամբ:
(4-րդ կետը փոփ. 23.10.08 N 1192-Ն)
5. Սույն կարգի 4-րդ կետում նշված առաջարկություններին կցվում են հարկային ծառայության մարմնի ծառայողական քննություն անցկացնող հանձնաժողովի անդամի թեկնածուի ծառայողական բնութագիրը, թեկնածուի մասին հարկային ծառայության մրցութային և ատեստավորման հանձնաժողովի եզրակացությունը, որը պետք է ներառի թեկնածուի կողմից հարկային օրենսդրության և հարկային ծառայության մարմնի կառուցվածքային ստորաբաժանումների գործառույթների իմացության գնահատականը:
6. Նախքան սույն կարգի 4-րդ կետով նախատեսված ժամկետը լրանալը՝ հարկային ծառայության մարմնի ղեկավարը հարկային ծառայության մարմնի ծառայողական քննություն անցկացնող հանձնաժողովի նոր անդամ է նշանակում գործող անդամի հարկային ծառայության պաշտոնից ազատվելու կամ այլ ստորաբաժանում տեղափոխվելու, ինչպես նաև կարգապահական պատասխանատվության ենթարկվելու դեպքերում: Ծառայողական անհրաժեշտությունից ելնելով, համապատասխան ստորաբաժանման ղեկավարի հիմնավորմամբ, հարկային ծառայության մարմնի ծառայողական քննություն անցկացնող հանձնաժողովի անդամը հարկային ծառայության մարմնի ղեկավարի կողմից կարող է մինչև մեկ ամիս ժամկետով փոխարինվել նույն ստորաբաժանման մեկ այլ հարկային ծառայողով:
Նախքան սույն կարգով նախատեսված ժամկետը լրանալը՝ հարկային ծառայության մարմնի ծառայողական քննություն անցկացնող հանձնաժողովի նոր անդամի թեկնածուն առաջարկվում է սույն կարգով՝ նախկին անդամի պաշտոնավարման չլրացած ժամկետով:
(հավելվածը փոփ. 30.01.03 N 129-Ն, 25.03.04 N 390-Ն, փոփ., խմբ., լրաց. 23.10.08 N 1192-Ն, խմբ., փոփ. 20.09.12 N 1197-Ն)
