# Հավելված N 2 ՀՀ կառավարության 2003 թվականի սեպտեմբերի 17-ի N 1193-Ն որոշման

Դ. Լոքյան | - ՀՀ գյուղատնտեսության նախարար (խորհրդի նախագահ)
Վ. Տերտերյան | - ՀՀ տարածքային կառավարման նախարարի տեղակալ
Կ. Աթոյան | - ՀՀ ֆինանսների և էկոնոմիկայի նախարարի տեղակալ
Ս. Գալստյան | - ՀՀ գյուղատնտեսության նախարարի տեղակալ
Ա. Ափոյան | - «Աշտարակ կաթ» փակ բաժնետիրական ընկերության նախագահ (համաձայնությամբ)
Գ. Սարդարյան | - «Ագրոբիզնեսի և գյուղի զարգացման կենտրոն» հիմնադրամի գործադիր տնօրեն (համաձայնությամբ)
Ա. Թամրազյան | - «Դիլի» սահմանափակ պատասխանատվությամբ ընկերության հիմնադիր (համաձայնությամբ)
Գ. Մկրտչյան | - «Արմենի տեխնոլոջի գրուպ» հիմնադրամի գործադիր տնօրեն (համաձայնությամբ)
Ա. Պետրոսյան | - «ՄԱՊ» սահմանափակ պատասխանատվությամբ ընկերության խորհրդի նախագահ (համաձայնությամբ)
Հ. Հովհաննիսյան | - ՀՀ գյուղատնտեսության նախարարության աշխատակազմի ֆինանսատնտեսագիտական և հաշվապահական հաշվառման վարչության պետ
Գ. Ավագյան | - ՀՀ գյուղատնտեսության նախարարության աշխատակազմի իրավաբանական վարչության օրենսդրական բարեփոխումների բաժնի պետ
(հավելվածը փոփ. 25.08.05 N 1387-Ն, 30.03.06 N 380-Ն, խմբ. 09.08.07 N 910-Ն)
