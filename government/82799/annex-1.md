# Հավելված N 1 ՀՀ կառավարության 2013 թվականի մարտի 21-ի N 271-Ն որոշման
Ծ Ր Ա Գ Ի Ր
ՄԱՐՏԱԿԱՆ ԳՈՐԾՈՂՈՒԹՅՈՒՆՆԵՐԻ ՀԵՏԵՎԱՆՔՈՎ ՉՕԳՏԱԳՈՐԾՎՈՂ ԵՎ ՀԱԿԱՌԱԿՈՐԴԻ ԿՈՂՄԻՑ ՀՈՂԱՏԱՐԱԾՔՆԵՐԻ ԳՆԴԱԿՈԾՄԱՆ ԴԵՊՔԵՐ ՈՒՆԵՑՈՂ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՍԱՀՄԱՆԱՄԵՐՁ ՀԱՄԱՅՆՔՆԵՐԻ ՀՈՂԻ ՀԱՐԿ ՎՃԱՐՈՂ ՖԻԶԻԿԱԿԱՆ ԵՎ ԻՐԱՎԱԲԱՆԱԿԱՆ ԱՆՁԱՆՑ ԵՎ ՋՐՕԳՏԱԳՈՐԾՈՂՆԵՐԻ ԸՆԿԵՐՈՒԹՅՈՒՆՆԵՐԻ ՍՊԱՍԱՐԿՄԱՆ ՏԱՐԱԾՔՈՒՄ ԸՆԴԳՐԿՎԱԾ ԱՅԴ ՀԱՄԱՅՆՔՆԵՐՈՒՄ ՈՌՈԳՄԱՆ ՋՈՒՐ ՕԳՏԱԳՈՐԾՈՂ ՖԻԶԻԿԱԿԱՆ ԵՎ ԻՐԱՎԱԲԱՆԱԿԱՆ ԱՆՁԱՆՑ ՊԵՏԱԿԱՆ ԱՋԱԿՑՈՒԹՅՈՒՆ ՑՈՒՑԱԲԵՐԵԼՈՒ (հավելվածն ուժը կորցրել է 18.12.14 N 1444-Ն )
