# Հավելված N 8 ՀՀ կառավարության 2006 թվականի նոյեմբերի 23-ի N 1910-Ն որոշման
Կ Ա Ր Գ
ՎԵՐԱՀՈՒՂԱՐԿԱՎՈՐՄԱՆ
1. Սույն կարգով սահմանվում են վերահուղարկավորման հետ կապված գործընթացները:
2. Հուղարկավորության կազմակերպումը ստանձնած անձի ցանկությամբ և գերեզման օգտագործողի համաձայնությամբ` մահացածի վերահուղարկավորումը (գերեզմանից այլ գերեզման տեղափոխելը) իրականացվում է թաղումից առնվազն երեք տարի հետո` բացառությամբ սույն հավելվածի 2.1-ին կետով նախատեսված դեպքի մահացածի հարազատների միջոցների հաշվին:
(2-րդ կետը լրաց. 10.08.21 N 1302-Ն, փոփ. 31.03.22 N 425-Ն)
2.1. 2020 թվականի սեպտեմբերի 27-ին Ադրբեջանի Հանրապետության կողմից Արցախի Հանրապետության դեմ սանձազերծված պատերազմական գործողությունների հետևանքով մահացած և հուղարկավորված, ինչպես նաև գերեզմանատան կազմակերպման համար նախատեսված վայրերից դուրս հուղարկավորված անձանց միայն առաջին անգամ վերահուղարկավորում իրականացնելու դեպքում ժամկետային սահմանափակումներ չեն գործում:
(2.1-ին կետը լրաց. 10.08.21 N 1302-Ն, 31.03.22 N 425-Ն)
3. Վերահուղարկավորումը թույլատրում է գերեզմանատան տնօրինությունը` հուղարկավորության կազմակերպումն ստանձնած անձի դիմումի և գերեզման օգտագործողի գրավոր համաձայնության, մահացածի մահվան վկայականի, ինչպես նաև բնակչության սանիտարահամաճարակային անվտանգության ապահովման և հանրային առողջապահության բնագավառում գործունեություն իրականացնող Հայաստանի Հանրապետության առողջապահության նախարարության ենթակայության պետական կազմակերպության (այսուհետ՝ պետական կազմակերպություն) կողմից տրված վերահուղարկավորում իրականացնելու հնարավորության վերաբերյալ եզրակացության և Հայաստանի Հանրապետության ոստիկանության համաձայնության հիման վրա` դրանք ստանալուց հետո մեկօրյա ժամկետում։
Մահացածի հուղարկավորության կազմակերպումը ստանձնած անձն այլ բնակավայրի գերեզմանատուն տեղափոխելու դեպքում ներկայացնում է նաև տվյալ բնակավայրի գերեզմանատան տնօրինության թույլտվությունը:
(3-րդ կետը փոփ. 30.11.17 N 1514-Ն, խմբ. 31.03.22 N 425-Ն, 31.07.25 N 1064-Ն)
3.1. Վերահուղարկավորում իրականացնելու հնարավորության կամ անհնարինության մասին եզրակացություն ստանալու համար գերեզմանատան տնօրինությունը վերահուղարկավորում իրականացնելու թույլտվության դիմումի ստացման օրը կից գրությամբ էլեկտրոնային եղանակով պետական կազմակերպություն է ներկայացնում մահացածի հուղարկավորության կազմակերպումն ստանձնողի դիմումը, մահացածի մահվան վկայականը` դրանք ուղարկելով պետական կազմակերպության պաշտոնական էլեկտրոնային փոստի հասցեով։
(3.1-ին կետը լրաց. 31.07.25 N 1064-Ն)
3.2. Պետական կազմակերպությունը սույն կարգի 3.1-ին կետում նշված գերեզմանատան տնօրինության գրությունն ստանալու պահից մեկ օրվա ընթացքում վերահուղարկավորում իրականացնելու հնարավորության կամ անհնարինության մասին եզրակացությունը ներկայացնում է գերեզմանատան տնօրինություն էլեկտրոնային եղանակով` ուղարկելով գերեզմանատան տնօրինության պաշտոնական էլեկտրոնային փոստի հասցեով։
(3.2-րդ կետը լրաց. 31.07.25 N 1064-Ն)
3.3. Պետական կազմակերպության կողմից տրվում է վերահուղարկավորում իրականացնելու անհնարինության մասին եզրակացությունը, եթե՝
1) մահացածի թաղումից չի անցել առնվազն երեք տարի, բացառությամբ սույն կարգի 2.1-ին կետով նախատեսված դեպքերի.
2) մահացածի մահվան պատճառը եղել է մարդու համար ախտածնության I-II խմբերի միկրոօրգանիզմներով (ժանտախտի, խոլերայի, դեղին տենդի) հարուցված վարակներից որևէ մեկը.
3) սույն կարգի 3.1-ին կետով սահմանված փաստաթղթերն ամբողջական կամ ընթեռնելի չլինելու դեպքում։
(3.3-րդ կետը լրաց. 31.07.25 N 1064-Ն)
3.4. Սույն կարգի 3.3-րդ կետով սահմանված վերահուղարկավորում իրականացնելու անհնարինության հիմքերի բացակայության դեպքում պետական կազմակերպության կողմից տրվում է վերահուղարկավորում իրականացնելու հնարավորության մասին եզրակացությունը։
(3.4-րդ կետը լրաց. 31.07.25 N 1064-Ն)
3.5. Պետական կազմակերպության կողմից վերահուղարկավորում իրականացնելու հնարավորության կամ անհնարինության մասին եզրակացությունը տրվում է անվճար։
(3.5-րդ կետը լրաց. 31.07.25 N 1064-Ն)
4. Մահացածի աճյունը (աճյունի մնացորդները) գերեզմանից հանվում է ցերեկային ժամերին, գերեզմանատան տնօրինության ու Առողջապահական և աշխատանքի տեսչական մարմնի ներկայացուցիչների պարտադիր ներկայությամբ, ինչպես նաև ոստիկանության ներկայացուցչի մասնակցությամբ:
(4-րդ կետը փոփ. 30.11.17 N 1514-Ն, 31.03.22 N 425-Ն)
5. Մահացածի աճյունը (աճյունի մնացորդները) գերեզմանից հանելուց հետո գերեզմանատան տնօրինության կողմից գերեզմանահորն անմիջապես ախտահանվում է, լցվում հողով, և տեղը հարթեցվում է:
6. Հանված աճյունը (աճյունի մնացորդները) փաթաթվում է բամբակյա կտորով և տեղադրվում պոլիէթիլենային պարկի մեջ, որից հետո տեղադրվում է փայտյա արկղի կամ դագաղի մեջ և տեղափոխվում նոր գերեզման: Նոր գերեզմանում թաղելուց առաջ աճյունը (աճյունի մնացորդները) հանվում է պոլիէթիլենային պարկից:
7. Նախկին և նոր գերեզմանների գերեզմանատների տնօրինությունները վերահուղարկավորման մասին գրանցումներ են կատարում թաղումների և գերեզմանատեղերի գրանցման մատյաններում ու գերեզմանների վկայականներում:
8. Գերեզմանատների տեղափոխման դեպքում վերահուղարկավորումն իրականացվում է օրենքով սահմանված կարգով և այդ դեպքերի համար նախատեսված միջոցների հաշվին:
(հավելվածը փոփ. 30.11.17 N 1514-Ն, լրաց. 10.08.21 N 1302-Ն, փոփ., լրաց., խմբ. 31.03.22 N 425-Ն, խմբ., լրաց. 31.07.25 N 1064-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
