# Հավելված N 2 ՀՀ կառավարության 2002 թվականի հուլիսի 11-ի N 1231-Ն որոշման
Կ Ա Ռ ՈՒ Ց Վ Ա Ծ Ք
ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԷԿՈՆՈՄԻԿԱՅԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ՄՏԱՎՈՐ ՍԵՓԱԿԱՆՈՒԹՅԱՆ ԳՈՐԾԱԿԱԼՈՒԹՅԱՆ
(վերնագիրը փոփ. 12.04.07 N 428-Ն, 15.05.08 N 550-Ն)
Կառուցվածքային ստորաբաժանումներ
1. Գյուտերի և օգտակար մոդելների բաժին
2. Ապրանքային նշանների և արդյունաբերական նմուշների բաժին
3. (տողը հանվել է 25.10.12 N 1331-Ն)
4. Հեղինակային և հարակից իրավունքների բաժին
5. Տեղեկատվական-տեխնոլոգիական ապահովման բաժին
6. Հայտերի ընդունման բաժին
7. Պետական գրանցամատյանների բաժին
(հավելվածը փոփ. 12.04.07 N 428-Ն, 15.05.08 N 550-Ն, 25.10.12 N 1331-Ն)
