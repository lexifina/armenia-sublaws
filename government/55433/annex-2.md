# Հավելված N 2 ՀՀ կառավարության 2009 թվականի դեկտեմբերի 3-ի N 1417-Ն որոշման
Կ Ա Ր Գ
ՓԱԽՍՏԱԿԱՆԻՆ ՏՐՎՈՂ ԿՈՆՎԵՆՑԻՈՆ ՃԱՄՓՈՐԴԱԿԱՆ ՓԱՍՏԱԹՈՒՂԹԸ ՏԱԼՈՒ
1. Կոնվենցիոն ճամփորդական փաստաթուղթը (այսուհետ` փաստաթուղթ) փախստականին տրվում է Հայաստանի Հանրապետության կառավարությանն առընթեր Հայաստանի Հանրապետության ոստիկանության մարմինների կողմից (այսուհետ` ոստիկանություն)` Հայաստանի Հանրապետության տարածքային կառավարման նախարարության միգրացիոն պետական ծառայության (այսուհետ` ծառայություն) պետի` փախստական ճանաչելու և ապաստան տրամադրելու վերաբերյալ որոշման հիման վրա:
(1-ին կետը փոփ. 18.03.10 N 317-Ն, խմբ. 07.07.11 N 939-Ն)
2. Հայաստանի Հանրապետությունում ապաստանի տրամադրման և փախստական ճանաչելու վերաբերյալ որոշումը ծառայության պետն ընդունում է` հիմք ընդունելով ծառայության կողմից ապաստան հայցողի վերաբերյալ նախապատրաստված փաստաթղթերը:
(2-րդ կետը փոփ. 18.03.10 N 317-Ն)
3. Փաստաթուղթը տրվում է Հայաստանի Հանրապետությունում ապաստան ստացած փախստականներին: Մինչև 16 տարեկան փախստականի տվյալներն ընդգրկվում են իր ծնողների փաստաթղթերում:
4. Մինչև 16 տարեկան` առանց ուղեկցողի կամ ընտանիքից անջատված անչափահաս փախստականներին տրամադրվում է փաստաթուղթ, որը չի կարող օգտագործվել առանց խնամակալի Հայաստանի Հանրապետությունից դուրս գալու դեպքում:
5. Փաստաթուղթը վավերական է երկու տարի, որից հետո ոստիկանությունը փախստականի դիմումի հիման վրա յուրաքանչյուր անգամ փաստաթղթի վավերականության ժամկետը երկարաձգում է ևս երկու տարով:
Փաստաթղթի վավերականության ժամկետն օտարերկրյա պետություններում երկարաձգվում է Հայաստանի Հանրապետության դիվանագիտական ներկայացուցչությունների կամ հյուպատոսական հիմնարկների կողմից: Փաստաթղթի վավերականության ժամկետը կարող է երկարաձգվել նաև, եթե դրա վավերականության ժամկետը լրանալուն մնացել է ոչ ավելի, քան 7 ամիս:
(5-րդ կետը փոփ. 18.03.10 N 317-Ն, փոփ., լրաց. 07.07.11 N 939-Ն)
6. Ապաստանի տրամադրման կամ փախստականի ճանաչման մասին որոշումը ծառայության պետի կողմից սահմանված կարգով չեղյալ հայտարարելու կամ դադարեցնելու մասին վերջնական որոշում ընդունվելու դեպքում դրա մասին տեղեկացվում է ոստիկանությանը` փաստաթուղթն անվավեր ճանաչելու համար:
(6-րդ կետը փոփ. 18.03.10 N 317-Ն, խմբ. 07.07.11 N 939-Ն)
7. Փաստաթուղթը պատրաստվում է միասնական նմուշով` հայերեն, ռուսերեն և անգլերեն:
8. Փաստաթղթում փախստականի անձի մասին նշվում են հետևյալ տեղեկությունները`
1) ազգանունը, անունը, հայրանունը.
2) սեռը.
3) ծննդյան վայրը, ամսաթիվը, ամիսը, տարեթիվը.
4) քաղաքացիությունը (կամ դրա բացակայությունը):
9. Փաստաթղթում կարող են կատարվել հետևյալ նշումները`
1) փաստաթղթի վավերականության ժամկետը երկարաձգելու մասին` ոստիկանության, իսկ օտարերկրյա պետություններում` Հայաստանի Հանրապետության դիվանագիտական ներկայացուցչությունների կամ հյուպատոսական հիմնարկների կողմից.
2) օտարերկրյա պետություններ ժամանակավորապես մեկնելու և վերադառնալու մասին` սահմանային ծառայությունների կողմից.
3) Հայաստանի Հանրապետությունում բնակության վայրի մասին` ոստիկանության կողմից.
4) ընտանեկան դրության մասին` քաղաքացիական կացության ակտերի գրանցման տարածքային մարմինների կողմից:
(9-րդ կետը փոփ., լրաց. 18.03.10 N 317-Ն, փոփ., լրաց. 07.07.11 N 939-Ն)
10. Արգելվում է փախստականի փաստաթղթում այլ նշումներ կատարելը:
11. Փախստականը փաստաթուղթ ստանալու համար ոստիկանություն է ներկայացնում`
1) դիմում փաստաթուղթ ստանալու մասին.
2) ոստիկանության պետի որոշումն իրեն փախստական ճանաչելու մասին.
3) 35 x 45 մմ չափսի 2 լուսանկար (գունավոր):
(11-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն)
12. Փախստականի հետ ճամփորդող յուրաքանչյուր երեխայի համար անհրաժեշտ է ներկայացնել`
1) ծննդյան վկայականը.
2) 35 x 45 մմ չափսի 2 լուսանկար (գունավոր):
13. Փաստաթուղթը տրվում է դիմումն ստանալուց հետո հինգ աշխատանքային օրվա ընթացքում:
(13-րդ կետը փոփ. 07.07.11 N 939-Ն)
14. Փաստաթուղթը փոխանակվում է ոստիկանության կողմից:
(14-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն)
15. Փաստաթուղթը կարող է փոխանակվել դրանում պարունակվող տեղեկությունները փոխվելու, գրառումներում անճշտություններ հայտնաբերվելու, օգտագործվելու համար ոչ պիտանի լինելու դեպքում:
16. Փախստականը փաստաթղթի փոխանակման համար ներկայացնում է փոխանակման ենթակա փաստաթուղթը, սահմանված ձևի դիմում և երկու` 35 x 45 մմ չափսի լուսանկար (գունավոր):
17. Փախստականը, փաստաթղթում որևէ տեղեկություն փոխելու կամ գրառումներում անճշտություններ հայտնաբերելու պատճառով այն փոխանակելիս, ներկայացնում է նաև փոփոխությունները կամ առկա անճշտությունները հավաստող փաստաթուղթ:
18. Փախստականը փաստաթուղթը կորցնելու դեպքում 10-օրյա ժամկետում դրա մասին հայտնում է ոստիկանությանը, իսկ օտարերկրյա պետություններում` Հայաստանի Հանրապետության դիվանագիտական ներկայացուցչությանը կամ հյուպատոսական հիմնարկին:
(18-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն)
19. Հայաստանի Հանրապետության քաղաքացիություն ձեռք բերելու կամ այլ պատճառով փախստականի ճանաչումը և ապաստանի տրամադրումը դադարեցվելու դեպքում անձը փաստաթուղթը հանձնում է ոստիկանությանը, իսկ օտարերկրյա պետություններում` Հայաստանի Հանրապետության դիվանագիտական ներկայացուցչությանը կամ հյուպատոսական հիմնարկին:
(19-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն)
20. Օտարերկրյա պետությունում մշտական բնակություն հաստատելու դեպքում անձը փաստաթուղթը հանձնում է Հայաստանի Հանրապետության դիվանագիտական ներկայացուցչությանը կամ հյուպատոսական հիմնարկին:
21. Մահացած փախստականի փաստաթուղթը հանձնվում է մահվան գրանցումը կատարող մարմնին: Մահվան գրանցման կատարումից հետո փաստաթուղթն ուղարկվում է ոստիկանություն:
(21-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն)
22. Օտարերկրյա պետությունում մահացած փախստականի փաստաթուղթը հանձնվում է Հայաստանի Հանրապետության դիվանագիտական ներկայացուցչությանը կամ հյուպատոսական հիմնարկին, որն այն հանձնում է ոստիկանությանը:
(22-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն)
23. Գտնված փաստաթղթերը հանձնվում են ոստիկանությանը:
(23-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն)
24. Փաստաթղթի կորստի, փչացման կամ գողանալու դեպքում ոստիկանությունը, գործը մանրամասն ուսումնասիրելուց հետո, անհրաժեշտության դեպքում, համագործակցելով ծառայության հետ, փախստականին տրամադրում է նոր փաստաթուղթ` նախորդ փաստաթղթի վավերականության ժամկետով: Նոր փաստաթուղթ ստանալու համար փախստականը ոստիկանություն է ներկայացնում նոր փաստաթուղթ ստանալու մասին դիմում և 2 գունավոր լուսանկար:
(24-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն)
25. Կասկածյալների, որոնց նկատմամբ որպես խափանման միջոց է ընտրվել չհեռանալու մասին ստորագրությունը, և մեղադրյալների, որոնց նկատմամբ որպես խափանման միջոց է ընտրվել կալանավորումը, ինչպես նաև ազատազրկման դատապարտված փախստականների փաստաթղթերը վերցվում են հետաքննության, նախաքննության մարմինների կամ դատարանի կողմից:
26. Խափանման միջոցի վերացման դեպքում` կասկածյալների և մեղադրյալների փաստաթղթերը վերադարձվում են տերերին:
27. Պատիժը կրելուց հետո փախստականին կարող է տրվել նոր փաստաթուղթ` սույն կարգով սահմանված ընդհանուր հիմունքներով:
28. Փաստաթուղթը վերցնելը (բացառությամբ սույն կարգի 25-րդ կետում նշված դեպքերի), այլ անձանց հանձնելը և գրավ դնելն արգելվում են:
29. Ոստիկանությունը փախստականին փաստաթուղթ տալու մասին տեղեկությունները հայտնում է ծառայությանը:
(29-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն)
