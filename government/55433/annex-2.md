# Հավելված N 2 ՀՀ կառավարության 2009 թվականի դեկտեմբերի 3-ի N 1417-Ն որոշման
Կ Ա Ր Գ
ՓԱԽՍՏԱԿԱՆԻՆ, ԻՆՉՊԵՍ ՆԱԵՎ ՔԱՂԱՔԱԿԱՆ ԱՊԱՍՏԱՆԻ ԻՐԱՎՈՒՆՔ ՍՏԱՑԱԾ ԱՆՁԻՆ ՏՐՎՈՂ ԿՈՆՎԵՆՑԻՈՆ ՃԱՄՓՈՐԴԱԿԱՆ ՓԱՍՏԱԹՈՒՂԹԸ ՏԱԼՈՒ
(վերնագիրը լրաց. 01.03.12 N 219-Ն)
1. Կոնվենցիոն ճամփորդական փաստաթուղթը (այսուհետ` փաստաթուղթ) փախստականին տրվում է Հայաստանի Հանրապետության ոստիկանության մարմինների կողմից (այսուհետ` ոստիկանություն)` Հայաստանի Հանրապետության ներքին գործերի նախարարության միգրացիայի և քաղաքացիության ծառայության (այսուհետ` ծառայություն) պետի` փախստական ճանաչելու և ապաստան տրամադրելու վերաբերյալ որոշման հիման վրա:
(1-ին կետը փոփ. 18.03.10 N 317-Ն, խմբ. 07.07.11 N 939-Ն, փոփ. 02.11.23 N 1880-Ն)
1.1. Փաստաթուղթը քաղաքական ապաստանի իրավունք ստացած անձին տրվում է ոստիկանության կողմից` անձին Հայաստանի Հանրապետությունում քաղաքական ապաստանի իրավունք տալու մասին Հայաստանի Հանրապետության Նախագահի որոշման հիման վրա:
(1.1-ին կետը լրաց. 01.03.12 N 219-Ն)
2. Հայաստանի Հանրապետությունում ապաստանի տրամադրման և փախստական ճանաչելու վերաբերյալ որոշումը ծառայության պետն ընդունում է` հիմք ընդունելով ծառայության կողմից ապաստան հայցողի վերաբերյալ նախապատրաստված փաստաթղթերը:
(2-րդ կետը փոփ. 18.03.10 N 317-Ն)
3. Փաստաթուղթը տրվում է Հայաստանի Հանրապետությունում ապաստան ստացած փախստականներին, ինչպես նաև քաղաքական ապաստանի իրավունք ստացած անձանց: Փաստաթուղթ կարող է տրվել նաև մինչև 16 տարեկան այն փախստականին, որի ծնողները Հայաստանի Հանրապետությունում ապաստան ստացած փախստական չեն:
(3-րդ կետը լրաց. 01.03.12 N 219-Ն, 23.10.13 N 1147-Ն, փոփ. 02.11.23 N 1880-Ն)
4. Մինչև 16 տարեկան` առանց ուղեկցողի կամ ընտանիքից անջատված փախստականներին տրամադրվում է փաստաթուղթ, որը չի կարող օգտագործվել առանց խնամակալի կամ հոգաբարձուի համաձայնության: Քաղաքական ապաստանի իրավունք ստացած անձի` մինչև 16 տարեկան երեխաներին տրամադրվում է փաստաթուղթ, որը չի կարող օգտագործվել առանց ծնողների համաձայնության:
(4-րդ կետը խմբ. 01.03.12 N 219-Ն)
5. Փաստաթուղթը վավերական է երկու տարի, որից հետո ոստիկանությունը փախստականի դիմումի հիման վրա յուրաքանչյուր անգամ փաստաթղթի վավերականության ժամկետը երկարաձգում է ևս երկու տարով: Քաղաքական ապաստան ստացած անձին տրվող փաստաթուղթը վավերական է մեկ տարի, որը չի կարող գերազանցել քաղաքական ապաստանի իրավունքի վավերականության ժամկետը: Անձին տրված քաղաքական ապաստանի իրավունքը «Քաղաքական ապաստանի մասին» Հայաստանի Հանրապետության օրենքով սահմանված կարգով յուրաքանչյուր անգամ մեկ տարի ժամկետով երկարաձգվելու դեպքում ոստիկանությունը, քաղաքական ապաստան ստացած անձի դիմումի հիման վրա, յուրաքանչյուր անգամ փաստաթղթի վավերականության ժամկետը երկարաձգում է ևս մեկ տարով:
Փաստաթղթի վավերականության ժամկետն օտարերկրյա պետություններում երկարաձգվում է Հայաստանի Հանրապետության դիվանագիտական ներկայացուցչությունների կամ հյուպատոսական հիմնարկների կողմից: Փաստաթղթի վավերականության ժամկետը կարող է երկարաձգվել նաև, եթե դրա վավերականության ժամկետը լրանալուն մնացել է ոչ ավելի, քան 7 ամիս, իսկ քաղաքական ապաստանի իրավունք ստացած անձի փաստաթղթինը` 3 ամիս:
(5-րդ կետը փոփ. 18.03.10 N 317-Ն, փոփ., լրաց. 07.07.11 N 939-Ն, լրաց. 01.03.12 N 219-Ն)
6. Փախստականի ճանաչումը և ապաստանի տրամադրումը, ինչպես նաև քաղաքական ապաստանի իրավունքի տրամադրումը Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով վերջնական չեղյալ հայտարարվելու կամ դադարեցվելու դեպքում դրա մասին տեղեկացվում է ոստիկանությանը` փաստաթուղթն անվավեր ճանաչելու համար:
(6-րդ կետը փոփ. 18.03.10 N 317-Ն, խմբ. 07.07.11 N 939-Ն, փոփ. 01.03.12 N 219-Ն)
7. Փաստաթուղթը պատրաստվում է միասնական նմուշով` հայերեն, ռուսերեն և անգլերեն:
8. Փաստաթղթում անձի մասին նշվում են հետևյալ տեղեկությունները`
1) ազգանունը, անունը, հայրանունը.
2) սեռը.
3) ծննդյան վայրը, ամսաթիվը, ամիսը, տարեթիվը.
4) քաղաքացիությունը (կամ դրա բացակայությունը).
5) հանրային ծառայությունների համարանիշը:
(8-րդ կետը փոփ. 01.03.12 N 219-Ն, լրաց. 05.04.12 N 419-Ն)
9. Փաստաթղթում կարող են կատարվել հետևյալ նշումները`
1) փաստաթղթի վավերականության ժամկետը երկարաձգելու մասին` ոստիկանության, իսկ օտարերկրյա պետություններում` Հայաստանի Հանրապետության դիվանագիտական ներկայացուցչությունների կամ հյուպատոսական հիմնարկների կողմից.
2) oտարերկրյա պետություններ ժամանակավորապես մեկնելու և վերադառնալու մասին` սահմանային ծառայությունների կողմից.
3) Հայաստանի Հանրապետությունում բնակության վայրի մասին` ոստիկանության կողմից.
4) ընտանեկան դրության մասին` քաղաքացիական կացության ակտերի գրանցման տարածքային մարմինների կողմից:
(9-րդ կետը փոփ., լրաց. 18.03.10 N 317-Ն, փոփ., լրաց. 07.07.11 N 939-Ն)
10. Արգելվում է փաստաթղթում այլ նշումներ կատարելը:
(10-րդ կետը փոփ. 01.03.12 N 219-Ն)
11. Փաստաթուղթ ստանալու համար ոստիկանություն է ներկայացվում`
1) դիմում փաստաթուղթ ստանալու մասին.
2) ծառայության պետի որոշումը տվյալ անձին փախստական ճանաչելու մասին կամ Հայաստանի Հանրապետության Նախագահի որոշումը տվյալ անձին քաղաքական ապաստանի իրավունք տրամադրելու մասին.
3) 35 x 45 մմ չափսի 2 լուսանկար (գունավոր):
(11-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն, փոփ., խմբ. 01.03.12 N 219-Ն)
11.1. Մինչև 16 տարեկան փախստականի ծնողներից մեկը կամ օրինական ներկայացուցիչը մինչև 16 տարեկան փախստականին տրվող փաստաթուղթն ստանալու կամ փոխանակելու համար ներկայացնում է`
1) դիմում փաստաթուղթ ստանալու մասին.
2) ծառայության պետի որոշումը մինչև 16 տարեկան անձին փախստական ճանաչելու և ապաստան տրամադրելու մասին.
3) «35 x 45 մմ» չափսի երկու լուսանկար (գունավոր).
4) երեխայի անձնագիրը կամ ծննդյան վկայականը կամ անձը հաստատող այլ փաստաթուղթ.
5) դիմող ծնողի կամ այլ օրինական ներկայացուցչի անձը հաստատող փաստաթուղթը:
Մինչև 16 տարեկան փախստականների փաստաթղթերն ստանում է նրանց ծնողներից մեկը կամ այլ օրինական ներկայացուցիչը կամ նրանց կողմից Հայաստանի Հանրապետության օրենսդրությամբ սահմանված կարգով լիազորված ներկայացուցիչը:
(11.1-ին կետը լրաց. 23.10.13 N 1147-Ն)
12. Փախստականի, ինչպես նաև քաղաքական ապաստանի իրավունք ստացած անձի հետ ճամփորդող յուրաքանչյուր երեխայի համար անհրաժեշտ է ներկայացնել`
1) ծննդյան վկայականը.
2) 35 x 45 մմ չափսի 2 լուսանկար (գունավոր):
(12-րդ կետը լրաց. 01.03.12 N 219-Ն)
13. Փաստաթուղթը տրվում է դիմումն ստանալուց հետո հինգ աշխատանքային օրվա ընթացքում:
(13-րդ կետը փոփ. 07.07.11 N 939-Ն)
14. Փաստաթուղթը փոխանակվում է ոստիկանության կողմից:
(14-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն)
15. Փաստաթուղթը կարող է փոխանակվել դրանում պարունակվող տեղեկությունները փոխվելու, գրառումներում անճշտություններ հայտնաբերվելու, oգտագործվելու համար ոչ պիտանի լինելու դեպքում:
16. Անձը փաստաթղթի փոխանակման համար ներկայացնում է փոխանակման ենթակա փաստաթուղթը, սահմանված ձևի դիմում և երկու` 35 x 45 մմ չափսի լուսանկար (գունավոր):
(16-րդ կետը փոփ. 01.03.12 N 219-Ն)
17. Անձը, փաստաթղթում որևէ տեղեկություն փոխելու կամ գրառումներում անճշտություններ հայտնաբերելու պատճառով այն փոխանակելիս, ներկայացնում է նաև փոփոխությունները կամ առկա անճշտությունները հավաստող փաստաթուղթ:
(17-րդ կետը փոփ. 01.03.12 N 219-Ն)
18. Անձը փաստաթուղթը կորցնելու դեպքում 10-oրյա ժամկետում դրա մասին հայտնում է ոստիկանությանը, իսկ oտարերկրյա պետություններում` Հայաստանի Հանրապետության դիվանագիտական ներկայացուցչությանը կամ հյուպատոսական հիմնարկին:
(18-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն, 01.03.12 N 219-Ն)
19. Հայաստանի Հանրապետության քաղաքացիություն ձեռք բերելու կամ այլ պատճառով փախստականի ճանաչումը և ապաստանի տրամադրումը կամ քաղաքական ապաստանի իրավունքը դադարեցվելու դեպքում անձը փաստաթուղթը հանձնում է ոստիկանությանը, իսկ օտարերկրյա պետություններում` Հայաստանի Հանրապետության դիվանագիտական ներկայացուցչությանը կամ հյուպատոսական հիմնարկին:
(19-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն, լրաց. 01.03.12 N 219-Ն)
20. Oտարերկրյա պետությունում մշտական բնակություն հաստատելու դեպքում անձը փաստաթուղթը հանձնում է Հայաստանի Հանրապետության դիվանագիտական ներկայացուցչությանը կամ հյուպատոսական հիմնարկին:
21. Մահացած անձի փաստաթուղթը հանձնվում է մահվան գրանցումը կատարող մարմնին: Մահվան գրանցման կատարումից հետո փաստաթուղթն ուղարկվում է ծառայություն:
(21-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն, 01.03.12 N 219-Ն)
22. Օտարերկրյա պետությունում մահացած անձի փաստաթուղթը հանձնվում է Հայաստանի Հանրապետության դիվանագիտական ներկայացուցչությանը կամ հյուպատոսական հիմնարկին, որն այն հանձնում է ոստիկանությանը:
(22-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն, 01.03.12 N 219-Ն)
23. Գտնված փաստաթղթերը հանձնվում են ոստիկանությանը:
(23-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն)
24. Փաստաթղթի կորստի, փչացման կամ գողանալու դեպքում ոստիկանությունը, գործը մանրամասն ուսումնասիրելուց հետո, անհրաժեշտության դեպքում, համագործակցելով ծառայության հետ, անձին տրամադրում է նոր փաստաթուղթ` նախորդ փաստաթղթի վավերականության ժամկետով: Նոր փաստաթուղթ ստանալու համար անձը ոստիկանություն է ներկայացնում նոր փաստաթուղթ ստանալու մասին դիմում և 2 գունավոր լուսանկար:
(24-րդ կետը փոփ. 18.03.10 N 317-Ն, 07.07.11 N 939-Ն, 01.03.12 N 219-Ն)
25. Կասկածյալների, որոնց նկատմամբ որպես խափանման միջոց է ընտրվել չհեռանալու մասին ստորագրությունը, և մեղադրյալների, որոնց նկատմամբ որպես խափանման միջոց է ընտրվել կալանավորումը, ինչպես նաև ազատազրկման դատապարտված անձանց փաստաթղթերը վերցվում են հետաքննության, նախաքննության մարմինների կամ դատարանի կողմից:
(25-րդ կետը փոփ. 01.03.12 N 219-Ն)
26. Խափանման միջոցի վերացման դեպքում` կասկածյալների և մեղադրյալների փաստաթղթերը վերադարձվում են տերերին:

(27-րդ կետը փոփ. 01.03.12 N 219-Ն)
28. Փաստաթուղթը վերցնելը (բացառությամբ սույն կարգի 25-րդ կետում նշված դեպքերի), այլ անձանց հանձնելը և գրավ դնելն արգելվում են:
