# Հավելված N 2 ՀՀ կառավարության 2002 թվականի նոյեմբերի 21-ի N 1925-Ն որոշման
«ՀԱՆՐԱՊԵՏԱԿԱՆ ՀԱԿԱՀԱՄԱՃԱՐԱԿԱՅԻՆ ԵՎ ԱԽՏՈՐՈՇԻՉ ԿԵՆՏՐՈՆ» ՊԵՏԱԿԱՆ ՈՉ ԱՌԵՎՏՐԱՅԻՆ ԿԱԶՄԱԿԵՐՊՈՒԹՅԱՆ ՆԵՐԿԱՅԱՑՈՒՑՉՈՒԹՅՈՒՆՆԵՐ
I. Մարզային ներկայացուցչություններ
Արագածոտնի մարզային ներկայացուցչություն
Արարատի մարզային ներկայացուցչություն
Արմավիրի մարզային ներկայացուցչություն
Գեղարքունիքի մարզային ներկայացուցչություն
Լոռու մարզային ներկայացուցչություն
Կոտայքի մարզային ներկայացուցչություն
Շիրակի մարզային ներկայացուցչություն
Սյունիքի մարզային ներկայացուցչություն
Վայոց ձորի մարզային ներկայացուցչություն
Տավուշի մարզային ներկայացուցչություն
Երևանի ներկայացուցչություն
II. Սահմանային հսկիչ անասնաբուժական կետերի ներկայացուցչություններ
Բավրայի սահմանային հսկիչ կետի ներկայացուցչություն
Բագրատաշենի սահմանային հսկիչ կետի ներկայացուցչություն
Գոգավանի սահմանային հսկիչ կետի ներկայացուցչություն
Ագարակի սահմանային հսկիչ կետի ներկայացուցչություն
Մարգարայի սահմանային հսկիչ կետի ներկայացուցչություն
Երևանի սահմանային հսկիչ կետի ներկայացուցչություն
Գյումրու Ախուրիկի սահմանային հսկիչ կետի ներկայացուցչություն
«Զվարթնոց» օդանավակայանի սահմանային հսկիչ կետի ներկայացուցչություն
III. Տրանսպորտային անասնաբուժասանիտարական տեղամասերի ներկայացուցչություններ
Երևանի երկաթգծի տրանսպորտային տեղամասի ներկայացուցչություն
Գյումրու երկաթգծի տրանսպորտային տեղամասի ներկայացուցչություն
Վանաձորի երկաթգծի տրանսպորտային տեղամասի ներկայացուցչություն
Այրումի երկաթգծի տրանսպորտային տեղամասի ներկայացուցչություն
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
