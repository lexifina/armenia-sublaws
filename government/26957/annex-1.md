# Հավելված ՀՀ կառավարության 2006 թվականի օգոստոսի 31-ի N 1308-Ն որոշման
Կ Ա Ր Գ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ՊԵՏԱԿԱՆ ԲՅՈՒՋԵԻ «ՏԱՐԵՑՆԵՐԻՆ ՄԱՏՈՒՑՎՈՂ ԾԱՌԱՅՈՒԹՅՈՒՆՆԵՐԻ ԾՐԱԳՐԻ ՇՐՋԱՆԱԿՆԵՐՈՒՄ ՏԱՐԵՑՆԵՐԻ ՇՈՒՐՋՕՐՅԱ ԽՆԱՄՔԻ ԻՐԱԿԱՆԱՑՄԱՆ ՆՊԱՏԱԿՈՎ ՊԵՏԱԿԱՆ ԱՋԱԿՑՈՒԹՅՈՒՆ ՀՀ ԱՇԽԱՏԱՆՔԻ ԵՎ ՍՈՑԻԱԼԱԿԱՆ ՀԱՐՑԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ՀԱՄԱԿԱՐԳԻ ՏԱՐԵՑՆԵՐԻ ՏՈՒՆ-ԻՆՏԵՐՆԱՏ ՀԱՆԴԻՍԱՑՈՂ ՊՈԱԿ-ՆԵՐԻՆ» ԵՎ «ԸՆՏԱՆԻՔՆԵՐԻՆ, ԿԱՆԱՆՑ ԵՎ ԵՐԵԽԱՆԵՐԻՆ ՄԱՏՈՒՑՎՈՂ ԾԱՌԱՅՈՒԹՅՈՒՆՆԵՐԻ ԾՐԱԳՐԻ ՇՐՋԱՆԱԿՆԵՐՈՒՄ ԵՐԵԽԱՆԵՐԻ ՇՈՒՐՋՕՐՅԱ ԽՆԱՄՔԻ ԻՐԱԿԱՆԱՑՄԱՆ ՆՊԱՏԱԿՈՎ ՊԵՏԱԿԱՆ ԱՋԱԿՑՈՒԹՅՈՒՆ ՀՀ ԱՇԽԱՏԱՆՔԻ ԵՎ ՍՈՑԻԱԼԱԿԱՆ ՀԱՐՑԵՐԻ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ՀԱՄԱԿԱՐԳԻ ԵՐԵԽԱՆԵՐԻ ՏՈՒՆ-ԻՆՏԵՐՆԱՏ ՀԱՆԴԻՍԱՑՈՂ ՊՈԱԿ-ՆԵՐԻՆ» ԾՐԱԳՐԵՐԻ ՇՐՋԱՆԱԿՆԵՐՈՒՄ ՓԱՍՏԱՑԻ ԽՆԱՄՎՈՂՆԵՐԻ ԹՎԱՔԱՆԱԿԻՑ ԵԼՆԵԼՈՎ ՏՈՒՆ-ԻՆՏԵՐՆԱՏՆԵՐԻ ՀԱՄԱՐ ՆԱԽԱՏԵՍՎԱԾ ԽՆԱՄՎՈՂՆԵՐԻ ԹՎԱՔԱՆԱԿԻ ԵՎ ԴՐԱՆՑ ԽՆԱՄՔԻ ԻՐԱԿԱՆԱՑՄԱՆ ՀԱՄԱՐ ԱՆՀՐԱԺԵՇՏ ՖԻՆԱՆՍԱԿԱՆ ՄԻՋՈՑՆԵՐԻ ՎԵՐԱՀԱՇՎԱՐԿՄԱՆ
1. Սույն կարգով կանոնակարգվում են Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարության (այսուհետ` նախարարություն) ենթակայությանը հանձնված տարեցների և երեխաների տուն-ինտերնատներում (այսուհետ` տուն-ինտերնատ) խնամվողների փաստացի թվաքանակից ելնելով` Հայաստանի Հանրապետության պետական բյուջեի «Տարեցներին մատուցվող ծառայությունների ծրագրի շրջանակներում տարեցների շուրջօրյա խնամքի իրականացման նպատակով պետական աջակցություն Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարության համակարգի տարեցների տուն-ինտերնատ հանդիսացող ՊՈԱԿ-ներին» և «Ընտանիքներին, կանանց և երեխաներին մատուցվող ծառայությունների ծրագրի շրջանակներում երեխաների շուրջօրյա խնամքի իրականացման նպատակով պետական աջակցություն Հայաստանի Հանրապետության աշխատանքի և սոցիալական հարցերի նախարարության համակարգի երեխաների տուն-ինտերնատ հանդիսացող ՊՈԱԿ-ներին» ծրագրերի (այսուհետ` ծրագրեր) շրջանակներում տուն-ինտերնատների համար նախատեսված խնամվողների թվաքանակի և դրանց խնամքի իրականացման համար անհրաժեշտ ֆինանսական միջոցների վերահաշվարկման հարցերը:
2. Տուն-ինտերնատում խնամվողների ժամանակավոր բացակայությունների դեպքում (բացառությամբ խնամվողների հիվանդանոցային բուժման մեջ գտնվելու դեպքերը), նախարարությունը մատուցված ծառայության դիմաց վճարման ենթակա մեկ խնամվողի միջին օրական հաշվարկված ծախսից պակաս է վճարում միայն «Սննդի ձեռքբերման ծախսեր» ծախսային հոդվածով նախատեսված գումարը:
3. Տուն-ինտերնատի համար նախատեսված խնամվողների թվաքանակը մինչև 20 տոկոս պակաս լինելու դեպքում` նախարարությունը մատուցված ծառայության դիմաց վճարման ենթակա մեկ խնամվողի միջին օրական հաշվարկված ծախսից պակաս է վճարում միայն «Սննդի ձեռքբերման ծախսեր», «Այլ ծառայությունների ձեռքբերման ծախսեր» և «Այլ ծախսեր» ծախսային հոդվածներով նախատեսված գումարները:
4. Տուն-ինտերնատի համար նախատեսված խնամվողների թվաքանակը 20 և ավելի տոկոս թերակատարվելու դեպքում՝ նախարարությունը մատուցված ծառայության դիմաց վճարման ենթակա մեկ խնամվողի միջին օրական հաշվարկված ծախսից վճարում է միայն «Աշխատավարձ» և «Պարտադիր սոցիալական ապահովագրական վճարներ» ծախսային հոդվածներով նախատեսված գումարները:
5. Տուն-ինտերնատի համար նախատեսված խնամվողների փաստացի թվաքանակը նախատեսվածից մինչև 20 տոկոս ավելի լինելու դեպքում նախարարությունը մատուցված ծառայության դիմաց վճարման ենթակա մեկ խնամվողի միջին օրական հաշվարկված ծախսից պակաս է վճարում միայն «Գույքի և սարքավորումների ձեռքբերում», «Գործուղումներ և ծառայողական ուղևորություններ», «Տրանսպորտային ծառայությունների վճար», «Կապի ծառայությունների վճար», «Էլեկտրաէներգիայի, վառելիքի և ջեռուցման ծախսեր» և «Այլ կոմունալ ծախսեր» ծախսային հոդվածներով նախատեսված գումարները:
(5-րդ կետը լրաց. 16.11.06 N 1621-Ն)
6. Տուն-ինտերնատի համար նախատեսված խնամվողների փաստացի թվաքանակը նախատեսվածից 20 և ավելի տոկոս ավելի լինելու դեպքում նախարարությունը մատուցված ծառայության դիմաց վճարման ենթակա մեկ խնամվողի միջին օրական հաշվարկված ծախսից պակաս է վճարում միայն «Գույքի և սարքավորումների ձեռքբերում», «Գործուղումներ և ծառայողական ուղևորություններ», «Քաղաքային հեռախոսների աբոնենտային վճարի կատարման ծախսեր» և «Այլ կոմունալ ծախսեր» ծախսային հոդվածներով նախատեսված գումարները:
(6-րդ կետը լրաց. 16.11.06 N 1621-Ն)
(հավելվածը լրաց. 16.11.06 N 1621-Ն)
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարար | Մ. Թոփուզյան
