2. Սահմանել, որ՝
1) սույն որոշմամբ նախատեսված սակագնային քվոտայի կիրառումը տարածվում է Հայաստանի Հանրապետության տարածք «Բացթողում՝ ներքին սպառման համար» մաքսային ընթացակարգի կիրառմամբ ներմուծվող՝ սույն որոշման N 1 հավելվածում նշված իրանական ծագում ունեցող առանձին տեսակի ապրանքների վրա.
2) 2025 թվականի ընթացքում իրանական ծագում ունեցող առանձին տեսակի ապրանքների ներմուծումը Իրանի Իսլամական Հանրապետությունից թույլատրվում է 0 տոկոս ներմուծման մաքսատուրքի դրույքաչափի կիրառման պայմանով` լիցենզիայի առկայության դեպքում․
3) իրանական ծագում ունեցող առանձին տեսակի ապրանքների ներմուծման լիցենզիա տալու մասով լիազոր մարմին է ճանաչվում Հայաստանի Հանրապետության էկոնոմիկայի նախարարությունը (այսուհետ` լիազոր մարմին)․
4) արտաքին տնտեսական գործունեության մասնակիցների միջև իրանական ծագում ունեցող առանձին տեսակի ապրանքների՝ Իրանի Իսլամական Հանրապետությունից Հայաստանի Հանրապետության տարածք ներմուծման թույլատրելի ծավալի բաշխման ընթացակարգը` համաձայն N 2 հավելվածի.
5) ԵԱՏՄ ԱՏԳ ԱԱ 2002 90 110 0, 2002 90 190 0, 2002 90 310 0, 2002 90 390 0, 2002 90 910 0, 2002 90 990 0 ծածկագրերին դասվող լոլիկներ՝ պատրաստված կամ պահածոյացված առանց քացախի կամ քացախաթթվի հավելման ապրանքների ներմուծման լիցենզիայի գործողության ժամկետ է սահմանվում 2025 թվականի հոկտեմբերի 16-ից մինչև 2025 թվականի դեկտեմբերի 31-ը ներառյալ:
(2-րդ կետը լրաց. 09.10.25 N 1428-Ն)
