# Հավելված N 2 ՀՀ կառավարության 2010 թվականի հոկտեմբերի 21-ի N 1361-Ն որոշման

Ս. Կարայան | - ՀՀ ֆինանսների նախարարի տեղակալ (խորհրդի նախագահ)
Գ. Մուրադյան | - ՀՀ արդարադատության նախարարի առաջին տեղակալ
Վ. Միրումյան | - ՀՀ կառավարությանն առընթեր պետական եկամուտների կոմիտեի նախագահի տեղակալ
Տ. Բարսեղյան | - ՀՀ կառավարությանն առընթեր պետական եկամուտների կոմիտեի նախագահի տեղակալ
Կ. Մինասյան | - ՀՀ էկոնոմիկայի նախարարի տեղակալ
Լ. Հունանյան | - ՀՀ կառավարության աշխատակազմի ֆինանսատնտեսագիտական վարչության պետ
Ա. Պողոսյան | - ՀՀ ֆինանսների նախարարության աշխատակազմի պետական եկամուտների քաղաքականության և վարչարարության մեթոդաբանության վարչության պետ
Ա. Մնացականյան | - ՀՀ ֆինանսների նախարարության աշխատակազմի իրավաբանական վարչության պետ
Հ. Թորոսյան | - ՀՀ կառավարությանն առընթեր պետական եկամուտների կոմիտեի հարկային տեսչությունների աշխատանքների համակարգման վարչության հարկային հսկողության համակարգման և կազմակերպման բաժնի պետ
(հավելվածը փոփ. 03.03.11 N 182-Ն, խմբ. 16.08.12 N 1044-Ն)
