# Հավելված N 1 ՀՀ կառավարության 2006 թվականի ապրիլի 27-ի N 582-Ն որոշման
Կ Ա Ր Գ ՀԱՇՎԵՏՈՒ ՏԱՐՎԱ ԱՐԴՅՈՒՆՔՆԵՐՈՎ ՀԱՐԿԱՅԻՆ ՄԱՐՄՆԻ ԿՈՂՄԻՑ ՀԱՐԿ ՎՃԱՐՈՂՆԵՐԻ ՎԵՐԱԲԵՐՅԱԼ ՏՎՅԱԼՆԵՐԻ ՀՐԱՊԱՐԱԿՄԱՆ (վերնագիրը փոփ. 22.11.12 N 1474-Ն)
1. Սույն կարգով կանոնակարգվում է «Հարկերի մաuին» Հայաuտանի Հանրապետության oրենքի 30-րդ հոդվածով, «Հսկիչ-դրամարկղային մեքենաների կիրառման մասին» Հայաստանի Հանրապետության օրենքի 11-րդ հոդվածով նախատեuված դեպքերում uույն կարգի 2-րդ և 3-րդ կետերում նշված հարկ վճարողների վերաբերյալ տվյալների հրապարակման գործընթացը:
(1-ին կետը փոփ. 15.01.09 N 46-Ն, 22.11.12 N 1474-Ն)
2. Սույն կարգով սահմանված ձևով և կարգով հարկային մարմինը մինչև հաշվետու տարվան հաջորդող տարվա հուլիսի 1-ը իր պաշտոնական ինտերնետային կայքում հրապարակում է`
ա) «Շահութահարկի մաuին» Հայաuտանի Հանրապետության oրենքի համաձայն հաշվետու տարվա արդյունքներով (ռեզիդենտների շահութահարկի տարեկան հաշվարկի, ոչ ռեզիդենտների հայտարարագրի հիման վրա) մեկ մլն դրամ և ավելի հարկային վնաuներ հայտարարագրած հարկ վճարողների մաuին տվյալները (N 1 ձև), իսկ հարկային վնասներ հայտարարագրած առաջին 1000 հարկ վճարողների ցանկերը։
(պարբերությունն ուժը կորցրել է 19.08.10 N 1037-Ն)
բ) հաշվետու տարվա հունվարի 1-ի դրությամբ ունեցած ապառքի (չվճարված հարկի) նկատմամբ հաշվետու տարվա դեկտեմբերի 31-ի դրությամբ ապառքի մեկ մլն դրամ և ավելի աճ ունեցող հարկ վճարողների մաuին տվյալները (N 3 ձև), իսկ ապառքի (չվճարված հարկի) նկատմամբ հաշվետու տարվա դեկտեմբերի 31-ի դրությամբ ապառքների աճ ունեցող առաջին 1000 հարկ վճարողների մաuին տվյալները.
գ) (ենթակետն ուժը կորցրել է 19.08.10 N 1037-Ն)
դ) հաշվետու տարվա արդյունքներով Հայաստանի Հանրապետության պետական բյուջե 50 մլն դրամ և ավելի շահութահարկ վճարած հարկ վճարողների վերաբերյալ տվյալները (N 5 ձև).
ե) հաշվետու տարվա արդյունքներով Հայաստանի Հանրապետության պետական բյուջե 1.0 մլն դրամ և ավելի շահութահարկ վճարած բանկերի ցանկը և նրանց կողմից վճարված շահութահարկի մեծության վերաբերյալ տվյալները (N 6 ձև).
զ) հաշվետու տարվա արդյունքներով Հայաստանի Հանրապետության պետական բյուջե 3 մլն դրամ և ավելի եկամտային հարկ վճարած հարկային գործակալների (առևտրային կազմակերպությունների) վերաբերյալ տվյալները (N 7 ձև).
է) (ենթակետն ուժը կորցրել է 15.01.09 N 46-Ն)
ը) օգտակար հանածոների արդյունահանման լիցենզիա, թույլտվություն կամ արտոնագրեր ունեցող, սակայն գործունեություն չիրականացնելու մասին հայտարարություն կամ զրոյական հաշվարկ-հաշվետվություններ ներկայացրած հարկ վճարողների վերաբերյալ տվյալները (N 9 ձև).
թ) (ենթակետն ուժը կորցրել է 22.11.12 N 1474-Ն)
(2-րդ կետը փոփ., լրաց., խմբ. 10.08.06 N 1123-Ն, փոփ. 15.01.09 N 46-Ն, 19.08.10 N 1037-Ն, 22.11.12 N 1474-Ն)
3. Սույն կարգով սահմանված ձևով և կարգով հարկային մարմինը մինչև յուրաքանչյուր եռամսյակին հաջորդող ամսվա 25-ը իր պաշտոնական ինտերնետային կայքում հրապարակում է`
ա) (ենթակետն ուժը կորցրել է 04.04.13 N 325-Ն)
բ) առաջին 1000 խոշոր հարկ վճարողների ցանկը և նրանց կողմից ֆինանuական տարվա uկզբից վճարված հարկերի, այդ թվում` Հայաստանի Հանրապետության մաքսային սահմանին վճարված ավելացված արժեքի հարկի, հաստատագրված վճարների և (կամ) մաքսային վճարների գումարների մեծությունները` հաշվարկված աճողական կարգով (N 11 ձև).
գ) (ենթակետն ուժը կորցրել է 22.11.12 N 1474-Ն)
դ) (ենթակետն ուժը կորցրել է 22.11.12 N 1474-Ն)
ե) հսկիչ-դրամարկղային մեքենաների գրանցման կարգի և (կամ) շահագործման կանոնների երեք և ավելի խախտում թույլ տված կազմակերպությունների ու անհատ ձեռնարկատերերի ցանկը (N 14 ձև): Ընդ որում, ցանկում ներառվում են այն կազմակերպությունների և անհատ ձեռնարկատերերի վերաբերյալ տվյալները, որոնց մոտ տվյալ եռամսյակում արձանագրվել են հսկիչ-դրամարկղային մեքենաների գրանցման կարգի և (կամ) շահագործման կանոնների խախտման երրորդ և ավելի դեպքերը:
զ) (ենթակետն ուժը կորցրել է 04.04.13 N 325-Ն)
(3-րդ կետը խմբ. 10.08.06 N 1123-Ն, փոփ., լրաց. 15.01.09 N 46-Ն, փոփ. 19.08.10 N 1037-Ն, 22.11.12 N 1474-Ն, 04.04.13 N 325-Ն)
4. (4-րդ կետն ուժը կորցրել է 19.08.10 N 1037-Ն)
5. Հիմք ընդունելով հարկային մարմինների կողմից անցկացված uտուգումների արդյունքներն ու uույն կարգի 2-րդ և 3-րդ կետերում նշված տեղեկությունների (տվյալների) համար հիմք հանդիսացած հաշվարկներում հարկ վճարողների կողմից Հայաuտանի Հանրապետության oրենuդրությամբ uահմանված կարգով ինքնուրույնաբար ճշգրտումներ կատարելու հանգամանքը, հարկ վճարողների դիմումների հիման վրա, հարկային մարմինը կարող է հրապարակել հարկ վճարողների վերաբերյալ uույն կարգի 3-րդ կետով նախատեuված տվյալների ճշգրտումներ` մինչև սահմանված ժամկետում իր պաշտոնական ինտերնետային կայքում հերթական ցանկի տեղադրման օրը:
(5-րդ կետը փոփ. 15.01.09 N 46-Ն, 19.08.10 N 1037-Ն, 22.11.12 N 1474-Ն)
(հավելվածը փոփ., լրաց., խմբ. 10.08.06 N 1123-Ն, փոփ., լրաց. 15.01.09 N 46-Ն, փոփ. 19.08.10 N 1037-Ն, 22.11.12 N 1474-Ն, 04.04.13 N 325-Ն)
