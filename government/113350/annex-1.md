# Հավելված ՀՀ կառավարության 2017 թվականի մայիսի 18-ի N 515-Ն որոշման
Կ Ա Ր Գ
ԼՈՒԾԱՐՄԱՆ (ՊԵՏԱԿԱՆ ՀԱՇՎԱՌՈՒՄԻՑ ՀԱՆՄԱՆ) ԵՆԹԱԿԱ ՀԱՐԿ ՎՃԱՐՈՂՆԵՐԻ ՑԱՆԿԵՐԸ ԵՎ ՑԱՆԿԵՐՈՒՄ ՆԵՐԱՌՎԱԾ ՀԱՐԿ ՎՃԱՐՈՂՆԵՐԻ` ՀԱՐԿԱՅԻՆ ՄԱՐՄՆԻ ԿՈՂՄԻՑ ՎԵՐԱՀՍԿՎՈՂ ՊԱՐՏԱՎՈՐՈՒԹՅՈՒՆՆԵՐԻ ԲԱՑԱԿԱՅՈՒԹՅԱՆ ՄԱՍԻՆ ՏԵՂԵԿԱՆՔԸ ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԱՐԴԱՐԱԴԱՏՈՒԹՅԱՆ ՆԱԽԱՐԱՐՈՒԹՅԱՆ ԱՇԽԱՏԱԿԱԶՄԻ ԻՐԱՎԱԲԱՆԱԿԱՆ ԱՆՁԱՆՑ ՊԵՏԱԿԱՆ ՌԵԳԻՍՏՐԻ ԳՈՐԾԱԿԱԼՈՒԹՅՈՒՆ ՆԵՐԿԱՅԱՑՆԵԼՈՒ
1. Սույն կարգով կարգավորվում են «Հարկային հաշվետվություններ չներկայացրած կազմակերպությունները լուծարելու և անհատ ձեռնարկատերերին պետական հաշվառումից հանելու մասին» Հայաստանի Հանրապետության օրենքով (այսուհետ՝ օրենք) սահմանված լուծարման (պետական հաշվառումից հանման) ենթակա հարկ վճարողների ցանկերը և ցանկերում ներառված հարկ վճարողների` հարկային մարմնի կողմից վերահսկվող պարտավորությունների բացակայության մասին տեղեկանքը Հայաստանի Հանրապետության արդարադատության նախարարության աշխատակազմի իրավաբանական անձանց պետական ռեգիստրի գործակալություն (այսուհետ՝ պետական ռեգիստր) ներկայացնելու հետ կապված հարաբերությունները:
2. Հարկային մարմինը մինչև 2017 թվականի հուլիսի 1-ը կազմում է օրենքով սահմանված կարգով լուծարման (պետական հաշվառումից հանման) ենթակա հարկ վճարողների ցանկեր (այսուհետ՝ ցանկ) և ցանկերում ներառված հարկ վճարողների` հարկային մարմնի կողմից վերահսկվող պարտավորությունների բացակայության մասին տեղեկանք:
3. Ցանկում ներառվում են այն հարկ վճարողները`
1) որոնք «Հայաստանի Հանրապետության քաղաքացիական օրենսգիրքը գործողության մեջ դնելու մասին» Հայաստանի Հանրապետության օրենքի 6-րդ հոդվածի համաձայն չեն վերագրանցվել, կամ՝
2) որոնց հիմնադիր կազմակերպությունները լուծարված են, կամ՝
3) որոնք 2013 թվականի հունվարի 1-ից մինչև 2017 թվականի հունվարի 1-ը հարկային մարմին չեն ներկայացրել որևէ հաշվետվություն, հաշվարկ կամ հայտարարագիր և միաժամանակ բավարարում են ստորև նշված պայմանները՝
ա. չունեն իրենց անվամբ գրանցված գույք (անհատ ձեռնարկատիրոջ մասով` անհատ ձեռնարկատիրոջ անվամբ հաշվառված),
բ. 2017 թվականի հունվարի 1-ի դրությամբ հարկային մարմնի կողմից վերահսկվող եկամուտների գծով ընդհանուր պարտավորությունները չեն գերազանցել տասը հազար դրամը:
4. Ցանկերում նշվում են կազմակերպության անվանումը (անհատ ձեռնարկատիրոջ դեպքում՝ անունը և ազգանունը), հարկային մարմնին հայտնի կամ պետական ռեգիստրում նշված` կազմակերպության գտնվելու վայրը (անհատ ձեռնարկատիրոջ դեպքում` բնակության վայրը), հարկ վճարողի հաշվառման համարը:
5. Հարկային մարմինը մինչև 2017 թվականի հուլիսի 1-ը էլեկտրոնային եղանակով պետական ռեգիստր է ներկայացնում ցանկերը և հարկային մարմնի կողմից վերահսկվող պարտավորությունների բացակայության մասին տեղեկանքը՝ օրենքով սահմանված կարգով լուծարման (պետական հաշվառումից հանման) պետական գրանցումն իրականացնելու համար:
Հայաստանի Հանրապետության կառավարության աշխատակազմի ղեկավար-նախարարի պաշտոնակատար | Դ. Հարությունյան
