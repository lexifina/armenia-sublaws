# Armenia sub-laws

Work in progress: the normative sub-laws of the Republic of Armenia (government and prime-minister decisions, ministerial orders) from ARLIS (www.arlis.am), with every consolidated text, one commit per amending act per in-force day. Built by scripts/armenia-law with `--set sublaws`; companion to lexifina/armenia-law. Corpus path am/national/sublaws.

The build streams to the `wip` branch; `main` gets the history once the first clean build passes its checks.
